> 상위: # 마이너 버전 업그레이드 (Minor Version Upgrade with a Package Manager) — EPAS 18 Upgrading

## 1. RPM 설치의 마이너 버전 업그레이드

> 원문: [05_performing_a_minor_version_update_of_an_rpm_installation](https://www.enterprisedb.com/docs/epas/latest/upgrading/minor_upgrade/05_performing_a_minor_version_update_of_an_rpm_installation/)

Red Hat Enterprise Linux 기반 시스템 또는 Rocky Linux, Alma Linux, Oracle Linux 같은 호환 시스템을 업그레이드하는 경우, EDB Postgres Advanced Server를 RPM 패키지로 설치한 것입니다. 이러한 시스템에서 마이너 업그레이드를 수행하려면 DNF 패키지 관리자를 사용합니다.

> **참고**: 이 절차는 EDB Postgres Advanced Server의 마이너 릴리스 간 업그레이드만 수행합니다. 이후 메이저 릴리스로 업그레이드하려면 [`pg_upgrade` 절차](https://www.enterprisedb.com/docs/epas/latest/upgrading/major_upgrade/)를 사용하십시오.

1. 시스템에 사용 가능한 패키지 업데이트를 나열하려면, 명령줄을 열고 root 권한을 획득한 뒤 다음을 실행합니다.
   ```shell
   dnf check-update <package_name>
   ```
   여기서 `package_name`은 사용 가능한 업데이트를 나열할 검색어입니다. 검색에 와일드카드 값을 포함하여 한 번의 명령으로 관련 패키지 여러 개를 나열할 수 있습니다. 예를 들어 이름이 `edb`로 시작하는 모든 패키지를 나열하려면 다음 명령을 사용합니다.
   ```shell
   dnf check-update edb*
   ```

2. 패키지를 확인한 후 업데이트합니다.
   ```shell
   dnf update <package_name>
   ```
   여기서 `package_name`은 업데이트할 패키지 이름입니다. 와일드카드 값을 포함하여 한 번의 명령으로 관련 패키지 여러 개를 업데이트할 수 있습니다. 예를 들어 이름이 `edb`로 시작하는 모든 패키지를 업데이트하려면 다음 명령을 사용합니다.
   ```shell
   dnf update edb*
   ```

3. 업그레이드를 완료하려면 서버를 재시작합니다.

DNF 명령과 옵션에 대한 자세한 내용은 명령줄에서 `dnf --help`를 입력하십시오.

> **중요**: 버전 15.4 이상으로 업그레이드하는 경우 `edb_sqlpatch`를 실행하십시오.
>
> 이 명령은 적용해야 할 패치가 여러 개 있다고 응답할 수 있습니다. 예:
> ```shell-session
> * database edb
> 0 patches were previously applied to this database.
> 58 patches need to be applied to this database.
> ```
> 이 경우 시스템 카탈로그를 패치하기 위해 `edb_sqlpatch`를 실행해야 합니다.
> ```shell
> edb_sqlpatch -af
> ```
> `edb_sqlpatch` 명령과 옵션에 대한 자세한 내용은 [edb_sqlpatch](https://www.enterprisedb.com/docs/tools/edb_sqlpatch/)를 참고하십시오.
