# pg_upgrade를 사용한 메이저 버전 업그레이드 (Major version upgrade with pg_upgrade) — EPAS 18 업그레이드

> 원문: [EPAS v18 — Upgrading › Major version upgrade with pg_upgrade](https://www.enterprisedb.com/docs/epas/latest/upgrading/major_upgrade/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

##### 참고 (Note)

`pg_upgrade` 유틸리티로 업그레이드를 수행하기 전에 [업그레이드 고려사항(upgrade considerations)](https://www.enterprisedb.com/docs/epas/latest/upgrading/major_upgrade/03_limitations/)을 검토하십시오.

버전 간 마이너 업그레이드는 비교적 간단하며 새 실행 파일을 설치하기만 하면 되지만, 과거의 메이저 버전 업그레이드는 비용이 많이 들고 시간도 오래 걸렸습니다. `pg_upgrade`는 EDB Postgres Advanced Server의 모든 버전(버전 9.0 이상)과 같은 플랫폼에서 지원되는 이후의 모든 EDB Postgres Advanced Server 릴리스 간의 마이그레이션을 쉽게 만들어 줍니다.

`pg_upgrade`를 사용하면 많은 메이저 버전 업그레이드에서 소요되는 시간과 필요한 디스크 공간을 모두 줄일 수 있습니다.
