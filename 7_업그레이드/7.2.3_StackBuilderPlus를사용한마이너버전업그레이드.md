> 상위: # 마이너 버전 업그레이드 (Minor Version Upgrade with a Package Manager) — EPAS 18 Upgrading

## 3. StackBuilder Plus를 사용한 마이너 버전 업그레이드

> 원문: [06_using_stackbuilder_plus_to_perform_a_minor_version_update](https://www.enterprisedb.com/docs/epas/latest/upgrading/minor_upgrade/06_using_stackbuilder_plus_to_perform_a_minor_version_update/)

> **참고**: StackBuilder Plus는 Windows 시스템에서만 지원됩니다.

StackBuilder Plus 유틸리티는 EDB Postgres Advanced Server 설치를 보완하는 모듈을 업데이트·다운로드·설치하는 과정을 단순화하는 그래픽 인터페이스를 제공합니다. StackBuilder Plus로 모듈을 설치하면 소프트웨어 의존성을 자동으로 해결합니다.

1. 설치 완료 후 언제든 StackBuilder Plus를 실행하려면 **Apps > StackBuilder Plus**를 선택합니다. 요청되면 시스템 비밀번호를 입력하면 StackBuilder Plus 환영(welcome) 창이 열립니다.

2. EDB Postgres Advanced Server 설치를 선택합니다.
   StackBuilder Plus는 인터넷 접근이 필요합니다. EDB Postgres Advanced Server 설치가 방화벽 뒤에 있어(인터넷 접근이 제한된 경우) StackBuilder Plus는 프록시 서버를 통해 프로그램 설치 파일을 다운로드할 수 있습니다. 모듈 제공자는 해당 모듈이 HTTP 프록시 또는 FTP 프록시로 접근 가능한지 결정합니다. 현재 모든 업데이트는 HTTP 프록시로 전송되며 FTP 프록시 정보는 사용되지 않습니다.

3. 선택한 EDB Postgres Advanced Server 설치가 인터넷 접근이 제한되어 있다면, 환영 화면에서 **Proxy Servers**를 선택하여 Proxy servers 대화 상자를 엽니다.

4. 대화 상자의 **HTTP proxy** 상자에 프록시 서버의 IP 주소와 포트 번호를 입력합니다. 현재 모든 StackBuilder Plus 모듈은 HTTP 프록시로 배포됩니다(FTP 프록시 정보는 무시됨). **OK**를 선택합니다.
   StackBuilder Plus 모듈 선택 창의 트리 컨트롤에 각 모듈 범주에 대한 노드가 표시됩니다.

5. 선택한 EDB Postgres Advanced Server 설치에 구성 요소를 추가하거나 구성 요소를 업그레이드하려면, 모듈 이름 왼쪽의 상자를 선택하고 **Next**를 선택합니다.

6. 요청되면 StackBuilder Plus 등록 창에 이메일 주소와 비밀번호를 입력합니다.
   StackBuilder Plus가 선택한 패키지를 확인합니다. Selected packages 대화 상자에 설치 파일의 이름과 버전이 표시됩니다. **Next**를 선택합니다.
   다운로드가 완료되면 설치 파일이 다운로드되어 설치 준비가 되었음을 확인하는 창이 열립니다.

7. **Skip Installation** 체크 박스를 비운 상태로 두고 **Next**를 선택하여 설치 과정을 시작합니다. (체크 박스를 선택하고 **Next**를 선택하면 다운로드한 파일을 설치하지 않고 StackBuilder Plus를 종료합니다.)

업그레이드가 완료되면 StackBuilder Plus가 요청한 패키지 설치의 성공 또는 실패를 알립니다. 설치 프로그램이 컴퓨터 재시작을 요청했다면 지금 재시작하십시오.

업데이트 설치에 실패하면 StackBuilder Plus가 설치 오류를 알리고 `%TEMP%`의 로그 파일에 메시지를 기록합니다.
