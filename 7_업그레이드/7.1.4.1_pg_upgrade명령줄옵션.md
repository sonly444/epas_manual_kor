## 4.1 pg_upgrade 명령줄 옵션 (Command line options for pg_upgrade)

> 원문: [02_invoking_pg_upgrade/01_command_line_options_reference](https://www.enterprisedb.com/docs/epas/latest/upgrading/major_upgrade/02_invoking_pg_upgrade/01_command_line_options_reference/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·옵션·경로는 원문 그대로 보존했습니다.

`pg_upgrade`는 다음 명령줄 옵션을 받습니다. 각 옵션은 긴 형식(long form)과 짧은 형식(short form)으로 사용할 수 있습니다.

**`-b path_to_old_bin_directory`**
**`--old-bindir path_to_old_bin_directory`**
`-b` 또는 `--old-bindir` 키워드로 이전 클러스터의 실행 파일 디렉터리 위치를 지정합니다.

**`-B path_to_new_bin_directory`**
**`--new-bindir path_to_new_bin_directory`**
`-B` 또는 `--new-bindir` 키워드로 새 클러스터의 실행 파일 디렉터리 위치를 지정합니다.

**`-c`**
**`--check`**
`-c` 또는 `--check` 키워드를 포함하면 `pg_upgrade`가 버전 업그레이드를 수행하지 않고 이전 클러스터와 새 클러스터에 대해 일관성 검사(consistency check)만 수행하도록 지정합니다.

**`-d path_to_old_data_directory`**
**`--old-datadir path_to_old_data_directory`**
`-d` 또는 `--old-datadir` 키워드로 이전 클러스터의 `data` 디렉터리 위치를 지정합니다.

**`-D path_to_new_data_directory`**
**`--new-datadir path_to_new_data_directory`**
`-D` 또는 `--new-datadir` 키워드로 새 클러스터의 `data` 디렉터리 위치를 지정합니다.

사용자 정의 테이블스페이스(user-defined tablespace)에 저장된 데이터는 새 클러스터로 복사되지 않습니다. 이 데이터는 파일 시스템의 동일한 위치에 그대로 남지만, 새 클러스터의 버전 번호를 반영하는 이름의 하위 디렉터리로 복사됩니다. 업그레이드 후 테이블스페이스에 저장된 파일을 수동으로 재배치하려면, 파일을 새 위치로 옮기고 심볼릭 링크(클러스터의 `data` 디렉터리 아래 `pg_tblspc` 디렉터리에 위치)를 해당 파일을 가리키도록 갱신해야 합니다.

**`-j`**
**`--jobs`**
`-j` 또는 `--jobs` 키워드를 포함하여 업그레이드 중 사용할 동시 프로세스 또는 스레드 수를 지정합니다.

**`-k`**
**`--link`**
`-k` 또는 `--link` 키워드를 포함하면 새 클러스터에서 이전 클러스터로 하드 링크(hard link)를 생성합니다. 심볼릭 링크 사용에 대한 자세한 내용은 [링크 대 복사(Linking versus copying)](https://www.enterprisedb.com/docs/epas/latest/upgrading/major_upgrade/01_performing_an_upgrade/01_linking_versus_copying/#linking_versus_copying)를 참고하십시오.

**`-o options`**
**`--old-options options`**
`-o` 또는 `--old-options` 키워드로 이전 `postgres` 명령에 전달할 옵션을 지정합니다. 옵션이 하나의 그룹으로 전달되도록 작은따옴표 또는 큰따옴표로 묶습니다.

**`-O options`**
**`--new-options options`**
`-O` 또는 `--new-options` 키워드로 새 `postgres` 명령에 전달할 옵션을 지정합니다. 옵션이 하나의 그룹으로 전달되도록 작은따옴표 또는 큰따옴표로 묶습니다.

**`-p old_port_number`**
**`--old-port old_port_number`**
`-p` 또는 `--old-port` 키워드를 포함하여 업그레이드하려는 EDB Postgres Advanced Server 설치의 포트 번호를 지정합니다.

**`-P new_port_number`**
**`--new-port new_port_number`**
`-P` 또는 `--new-port` 키워드를 포함하여 새 EDB Postgres Advanced Server 설치의 포트 번호를 지정합니다.

> **참고**
> 기존 EDB Postgres Advanced Server 설치가 포트 번호 `5444`를 사용하는 상태에서 EDB Postgres Advanced Server 인스톨러를 실행하면, 인스톨러는 새 EDB Postgres Advanced Server 설치에 리스너 포트 `5445`를 사용할 것을 권장합니다.

**`-r`**
**`--retain`**
업그레이드 과정에서 `pg_upgrade`는 4개의 추가 전용(append-only) 로그 파일을 생성합니다. 업그레이드가 완료되면 `pg_upgrade`는 이 파일들을 삭제합니다. `pg_upgrade` 로그 파일을 보존하려면 `-r` 또는 `--retain` 옵션을 포함합니다.

**`-U user_name`**
**`--username user_name`**
`-U` 또는 `--username` 키워드를 포함하여 EDB Postgres Advanced Server 데이터베이스 슈퍼유저의 이름을 지정합니다. 동일한 슈퍼유저가 두 클러스터 모두에 존재해야 합니다.

**`-v`**
**`--verbose`**
`-v` 또는 `--verbose` 키워드를 포함하여 업그레이드 과정에서 상세 출력(verbose output)을 활성화합니다.

**`-V`**
**`--version`**
`-V` 또는 `--version` 키워드로 `pg_upgrade`의 버전 정보를 표시합니다.

**`-?`**
**`-h`**
**`--help`**
`-?`, `-h`, 또는 `--help` 옵션으로 `pg_upgrade` 도움말 정보를 표시합니다.
