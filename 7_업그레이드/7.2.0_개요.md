# 마이너 버전 업그레이드 (Minor Version Upgrade with a Package Manager) — EPAS 18 Upgrading

> 원문: [EPAS v18 — Upgrading › Minor version upgrade with a package manager](https://www.enterprisedb.com/docs/epas/latest/upgrading/minor_upgrade/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·패키지명은 원문 그대로 보존했습니다.

마이너 버전 업그레이드는 기존 실행 파일을 갱신하고 데이터베이스 서버를 재시작하는 것만 필요합니다.

데이터베이스 서버의 기반 운영체제에 따라 마이너 업그레이드 방법을 선택하십시오.

- EDB Postgres Advanced Server를 RPM 패키지로 설치했다면(RHEL, AlmaLinux, Rocky Linux에서 `dnf`로 설치), 아래 **RPM 설치의 마이너 버전 업그레이드**를 참고하십시오.
- Debian 패키지로 설치했다면(Ubuntu, Debian에서 `apt-get`으로 설치), 아래 **Debian 설치의 마이너 버전 업그레이드**를 참고하십시오.
- StackBuilder Plus로 설치했다면, 아래 **StackBuilder Plus를 사용한 마이너 버전 업그레이드**를 참고하십시오.
