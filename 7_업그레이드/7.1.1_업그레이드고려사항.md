> 상위: # 메이저 버전 업그레이드 (Major Version Upgrade with pg_upgrade) — EPAS 18 Upgrading

## 1. 업그레이드 고려사항 (Upgrade considerations)

> 원문: [03_limitations](https://www.enterprisedb.com/docs/epas/latest/upgrading/major_upgrade/03_limitations/)

`pg_upgrade` 실행 파일은 EDB Postgres Advanced Server와 함께 배포되며 Database Server 구성 요소의 일부로 설치됩니다. 추가 설치나 구성이 필요하지 않습니다. `pg_upgrade` 유틸리티는 EDB Postgres Advanced Server와 그 이후 버전 사이에서 기존 데이터의 제자리 이전을 수행합니다.

제자리 업그레이드가 실제로 가능한지는 다음 여러 요인에 따라 결정됩니다.

- 사용자 정의 테이블의 온디스크 표현이 원래 버전과 업그레이드된 버전 사이에서 바뀌지 않아야 합니다.
- 데이터 타입의 온디스크 표현이 원래 버전과 업그레이드된 버전 사이에서 바뀌지 않아야 합니다.
- `pg_upgrade`로 EDB Postgres Advanced Server의 메이저 버전 간 업그레이드를 하려면 두 버전이 각 데이터 타입에 대해 공통의 이진 표현을 공유해야 합니다. 따라서 `pg_upgrade`를 사용해 32비트에서 64비트 Linux 플랫폼으로 마이그레이션할 수 없습니다.

버전 업그레이드를 수행하기 전에 `pg_upgrade`는 이전 클러스터와 새 클러스터가 호환되는지 검증합니다.

업그레이드에 데이터베이스 객체나 데이터의 온디스크 표현 변경이 포함되거나 데이터 타입의 이진 표현 변경이 포함되면 `pg_upgrade`는 업그레이드를 수행할 수 없습니다. 이 경우 아래 설명처럼 이전 데이터를 `pg_dump`로 내보낸 뒤 새 클러스터로 가져와야 합니다.

1. `pg_dump`로 모든 데이터를 내보냅니다.
2. 새 릴리스를 설치합니다.
3. `initdb`를 실행하여 새 클러스터를 생성합니다.
4. 이전 데이터를 가져옵니다(import).

데이터베이스 애플리케이션 연결에 ODBC, JDBC, OCI 또는 .NET 드라이버를 사용하고 있고 EDB Postgres Advanced Server의 새 메이저 버전으로 업그레이드하는 경우, EDB Postgres Advanced Server 업그레이드 시 드라이버도 최신 버전으로 업그레이드하십시오.
