# GROUPING function — EPAS 18 SQL 기본 사항

> 원문: [EPAS v18 — Fundamentals › SQL fundamentals › Advanced concepts › Multidimensional analysis › GROUPING function](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/03_advanced_concepts/06_multidimensional_analysis/04_grouping_function/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`GROUP BY` 절에 `ROLLUP`, `CUBE`, `GROUPING SETS` 확장을 사용할 때, 확장이 생성하는 다양한 수준의 소계와 결과 집합의 기본 집계 행을 구별하기 어려운 경우가 있습니다. `GROUPING` 함수는 이러한 구별을 할 수 있는 수단을 제공합니다.

## 구문 (Syntax)

`GROUPING` 함수 사용의 일반적인 구문은 다음과 같습니다.

```sql
SELECT [ <expr> ...,] GROUPING( <col_expr> ) [, <expr> ] ...
FROM ...
GROUP BY [...,]
  { ROLLUP | CUBE | GROUPING SETS }( [...,] <col_expr>
  [, ...] ) [, ...]
```

`GROUPING` 함수는 단일 매개변수를 받으며, 이 매개변수는 `GROUP BY` 절의 `ROLLUP`, `CUBE`, `GROUPING SETS` 확장의 표현식 목록에 지정된 차원 열(dimension column)의 표현식이어야 합니다.

`GROUPING` 함수의 반환 값은 0 또는 1입니다. 쿼리의 결과 집합에서:

- `GROUPING` 함수에 지정된 열 표현식이, 해당 행이 그 열의 여러 값에 대한 소계를 나타내기 때문에 null인 경우, `GROUPING` 함수는 값 1을 반환합니다.
- 해당 행이 `GROUPING` 함수에 지정된 열의 특정 값을 기반으로 결과를 반환하는 경우, `GROUPING` 함수는 값 0을 반환합니다.

후자의 경우, 그 열은 null일 수도 있고 null이 아닐 수도 있습니다. 어느 경우든, 그것은 여러 값에 걸친 소계가 아니라 그 열의 특정 값에 대한 것입니다.

## 예제 (Examples)

다음 쿼리는 `GROUPING` 함수의 반환 값이 소계 줄과 어떻게 대응되는지 보여줍니다.

```sql
SELECT loc, dname, job, COUNT(*) AS "employees",
  GROUPING(loc) AS "gf_loc",
  GROUPING(dname) AS "gf_dname",
  GROUPING(job) AS "gf_job"
FROM emp e, dept d
WHERE e.deptno = d.deptno
GROUP BY ROLLUP (loc, dname, job)
ORDER BY 1, 2, 3;
```

이러한 지시자(indicator)를 특정 소계에 대한 선별 기준으로 사용할 수 있습니다. 예를 들어, 앞선 쿼리를 사용하여 `HAVING` 절에 `GROUPING` 함수를 사용함으로써 `loc`와 `dname` 조합에 대한 소계만 표시할 수 있습니다.

```sql
SELECT loc, dname, job, COUNT(*) AS "employees",
  GROUPING(loc) AS "gf_loc",
  GROUPING(dname) AS "gf_dname",
  GROUPING(job) AS "gf_job"
FROM emp e, dept d
WHERE e.deptno = d.deptno
GROUP BY ROLLUP (loc, dname, job)
HAVING GROUPING(loc) = 0
  AND  GROUPING(dname) = 0
  AND  GROUPING(job) = 1
ORDER BY 1, 2;
```

`GROUPING` 함수를 사용하여 소계 행을 기본 집계 행 또는 특정 소계 행과 구별할 수 있습니다. 이러한 소계 행은 표현식 목록에서, 표의 하나 이상의 행에 대해 표현식이 기반으로 하는 열이 null이기 때문에 결과적으로 null을 반환하는 항목을 하나 가지고 있습니다. 이는 그 열에 걸친 소계를 나타내는 것과는 대조됩니다.

이 점을 설명하기 위해, `emp` 테이블에 다음 행을 추가합니다. 이 행은 `job` 열에 null 값을 가지는 행을 제공합니다.

```sql
INSERT INTO emp (empno,ename,deptno) VALUES (9004,'PETERS',40);
```

명확성을 위해 행 수를 줄여서 다음 쿼리를 실행합니다.

```sql
SELECT loc, job, COUNT(*) AS "employees",
  GROUPING(loc) AS "gf_loc",
  GROUPING(job) AS "gf_job"
FROM emp e, dept d
WHERE e.deptno = d.deptno AND loc = 'BOSTON'
GROUP BY CUBE (loc, job)
ORDER BY 1, 2;
```

출력에는 `loc` 열에 `BOSTON`, `job` 열에 공백을 포함하는 두 개의 행(표의 네 번째와 다섯 번째 항목)이 포함됩니다.

`job` 열에 대한 `GROUPING` 함수 `(gf_job)`가 1을 반환하는 다섯 번째 행은, 이것이 모든 job에 대한 소계임을 나타냅니다. 이 행은 `employees` 열에 소계 값 9를 포함합니다.

네 번째 행에서는 `job` 열뿐만 아니라 `loc` 열에 대한 `GROUPING` 함수도 0을 반환합니다. 이는 이것이 `loc`가 `BOSTON`이고 `job`이 null인 모든 행의 기본 집계임을 나타내며, 이는 이 예제를 위해 삽입한 행입니다. `employees` 열은 1을 포함하며, 이는 삽입된 단일 행의 개수입니다.

아홉 번째 행(마지막에서 두 번째)에서는 `job` 열에 대한 `GROUPING` 함수가 0을 반환하는 반면, `loc` 열에 대한 `GROUPING` 함수는 1을 반환합니다. 이는 이것이 `job` 열이 null인 모든 위치(location)에 대한 소계임을 나타내며, 이 역시 이 예제를 위해 삽입한 단일 행의 개수입니다.
