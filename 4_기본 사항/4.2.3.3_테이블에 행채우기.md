# 테이블에 행 채우기 (Populating a table with rows) — EPAS 18 SQL 튜토리얼

> 원문: [EPAS v18 — SQL tutorial › Populating a table with rows](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/02_sql_tutorial/03_populating_a_table_with_rows/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드는 원문 그대로 보존했습니다.

`INSERT` 문을 사용하여 테이블에 행을 채웁니다.

```sql
INSERT INTO emp VALUES (7369,'SMITH','CLERK',7902,'17-DEC-80',800,NULL,20);
```

모든 데이터 타입은 명확한 입력 형식을 사용합니다. 단순 수치 값이 아닌 상수는 예제처럼 대개 작은따옴표(')로 묶습니다. `DATE` 타입은 받아들이는 형식이 유연합니다. 다만 이 튜토리얼에서는 여기 표시된 명확한(unambiguous) 형식을 사용합니다.

지금까지 사용한 구문은 컬럼 순서를 기억해야 합니다. 대안 구문은 컬럼을 명시적으로 나열할 수 있게 합니다.

```sql
INSERT INTO emp(empno,ename,job,mgr,hiredate,sal,comm,deptno)
    VALUES (7499,'ALLEN','SALESMAN',7698,'20-FEB-81',1600,300,30);
```

원하면 컬럼을 다른 순서로 나열하거나, 예를 들어 커미션을 모르는 경우 일부 컬럼을 생략할 수도 있습니다.

```sql
INSERT INTO emp(empno,ename,job,mgr,hiredate,sal,deptno)
    VALUES (7369,'SMITH','CLERK',7902,'17-DEC-80',800,20);
```

많은 개발자가 컬럼을 명시적으로 나열하는 것이 암묵적 순서에 의존하는 것보다 더 나은 스타일이라고 여깁니다.
