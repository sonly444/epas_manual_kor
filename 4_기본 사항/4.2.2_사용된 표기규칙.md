# 표기 규칙 (Conventions Used) — EPAS 18 SQL 기본 개념

> 원문: [EPAS v18 — Fundamentals › SQL fundamentals › Conventions used](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/02_conventions/)
> EPAS v18 공식 문서의 한글 번역입니다. 명령·용어·플레이스홀더는 원문 그대로 보존했습니다.

이 문서에서 사용하는 표기 규칙은 다음과 같습니다.

## 디렉터리 경로

디렉터리 경로는 Linux 형식(슬래시 `/`)으로 표기합니다. Windows 시스템에서 작업할 때는 경로를 드라이브 문자와 콜론(`:`)으로 시작하고, 슬래시(`/`) 대신 백슬래시(`\`)로 바꾸어 사용합니다.

## 용어 규칙

- **EDB Postgres Advanced Server**: 해당 제품(EPAS)을 구체적으로 지칭할 때 사용.
- **Postgres**: PostgreSQL과 EDB Postgres Advanced Server를 아우르는 일반적 지칭.
- 두 시스템을 구분해야 할 때는 각각의 구체적 명칭을 사용.

## 설치 디렉터리 참조

플레이스홀더 **POSTGRES_INSTALL_HOME** 은 설치 디렉터리를 나타냅니다. 기본값은 플랫폼과 버전에 따라 다릅니다.

> 참고: 그 외 대괄호 `[ ]`(선택 요소), 중괄호 `{ }`(택일 그룹), 파이프 `|`(대안 구분), 말줄임표 `...`(반복) 등 구문 표기(syntax notation)는 SQL 참조(Reference) 섹션의 구문 설명에서 동일한 관례로 사용됩니다.
