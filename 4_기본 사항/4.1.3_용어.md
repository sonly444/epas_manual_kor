# 용어 (Terminology) — EPAS 18 기본 개념

> 원문: [EPAS v18 — Fundamentals › EPAS fundamentals › Terminology](https://www.enterprisedb.com/docs/epas/latest/fundamentals/epas_fundamentals/terminology/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 용어·경로는 원문 그대로 보존했습니다.

다음 용어는 EDB Postgres Advanced Server의 기능과 그 구성 요소를 이해하는 데 중요합니다.

## 데이터베이스 서버 (Database server, postmaster)

데이터를 저장하고 관리할 수 있게 하는 핵심 기능을 제공하는 서버 프로세스입니다. 데이터베이스 파일을 관리하고, 클라이언트 애플리케이션으로부터 데이터베이스 연결을 수락하며, 클라이언트를 대신하여 데이터베이스 작업을 수행합니다. 데이터베이스 서버 프로세스는 *postgres*라고 부릅니다.

## 데이터베이스 클러스터 (Database cluster)

데이터베이스 모음(collection)을 구성하는 디스크상의 구조 집합입니다. 클러스터는 데이터베이스 서버의 단일 인스턴스에 의해 서비스됩니다. 데이터베이스 클러스터는 `data` 디렉터리에 저장됩니다. 프로덕션 데이터베이스의 `data` 디렉터리를 NFS 파일 시스템에 저장하지 마십시오.

## 구성 파일 (Configuration files)

Postgres 구성 파일에 나열된 파라미터를 사용하여 배포 기본 설정, 보안 기본 설정, 연결 동작, 로깅 기본 설정을 관리할 수 있습니다.
