# 시노님 (Synonyms) — EPAS 18 고급 개념

> 원문: [EPAS v18 — SQL fundamentals › Advanced concepts › Synonyms](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/03_advanced_concepts/04_synonyms/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·키워드는 원문 그대로 보존했습니다.

## 개요

시노님(synonym)은 SQL 문에서 데이터베이스 객체를 참조하기 위한 대체 식별자로 동작합니다. 문서에 따르면 "시노님은 데이터베이스 객체가 SQL 문에서 올바르게 참조되기 위해 일반적으로 스키마 이름으로 완전 한정(full qualification)을 요구하는 경우에 유용합니다."

## 지원 객체 유형

EDB Postgres Advanced Server는 테이블, 뷰, 구체화 뷰(materialized view), 시퀀스, 패키지, 프로시저, 함수, 타입, 그리고 데이터베이스 링크를 통해 접근 가능한 객체에 대한 시노님을 지원합니다.

## 주요 특성

문서는 "시노님을 생성할 때 참조된 스키마나 참조된 객체가 반드시 존재할 필요는 없다"고 언급합니다. 다만 기반 객체나 스키마가 삭제되면 시노님은 무효가 되며, DROP 명령을 통해 명시적으로 제거해야 합니다.

## 시노님 생성

기본 구문은 `CREATE [OR REPLACE] [PUBLIC] SYNONYM` 뒤에 시노님 이름과 대상 객체 참조를 사용합니다. `PUBLIC` 절은 public 스키마에 시노님을 생성하여 Oracle 데이터베이스 호환성을 제공합니다.

## 시노님 삭제

시노님을 제거하려면 `DROP [PUBLIC] SYNONYM [<schema>.]<syn_name>`을 사용합니다. 문서는 스키마 한정 없이는 시스템이 "search path에서 처음 찾은 시노님 인스턴스를 삭제"한다고 안내합니다.

## 권한 요구 사항

시스템은 "현재 사용자의 권한을 시노님의 기반 데이터베이스 객체에 대해 검사"하므로, 권한이 부족하면 SQL 명령이 실패합니다.
