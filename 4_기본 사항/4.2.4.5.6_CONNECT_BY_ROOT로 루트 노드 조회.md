# CONNECT_BY_ROOT로 루트 노드 조회하기 (Retrieving the root node with CONNECT_BY_ROOT)

`CONNECT_BY_ROOT`는 단항 연산자(unary operator)로, 열을 한정하여 현재 행과의 관계에서 루트 노드로 간주되는 행의 해당 열 값을 반환하도록 하는 데 사용할 수 있습니다.

##### 참고 (Note)

_단항 연산자(unary operator)_ 는 단일 피연산자에 대해 작동합니다. `CONNECT_BY_ROOT`의 경우, 그 피연산자는 `CONNECT_BY_ROOT` 키워드 뒤에 오는 열 이름입니다.

## 구문 (Syntax)

`SELECT` 목록의 문맥에서 `CONNECT_BY_ROOT` 연산자는 다음과 같이 표기됩니다.

```sql
SELECT [... ,] CONNECT_BY_ROOT <column> [, ...]
  FROM <table_expression> ...
```

`CONNECT_BY_ROOT` 연산자에 대해 유의할 몇 가지 사항은 다음과 같습니다.

- `SELECT` 명령이 계층적 질의를 위한 것인 한, `CONNECT_BY_ROOT` 연산자를 `SELECT` 목록, `WHERE` 절, `GROUP BY` 절, `HAVING` 절, `ORDER BY` 절, `ORDER SIBLINGS BY` 절에서 사용할 수 있습니다.
- 계층적 질의의 `CONNECT BY` 절이나 `START WITH` 절에서는 `CONNECT_BY_ROOT` 연산자를 사용할 수 없습니다.
- `CONNECT_BY_ROOT`를 열이 포함된 표현식에 적용할 수 있습니다. 그렇게 하려면 표현식을 괄호로 묶어야 합니다.

## 예제 (Examples)

다음 질의는 `CONNECT_BY_ROOT` 연산자를 사용하여, 직원 `BLAKE`, `CLARK`, `JONES`로 시작하는 트리를 기준으로 결과 집합에 나열된 각 직원에 대한 루트 노드의 사번과 직원 이름을 반환하는 것을 보여줍니다.

```sql
SELECT LEVEL, LPAD (' ', 2 * (LEVEL - 1)) || ename "employee", empno, mgr,
CONNECT_BY_ROOT empno "mgr empno",
CONNECT_BY_ROOT ename "mgr ename"
FROM emp
START WITH ename IN ('BLAKE','CLARK','JONES')
CONNECT BY PRIOR empno = mgr
ORDER SIBLINGS BY ename ASC;
```

이 질의의 출력은 `mgr empno`와 `mgr ename` 열의 모든 루트 노드가 `START WITH` 절에 나열된 직원인 `BLAKE`, `CLARK`, `JONES` 중 하나임을 보여줍니다.

괄호로 묶이지 않은 표현식에 적용될 때, `CONNECT_BY_ROOT` 연산자는 바로 뒤에 오는 `ename` 항에만 영향을 미칩니다. 그 이후의 `|| ' manages ' || ename` 연결(concatenation)은 `CONNECT_BY_ROOT` 연산의 일부가 아닙니다. 따라서 두 번째로 나오는 `ename`은 현재 처리 중인 행의 값을 산출하는 반면, 첫 번째로 나오는 `ename`은 루트 노드의 값을 산출합니다.

```sql
SELECT LEVEL, LPAD (' ', 2 * (LEVEL - 1)) || ename "employee", empno, mgr,
CONNECT_BY_ROOT ename || ' manages ' || ename "top mgr/employee"
FROM emp
START WITH ename IN ('BLAKE','CLARK','JONES')
CONNECT BY PRIOR empno = mgr
ORDER SIBLINGS BY ename ASC;
```

이 예제는 괄호로 묶인 표현식에 `CONNECT_BY_ROOT` 연산자를 사용합니다.

```sql
SELECT LEVEL, LPAD (' ', 2 * (LEVEL - 1)) || ename "employee", empno, mgr,
CONNECT_BY_ROOT ('Manager ' || ename || ' is emp # ' || empno)
"top mgr/empno"
FROM emp
START WITH ename IN ('BLAKE','CLARK','JONES')
CONNECT BY PRIOR empno = mgr
ORDER SIBLINGS BY ename ASC;
```

`ename`과 `empno`의 값 모두 `CONNECT_BY_ROOT` 연산자의 영향을 받습니다. 그 결과, `top mgr/empno` 열 아래에 루트 노드의 값을 반환합니다.
