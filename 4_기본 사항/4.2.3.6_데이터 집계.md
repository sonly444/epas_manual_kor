# 데이터 집계 (Aggregating data) — EPAS 18 SQL 튜토리얼

> 원문: [EPAS v18 — SQL tutorial › Aggregating data](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/02_sql_tutorial/06_aggregate_functions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·명령·코드·출력은 원문 그대로 보존했습니다.

집계 함수(aggregate function)는 여러 입력 행으로부터 단일 결과를 계산합니다. 일반적인 집계 함수로는 `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`이 있습니다.

### 기본 집계 함수

가장 높은 급여와 가장 낮은 급여 찾기:

```sql
SELECT MAX(sal) highest_salary, MIN(sal) lowest_salary FROM emp;
```

출력:
```
 highest_salary | lowest_salary
----------------+---------------
       5000.00  |        800.00
(1 row)
```

### WHERE 절에서 집계 함수 제한

WHERE 절에서 집계 함수를 직접 사용하려는 시도는 실패합니다.

```sql
SELECT ename FROM emp WHERE sal = MAX(sal);
```

이는 `"aggregates not allowed in WHERE clause"` 오류를 발생시킵니다. WHERE 절 평가가 집계 처리보다 먼저 이루어지기 때문입니다.

### 집계와 함께 하위 쿼리 사용

하위 쿼리(subquery)가 이 제한을 해결합니다.

```sql
SELECT ename FROM emp WHERE sal = (SELECT MAX(sal) FROM emp);
```

출력:
```
 ename
-------
 KING
(1 row)
```

### GROUP BY와 집계

부서별 최고 급여 찾기:

```sql
SELECT deptno, MAX(sal) FROM emp GROUP BY deptno;
```

출력:
```
 deptno |   max
--------+---------
     10 | 5000.00
     20 | 3000.00
     30 | 2850.00
(3 rows)
```

### 그룹 필터링을 위한 HAVING 절

```sql
SELECT deptno, MAX(sal) FROM emp GROUP BY deptno HAVING AVG(sal) > 2000;
```

출력:
```
 deptno |   max
--------+---------
     10 | 5000.00
     20 | 3000.00
(2 rows)
```

### WHERE와 GROUP BY 결합

```sql
SELECT deptno, MAX(sal) FROM emp WHERE job = 'ANALYST' GROUP BY deptno HAVING AVG(sal) > 2000;
```

출력:
```
 deptno |   max
--------+---------
     20 | 3000.00
(1 row)
```

### WHERE 대 HAVING 구분

`WHERE` 절은 그룹화와 집계가 일어나기 전에 행을 필터링합니다. `HAVING` 절은 행이 그룹화되고 각 그룹에 대한 집계 함수가 계산된 후에 결과를 필터링합니다.
