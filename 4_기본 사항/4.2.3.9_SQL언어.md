# SQL 언어 (The SQL language) — EPAS 18 SQL 튜토리얼

> 원문: [EPAS v18 — SQL tutorial › The SQL language](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/02_sql_tutorial/09_the_sql_language/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 용어는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 Oracle 구문과 호환되는 SQL 언어와, 확장 기능을 위한 구문·명령을 지원합니다. 확장 기능은 Oracle에 대한 데이터베이스 호환성을 제공하거나 Oracle 스타일 애플리케이션을 지원하지 않습니다.

SQL 참조(SQL reference) 문서는 다음에 대한 상세 정보를 제공합니다.

- 호환 SQL 구문 및 언어 요소
- 데이터 타입
- 내장 데이터 타입을 위한 함수와 연산자
