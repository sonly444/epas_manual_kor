# 샘플 데이터베이스 (Sample database) — EPAS 18 SQL 튜토리얼

> 원문: [EPAS v18 — SQL tutorial › Sample database](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/02_sql_tutorial/01_sample_database/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다.

이 튜토리얼에서 사용하는 샘플 데이터베이스는 세 개의 테이블 `dept`(부서), `emp`(직원), `jobhist`(직무 이력)로 구성됩니다. 테이블 구조와 샘플 데이터, 접근·설치 방법의 상세 설명은 본 번역의 `03_2_5_샘플DB설명.md`를 참조하십시오.

- 스크립트 위치: `/usr/edb/as18/share/edb-sample.sql`
- EPAS 설치 시 샘플 객체를 담을 `edb` 데이터베이스가 자동 생성됩니다.
- `edb-sample.sql` 실행 시 현재 연결된 데이터베이스에 샘플 테이블·프로그램을 생성하고, 모든 권한을 `PUBLIC` 그룹에 부여합니다.
