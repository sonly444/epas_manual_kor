# 뷰 (Views) — EPAS 18 고급 개념

> 원문: [EPAS v18 — SQL fundamentals › Advanced concepts › Views](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/03_advanced_concepts/01_views/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드는 원문 그대로 보존했습니다.

## 개요

뷰(view)는 추상화 계층으로 동작하며, "애플리케이션이 발전함에 따라 변경될 수 있는 테이블 구조의 세부 사항을 캡슐화하는 일관된 인터페이스를 제공"합니다.

## 기본 예제

문서는 급여 계산 쿼리로부터 뷰를 생성하는 것을 보여 줍니다.

```sql
CREATE VIEW employee_pay AS SELECT ename, sal, sal * 24 AS yearly_salary,
deptno FROM emp;
```

정의되고 나면 뷰는 표준 테이블처럼 질의할 수 있습니다.

```sql
SELECT * FROM employee_pay;
```

## 주요 사항

- 뷰는 "매번 전체 `SELECT` 명령을 다시 입력하지 않고 이 쿼리를 재사용하는 간편한 방법"을 제공합니다.
- 뷰는 다른 뷰 위에 구축할 수 있습니다.
- "실제 테이블을 사용하는 거의 모든 곳에서 뷰를 사용할 수 있습니다."
- 뷰를 효과적으로 구현하는 것은 "좋은 SQL 데이터베이스 설계의 핵심 측면"으로 특징지어집니다.
