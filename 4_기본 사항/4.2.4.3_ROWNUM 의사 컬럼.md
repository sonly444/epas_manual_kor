# ROWNUM 의사 컬럼 (The ROWNUM pseudo-column) — EPAS 18 고급 개념

> 원문: [EPAS v18 — SQL fundamentals › Advanced concepts › The ROWNUM pseudo-column](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/03_advanced_concepts/03_the_rownum_pseudo_column/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드는 원문 그대로 보존했습니다.

`ROWNUM`은 "쿼리에서 행이 조회된 순서에 따라 각 행에 증가하는 고유한 정수 값을 할당"하는 의사 컬럼(pseudo-column)입니다.

## 반환 행 제한

이 기능은 쿼리 결과 제한을 가능하게 합니다.

```sql
SELECT empno, ename, job FROM emp WHERE ROWNUM < 5;
```

중요한 특성: 할당은 결과 집합 정렬 이전에 발생합니다. `ORDER BY` 절은 출력 순서를 결정하지만, `ROWNUM` 값은 순차적으로 나타나지 않을 수 있습니다.

## 테이블에 시퀀스 번호 추가

새 컬럼을 행 시퀀스 값으로 채울 수 있습니다.

```sql
ALTER TABLE jobhist ADD seqno NUMBER(3);
UPDATE jobhist SET seqno = ROWNUM;
```

이는 조회 순서대로 각 행에 증가하는 번호를 할당하며, 데이터셋 내에서 고유한 행 식별자를 설정하는 데 유용합니다.
