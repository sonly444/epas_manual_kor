# 테이블 질의 (Querying a table) — EPAS 18 SQL 튜토리얼

> 원문: [EPAS v18 — SQL tutorial › Querying a table](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/02_sql_tutorial/04_querying_a_table/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·출력은 원문 그대로 보존했습니다.

테이블에서 데이터를 조회하려면 SQL `SELECT` 문을 사용하여 *쿼리(query)*를 실행합니다. 이 문은 다음으로 나뉩니다.

- 선택 목록(select list) — 반환할 컬럼을 나열하는 부분
- 테이블 목록(table list) — 데이터를 조회할 테이블을 나열하는 부분
- 선택적 한정(qualification) — 제한 조건을 지정하는 부분

다음 쿼리는 테이블의 모든 직원의 모든 컬럼을 특별한 순서 없이 나열합니다.

```sql
SELECT * FROM emp;
```

```sql
SELECT ename, sal, sal * 24 AS yearly_salary, deptno FROM emp;
```

`AS` 절이 출력 컬럼의 이름을 다시 붙이는(relabel) 데 사용되는 것에 주목하십시오. `AS` 절은 선택 사항입니다.

원하는 행을 지정하는 `WHERE` 절을 추가하여 쿼리를 한정할 수 있습니다. `WHERE` 절은 불리언(진리값) 표현식을 포함합니다. 불리언 표현식이 참인 행만 반환됩니다. 한정에는 일반적인 불리언 연산자(`AND`, `OR`, `NOT`)를 사용할 수 있습니다. 예를 들어 다음은 급여가 $1000.00를 초과하는 20번 부서의 직원을 조회합니다.

```sql
SELECT ename, sal, deptno FROM emp WHERE deptno = 20 AND sal > 1000;
```


