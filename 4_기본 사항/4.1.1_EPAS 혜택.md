# EDB Postgres Advanced Server의 혜택 (Benefits) — EPAS 18 기본 개념

> 원문: [EPAS v18 — Fundamentals › EPAS fundamentals › Benefits of EDB Postgres Advanced Server](https://www.enterprisedb.com/docs/epas/latest/fundamentals/epas_fundamentals/benefits_epas/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 이름·용어는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 오픈 소스 PostgreSQL 데이터베이스를 확장된 기능으로 강화한 상용(proprietary) 데이터베이스 시스템으로 동작합니다.

이 플랫폼은 여러 핵심 영역을 통해 엔터프라이즈급 기능을 제공합니다.

- 데이터베이스 관리 및 운영 유지 관리 지원
- 유연성과 편의성을 제공하는 향상된 SQL 기능
- 무단 접근을 방지하도록 설계된 보안 확장
- 성능 모니터링 및 분석 도구
- 애플리케이션 프로그래머 생산성 기능
- 고급 복제(replication) 기능(버전 14 이상)

## Oracle 호환성

주요 강점 중 하나는 Oracle에서 Postgres로의 마이그레이션을 용이하게 하는 호환성 기능입니다. 시스템은 Oracle 애플리케이션 구문, 절차적 로직, 데이터 타입, 시스템 카탈로그 뷰를 지원합니다. 이를 통해 Oracle 호환 커넥터, EDB\*Plus, EDB\*Loader 및 관련 도구를 사용할 수 있습니다.

## 릴리스 일정

"EDB Postgres Advanced Server의 메이저 버전은 PostgreSQL의 메이저 버전 릴리스에 맞춰 매년 릴리스되며", 일반적으로 PostgreSQL 릴리스 후 1~2개월 뒤에 나옵니다.

## 플랫폼 지원

이 제품은 Linux x86-64, IBM Power의 Linux, Windows x86-64 시스템에서 실행됩니다.
