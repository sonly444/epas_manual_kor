## 조인 쿼리 실행

*조인(join)* 쿼리는 동일하거나 서로 다른 테이블의 여러 행에 동시에 접근합니다. 예를 들어 직원 레코드를 연관된 부서 정보와 함께 나열하려면 `emp`와 `dept` 테이블에서 `deptno` 컬럼을 비교합니다.

```sql
SELECT emp.ename, emp.sal, dept.deptno, dept.dname, dept.loc FROM emp, dept
WHERE emp.deptno = dept.deptno;
```

결과는 직원과 부서를 일치시킨 14개 행을 보여 줍니다. 다만 "40번 부서에 대한 결과 행은 없습니다. 이는 `emp` 테이블에 40번 부서에 대한 일치하는 항목이 없기 때문입니다." 이는 내부 조인(inner join)이 일치하지 않는 레코드를 제외하는 방식을 보여 줍니다.

대안 구문은 명시적 조인 표기를 사용합니다.

```sql
SELECT emp.ename, emp.sal, dept.deptno, dept.dname, dept.loc FROM emp INNER
JOIN dept ON emp.deptno = dept.deptno;
```

## 외부 조인 실행 (Executing an Outer Join)

*왼쪽 외부 조인(left outer join)*은 오른쪽 테이블에 일치가 없을 때 NULL 값으로 대체하면서 왼쪽 테이블의 모든 행을 보존합니다.

```sql
SELECT emp.ename, emp.sal, dept.deptno, dept.dname, dept.loc FROM dept LEFT
OUTER JOIN emp ON emp.deptno = dept.deptno;
```

이는 NULL 직원 값을 가진 40번 부서를 포함하여 15개 행을 반환합니다.

또는 WHERE 절에서 "(+)" 연산자를 사용합니다.

```sql
SELECT emp.ename, emp.sal, dept.deptno, dept.dname, dept.loc FROM dept, emp
WHERE emp.deptno(+) = dept.deptno;
```

## 셀프 조인 실행 (Executing a Self Join)

*셀프 조인(self join)*은 테이블을 자기 자신과 비교합니다. 각 직원과 그 관리자를 찾으려면:

```sql
SELECT e1.ename || ' works for ' || e2.ename AS "Employees and their
Managers" FROM emp e1, emp e2 WHERE e1.mgr = e2.empno;
```

테이블 별칭(e1, e2)은 복잡한 조인에서 쿼리를 단순화하고 입력을 줄입니다.
