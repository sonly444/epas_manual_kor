# SQL 튜토리얼 (SQL tutorial) — EPAS 18

> 원문: [EPAS v18 — Fundamentals › SQL fundamentals › SQL tutorial](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/02_sql_tutorial/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 _관계형 데이터베이스 관리 시스템(relational database management system, RDBMS)_ 으로, _관계(relation)_ 에 저장된 데이터를 관리하는 시스템입니다. 관계는 본질적으로 _테이블(table)_ 을 가리키는 수학적 용어입니다. 각 테이블은 이름이 지정된 _행(row)_ 의 모음입니다. 주어진 테이블의 각 행은 이름이 지정된 동일한 _열(column)_ 집합을 가지며, 각 열은 특정 _데이터 타입(data type)_ 을 갖습니다. 열은 각 행에서 고정된 순서를 갖지만, SQL은 테이블의 행 순서를 어떤 식으로도 보장하지 않는다는 점을 기억하는 것이 중요합니다(단, 표시를 위해 명시적으로 정렬할 수는 있습니다).

테이블은 _데이터베이스(database)_ 로 그룹화되며, 단일 EDB Postgres Advanced Server 인스턴스가 관리하는 데이터베이스의 모음이 데이터베이스 _클러스터(cluster)_ 를 구성합니다.

이 튜토리얼은 샘플 데이터베이스를 사용하여 RDBMS의 주요 기능을 단계별로 안내합니다.
