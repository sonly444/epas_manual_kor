# 외래 키 (Foreign keys) — EPAS 18 고급 개념

> 원문: [EPAS v18 — SQL fundamentals › Advanced concepts › Foreign keys](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/03_advanced_concepts/02_foreign_keys/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·제약·코드는 원문 그대로 보존했습니다.

## 정의와 목적

외래 키(foreign key)는 두 데이터베이스 테이블의 데이터 사이의 연결을 설정하고 강제하는 하나 이상의 컬럼으로 구성되며, 외래 키 테이블에 저장되는 데이터를 제어합니다.

## 참조 무결성 유지

문서는 모든 직원이 유효한 부서에 속하도록 보장하려면 참조 무결성(referential integrity)을 유지해야 한다고 설명합니다. 수동 검증 방식은 문제가 있고 불편합니다. EDB Postgres Advanced Server는 외래 키 제약 조건을 통해 이 과정을 자동화합니다.

## 예제 구현

`emp` 테이블은 다음 제약 조건으로 외래 키 사용을 보여 줍니다.

```sql
deptno NUMBER(2) CONSTRAINT emp_ref_dept_fk
    REFERENCES dept(deptno)
```

## 오류 처리

존재하지 않는 부서로 직원을 삽입하려고 하면 시스템은 작업을 거부합니다.

> "insert or update on table "emp" violates foreign key constraint
> "emp_ref_dept_fk""

문서는 "외래 키를 올바르게 사용하면 데이터베이스 애플리케이션의 품질이 향상된다"고 강조하며, 구성 가능한 외래 키 동작에 대해 더 깊이 학습할 것을 권장합니다.
