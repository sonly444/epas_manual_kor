# SQL 기본 사항 (SQL fundamentals) — EPAS 18

> 원문: [EPAS v18 — Fundamentals › SQL fundamentals](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

구조화 질의 언어(Structured Query Language, SQL)는 데이터베이스에 접근하고 데이터를 조작하기 위한 표준 언어입니다. 이 기본 사항은 SQL로 작업할 때 가장 일반적인 작업의 출발점을 제공하며, 더 심층적인 문서로 연결되는 링크를 함께 제공합니다. 이 튜토리얼은 샘플 데이터베이스를 사용하여 핵심 개념을 설명합니다.
