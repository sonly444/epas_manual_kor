# 새 테이블 생성 (Creating a new table) — EPAS 18 SQL 튜토리얼

> 원문: [EPAS v18 — SQL tutorial › Creating a new table](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/02_sql_tutorial/02_creating_a_new_table/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·타입·코드는 원문 그대로 보존했습니다.

테이블 이름과 함께 모든 컬럼 이름 및 그 타입을 지정하여 새 테이블을 만듭니다. 다음은 테이블을 정의하는 데 필요한 최소 정보만 담은 `emp` 샘플 테이블의 간소화된 버전입니다.

```sql
CREATE TABLE emp (
    empno           NUMBER(4),
    ename           VARCHAR2(10),
    job             VARCHAR2(9),
    mgr             NUMBER(4),
    hiredate        DATE,
    sal             NUMBER(7,2),
    comm            NUMBER(7,2),
    deptno          NUMBER(2)
);
```

이 코드를 줄 바꿈과 함께 PSQL에 입력할 수 있습니다. PSQL은 세미콜론이 나오기 전까지는 명령이 종료되지 않은 것으로 인식합니다.

SQL 명령에서 공백 문자(스페이스, 탭, 개행)를 사용할 수 있습니다. 원하는 대로 명령을 정렬하거나 모든 텍스트를 한 줄에 넣을 수도 있습니다.

두 개의 대시("--")는 주석을 시작합니다. 그 뒤에 오는 내용은 줄 끝까지 무시됩니다. 또한 SQL은 식별자가 대소문자를 보존하기 위해 큰따옴표로 묶인 경우를 제외하고, 키워드와 식별자의 대소문자를 구분하지 않습니다.

`VARCHAR2(10)`은 최대 10자 길이의 임의 문자열을 저장할 수 있는 데이터 타입을 지정합니다. `NUMBER(7,2)`는 정밀도(precision) 7, 스케일(scale) 2의 고정 소수점 수입니다. `NUMBER(4)`는 정밀도 4, 스케일 0의 정수입니다.

EDB Postgres Advanced Server는 일반적인 SQL 데이터 타입 `INTEGER`, `SMALLINT`, `NUMBER`, `REAL`, `DOUBLE PRECISION`, `CHAR`, `VARCHAR2`, `DATE`, `TIMESTAMP`와 이러한 타입의 다양한 동의어(synonym)를 지원합니다.

테이블이 필요 없거나 다시 만들고 싶으면 다음 명령으로 제거할 수 있습니다.

```sql
DROP TABLE tablename;
```
