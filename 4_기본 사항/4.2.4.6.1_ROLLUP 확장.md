# ROLLUP extension — EPAS 18 SQL 기본 사항

> 원문: [EPAS v18 — Fundamentals › SQL fundamentals › Advanced concepts › Multidimensional analysis › ROLLUP extension](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/03_advanced_concepts/06_multidimensional_analysis/01_rollup_extension/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ROLLUP` 확장은 계층적인 그룹 집합을 생성하며, 각 계층 그룹에 대한 소계(subtotal)와 총계(grand total)를 함께 제공합니다. 계층의 순서는 `ROLLUP` 표현식 목록에 지정된 표현식의 순서에 따라 결정됩니다. 계층의 최상위는 목록에서 가장 왼쪽에 있는 항목입니다. 오른쪽으로 진행하는 각 항목은 계층에서 한 단계씩 아래로 내려갑니다. 가장 오른쪽 항목이 가장 낮은 수준에 위치합니다.

## 구문 (Syntax)

단일 `ROLLUP`의 구문은 다음과 같습니다.

```sql
ROLLUP ( { <expr_1> | ( <expr_1a> [, <expr_1b> ] ...) }
  [, <expr_2> | ( <expr_2a> [, <expr_2b> ] ...) ] ...)
```

각 `expr`는 결과 집합의 그룹화를 결정하는 표현식입니다. `( expr_1a, expr_1b, ...)`처럼 괄호로 묶인 경우, `expr_1a`와 `expr_1b`가 반환하는 값들의 조합이 계층의 단일 그룹화 수준을 정의합니다.

결과 집합에서 반환되는 집계의 기본 수준은 표현식 목록이 반환하는 값들의 고유한 조합 각각에 대한 것입니다.

또한 목록의 첫 번째 항목(지정된 것에 따라 `expr_1` 또는 `( expr_1a, expr_1b, ...)` 조합)의 각 고유 값에 대해 소계가 반환됩니다. 목록의 두 번째 항목(지정된 것에 따라 `expr_2` 또는 `( expr_2a, expr_2b, ...)` 조합)에 대해서는 첫 번째 항목의 각 그룹화 내의 각 고유 값에 대해 소계가 반환되며, 이런 방식으로 계속됩니다. 마지막으로 전체 결과 집합에 대한 총계가 반환됩니다.

소계 행의 경우, 소계가 계산되는 대상 항목에 대해서는 null이 반환됩니다.

`GROUP BY` 절의 문맥에서 지정된 `ROLLUP` 확장은 다음과 같이 표시됩니다.

```sql
SELECT <select_list> FROM ...
GROUP BY [... ,] ROLLUP ( <expression_list> ) [, ...]
```

`select_list`에 지정된 항목은 다음 중 하나여야 합니다.

- `ROLLUP expression_list`에도 함께 나타나거나
- `COUNT`, `SUM`, `AVG`, `MIN,` `MAX`와 같은 집계 함수이거나
- 그룹 내 개별 행과 무관한 반환 값을 가지는 상수 또는 함수(예: `SYSDATE` 함수)여야 합니다.

`GROUP BY` 절을 사용하여 여러 개의 `ROLLUP` 확장뿐만 아니라, 다른 `GROUP BY` 확장 및 개별 표현식의 여러 사용을 함께 지정할 수 있습니다.

`ORDER BY` 절을 사용하여 출력을 계층적 또는 다른 의미 있는 구조로 표시할 수 있습니다. 이 절을 사용하면 결과 집합의 순서가 보장됩니다.

그룹화 수준 또는 합계의 개수는 _n_ + _1_이며, 여기서 _n_은 `ROLLUP` 표현식 목록의 항목 수를 나타냅니다. 괄호로 묶인 목록은 하나의 항목으로 계산됩니다.

## 예제 (Examples)

다음 쿼리는 `loc`, `dname`, 그다음 `job` 열의 계층을 기반으로 롤업을 생성합니다.

```sql
SELECT loc, dname, job, COUNT(*) AS "employees" FROM emp e, dept d
WHERE e.deptno = d.deptno
GROUP BY ROLLUP (loc, dname, job)
ORDER BY 1, 2, 3;
```
