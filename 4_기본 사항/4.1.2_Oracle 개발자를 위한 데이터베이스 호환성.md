# Oracle 호환 개요 (Overview of Oracle compatibility) — EPAS 18 기본 개념

> 원문: [EPAS v18 — Fundamentals › EPAS fundamentals › Overview of Oracle compatibility](https://www.enterprisedb.com/docs/epas/latest/fundamentals/epas_fundamentals/epas_compat_ora_dev_guide/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 용어·이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 Postgres가 Oracle처럼 보이고, 느껴지고, 동작하도록 만들어, 마이그레이션 시 다시 작성할 코드가 줄어들고 빠르게 가동할 수 있게 합니다. Oracle 호환 기능을 통해 Oracle용으로 작성된 많은 애플리케이션을 최소한의 변경 또는 무변경으로 EDB Postgres Advanced Server에서 실행할 수 있습니다.

EDB Postgres Advanced Server는 다음의 Oracle 호환 기능을 제공합니다.

- 저장 프로시저, 함수, 트리거, 패키지를 위한 데이터베이스 서버 측 애플리케이션 로직을 작성할 때 사용하는 저장 프로시저 언어(SPL)
- Oracle 데이터베이스와 호환되는 데이터 타입
- Oracle SQL과 호환되는 SQL 문
- SQL 문과 절차적 로직에서 사용하는 시스템 및 내장 함수
- Oracle의 데이터 딕셔너리(data dictionary)와 호환되는 시스템 카탈로그 뷰
- Oracle MERGE와의 추가 호환성

##### 추가 참고 자료

- SQL 참조(SQL reference)의 호환 SQL 구문, 데이터 타입, 뷰
- 내장 패키지(Built-in packages)에 포함된 프로시저·함수가 제공하는 호환성
- EDB Postgres Advanced Server 설치본에 포함된 호환 도구·유틸리티(EDB\*Plus, EDB\*Loader, DRITA, EDB\*Wrap) — 도구·유틸리티·구성 요소(Tools, utilities, and components)
- Oracle Call Interface(OCI)를 사용하여 작성된 애플리케이션의 경우, EDB의 Open Client Library(OCL)가 이러한 애플리케이션과의 상호운용성을 제공합니다. EDB OCL Connector를 참조하십시오.
