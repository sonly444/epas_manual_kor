# GROUPING SETS extension — EPAS 18 SQL 기본 사항

> 원문: [EPAS v18 — Fundamentals › SQL fundamentals › Advanced concepts › Multidimensional analysis › GROUPING SETS extension](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/03_advanced_concepts/06_multidimensional_analysis/03_grouping_sets_extension/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`GROUP BY` 절에서 `GROUPING SETS` 확장을 사용하면 서로 다른 그룹화를 기반으로 하는 여러 결과 집합을 연결(concatenation)한 하나의 결과 집합을 생성할 수 있습니다. 다시 말해, 여러 그룹화의 결과 집합을 하나의 결과 집합으로 결합하는 `UNION ALL` 연산이 수행됩니다.

`UNION ALL` 연산, 따라서 `GROUPING SETS` 확장은 결합되는 결과 집합에서 중복 행을 제거하지 않습니다.

## 구문 (Syntax)

단일 `GROUPING SETS` 확장의 구문은 다음과 같습니다.

```sql
GROUPING SETS (
   { <expr_1> | ( <expr_1a> [, <expr_1b> ] ...) |
     ROLLUP ( <expr_list> ) | CUBE ( <expr_list> )
   } [, ...] )
```

`GROUPING SETS` 확장은 하나 이상의 쉼표로 구분된 표현식, 괄호로 묶인 표현식 목록, `ROLLUP` 확장, `CUBE` 확장의 임의 조합을 포함할 수 있습니다.

`GROUPING SETS` 확장은 `GROUP BY` 절의 문맥에서 지정됩니다.

```sql
SELECT <select_list> FROM ...
GROUP BY [... ,] GROUPING SETS ( <expression_list> ) [, ...]
```

`select_list`에 지정된 항목은 다음 중 하나여야 합니다.

- `GROUPING SETS expression_list`에도 함께 나타나거나
- `COUNT, SUM, AVG, MIN`, `MAX`와 같은 집계 함수이거나
- 그룹 내 개별 행과 무관한 반환 값을 가지는 상수 또는 함수(예: `SYSDATE` 함수)여야 합니다.

`GROUP BY` 절을 사용하여 여러 개의 `GROUPING SETS` 확장뿐만 아니라, 다른 `GROUP BY` 확장 및 개별 표현식의 여러 사용을 함께 지정할 수 있습니다.

`ORDER BY` 절을 사용하여 출력을 의미 있는 구조로 표시하고 결과 집합의 순서를 보장할 수 있습니다.

## 예제 (Examples)

다음 쿼리는 `loc`, `dname`, `job` 열로 주어지는 그룹들의 합집합(union)을 생성합니다.

```sql
SELECT loc, dname, job, COUNT(*) AS "employees" FROM emp e, dept d
WHERE e.deptno = d.deptno
GROUP BY GROUPING SETS (loc, dname, job)
ORDER BY 1, 2, 3;
```

```sql
SELECT loc AS "loc", NULL AS "dname", NULL AS "job", COUNT(*) AS "employees"
FROM emp e, dept d

GROUP BY loc
  UNION ALL
SELECT NULL, dname, NULL, COUNT(*) AS "employees" FROM emp e, dept d
WHERE e.deptno = d.deptno
GROUP BY dname
  UNION ALL
SELECT NULL, NULL, job, COUNT(*) AS "employees" FROM emp e, dept d
WHERE e.deptno = d.deptno
```

```sql
SELECT NULL, dname, job, count(*) AS "employees" FROM emp e, dept d
WHERE e.deptno = d.deptno
GROUP BY ROLLUP (dname, job)
  UNION ALL

WHERE e.deptno = d.deptno
GROUP BY CUBE (job, loc)
ORDER BY 1, 2, 3;
```
