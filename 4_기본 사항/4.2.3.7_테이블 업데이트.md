# 테이블 업데이트 (Updating a table) — EPAS 18 SQL 튜토리얼

> 원문: [EPAS v18 — SQL tutorial › Updating a table](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/02_sql_tutorial/07_updates/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·출력은 원문 그대로 보존했습니다.

`UPDATE` 명령을 사용하여 기존 행의 컬럼 값을 변경할 수 있습니다. 예를 들어 다음 명령 시퀀스는 관리자(manager)인 모든 사람에게 10% 인상을 적용한 전후 결과를 보여 줍니다.

```sql
SELECT ename, sal FROM emp WHERE job = 'MANAGER';
```

출력

```text
 ename |   sal
-------+---------
 JONES | 2975.00
 BLAKE | 2850.00
 CLARK | 2450.00
(3 rows)
```

```sql
UPDATE emp SET sal = sal * 1.1 WHERE job = 'MANAGER';

SELECT ename, sal FROM emp WHERE job = 'MANAGER';
```

출력

```text
 ename |   sal
-------+---------
 JONES | 3272.50
 BLAKE | 3135.00
 CLARK | 2695.00
(3 rows)
```
