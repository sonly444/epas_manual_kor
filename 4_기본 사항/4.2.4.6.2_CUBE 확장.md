# CUBE extension — EPAS 18 SQL 기본 사항

> 원문: [EPAS v18 — Fundamentals › SQL fundamentals › Advanced concepts › Multidimensional analysis › CUBE extension](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/03_advanced_concepts/06_multidimensional_analysis/02_cube_extension/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`CUBE` 확장은 `ROLLUP` 확장과 유사합니다. 그러나 `ROLLUP`은 `ROLLUP` 표현식 목록의 항목을 왼쪽에서 오른쪽으로 나열한 순서를 기반으로 그룹화와 결과를 계층 구조로 생성합니다. `CUBE`는 `CUBE` 표현식 목록에 있는 모든 항목의 모든 순열(permutation)을 기반으로 그룹화와 소계를 생성합니다. 따라서 결과 집합에는 동일한 표현식 목록에 대해 수행된 `ROLLUP`보다 더 많은 행이 포함됩니다.

## 구문 (Syntax)

단일 `CUBE`의 구문은 다음과 같습니다.

```sql
CUBE ( { <expr_1> | ( <expr_1a> [, <expr_1b> ] ...) }
  [, <expr_2> | ( <expr_2a> [, <expr_2b> ] ...) ] ...)
```

각 `expr`는 결과 집합의 그룹화를 결정하는 표현식입니다. `( expr_1a, expr_1b, ...)`처럼 괄호로 묶인 경우, `expr_1a`와 `expr_1b`가 반환하는 값들의 조합이 단일 그룹을 정의합니다.

결과 집합에서 반환되는 집계의 기본 수준은 표현식 목록이 반환하는 값들의 고유한 조합 각각에 대한 것입니다.

또한 목록의 첫 번째 항목(지정된 것에 따라 `expr_1` 또는 `( expr_1a, expr_1b, ...)` 조합)의 각 고유 값에 대해 소계가 반환됩니다. 목록의 두 번째 항목(지정된 것에 따라 `expr_2` 또는 `( expr_2a, expr_2b, ...)` 조합)의 각 고유 값에 대해서도 소계가 반환됩니다. 첫 번째 항목과 두 번째 항목의 각 고유 조합에 대해서도 소계가 반환됩니다. 마찬가지로 세 번째 항목이 있는 경우, 다음에 대해 소계가 반환됩니다.

- 세 번째 항목의 각 고유 값
- 세 번째 항목과 첫 번째 항목 조합의 각 고유 값
- 세 번째 항목과 두 번째 항목 조합의 각 고유 값
- 세 번째 항목, 두 번째 항목, 첫 번째 항목 조합의 각 고유 값

마지막으로 전체 결과 집합에 대한 총계가 반환됩니다.

소계 행의 경우, 소계가 계산되는 대상 항목에 대해서는 null이 반환됩니다.

`GROUP BY` 절의 문맥에서 지정된 `CUBE` 확장은 다음과 같이 표시됩니다.

```sql
SELECT <select_list> FROM ...
GROUP BY [... ,] CUBE ( <expression_list> ) [, ...]
```

`select_list`에 지정된 항목은 다음 중 하나여야 합니다.

- `CUBE expression_list`에도 함께 나타나거나
- `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`와 같은 집계 함수이거나
- 그룹 내 개별 행과 무관한 반환 값을 가지는 상수 또는 함수(예: `SYSDATE` 함수)여야 합니다.

`GROUP BY` 절을 사용하여 여러 개의 `CUBE` 확장뿐만 아니라, 다른 `GROUP BY` 확장 및 개별 표현식의 여러 사용을 함께 지정할 수 있습니다.

`ORDER BY` 절을 사용하여 출력을 의미 있는 구조로 표시하고 결과 집합의 순서를 보장할 수 있습니다.

그룹화 수준 또는 합계의 개수는 `2`의 _n_ 제곱이며, 여기서 _n_은 `CUBE` 표현식 목록의 항목 수를 나타냅니다. 괄호로 묶인 목록은 하나의 항목으로 계산됩니다.

## 예제 (Examples)

다음 쿼리는 `loc`, `dname`, `job` 열의 순열을 기반으로 큐브를 생성합니다.

```sql
SELECT loc, dname, job, COUNT(*) AS "employees" FROM emp e, dept d
WHERE e.deptno = d.deptno
GROUP BY CUBE (loc, dname, job)
ORDER BY 1, 2, 3;
```

- `loc`와 `dname`의 각 조합
- `loc`와 `job`의 각 조합
- `dname`와 `job`의 각 조합
- `loc`의 각 고유 값
- `dname`의 각 고유 값
