# GROUPING_ID function — EPAS 18 SQL 기본 사항

> 원문: [EPAS v18 — Fundamentals › SQL fundamentals › Advanced concepts › Multidimensional analysis › GROUPING_ID function](https://www.enterprisedb.com/docs/epas/latest/fundamentals/sql_fundamentals/03_advanced_concepts/06_multidimensional_analysis/05_grouping_id_function/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`GROUPING_ID` 함수는 `ROLLBACK`, `CUBE`, `GROUPING SETS` 확장에서 나온 결과 집합에서 행의 소계 수준을 판별하기 위한 `GROUPING` 함수의 단순화된 형태를 제공합니다.

`GROUPING` 함수는 단 하나의 열 표현식만 받으며, 특정 행이 주어진 열의 모든 값에 걸친 소계인지 여부를 나타냅니다. 따라서 여러 개의 그룹화 열을 가진 쿼리에서 소계 수준을 해석하려면 여러 개의 `GROUPING` 함수가 필요할 수 있습니다.

`GROUPING_ID` 함수는 `ROLLBACK`, `CUBE`, `GROUPING SETS` 확장에서 사용된 하나 이상의 열 표현식을 받습니다. 이 함수는 단일 정수를 반환하며, 이를 사용하여 이러한 열 중 어떤 열에 걸쳐 소계가 집계되었는지 판별할 수 있습니다.

## 구문 (Syntax)

`GROUPING_ID` 함수의 일반적인 구문은 다음과 같습니다.

```sql
SELECT [ <expr> ...,]
  GROUPING_ID( <col_expr_1> [, <col_expr_2> ] ... )
  [, <expr> ] ...
FROM ...
GROUP BY [...,]
  { ROLLUP | CUBE | GROUPING SETS }( [...,] <col_expr_1>
  [, <col_expr_2> ] [, ...] ) [, ...]
```

`GROUPING_ID` 함수는 하나 이상의 매개변수를 받으며, 이 매개변수들은 `GROUP BY` 절의 `ROLLUP`, `CUBE`, `GROUPING SETS` 확장의 표현식 목록에 지정된 차원 열(dimension column)의 표현식이어야 합니다.

`GROUPING_ID` 함수는 정수 값을 반환합니다. 이 값은, `GROUPING_ID` 함수에 지정된 매개변수의 순서와 동일한 왼쪽에서 오른쪽 순서로 지정된 일련의 `GROUPING` 함수가 반환하는 1과 0을 연결하여 구성한 비트 벡터를 10진수로 해석한 것에 해당합니다.

## 예제 (Examples)

다음 쿼리는 `gid` 열에 표현된 `GROUPING_ID` 함수의 반환 값이 `loc`와 `dname` 열에 대한 두 개의 `GROUPING` 함수가 반환하는 값과 어떻게 대응되는지 보여줍니다.

```sql
SELECT loc, dname, COUNT(*) AS "employees",
  GROUPING(loc) AS "gf_loc", GROUPING(dname) AS "gf_dname",
  GROUPING_ID(loc, dname) AS "gid"
FROM emp e, dept d
WHERE e.deptno = d.deptno
GROUP BY CUBE (loc, dname)
ORDER BY 6, 1, 2;
```

`dname`별 소계만 표시하려면, `GROUPING_ID` 함수를 기반으로 하는 `HAVING` 절을 사용하는 다음의 단순화된 쿼리를 사용하십시오.

```sql
SELECT loc, dname, COUNT(*) AS "employees",
  GROUPING(loc) AS "gf_loc", GROUPING(dname) AS "gf_dname",
  GROUPING_ID(loc, dname) AS "gid"
FROM emp e, dept d
WHERE e.deptno = d.deptno
GROUP BY CUBE (loc, dname)
HAVING GROUPING_ID(loc, dname) = 2
ORDER BY 6, 1, 2;
```
