# 클러스터 옵션 지정 (Specifying cluster options with INITDBOPTS) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › … › Managing an installation › Specifying cluster options with INITDBOPTS](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/managing_an_advanced_server_installation/specifying_cluster_options/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·옵션·패키지명은 원문 그대로 보존했습니다.

`INITDBOPTS` 변수로 클러스터 구성 선호를 지정할 수 있습니다. 기본적으로 `INITDBOPTS` 변수는 서비스 구성 파일에서 주석 처리되어 있습니다. 수정하지 않으면 서비스 시작 스크립트를 실행할 때 새 클러스터가 Oracle 데이터베이스와 호환되는 모드로 생성됩니다. 이 모드로 생성된 클러스터에는 `edb`라는 데이터베이스가 포함되며 데이터베이스 슈퍼유저 이름은 enterprisedb입니다.

## Oracle 모드로 클러스터 초기화

Oracle 호환 모드로 데이터베이스를 초기화하면 설치에 다음이 포함됩니다.

- Oracle 데이터베이스와 호환되는 데이터 딕셔너리 뷰
- Oracle 데이터 타입 변환
- Oracle 구문과 호환되는 형식으로 표시되는 날짜 값
- Oracle 스타일 연결(concatenation) 규칙 지원. 문자열 값을 `NULL` 값과 연결하면 반환값은 문자열의 값입니다.
- 다음 Oracle 내장 패키지 지원.

| 패키지 | Oracle 데이터베이스와 호환되는 기능 |
|---|---|
| `dbms_alert` | 알림 등록·전송·수신 기능. |
| `dbms_job` | 작업 생성·스케줄·관리 기능. |
| `dbms_lob` | 대형 객체 관리 기능. |
| `dbms_output` | 메시지 버퍼로 메시지 전송·수신 기능. |
| `dbms_pipe` | 동일 클러스터에 연결된 세션 내·간에 파이프로 메시지 전송 기능. |
| `dbms_rls` | 특정 EPAS 객체에 Virtual Private Database 구현 지원. |
| `dbms_sql` | EDB 동적 SQL 기능에 대한 애플리케이션 인터페이스 제공. |
| `dbms_utility` | 다양한 유틸리티 프로그램 제공. |
| `dbms_aqadm` | Advanced Queueing 기능 지원 프로시저 제공. |
| `dbms_aq` | EPAS용 메시지 큐잉·처리 제공. |
| `dbms_profiler` | 성능 프로파일링 세션 중 실행된 PL/pgSQL·SPL 문의 성능 정보 수집·저장. |
| `dbms_random` | 무작위 값 생성 메서드 제공. |
| `dbms_redact` | 쿼리 반환 데이터의 편집(redact)·마스킹 기능. |
| `dbms_lock` | `DBMS_LOCK.SLEEP` 프로시저 지원. |
| `dbms_scheduler` | 작업·프로그램·작업 스케줄 생성·관리 기능. |
| `dbms_crypto` | RAW/BLOB/CLOB 데이터 암·복호화 함수·프로시저 제공. 암호학적으로 강한 무작위 값 생성에도 사용. |
| `dbms_mview` | 구체화 뷰와 그 의존성 관리·새로 고침 기능. |
| `dbms_session` | `DBMS_SESSION.SET_ROLE` 프로시저 지원. |
| `utl_encode` | 데이터 인코딩·디코딩 기능. |
| `utl_http` | HTTP/HTTPS 프로토콜로 URL의 정보를 가져오는 기능. |
| `utl_file` | 운영체제 파일 시스템의 파일 읽기·쓰기 기능. |
| `utl_smtp` | SMTP로 이메일 전송 기능. |

| `utl_raw` | raw 데이터 타입 조작·길이 조회 기능. |

## Postgres 모드로 클러스터 초기화

PostgreSQL 모드로 생성된 클러스터에는 호환성 기능이 포함되지 않습니다. PostgreSQL 모드로 새 클러스터를 생성하려면 `INITDBOPTS` 변수 앞의 파운드 기호(#)를 제거하여 `--no-redwood-compat` 옵션을 활성화합니다. PostgreSQL 모드로 생성된 클러스터에는 `postgres`라는 데이터베이스가 포함되며 데이터베이스 슈퍼유저 이름은 postgres입니다.

여러 `initdb` 옵션을 지정할 수도 있습니다. 예를 들어 다음 문은 Oracle 호환성 기능 없이 데이터베이스 클러스터를 생성합니다. 이 클러스터에는 alice라는 사용자가 소유한 `postgres` 데이터베이스가 포함되고 UTF-8 인코딩을 사용합니다.

```text
INITDBOPTS="--no-redwood-compat -U alice --locale=en_US.UTF-8"
```

`--no-redwood-compat` 모드로 데이터베이스를 초기화하면 설치에 다음 패키지가 포함됩니다.

| 패키지 | Oracle 데이터베이스와 비호환 기능 |
|---|---|
| `dbms_aqadm` | Advanced Queueing 기능 지원 프로시저. |
| `dbms_aq` | EPAS용 메시지 큐잉·처리. |
| `edb_bulkload` | 대량 데이터 로딩 시 직접/컨벤셔널 데이터 로딩 기능. |
| `edb_gen` | 내장 패키지 실행을 위한 기타 패키지. |
| `edb_objects` | 패키지·프로시저 등 Oracle 호환 객체. |
| `waitstates` | 세션 블로킹 모니터링. |
| `edb_dblink_libpq` | libpq로 외부 데이터베이스에 링크. |
| `edb_dblink_oci` | OCI로 외부 데이터베이스에 링크. |
| `snap_tables` | 대기 정보를 담는 테이블 생성. DRITA 스크립트에 포함. |
| `snap_functions` | snap id 목록과 스냅샷 시각을 반환하는 함수 생성. DRITA 스크립트에 포함. |
| `sys_stats` | OS 성능 통계 제공. |

PostgreSQL 코어 문서에 문서화된 클러스터 구성 옵션 외에, EDB Postgres Advanced Server는 다음 `initdb` 옵션을 지원합니다.

**`--no-redwood-compat`**

`--no-redwood-compat` 키워드를 포함하여 PostgreSQL 모드로 클러스터를 생성합니다. PostgreSQL 모드로 생성 시 데이터베이스 슈퍼유저 이름은 postgres, 기본 데이터베이스 이름은 `postgres`입니다. 이 모드에서는 Oracle 호환 기능 중 일부만 사용할 수 있습니다. 모든 기능을 사용하려면 redwood 호환 모드로 EPAS를 사용하는 것을 권장합니다.

**`--redwood-like`**

`--redwood-like` 키워드를 포함하여 이스케이프 문자를 사용합니다. 이 문자는 빈 문자열('')이며, Oracle 구문과 호환되는 SQL 문에서 `LIKE`(또는 PostgreSQL 호환 `ILIKE`) 연산자 뒤에 옵니다.

**`--icu-short-form`**

`--icu-short-form` 키워드를 포함하여 클러스터의 모든 데이터베이스에 기본 ICU(International Components for Unicode) 콜레이션을 사용하는 클러스터를 생성합니다. Unicode 콜레이션에 대한 자세한 내용은 Unicode collation algorithm 문서를 참고하십시오.

`initdb` 사용과 사용 가능한 클러스터 구성 옵션에 대한 자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/app-initdb.html)를 참고하십시오.

슈퍼유저 권한을 얻고 다음을 입력하여 `initdb`의 온라인 도움말을 볼 수도 있습니다.

```text
/path_to_initdb_installation_directory/initdb --help
```

`path_to_initdb_installation_directory`는 `initdb` 바이너리 파일의 위치를 지정합니다.
