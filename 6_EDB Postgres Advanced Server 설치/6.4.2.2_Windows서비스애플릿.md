# Windows 서비스 애플릿 사용 (Using the Windows services applet) — EPAS 18 Windows 설치

> 원문: [EPAS v18 — Installing › On Windows › Managing an installation › Using the Windows services applet](https://www.enterprisedb.com/docs/epas/latest/installing/windows/managing_an_advanced_server_installation/using_the_windows_services_applet/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 서비스명·UI 항목명은 원문 그대로 보존했습니다.

Windows 운영체제에는 EDB Postgres Advanced Server와 그 구성 요소 관련 서비스를 제어하는 그래픽 서비스 컨트롤러가 포함되어 있습니다. Windows 제어판의 관리 도구(Administrative Tools) 섹션에서 Services 유틸리티에 접근합니다.

![Windows Services 창의 EDB Postgres Advanced Server 서비스](https://www.enterprisedb.com/docs/static/9f178b88c18bdd4b227b7a53ff5e0bb6/764be/advanced_server_services.png)

Services 창은 알파벳순으로 정렬된 서비스 목록을 표시합니다. `edb-as-18` 서비스가 EDB Postgres Advanced Server를 제어합니다.

- **Stop** — EDB Postgres Advanced Server 인스턴스 중지. 서비스를 중지하면 인스턴스에 연결된 사용자·클라이언트 애플리케이션 연결이 끊깁니다.
- **Start** — EDB Postgres Advanced Server 서비스 시작.
- **Pause** — 많은 구성 파라미터에 대해 사용자 세션을 방해하지 않고 서버 구성 파라미터를 다시 로드. 서버 reload로 갱신 가능한 파라미터는 "EDB Postgres Advanced Server 구성" 참조.
- **Restart** — EDB Postgres Advanced Server 중지 후 시작. 서비스를 중지하면 모든 사용자 세션이 종료됩니다. 서버 시작 시에만 적용되는 서버 파라미터를 재설정하는 데 유용합니다.
