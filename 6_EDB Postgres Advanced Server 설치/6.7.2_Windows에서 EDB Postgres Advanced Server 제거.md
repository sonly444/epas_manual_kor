# Windows에서 제거 — EPAS 18 설치

> 원문: [EPAS v18 — Installing › Uninstalling › On Windows](https://www.enterprisedb.com/docs/epas/latest/installing/uninstalling/windows_uninstall/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·경로·UI 항목명은 원문 그대로 보존했습니다.

> **참고(Note)**
>
> EDB Postgres Advanced Server를 제거한 후에도 클러스터 데이터 파일은 그대로 남고 서비스 사용자도 유지됩니다. 필요하면 클러스터 데이터와 서비스 사용자를 시스템에서 수동으로 제거할 수 있습니다.

## 명령줄에서 제거 관리자(uninstaller) 사용

EDB Postgres Advanced Server 대화형 인스톨러는 Windows 호스트에 있는 EDB Postgres Advanced Server 또는 구성 요소를 제거하는 데 사용할 수 있는 제거 관리자(uninstaller)를 생성합니다. 제거 관리자는 `C:\Program Files\edb\as<xx>`에 생성됩니다.

1. 슈퍼유저 권한을 얻고, 제거 관리자가 있는 디렉터리에서 다음을 입력합니다.

```text
uninstall-edb-as<xx>-server.exe
```

   `<xx>`는 EDB Postgres Advanced Server 버전 번호입니다. 제거 관리자가 열립니다.

   ![EDB Postgres Advanced Server 제거 관리자](https://www.enterprisedb.com/docs/static/fb912265e7f3a20fafbcbac76ab54b8c/08c0b/advanced_server_uninstaller.png)

2. 기본적으로 인스톨러는 전체 애플리케이션을 제거합니다. 대신 제거할 구성 요소를 선택하려면 **Individual components**를 선택합니다. 제거할 구성 요소를 선택하라는 대화 상자가 표시됩니다. 원하는 항목을 선택합니다.

3. **Next**를 선택합니다.

   EDB Postgres Advanced Server에 의존하는 구성 요소를 제거하도록 선택한 경우, 해당 구성 요소가 먼저 제거됩니다.

   ![의존 구성 요소가 먼저 제거됨을 확인](https://www.enterprisedb.com/docs/static/474e4ca5fb6862b20b48a2ff46ae6c7c/a4078/acknowledging_components_removed.png)

4. 계속하려면 **Yes**를 선택합니다.

   소프트웨어가 제거되는 동안 진행률 표시줄이 표시됩니다. 제거 과정이 완료되면 확인 메시지가 표시됩니다.

   ![제거 완료](https://www.enterprisedb.com/docs/static/8e0cc0cff7529f3d9eb3b169f6ba953b/a2d4f/uninstallation_complete.png)
