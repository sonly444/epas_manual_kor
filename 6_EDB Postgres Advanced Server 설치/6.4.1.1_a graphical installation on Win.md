# Windows에서 그래픽 설치 수행 (Performing a graphical installation on Windows) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › On Windows › … › Performing a graphical installation on Windows](https://www.enterprisedb.com/docs/epas/latest/installing/windows/installing_advanced_server_with_the_interactive_installer/performing_a_graphical_installation_on_windows/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·경로·UI 항목명·파라미터는 원문 그대로 보존했습니다.

그래픽 설치는 Windows 시스템에 EDB Postgres Advanced Server를 설치하는 빠르고 쉬운 방법입니다. 마법사 화면에서 시스템과 사용에 대한 정보를 지정합니다. 화면을 완료하면 인스톨러가 설정 과정에서 선택한 내용을 기반으로 설치를 수행합니다.

1. 관리자 권한을 가정하고 `edb-as<xx>-server-xx.x.x-x-windows-x64` 실행 파일을 더블클릭합니다(`<xx>`는 EPAS 버전 번호).

   > **참고(Note):** 일부 Windows 버전에서는 파일을 마우스 오른쪽 클릭하고 컨텍스트 메뉴에서 **Run as Administrator**를 선택하여 관리자 권한으로 인스톨러를 호출해야 할 수 있습니다.

   ![EDB Postgres Advanced Server 인스톨러 환영 창](https://www.enterprisedb.com/docs/static/2c518d038d6a526b9a435bbe53f31c3d/08c0b/advanced_server_installer_welcome.png)

2. **Next**를 선택합니다. EnterpriseDB 라이선스 동의서가 열립니다.

   ![EnterpriseDB 라이선스 동의서](https://www.enterprisedb.com/docs/static/2ef0776daba93ef64f96ee6b28e457a8/0a47e/enterprisedb_license_agreement.png)

3. 라이선스 동의서를 주의 깊게 검토한 뒤 적절한 옵션을 선택하고 **Next**를 선택합니다. Installation Directory 창이 열립니다.

   ![Installation Directory 창](https://www.enterprisedb.com/docs/static/1f72006739995fd9e61c681cec9f10cb/74cfa/installation_directory.png)

   기본적으로 EDB Postgres Advanced Server 설치 디렉터리는 다음과 같습니다.

   ```text
   C:\Program Files\edb\as<xx>
   ```

   `<xx>`는 EPAS 버전 번호입니다.

4. 기본 설치 위치를 수락하고 **Next**를 선택합니다. 또는 파일 브라우저 아이콘을 선택하여 Browse For Folder 대화 상자를 열고 다른 설치 디렉터리를 선택합니다.

   > **참고(Note):** 운영 데이터베이스의 `data` 디렉터리를 NFS 파일 시스템에 저장하지 마십시오.

   Select Components 창이 열립니다. EDB Postgres Advanced Server 설정 마법사로 설치할 수 있는 선택적 구성 요소 목록이 포함됩니다. 이름 옆의 체크박스를 해제하여 구성 요소를 설치에서 제외할 수 있습니다.

   ![Select Components 창](https://www.enterprisedb.com/docs/static/8514c638fca7fdb02e8e0b8384bff306/0a47e/select_components.png)

   설정 마법사는 다음 구성 요소를 설치할 수 있습니다.

   - **EDB Postgres Advanced Server** — EDB Postgres Advanced Server 설치.
   - **StackBuilder Plus** — 설치·설정 완료 후 설치된 제품을 업데이트하거나 지원 모듈(및 의존성)을 내려받아 추가할 수 있는 그래픽 도구. 자세한 내용은 StackBuilder Plus 사용 참조.
   - **Command Line Tools** — 명령줄 도구와 지원 클라이언트 라이브러리 설치. 다음 등을 포함: libpq, psql, EDB\*Loader, ecpgPlus, pg_basebackup·pg_dump·pg_restore, pg_bench.

   > **참고(Note):** EDB Postgres Advanced Server 또는 pgAdmin 4를 설치하는 경우 명령줄 도구가 필요합니다.

5. 설치할 구성 요소를 선택한 뒤 **Next**를 선택합니다. Additional Directories 창이 열립니다.

   ![Additional Directories 창](https://www.enterprisedb.com/docs/static/7c12154e4df58517323651ce8e0154fb/db783/additional_directories.png)

   기본적으로 EDB Postgres Advanced Server 데이터 파일은 다음에 저장됩니다.

   ```text
   C:\Program Files\edb<xx>\data
   ```

   EDB Postgres Advanced Server `Write-Ahead Log (WAL) Directory`의 기본 위치는 다음과 같습니다.

   ```text
   C:\Program Files\edb\as<xx>\data\pg_wal
   ```

   EDB Postgres Advanced Server는 트랜잭션 안전성을 높이고 처리 속도를 높이기 위해 미리 쓰기 로그(WAL)를 사용합니다. 테이블을 변경하면 변경 내용이 공유 메모리에 저장되고 변경 기록이 WAL에 기록됩니다. COMMIT을 수행하면 WAL 내용이 디스크에 기록됩니다.

6. 기본 파일 위치를 수락하거나 파일 브라우저로 다른 위치를 선택하고 **Next**를 선택합니다. EDB Postgres Advanced Server Dialect 창이 열립니다. 서버 dialect는 EPAS가 지원하는 호환성 기능을 지정합니다.

   ![EDB Postgres Advanced Server Dialect 창](https://www.enterprisedb.com/docs/static/2344c5833af15d92ad482441b821595f/0a47e/advanced_server_dialect.png)

7. 목록에서 서버 dialect를 선택합니다. 기본적으로 EPAS는 **Compatible with Oracle** 모드로 설치됩니다. **Compatible with Oracle**과 **Compatible with PostgreSQL** 설치 모드 중에서 선택할 수 있습니다.

   **Compatible with Oracle**을 선택하면 설치에 다음 기능이 포함됩니다.

   - Oracle 데이터베이스와 호환되는 데이터 딕셔너리 뷰
   - Oracle 데이터 타입 변환
   - Oracle 구문과 호환되는 형식으로 표시되는 날짜 값
   - Oracle 스타일 연결 규칙 지원(문자열을 `NULL`과 연결하면 반환값은 문자열의 값)
   - `SEARCH_PATH`에 추가되는 Oracle 호환 스키마(`dbo`, `sys`)
   - 다음 Oracle 내장 패키지 지원.

   | 패키지 | Oracle 데이터베이스와 호환되는 기능 |
   |---|---|
   | `dbms_alert` | 알림 등록·전송·수신 기능. |
   | `dbms_job` | 작업 생성·스케줄·관리 기능. |
   | `dbms_lob` | 대형 객체 관리 기능. |
   | `dbms_output` | 메시지 버퍼로 메시지 전송·수신 기능. |
   | `dbms_pipe` | 동일 클러스터 세션 내·간 파이프로 메시지 전송. |
   | `dbms_rls` | 특정 EPAS 객체에 VPD 구현 지원. |
   | `dbms_sql` | EDB 동적 SQL 기능 애플리케이션 인터페이스. |
   | `dbms_utility` | 다양한 유틸리티 프로그램. |
   | `dbms_aqadm` | Advanced Queueing 지원 프로시저. |
   | `dbms_aq` | 메시지 큐잉·처리. |
   | `dbms_profiler` | PL/pgSQL·SPL 문의 성능 정보 수집·저장. |
   | `dbms_random` | 무작위 값 생성 메서드. |
   | `dbms_redact` | 쿼리 반환 데이터 편집·마스킹. |
   | `dbms_lock` | `DBMS_LOCK.SLEEP` 프로시저 지원. |
   | `dbms_scheduler` | 작업·프로그램·스케줄 생성·관리. |
   | `dbms_crypto` | RAW/BLOB/CLOB 암·복호화, 강한 무작위 값 생성. |
   | `dbms_mview` | 구체화 뷰·의존성 관리·새로 고침. |
   | `dbms_session` | `DBMS_SESSION.SET_ROLE` 지원. |
   | `utl_encode` | 데이터 인코딩·디코딩. |
   | `utl_http` | HTTP/HTTPS로 URL 정보 조회. |
   | `utl_file` | OS 파일 시스템 파일 읽기·쓰기. |
   | `utl_smtp` | SMTP로 이메일 전송. |
   | `utl_mail` | 이메일 관리. |
   | `utl_url` | URL의 불법·예약 문자 이스케이프. |
   | `utl_raw` | raw 데이터 타입 조작·길이 조회. |

   이는 Oracle 호환 모드 설치 시 포함되는 호환성 기능의 전체 목록이 아닙니다. 자세한 내용은 Oracle 개발자용 데이터베이스 호환성 내장 패키지 문서 참조. Oracle 호환 모드로 설치하면 EPAS 슈퍼유저 이름은 enterprisedb입니다.

   **Compatible with PostgreSQL**을 선택하면 EPAS는 PostgreSQL 15와 호환됩니다. 이 모드로 설치하면 기본 EPAS 슈퍼유저 이름은 postgres입니다.

8. 구성 모드를 지정한 뒤 **Next**를 선택합니다. Password 창이 열립니다.

   ![Password 창](https://www.enterprisedb.com/docs/static/51f11fac06a46f023efa09d7c5e638ae/0a47e/password_window.png)

   EPAS는 Password 창에 지정한 비밀번호를 데이터베이스 슈퍼유저에 사용합니다. 지정한 비밀번호는 EPAS 호스트의 보안 정책을 준수해야 합니다.

9. **Password** 필드에 비밀번호를 입력하고 **Retype Password** 필드에서 확인한 뒤 **Next**를 선택합니다. Additional Configuration 창이 열립니다.

   ![Additional Configuration 창](https://www.enterprisedb.com/docs/static/f82878e002127af5ebdc89de5a5bcd33/0a47e/additional_configuration.png)

10. Additional Configuration 창의 필드로 설치 세부를 지정합니다.

    - **Port** 필드 — 클라이언트 연결 요청을 수신할 포트 번호. 기본값은 `5444`.
    - **Locale** 필드가 **[Default locale]**이면 EPAS는 시스템 로케일을 작업 로케일로 사용. 목록에서 대체 로케일을 선택할 수 있습니다.
    - 기본적으로 설정 마법사는 호환성 모드(Oracle 또는 PostgreSQL)에 해당하는 샘플 데이터를 설치합니다. 설치하지 않으려면 **Install sample tables and procedures** 옆 체크박스를 해제합니다.

11. 정보를 확인한 뒤 **Next**를 선택합니다. Dynatune Dynamic Tuning: Server Utilization 창이 열립니다.

    ![Dynatune Dynamic Tuning: Server Utilization 창](https://www.enterprisedb.com/docs/static/0ea18dc915648a3801bcb11e8f8a064f/0a47e/dynatune_dynamic_tuning_server_utilization.png)

    설정 마법사는 Dynatune Dynamic Tuning 기능으로 성능 튜닝을 돕습니다. Dynatune은 EPAS가 설치된 호스트의 시스템 리소스를 최적으로 사용하도록 합니다.

12. Server Utilization 창의 옵션으로 `edb_dynatune` 구성 파라미터의 초기값을 설정합니다. `edb_dynatune`은 EPAS가 시스템 리소스를 할당하는 방식을 결정합니다.

    - **Development** — `edb_dynatune`을 `33`으로 설정. 호스트 리소스를 최소로 할당. 개발용으로 적합.
    - **General Purpose** — `66`으로 설정. 중간 수준 할당. EPAS와 같은 호스트에서 고정 수의 애플리케이션을 실행하는 애플리케이션 서버에 적합.
    - **Dedicated** — `100`으로 설정. 대부분의 리소스를 할당. 전용 서버 호스트에 적합.

    (설치 완료 후 `data` 디렉터리의 `postgresql.conf`를 편집하여 `edb_dynatune` 값을 조정할 수 있습니다. 편집 후 변경 적용을 위해 서버를 재시작해야 합니다.)

    적절한 설정을 선택하고 **Next**를 선택합니다. Dynatune Dynamic Tuning: Workload Profile 창이 열립니다.

    ![Dynatune Dynamic Tuning: Workload Profile 창](https://www.enterprisedb.com/docs/static/7e66a462c368d249c34bc6e684e1ac9b/0a47e/dynatune_dynamic_tuning_workload_profile.png)

13. Workload Profile 창의 옵션으로 `edb_dynatune_profile` 구성 파라미터의 초기값을 지정합니다. 이 파라미터는 서버가 수행하는 작업 유형에 따른 성능 튜닝 측면을 제어합니다.

    - **Transaction Processing (OLTP systems)** — `edb_dynatune_profile` 값 `oltp`. 대량 OLTP 지원 시 권장.
    - **General Purpose (OLTP and reporting workloads)** — 값 `mixed`. 트랜잭션 처리와 데이터 리포팅 혼합 서버에 권장.
    - **Reporting (Complex queries or OLAP workloads)** — 값 `reporting`. 대량 데이터 리포팅 서버에 권장.

    설치 완료 후 `postgresql.conf`를 편집하여 값을 조정할 수 있으며, 편집 후 서버를 재시작해야 합니다. 자세한 내용은 Dynatune 문서 참조.

14. **Next**를 선택합니다. 기본적으로 EPAS는 시스템 부팅 시 서비스를 시작하도록 구성됩니다. Pre Installation Summary가 열립니다.

    ![Pre Installation Summary](https://www.enterprisedb.com/docs/static/f22f82692d13afe6d897822b4ec97c92/74cfa/pre_installation_summary.png)

    Pre Installation Summary는 설정 과정에서 지정한 옵션의 개요를 제공합니다.

15. 옵션을 검토한 뒤 **Next**를 선택합니다. (**Back**으로 화면을 되돌아가 옵션을 갱신할 수 있습니다.) Ready to Install 창은 인스톨러가 설치에 필요한 정보를 가지고 있음을 확인합니다.

16. **Next**를 선택합니다. 각 지원 모듈이 압축 해제·설치되며 진행률 표시줄로 확인됩니다. 설치 완료 전 마법사가 `Launch StackBuilder Plus at exit?`를 묻습니다.

    ![설정 마법사가 종료 시 StackBuilder Plus 실행 제안](https://www.enterprisedb.com/docs/static/09efe2237d21fe566d2a54a25e6c28a9/0a47e/setup_wizard.png)

    EDB Postgres StackBuilder Plus는 EPAS와 핵심 지원 구성 요소 설치에 포함됩니다.

17. EPAS 설치를 완료하려면 **StackBuilder Plus** 체크박스를 해제하고 **Finish**를 선택합니다. 또는 기본값을 수락하고 StackBuilder Plus로 진행합니다.
