# 설치 문제 해결 (Installation troubleshooting) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › Troubleshooting › On Linux › Installation troubleshooting](https://www.enterprisedb.com/docs/epas/latest/installing/troubleshooting/linux_troubleshooting/installation_troubleshooting_linux/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·경로·오류 메시지는 원문 그대로 보존했습니다.

### Java 기반 애플리케이션 표시 문제

Java 기반 서버 기능이 제대로 표시되지 않는 경우(컨트롤·텍스트가 올바르게 표시되지 않거나 빈 창이 나타나는 경우), 대부분의 배포판에서는 최신 `libxcb-xlib` 라이브러리로 업그레이드하면 문제가 해결됩니다. 다른 가능한 해결책은 [Java 버그 데이터베이스](http://bugs.sun.com/bugdatabase/view_bug.do?bug_id=6532373)를 참고하십시오.

### 데이터 디렉터리에 기존 내용이 있어 설치가 완료되지 않는 경우

데이터 디렉터리에 기존 내용이 있어 설치가 완료되지 않으면 서버는 서버 로그에 오류 메시지를 기록합니다.

`A data directory is neither empty, or a recognisable data directory.`

이와 유사한 메시지가 나타나면 데이터 디렉터리가 비어 있는지 확인하십시오. 시스템이 생성한 `lost+found` 폴더를 포함하여 파일이 존재하면 설치가 완료되지 않습니다. 데이터 디렉터리에서 파일을 제거하거나, 인스톨러를 다시 실행하기 전에 데이터 디렉터리 위치를 다른 곳으로 지정하십시오.

### EPEL 릴리스 패키지 설치 문제

EPEL 릴리스 패키지를 설치하는 데 어려움이 있으면, RHEL/Rocky Linux/AlmaLinux 8.x | 9.x에서 다음 명령 중 하나로 `epel-release` 패키지를 설치할 수 있습니다.

```text
dnf -y install https://dl.fedoraproject.org/pub/epel/epel-release-latest-8.noarch.rpm

dnf -y install https://dl.fedoraproject.org/pub/epel/epel-release-latest-9.noarch.rpm
```

`/etc/yum.repos.d`에 있는 `CentOS-Base.repo` 파일에서 `[extras]` 리포지토리 정의를 활성화해야 할 수도 있습니다. yum이 `epel-release`가 포함된 리포지토리에 접근할 수 없으면 다음 오류 메시지가 표시됩니다.

```text
No package epel available.
Error: Nothing to do
```

이 오류가 발생하면 EPEL rpm 패키지를 내려받아 수동으로 설치할 수 있습니다. 수동으로 EPEL을 설치하려면 rpm 패키지를 내려받고, 슈퍼유저 권한을 얻은 뒤, 패키지가 있는 디렉터리로 이동하여 다음 명령을 사용합니다.

```text
yum -y install epel-release

dnf -y install epel-release
```
