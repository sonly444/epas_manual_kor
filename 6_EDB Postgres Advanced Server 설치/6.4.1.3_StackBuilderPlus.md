# StackBuilder Plus 사용 (Using StackBuilder Plus) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › On Windows › … › Using StackBuilder Plus](https://www.enterprisedb.com/docs/epas/latest/installing/windows/installing_advanced_server_with_the_interactive_installer/using_stackbuilder_plus/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 경로·UI 항목명은 원문 그대로 보존했습니다.

StackBuilder Plus 유틸리티는 EPAS 설치를 보완하는 모듈을 업데이트·다운로드·설치하는 과정을 단순화하는 그래픽 인터페이스를 제공합니다. StackBuilder Plus로 모듈을 설치하면 소프트웨어 의존성이 해결됩니다.

설치 완료 후 언제든 **Apps > StackBuilder Plus**를 선택하여 StackBuilder Plus를 호출할 수 있습니다. 시스템 비밀번호를 입력하라는 메시지가 나오면 입력하고, StackBuilder Plus 환영 창이 열립니다.

![StackBuilder Plus 환영 창](https://www.enterprisedb.com/docs/static/766e5f35c5ad7cb648b8fe5c2eaade94/4597d/stackbuilder_plus_welcome.png)

목록에서 EPAS 설치를 선택합니다.

StackBuilder Plus는 인터넷 접근이 필요합니다. EPAS 설치가 인터넷 접근이 제한된 방화벽 뒤에 있으면 StackBuilder Plus는 프록시 서버를 통해 프로그램 인스톨러를 내려받을 수 있습니다. 모듈 제공자가 HTTP 프록시 또는 FTP 프록시로 접근 가능한지 결정합니다. 현재 모든 업데이트는 HTTP 프록시로 전송되며 FTP 프록시 정보는 사용되지 않습니다.

선택한 EPAS 설치의 인터넷 접근이 제한된 경우, 환영 창에서 **Proxy Servers**를 선택하여 Proxy Servers 대화 상자를 엽니다.

![Proxy Servers 대화 상자](https://www.enterprisedb.com/docs/static/7d53e1ff370bc2871fb0e4917107ecb3/9f933/proxy_servers.png)

Proxy Servers 대화 상자의 **HTTP proxy** 필드에 프록시 서버의 IP 주소와 포트 번호를 입력합니다. 현재 모든 StackBuilder Plus 모듈은 HTTP 프록시로 배포되며 FTP 프록시 정보는 무시됩니다. **OK**를 선택합니다.

![StackBuilder Plus 모듈 선택 창](https://www.enterprisedb.com/docs/static/e4f16134082ef86e392ec4f09273872e/f058b/stackbuilder_plus_module_selection.png)

모듈 선택 창의 트리 컨트롤은 각 모듈 범주 노드를 표시합니다.

구성 요소의 상세 설명을 보려면 모듈을 확장하고 트리에서 구성 요소 이름을 선택합니다. 구성 요소를 추가하거나 업그레이드하려면 모듈 이름 왼쪽 체크박스를 선택하고 **Next**를 선택합니다.

StackBuilder Plus가 선택한 패키지를 확인합니다.

![선택된 패키지 목록 요약 창](https://www.enterprisedb.com/docs/static/dbbd4db924e9cb7f09e228fc03216472/4597d/summary-window-displaying-selected-packages.png)

**Download directory** 필드 오른쪽의 찾아보기 아이콘(...)으로 파일 선택기를 열어 내려받은 인스톨러를 저장할 대체 위치를 선택합니다. **Next**를 선택하여 서버에 연결하고 필요한 설치 파일을 내려받습니다.

다운로드가 완료되면 설치 파일이 내려받아져 설치 준비가 되었음을 확인하는 창이 열립니다.

![다운로드 완료 확인](https://www.enterprisedb.com/docs/static/b2cd5e80e282195013085720a5af90b1/f058b/download_complete.png)

설치 과정을 시작하려면 **Skip Installation** 박스를 해제한 채로 두고 **Next**를 선택합니다. 내려받은 파일을 설치하지 않고 StackBuilder Plus를 종료하려면 체크박스를 선택하고 **Next**를 선택합니다.

내려받은 각 인스톨러는 요구 사항이 다릅니다. 실행 시 라이선스 동의, 비밀번호 입력, 구성 정보 제공을 요청할 수 있습니다.

설치 과정에서 하나 이상의 인스톨러가 시스템 재시작을 요청할 수 있습니다. 모든 설치가 완료될 때까지 **No** 또는 **Restart Later**를 선택합니다. 마지막 설치가 완료되면 시스템을 재시작하여 모든 업데이트를 적용합니다.

가끔 설치에 실패하는 패키지가 있을 수 있습니다. 패키지 설치가 실패하면 StackBuilder Plus가 설치 오류를 알리고 `%TEMP%`의 로그 파일에 메시지를 기록합니다.

설치가 완료되면 StackBuilder Plus가 요청한 패키지 설치의 성공·실패를 알립니다. 인스톨러가 컴퓨터 재시작을 요청했다면 지금 재시작합니다.

![StackBuilder Plus 설치 완료 확인](https://www.enterprisedb.com/docs/static/e3a115c606bc706c44da59bf20b3f3d0/f058b/stackbuilder_plus_completed_installation.png)
