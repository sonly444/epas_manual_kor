# 로컬 리포지토리로 Linux에 설치 (Installing on Linux using a local repository) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › Linux installation details › Setting up a local repository](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/installing_epas_using_local_repository/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·경로·설정은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server 또는 지원 구성 요소를 설치하려는 서버가 EDB 리포지토리에 직접 접근할 수 없으면, EDB Postgres Advanced Server 네이티브 패키지를 호스팅하는 로컬 리포지토리를 만들 수 있습니다. 사용자의 네트워크에 맞게 다음 상위 수준 단계를 조정하십시오.

로컬 리포지토리를 만들고 사용하려면 다음을 수행해야 합니다.

- `dnf`로 `epel-release`, `yum-utils`, `createrepo` 패키지를 설치합니다. RHEL 또는 Rocky Linux 또는 AlmaLinux 8.x의 경우:

```bash
dnf install epel-release
dnf install yum-utils
dnf install createrepo
```

- 리포지토리를 저장할 디렉터리를 만듭니다.

```text
mkdir /srv/repos
```

- RPM 설치 패키지를 로컬 리포지토리로 복사합니다. 개별 패키지를 내려받거나 tarball로 리포지토리를 채울 수 있습니다. 패키지는 [EDB 리포지토리](https://repos.enterprisedb.com/)에서 제공됩니다.

- RPM 패키지를 동기화하고 리포지토리를 생성합니다.

```text
reposync -r edbas18 -p /srv/repos
createrepo /srv/repos
```

- 로컬 리포지토리 역할을 하는 호스트에 원하는 웹서버를 설치하고, 리포지토리 디렉터리가 네트워크의 다른 서버에서 접근 가능하도록 합니다.

- 격리된 각 데이터베이스 서버에서 로컬 네트워크의 미러 리포지토리에서 업데이트를 받도록 yum 또는 dnf를 구성합니다. 예를 들어 다음을 지정하는 연결 정보를 담은 리포지토리 구성 파일 `/etc/yum.repos.d/edb.repo`를 만들 수 있습니다.

```text
[edbas18]
name=EnterprisEDB Postgres Advanced Server 18
baseurl=https://yum.your_domain.com/edbas18
enabled=1
gpgcheck=0
```

로컬 리포지토리의 위치와 연결 정보를 지정한 뒤, dnf 명령으로 격리된 서버에 EDB Postgres Advanced Server와 지원 구성 요소를 설치할 수 있습니다. 예를 들어 RHEL 또는 Rocky Linux 또는 AlmaLinux 8의 경우:

```text
dnf -y install edb-as18-server
```

로컬 yum 리포지토리 생성에 대한 자세한 내용은 [CentOS wiki](https://wiki.centos.org/HowTos/CreateLocalRepos)를 참고하십시오.
