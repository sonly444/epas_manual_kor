# 패키지 설치 구성 (Configuring a package installation) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › … › Managing an installation › Configuring a package installation](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/managing_an_advanced_server_installation/configuring_a_package_installation/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·경로·변수는 원문 그대로 보존했습니다.

데이터베이스 서버 구성 요소를 설치하는 패키지는 7.x 또는 8.x 호스트에 유닛 파일과 서비스 시작 스크립트를 생성합니다.

## 데이터베이스 클러스터 생성 및 서비스 시작

PostgreSQL `initdb` 명령은 데이터베이스 클러스터를 생성합니다. EDB Postgres Advanced Server를 RPM 패키지로 설치하면 `initdb` 실행 파일은 `/usr/edb/asx.x/bin`에 있습니다. EDB Postgres Advanced Server 설치 후에는 서비스를 수동으로 구성하고 `initdb`를 호출하여 클러스터를 생성해야 합니다. `initdb`를 호출할 때 다음을 할 수 있습니다.

- 명령줄에서 환경 옵션을 지정합니다.
- RHEL/Rocky Linux/AlmaLinux 8.x에서 systemd 서비스 관리자를 포함하고, 서비스 구성 파일로 환경을 구성합니다.

자세한 내용은 [`initdb` 문서](https://www.postgresql.org/docs/current/static/app-initdb.html)를 참고하십시오.

서비스 구성 파일에 옵션을 지정한 뒤, 데이터베이스 클러스터를 생성하고 서비스를 시작할 수 있습니다. 단계는 플랫폼별로 다릅니다.

### RHEL / Rocky Linux / AlmaLinux 8.x

서비스 구성 파일에 지정된 옵션으로 RHEL/Rocky Linux/AlmaLinux 8.x 시스템에서 `initdb`를 호출하려면, 운영체제 슈퍼유저 신원을 가정합니다.

```text
su - root
```

기본값이 아닌 값으로 클러스터를 초기화하려면 `PGSETUP_INITDB_OPTIONS` 환경 변수를 사용할 수 있습니다. `EPAS_Home/bin`에 있는 `edb-as-18-setup` 스크립트로 클러스터를 초기화할 수 있습니다.

`initdb`를 호출하려면 `PGSETUP_INITDB_OPTIONS` 환경 변수를 내보냅니다.

```text
PGSETUP_INITDB_OPTIONS="-E UTF-8" /usr/edb/as18/bin/edb-as-18-setup initdb
```

클러스터를 생성한 뒤 `systemctl`로 서비스를 시작·중지·재시작합니다.

```text
systemctl { start | stop | restart } edb-as-18
```

### Debian 11.x 또는 Ubuntu 20.04 | 22.04

번들 스크립트를 사용하여 여러 클러스터를 초기화할 수 있습니다. 새 클러스터를 생성하려면 root 권한을 얻고 번들 스크립트를 호출합니다.

```text
/usr/bin/epas_createcluster 18 main2
```

새 클러스터를 시작하려면:

```text
/usr/bin/epas_ctlcluster 18 main2 start
```

사용 가능한 모든 클러스터를 나열하려면:

```text
/usr/bin/epas_lsclusters
```

> **참고(Note)**
>
> 데이터 디렉터리는 `/var/lib/edb-as/18/main2` 아래에, 구성 디렉터리는 `/etc/edb-as/18/main/` 아래에 생성됩니다.
