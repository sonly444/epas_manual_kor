# 설치 명령줄 옵션 (Installation command line options) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › On Windows › … › Installation command line options](https://www.enterprisedb.com/docs/epas/latest/installing/windows/installing_advanced_server_with_the_interactive_installer/invoking_the_graphical_installer_from_the_command_line/reference_command_line_options/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·옵션·값·경로는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server 인스톨러 호출 시, 명령줄 또는 구성 파일에 다음 파라미터를 선택적으로 포함할 수 있습니다.

**`--create_samples { yes | no }`** — `--databasemode`로 지정한 dialect의 샘플 테이블·프로시저 생성 여부. 기본값 `yes`.

**`--databasemode { oracle | postgresql }`** — 데이터베이스 dialect 지정. 기본값 `oracle`.

**`--datadir data_directory`** — 클러스터 데이터 디렉터리 위치 지정(전체 경로 포함).

**`--debuglevel { 0 | 1 | 2 | 3 | 4 }`** — `debug_log` 파일에 기록되는 상세 수준. 값이 클수록 상세. 기본값 `2`.

**`--debugtrace debug_log`** — 설치 문제 해결용. `debug_log`는 문제 해결 세부를 담는 파일명.

**`--disable-components component_list`** — 설치에서 제외할 EPAS 구성 요소 목록. 기본값은 ''(빈 문자열). 쉼표 구분 목록으로 다음 포함 가능: `dbserver`(EPAS), `pgadmin4`(pgAdmin 4).

**`--enable_acledit { 1 | 0 }`** — `--enable_acledit 1`은 `--serviceaccount`로 지정한 사용자에게 EPAS 바이너리·`data` 디렉터리 접근 권한을 부여. `0` 지정 또는 생략 시 비활성화.
> **참고:** Windows 설치 시에만 유효. 객체 접근 허용을 위해 DACL 설정이 필요할 때 지정. 업그레이드 등 향후 작업을 위해 서비스 계정 사용자가 `data` 디렉터리에 접근할 수 있어야 하며, `--enable_acledit 1`이 이를 제공.

**`--enable-components component_list`** — `--help`에 표시되지만 설치되는 구성 요소에는 영향을 주지 않음. 모든 구성 요소가 설치됨. 특정 구성 요소만 설치하려면 `--disable-components`로 설치하지 않을 것을 나열.

**`--extract-only { yes | no }`** — 완전 설치 없이 EPAS 바이너리만 추출. 슈퍼유저 권한 불필요. 기본값 `no`.

**`--help`** — 선택적 파라미터 목록 표시.

**`--installer-language { en | ja | zh_CN | zh_TW | ko }`** — 설치 언어 지정. `en`(영어, 기본), `ja`(일본어), `zh_CN`(중국어 간체), `zh_TW`(중국어 번체), `ko`(한국어).

**`--install_runtimes { yes | no }`** — Microsoft Visual C++ 런타임 라이브러리 설치 여부. 기본값 `yes`.

**`--locale locale`** — EPAS 클러스터 로케일 지정. 기본은 `initdb`가 감지한 로케일.

**`--mode { unattended }`** — 설치 과정에서 사용자 입력이 필요 없는 설치 수행.

**`--optionfile config_file`** — 설치 구성 파라미터를 담은 파일명(전체 경로 지정).

**`--prefix installation_dir/as18`** — EPAS 설치 디렉터리 지정. 버전별 하위 디렉터리(`as18`)가 추가됨. 기본: `C:\Program Files\edb\as18`.

**`--serverport port_number`** — EPAS 리스너 포트 번호. 무인 모드에서 미지정 시 `5444` 또는 그 이후 첫 사용 가능 포트를 기본으로 사용.

**`--server_utilization {33 | 66 | 100}`** — `edb_dynatune` 값 지정. `33`(개발), `66`(고정 수 애플리케이션 서버, 기본), `100`(전용 호스트). 설치 완료 후 `postgresql.conf` 편집으로 조정 가능(서버 재시작 필요).

**`--serviceaccount user_account_name`** — 서버 프로세스를 소유하는 사용자 계정명. `--databasemode`가 `oracle`(기본)이면 기본값 `enterprisedb`, `postgresql`이면 `postgres`. 보안상 관리자 권한이 없는 계정을 지정해야 함. `--serviceaccount`와 `--enable_acledit 1`을 함께 지정하면 데이터베이스 서비스가 동일 서비스 계정을 사용.
> **참고:** `--serviceaccount`를 생략하면 설치 모드에 따라 enterprisedb 또는 postgres가 서비스를 소유.

**`--servicename service_name`** — EPAS 서비스명. 기본값 `edb-as-18`.

**`--servicepassword user_password`** — OS 시스템 비밀번호. 미지정 시 `--superpassword` 값을 기본으로 사용.

**`--superaccount super_user_name`** — 데이터베이스 슈퍼유저 이름. `oracle`이면 기본 `enterprisedb`, `postgresql`이면 `postgres`.

**`--superpassword superuser_password`** — 데이터베이스 슈퍼유저 비밀번호. 비대화형 모드에서 기본값 `enterprisedb`.

**`--unattendedmodeui { none | minimal | minimalWithDialogs }`** — 무인 설치 중 인스톨러 동작. `none`(진행률 미표시), `minimal`(진행률 표시, 기본), `minimalWithDialogs`(진행률 + 오류 대화 상자).

**`--version`** — 인스톨러 버전 정보 조회.

**`--workload_profile {oltp | mixed | reporting}`** — `edb_dynatune_profile` 초기값. `oltp`(대량 OLTP, 기본), `mixed`(혼합), `reporting`(대량 리포팅). 설치 완료 후 `postgresql.conf` 편집으로 조정 가능(서버 재시작 필요).
