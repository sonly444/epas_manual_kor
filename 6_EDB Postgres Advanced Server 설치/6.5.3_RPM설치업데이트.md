# RPM 설치 업데이트 (Updating an RPM installation) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › Linux installation details › Updating an RPM installation](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/updating_an_rpm_installation/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·파일명은 원문 그대로 보존했습니다.

기존 EDB Postgres Advanced Server RPM 설치가 있으면 yum 또는 dnf를 사용하여 리포지토리 구성 파일을 업그레이드하고 최신 제품 버전으로 업데이트할 수 있습니다.

`enterprisedb-enterprise.repo` 파일을 업데이트하려면 슈퍼유저 권한을 얻고 다음을 입력합니다.

```text
dnf upgrade enterprisedb-enterprise
```

`dnf`는 현재 EDB 리포지토리에 접근할 수 있도록 `enterprisedb-enterprise.repo` 파일을 업데이트합니다. 그런 다음 `dnf`를 사용하여 이름에 `edb` 표현이 포함된 모든 패키지를 업그레이드할 수 있습니다.

```text
dnf upgrade edb*
```

> **참고(Note)**
>
> `dnf upgrade` 명령은 마이너 릴리스 간에만 업데이트를 수행합니다. 메이저 릴리스 간에 업데이트하려면 `pg_upgrade`를 사용하십시오.

dnf 명령과 옵션 사용에 대한 자세한 내용은 [dnf 문서](https://docs.fedoraproject.org/en-US/quick-docs/dnf/)를 참고하십시오.
