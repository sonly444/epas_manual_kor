# Windows에서 서버 시작 동작 제어 (Controlling server startup behavior on Windows) — EPAS 18 Windows 설치

> 원문: [EPAS v18 — Installing › On Windows › Managing an installation › Controlling server startup behavior on Windows](https://www.enterprisedb.com/docs/epas/latest/installing/windows/managing_an_advanced_server_installation/controlling_server_startup_behavior_on_windows/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. UI 항목명은 원문 그대로 보존했습니다.

Windows Services 유틸리티로 서버의 시작 동작을 제어할 수 있습니다. 업데이트할 서비스 이름을 마우스 오른쪽 클릭하고 컨텍스트 메뉴에서 **Properties**를 선택합니다.

Properties 대화 상자의 **Startup type** 목록에서 호스트가 시작될 때 EDB Postgres Advanced Server 서비스가 어떻게 동작할지 지정합니다.

![EDB Postgres Advanced Server 시작 동작 지정](https://www.enterprisedb.com/docs/static/665401c8e5c5a01488164291f6c27383/e33ef/advanced_server_startup.png)

- **Automatic (Delayed Start)** — 부팅 후 시작.
- **Automatic** — 시스템이 시작·중지될 때마다 서버를 시작·중지.
- **Manual** — 서버를 수동으로 시작.
- **Disabled** — 서비스 비활성화. 비활성화 후 변경을 적용하려면 서비스를 중지하거나 서버를 재시작해야 합니다. 서비스를 비활성화하면 **Startup type**을 **Automatic (Delayed Start)**, **Automatic**, 또는 **Manual**로 재설정하기 전까지 서버 상태를 변경할 수 없습니다.
