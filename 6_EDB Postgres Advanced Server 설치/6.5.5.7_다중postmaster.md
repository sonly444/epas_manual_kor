# 다중 postmaster 시작 (Starting multiple postmasters with different clusters) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › … › Managing an installation › Starting multiple postmasters with different clusters](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/managing_an_advanced_server_installation/starting_multiple_postmasters/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·경로·유닛명은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server를 각자 고유한 데이터베이스 클러스터를 가진 여러 postmaster를 사용하도록 구성할 수 있습니다. 필요한 단계는 Linux 호스트 버전에 따라 다릅니다.

## RHEL / Rocky Linux / AlmaLinux 8.x | 9.x

8.x | 9.x용 `edb-as18-server-core` RPM에는 EDB Postgres Advanced Server 인스턴스를 시작하는 유닛 파일이 포함됩니다. 이 파일을 통해 고유한 `data` 디렉터리를 가지고 서로 다른 포트를 모니터링하는 여러 서비스를 시작할 수 있습니다. 스크립트를 호출하거나 수정하려면 root 접근이 필요합니다.

이 예제는 인스턴스가 두 개인 EDB Postgres Advanced Server 설치를 만듭니다. 보조 인스턴스의 이름은 `secondary`입니다.

- 기본 파일을 새 이름으로 복사합니다. 파일 상단에 명시된 대로 모든 수정은 `/etc` 아래에 있어야 합니다. `/etc/systemd/system`에서 이미 사용 중이지 않은 이름을 선택해야 합니다.

```text
cp /usr/lib/systemd/system/edb-as-18.service /etc/systemd/system/secondary-edb-as-15.service
```

- 파일을 편집하여 `PGDATA`를 새로 클러스터를 생성할 새 `data` 디렉터리를 가리키도록 변경합니다.

- enterprisedb 사용자로 대상 `PGDATA`를 만듭니다.

- 설정 스크립트를 지정하여 `initdb`를 실행합니다.

```text
/usr/edb/as18/bin/edb-as-18-setup initdb secondary-edb-as-18
```

- 새 인스턴스의 `postgresql.conf` 파일을 편집하여 포트, IP 주소, TCP/IP 설정 등을 지정합니다.

- 재부팅 후에도 새 클러스터가 실행되도록 합니다.

```text
systemctl enable secondary-edb-as-18
```

- 두 번째 클러스터를 시작합니다.

```text
systemctl start secondary-edb-as-18
```
