# 무인 설치 수행 (Performing an unattended installation) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › On Windows › … › Performing an unattended installation](https://www.enterprisedb.com/docs/epas/latest/installing/windows/installing_advanced_server_with_the_interactive_installer/invoking_the_graphical_installer_from_the_command_line/performing_an_unattended_installation/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·옵션은 원문 그대로 보존했습니다.

인스톨러가 사용자 상호작용 없이 실행되도록 지정하려면 `--mode unattended` 명령줄 옵션을 포함합니다. 무인 모드에서 인스톨러는 다음 소스 중 하나를 구성 파라미터로 사용합니다.

- 명령줄 옵션(인스톨러 호출 시 지정)
- 옵션 파일에 지정된 파라미터
- EDB Postgres Advanced Server 설치 기본값

비대화형 EPAS 인스톨러를 다른 애플리케이션 인스톨러 안에 임베드할 수 있으며, 설치 과정에서 진행률 표시줄로 진행 상황을 볼 수 있습니다.

`--mode unattended` 옵션으로 EPAS를 설치하려면 관리자 권한이 있어야 합니다. 이 옵션으로 클라이언트를 통해 EPAS를 설치하는 경우, 호출하는 클라이언트를 슈퍼유저 또는 관리자 권한으로 호출해야 합니다.

무인 모드로 인스톨러를 시작하려면 실행 파일이 있는 디렉터리로 이동하여 다음을 입력합니다.

```text
edb-as<xx>-server-xx.x.x-x-windows-x64.exe --mode unattended --superpassword
database_superuser_password --servicepassword system_password
```

`<xx>`는 EPAS 버전 번호입니다.

인스톨러 호출 시 `--servicepassword` 옵션을 포함하여 EPAS를 설치하는 사용자의 운영체제 비밀번호를 지정합니다.

`--superpassword` 옵션으로 호스트의 비밀번호 보안 정책을 준수하는 비밀번호를 지정합니다. 시스템에 적용된 비밀번호 정책이 기본 비밀번호 `(enterprisedb)`를 허용하지 않을 수 있습니다.
