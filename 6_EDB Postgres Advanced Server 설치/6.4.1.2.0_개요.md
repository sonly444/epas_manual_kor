# 명령줄에서 그래픽 인스톨러 호출 (Invoking the graphical installer from the command line) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › On Windows › … › Invoking the graphical installer from the command line](https://www.enterprisedb.com/docs/epas/latest/installing/windows/installing_advanced_server_with_the_interactive_installer/invoking_the_graphical_installer_from_the_command_line/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·옵션은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server 인스톨러의 명령줄 옵션은, 제한된 리소스나 권한 때문에 그래픽 설치가 동작하지 않을 수 있는 상황의 Windows 시스템을 위한 기능을 제공합니다. 다음을 할 수 있습니다.

- 인스톨러 호출 시 `--mode unattended` 옵션을 포함하여 사용자 입력 없이 설치를 수행합니다.
- 완전한 설치에 필요한 권한이 없을 때 `--extract-only` 옵션으로 최소 설치를 수행합니다.

모든 명령줄 옵션이 모든 상황에 적합한 것은 아닙니다. 명령줄 옵션 전체 참조는 "설치 명령줄 옵션" 페이지를 참고하십시오.

> **참고(Note)**
>
> 시스템 업그레이드를 위해 명령줄에서 인스톨러를 호출하는 경우, 인스톨러는 명령줄 옵션을 무시하고 이전 설치의 구성을 보존합니다.

하위 구성:
- 무인 설치 수행 (Performing an unattended installation)
- 제한된 권한으로 설치 수행 (Performing an installation with limited privileges)
- 설치 명령줄 옵션 (Installation command line options)
