# EDB Postgres Advanced Server 구성 (Configuring EPAS) — EPAS 18 Windows 설치

> 원문: [EPAS v18 — Installing › On Windows › Managing an installation › Configuring EPAS](https://www.enterprisedb.com/docs/epas/latest/installing/windows/managing_an_advanced_server_installation/configuring_epas/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·경로·변수·UI 항목명은 원문 그대로 보존했습니다.

다음 구성 파일을 수정하여 EDB Postgres Advanced Server와 지원 구성 요소의 동작을 결정하는 파라미터를 쉽게 갱신할 수 있습니다.

- `postgresql.conf` 파일 — EDB Postgres Advanced Server 구성 파라미터의 초기값을 결정합니다.
- `pg_hba.conf` 파일 — 네트워크 인증·인가에 대한 선호를 지정합니다.
- `pg_ident.conf` 파일 — `ident` 기반 인증 사용 시 운영체제 신원(사용자 이름)을 EDB Postgres Advanced Server 신원(역할)에 매핑합니다.

`postgresql.conf`와 `pg_hba.conf` 수정에 대한 자세한 내용은 파라미터 설정 문서를 참고하십시오.

원하는 편집기로 구성 파일을 열 수 있습니다. Windows에서는 **EDB Postgres** 메뉴를 통해 파일을 열 수 있습니다.

![Windows 시스템 메뉴를 통한 구성 파일 접근](https://www.enterprisedb.com/docs/static/d2e59c1fb9b16496420c99ec876f13f4/a48b3/accessing_configuration_files.png)

## EDB Postgres Advanced Server 환경 변수 설정

그래픽 인스톨러는 Windows 사용자를 위해 환경 변수 설정 작업을 단순화하는 스크립트를 제공합니다. 이 스크립트는 현재 셸 세션의 환경 변수를 설정합니다. 셸 세션이 끝나면 환경 변수는 사라집니다. 각 셸 세션마다 환경 변수를 정의하려면 시스템 전역 셸 시작 스크립트에서 `pgplus_env.bat`를 호출하는 것이 좋습니다.

`pgplus_env` 스크립트는 EDB Postgres Advanced Server 설치 과정에서 생성되며 설치 시 선택한 내용을 반영합니다. 스크립트를 호출하려면 명령줄에서 다음을 입력합니다.

```text
C:\Program Files\edb\as18\pgplus_env.bat
```

`pgplus_env.bat` 스크립트가 실행되면 다음 환경 변수를 설정합니다.

```text
PATH="C:\Program Files\edb\as18\bin";%PATH%
EDBHOME=C:\Program Files\edb\as18
PGDATA=C:\Program Files\edb\as18\data
PGDATABASE=edb
REM @SET PGUSER=enterprisedb
PGPORT=5444
PGLOCALEDIR=C:\Program Files\edb\as18\share\locale
```

EDB가 만든 인스톨러로 PostgreSQL을 설치한 경우 `pg_env` 스크립트가 동일한 기능을 수행합니다.

```text
C:\Progra~1\PostgreSQL\18\pg_env.bat
```

PostgreSQL에서 `pg_env.bat` 스크립트가 실행되면 다음 환경 변수를 설정합니다.

```text
PATH="C:\Program Files\PostgreSQL\18\bin";%PATH%
PGDATA=C:\Program Files\PostgreSQL\18\data
PGDATABASE=postgres
PGUSER=postgres
PGPORT=5432
PGLOCALEDIR=C:\Program Files\PostgreSQL\18\share\locale
```

## edb-psql로 EDB Postgres Advanced Server 접속

edb-psql은 SQL 명령을 실행하고 결과를 볼 수 있는 명령줄 클라이언트 애플리케이션입니다. edb-psql 클라이언트를 열려면 클라이언트가 검색 경로에 있어야 합니다. 실행 파일은 EDB Postgres Advanced Server 설치의 `bin` 디렉터리에 있습니다.

edb-psql 클라이언트를 시작하려면 다음 명령과 옵션을 사용합니다.

```text
psql -d edb -U enterprisedb
```

여기서 `-d`는 연결할 데이터베이스를, `-U`는 세션에 사용할 데이터베이스 사용자의 신원을 지정합니다.

대화형 인스톨러로 설치한 경우 **EDB Postgres > EDB-PSQL**을 선택하여 edb-psql 클라이언트에 접근할 수 있습니다. 클라이언트가 열리면 세션 연결 정보를 제공합니다.

`edb-psql` 파일은 `psql`이라는 바이너리에 대한 심볼릭 링크이며, EDB Postgres Advanced Server 기능 지원이 추가된 PostgreSQL 커뮤니티 psql의 수정 버전입니다. 자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/app-psql.html)를 참고하십시오.

## pgAdmin 4 클라이언트로 EDB Postgres Advanced Server 접속

pgAdmin 4는 데이터베이스와 데이터베이스 객체를 관리하는 그래픽 인터페이스를 제공합니다. 대화 상자와 온라인 도움말이 객체 생성, 역할 관리, 권한 부여·취소 같은 작업을 단순화합니다. 탭 브라우저 패널은 pgAdmin 트리에서 현재 선택된 객체 정보에 빠르게 접근할 수 있게 합니다.

이 클라이언트는 그래픽 인스톨러와 함께 배포됩니다. pgAdmin을 열려면 **EDB Postgres > pgAdmin4**를 선택합니다. 클라이언트가 기본 브라우저에서 열립니다.

![pgAdmin 4 클라이언트 대시보드](https://www.enterprisedb.com/docs/static/be4d40b17a5411c28e03efaea909023f/e088a/pgadmin4_client_dashboard.png)

EDB Postgres Advanced Server 데이터베이스 서버에 연결하려면 Browser 트리의 Servers 노드를 확장하고 EDB Postgres Advanced Server 노드를 마우스 오른쪽 클릭합니다. 컨텍스트 메뉴에서 **Connect Server**를 선택합니다. Connect to Server 대화 상자가 열립니다.

![Connect to Server 대화 상자](https://www.enterprisedb.com/docs/static/05b417d8e659ea8eb5d42d5dc2f49fee/9128f/connecting_server.png)

연결하려면 **Password** 필드에 데이터베이스 슈퍼유저 비밀번호를 입력하고 **OK**를 선택합니다.

![EDB Postgres Advanced Server 데이터베이스 연결](https://www.enterprisedb.com/docs/static/b38d1e00df6a4b7c1fed2fc7630a79b5/302a4/connecting_to_advanced_server_database.png)

클라이언트가 연결되면 Browser 트리로 기존 데이터베이스 객체 정보를 조회하거나 새 객체를 생성할 수 있습니다. pgAdmin 클라이언트 사용에 대한 자세한 내용은 **Help** 메뉴를 이용하십시오.
