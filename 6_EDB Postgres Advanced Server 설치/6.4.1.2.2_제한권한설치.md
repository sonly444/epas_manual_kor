# 제한된 권한으로 설치 수행 (Performing an installation with limited privileges) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › On Windows › … › Performing an installation with limited privileges](https://www.enterprisedb.com/docs/epas/latest/installing/windows/installing_advanced_server_with_the_interactive_installer/invoking_the_graphical_installer_from_the_command_line/performing_an_installation_with_limited_privileges/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·경로·옵션·UI 항목명은 원문 그대로 보존했습니다.

관리자 권한 없이 EDB Postgres Advanced Server를 축약 설치하려면 명령줄에서 인스톨러를 호출하고 `--extract-only` 옵션을 포함합니다. `--extract-only` 옵션은 바이너리 파일을 변경 없이 추출하여 EPAS의 최소 설치를 실험할 수 있게 합니다.

`--extract-only` 옵션으로 인스톨러를 호출하면 클러스터를 수동으로 생성하고 서비스를 시작하거나 설치 스크립트를 실행할 수 있습니다. 클러스터를 수동으로 생성하려면 다음을 해야 합니다.

- initdb로 클러스터 초기화
- 클러스터 구성
- pg_ctl로 서비스 시작

initdb와 pg_ctl에 대한 자세한 내용은 PostgreSQL 코어 문서([initdb](https://www.postgresql.org/docs/current/static/app-initdb.html), [pg_ctl](https://www.postgresql.org/docs/current/static/app-pg-ctl.html))를 참고하십시오.

`--extract-only` 옵션을 포함하면 인스톨러는 축약된 형태의 설정 마법사를 진행합니다. 짧은 설치 과정에서 인스톨러는 나중에 더 완전한 설치를 완료하는 데 사용할 수 있는 설치 스크립트를 생성합니다. 설치 스크립트를 호출하려면 관리자 권한이 있어야 합니다.

설치 스크립트는 다음을 수행합니다.

- 클러스터가 비어 있으면 데이터베이스 클러스터를 초기화합니다.
- 부팅 시 서버가 시작되도록 구성합니다.
- Dynatune(동적 튜닝) 변수의 초기값을 설정합니다.

스크립트 방식 EPAS 설치는 메뉴 바로 가기를 만들지 않고, StackBuilder Plus 접근을 제공하지 않으며, 레지스트리 파일을 변경하지 않습니다.

제한 설치를 수행하고 설치 스크립트를 생성하려면:

1. EPAS 인스톨러를 내려받아 압축을 풉니다.

2. 인스톨러가 있는 디렉터리로 이동하여 인스톨러를 호출합니다.

```text
edb-as<xx>-server-xx.x.x-x-windows.exe --extract-only yes
```

   `<xx>`는 EPAS 버전 번호입니다. 설치 언어를 선택하라는 대화 상자가 열립니다.

3. 설치 언어를 선택하고 **OK**를 선택합니다. 설정 마법사가 열립니다.

![환영 창](https://www.enterprisedb.com/docs/static/2c518d038d6a526b9a435bbe53f31c3d/08c0b/advanced_server_installer_welcome.png)

4. **Next**를 선택합니다.

![설치 디렉터리 지정](https://www.enterprisedb.com/docs/static/1f72006739995fd9e61c681cec9f10cb/74cfa/installation_directory.png)

Windows에서 기본 EPAS 설치 디렉터리는 `C:\Program Files\edb\as15`입니다.

5. 기본 설치 위치를 수락하고 **Next**를 선택하여 Ready to Install 창으로 진행합니다. 또는 파일 브라우저로 다른 디렉터리를 선택할 수 있습니다.

![설정 마법사가 EPAS 설치 준비 완료](https://www.enterprisedb.com/docs/static/0810fcfc2dbf8e67211b1aafdd076723/0a47e/ready_to_install.png)

6. EPAS 설치를 진행하려면 **Next**를 선택합니다. 설치 중 진행률 표시줄과 팝업으로 진행 상황이 표시됩니다. 설치가 완료되면 알림이 표시됩니다.

![EPAS 설치 완료](https://www.enterprisedb.com/docs/static/589e854215b8056a02822a230535dc7a/08c0b/advanced_server_installation_completion.png)

최소 설치를 완료한 뒤, 스크립트를 실행하여 클러스터를 초기화하고 서비스를 시작할 수 있습니다. 스크립트는 기본적으로 `C:\Program Files\edb`에 위치합니다.
