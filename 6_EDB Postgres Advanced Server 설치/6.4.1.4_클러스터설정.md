# 그래픽 설치 중 클러스터 설정 지정 (Setting cluster preferences during a graphical installation) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › On Windows › … › Setting cluster preferences](https://www.enterprisedb.com/docs/epas/latest/installing/windows/installing_advanced_server_with_the_interactive_installer/setting_cluster_preferences/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·옵션은 원문 그대로 보존했습니다.

설치 중 그래픽 인스톨러는 PostgreSQL `initdb` 유틸리티를 호출하여 클러스터를 초기화합니다. 그래픽 인스톨러를 사용하는 경우 `INITDBOPTS` 환경 변수로 `initdb` 선호를 지정할 수 있습니다. 그래픽 인스톨러를 호출하기 전에 명령줄에서 `INITDBOPTS` 값을 설정하여 하나 이상의 클러스터 옵션을 지정합니다. 예:

```text
SET INITDBOPTS= -k -E=UTF-8
```

인스톨러가 제공하는 값(예: 설치 디렉터리를 지정하는 `-D` 옵션)을 `INITDBOPTS`에도 지정하면, 그래픽 인스톨러에 지정된 값이 우선합니다.

`initdb` 클러스터 구성 옵션 사용에 대한 자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/app-initdb.html)를 참고하십시오. PostgreSQL 코어 문서에 문서화된 옵션 외에 EPAS는 다음 `initdb` 옵션을 지원합니다.

**`--no-redwood-compat`** — 서버가 PostgreSQL 모드로 클러스터를 생성하도록 지시. 이 모드에서는 데이터베이스 슈퍼유저 이름이 `postgres`, 기본 데이터베이스 이름이 `postgres`. Oracle 호환 기능 중 일부만 사용 가능. 모든 Oracle 호환 기능을 사용하려면 redwood 호환 모드 권장.

**`--redwood-like`** — Oracle 구문과 호환되는 SQL 문에서 `LIKE`(또는 PostgreSQL 호환 `ILIKE`) 연산자 뒤에 이스케이프 문자(빈 문자열 '')를 사용하도록 지시.

**`--icu-short-form`** — 클러스터의 모든 데이터베이스에 기본 ICU(International Components for Unicode) 콜레이션을 사용하는 클러스터를 생성. 자세한 내용은 Unicode collation algorithm 문서 참조.
