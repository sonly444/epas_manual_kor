# 대화형 인스톨러로 설치 (Installing with the interactive installer) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › On Windows › Using the interactive installer](https://www.enterprisedb.com/docs/epas/latest/installing/windows/installing_advanced_server_with_the_interactive_installer/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·경로·변수는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server 대화형 인스톨러로 Windows에 EDB Postgres Advanced Server를 설치할 수 있습니다. 대화형 인스톨러는 EDB 웹사이트의 [Downloads 페이지](https://www.enterprisedb.com/advanced-downloads)에서 제공됩니다.

그래픽 인스톨러를 여러 설치 모드로 호출하여 EDB Postgres Advanced Server 설치를 수행할 수 있습니다.

설치 중 그래픽 인스톨러는 여러 임시 파일을 `TEMP` 환경 변수가 지정한 위치로 복사합니다. 명령줄에서 `TEMP` 환경 변수 값을 수정하여 임시 파일의 대체 위치를 선택적으로 지정할 수 있습니다.

```text
SET TEMP=<temp_file_location>
```

`<temp_file_location>`은 임시 파일의 대체 위치를 지정하며, `TEMP` 환경 변수의 권한과 일치해야 합니다.

> **참고(Note)**
>
> 시스템 업그레이드를 위해 인스톨러를 호출하는 경우, 인스톨러는 이전 설치 시 지정한 구성 옵션을 보존합니다.

- StackBuilder Plus 사용 (Using StackBuilder Plus)
- 클러스터 설정 지정 (Setting cluster preferences)
