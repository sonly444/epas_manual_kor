# EDB Postgres Advanced Server 시작·중지 (Starting and stopping) — EPAS 18 Windows 설치

> 원문: [EPAS v18 — Installing › On Windows › Managing an installation › Starting and stopping EPAS](https://www.enterprisedb.com/docs/epas/latest/installing/windows/managing_an_advanced_server_installation/starting_and_stopping_epas/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 서비스명은 원문 그대로 보존했습니다.

서비스(service)는 백그라운드에서 실행되며 사용자 상호작용이 필요 없는 프로그램입니다. 서비스에는 사용자 인터페이스가 없습니다. 부팅 시 시작하거나 필요 시 수동으로 시작하도록 구성할 수 있습니다. 서비스는 플랫폼별 운영체제 서비스 제어 유틸리티로 제어하는 것이 가장 좋습니다. EDB Postgres Advanced Server 지원 구성 요소 중 다수가 서비스입니다.

다음 표는 EDB Postgres Advanced Server와 그 지원 구성 요소를 제어하는 서비스의 이름을 나열합니다.

| EPAS 구성 요소 이름 | Windows 서비스명 |
|---|---|
| EDB Postgres Advanced Server | edb-as-18 |
| PgBouncer | edb-pgbouncer-1.21 |
| Slony | edb-slony-replication-14 |

Windows 호스트에서 명령줄 또는 Windows Services 애플릿을 사용하여 EDB Postgres Advanced Server 데이터베이스 서버와 지원 구성 요소의 서비스를 제어할 수 있습니다.
