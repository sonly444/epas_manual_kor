# 패키지 제외/포함 (Excluding/Including the packages) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › … › Managing an installation › Excluding/Including the packages](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/managing_an_advanced_server_installation/exclude_include_packages/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·설정은 원문 그대로 보존했습니다.

각 Linux 배포판은 권장(recommended) 또는 약한(weak) 의존성을 고유하게 처리합니다. 여기서는 패키지 설치 중 이러한 의존성을 포함하거나 제외하는 방법을 설명합니다.

이 설정을 조정하면 패키지 설치를 더 세밀하게 제어할 수 있어, 최소 환경을 만들거나 불필요한 패키지 비대화를 줄이는 데 유용합니다.

## RHEL / Rocky Linux / AlmaLinux

**약한 의존성 임시 제외:**

단일 작업에서 DNF가 약한 의존성을 설치하지 않도록 하려면:

```bash
dnf --setopt=install_weak_deps=False install <package-name>
```

**약한 의존성 영구 제외:**

시스템 전체에서 약한 의존성 설치를 비활성화하려면:

1. DNF 구성 파일을 엽니다.

```bash
sudo nano /etc/dnf/dnf.conf
```

2. 다음 줄을 추가합니다.

```ini
install_weak_deps=False
```

이 설정은 약한 의존성이 기본적으로 설치되지 않도록 보장합니다.

## SLES

**권장 패키지 임시 제외:**

권장 패키지 없이 필수 패키지만 설치하려면:

```bash
zypper install --no-recommends <package-name>
```

**권장 패키지 명시적 포함:**

필수 패키지와 권장 패키지를 모두 설치하려면:

```bash
zypper install --recommends <package-name>
```

**기본 동작 구성:**

권장 패키지에 대한 Zypper의 기본 동작을 변경하려면:

1. Zypper 구성 파일을 편집합니다.

```bash
sudo nano /etc/zypp/zypp.conf
```

2. 다음 옵션을 설정합니다.

```ini
solver.onlyRequires = true
```

이 구성은 기본적으로 필수 패키지만 설치되도록 보장합니다.

## Debian / Ubuntu

**권장 패키지 임시 제외:**

권장 의존성 없이 패키지를 설치하려면:

```bash
apt-get install --no-install-recommends <package-name>
```

**기본 동작 설정:**

APT가 기본적으로 권장 패키지를 설치하지 않도록 하려면:

1. 새 구성 파일을 만듭니다.

```bash
sudo nano /etc/apt/apt.conf.d/99norecommends
```

2. 다음 줄을 추가합니다.

```ini
APT::Install-Recommends "false";
APT::Install-Suggests "false";
```

이 구성은 권장·제안 패키지의 자동 설치를 비활성화합니다.
