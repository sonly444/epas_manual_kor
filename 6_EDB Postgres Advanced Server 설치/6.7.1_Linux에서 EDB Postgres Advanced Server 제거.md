# Linux에서 제거 — EPAS 18 설치

> 원문: [EPAS v18 — Installing › Uninstalling › On Linux](https://www.enterprisedb.com/docs/epas/latest/installing/uninstalling/linux_uninstall/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·패키지·경로는 원문 그대로 보존했습니다.

> **참고(Note)**
>
> EDB Postgres Advanced Server를 제거한 후에도 클러스터 데이터 파일은 그대로 남고 서비스 사용자도 유지됩니다. 필요하면 클러스터 `data`와 서비스 사용자를 시스템에서 수동으로 제거할 수 있습니다.

## RHEL / AlmaLinux / Rocky Linux에서 제거

`dnf` 명령으로 설치된 패키지를 제거할 수 있습니다. 패키지를 제거해도 EDB Postgres Advanced Server `data` 디렉터리는 손상되지 않습니다.

`rpm` 명령으로 설치된 패키지를 제거하려면 `-e` 옵션을 포함합니다.

```text
rpm -e <package_name>
```

`package_name`은 제거하려는 패키지의 이름입니다.

dnf로 설치한 패키지는 `dnf remove` 명령으로 제거할 수 있습니다. 패키지를 제거하려면 명령줄에서 슈퍼유저 권한을 얻고 다음을 입력합니다.

```text
dnf remove <package_name>
```

`package_name`은 제거하려는 패키지의 이름입니다.

yum과 rpm은 다른 패키지가 필요로 하는 패키지는 제거하지 않습니다. 패키지 의존성을 충족하는 패키지를 제거하려고 하면 yum 또는 rpm이 경고를 표시합니다.

> **참고(Note)**
>
> RHEL 또는 Rocky Linux 또는 AlmaLinux 8·9에서는 패키지를 제거하면 다른 패키지가 필요로 하지 않는 모든 의존성도 함께 제거됩니다. 이 기본 동작을 재정의하려면 `/etc/yum.conf` 파일에서 `clean_requirements_on_remove` 파라미터를 비활성화합니다.

EDB Postgres Advanced Server와 그 의존 패키지를 제거하려면 다음을 입력합니다.

```text
dnf remove edb-as<xx>-server*
```

`<xx>`는 EDB Postgres Advanced Server 버전 번호입니다.

## Debian 또는 Ubuntu에서 제거

- EDB Postgres Advanced Server를 제거하려면 다음 명령을 실행합니다. 구성 파일과 데이터 디렉터리는 그대로 유지됩니다.

```text
apt-get remove edb-as<xx>-server*
```

- EDB Postgres Advanced Server와 구성 파일, 데이터 디렉터리까지 제거하려면 다음 명령을 실행합니다.

```text
apt-get purge edb-as<xx>-server*
```
