# 사용 가능한 네이티브 패키지 (Available native packages) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › Linux installation details › Available native packages](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/rpm_packages/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지명·명령·경로는 원문 그대로 보존했습니다.

EDB는 EDB 리포지토리에서 여러 네이티브 패키지를 제공합니다. 패키지는 각 Linux 배포판마다 약간씩 다릅니다.

## RHEL / Rocky Linux / AlmaLinux / SLES 패키지

### EDB Postgres Advanced Server RPM 패키지

다음 표는 EDB에서 제공하는 RPM 패키지를 나열합니다. `dnf search` 명령으로 구성된 리포지토리에서 현재 사용 가능한 패키지 목록을 확인할 수도 있습니다. 명령줄에서 슈퍼유저 권한을 얻고 입력합니다.

RHEL 또는 Rocky Linux 또는 AlmaLinux 8:

```text
dnf search <package>
```

`package`는 패키지의 이름 또는 부분 이름을 지정하는 검색어입니다.
