# edb-psql로 EPAS 접속 (Connecting to EDB Postgres Advanced Server with edb-psql) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › … › Managing an installation › Connecting to EPAS with edb-psql](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/managing_an_advanced_server_installation/connecting_to_epas/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·옵션·경로는 원문 그대로 보존했습니다.

edb-psql은 SQL 명령을 실행하고 결과를 볼 수 있는 명령줄 클라이언트 애플리케이션입니다. edb-psql 클라이언트를 열려면 클라이언트가 검색 경로에 있어야 합니다. 실행 파일은 EDB Postgres Advanced Server 설치의 `bin` 디렉터리에 있습니다.

## 클라이언트 시작

edb-psql 클라이언트를 시작하려면 다음 명령과 옵션을 사용합니다.

```text
edb-psql -d edb -U enterprisedb
```

여기서:

- `-d`는 edb-psql이 연결할 데이터베이스를 지정합니다.
- `-U`는 세션에 사용할 데이터베이스 사용자의 신원을 지정합니다.

`edb-psql` 실행 파일은 `psql`이라는 바이너리에 대한 심볼릭 링크이며, 이는 EDB Postgres Advanced Server 기능 지원이 추가된 PostgreSQL 커뮤니티 psql의 수정 버전입니다. 명령줄 클라이언트 사용에 대한 자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/app-psql.html)를 참고하십시오.

## Debian 또는 Ubuntu 호스트에서 인증 관리

Debian 또는 Ubuntu 호스트에서 서버는 기본적으로 peer 또는 md5 권한으로 실행됩니다. `/etc/edb-as/18/main/` 아래에 있는 `pg_hba.conf` 파일을 수정하여 인증 방식을 변경할 수 있습니다.

`pg_hba.conf` 파일 수정에 대한 자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/auth-pg-hba-conf.html)를 참고하십시오.
