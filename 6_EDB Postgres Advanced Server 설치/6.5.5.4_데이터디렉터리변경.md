# 데이터 디렉터리 위치 변경 (Modifying the data directory location) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › … › Managing an installation › Modifying the data directory location](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/managing_an_advanced_server_installation/modifying_the_data_directory_location/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·경로·설정은 원문 그대로 보존했습니다.

## RHEL / Rocky Linux / AlmaLinux 8.x | 9.x

RHEL/Rocky Linux/AlmaLinux 8.x 또는 9.x 호스트에서 유닛 파일 이름은 `edb-as-<xx>.service`(`<xx>`는 EPAS 버전)이며 `/usr/lib/systemd/system`에 있습니다. 유닛 파일에는 EDB Postgres Advanced Server `data` 디렉터리 위치에 대한 참조가 포함됩니다. 패키지 업그레이드 시 덮어쓰일 수 있으므로 유닛 파일을 직접 수정하지 마십시오.

기본적으로 데이터 파일은 `/var/lib/edb/as18/data` 디렉터리 아래에 있습니다. 기본이 아닌 위치의 데이터 디렉터리를 사용하려면:

- `/etc` 디렉터리 아래에 유닛 파일의 복사본을 만듭니다.

```text
cp /usr/lib/systemd/system/edb-as-18.service /etc/systemd/system/
```

- `/etc/systemd/system/edb-as-18.service` 파일에서 다음 값을 데이터 디렉터리의 새 위치로 업데이트합니다.

```text
Environment=PGDATA=/var/lib/edb/as18/data
PIDFile=/var/lib/edb/as18/data/postmaster.pid
```

- bin 디렉터리로 이동하여 새 위치로 클러스터를 초기화합니다.

```text
./edb-as-18-setup initdb
```

- EDB Postgres Advanced Server 서비스를 시작합니다.

```text
systemctl start edb-as-18
```

## RHEL / Rocky Linux / AlmaLinux 8.x | 9.x에서 SELinux 정책을 구성하여 데이터 디렉터리 위치 변경

기본적으로 데이터 파일은 `/var/lib/edb/as18/data` 디렉터리 아래에 있습니다. 개별 환경 선호에 따라 기본 데이터 디렉터리 위치를 변경하려면 SELinux 정책을 구성해야 합니다.

- 서버를 중지합니다.

```text
systemctl stop edb-as-18
```

- `getenforce` 또는 `sestatus` 명령으로 SELinux 상태를 확인합니다.

```text
# getenforce
Enforcing

# sestatus
SELinux status:                 enabled
SELinuxfs mount:                /sys/fs/selinux
SELinux root directory:         /etc/selinux
Loaded policy name:             targeted
Current mode:                   enforcing
Mode from config file:          enforcing
Policy MLS status:              enabled
Policy deny_unknown status:     allowed
Max kernel policy version:      31
```

- 기본 데이터베이스 위치의 SELinux 컨텍스트를 확인합니다.

```text
ls -lZ /var/lib/edb/as18/data
drwx------. enterprisedb enterprisedb unconfined_u:object_r:var_lib_t:s0 log
```

- 데이터베이스의 새 위치를 위한 디렉터리를 만듭니다.

```text
mkdir /opt/edb
```

- 데이터 디렉터리를 `/opt/edb`로 이동합니다.

```text
mv /var/lib/edb/as18/data /opt/edb/
```

- 새 데이터 디렉터리 위치를 포함하도록 `/etc/systemd/system` 아래에 `edb-as-18.service` 파일을 만듭니다.

```text
.include /lib/systemd/system/edb-as-18.service
[Service]
Environment=PGDATA=/opt/edb/data
PIDFile=/opt/edb/data/postmaster.pid
```

- semanage 유틸리티로 `/opt/edb/`의 컨텍스트 매핑을 설정합니다. 매핑은 `/etc/selinux/targeted/contexts/files/file.contexts.local` 파일에 기록됩니다.

```text
semanage fcontext --add --equal /var/lib/edb/as18/data /opt/edb
```

- restorecon 유틸리티로 컨텍스트 매핑을 적용합니다.

```text
restorecon -rv /opt/edb/
```

- systemd를 다시 로드하여 서비스 스크립트를 수정합니다.

```text
systemctl daemon-reload
```

- `/opt/edb` 위치에 컨텍스트가 올바르게 라벨링된 상태에서 서비스를 시작합니다.

```text
systemctl start edb-as-18
```
