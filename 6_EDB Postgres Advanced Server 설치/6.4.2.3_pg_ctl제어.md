# pg_ctl로 EDB Postgres Advanced Server 제어 (Using pg_ctl) — EPAS 18 Windows 설치

> 원문: [EPAS v18 — Installing › On Windows › Managing an installation › Using pg_ctl to control EPAS](https://www.enterprisedb.com/docs/epas/latest/installing/windows/managing_an_advanced_server_installation/using_pg_ctl_to_control_advanced_server/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·옵션은 원문 그대로 보존했습니다.

pg_ctl 유틸리티로 어떤 플랫폼에서든 명령줄에서 EDB Postgres Advanced Server 서비스를 제어할 수 있습니다. pg_ctl로 EDB Postgres Advanced Server 데이터베이스 서버를 시작·중지·재시작하거나, 구성 파라미터를 다시 로드하거나, 실행 중인 서버의 상태를 표시할 수 있습니다. 유틸리티를 호출하려면 클러스터 소유자 신원을 가정하고 EDB Postgres Advanced Server 홈 디렉터리로 이동하여 다음 명령을 실행합니다.

```text
./bin/pg_ctl -D <data_directory> <action>
```

여기서:

- `data_directory`는 EDB Postgres Advanced Server 클러스터가 제어하는 데이터의 위치입니다.
- `action`은 pg_ctl 유틸리티가 수행할 동작을 지정합니다.
  - `start` — 서비스 시작
  - `stop` — 서비스 중지
  - `restart` — 서비스 중지 후 시작
  - `reload` — 서버에 `SIGHUP` 신호를 보내 구성 파라미터를 다시 로드
  - `status` — 서비스의 현재 상태 확인

pg_ctl 유틸리티 사용이나 사용 가능한 명령줄 옵션에 대한 자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/app-pg-ctl.html)를 참고하십시오.
