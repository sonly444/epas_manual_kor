# Debian 11 x86_64에 EDB Postgres Advanced Server 설치 (Installing EDB Postgres Advanced Server on Debian 11 x86_64) — EPAS 18

> 원문: [EPAS v18 — Installing › Linux x86 (amd64) › Debian 11 x86_64](https://www.enterprisedb.com/docs/epas/latest/installing/linux_x86_64/epas_debian_11/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 사전 요구사항 (Prerequisites)

설치 프로세스를 시작하기 전에:

- EDB 저장소(repository)를 설정합니다.

저장소 설정은 한 번만 수행하는 작업입니다. 이미 저장소를 설정했다면 이 단계를 수행할 필요가 없습니다.

저장소가 존재하는지 확인하려면 다음 명령을 입력합니다:

`apt-cache search enterprisedb`

출력이 생성되지 않으면 저장소가 설치되지 않은 것입니다.

EDB 저장소를 설정하려면:

1. [EDB repositories](https://www.enterprisedb.com/repos-downloads)로 이동합니다.

2. EDB 저장소에 대한 접근을 제공하는 버튼을 선택합니다.

3. 다운로드하려는 플랫폼과 소프트웨어를 선택합니다.

4. EDB 저장소 설정 지침을 따릅니다.

## 패키지 설치 (Install the package)

```shell
sudo apt-get -y install edb-as<xx>-server
```

여기서 `<xx>`는 설치하려는 EDB Postgres Advanced Server의 버전입니다. 예를 들어 버전 18을 설치하는 경우 패키지 이름은 `edb-as18-server`입니다.

개별 구성 요소를 설치하려면:

```shell
sudo apt-get -y install <package_name>
```

여기서 `package_name`은 [사용 가능한 패키지 목록(available package list)](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/rpm_packages/)의 어떤 패키지든 될 수 있습니다.

EDB Postgres Advanced Server를 설치하는 동안 개별 패키지를 제외하거나 포함하려면 [패키지 제외/포함(excluding/including the packages)](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/managing_an_advanced_server_installation/exclude_include_packages/)을 참고하십시오.

## 초기 구성 (Initial configuration)

이 섹션에서는 로그인, 설치 성공 여부 확인, 클러스터 연결, 사용자 비밀번호 생성 등 클러스터를 시작하는 과정을 단계별로 안내합니다.

클러스터에서 작업하려면 enterprisedb 사용자로 로그인합니다. psql 명령줄 클라이언트를 사용하여 데이터베이스 서버에 연결합니다. 또는 적절한 연결 문자열과 함께 원하는 클라이언트를 사용할 수도 있습니다.

```shell
sudo su - enterprisedb

psql edb
```

서버는 기본적으로 `peer` 또는 `ident` 권한으로 실행됩니다. `pg_hba.conf` 파일을 수정하여 인증 방식을 변경할 수 있습니다.

인증 방식을 변경하기 전에 데이터베이스 슈퍼유저 enterprisedb에 비밀번호를 할당하십시오. 인증 변경에 대한 자세한 내용은 [pg_hba.conf 파일 수정(Modifying the pg_hba.conf file)](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/01_setting_new_parameters/#modifying-the-pg_hbaconf-file)을 참고하십시오.

```sql
ALTER ROLE enterprisedb IDENTIFIED BY password;
```

## 실습 (Experiment)

이제 데이터베이스를 생성하고 연결하며, 테이블을 만들고, 테이블에 데이터를 삽입하고, 테이블의 데이터를 조회할 준비가 되었습니다.

먼저 psql을 사용하여 인사(human resource) 정보를 담을 `hr`이라는 데이터베이스를 생성합니다.

```sql
# running in psql
CREATE DATABASE hr;
```

출력(Output)

```text
CREATE DATABASE
```

psql 내에서 `hr` 데이터베이스에 연결합니다:

```text
\c hr
```

출력(Output)

```text
psql (18.0.0, server 18.0.0)
You are now connected to database "hr" as user "enterprisedb".
```

부서 번호, 고유한 부서 이름, 위치를 담을 열을 생성합니다:

```text
CREATE TABLE public.dept (deptno numeric(2) NOT NULL CONSTRAINT dept_pk
PRIMARY KEY, dname varchar(14) CONSTRAINT dept_dname_uq UNIQUE, loc
varchar(13));
```

출력(Output)

```text
CREATE TABLE
```

`dept` 테이블에 값을 삽입합니다:

```text
INSERT INTO dept VALUES (10,'ACCOUNTING','NEW YORK');
```

출력(Output)

```text
INSERT 0 1
```

```text
INSERT into dept VALUES (20,'RESEARCH','DALLAS');
```

출력(Output)

```text
INSERT 0 1
```

테이블에서 값을 선택하여 테이블 데이터를 조회합니다:

```text
SELECT * FROM dept;
```

출력(Output)

```text
deptno  |   dname    |   loc
--------+------------+----------
10      | ACCOUNTING | NEW YORK
20      | RESEARCH   | DALLAS
(2 rows)
```
