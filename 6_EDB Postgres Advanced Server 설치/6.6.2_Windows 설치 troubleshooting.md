# Windows 설치 문제 해결 (Windows installation troubleshooting) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › Troubleshooting › On Windows](https://www.enterprisedb.com/docs/epas/latest/installing/troubleshooting/windows_troubleshooting/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·옵션·오류 메시지는 원문 그대로 보존했습니다.

### Java 기반 애플리케이션 표시 문제

Java 기반 서버 기능이 제대로 표시되지 않는 경우(컨트롤·텍스트가 올바르게 표시되지 않거나 빈 창이 나타나는 경우), 대부분의 배포판에서는 최신 `libxcb-xlib` 라이브러리로 업그레이드하면 문제가 해결됩니다. 다른 가능한 해결책은 [Java 버그 데이터베이스](http://bugs.sun.com/bugdatabase/view_bug.do?bug_id=6532373)를 참고하십시오.

### `--mode unattended` 인증 오류

무인(unattended) 설치 중 구성 요소 모듈에서 발생하는 인증 오류는 지정한 `--servicepassword` 또는 `--superpassword` 값이 올바르지 않음을 나타낼 수 있습니다.

### EDB Postgres Advanced Server 설치 중 오류

설치 과정에서 오류가 발생하면 설치를 종료하고, Windows 버전이 최신인지 확인하십시오. 미적용 운영체제 업데이트를 적용한 뒤 EDB Postgres Advanced Server 인스톨러를 다시 실행하십시오.

### 데이터 디렉터리에 기존 내용이 있어 설치가 완료되지 않는 경우

데이터 디렉터리에 기존 내용이 있어 설치가 완료되지 않으면 서버는 서버 로그에 오류 메시지를 기록합니다.

`A data directory is neither empty, or a recognisable data directory`.

이와 유사한 메시지가 나타나면 데이터 디렉터리가 비어 있는지 확인하십시오. 시스템이 생성한 `lost+found` 폴더를 포함하여 파일이 존재하면 설치가 완료되지 않습니다. 데이터 디렉터리에서 파일을 제거하거나, 인스톨러를 다시 실행하기 전에 데이터 디렉터리 위치를 다른 곳으로 지정하십시오.
