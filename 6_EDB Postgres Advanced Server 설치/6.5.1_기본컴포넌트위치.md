# 기본 컴포넌트 위치 (Default component locations) — EPAS 18 설치

> 원문: [EPAS v18 — Installing › Linux installation details › Default component locations](https://www.enterprisedb.com/docs/epas/latest/installing/linux_install_details/component_locations/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 경로는 원문 그대로 보존했습니다.

각 Linux 배포판의 패키지 관리자는 EDB Postgres Advanced Server 구성 요소를 서로 다른 위치에 설치합니다.

## RHEL / Rocky Linux / AlmaLinux / SLES 위치

RPM 인스톨러는 EDB Postgres Advanced Server 구성 요소를 다음 표의 디렉터리에 배치합니다.

| 구성 요소 | 위치 |
|---|---|
| 실행 파일(Executables) | `/usr/edb/as18/bin` |
| 라이브러리(Libraries) | `/usr/edb/as18/lib` |
| 클러스터 구성 파일 | `/var/lib/edb/as18` |
| 문서(Documentation) | `/usr/edb/as18/share/doc` |
| Contrib | `/usr/edb/as18/share/contrib` |
| 데이터(Data) | `/var/lib/edb/as18/data` |
| 로그(Logs) | `/var/log/edb/as18` |
| 잠금 파일(Lock files) | `/var/lock/edb/as18` |
| 백업 영역(Backup area) | `/var/lib/edb/as18/backups` |
| 템플릿(Templates) | `/usr/edb/as18/share` |
| 절차적 언어(Procedural Languages) | `/usr/edb/as18/lib` 또는 `/usr/edb/as18/lib64` |
| 개발 헤더(Development Headers) | `/usr/edb/as18/include` |
| 공유 데이터(Shared data) | `/usr/edb/as18/share` |
| SGML 문서 | `/usr/edb/as18/share/doc` |

## Debian / Ubuntu 위치

Debian 패키지 관리자는 EDB Postgres Advanced Server와 지원 구성 요소를 다음 표의 디렉터리에 배치합니다.

| 구성 요소 | 위치 |
|---|---|
| 서버(Server) | `/usr/lib/edb-as/18/` |
| 데이터·구성 디렉터리 | `/var/lib/edb-as/18/main`, `/etc/edb-as/18/main/` |
| Pgpool | `/usr/edb/pgpool4.6/` |
| Postgis | `/usr/lib/edb-as/18/` |
| pgBouncer | `/usr/edb/pgbouncer1.25/` |
| pgBouncer 구성 파일 | `/etc/edb/pgbouncer1.25/pgbouncer.ini`, `/etc/edb/pgbouncer1.25/userlist.txt` |
| SQL-Profiler | `/usr/lib/edb-as/18/lib` |
| SQL-Protect | `/usr/lib/edb-as/18/lib` |
| SSLUTILS | `/usr/lib/edb-as/18/lib` |
| PL-PERL | `/usr/lib/edb-as/18/lib` |
| PL-PYTHON | `/usr/lib/edb-as/18/lib` |
| PLTCL | `/usr/lib/edb-as/18/lib` |
| EFM | `/usr/edb/efm-5.0/` |
| JDBC | `/usr/edb/jdbc` |
| MTK | `/usr/edb/migrationtoolkit/` |
