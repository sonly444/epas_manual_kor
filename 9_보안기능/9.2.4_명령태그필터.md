# 명령 태그로 감사 로그 필터링 (Using command tags to filter audit logs) — EPAS 18

> 원문: [EPAS v18 — Security guide › Using EDB audit logging › Using command tags to filter audit logs](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/05_edb_audit_logging/06_using_command_tags_to_filter_audit_logs/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·로그 출력은 원문 그대로 보존했습니다.

로그 파일의 각 항목에는 오류 메시지를 표시하는 항목을 제외하고 *명령 태그(command tag)*가 포함됩니다. 명령 태그는 해당 로그 항목에 대해 실행된 SQL 명령입니다. 명령 태그를 사용하면 나중에 도구로 로그 파일을 스캔하여 SQL 명령과 관련된 항목을 찾을 수 있습니다.

이 예는 검토를 쉽게 하기 위해 형식을 지정한 XML 형태입니다. 명령 태그는 `event` 요소의 `command_tag` 속성으로 표시되며, 값은 `CREATE ROLE`, `ALTER ROLE`, `DROP ROLE`입니다.

```xml

"[local]"
       session_id="5ecbc7e6.faea" session_line_num="2" process_status="idle"
       session_start_time="2020-05-25 18:58:06 IST" log_time="2020-05-25
       18:58:21.147 IST"
       virtual_transaction_id="4/30" type="create" command_tag="CREATE ROLE"
       application_name="psql" backend_type="client backend">
           <error_severity>AUDIT</error_severity>
           <message>statement: CREATE ROLE newuser WITH LOGIN;</message>
</event>
<event user="enterprisedb" database="edb" process_id="64234" remote_host=
"[local]"

       18:58:34.142 IST"

           <error_severity>ERROR</error_severity>
           <message>unrecognized role option &quot;super&quot;</message>
           <query>ALTER ROLE newuser WITH SUPER USER;</query>
           <query_pos>25</query_pos>
</event>
```
