# SSL 인증서 생성 (sslutils) — EPAS 18 Security

> 원문: [EPAS v18 — Security › Generating SSL certificates](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/04_sslutils/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·시그니처·패키지 이름은 원문 그대로 보존했습니다.

`sslutils`는 EDB Postgres Enterprise Manager 서버가 사용할 SSL 인증서 생성 함수를 EDB Postgres Advanced Server에 제공하는 Postgres 확장입니다.

## 확장 설치

`sslutils`는 `edb-as<xx>-server-sslutils` RPM 패키지로 설치합니다(`<xx>`는 EDB Postgres Advanced Server 버전 번호).

함수의 파라미터 목록에서 각 파라미터는 `parameter n`으로 설명되며, `n`은 함수 파라미터 목록에서의 n번째 서수 위치(예: 첫째, 둘째, 셋째)를 가리킵니다.

## openssl_rsa_generate_key

`openssl_rsa_generate_key` 함수는 RSA 개인 키를 생성합니다. 함수 시그니처:

```
openssl_rsa_generate_key(<integer>) RETURNS <text>
```

함수를 호출할 때 비트 수를 정수 값으로 전달합니다. 함수는 생성된 키를 반환합니다.

## openssl_rsa_key_to_csr

`openssl_rsa_key_to_csr` 함수는 인증서 서명 요청(CSR)을 생성합니다. 파일 경로 인자는 `PGDATA` 안에 있어야 합니다. 시그니처:

```
openssl_rsa_key_to_csr(<text>, <text>, <text>, <text>, <text>, <text>,
<text>) RETURNS <text>
```

함수는 인증서 서명 요청을 생성하여 반환합니다.

**파라미터**

- `parameter 1`: RSA 개인 키의 PEM 본문 텍스트 (`openssl_rsa_generate_key()`반환값 또는 암호화되지 않은 PEM 형식 텍스트. 파일 경로가 아닌 PEM 텍스트 값을 직접 전달)
- `parameter 2`: 서명 요청을 사용할 에이전트의 common name(예: `agentN`).
- `parameter 3`: 서버가 위치한 국가 이름.
- `parameter 4`: 서버가 위치한 주(state) 이름.
- `parameter 5`: 서버가 위치한 주 내의 위치(도시).
- `parameter 6`: 인증서를 요청하는 조직 단위(organization unit)의 이름.
- `parameter 7`: 인증서를 요청하는 사용자의 이메일 주소.

```SQL
SELECT openssl_rsa_key_to_csr(
    openssl_rsa_generate_key(2048),
    'agentN',
    'KR',
    'Seoul',
    'Seoul',
    'Seoul',
    'user@example.com'
);
```

## openssl_csr_to_crt

`openssl_csr_to_crt` 함수는 자체 서명 인증서 또는 인증 기관(CA) 인증서를 생성합니다. 시그니처:

```
openssl_csr_to_crt(<text>, <text>, <text>) RETURNS <text>
```

함수는 자체 서명 인증서 또는 CA 인증서를 반환합니다.

**파라미터**

- `parameter 1`: 서명하는 인증서 요청의 이름.
- `parameter 2`: CA 인증서 경로, 또는 CA 인증서를 생성하는 경우 `NULL`.
- `parameter 3`: CA의 개인 키 경로, 또는 인자 `2`가 `NULL`이면 개인 키 경로.

## openssl_rsa_generate_crl

`openssl_rsa_generate_crl` 함수는 기본 인증서 폐기 목록(CRL)을 생성합니다. 시그니처:

```
openssl_rsa_generate_crl(<text>, <text>) RETURNS <text>
```

함수는 인증서 폐기 목록을 반환합니다.

**파라미터**

- `parameter 1`: CA 인증서 경로.
- `parameter 2`: CA 개인 키 경로.
