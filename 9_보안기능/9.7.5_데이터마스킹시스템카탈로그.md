> 상위: # 데이터 마스킹 (Data Redaction) — EPAS 18 Security

## 5. 데이터 마스킹 시스템 카탈로그 (Data redaction system catalogs)

> 원문: [data_redaction_system_catalogs](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/05_data_redaction/data_redaction_system_catalogs/)

시스템 카탈로그가 마스킹 정책 정보를 저장합니다.

### edb_redaction_column
`edb_redaction_column` 시스템 카탈로그는 테이블 컬럼에 부착된 데이터 마스킹 정책 정보를 저장합니다.

| 컬럼 | 타입 | 참조 | 설명 |
| --- | --- | --- | --- |
| `oid` | `oid` |  | 행 식별자(숨김 속성, 명시적으로 선택해야 함) |
| `rdpolicyid` | `oid` | `edb_redaction_policy.oid` | 설명된 컬럼에 적용되는 마스킹 정책 |
| `rdrelid` | `oid` | `pg_class.oid` | 설명된 컬럼이 속한 테이블 |
| `rdattnum` | `int2` | `pg_attribute.attnum` | 설명된 컬럼의 번호 |
| `rdscope` | `int2` |  | 마스킹 scope: `1`=query, `2`=top_tlist, `4`=top_tlist_or_error |
| `rdexception` | `int2` |  | 마스킹 exception: `8`=none, `16`=equal, `32`=leakproof |
| `rdfuncexpr` | `pg_node_tree` |  | 데이터 마스킹 함수 표현식 |

> **참고**: 테이블의 마스킹 정책 `edb_redaction_column.rdpolicyid`가 활성화되어 있고 "마스킹 정책 표현식 `edb_redaction_policy.rdexpr`가 `true`로 평가되면" 설명된 컬럼이 마스킹됩니다.

### edb_redaction_policy
`edb_redaction_policy` 카탈로그는 테이블에 대한 마스킹 정책 정보를 저장합니다.

| 컬럼 | 타입 | 참조 | 설명 |
| --- | --- | --- | --- |
| `oid` | `oid` |  | 행 식별자(숨김 속성, 명시적으로 선택해야 함) |
| `rdname` | `name` |  | 데이터 마스킹 정책 이름 |
| `rdrelid` | `oid` | `pg_class.oid` | 마스킹 정책이 적용되는 테이블 |
| `rdenable` | `boolean` |  | 마스킹 정책 활성화 여부 |
| `rdexpr` | `pg_node_tree` |  | 데이터 마스킹 정책 표현식 |

> **참고**: "마스킹 정책은 활성화되어 있고 표현식이 true로 평가된 적이 있으면 테이블에 적용됩니다."
