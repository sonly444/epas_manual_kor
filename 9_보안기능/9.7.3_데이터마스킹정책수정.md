> 상위: # 데이터 마스킹 (Data Redaction) — EPAS 18 Security

## 3. 데이터 마스킹 정책 수정 (Modifying a data redaction policy)

> 원문: [modifying_a_data_redaction_policy](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/05_data_redaction/modifying_a_data_redaction_policy/)

`ALTER REDACTION POLICY` 명령은 테이블의 데이터 마스킹 정책 정의를 변경합니다.

### 구문
```sql
ALTER REDACTION POLICY <name> ON <table_name> RENAME TO <new_name>

ALTER REDACTION POLICY <name> ON <table_name> FOR ( <expression> )

ALTER REDACTION POLICY <name> ON <table_name> { ENABLE | DISABLE}

ALTER REDACTION POLICY <name> ON <table_name>
  ADD [ COLUMN ] <column_name> USING <funcname_clause>
    [ WITH OPTIONS ( [ <redaction_option> ] [, <redaction_option> ] ) ]

ALTER REDACTION POLICY <name> ON <table_name>
  MODIFY [ COLUMN ] <column_name>
  {
    [ USING <funcname_clause> ]
  |
    [ WITH OPTIONS ( [ <redaction_option> ] [, <redaction_option> ] ) ]
  }

ALTER REDACTION POLICY <name> ON <table_name>
  DROP [ COLUMN ] <column_name>
```
`redaction_option`은 `{ SCOPE <scope_value> | EXCEPTION <exception_value> }`.

### 설명
`ALTER REDACTION POLICY`는 기존 마스킹 정책을 수정합니다. 이 명령을 실행하려면 대상 테이블의 소유권이 필요합니다.
- **FOR ( expression )**: 마스킹 정책 표현식을 추가하거나 교체.
- **ENABLE**: 이전에 비활성화된 정책을 복원.
- **DISABLE**: 테이블의 마스킹 정책을 비활성화.
- **ADD [ COLUMN ]**: 기존 정책에 컬럼 추가(자세한 내용은 `CREATE REDACTION POLICY` 참조).
- **MODIFY [ COLUMN ]**: `USING`으로 마스킹 함수를, `WITH OPTIONS ( ... )`로 마스킹 옵션을 갱신하여 컬럼의 마스킹 설정 조정.
- **DROP [ COLUMN ]**: 정책에서 컬럼 제거.

### 파라미터
`name`(변경할 기존 정책 식별자), `table_name`(정책이 있는 테이블의 스키마 한정 이름), `new_name`(정책의 새 이름, 테이블에 고유해야 함), `expression`(정책 표현식), `column_name`(변경·제거할 컬럼), `funcname_clause`(컬럼의 마스킹 함수 표현식), `scope_value`(마스킹 적용 쿼리 부분), `exception_value`(마스킹 면제 쿼리 부분).

### 예제
정책 표현식 갱신:
```sql
ALTER REDACTION POLICY redact_policy_personal_info ON employees
FOR (session_user != 'hr' AND session_user != 'manager');
```
특정 컬럼의 마스킹 함수 수정:
```sql
ALTER REDACTION POLICY redact_policy_personal_info ON employees
MODIFY COLUMN ssn USING redact_ssn_new(ssn);
```

### 호환성
`ALTER REDACTION POLICY`는 표준 SQL에 대한 EDB 고유 확장입니다.
