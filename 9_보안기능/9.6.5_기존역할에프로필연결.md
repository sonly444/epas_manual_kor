# 기존 역할에 프로필 연결 (Associating a profile with an existing role) — EPAS 18

> 원문: [EPAS v18 — Security features › Managing user profiles › Associating a profile with an existing role](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/04_profile_management/04_associating_a_profile_with_an_existing_role/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·절·파라미터·코드는 원문 그대로 보존했습니다.

프로필을 생성한 후 `ALTER USER... PROFILE` 또는 `ALTER ROLE... PROFILE` 명령을 사용하여 프로필을 역할과 연결할 수 있습니다. 프로필 관리 기능과 관련된 명령 구문은 다음과 같습니다.

```sql
ALTER USER|ROLE <name> [[WITH] option[…]
```

여기서 `option`은 다음 호환 절일 수 있습니다.

```sql
   PROFILE <profile_name>
| ACCOUNT {LOCK|UNLOCK}
| PASSWORD EXPIRE [AT '<timestamp>']
```

또는 `option`은 다음 비호환 절일 수 있습니다.

```sql
| PASSWORD SET AT '<timestamp>'
| STORE PRIOR PASSWORD {'<password>' '<timestamp>} [, ...]
```

EDB Postgres Advanced Server가 지원하는 `ALTER USER` 또는 `ALTER ROLE` 명령의 관리 절에 대한 정보는 PostgreSQL 코어 문서를 참조하십시오.

데이터베이스 슈퍼유저만 프로필 관리를 강제하는 `ALTER USER|ROLE` 절을 사용할 수 있습니다. 이 절들은 다음 동작을 강제합니다.

- 미리 정의된 프로필을 역할과 연결하거나 사용자와 연결된 미리 정의된 프로필을 변경하려면 `PROFILE` 절과 `profile_name`을 포함합니다.

- 사용자 계정을 잠금 또는 잠금 해제 상태로 두려면 `ACCOUNT` 절과 `LOCK` 또는 `UNLOCK` 키워드를 포함합니다.

- 역할과 연결된 비밀번호가 만료되는 날짜/시간을 지정하려면 `AT 'timestamp'` 키워드와 함께 `PASSWORD EXPIRE` 절을 포함합니다. `AT 'timestamp'` 키워드를 생략하면 비밀번호가 즉시 만료됩니다.

- 비밀번호 수정 날짜를 지정된 시간으로 설정하려면 `PASSWORD SET AT 'timestamp'` 키워드를 포함합니다.

- 새 비밀번호와 비밀번호가 설정된 시간을 추가하여 비밀번호 이력을 수정하려면 `STORE PRIOR PASSWORD {'password' 'timestamp} [, ...]` 절을 포함합니다.

각 로그인 역할은 하나의 프로필만 가질 수 있습니다. 로그인 역할과 현재 연결된 프로필을 확인하려면 `DBA_USERS` 뷰의 `profile` 컬럼을 조회합니다.

## 파라미터

`name`

지정된 프로필과 연결할 역할의 이름.

`password`

역할과 연결된 비밀번호.

`profile_name`

역할과 연결할 프로필의 이름.

`timestamp`

절을 강제할 날짜와 시간. `timestamp` 값을 지정할 때는 값을 작은따옴표로 묶습니다.

## 예제

이 명령은 `ALTER USER... PROFILE` 명령을 사용하여 `acctg`라는 프로필을 `john`이라는 사용자와 연결합니다.

```sql
ALTER USER john PROFILE acctg_profile;
```

다음 명령은 `ALTER ROLE... PROFILE` 명령을 사용하여 `acctg`라는 프로필을 `john`이라는 사용자와 연결합니다.

```sql
ALTER ROLE john PROFILE acctg_profile;
```
