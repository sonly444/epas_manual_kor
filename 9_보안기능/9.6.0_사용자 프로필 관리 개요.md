# 사용자 프로필 관리 (Managing user profiles) — EPAS 18 보안 가이드

> 원문: [EPAS v18 — Security guide › Managing user profiles](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/04_profile_management/)
