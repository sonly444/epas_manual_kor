# 프로필과 연결된 새 역할 생성 (Creating a New Role Associated with a Profile) — EPAS 18

> 원문: [EPAS v18 — Security features › Managing user profiles › Creating a new role associated with a profile](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/04_profile_management/06_creating_a_new_role_associated_with_a_profile/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·절·코드는 원문 그대로 보존했습니다.

## 개요

데이터베이스 슈퍼유저는 프로필 관리 절과 함께 `CREATE USER|ROLE` 명령을 사용하여 역할 생성 중에 프로필을 역할에 할당할 수 있습니다.

## 명령 구문

기본 구문은 다음과 같습니다.

```sql
CREATE USER|ROLE <name> [[WITH] <option> […]]
```

프로필 관련 옵션은 다음을 포함합니다.

```sql
   PROFILE <profile_name>
|  ACCOUNT {LOCK|UNLOCK}
|  PASSWORD EXPIRE [AT '<timestamp>']
```

## 주요 기능

슈퍼유저는 여러 메커니즘을 통해 프로필 관리를 강제할 수 있습니다.

- **프로필 연결**: "미리 정의된 프로필을 역할과 연결하려면 `PROFILE` 절과 `profile_name`을 포함합니다."

- **계정 잠금**: `ACCOUNT LOCK` 또는 `ACCOUNT UNLOCK`을 사용하여 계정 접근 상태를 제어합니다.

- **비밀번호 만료**: `PASSWORD EXPIRE` 절을 적용하며, 선택적으로 만료 시점을 지정합니다.

## 중요 제약

각 로그인 역할은 단일 프로필 할당만 지원합니다. 현재 프로필 연결을 확인하려면 `DBA_USERS` 뷰의 `profile` 컬럼을 조회합니다.

## 예제

**CREATE USER 사용:**
```sql
CREATE USER john PROFILE acctg_profile IDENTIFIED BY "1safepwd";
```

**CREATE ROLE 사용:**
```sql
CREATE ROLE john PROFILE acctg_profile LOGIN PASSWORD "1safepwd";
```

두 방법 모두 연관된 보안 프로필을 가진 로그인 가능 역할을 생성합니다.
