# 오류 코드로 감사 로그 필터링 (Using error codes to filter audit logs) — EPAS 18

> 원문: [EPAS v18 — Security guide › Using EDB audit logging › Using error codes to filter audit logs](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/05_edb_audit_logging/05_using_error_codes_to_filter_audit_logs/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터·코드는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server에는 사용자가 지정한 오류 코드를 포함하는 항목을 EDB Postgres Advanced Server 로그 파일에서 제외하는 데 사용할 수 있는 확장이 포함되어 있습니다. 감사 로그 항목을 필터링하려면 먼저 `postgresql.conf` 파일을 수정하여 확장을 활성화해야 합니다. `shared_preload_libraries` 파라미터에 지정된 값에 다음 값을 추가합니다.

```text
$libdir/edb_filter_log
```

그런 다음 `edb_filter_log.errcodes` 파라미터를 사용하여 로그 파일에서 생략하려는 오류 코드를 지정합니다.

```ini
edb_filter_log.errcode = 'error_code'
```

여기서 `error_code`는 로그 파일에서 생략하려는 하나 이상의 오류 코드를 지정합니다. 여러 오류 코드는 쉼표로 구분된 목록으로 제공합니다.

예를 들어 `edb_filter_log`가 활성화되어 있고 `edb_filter_log.errcode`가 `'23505,23502,22012'`로 설정된 경우, 다음 `SQLSTATE` 오류 중 하나를 반환하는 로그 항목은 로그 파일에서 생략됩니다.

- `23505` (고유 제약 조건 위반)
- `23502` (NOT NULL 제약 조건 위반)
- `22012` (0으로 나누기)

EDB Postgres Advanced Server 감사 로그 필터링에서 지원하는 오류 코드의 전체 목록은 [Postgres 코어 문서](https://www.postgresql.org/docs/current/static/errcodes-appendix.html)를 참고하십시오.
