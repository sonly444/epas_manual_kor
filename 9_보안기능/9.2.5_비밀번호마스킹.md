# 감사 로그의 비밀번호 마스킹 (Redacting passwords in audit logs) — EPAS 18

> 원문: [EPAS v18 — Security guide › Using EDB audit logging › Redacting passwords in audit logs](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/05_edb_audit_logging/07_redacting_passwords_from_audit_logs/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터·명령·코드·로그 출력은 원문 그대로 보존했습니다.

`postgresql.conf` 파일의 GUC 파라미터 `edb_filter_log.redact_password_commands`를 사용하여 로그 파일에 저장된 비밀번호를 마스킹(redact)할 수 있습니다.

구문은 다음과 같습니다.

```sql
{CREATE|ALTER} {USER|ROLE|GROUP} identifier
   { [WITH] [ENCRYPTED] PASSWORD 'nonempty_string_literal'
    | IDENTIFIED BY { 'nonempty_string_literal'
    | bareword } }
    [ REPLACE { 'nonempty_string_literal' | bareword } ]
```

비밀번호 마스킹을 활성화하려면 먼저 `postgresql.conf` 파일을 수정하여 파라미터를 활성화해야 합니다. `shared_preload_libraries` 파라미터에 지정된 값에 다음 값을 추가합니다.

```text
$libdir/edb_filter_log
```

그런 다음 `edb_filter_log.redact_password_commands`를 `true`로 설정합니다.

```ini
edb_filter_log.redact_password_commands = true
```

`postgresql.conf` 파일을 수정한 후, 변경 사항을 적용하려면 서버를 재시작해야 합니다.

## 예제 (Examples)

다음 구문이 `log_statement`에 의해 로깅될 때, 서버는 비밀번호를 `x`로 마스킹합니다. 예를 들어 이 명령이 로그 파일에 추가됩니다.

```sql
CREATE USER carol with login PASSWORD '1safepwd';
```

다음과 같이 나타납니다.

```text
2021-05-17 05:01:46.841 IST,"enterprisedb","edb",18415,"[local]",60a230f0.47ef,1,"idle",2021-05-17 05:01:36 IST,3/3,0,AUDIT,00000,"statement: CREATE USER carol with login PASSWORD 'x';",,,,,,,,,"psql","client backend","CREATE ROLE","","create"
```

다음 구문이 `log_statement`에 의해 로깅될 때, 서버는 새 비밀번호와 replace를 식별하고 비밀번호를 `x`로 마스킹합니다. 예를 들어 이 명령이 로그 파일에 추가됩니다.

```sql
ALTER USER carol IDENTIFIED BY 'new_pass' REPLACE '1safepwd';
```

다음과 같이 나타납니다.

```text
2021-05-19 04:41:45.718 IST,"enterprisedb","edb",19354,"[local]",60a23a72.4b9a,1,"idle",2021-05-19 04:41:23 IST,3/3,0,AUDIT,00000,"statement: ALTER USER carol IDENTIFIED BY 'x' REPLACE 'x';",,,,,,,,,"psql","client backend","ALTER ROLE","","alter"
```

비밀번호를 포함하는 구문이 로깅됩니다. 서버는 비밀번호 텍스트를 `x`로 마스킹합니다. 해당 구문이 다른 메시지의 컨텍스트로 로깅되는 경우, 서버는 컨텍스트에서 그 구문을 생략합니다.
