> 상위: # 사용자 프로필 관리 (Managing User Profiles) — EPAS 18 Security

## 1. 핵심 개념 (Profile management key concepts)

> 원문: [profile_overview](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/04_profile_management/profile_overview/)

프로필(profile)은 유사한 인증 요구를 공유하는 역할 그룹을 쉽게 관리할 수 있게 하는 비밀번호 속성의 집합입니다. 각 프로필은 `password` 및 `md5` 인증을 보강하는 비밀번호 관리 규칙을 정의합니다. 프로필의 규칙은 다음을 할 수 있습니다.
- 로그인 실패 횟수 계산
- 과도한 로그인 실패로 인한 계정 잠금
- 비밀번호 만료 표시
- 비밀번호 만료 후 유예 기간 정의
- 비밀번호 복잡도 규칙 정의
- 비밀번호 재사용을 제한하는 규칙 정의

비밀번호 요구가 바뀌면 프로필을 수정하여 해당 프로필과 연결된 각 사용자에게 새 요구를 적용할 수 있습니다.

프로필 생성 후 하나 이상의 사용자와 연결할 수 있습니다. 사용자가 서버에 연결하면 서버는 그 로그인 역할과 연결된 프로필을 강제합니다. 프로필은 클러스터의 모든 데이터베이스가 공유하지만, 각 클러스터는 여러 프로필을 가질 수 있습니다. 여러 데이터베이스에 접근하는 단일 사용자는 클러스터의 각 데이터베이스에 연결할 때 동일한 프로필을 사용합니다.

EDB Postgres Advanced Server는 `default`라는 프로필을 생성하며, 대체 프로필을 지정하지 않으면 역할 생성 시 새 역할에 이 프로필이 연결됩니다. 이전 서버 버전에서 업그레이드하면 기존 역할이 자동으로 `default` 프로필에 배정됩니다. `default` 프로필은 삭제할 수 없습니다.

`default` 프로필이 지정하는 속성:

| 속성 | 값 |
| --- | --- |
| `FAILED_LOGIN_ATTEMPTS` | `UNLIMITED` |
| `PASSWORD_LOCK_TIME` | `UNLIMITED` |
| `PASSWORD_LIFE_TIME` | `UNLIMITED` |
| `PASSWORD_GRACE_TIME` | `UNLIMITED` |
| `PASSWORD_REUSE_TIME` | `UNLIMITED` |
| `PASSWORD_REUSE_MAX` | `UNLIMITED` |
| `PASSWORD_VERIFY_FUNCTION` | `NULL` |
| `PASSWORD_ALLOW_HASHED` | `TRUE` |

데이터베이스 슈퍼유저는 `ALTER PROFILE` 명령으로 `default` 프로필이 지정한 값을 수정할 수 있습니다.
