> 상위: # 데이터 마스킹 (Data Redaction) — EPAS 18 Security

## 4. 데이터 마스킹 정책 삭제 (Removing a data redaction policy)

> 원문: [removing_a_data_redaction_policy](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/05_data_redaction/removing_a_data_redaction_policy/)

`DROP REDACTION POLICY` 명령은 테이블에서 데이터 마스킹 정책을 제거합니다.

### 구문
```sql
DROP REDACTION POLICY [ IF EXISTS ] <name> ON <table_name>
  [ CASCADE | RESTRICT ]
```

### 설명
`DROP REDACTION POLICY`는 지정된 마스킹 정책을 테이블에서 제거합니다. 사용하려면 정책이 적용되는 테이블을 소유해야 합니다.

### 파라미터
- `IF EXISTS`: 정책이 없어도 오류를 발생시키지 않고 notice를 발행.
- `name`: 삭제할 마스킹 정책 이름.
- `table_name`: 정책이 있는 테이블의 (선택적 스키마 한정) 이름.
- `CASCADE` / `RESTRICT`: 마스킹 정책에 대한 의존성이 없으므로 이 키워드는 효과가 없습니다.

### 예제
```sql
DROP REDACTION POLICY redact_policy_personal_info ON employees;
```

### 호환성
`DROP REDACTION POLICY`는 EDB 확장입니다.
