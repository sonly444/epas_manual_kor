# EDB 감사 로깅 사용 (Using EDB audit logging) — EPAS 18 보안 가이드

> 원문: [EPAS v18 — Security guide › Using EDB audit logging](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/05_edb_audit_logging/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 데이터베이스 및 보안 관리자, 감사자(auditor), 운영자가 EDB _감사 로깅(audit logging)_ 을 사용하여 데이터베이스 활동을 추적하고 분석할 수 있게 합니다. EDB 감사 로깅은 감사 로그 파일을 생성하며, 다음과 같은 정보를 기록하도록 구성할 수 있습니다:

- 롤(role)이 EDB Postgres Advanced Server 데이터베이스에 대한 연결을 설정하는 시점
- 롤이 EDB Postgres Advanced Server에 연결된 상태에서 생성·수정·삭제하는 데이터베이스 객체
- 인증 실패 시도가 발생하는 시점

구성 파일 `postgresql.conf` 또는 `postgresql.auto.conf`에 지정된 파라미터가 감사 로그에 포함되는 정보를 제어합니다.
