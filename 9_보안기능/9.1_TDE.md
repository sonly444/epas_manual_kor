# 투명 데이터 암호화 (Transparent Data Encryption, TDE) — EPAS 18 Security

> 원문: [EPAS v18 — Security › Transparent Data Encryption overview](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/tde_feature/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 기능 이름은 원문 그대로 보존했습니다.

**투명 데이터 암호화(Transparent Data Encryption, TDE)**는 기저 파일(underlying files)을 암호화하여 데이터베이스 정보를 보호하는 선택적 암호화 방식입니다.

TDE는 인가된 데이터베이스 사용자에게 투명하게 동작하며, 애플리케이션이나 기존 접근 정책에 대한 수정이 필요하지 않습니다. 이 기능은 EDB Postgres Advanced Server 및 EDB Postgres Extended Server 15 이상과 호환되며, 고가용성(high availability)을 지원합니다.

이 기술은 최소한의 성능 영향과 추가 저장 용량 요구 없이 조직의 데이터 보안을 강화합니다. 애플리케이션 수정 없이 안전한 암호화 알고리즘을 구현할 수 있게 합니다. 시스템은 개별 테이블스페이스와 로그를 서로 다른 암호화 키로 독립적으로 암호화하여, 사용자 데이터를 보호하는 동시에 데이터베이스 관리자의 관리 책임을 단순화합니다.

구현 세부 사항과 암호화된 파일 관리 지침은 전용 [Transparent Data Encryption 문서](https://www.enterprisedb.com/docs/tde/latest/)를 참조하십시오.

> 참고: TDE 활성화 시, 데이터 암호화 보장을 위해 EDB\*Loader의 직접 경로 로딩(direct path loading)이 방지됩니다(릴리스 18.4).
