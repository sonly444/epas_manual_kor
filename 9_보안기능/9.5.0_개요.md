# 독점 소스 코드 보호 (Protecting proprietary source code) — EPAS 18

> 원문: [EPAS v18 — Security guide › Protecting proprietary source code (EDB*Wrap)](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/03_edb_wrap/)
> EPAS v18 공식 문서의 한글 **전문 번역** 인덱스입니다. 유틸리티명·명령·코드는 원문 그대로 보존했습니다.

EDB*Wrap 유틸리티는 함수, 저장 프로시저, 트리거, 패키지와 같은 독점 소스 코드와 프로그램을 인가되지 않은 검사(scrutiny)로부터 보호합니다.

## 하위 페이지

- **EDB*Wrap 핵심 개념 (EDB*Wrap key concepts)** — EDB*Wrap 기능의 이점과 기본 동작 설명
- **소스 코드 난독화 (Obfuscating source code)** — EDB*Wrap 유틸리티를 사용하여 독점 소스 코드와 프로그램을 난독화하는 방법
