# SQL 인젝션 공격 방어 (Protecting against SQL injection attacks) — EPAS 18

> 원문: [EPAS v18 — Security guide › Protecting against SQL injection attacks](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/02_protecting_against_sql_injection_attacks/)
> EPAS v18 공식 문서의 한글 **전문 번역** 인덱스입니다. 기능명·파라미터·코드는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 *SQL 인젝션 공격(SQL injection attack)*에 대한 방어를 제공합니다. SQL 인젝션 공격은, 실행 결과가 공격자에게 해당 데이터베이스의 내용·구조·보안에 대한 단서를 제공하는 SQL 구문을 실행하여 데이터베이스를 침해하려는 시도입니다.

SQL 인젝션 공격을 막는 것은 일반적으로 애플리케이션 개발자의 책임입니다. 데이터베이스 관리자는 대개 잠재적 위협을 거의 또는 전혀 제어할 수 없습니다. 데이터베이스 관리자에게 어려운 점은, 애플리케이션이 제대로 동작하려면 데이터에 접근할 수 있어야 한다는 것입니다.

SQL/Protect는 다음을 수행합니다.

- 데이터베이스 관리자가 데이터베이스를 SQL 인젝션 공격으로부터 보호할 수 있게 합니다.
- 들어오는 쿼리에서 일반적인 SQL 인젝션 프로파일을 검사하여, 일반적인 데이터베이스 보안 정책에 더해 추가 보안 계층을 제공합니다.
- 잠재적으로 위험한 쿼리를 관리자에게 알리고 이러한 쿼리를 차단함으로써 제어권을 데이터베이스 관리자에게 돌려줍니다.
