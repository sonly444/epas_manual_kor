# 프로필 변경 (Altering a Profile) — EPAS 18

> 원문: [EPAS v18 — Security features › Managing user profiles › Altering a profile](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/04_profile_management/02_altering_a_profile/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·파라미터·코드는 원문 그대로 보존했습니다.

`ALTER PROFILE` 명령은 두 가지 구문 옵션으로 사용자 정의 프로필을 수정합니다.

```sql
ALTER PROFILE <profile_name> RENAME TO <new_name>;

ALTER PROFILE <profile_name>
      LIMIT {<parameter value>}[...];
```

## 주요 파라미터

- **profile_name**: 수정할 프로필
- **new_name**: 이름 변경 작업의 대체 이름
- **parameter**: 제약되는 속성
- **value**: 해당 속성에 적용되는 제한

허용되는 파라미터/값 조합의 포괄적인 목록은 "새 프로필 생성" 문서 섹션을 참조하십시오.

## 실용 예제

**프로필 제한 수정:**

```sql
ALTER PROFILE acctg_profile
       LIMIT FAILED_LOGIN_ATTEMPTS 3 PASSWORD_LOCK_TIME 1;
```

이 구성은 "로그인 역할이 서버에 연결을 시도할 때 실패한 연결 시도를 계산"하고 세 번의 인증 실패 후 하루 동안 계정을 잠급니다.

**프로필 이름 변경:**

```sql
ALTER PROFILE acctg_profile RENAME TO payables_profile;
```

명령은 하나 이상의 공백으로 구분된 파라미터 쌍을 가진 `LIMIT` 절, 또는 프로필 이름 변경을 위한 `RENAME TO` 절을 받습니다.
