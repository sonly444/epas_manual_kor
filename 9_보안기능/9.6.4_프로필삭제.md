# 프로필 삭제 (Dropping a profile) — EPAS 18

> 원문: [EPAS v18 — Security features › Managing user profiles › Dropping a profile](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/04_profile_management/03_dropping_a_profile/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·파라미터·코드는 원문 그대로 보존했습니다.

프로필을 삭제하려면 `DROP PROFILE` 명령을 사용합니다. 구문은 다음과 같습니다.

```sql
DROP PROFILE [IF EXISTS] <profile_name> [CASCADE|RESTRICT];
```

지정된 프로필이 존재하지 않을 때 서버가 오류를 발생시키지 않도록 지시하려면 `IF EXISTS` 절을 포함합니다. 프로필이 존재하지 않으면 서버는 알림(notice)을 발행합니다.

현재 프로필과 연결된 사용자를 `default` 프로필로 재할당한 다음 프로필을 삭제하려면 선택적 `CASCADE` 절을 포함합니다. 역할과 연결된 프로필을 삭제하지 않도록 서버에 지시하려면 선택적 `RESTRICT` 절을 포함합니다. 이것이 기본 동작입니다.

## 파라미터

`profile_name`

삭제되는 프로필의 이름.

## 예제

이 예는 `acctg_profile`이라는 프로필을 삭제합니다.

```sql
DROP PROFILE acctg_profile CASCADE;
```

명령은 먼저 `acctg_profile` 프로필과 연결된 역할을 `default` 프로필과 재연결한 다음 `acctg_profile` 프로필을 삭제합니다.

다음 예는 `acctg_profile`이라는 프로필을 삭제합니다.

```sql
DROP PROFILE acctg_profile RESTRICT;
```

명령의 `RESTRICT` 절은 프로필과 연결된 역할이 있으면 `acctg_profile`을 삭제하지 않도록 서버에 지시합니다.
