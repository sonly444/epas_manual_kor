# 데이터 마스킹 (Data Redaction) — EPAS 18 Security

> 원문: [EPAS v18 — Security › Redacting data](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/05_data_redaction/)

EDB Postgres Advanced Server *데이터 마스킹(Data redaction)* 기능은 특정 사용자에게 표시되는 시점에 데이터를 동적으로 변경하여 민감 데이터 노출을 제한합니다.
