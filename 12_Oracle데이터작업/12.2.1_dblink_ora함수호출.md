# dblink_ora 함수 호출 (Calling dblink_ora functions) — dblink_ora

> 원문: [EPAS v18 — Working with Oracle data › dblink_ora › Calling dblink_ora functions](https://www.enterprisedb.com/docs/epas/latest/working_with_oracle_data/dblink_ora/calling_dblink_ora_functions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·명령·파라미터 이름은 원문 그대로 보존했습니다.

`dblink_ora`는 Oracle 데이터베이스에 연결하여 데이터를 조회하고 복사할 수 있는 함수를 제공합니다.

## dblink_ora_connect

`dblink_ora_connect` 함수는 지정한 연결 정보를 사용하여 Oracle 데이터베이스에 대한 영구 연결을 설정합니다.

```sql
dblink_ora_connect('acctg', 'localhost', 'xe', 'hr', 'pwd', 1521)
```

인자는 순서대로 다음과 같습니다.
- 연결에 부여하는 이름(`acctg`)
- 호스트 이름(`localhost`)
- Oracle 데이터베이스 이름/서비스 이름(`xe`)
- 사용자 이름(`hr`)
- 비밀번호(`pwd`)
- 포트 번호(`1521`)

## dblink_ora_copy

`dblink_ora_copy` 함수는 Oracle 데이터베이스의 데이터를 EDB Postgres Advanced Server 테이블로 복사합니다.

```sql
dblink_ora_copy('edb_conn', 'select empid, deptno FROM ora_acctg', 'public', 'as_acctg', true, 3)
```

인자는 순서대로 다음과 같습니다.
- 연결 이름(`edb_conn`)
- Oracle 데이터베이스에서 실행할 `SELECT` 명령
- 대상 스키마 이름(`public`)
- 대상 테이블 이름(`as_acctg`)
- 복사 전에 대상 테이블을 TRUNCATE할지 여부(`true`)
- 복사할 행 수(또는 커밋 간격, `3`)

## dblink_ora_record

`dblink_ora_record` 함수는 Oracle 데이터베이스에 질의를 실행하고 결과 레코드를 반환합니다.

```sql
dblink_ora_record('acctg', 'SELECT first_name from employees') AS t1(id VARCHAR)
```

인자는 순서대로 다음과 같습니다.
- 연결 이름(`acctg`)
- Oracle 데이터베이스에서 실행할 `SELECT` 명령

반환되는 레코드의 구조는 `AS` 절(`t1(id VARCHAR)`)로 정의합니다.
