# 임베디드 SQL 명령 (Embedded SQL Commands) — EPAS 18 Working with Oracle Data

> 원문: [EPAS v18 — Working with Oracle data › Including embedded SQL commands](https://www.enterprisedb.com/docs/epas/latest/working_with_oracle_data/embedded_sql_commands/)
> EPAS v18 공식 문서의 한글 번역입니다. 이름은 원문 그대로 보존했습니다.

C 애플리케이션에 SQL 명령을 임베드하는 ECPGPlus 유틸리티 개요입니다.

- ECPGPlus는 Pro\*C 호환 임베디드 SQL을 지원하며, EPAS 연결 시 Oracle Dynamic SQL Method 4(ODS-M4)와 `CALL` 문을 사용할 수 있습니다.
- 상세는 "애플리케이션 프로그래밍" 섹션의 ECPGPlus 항목(`11_4_ECPGPlus.md`)을 참조하십시오.
