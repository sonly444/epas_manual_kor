# Oracle 서버 질의 (dblink_ora) — EPAS 18 Working with Oracle Data

> 원문: [EPAS v18 — Working with Oracle data › Querying an Oracle server](https://www.enterprisedb.com/docs/epas/latest/working_with_oracle_data/06_dblink_ora/)
> EPAS v18 공식 문서의 한글 번역입니다. 함수 이름은 원문 그대로 보존했습니다.

원격 Oracle 서버에 임의의 쿼리를 발행할 수 있게 하는 유틸리티입니다. OCI 기반 연결을 제공하여 EPAS에서 Oracle 데이터에 대해 SELECT/INSERT/UPDATE/DELETE를 수행합니다.

## 함수
- `dblink_ora_connect`: Oracle 데이터베이스 연결 수립.
- `dblink_ora_record`: 레코드(결과 집합) 조회.
- `dblink_ora_exec`: 명령 실행(DML 등).
- `dblink_ora_call`: 함수·프로시저 호출.
- (그 외 연결 해제·상태 관련 함수 포함.)

## 요구 사항
연결을 위해 OCI(Oracle Call Interface) 지원이 필요합니다. Oracle 클라이언트 라이브러리가 설치되어 있어야 합니다.
