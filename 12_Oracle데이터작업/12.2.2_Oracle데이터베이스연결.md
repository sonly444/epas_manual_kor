# Oracle 데이터베이스에 연결 (Connecting to an Oracle database) — dblink_ora

> 원문: [EPAS v18 — Working with Oracle data › dblink_ora › Connecting to an Oracle database](https://www.enterprisedb.com/docs/epas/latest/working_with_oracle_data/dblink_ora/connecting_to_an_oracle_database/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·명령·파라미터 이름은 원문 그대로 보존했습니다.

`dblink_ora`가 Oracle 데이터베이스에 연결하려면 먼저 Oracle Call Interface(OCI) 드라이버를 설치하고 EDB Postgres Advanced Server가 그 드라이버를 찾을 수 있도록 구성해야 합니다.

## Oracle OCI 드라이버 설치

Oracle에서 제공하는 OCI(Oracle Call Interface) 드라이버를 다운로드하여 설치합니다. 드라이버는 Oracle Instant Client 패키지의 일부로 제공됩니다.

Linux 시스템에서는 OCI 라이브러리(`libclntsh.so`)에 대한 심볼릭 링크를 만들어야 할 수 있습니다. 예를 들어 설치된 라이브러리가 `libclntsh.so.12.1`이라면 다음과 같이 버전 없는 이름으로 심볼릭 링크를 생성합니다.

```
ln -s libclntsh.so.<version> libclntsh.so
```

예:

```
ln -s libclntsh.so.12.1 libclntsh.so
```

## OCI 라이브러리 위치 지정

EDB Postgres Advanced Server가 OCI 라이브러리를 찾을 수 있도록 라이브러리 위치를 지정하는 두 가지 방법이 있습니다.

### 방법 1: 환경 변수 사용

- **Linux**: `LD_LIBRARY_PATH` 환경 변수에 Oracle 클라이언트 라이브러리 디렉터리를 추가합니다. OS 사용자 profile(.bash_profile 등)에 등록을 권장합니다.
- **Windows**: `PATH` 환경 변수에 Oracle 클라이언트 라이브러리 디렉터리를 추가합니다.

### 방법 2: `oracle_home` 구성 파라미터 사용

`postgresql.conf` 파일에 `oracle_home` 구성 파라미터를 설정하여 Oracle 클라이언트 라이브러리 디렉터리를 지정할 수 있습니다.

```
oracle_home = 'lib_directory'
```

`oracle_home` 파라미터를 설정하면 `LD_LIBRARY_PATH`(Linux) 또는 `PATH`(Windows) 환경 변수에 지정된 값보다 우선합니다.

## 데이터베이스 서버 재시작

라이브러리 위치를 구성한 후 변경 사항을 적용하려면 데이터베이스 서버를 재시작해야 합니다.

```
systemctl restart edb-as-18
```

- **Linux**: `systemctl` 또는 `pg_ctl` 명령을 사용하여 서비스를 재시작합니다.
- **Windows**: Windows 서비스 콘솔에서 서비스를 재시작합니다.
