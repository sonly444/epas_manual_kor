# 대량 데이터 로딩 (Loading Bulk Data) — EPAS 18 Working with Oracle Data

> 원문: [EPAS v18 — Working with Oracle data › Loading bulk data](https://www.enterprisedb.com/docs/epas/latest/working_with_oracle_data/loading_bulk_data/)
> EPAS v18 공식 문서의 한글 번역입니다. 이름은 원문 그대로 보존했습니다.

EDB\*Loader를 이용한 대량 데이터 로딩 개요입니다.

- EDB\*Loader는 Oracle SQL\*Loader 호환 고성능 대량 데이터 로더로, 명령줄 유틸리티 `edbldr`로 실행합니다.
- 컨트롤 파일로 로드 동작을 정의하며, 일반 경로·직접 경로 로딩을 지원합니다.
- 상세는 "데이터베이스 관리" 섹션의 EDB\*Loader 항목(`08_3_EDB_Loader.md`)을 참조하십시오.
