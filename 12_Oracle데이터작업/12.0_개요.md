# Oracle 데이터 작업 (Working with Oracle Data) — EDB Postgres Advanced Server 18

> 원문: [EPAS v18 Documentation — Working with Oracle data](https://www.enterprisedb.com/docs/epas/latest/working_with_oracle_data/)
> EPAS v18 공식 문서의 한글 번역입니다. 기능·함수·데이터타입·패키지 이름은 원문 그대로 보존했습니다.
> ※ 본 섹션은 GS 인증 Oracle 호환 항목의 근거 문서로 활용됩니다.

EPAS의 Oracle 호환 기능과 Oracle 연동 방법을 다룹니다. 하위 구성: 향상된 호환 기능 / Oracle 서버 질의(dblink_ora) / Open Client Library(EDB OCL Connector) / 임베디드 SQL(ECPGPlus) / 대량 데이터 로딩(EDB\*Loader) / 독점 코드 보호(EDB\*Wrap).

---

## 1. 향상된 호환 기능 (Enhanced compatibility features)

Oracle 애플리케이션 마이그레이션을 지원하는 EPAS의 호환 기능 개요입니다.

- **데이터 딕셔너리·카탈로그 뷰**: Oracle 데이터 딕셔너리 뷰와 호환되는 방식으로 데이터베이스 객체 정보를 제공하는 뷰 집합(Oracle 호환 카탈로그 뷰).
- **내장 패키지(23개)**: `DBMS_ALERT`, `DBMS_AQ`, `DBMS_AQADM`, `DBMS_CRYPTO`(암호화/복호화), `DBMS_JOB`, `DBMS_SCHEDULER`(작업 관리), `DBMS_LOB`, `DBMS_OUTPUT`, `DBMS_PIPE`, `DBMS_PROFILER`, `DBMS_RANDOM`, `DBMS_REDACT`(데이터 마스킹), `DBMS_RLS`(VPD), `UTL_ENCODE`, `UTL_FILE`, `UTL_HTTP`, `UTL_MAIL`, `UTL_RAW`, `UTL_SMTP`, `UTL_URL` 등.
- **저장 프로시저 언어(SPL)**: 사용자 정의 프로시저·함수·트리거·패키지.
- **옵티마이저 힌트**: 성능 튜닝용 쿼리 계획 지시.
- **프로필 관리**: 비밀번호 정책·인증 규칙.
- **dblink_ora**: Oracle 데이터베이스 연결(SELECT/INSERT/UPDATE/DELETE).
- **테이블 파티셔닝**: 논리적 분할을 통한 성능 최적화.
- **개발 도구**: ECPGPlus, EDB\*Plus, EDB\*Loader, EDB\*Wrap.

> Oracle 호환 데이터 타입(예: `NUMBER`, `VARCHAR2`, `DATE`, `CLOB`, `BLOB`), `ROWNUM`, `SYNONYM`, 계층 질의 `CONNECT BY`, `DUAL`, 시퀀스, `MERGE` 등도 지원됩니다(상세는 참조 섹션).

---

## 2. Oracle 서버 질의 (dblink_ora)

원격 Oracle 서버에 임의의 쿼리를 발행할 수 있게 하는 유틸리티입니다. OCI 기반 연결을 제공하여 EPAS에서 Oracle 데이터에 대해 SELECT/INSERT/UPDATE/DELETE를 수행합니다.

- **함수**: `dblink_ora_connect`(연결), `dblink_ora_record`(레코드 조회), `dblink_ora_exec`(실행), `dblink_ora_call`(호출) 등.
- **요구 사항**: 연결을 위해 OCI(Oracle Call Interface) 지원 필요.

---

## 3. Open Client Library (EDB OCL Connector)

C로 작성된 EDB 구현으로, Oracle Call Interface 기술과의 애플리케이션 상호운용을 가능하게 합니다.

- Oracle에 의존하던 애플리케이션을 코드 변경 없이(또는 최소 변경으로) EPAS에서 동작하게 함.
- Oracle Call Interface 애플리케이션을 EPAS용으로 컴파일.
- **제약**: Oracle Real Application Clusters(RAC) 및 Oracle Exadata와는 지원되지 않음(해당 Oracle 제품은 본 EDB 제품과 평가·인증되지 않음).
- 상세는 [EDB OCL Connector 문서](https://www.enterprisedb.com/docs/ocl_connector/15/) 참조.

---

## 4. 임베디드 SQL 명령 (ECPGPlus)

C 애플리케이션에 SQL 명령을 임베드하는 ECPGPlus 유틸리티 개요입니다. (상세는 "애플리케이션 프로그래밍" 섹션의 ECPGPlus 항목 참조 — Pro\*C 호환, ODS-M4, `CALL` 문 등.)

## 5. 대량 데이터 로딩 (EDB\*Loader)

EDB\*Loader를 이용한 대량 데이터 로딩 개요입니다. (상세는 "데이터베이스 관리" 섹션의 EDB\*Loader 항목 참조 — `edbldr`, 컨트롤 파일, Oracle SQL\*Loader 호환.)

## 6. 독점 코드 보호 (EDB\*Wrap)

독점 소스 코드·프로그램을 보호하는 EDB\*Wrap 유틸리티 개요입니다. (상세는 "보안 기능" 섹션의 EDB\*Wrap 항목 참조 — `edbwrap`, SPL 소스 난독화.)
