# Open Client Library (OCL) — Oracle 데이터 작업

> 원문: [EPAS v18 — Working with Oracle data › Open Client Library](https://www.enterprisedb.com/docs/epas/latest/working_with_oracle_data/using_the_oracle_call_interface_library/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 라이브러리·제품 이름은 원문 그대로 보존했습니다.

EDB Open Client Library(OCL)는 Oracle Call Interface(OCI)와의 상호운용성을 제공하는 C 언어 구현입니다. OCL은 Oracle OCI 애플리케이션이 EDB Postgres Advanced Server와 함께 동작할 수 있도록 OCI와 호환되는 인터페이스를 제공합니다.

이를 통해 OCI를 사용하도록 작성된 애플리케이션을 최소한의 수정으로 EDB Postgres Advanced Server에 연결하여 사용할 수 있습니다.

## 지원되지 않는 환경

EDB Open Client Library는 **Oracle RAC(Real Application Clusters)** 및 **Oracle Exadata**와 함께 사용하는 것은 지원되지 않습니다. 이러한 환경은 평가·인증되지 않았습니다.
