# EDB Query Advisor — EPAS 18 성능 관리

> 원문: [EPAS v18 — Managing performance › EDB Query Advisor](https://www.enterprisedb.com/docs/epas/latest/managing_performance/query_advisor/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 확장·함수 이름은 원문 그대로 보존했습니다.

## 개요

EDB Query Advisor는 `WHERE` 문, `JOIN` 절, 워크로드 쿼리에서 발견되는 술어(predicate)에 대한 통계를 유지하여 인덱스 추천을 제공하는 Postgres 확장입니다. 가상 인덱스(hypothetical index)로 워크로드 쿼리를 다시 계획(replan)하여 실제 워크로드 쿼리에 대한 비용-이익을 분석합니다. 가상 인덱스는 워크로드 쿼리에서 수집한 술어를 기반으로 생성됩니다.
