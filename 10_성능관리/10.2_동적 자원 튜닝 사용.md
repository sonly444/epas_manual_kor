# 동적 자원 튜닝 사용 (Using dynamic resource tuning) — EPAS 18 성능 관리

> 원문: [EPAS v18 — Managing performance › Using dynamic resource tuning](https://www.enterprisedb.com/docs/epas/latest/managing_performance/using_dynatune/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터·값 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 설치된 호스트 머신에서 사용 가능한 시스템 자원을 최적으로 활용하도록 데이터베이스 서버를 동적으로 튜닝하는 것을 지원합니다. 이 기능을 제어하는 두 파라미터는 `postgresql.conf` 파일에 위치합니다.

- `edb_dynatune`
- `edb_dynatune_profile`

## 동적 튜닝 구현 (Implementing Dynamic Tuning)

`edb_dynatune` 파라미터는 전체 가용 자원과 머신의 용도에 따라 "데이터베이스 서버가 호스트 시스템의 자원을 얼마나 사용할지 결정"합니다.

동적 튜닝을 설정할 때의 핵심 사항:

- 최초 설치 이후에도 `postgresql.conf`를 편집하고 postmaster를 재시작하여 `edb_dynatune`를 변경할 수 있습니다.
- 이 파라미터는 0에서 100 사이의 정수 값으로 설정합니다.
- 값이 0이면 동적 튜닝을 비활성화하며, 자원 사용은 다른 구성 파라미터의 제어에 맡깁니다.
- **1–33**: 최소한의 자원을 할당합니다(여러 애플리케이션이 함께 도는 개발 머신).
- **34–66**: 중간 정도의 자원을 할당합니다(고정된 애플리케이션을 실행하는 전용 애플리케이션 서버).
- **67–100**: 대부분의 자원을 할당합니다(EDB Postgres Advanced Server 전용 머신).

`edb_dynatune` 기능은 다음 항목에 대한 자동 튜닝에 집중합니다.

- `shared_buffers`
- `work_mem`
- `maintenance_work_mem`
- `effective_cache_size`
- `random_page_cost`
- `max_connections`

참고: "수동으로 설정된 모든 파라미터는 자동 튜닝 과정에서 제외됩니다."

## 파라미터 값 변경 (Changing Parameter Values)

`edb_dynatune` 값을 선택한 후에는 `postgresql.conf`의 다른 구성 파라미터를 조정하여 성능을 추가로 세밀하게 튜닝할 수 있습니다. 조정된 설정은 `edb_dynatune`가 선택한 해당 값보다 우선합니다.

파라미터 값을 변경하려면:

1. 구성 파라미터의 주석을 해제합니다.
2. 원하는 값을 지정합니다.
3. 데이터베이스 서버를 재시작합니다.

## 튜닝 동작 제어 (Controlling Tuning Behavior)

예상되는 워크로드 프로파일에 따라 튜닝 방식을 제어하려면 `edb_dynatune_profile` 파라미터를 사용합니다. 이 파라미터는 데이터베이스 서버를 시작할 때 적용됩니다.

| 값 | 용도 |
| --- | --- |
| `oltp` | 데이터베이스 서버가 대량의 온라인 트랜잭션 처리(OLTP) 워크로드를 처리할 때 권장됩니다. |
| `reporting` | 대량의 데이터 리포팅에 사용되는 데이터베이스 서버에 권장됩니다. |
| `mixed` | 트랜잭션 처리와 데이터 리포팅이 혼합된 서버에 권장됩니다. |
