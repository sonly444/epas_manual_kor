# 계획 사전 요건 (Planning Prerequisites) — EPAS 18 Planning

> 원문: [EPAS v18 — Planning › Planning prerequisites](https://www.enterprisedb.com/docs/epas/latest/planning/planning_prerequisites/)
> EPAS v18 공식 문서의 한글 번역입니다. 값·이름은 원문 그대로 보존했습니다.

하위 구성: 제한 사항(Limitations) / 요구 사항(Requirements).

## 1. 제한 사항 (Limitations)

- **NFS 파일시스템 저장**: 운영 데이터베이스의 `data` 디렉터리를 NFS 파일시스템에 저장하는 것은 권장하지 않습니다. 이 권장을 따르지 않을 경우 구성 지침은 PostgreSQL 문서를 참조하십시오.
- **LLVM JIT 패키지 지원**: LLVM JIT 패키지는 **RHEL x86**에서만 지원됩니다.

## 2. 요구 사항 (Requirements)

### 하드웨어 최소 요구 사항 (설치·구동 최소치)
- **프로세서**: 1 GHz processor
- **RAM**: 2 GB of RAM
- **저장소**: 512 MB of HDD

데이터 및 지원 구성 요소를 위한 추가 디스크 공간이 필요합니다. 위 값은 최소치이며, 운영 배포는 워크로드·데이터 양·성능 요구에 따라 훨씬 더 많은 자원이 필요합니다.

### 소프트웨어 요구 사항 — 사용자 권한
- **Linux**: superuser, administrator 또는 sudo 접근 권한 필요.
- **Windows**: administrator 권한 필요. UAC(User Account Control)가 켜져 있으면 인스톨러를 우클릭해 "Run as administrator"로 실행.

### Windows 관련
- 인스톨러 실행 전 모든 Windows OS 업데이트 적용.
- 설치 오류 발생 시 종료 → Windows 업데이트 → 인스톨러 재시작.

### 플랫폼 지원
EPAS 18의 지원 OS·기능은 릴리스 노트를 참조하십시오(02 지원플랫폼 참고).
