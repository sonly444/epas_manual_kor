# 구성 모드 선택 (Choosing the Configuration Mode) — EPAS 18 Planning

> 원문: [EPAS v18 — Planning › Choosing the configuration mode](https://www.enterprisedb.com/docs/epas/latest/planning/configuration_mode/)
> EPAS v18 공식 문서의 한글 번역입니다. 옵션·명령 이름은 원문 그대로 보존했습니다.

EPAS는 클러스터 초기화 시 두 가지 구성 모드 중 하나를 선택합니다. 모드는 `initdb` 명령으로 지정합니다.

## Postgres 모드 (`no-redwood-compat`)

표준 PostgreSQL 클러스터를 생성하며 고급 데이터베이스 관리 기능을 제공합니다. 패키지(package)·컬렉션(collection) 등 일부 Oracle 호환 기능은 사용할 수 있으나, Oracle 마이그레이션에 최적화된 모드는 아닙니다. 표준 PostgreSQL 기능과 고급 운영 기능을 우선합니다.

## Oracle 호환 모드 (`redwood-like`)

포괄적인 Oracle 호환성을 활성화합니다. Oracle 호환 사용자 정의 데이터 타입, 키워드(keyword), 함수, 카탈로그 뷰를 포함하여 Oracle → Postgres 마이그레이션을 지원합니다.

## 선택 기준

Oracle에서 Postgres로 마이그레이션하는 경우 `redwood-like` 모드가 권장됩니다. 애플리케이션 전환에 필요한 풍부한 호환 기능을 제공하기 때문입니다.

| 구분 | Postgres 모드(`no-redwood-compat`) | Oracle 호환 모드(`redwood-like`) |
|------|-----------------------------------|----------------------------------|
| 우선 사항 | 표준 PostgreSQL·고급 운영 기능 | Oracle 호환성 |
| Oracle 호환 데이터타입·키워드·함수·뷰 | 제한적 | 전체 |
| 권장 상황 | 순수 Postgres 신규 구축 | Oracle 마이그레이션 |
