# TABLE 함수 사용 (Using the TABLE function) — EPAS 18 SPL 컬렉션 작업

> 원문: [EPAS v18 — SPL › Working with collections › Using the TABLE function](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/12_working_with_collections/01_table/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·구문·코드는 원문 그대로 보존했습니다.

`TABLE()` 함수를 사용하여 배열의 멤버를 행 집합(set of rows)으로 변환합니다. 시그니처는 다음과 같습니다.

```sql
TABLE(<collection_value>)
```

여기서 `collection_value`는 컬렉션 타입의 값으로 평가되는 표현식입니다.

`TABLE()` 함수는 컬렉션의 중첩된 내용을 테이블 형식으로 확장합니다. 일반 테이블 표현식을 사용하는 곳이라면 어디에서나 `TABLE()` 함수를 사용할 수 있습니다.

`TABLE()` 함수는 `SETOF ANYELEMENT`를 반환하며, 이는 임의 타입의 값 집합입니다. 예를 들어, 이 함수에 전달된 인자가 `dates` 배열이면 `TABLE()`은 `SETOF dates`를 반환합니다. 이 함수에 전달된 인자가 `paths` 배열이면 `TABLE()`은 `SETOF paths`를 반환합니다.

`TABLE()` 함수를 사용하여 컬렉션의 내용을 테이블 형식으로 확장할 수 있습니다.

```sql
postgres=# SELECT * FROM TABLE(monthly_balance(445.00, 980.20, 552.00));
```

출력

```text
 monthly_balance
----------------
  445.00
  980.20
  552.00
(3 rows)
```
