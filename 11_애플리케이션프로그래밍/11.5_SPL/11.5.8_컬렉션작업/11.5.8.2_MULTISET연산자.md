# MULTISET 연산자 사용 (Using the MULTISET operators) — EPAS 18 SPL 컬렉션 작업

> 원문: [EPAS v18 — SPL › Working with collections › Using the MULTISET operators](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/12_working_with_collections/02_using_the_multiset_union_operator/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 연산자·키워드·구문은 원문 그대로 보존했습니다.

`MULTISET` 연산자는 두 컬렉션을 결합하여 세 번째 컬렉션을 만듭니다.

## 구문

```sql
<coll_1> MULTISET [ UNION | INTERSECT | EXCEPT ] [ ALL | DISTINCT | UNIQUE ] <coll_2>
```

여기서 `coll_1`과 `coll_2`는 결합할 컬렉션의 이름을 지정합니다.

`ALL` 키워드를 포함하면 결과에서 중복 요소(`coll_1`과 `coll_2` 모두에 존재하는 요소)를 원본 컬렉션에 나타난 횟수만큼 각각 표현하도록 지정합니다. 이것이 기본 동작입니다.

`DISTINCT` 또는 `UNIQUE` 키워드를 포함하면 중복 요소를 결과에 한 번만 포함합니다. `DISTINCT`와 `UNIQUE` 키워드 사이에는 차이가 없습니다.

세 가지 형태의 MULTISET 연산자가 있습니다.

- MULTISET UNION
- MULTISET INTERSECT
- MULTISET EXCEPT

## MULTISET UNION

`MULTISET UNION`은 두 중첩 테이블을 인자로 받아 두 입력 중첩 테이블 모두의 값을 담은 중첩 테이블을 반환합니다. 두 입력 중첩 테이블은 동일한 타입이어야 하며, 반환되는 중첩 테이블도 마찬가지로 동일한 타입입니다.

이 예제는 `MULTISET UNION` 연산자를 사용하여 `collection_1`과 `collection_2`를 세 번째 컬렉션 `collection_3`으로 결합합니다.

```sql
DECLARE
    TYPE int_arr_typ IS TABLE OF NUMBER(2);
    collection_1    int_arr_typ;
    collection_2    int_arr_typ;
    collection_3    int_arr_typ;
    v_results       VARCHAR2(50);
BEGIN
    collection_1 := int_arr_typ(10,20,30);
    collection_2 := int_arr_typ(30,40);
    collection_3 := collection_1 MULTISET UNION ALL collection_2;
    DBMS_OUTPUT.PUT_LINE('COUNT: ' || collection_3.COUNT);
    FOR i IN collection_3.FIRST .. collection_3.LAST LOOP
        IF collection_3(i) IS NULL THEN
            v_results := v_results || 'NULL ';
        ELSE
            v_results := v_results || collection_3(i) || ' ';
        END IF;
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('Results: ' || v_results);
END;

COUNT: 5
Results: 10 20 30 30 40
```

결과 컬렉션은 `collection_1`과 `collection_2`의 각 요소에 대해 하나의 항목을 포함합니다. `DISTINCT` 키워드를 사용하면 결과는 다음과 같습니다.

```sql
DECLARE
    TYPE int_arr_typ IS TABLE OF NUMBER(2);
    collection_1    int_arr_typ;
    collection_2    int_arr_typ;
    collection_3    int_arr_typ;
    v_results       VARCHAR2(50);
BEGIN
    collection_1 := int_arr_typ(10,20,30);
    collection_2 := int_arr_typ(30,40);
    collection_3 := collection_1 MULTISET UNION DISTINCT collection_2;
    DBMS_OUTPUT.PUT_LINE('COUNT: ' || collection_3.COUNT);
    FOR i IN collection_3.FIRST .. collection_3.LAST LOOP
        IF collection_3(i) IS NULL THEN
            v_results := v_results || 'NULL ';
        ELSE
            v_results := v_results || collection_3(i) || ' ';
        END IF;
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('Results: ' || v_results);
END;

COUNT: 4
Results: 10 20 30 40
```

결과 컬렉션은 고유한 값을 가진 멤버만 포함합니다.

이 예제에서 `MULTISET UNION DISTINCT` 연산자는 동일한 컬렉션에 저장된 중복 항목을 제거합니다.

```sql
DECLARE
    TYPE int_arr_typ IS TABLE OF NUMBER(2);
    collection_1    int_arr_typ;
    collection_2    int_arr_typ;
    collection_3    int_arr_typ;
    v_results       VARCHAR2(50);
BEGIN
    collection_1 := int_arr_typ(10,20,30,30);
    collection_2 := int_arr_typ(40,50);
    collection_3 := collection_1 MULTISET UNION DISTINCT collection_2;
    DBMS_OUTPUT.PUT_LINE('COUNT: ' || collection_3.COUNT);
    FOR i IN collection_3.FIRST .. collection_3.LAST LOOP
        IF collection_3(i) IS NULL THEN
            v_results := v_results || 'NULL ';
        ELSE
            v_results := v_results || collection_3(i) || ' ';
        END IF;
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('Results: ' || v_results);
END;

COUNT: 5
Results: 10 20 30 40 50
```

### MULTISET INTERSECT

`MULTISET INTERSECT`는 두 중첩 테이블을 인자로 받아 두 입력 중첩 테이블에 공통인 값을 담은 중첩 테이블을 반환합니다. 두 입력 중첩 테이블은 동일한 타입이어야 하며, 반환되는 중첩 테이블도 마찬가지로 동일한 타입입니다.

이 예제는 `MULTISET INTERSECT` 연산자를 사용하여 `color_name`과 `fruit_name`을 세 번째 컬렉션 `common_name`으로 결합합니다.

```sql
DECLARE
  TYPE name_typ IS TABLE OF VARCHAR(50);
  color_name  name_typ;
  fruit_name  name_typ;
  common_name name_typ;
BEGIN
  color_name := name_typ('Red', 'Green', 'Blue', 'Orange', 'Peach', 'Yellow', 'Peach');
  fruit_name := name_typ('Mango', 'Orange', 'Grapes', 'Banana', 'Peach', 'Peach');
  common_name := color_name MULTISET INTERSECT UNIQUE fruit_name;
  FOR i IN common_name.FIRST .. common_name.LAST LOOP
    DBMS_OUTPUT.PUT_LINE(common_name(i));
  END LOOP;
END;
```

출력

```text
Orange
Peach
```

이 예제는 `MULTISET INTERSECT DISTINCT`의 사용을 보여 줍니다.

### MULTISET EXCEPT

`MULTISET EXCEPT`는 두 중첩 테이블을 인자로 받아 첫 번째 중첩 테이블에는 있지만 두 번째 중첩 테이블에는 없는 요소를 담은 중첩 테이블을 반환합니다. 두 입력 중첩 테이블은 동일한 타입이어야 하며, 반환되는 중첩 테이블도 마찬가지로 동일한 타입입니다.

이 예제는 `MULTISET EXCEPT UNIQUE`의 사용을 보여 줍니다.

```sql
DECLARE
  TYPE name_typ IS TABLE OF VARCHAR(50);
  color_name  name_typ;
  fruit_name  name_typ;
  common_name name_typ;
BEGIN
  color_name := name_typ('Red', 'Green', 'Blue', 'Blue', 'Orange', 'Peach', 'Yellow');
  fruit_name := name_typ('Mango', 'Orange', 'Grapes', 'Banana', 'Peach');
  common_name := color_name MULTISET EXCEPT UNIQUE fruit_name;

  FOR i IN common_name.FIRST .. common_name.LAST LOOP
    DBMS_OUTPUT.PUT_LINE(common_name(i));
  END LOOP;
END;
```

출력

```text
Blue
Green
Red
Yellow
```
