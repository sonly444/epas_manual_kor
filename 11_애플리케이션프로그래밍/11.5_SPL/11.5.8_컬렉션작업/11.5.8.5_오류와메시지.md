# 오류와 메시지 (Errors and messages) — EPAS 18 SPL 컬렉션 작업

> 원문: [EPAS v18 — SPL › Working with collections › Errors and messages](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/12_working_with_collections/05_errors_and_messages/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·변수·코드는 원문 그대로 보존했습니다.

## 메시지 보고

`DBMS_OUTPUT.PUT_LINE` 문을 사용하여 메시지를 보고합니다.

```sql
DBMS_OUTPUT.PUT_LINE ( <message> );
```

여기서 `message`는 문자열로 평가되는 임의의 표현식입니다.

이 예제는 사용자의 출력 화면에 메시지를 표시합니다.

```sql
DBMS_OUTPUT.PUT_LINE('My name is John');
```

특수 변수 `SQLCODE`와 `SQLERRM`은 각각 마지막으로 실행된 SQL 명령의 결과를 설명하는 숫자 코드와 텍스트 메시지를 담습니다. 0으로 나누기 같은 다른 오류가 프로그램에서 발생하면, 이 변수들은 그 오류와 관련된 정보를 담습니다.

## SQLCODE 및 SQLERRM 함수

SQLCODE 및 SQLERRM 함수는 이제 EDB Postgres Advanced Server에서 사용할 수 있습니다.

예외 처리기 안에서 `SQLCODE` 함수는 처리 중인 예외의 숫자 코드를 반환합니다. 예외 처리기 밖에서는 `SQLCODE`가 `0`을 반환합니다.

`SQLERRM` 함수는 `SQLCODE` 변수 값과 연관된 오류 메시지를 반환합니다. 오류 코드 값이 `SQLERRM` 함수에 전달되면, 현재 발생한 오류와 관계없이 전달된 오류 코드 값과 연관된 오류 메시지를 반환합니다.

SQL 문은 `SQLCODE`와 `SQLERRM` 함수를 호출할 수 없습니다.

예제:

```sql
declare
l_var number;
begin
l_var:=-1476;
dbms_output.put_line(sqlerrm(l_var::int));
l_var:=0;
dbms_output.put_line(sqlerrm(l_var::int));
l_var:=12;
dbms_output.put_line(sqlerrm(l_var::int));
l_var:=01403;
dbms_output.put_line(sqlerrm(l_var::int));

end;
```

출력

```text
division_by_zero
normal, successful completion
message 12 not found
message 1403 not found
```

```sql
DECLARE
Balance integer := 24;
BEGIN
IF (Balance <= 100) THEN
Raise_Application_Error (-20343, 'The balance is too low.');
END IF;
exception
    when others then
        dbms_output.put_line('sqlcode ==>'|| sqlcode);
        dbms_output.put_line('sqlerrm ==>'|| sqlerrm);
        dbms_output.put_line('sqlerrm(sqlcode) ==>'|| sqlerrm(sqlcode));
END;
```

출력

```text
sqlcode ==>-20343
sqlerrm ==>EDB-20343: The balance is too low.
sqlerrm(sqlcode) ==>EDB-20343: The balance is too low.
```
