# After statement-level trigger — EPAS 18 SPL 트리거 예제

> 원문: [EPAS v18 — SPL › Working with triggers › Trigger examples › After statement-level trigger](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/13_triggers/07_trigger_examples/02_after_statement_level_trigger/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 after 문장 수준(statement-level) 트리거를 보여줍니다. `emp` 테이블에 insert, update, delete 작업이 발생하면, 날짜, 사용자, 작업 내용을 기록하는 행이 `empauditlog` 테이블에 추가됩니다.

```sql
CREATE TABLE empauditlog (
    audit_date      DATE,
    audit_user      VARCHAR2(20),
    audit_desc      VARCHAR2(20)
);
CREATE OR REPLACE TRIGGER emp_audit_trig
    AFTER INSERT OR UPDATE OR DELETE ON emp
DECLARE
    v_action        VARCHAR2(20);
BEGIN
    IF INSERTING THEN
        v_action := 'Added employee(s)';
    ELSIF UPDATING THEN
        v_action := 'Updated employee(s)';
    ELSIF DELETING THEN
        v_action := 'Deleted employee(s)';
    END IF;
    INSERT INTO empauditlog VALUES (SYSDATE, USER,
        v_action);
END;
```

다음 일련의 명령에서는 두 개의 `INSERT` 명령을 사용하여 `emp` 테이블에 두 개의 행이 삽입됩니다. 하나의 `UPDATE` 명령이 두 행의 `sal`과 `comm` 컬럼을 갱신합니다. 그런 다음, 하나의 `DELETE` 명령이 두 행을 삭제합니다.

```sql
INSERT INTO emp VALUES (9001,'SMITH','ANALYST',7782,SYSDATE,NULL,NULL,10);

INSERT INTO emp VALUES (9002,'JONES','CLERK',7782,SYSDATE,NULL,NULL,10);

UPDATE emp SET sal = 4000.00, comm = 1200.00 WHERE empno IN (9001, 9002);

DELETE FROM emp WHERE empno IN (9001, 9002);

SELECT TO_CHAR(AUDIT_DATE,'DD-MON-YY HH24:MI:SS') AS "AUDIT DATE",
    audit_user, audit_desc FROM empauditlog ORDER BY 1 ASC;
```

출력(Output)

```text
AUDIT DATE         AUDIT_USER           AUDIT_DESC
------------------ -------------------- --------------------
31-MAR-05 14:59:48 SYSTEM               Added employee(s)
31-MAR-05 15:00:07 SYSTEM               Added employee(s)
31-MAR-05 15:00:19 SYSTEM               Updated employee(s)
31-MAR-05 15:00:34 SYSTEM               Deleted employee(s)
```

`empauditlog` 테이블의 내용은 트리거가 몇 번 실행되었는지를 보여줍니다.

- 두 번의 insert에 대해 각각 한 번씩
- update에 대해 한 번 (두 개의 행이 변경되었음에도)
- 삭제에 대해 한 번 (두 개의 행이 삭제되었음에도)
