# Before row-level trigger — EPAS 18 SPL 트리거 예제

> 원문: [EPAS v18 — SPL › Working with triggers › Trigger examples › Before row-level trigger](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/13_triggers/07_trigger_examples/03_before_row_level_trigger/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 `emp` 테이블에 삽입되는, 부서 30에 속한 모든 신규 사원의 커미션을 계산하는 before 행 수준(row-level) 트리거를 보여줍니다.

```sql
CREATE OR REPLACE TRIGGER emp_comm_trig
    BEFORE INSERT ON emp
    FOR EACH ROW
BEGIN
    IF :NEW.deptno = 30 THEN
        :NEW.comm := :NEW.sal * .4;
    END IF;
END;
```

두 명의 사원을 추가한 후의 목록은, 트리거가 그들의 커미션을 계산하여 신규 사원 행의 일부로 삽입했음을 보여줍니다.

```sql
INSERT INTO emp VALUES (9005,'ROBERS','SALESMAN',7782,SYSDATE,3000.00,NULL,30);

INSERT INTO emp VALUES (9006,'ALLEN','SALESMAN',7782,SYSDATE,4500.00,NULL,30);

SELECT * FROM emp WHERE empno IN (9005, 9006);
```

출력(Output)

```text
 EMPNO ENAME  JOB       MGR    HIREDATE       SAL       COMM       DEPTNO
------ ------ --------  ------ ---------- --------- ---------- -------------
 9005  ROBERS SALESMAN  7782   01-APR-05      3000       1200         30
 9006  ALLEN  SALESMAN  7782   01-APR-05      4500       1800         30
```
