# INSTEAD OF trigger — EPAS 18 SPL 트리거 예제

> 원문: [EPAS v18 — SPL › Working with triggers › Trigger examples › INSTEAD OF trigger](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/13_triggers/07_trigger_examples/05_instead_of_trigger/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 `emp_vw` 뷰에 새 사원 행을 삽입하기 위한 `INSTEAD OF` 트리거를 보여줍니다. `CREATE VIEW` 문은 두 테이블을 조인하여 `emp_vw` 뷰를 생성합니다. 트리거는 특정 사원에 대해 해당하는 새 행을 각각 `emp` 및 `dept` 테이블에 추가합니다.

```sql
CREATE VIEW emp_vw AS SELECT * FROM emp e JOIN dept d USING(deptno);
CREATE VIEW

CREATE OR REPLACE TRIGGER empvw_instead_of_trig
    INSTEAD OF INSERT ON emp_vw
    FOR EACH ROW
DECLARE
    v_empno         emp.empno%TYPE;
    v_ename         emp.ename%TYPE;
    v_deptno        emp.deptno%TYPE;
    v_dname         dept.dname%TYPE;
    v_loc           dept.loc%TYPE;
    v_action        VARCHAR2(7);
BEGIN
    v_empno     := :NEW.empno;
    v_ename     := :New.ename;
    v_deptno    := :NEW.deptno;
    v_dname     := :NEW.dname;
    v_loc       := :NEW.loc;
     INSERT INTO emp(empno, ename, deptno) VALUES(v_empno, v_ename, v_deptno);
     INSERT INTO dept(deptno, dname, loc) VALUES(v_deptno, v_dname, v_loc);
END;
CREATE TRIGGER
```

다음으로, `emp_vw` 뷰에 값을 삽입합니다. 삽입 작업은 새 행을 삽입하고 다음과 같은 출력을 생성합니다.

```sql
INSERT INTO emp_vw (empno, ename, deptno, dname, loc ) VALUES(1234, 'ASHTON', 50, 'IT', 'NEW JERSEY');
```

출력(Output)

```text
INSERT 0 1
```

```sql
SELECT empno, ename, deptno FROM emp  WHERE deptno = 50;
```

출력(Output)

```text
 empno | ename  | deptno
-------+--------+--------
  1234 | ASHTON |     50
(1 row)
```

```sql
SELECT * FROM dept  WHERE deptno = 50;
```

출력(Output)

```text
 deptno | dname |    loc
--------+-------+------------
     50 | IT    | NEW JERSEY
(1 row)
```

마찬가지로, `UPDATE` 또는 `DELETE` 문을 지정하면, 트리거는 `UPDATE` 또는 `DELETE` 이벤트에 대해 적절한 작업을 수행합니다.
