## 테이블에 복합 트리거(compound trigger) 정의하기 (Defining a compound trigger on a table)

이 예제는 `emp` 테이블에 `hr_trigger`라는 복합 트리거(compound trigger)를 정의하여 사원 급여의 변경을 기록하는 복합 트리거를 보여줍니다.

1. `emp`라는 테이블을 생성합니다.

   ```sql
   CREATE TABLE emp(EMPNO INT, ENAME TEXT, SAL INT, DEPTNO INT);
   CREATE TABLE
   ```

2. `hr_trigger`라는 복합 트리거를 생성합니다. 이 트리거는 네 개의 타이밍 포인트(timing point) 각각을 사용하여 `INSERT`, `UPDATE`, 또는 `DELETE` 문으로 급여를 수정합니다. 전역 선언(global declaration) 섹션에서 초기 급여는 `10,000`으로 선언됩니다.

   ```sql
   CREATE OR REPLACE TRIGGER hr_trigger
        FOR INSERT OR UPDATE OR DELETE ON emp
          COMPOUND TRIGGER
        -- Global declaration.
        var_sal NUMBER := 10000;

        BEFORE STATEMENT IS
        BEGIN
          var_sal := var_sal + 1000;
          DBMS_OUTPUT.PUT_LINE('Before Statement: ' || var_sal);
        END BEFORE STATEMENT;

        BEFORE EACH ROW IS
        BEGIN
          var_sal := var_sal + 1000;
          DBMS_OUTPUT.PUT_LINE('Before Each Row: ' || var_sal);
        END BEFORE EACH ROW;

        AFTER EACH ROW IS
        BEGIN
          var_sal := var_sal + 1000;
          DBMS_OUTPUT.PUT_LINE('After Each Row: ' || var_sal);
        END AFTER EACH ROW;

        AFTER STATEMENT IS
        BEGIN
          var_sal := var_sal + 1000;
          DBMS_OUTPUT.PUT_LINE('After Statement: ' || var_sal);
        END AFTER STATEMENT;

   END hr_trigger;

   Output: Trigger created.
   ```

3. `emp` 테이블에 레코드를 삽입합니다.

   ```sql
   INSERT INTO emp (EMPNO, ENAME, SAL, DEPTNO) VALUES(1111,'SMITH', 10000, 20);
   ```

   `INSERT` 문은 다음과 같은 출력을 생성합니다.

   ```sql

   ```

   출력(Output)

   ```text
   Before Statement: 11000
   Before each row: 12000
   After each row: 13000
   After statement: 14000
   INSERT 0 1
   ```

4. `UPDATE` 문은 특정 사원 번호에 대해 급여를 `15000`으로 설정하여 사원 급여 레코드를 갱신합니다.

   ```sql
   UPDATE emp SET SAL = 15000 where EMPNO = 1111;
   ```

   `UPDATE` 문은 다음과 같은 출력을 생성합니다.

   ```sql
   Before Statement: 11000
   Before each row: 12000
   After each row: 13000
   After statement: 14000
   UPDATE 1

   SELECT * FROM emp;
   ```

   출력(Output)

   ```text
       EMPNO | ENAME |  SAL  | DEPTNO
      -------+-------+-------+--------
        1111 | SMITH | 15000 |     20
   (1 row)
   ```

### TRUNCATE

`TRUNCATE` 문은 `emp` 테이블에서 모든 레코드를 제거합니다.

```sql
CREATE OR REPLACE TRIGGER hr_trigger
  FOR TRUNCATE ON emp
    COMPOUND TRIGGER
  -- Global declaration.
  var_sal NUMBER := 10000;
  BEFORE STATEMENT IS
  BEGIN
    var_sal := var_sal + 1000;
    DBMS_OUTPUT.PUT_LINE('Before Statement: ' || var_sal);
  END BEFORE STATEMENT;

  AFTER STATEMENT IS
  BEGIN
    var_sal := var_sal + 1000;
    DBMS_OUTPUT.PUT_LINE('After Statement: ' || var_sal);
  END AFTER STATEMENT;

END hr_trigger;

Output: Trigger created.
```

`TRUNCATE` 문은 다음과 같은 출력을 생성합니다.

```sql
TRUNCATE emp;
```

출력(Output)

```text
Before Statement: 11000
After statement: 12000
TRUNCATE TABLE
```

##### 참고 (Note)

`TRUNCATE` 문은 `BEFORE STATEMENT` 또는 `AFTER STATEMENT` 타이밍 포인트에서만 사용할 수 있습니다.

## WHEN 조건이 있는 테이블에 복합 트리거 생성하기 (Creating a compound trigger on a table with a WHEN condition)

이 예제는 `emp` 테이블에 `WHEN` 조건을 가진 `hr_trigger`라는 복합 트리거를 생성합니다. `WHEN` 조건은 `INSERT`, `UPDATE`, 또는 `DELETE` 문이 `emp` 테이블에 영향을 줄 때 사원 급여를 확인하고 출력합니다. 데이터베이스는 행 수준(row-level) 트리거에 대해 `WHEN` 조건을 평가하며, `WHEN` 조건이 `TRUE`로 평가되면 트리거는 행마다 한 번씩 실행됩니다. 문장 수준(statement-level) 트리거는 `WHEN` 조건과 관계없이 실행됩니다.

```sql
CREATE OR REPLACE TRIGGER hr_trigger
  FOR INSERT OR UPDATE OR DELETE ON emp
  REFERENCING NEW AS new OLD AS old
  WHEN (old.sal > 5000 OR new.sal < 8000)
    COMPOUND TRIGGER

  BEFORE STATEMENT IS
  BEGIN
    DBMS_OUTPUT.PUT_LINE('Before Statement');
  END BEFORE STATEMENT;

  BEFORE EACH ROW IS
  BEGIN
    DBMS_OUTPUT.PUT_LINE('Before Each Row: ' || :OLD.sal ||' ' || :NEW.sal);
  END BEFORE EACH ROW;

  AFTER EACH ROW IS
  BEGIN
    DBMS_OUTPUT.PUT_LINE('After Each Row: ' || :OLD.sal ||' ' || :NEW.sal);
  END AFTER EACH ROW;

  AFTER STATEMENT IS
  BEGIN
    DBMS_OUTPUT.PUT_LINE('After Statement');
  END AFTER STATEMENT;

END hr_trigger;
```
