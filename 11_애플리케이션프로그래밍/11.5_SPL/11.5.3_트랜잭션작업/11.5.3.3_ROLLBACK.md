# ROLLBACK — EPAS 18 SPL 트랜잭션

> 원문: [EPAS v18 — SPL › Working with transactions › ROLLBACK](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/06_transaction_control/02_rollback/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·출력은 원문 그대로 보존했습니다.

# ROLLBACK v18

`ROLLBACK` 명령은 현재 트랜잭션 중에 이루어진 모든 데이터베이스 업데이트를 취소하고 현재 트랜잭션을 종료합니다.

```sql
ROLLBACK [ WORK ];
```

`ROLLBACK` 명령은 익명 블록(anonymous block), 저장 프로시저, 함수에서 사용할 수 있습니다. SPL 프로그램에서는 실행 섹션(executable section)과 예외 섹션(exception section)에 나타날 수 있습니다.

이 예제에서 예외 섹션에는 `ROLLBACK` 명령이 포함되어 있습니다. 처음 두 `INSERT` 명령이 성공적으로 실행되더라도, 세 번째 명령이 예외를 발생시켜 익명 블록의 모든 `INSERT` 명령이 롤백됩니다.

```sql
\set AUTOCOMMIT off
SET edb_stmt_level_tx TO on;

BEGIN
    INSERT INTO dept VALUES (50, 'FINANCE', 'DALLAS');
    INSERT INTO dept VALUES (60, 'MARKETING', 'CHICAGO');
    INSERT INTO dept VALUES (70, 'HUMAN RESOURCES', 'CHICAGO');
EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
        DBMS_OUTPUT.PUT_LINE('SQLERRM: ' || SQLERRM);
        DBMS_OUTPUT.PUT_LINE('SQLCODE: ' || SQLCODE);
END;

SQLERRM: value too long for type character varying(14)
SQLCODE: 22001

SELECT * FROM dept;
```

Output

```text
deptno  |   dname    |   loc
--------+------------+----------
     10 | ACCOUNTING | NEW YORK
     20 | RESEARCH   | DALLAS
     30 | SALES      | CHICAGO
     40 | OPERATIONS | BOSTON
(4 rows)
```

이 예제는 `COMMIT`과 `ROLLBACK`을 모두 사용합니다. 먼저, 다음 저장 프로시저가 생성됩니다. 이 프로시저는 새 사원을 삽입합니다.

```sql
\set AUTOCOMMIT off
SET edb_stmt_level_tx TO on;

CREATE OR REPLACE PROCEDURE emp_insert (
    p_empno         IN emp.empno%TYPE,
    p_ename         IN emp.ename%TYPE,
    p_job           IN emp.job%TYPE,
    p_mgr           IN emp.mgr%TYPE,
    p_hiredate      IN emp.hiredate%TYPE,
    p_sal           IN emp.sal%TYPE,
    p_comm          IN emp.comm%TYPE,
    p_deptno        IN emp.deptno%TYPE
)
IS
BEGIN
    INSERT INTO emp VALUES (
        p_empno,
        p_ename,
        p_job,
        p_mgr,
        p_hiredate,
        p_sal,
        p_comm,
        p_deptno);

    DBMS_OUTPUT.PUT_LINE('Added employee...');
    DBMS_OUTPUT.PUT_LINE('Employee # : ' || p_empno);
    DBMS_OUTPUT.PUT_LINE('Name       : ' || p_ename);
    DBMS_OUTPUT.PUT_LINE('Job        : ' || p_job);
    DBMS_OUTPUT.PUT_LINE('Manager    : ' || p_mgr);
    DBMS_OUTPUT.PUT_LINE('Hire Date  : ' || p_hiredate);
    DBMS_OUTPUT.PUT_LINE('Salary     : ' || p_sal);
    DBMS_OUTPUT.PUT_LINE('Commission : ' || p_comm);
    DBMS_OUTPUT.PUT_LINE('Dept #     : ' || p_deptno);
    DBMS_OUTPUT.PUT_LINE('----------------------');
END;
```

이 프로시저에는 예외 섹션이 없습니다. 모든 오류는 호출 프로그램으로 전파됩니다.

그런 다음 아래 익명 블록이 실행됩니다. `COMMIT` 명령은 `emp_insert` 프로시저에 대한 모든 호출 후에 사용되고, `ROLLBACK` 명령은 예외 섹션에 사용됩니다.

```sql
BEGIN
    emp_insert(9601,'FARRELL','ANALYST',7902,'03-MAR-08',5000,NULL,40);
    emp_insert(9602,'TYLER','ANALYST',7900,'25-JAN-08',4800,NULL,40);
    COMMIT;
EXCEPTION
    WHEN OTHERS THEN
        DBMS_OUTPUT.PUT_LINE('SQLERRM: ' || SQLERRM);
        DBMS_OUTPUT.PUT_LINE('An error occurred - roll back inserts');
        ROLLBACK;
END;
```

Output

```text
Added employee...
Employee # : 9601
Name       : FARRELL
Job        : ANALYST
Manager    : 7902
Hire Date  : 03-MAR-08 00:00:00
Salary     : 5000
Commission :
Dept #     : 40
----------------------
Added employee...
Employee # : 9602
Name       : TYLER
Job        : ANALYST
Manager    : 7900
Hire Date  : 25-JAN-08 00:00:00
Salary     : 4800
Commission :
Dept #     : 40
----------------------
```

다음 `SELECT` 명령은 사원 Farrell과 Tyler가 성공적으로 추가되었음을 보여줍니다.

```sql
SELECT * FROM emp WHERE empno > 9600;
```

Output

```text
empno | ename  |  job   | mgr |     hiredate       |   sal   | comm | deptno
------+--------+--------+-----+--------------------+---------+------+--------
  9601| FARRELL| ANALYST|7902 | 03-MAR-08 00:00:00 | 5000.00 |      |   40
  9602| TYLER  | ANALYST|7900 | 25-JAN-08 00:00:00 | 4800.00 |      |   40
(2 rows)
```

다음으로, 아래 익명 블록을 실행합니다.

```sql
BEGIN
    emp_insert(9603,'HARRISON','SALESMAN',7902,'13-DEC-07',5000,3000,20);
    emp_insert(9604,'JARVIS','SALESMAN',7902,'05-MAY-08',4800,4100,11);
    COMMIT;
EXCEPTION
    WHEN OTHERS THEN
        DBMS_OUTPUT.PUT_LINE('SQLERRM: ' || SQLERRM);
        DBMS_OUTPUT.PUT_LINE('An error occurred - roll back inserts');
        ROLLBACK;
END;
```

Output

```text
Added employee...
Employee # : 9603
Name       : HARRISON
Job        : SALESMAN
Manager    : 7902
Hire Date  : 13-DEC-07 00:00:00
Salary     : 5000
Commission : 3000
Dept #     : 20
----------------------
SQLERRM: insert or update on table "emp" violates foreign key constraint
"emp_ref_dept_fk"
An error occurred - roll back inserts
```

테이블에 대해 실행한 `SELECT` 명령은 다음을 생성합니다.

```sql
SELECT * FROM emp WHERE empno > 9600;
```

Output

```text
empno | ename  |  job   | mgr |     hiredate       |   sal   | comm | deptno
------+--------+--------+-----+--------------------+---------+------+--------
  9601| FARRELL| ANALYST|7902 | 03-MAR-08 00:00:00 | 5000.00 |      |   40
  9602| TYLER  | ANALYST|7900 | 25-JAN-08 00:00:00 | 4800.00 |      |   40
(2 rows)
```

예외 섹션의 `ROLLBACK` 명령은 사원 Harrison의 삽입을 성공적으로 취소합니다. 사원 Farrell과 Tyler는 첫 번째 익명 블록의 `COMMIT` 명령에 의해 영구적으로 반영되었으므로 여전히 테이블에 남아 있습니다.

##### 참고 (Note)

Oracle 스타일의 SPL 프로시저가 런타임 스택에 있는 경우, plpgsql 프로시저에서 `COMMIT` 또는 `ROLLBACK`을 실행하면 오류가 발생합니다.
