# 저장 프로시저 언어 사용 (Using the stored procedural language) v18

EDB Postgres Advanced Server의 저장 프로시저 언어(stored procedural language, SPL)는 EDB Postgres Advanced Server를 위한 사용자 정의 프로시저, 함수, 트리거, 패키지를 작성하기 위한 생산성이 매우 높은 절차적 프로그래밍 언어입니다. SPL은 다음을 제공합니다.

- SQL 언어를 보완하는 완전한 절차적 프로그래밍 기능
- EDB Postgres Advanced Server 데이터베이스를 위한 저장 프로시저, 함수, 트리거, 패키지를 생성할 수 있는 단일 공통 언어
- 매끄러운 개발 및 테스트 환경
- 재사용 가능한 코드의 활용
- 사용의 편의성

SPL 프로그램 유형, 프로그래밍 문(statement), 제어 구조, 컬렉션 타입, 컬렉션 메서드에 대한 참조 정보는 [Stored procedural language (SPL) reference](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/)를 참조하십시오.
