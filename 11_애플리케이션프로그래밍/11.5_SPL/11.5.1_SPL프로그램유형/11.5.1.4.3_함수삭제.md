# 함수 삭제 (Deleting a function) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Functions overview › Deleting a function](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/05_functions_overview/03_deleting_a_function/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드는 원문 그대로 보존했습니다.

`DROP FUNCTION`을 사용하여 데이터베이스에서 함수를 삭제할 수 있습니다.

```sql
DROP FUNCTION [ IF EXISTS ] <name> [ (<parameters>) ]
    [ CASCADE | RESTRICT ];
```

여기서 `name`은 삭제할 함수의 이름입니다.

> **참고**
>
> - 오버로딩된 함수와 같은 특정 상황에서는 EDB Postgres Advanced Server에서 파라미터 목록을 지정하는 것이 필수입니다. Oracle에서는 항상 파라미터 목록을 생략해야 합니다.
>
> - `IF EXISTS`, `CASCADE`, `RESTRICT`의 사용은 Oracle 데이터베이스와 호환되지 않습니다. 이러한 옵션에 대한 정보는 [SQL 참조](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/47_drop_function/)를 참조하세요.

이 예제는 `simple_function` 함수를 삭제합니다.

```sql
DROP FUNCTION simple_function;
```
