# 전방 선언 사용 (Using forward declarations) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Subprograms › Using forward declarations](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/07_subprograms_subprocedures_and_subfunctions/05_using_forward_declarations/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 용어·코드는 원문 그대로 보존했습니다.

서브프로그램을 호출하려면, 독립 프로그램의 블록 계층에서 그것을 호출하는 위치보다 앞서 선언해야 합니다. 다시 말해, SPL 코드를 처음부터 끝까지 살펴볼 때 서브프로그램 선언은 그 호출보다 앞에 나타나야 합니다.

그러나 서브프로그램의 완전한 선언이 그것이 호출되는 코드 지점보다 뒤의 SPL 코드에 나타나도록 SPL 코드를 구성할 수 있습니다. (완전한 선언에는 선택적 선언 섹션, 필수 실행 섹션, 선택적 예외 섹션이 포함됩니다.)

이를 위해 호출보다 앞서 SPL 코드에 _전방 선언(forward declaration)_ 을 삽입할 수 있습니다. 전방 선언은 서브프로시저나 서브함수의 이름, 형식 매개변수, 그리고 서브함수인 경우 반환 타입에 대한 명세입니다.

선택적 선언 섹션, 실행 섹션, 선택적 예외 섹션으로 구성된 전체 서브프로그램은 전방 선언과 동일한 선언 섹션에 지정해야 합니다. 다만, 그것은 전방 선언을 사용하여 이 서브프로그램을 호출하는 다른 서브프로그램 선언 뒤에 나타날 수 있습니다.

전방 선언의 전형적인 사용은 두 서브프로그램이 서로를 호출하는 경우입니다.

```sql
DECLARE
    FUNCTION add_one (
        p_add       IN NUMBER
    ) RETURN NUMBER;
    FUNCTION test_max (
        p_test      IN NUMBER)
    RETURN NUMBER
    IS
    BEGIN
        IF p_test < 5 THEN
            RETURN add_one(p_test);
        END IF;
        DBMS_OUTPUT.PUT('Final value is ');
        RETURN p_test;
    END;
    FUNCTION add_one (
        p_add       IN NUMBER)
    RETURN NUMBER
    IS
    BEGIN
        DBMS_OUTPUT.PUT_LINE('Increase by 1');
        RETURN test_max(p_add + 1);
    END;
BEGIN
    DBMS_OUTPUT.PUT_LINE(test_max(3));
END;
```

서브함수 `test_max`는 서브함수 `add_one`을 호출하고, `add_one`도 서브함수 `test_max`를 호출합니다. 서브프로그램 중 하나에 대해 전방 선언이 필요하며, 여기서는 익명 블록 선언 섹션의 시작 부분에서 `add_one`에 대해 구현되었습니다.

익명 블록에서 얻어지는 출력은 다음과 같습니다.

Output

```text
Increase by 1
Increase by 1
Final value is 5
```
