# 파라미터 선언 (Declaring parameters) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Procedure and function parameters › Declaring parameters](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/06_procedure_and_function_parameters/declaring_parameters/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·키워드·코드는 원문 그대로 보존했습니다.

파라미터는 프로시저 또는 함수 정의에서 선언하며, 프로시저나 함수 이름 뒤의 괄호 안에 넣습니다. 프로시저 또는 함수 정의에 선언된 파라미터를 *형식 파라미터(formal parameter)*라고 합니다. 프로시저나 함수를 호출할 때, 호출하는 프로그램은 호출된 프로그램의 처리에 사용할 실제 데이터와 호출된 프로그램의 처리 결과를 받을 변수를 제공합니다. 프로시저나 함수가 호출될 때 호출하는 프로그램이 제공하는 데이터와 변수를 *실제 파라미터(actual parameter)*라고 합니다.

다음은 형식 파라미터 선언의 일반적인 형식입니다.

```text
(<name> [ IN | OUT | IN OUT ] <data_type> [ DEFAULT <value> ])
```

- `name`은 형식 파라미터에 할당된 식별자입니다.
- 파라미터가 `IN`, `OUT`, `IN OUT` 중 무엇인지를 파라미터의 *모드(mode)*라고 합니다. `IN`을 지정하면 해당 파라미터는 프로시저나 함수로 입력 데이터를 받는 용도로 정의됩니다. `IN` 파라미터는 기본값으로 초기화할 수도 있습니다. `OUT`을 지정하면 해당 파라미터는 프로시저나 함수에서 데이터를 반환하는 용도로 정의됩니다. `IN OUT`을 지정하면 해당 파라미터를 입력과 출력 모두에 사용할 수 있습니다. `IN`, `OUT`, `IN OUT`을 모두 생략하면 파라미터는 기본적으로 `IN`으로 정의된 것처럼 동작합니다.
- `data_type`은 파라미터의 데이터 타입을 정의합니다.
- `value`는 호출에서 실제 파라미터를 지정하지 않는 경우 호출된 프로그램에서 `IN` 파라미터에 할당되는 기본값입니다.

이 예제는 파라미터를 받는 프로시저를 보여 줍니다.

```sql
CREATE OR REPLACE PROCEDURE emp_query (
    p_deptno        IN     NUMBER,
    p_empno         IN OUT NUMBER,
    p_ename         IN OUT VARCHAR2,
    p_job           OUT    VARCHAR2,
    p_hiredate      OUT    DATE,
    p_sal           OUT    NUMBER
)
IS
BEGIN
    SELECT empno, ename, job, hiredate, sal
        INTO p_empno, p_ename, p_job, p_hiredate, p_sal
        FROM emp
        WHERE deptno = p_deptno
          AND (empno = p_empno
           OR  ename = UPPER(p_ename));
END;
```

이 예제에서 `p_deptno`는 `IN` 형식 파라미터이고, `p_empno`와 `p_ename`은 `IN OUT` 형식 파라미터이며, `p_job`, `p_hiredate`, `p_sal`은 `OUT` 형식 파라미터입니다.

> **참고**
>
> 이 예제에서는 `VARCHAR2` 파라미터에 최대 길이를 지정하지 않았고, `NUMBER` 파라미터에 정밀도(precision)와 스케일(scale)을 지정하지 않았습니다. 파라미터 선언에 길이, 정밀도, 스케일 또는 기타 제약 조건을 지정하는 것은 허용되지 않습니다. 이러한 제약 조건은 프로시저나 함수를 호출할 때 사용되는 실제 파라미터로부터 상속됩니다.

`emp_query` 프로시저는 다른 프로그램에서 실제 파라미터를 전달하여 호출할 수 있습니다. 이 예제는 `emp_query`를 호출하는 또 다른 SPL 프로그램입니다.

```sql
DECLARE
    v_deptno        NUMBER(2);
    v_empno         NUMBER(4);
    v_ename         VARCHAR2(10);
    v_job           VARCHAR2(9);
    v_hiredate      DATE;
    v_sal           NUMBER;
BEGIN
    v_deptno := 30;
    v_empno  := 7900;
    v_ename  := '';
    emp_query(v_deptno, v_empno, v_ename, v_job, v_hiredate, v_sal);
    DBMS_OUTPUT.PUT_LINE('Department : ' || v_deptno);
    DBMS_OUTPUT.PUT_LINE('Employee No: ' || v_empno);
    DBMS_OUTPUT.PUT_LINE('Name       : ' || v_ename);
    DBMS_OUTPUT.PUT_LINE('Job        : ' || v_job);
    DBMS_OUTPUT.PUT_LINE('Hire Date  : ' || v_hiredate);
    DBMS_OUTPUT.PUT_LINE('Salary     : ' || v_sal);
END;
```

이 예제에서 `v_deptno`, `v_empno`, `v_ename`, `v_job`, `v_hiredate`, `v_sal`은 실제 파라미터입니다.

이 예제의 출력은 다음과 같습니다.

Output

```text
Department : 30
Employee No: 7900
Name       : JAMES
Job        : CLERK
Hire Date  : 03-DEC-81
Salary     : 950
```
