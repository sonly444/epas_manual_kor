# 위치 표기법 대 명명 표기법 (Positional versus named parameter notation) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Procedure and function parameters › Positional versus named parameter notation](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/06_procedure_and_function_parameters/01_positional_vs_named_parameter_notation/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·키워드·코드는 원문 그대로 보존했습니다.

함수나 프로시저에 파라미터를 전달할 때 *위치(positional)* 표기법 또는 *명명(named)* 표기법 중 하나를 사용할 수 있습니다.

- *위치 표기법*으로 파라미터를 지정하면, 선언된 순서대로 파라미터를 나열해야 합니다. 명명 표기법으로 파라미터를 지정하면 파라미터의 순서는 상관없습니다.

- *명명 표기법*으로 파라미터를 지정하면, 각 파라미터의 이름 뒤에 화살표(`=>`)와 파라미터 값을 나열합니다. 명명 표기법은 더 장황하지만 코드를 읽고 유지 관리하기 쉽게 만듭니다.

이 예제는 위치 표기법과 명명 표기법을 사용합니다.

```sql
CREATE OR REPLACE PROCEDURE emp_info (
    p_deptno        IN     NUMBER,
    p_empno         IN OUT NUMBER,
    p_ename         IN OUT VARCHAR2,
)
IS
BEGIN
    dbms_output.put_line('Department Number =' || p_deptno);
    dbms_output.put_line('Employee Number =' || p_empno);
    dbms_output.put_line('Employee Name =' || p_ename;
END;
```

위치 표기법으로 프로시저를 호출하려면 다음을 전달합니다.

```sql
emp_info(30, 7455, 'Clark');
```

명명 표기법으로 프로시저를 호출하려면 다음을 전달합니다.

```sql
emp_info(p_ename =>'Clark', p_empno=>7455, p_deptno=>30);
```

명명 표기법을 사용하면 파라미터 목록이 변경되거나, 파라미터가 재정렬되거나, 선택적 파라미터가 추가되어도 프로시저의 파라미터 목록을 재배열할 필요가 없습니다.

인자에 기본값이 있고 그 인자가 후행(trailing) 인자가 아닌 경우, 프로시저나 함수를 호출하려면 명명 표기법을 사용해야 합니다. 이 예제는 두 개의 선행(leading) 기본 인자를 가진 프로시저를 보여 줍니다.

```sql
CREATE OR REPLACE PROCEDURE check_balance (
    p_customerID  IN NUMBER DEFAULT NULL,
    p_balance     IN NUMBER DEFAULT NULL,
    p_amount      IN NUMBER
)
IS
DECLARE
    balance NUMBER;
BEGIN
   IF (p_balance IS NULL AND p_customerID IS NULL) THEN
      RAISE_APPLICATION_ERROR
          (-20010, 'Must provide balance or customer');
   ELSEIF (p_balance IS NOT NULL AND p_customerID IS NOT NULL) THEN
      RAISE_APPLICATION_ERROR
          (-20020,'Must provide balance or customer, not both');
   ELSEIF (p_balance IS NULL) THEN
      balance := getCustomerBalance(p_customerID);
   ELSE
      balance := p_balance;
   END IF;

   IF (amount > balance) THEN
      RAISE_APPLICATION_ERROR
        (-20030, 'Balance insufficient');
   END IF;
END;
```

이 프로시저를 호출할 때 비후행(nontrailing) 인자 값을 생략하려면 오직 명명 표기법을 사용해야 합니다. 위치 표기법을 사용할 때는 후행 인자만 기본값을 사용할 수 있습니다. 다음 인자로 이 프로시저를 호출할 수 있습니다.

```sql
check_balance(p_customerID => 10, p_amount = 500.00)

check_balance(p_balance => 1000.00, p_amount = 500.00)
```

파라미터를 지정하기 위해 위치 표기법과 명명 표기법의 조합인 *혼합(mixed)* 표기법을 사용할 수 있습니다. 이 예제는 혼합 파라미터 표기법 사용을 보여 줍니다.

```sql
CREATE OR REPLACE PROCEDURE emp_info (
    p_deptno        IN     NUMBER,
    p_empno         IN OUT NUMBER,
    p_ename         IN OUT VARCHAR2,
)
IS
BEGIN
    dbms_output.put_line('Department Number =' || p_deptno);
    dbms_output.put_line('Employee Number =' || p_empno);
    dbms_output.put_line('Employee Name =' || p_ename;
END;
```

혼합 표기법으로 프로시저를 호출할 수 있습니다.

```sql
emp_info(30, p_ename =>'Clark', p_empno=>7455);
```

혼합 표기법을 사용할 때, 명명 인자는 위치 인자보다 앞에 올 수 없습니다.
