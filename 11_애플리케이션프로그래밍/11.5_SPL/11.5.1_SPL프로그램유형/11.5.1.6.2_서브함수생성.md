# 서브함수 생성 (Creating a subfunction) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Subprograms › Creating a subfunction](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/07_subprograms_subprocedures_and_subfunctions/02_creating_a_subfunction/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 키워드·코드는 원문 그대로 보존했습니다.

선언 섹션에 지정된 `FUNCTION` 절은 해당 블록에 지역적인(local) 서브함수를 정의하고 이름을 부여합니다.

- *블록(block)*이라는 용어는 선택적 선언 섹션, 필수 실행 섹션, 선택적 예외 섹션으로 구성된 SPL 블록 구조를 가리킵니다. 블록은 독립형 프로시저 및 함수, 익명 블록, 서브프로그램, 트리거, 패키지, 객체 타입 메서드의 구조입니다.

- *식별자가 블록에 지역적이다(the identifier is local to the block)*라는 표현은 그 식별자(즉, 변수, 커서, 타입, 또는 서브프로그램)가 해당 블록의 선언 섹션에 선언되어, 따라서 그 블록의 실행 섹션 및 선택적 예외 섹션에서 SPL 코드가 접근할 수 있음을 의미합니다.

## 서브함수 선언 (Declaring a subfunction)

```sql
FUNCTION <name> [ (<parameters>) ]
RETURN <data_type>
{ IS | AS }
    [ PRAGMA AUTONOMOUS_TRANSACTION; ]
    [ <declarations> ]
  BEGIN
    <statements>
  END [ <name> ];
```

여기서:

- `name`은 서브함수의 식별자입니다.

- `parameters`는 형식 파라미터(formal parameter)의 목록입니다.

- `data_type`은 함수의 `RETURN` 문이 반환하는 값의 데이터 타입입니다.

- `PRAGMA AUTONOMOUS_TRANSACTION`은 서브함수를 자율 트랜잭션(autonomous transaction)으로 설정하는 지시어입니다.

- `declarations`는 변수, 커서, 타입, 또는 서브프로그램 선언입니다. 서브프로그램 선언이 포함되는 경우, 다른 모든 변수, 커서, 타입 선언 뒤에 선언해야 합니다.

- `statements`는 SPL 프로그램 문(statement)입니다. `BEGIN - END` 블록은 `EXCEPTION` 섹션을 포함할 수 있습니다.

## 예제: 재귀 서브함수 (Example: Recursive subfunction)

다음 예제는 재귀 서브함수의 사용을 보여 줍니다.

```sql
DECLARE
    FUNCTION factorial (
        n           BINARY_INTEGER
    ) RETURN BINARY_INTEGER
    IS
    BEGIN
        IF n = 1 THEN
            RETURN n;
        ELSE
            RETURN n * factorial(n-1);
        END IF;
    END factorial;
BEGIN
    FOR i IN 1..5 LOOP
        DBMS_OUTPUT.PUT_LINE(i || '! = ' || factorial(i));
    END LOOP;
END;
```

출력은 다음과 같습니다.

```text
1! = 1
2! = 2
3! = 6
4! = 24
5! = 120
```
