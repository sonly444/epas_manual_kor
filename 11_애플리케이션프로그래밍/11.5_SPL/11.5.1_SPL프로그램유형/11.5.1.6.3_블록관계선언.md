# 블록 관계 선언 (Declaring block relationships) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Subprograms › Declaring block relationships](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/07_subprograms_subprocedures_and_subfunctions/03_block_relationships/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 용어·코드는 원문 그대로 보존했습니다.

SPL 프로그램에서 블록 간의 관계를 선언할 수 있습니다. 서브프로그램을 호출하고 블록에 선언된 식별자에 접근하는 능력은 이 관계에 달려 있습니다.

## 블록 관계 개요 (About block relationships)

기본 용어는 다음과 같습니다.

- *블록(block)*은 선택적 선언 섹션, 필수 실행 섹션, 선택적 예외 섹션으로 구성된 기본 SPL 구조입니다. 블록은 독립형 프로시저 및 함수 프로그램, 익명 블록, 트리거, 패키지, 서브프로시저 및 서브함수를 구현합니다.
- 식별자(변수, 커서, 타입, 또는 서브프로그램)가 *블록에 지역적이다(local to a block)*라는 것은 해당 식별자가 주어진 블록의 선언 섹션에 선언되었음을 의미합니다. 이러한 지역 식별자는 그 블록의 실행 섹션과 선택적 예외 섹션에서 접근할 수 있습니다.
- *부모 블록(parent block)*은 다른 블록, 즉 *자식 블록(child block)*의 선언을 포함합니다.
- *후손 블록(descendent blocks)*은 주어진 부모 블록에서 시작하여 자식 관계를 형성하는 블록들의 집합입니다.
- *조상 블록(ancestor blocks)*은 주어진 자식 블록에서 시작하여 부모 관계를 형성하는 블록들의 집합입니다.
- 후손(조상) 블록들의 집합은 *계층(hierarchy)*을 형성합니다.
- *수준(level)*은 최상위 조상 블록으로부터 계산한 주어진 블록의 서수적(ordinal) 번호입니다. 예를 들어, 독립형 프로시저가 주어졌을 때, 이 프로시저의 선언 섹션에 선언된 서브프로그램들은 모두 동일한 수준(예: level 1)에 있습니다. 독립형 프로시저에 선언된 서브프로그램들의 선언 섹션에 있는 추가 서브프로그램들은 다음 수준, 즉 level 2에 있습니다.
- *형제 블록(sibling blocks)*은 동일한 부모 블록을 갖는, 즉 모두 같은 블록에 지역적으로 선언된 블록들의 집합입니다. 형제 블록들은 서로에 대해 동일한 수준에 있습니다.

## 예제 (Example)

다음의 프로시저 선언 섹션 집합에 대한 개략도는 블록들의 집합과 그들을 둘러싼 블록들과의 관계에 대한 예를 제공합니다.

블록 왼쪽의 두 개의 수직선은 두 쌍의 형제 블록이 있음을 나타냅니다. `block_1a`와 `block_1b`가 한 쌍이고, `block_2a`와 `block_2b`가 두 번째 쌍입니다.

각 블록과 그 조상 간의 관계는 블록의 오른쪽에 표시되어 있습니다. 최하위 수준의 자식 블록에서 계층을 따라 위로 올라가면 세 개의 계층 경로가 형성됩니다. 첫 번째는 `block_0`, `block_1a`, `block_2a`, `block_3`으로 구성됩니다. 두 번째는 `block_0`, `block_1a`, `block_2b`입니다. 세 번째는 `block_0`, `block_1b`, `block_2b`입니다.

```sql
CREATE PROCEDURE block_0
IS
        .
    +---- PROCEDURE block_1a    ------- Local to block_0
    |     IS
    |         .                          |
    |         .                          |
    |         .                          |
    |     +-- PROCEDURE block_2a   ---- Local to block_1a and descendant
    |     |   IS                          of block_0
    |     |       .                      |
    |     |       .                      |
    |     |       .                      |
    |     |      PROCEDURE block_3   -- Local to block_2a and descendant
    |     |      IS                       of block_1a, and block_0
    | Siblings        .                  |
    |     |           .                  |
    |     |           .                  |
    |     |       END block_3;           |
    |     |   END block_2a;              |
    |     +-- PROCEDURE block_2b   ---- Local to block_1a and descendant
    |     |   IS                          of block_0
 Siblings |       ,                      |
    |     |       .                      |
    |     |       .                      |
    |     +-- END block_2b;              |
    |                                    |
    |      END block_1a;        ---------+
    +----  PROCEDURE block_1b;   ------- Local to block_0
    |      IS
    |          .                         |
    |          .                         |
    |          .                         |
    |          PROCEDURE block_2b   ---- Local to block_1b and descendant
    |          IS                          of block_0
    |              .                     |
    |              .                     |
    |              .                     |
    |          END block_2b;             |
    |                                    |
    +----  END block_1b;        ---------+
BEGIN
      .
      .
      .
END block_0;
```

블록 위치를 기반으로 한 서브프로그램 호출 규칙은 [서브프로그램 호출(Invoking subprograms)](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/07_subprograms_subprocedures_and_subfunctions/04_invoking_subprograms/#invoking_subprograms)부터 설명합니다. 블록 위치를 기반으로 한 변수 접근 규칙은 [서브프로그램 변수 접근(Accessing subprogram variables)](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/07_subprograms_subprocedures_and_subfunctions/07_accessing_subprogram_variables/#accessing_subprogram_variables)에서 설명합니다.
