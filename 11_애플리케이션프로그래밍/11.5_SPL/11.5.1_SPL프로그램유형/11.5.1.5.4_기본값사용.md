# 파라미터의 기본값 사용 (Using default values in parameters) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Procedure and function parameters › Using default values in parameters](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/06_procedure_and_function_parameters/03_using_default_values_in_parameters/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·키워드·코드는 원문 그대로 보존했습니다.

`CREATE PROCEDURE` 또는 `CREATE FUNCTION` 문에서 `DEFAULT` 절을 포함하거나 할당 연산자(`:=`)를 사용하여 형식 파라미터(formal parameter)의 기본값을 설정할 수 있습니다.

## 구문 (Syntax)

형식 파라미터 선언의 일반적인 형태는 다음과 같습니다.

```text
(<name> [ IN|OUT|IN OUT ] <data_type> [{DEFAULT | := } <expr> ])
```

`name`은 파라미터에 할당된 식별자입니다.

`IN|OUT|IN OUT`은 파라미터 모드를 지정합니다.

`data_type`은 변수에 할당된 데이터 타입입니다.

`expr`은 파라미터에 할당된 기본값입니다. `DEFAULT` 절을 포함하지 않으면, 호출자가 해당 파라미터에 값을 반드시 제공해야 합니다.

기본값은 함수나 프로시저를 호출할 때마다 평가됩니다. 예를 들어, `DATE` 타입 파라미터에 `SYSDATE`를 할당하면, 해당 파라미터는 프로시저나 함수가 생성된 시점의 시간이 아니라 현재 호출 시점의 시간을 갖게 됩니다.

## 예제 (Example)

이 예제는 할당 연산자를 사용하여 파라미터 `hiredate`에 기본값 `SYSDATE`를 설정합니다.

```sql
CREATE OR REPLACE PROCEDURE hire_emp (
    p_empno         NUMBER,
    p_ename         VARCHAR2,
    p_hiredate      DATE := SYSDATE
)
IS
BEGIN
    INSERT INTO emp(empno, ename, hiredate)
                   VALUES(p_empno, p_ename, p_hiredate);

    DBMS_OUTPUT.PUT_LINE('Hired!');
END hire_emp;
```

파라미터 선언에 기본값이 포함되어 있으면, 프로시저를 호출할 때 실제 파라미터 목록에서 해당 파라미터를 생략할 수 있습니다. 예제 프로시저 `(hire_emp)`에 대한 호출은 직원 번호 `(p_empno)`와 직원 이름 `(p_empno)` 두 개의 인수를 반드시 포함해야 합니다. 세 번째 파라미터 `(p_hiredate)`는 `SYSDATE` 값으로 기본 설정됩니다.

```sql
hire_emp (7575, Clark)
```

프로시저를 호출할 때 실제 파라미터에 값을 포함하면, 그 값이 기본값보다 우선합니다. 다음 명령은 현재 `SYSDATE` 값과 관계없이 `February 15, 2010`을 hiredate로 갖는 직원을 추가합니다.

```sql
hire_emp (7575, Clark, 15-FEB-2010)
```

할당 연산자 대신 `DEFAULT` 키워드로 대체하여 동일한 프로시저를 작성할 수 있습니다.

```sql
CREATE OR REPLACE PROCEDURE hire_emp (
    p_empno         NUMBER,
    p_ename         VARCHAR2,
    p_hiredate      DATE DEFAULT SYSDATE
)
IS
BEGIN
    INSERT INTO emp(empno, ename, hiredate)
                   VALUES(p_empno, p_ename, p_hiredate);

    DBMS_OUTPUT.PUT_LINE('Hired!');
END hire_emp;
```
