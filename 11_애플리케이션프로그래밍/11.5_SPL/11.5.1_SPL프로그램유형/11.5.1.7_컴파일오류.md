# 프로시저·함수의 컴파일 오류 (Compilation errors in procedures and functions) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Types of SPL programs › Compilation errors in procedures and functions](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/08_compilation_errors_in_procedures_and_functions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터·명령은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server 파서가 프로시저나 함수를 컴파일할 때, `CREATE` 문과 프로그램 본문(`AS` 키워드 다음에 오는 프로그램 부분)이 모두 SPL 및 SQL 구성 요소에 대한 문법 규칙을 준수하는지 확인합니다. 기본적으로 파서가 오류를 감지하면 서버는 컴파일을 중지합니다. 파서는 표현식의 구문 오류(syntax error)를 감지하지만, 의미 오류(semantic error)는 감지하지 못합니다. 의미 오류에는 존재하지 않는 컬럼, 테이블, 함수를 참조하는 표현식이나 잘못된 타입의 값이 포함됩니다.

## 오류 개수 컴파일 제한 설정

`spl.max_error_count`는 SPL 코드에서 지정된 개수의 오류를 만나거나 SQL 코드에서 오류를 만나면 파싱을 중지하도록 서버에 지시합니다. `spl.max_error_count`의 기본값은 `10`입니다. 최대값은 `1000`입니다. `spl.max_error_count`를 `1`로 설정하면 SPL 또는 SQL 코드에서 첫 번째 오류를 만날 때 파싱을 중지하도록 서버에 지시합니다.

`SET` 명령을 사용하여 현재 세션에 대해 `spl.max_error_count` 값을 지정할 수 있습니다. 구문은 다음과 같습니다.

```sql
SET spl.max_error_count = <number_of_errors>
```

여기서 `number_of_errors`는 서버가 컴파일을 중지하기 전에 발생할 수 있는 SPL 오류의 개수를 지정합니다. 예를 들면 다음과 같습니다.

```sql
SET spl.max_error_count = 6
```

## 예제

이 예제는 서버가 처음 만나는 5개의 SPL 오류를 지나쳐 계속 진행하도록 지시합니다. 서버가 여섯 번째 오류를 만나면 검증을 중지하고 6개의 상세 오류 메시지와 1개의 오류 요약을 출력합니다.

새 코드를 개발하거나 다른 소스에서 코드를 가져올 때 시간을 절약하려면, `spl.max_error_count` 구성 파라미터를 비교적 높은 오류 개수로 설정하는 것이 좋습니다.

프로그램 본문의 SPL 코드에 오류가 있더라도 서버가 파싱을 계속하도록 지시했고 파서가 SQL 코드 세그먼트에서 오류를 만나면, 잘못된 SQL 코드 뒤에 오는 SPL 또는 SQL 코드에 더 많은 오류가 있을 수 있습니다. 예를 들어, 다음 함수는 두 개의 오류를 발생시킵니다.

```sql
CREATE FUNCTION computeBonus(baseSalary number) RETURN number AS
BEGIN

    bonus := baseSalary * 1.10;
    total := bonus + 100;

    RETURN bonus;
END;

ERROR:  "bonus" is not a known variable
LINE 4:     bonus := baseSalary * 1.10;
            ^
ERROR:  "total" is not a known variable
LINE 5:     total := bonus + 100;
            ^
ERROR:  compilation of SPL function/procedure "computebonus" failed due to 2 errors
```

이 예제는 앞 예제에 `SELECT` 문을 추가합니다. `SELECT` 문의 오류가 그 뒤에 오는 다른 오류들을 가립니다.

```sql
CREATE FUNCTION computeBonus(employeeName number) RETURN number AS
BEGIN
    SELECT salary INTO baseSalary FROM emp
      WHERE ename = employeeName;

    bonus := baseSalary * 1.10;
    total := bonus + 100;

    RETURN bonus;

END;

ERROR:  "basesalary" is not a known variable
LINE 3:     SELECT salary INTO baseSalary FROM emp WHERE ename = emp...
```
