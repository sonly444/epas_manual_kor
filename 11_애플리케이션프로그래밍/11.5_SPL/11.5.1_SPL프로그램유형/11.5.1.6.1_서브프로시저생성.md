# 서브프로시저 생성 (Creating a subprocedure) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Subprograms › Creating a subprocedure](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/07_subprograms_subprocedures_and_subfunctions/01_creating_a_subprocedure/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 키워드·코드는 원문 그대로 보존했습니다.

선언 섹션에 지정된 `PROCEDURE` 절은 해당 블록에 지역적인(local) 서브프로시저를 정의하고 이름을 부여합니다.

- *블록(block)*이라는 용어는 선택적 선언 섹션, 필수 실행 섹션, 선택적 예외 섹션으로 구성된 SPL 블록 구조를 가리킵니다. 블록은 독립형 프로시저 및 함수, 익명 블록, 서브프로그램, 트리거, 패키지, 객체 타입 메서드의 구조입니다.

- *식별자가 블록에 지역적이다(the identifier is local to the block)*라는 표현은 그 식별자(즉, 변수, 커서, 타입, 또는 서브프로그램)가 해당 블록의 선언 섹션에 선언되었음을 의미합니다. 따라서 SPL 코드는 그 블록의 실행 섹션 및 선택적 예외 섹션에서 해당 식별자에 접근할 수 있습니다.

## 서브프로시저 선언 (Declaring subprocedures)

서브프로시저는 선언 섹션에 포함된 다른 모든 변수, 커서, 타입 선언 뒤에만 선언할 수 있습니다. 서브프로그램은 반드시 마지막 선언 집합이어야 합니다.

```sql
PROCEDURE <name> [ (<parameters>) ]
{ IS | AS }
    [ PRAGMA AUTONOMOUS_TRANSACTION; ]
    [ <declarations> ]
  BEGIN
    <statements>
  END [ <name> ];
```

여기서:

- `name`은 서브프로시저의 식별자입니다.

- `parameters`는 형식 파라미터(formal parameter)의 목록입니다.

- `PRAGMA AUTONOMOUS_TRANSACTION`은 서브프로시저를 자율 트랜잭션(autonomous transaction)으로 설정하는 지시어입니다.

- `declarations`는 변수, 커서, 타입, 또는 서브프로그램 선언입니다. 서브프로그램 선언이 포함되는 경우, 다른 모든 변수, 커서, 타입 선언 뒤에 선언해야 합니다.

- `statements`는 SPL 프로그램 문(statement)입니다. `BEGIN - END` 블록은 `EXCEPTION` 섹션을 포함할 수 있습니다.

## 예제: 익명 블록 내 서브프로시저 (Example: Subprocedure in an anonymous block)

다음은 익명 블록 안의 서브프로시저 예제입니다.

```sql
DECLARE
    PROCEDURE list_emp
    IS
        v_empno     NUMBER(4);
        v_ename     VARCHAR2(10);
        CURSOR emp_cur IS
            SELECT empno, ename FROM emp ORDER BY empno;
    BEGIN
        OPEN emp_cur;
        DBMS_OUTPUT.PUT_LINE('Subprocedure list_emp:');
        DBMS_OUTPUT.PUT_LINE('EMPNO    ENAME');
        DBMS_OUTPUT.PUT_LINE('-----    -------');
        LOOP
            FETCH emp_cur INTO v_empno, v_ename;
            EXIT WHEN emp_cur%NOTFOUND;
            DBMS_OUTPUT.PUT_LINE(v_empno || '     ' || v_ename);
        END LOOP;
        CLOSE emp_cur;
    END;
BEGIN
    list_emp;
END;
```

이 익명 블록을 실행하면 다음과 같은 출력이 생성됩니다.

```text

EMPNO    ENAME
-----    -------

7499     ALLEN
7521     WARD
7566     JONES
7654     MARTIN
7698     BLAKE
7782     CLARK
7788     SCOTT
7839     KING
7844     TURNER
7876     ADAMS
7900     JAMES
7902     FORD
7934     MILLER
```

## 예제: 트리거 내 서브프로시저 (Example: Subprocedure in a trigger)

다음은 트리거 안의 서브프로시저 예제입니다.

```sql
CREATE OR REPLACE TRIGGER dept_audit_trig
    AFTER INSERT OR UPDATE OR DELETE ON dept
DECLARE
    v_action        VARCHAR2(24);
    PROCEDURE display_action (
        p_action    IN  VARCHAR2
    )
    IS
    BEGIN
        DBMS_OUTPUT.PUT_LINE('User ' || USER || ' ' || p_action ||
            ' dept on ' || TO_CHAR(SYSDATE,'YYYY-MM-DD'));
    END display_action;
BEGIN
    IF INSERTING THEN
        v_action := 'added';
    ELSIF UPDATING THEN
        v_action := 'updated';
    ELSIF DELETING THEN
        v_action := 'deleted';
    END IF;
    display_action(v_action);
END;
```

이 트리거를 실행하면 다음과 같은 출력이 생성됩니다.

```sql
INSERT INTO dept VALUES (50,'HR','DENVER');
```

Output

```text
User enterprisedb added dept on 2016-07-26
```
