# SPL 블록 구조 개요 (SPL block structure overview) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Types of SPL programs › SPL block structure overview](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/02_spl_block_structure/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 키워드·코드·출력은 원문 그대로 보존했습니다.

프로그램이 프로시저이든, 함수이든, 서브프로그램이든, 트리거이든 관계없이 SPL 프로그램은 동일한 _블록(block)_ 구조를 가집니다. 하나의 블록은 최대 세 개의 섹션으로 구성됩니다. 선택적 선언 섹션(declaration section), 필수 실행 섹션(executable section), 그리고 선택적 예외 섹션(exception section)입니다. 최소한, 블록은 `BEGIN`과 `END` 키워드 사이에 하나 이상의 SPL 문(statement)으로 구성된 실행 섹션을 가집니다.

선택적 선언 섹션은 실행 섹션과 예외 섹션의 문에서 사용되는 변수, 커서, 타입, 서브프로그램을 선언하는 데 사용합니다. 선언은 실행 섹션의 `BEGIN` 키워드 바로 앞에 나타납니다. 블록이 사용되는 문맥에 따라, 선언 섹션은 `DECLARE` 키워드로 시작할 수 있습니다.

`BEGIN - END` 블록에 예외 섹션을 포함할 수 있습니다. 예외 섹션은 `EXCEPTION` 키워드로 시작하여 그것이 나타난 블록의 끝까지 이어집니다. 블록 안의 어떤 문이 예외를 발생시키면, 예외의 종류와 예외 섹션의 내용에 따라 프로그램 제어권이 발생한 예외를 처리하는 예외 섹션으로 이동할 수 있습니다.

블록의 일반적인 구조는 다음과 같습니다.

```sql
[ [ DECLARE ]
      <pragmas>
      <declarations> ]
    BEGIN
      <statements>
  [ EXCEPTION
      WHEN <exception_condition> THEN
        <statements> [, ...] ]
    END;
```

- `pragmas`는 지시어(directive)입니다(현재 지원되는 프래그마는 `AUTONOMOUS_TRANSACTION`입니다).
- `declarations`는 블록에 국한된(local) 하나 이상의 변수, 커서, 타입, 또는 서브프로그램 선언입니다. 서브프로그램 선언을 포함하는 경우, 다른 모든 변수·커서·타입 선언 뒤에 선언해야 합니다. 각 선언은 세미콜론으로 종료합니다. `DECLARE` 키워드의 사용 여부는 블록이 나타나는 문맥에 따라 달라집니다.
- `statements`는 하나 이상의 SPL 문입니다. 각 문은 세미콜론으로 종료합니다. `END` 키워드로 표시되는 블록의 끝도 세미콜론으로 종료해야 합니다.
- `EXCEPTION` 키워드가 있으면 예외 섹션의 시작을 표시합니다. `exception_condition`은 하나 이상의 예외 유형을 테스트하는 조건식입니다. 예외가 `exception_condition`의 예외 중 하나와 일치하면, `WHEN exception_condition` 절 다음의 `statements`가 실행됩니다. `WHEN exception_condition` 절은 하나 이상 있을 수 있으며, 각 절 다음에는 `statements`가 옵니다.

> **참고**
>
> `BEGIN/END` 블록은 하나의 문으로 간주되므로 블록을 중첩할 수 있습니다. 예외 섹션 역시 중첩된 블록을 포함할 수 있습니다.

다음은 가능한 가장 단순한 블록으로, 실행 섹션에 `NULL` 문만 포함합니다. `NULL` 문은 아무 일도 하지 않는 실행 문입니다.

```sql
BEGIN
   NULL;
END;
```

다음 블록은 선언 섹션과 실행 섹션을 함께 포함합니다.

```sql
DECLARE
    v_numerator     NUMBER(2);
    v_denominator   NUMBER(2);
    v_result        NUMBER(5,2);
BEGIN
   v_numerator := 75;
   v_denominator := 14;
   v_result := v_numerator / v_denominator;
   DBMS_OUTPUT.PUT_LINE(v_numerator || ' divided by ' || v_denominator ||
       ' is ' || v_result);
END;
```

이 예제에서는 세 개의 숫자 변수를 `NUMBER` 데이터 타입으로 선언합니다. 그중 두 변수에 값을 할당하고, 한 숫자를 다른 숫자로 나눕니다. 결과는 세 번째 변수에 저장한 뒤 표시합니다. 출력은 다음과 같습니다.

Output

```text
75 divided by 14 is 5.36
```

다음 블록은 선언 섹션, 실행 섹션, 예외 섹션으로 구성됩니다.

```sql
DECLARE
    v_numerator     NUMBER(2);
    v_denominator   NUMBER(2);
    v_result        NUMBER(5,2);
BEGIN
   v_numerator := 75;
   v_denominator := 0;
   v_result := v_numerator / v_denominator;
   DBMS_OUTPUT.PUT_LINE(v_numerator || ' divided by ' || v_denominator ||
       ' is ' || v_result);
EXCEPTION
    WHEN OTHERS THEN
        DBMS_OUTPUT.PUT_LINE('An exception occurred');
END;
```

다음 출력은 0으로 나눈 결과로 예외 섹션의 문이 실행되었음을 보여줍니다.

Output

```text
An exception occurred
```
