# 프로시저 삭제 (Deleting a procedure) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Procedures overview › Deleting a procedure](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/04_procedures_overview/03_deleting_a_procedure/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드는 원문 그대로 보존했습니다.

`DROP PROCEDURE` 명령을 사용하여 데이터베이스에서 프로시저를 삭제할 수 있습니다.

```sql
DROP PROCEDURE [ IF EXISTS ] <name> [ (<parameters>) ]
    [ CASCADE | RESTRICT ];
```

여기서 `name`은 삭제할 프로시저의 이름입니다.

> **참고**
>
> - EDB Postgres Advanced Server에서는 오버로딩된 프로시저와 같은 특정 상황에서 파라미터 목록의 지정이 필요합니다. Oracle은 항상 파라미터 목록을 생략하도록 요구합니다.
>
> - `IF EXISTS`, `CASCADE`, `RESTRICT`를 사용하는 것은 Oracle 데이터베이스와 호환되지 않습니다. 이러한 옵션에 대한 정보는 [SQL 참조](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/50_drop_procedure/)를 참조하십시오.

이 예제는 프로시저 `simple_procedure`를 삭제합니다.

```sql
DROP PROCEDURE simple_procedure;
```
