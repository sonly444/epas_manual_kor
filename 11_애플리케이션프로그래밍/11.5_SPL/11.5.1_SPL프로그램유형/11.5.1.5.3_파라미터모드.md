# 파라미터 모드 (Parameter modes) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Procedure and function parameters › Parameter modes](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/06_procedure_and_function_parameters/02_parameter_modes/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 키워드·표는 원문 그대로 보존했습니다.

파라미터는 `IN`, `OUT`, `IN OUT`의 세 가지 모드 중 하나를 가집니다. 형식 파라미터의 다음 특성은 그 모드에 따라 달라집니다.

- 프로시저나 함수가 호출될 때의 초기값
- 호출된 프로시저나 함수가 형식 파라미터를 수정할 수 있는지 여부
- 실제 파라미터 값이 호출하는 프로그램에서 호출된 프로그램으로 어떻게 전달되는지
- 호출된 프로그램에서 처리되지 않은(unhandled) 예외가 발생할 때 형식 파라미터 값에 어떤 일이 일어나는지

다음 표는 모드에 따른 파라미터의 동작을 요약합니다.

| 모드 속성 | IN | IN OUT | OUT |
| --- | --- | --- | --- |
| 형식 파라미터 초기값: | 실제 파라미터 값 | 실제 파라미터 값 | 실제 파라미터 값 |
| 호출된 프로그램이 형식 파라미터를 수정할 수 있는가? | 아니오 | 예 | 예 |
| 실제 파라미터의 내용: (호출된 프로그램의 정상 종료 후) | 호출 전 원래의 실제 파라미터 값 | 형식 파라미터의 마지막 값 | 형식 파라미터의 마지막 값 |
| 실제 파라미터의 내용: (호출된 프로그램에서 처리된(handled) 예외 발생 후) | 호출 전 원래의 실제 파라미터 값 | 형식 파라미터의 마지막 값 | 형식 파라미터의 마지막 값 |
| 실제 파라미터의 내용: (호출된 프로그램에서 처리되지 않은 예외 발생 후) | 호출 전 원래의 실제 파라미터 값 | 호출 전 원래의 실제 파라미터 값 | 호출 전 원래의 실제 파라미터 값 |

표에서 보듯이:

- `IN` 형식 파라미터는 기본값으로 명시적으로 초기화되지 않은 한, 호출에 사용된 실제 파라미터로 초기화됩니다. 호출된 프로그램에서 `IN` 파라미터를 참조할 수 있습니다. 그러나 호출된 프로그램은 `IN` 파라미터에 새 값을 할당할 수 없습니다. 제어가 호출하는 프로그램으로 반환된 후, 실제 파라미터는 항상 호출 전에 가지고 있던 것과 동일한 값을 유지합니다.

- `IN` 파라미터와 마찬가지로, `IN OUT` 형식 파라미터는 호출에 사용된 실제 파라미터로 초기화됩니다. `OUT` 파라미터와 마찬가지로, `IN OUT` 형식 파라미터는 호출된 프로그램에 의해 수정될 수 있습니다. 호출된 프로그램이 예외 없이 종료되면 형식 파라미터의 마지막 값이 호출하는 프로그램의 실제 파라미터로 전달됩니다. 처리된 예외가 발생하면 실제 파라미터의 값은 형식 파라미터에 마지막으로 할당된 값을 취합니다. 처리되지 않은 예외가 발생하면 실제 파라미터의 값은 호출 전 상태로 유지됩니다.

- `OUT` 형식 파라미터는 호출에 사용된 실제 파라미터로 초기화됩니다. 호출된 프로그램은 형식 파라미터를 참조하고 새 값을 할당할 수 있습니다. 호출된 프로그램이 예외 없이 종료되면 실제 파라미터는 형식 파라미터에 마지막으로 설정된 값을 취합니다. 처리된 예외가 발생하면 실제 파라미터의 값은 형식 파라미터에 마지막으로 할당된 값을 취합니다. 처리되지 않은 예외가 발생하면 실제 파라미터의 값은 호출 전 상태로 유지됩니다.
