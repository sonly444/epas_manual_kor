# 서브프로그램 변수 접근 (Accessing subprogram variables) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Subprograms › Accessing subprogram variables](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/07_subprograms_subprocedures_and_subfunctions/07_accessing_subprogram_variables/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 용어·코드는 원문 그대로 보존했습니다.

서브프로그램이나 익명 블록 같은 블록에 선언된 변수는, 다른 블록의 상대적 위치에 따라 그 블록의 실행 섹션이나 예외 섹션에서 접근할 수 있습니다.

변수에 접근한다는 것은, 임의의 지역 변수와 마찬가지로 SQL 문이나 SPL 문에서 그것을 참조할 수 있음을 의미합니다.

> **참고**
>
> 서브프로그램 시그니처에 형식 매개변수가 포함되어 있으면, 서브프로그램의 지역 변수와 동일한 방식으로 이들에 접근할 수 있습니다. 서브프로그램의 변수와 관련된 모든 논의는 서브프로그램의 형식 매개변수에도 적용됩니다.

변수 접근에는 데이터 타입으로 정의된 것뿐만 아니라 레코드 타입, 컬렉션 타입, 커서 같은 다른 것들도 포함됩니다.

변수에 접근하는 데는 최대 하나의 한정자를 사용할 수 있습니다. 한정자는 변수가 지역적으로 선언된 서브프로그램 또는 레이블이 붙은 익명 블록의 이름입니다.

## 구문

변수를 참조하는 구문은 다음과 같습니다.

```text
[<qualifier>.]<variable>
```

`qualifier`를 지정하는 경우, 이는 `variable`이 자신의 선언 섹션에서 선언된(즉, 지역 변수인) 서브프로그램 또는 레이블이 붙은 익명 블록입니다.

> **참고**
>
> EDB Postgres Advanced Server에서는 단 하나의 상황에서만 두 개의 한정자가 허용됩니다. 이 시나리오는 패키지의 공개(public) 변수에 접근하는 경우로, 다음 형식으로 참조를 지정할 수 있습니다.
>
> ```text
> schema_name.package_name.public_variable_name
> ```
>
> 지원되는 패키지 구문에 대한 자세한 내용은 [Built-in packages](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/)를 참조하십시오.

## 요구 사항

다음과 같은 방식으로 변수에 접근할 수 있습니다.

- 변수가 지역적으로 선언된 블록이, 변수에 대한 참조를 포함하는 블록에서 시작하는 조상 계층 경로 상에 있는 한 그 변수에 접근할 수 있습니다. 조상 블록에 선언된 이러한 변수를 _전역 변수(global variables)_ 라고 합니다.
- 비한정 변수에 대한 참조가 이루어지면, 먼저 해당 이름의 지역 변수를 찾으려고 시도합니다. 그러한 지역 변수가 존재하지 않으면, 현재 블록의 부모에서 변수를 검색하고, 이런 식으로 조상 계층 위쪽으로 진행합니다. 그러한 변수가 발견되지 않으면 서브프로그램을 호출할 때 오류가 발생합니다.
- 한정된 변수에 대한 참조가 이루어지면, 지역 변수를 포함하는 서브프로그램이나 레이블이 붙은 익명 블록의 첫 번째 일치를 검색하는 것을 제외하면 동일한 검색 과정이 수행됩니다. 검색은 일치가 발견될 때까지 조상 계층 위쪽으로 진행합니다. 그러한 일치가 발견되지 않으면 서브프로그램을 호출할 때 오류가 발생합니다.

변수에 대한 참조가 이루어지는 블록을 기준으로 다음과 같은 위치의 변수에는 접근할 수 없습니다.

- 후손 블록에 선언된 변수
- 형제 블록, 조상 블록의 형제 블록, 또는 형제 블록 내의 임의의 후손에 선언된 변수

> **참고**
>
> EDB Postgres Advanced Server의 변수 접근 방식은 Oracle 데이터베이스와 호환되지 않습니다. Oracle의 경우, 임의의 개수의 한정자를 지정할 수 있으며, 검색은 서브프로그램 호출에 대한 Oracle의 일치 알고리즘과 유사한 방식으로 첫 번째 한정자의 첫 번째 일치를 기반으로 합니다.

## 동일한 이름의 변수 접근

이 예제는 모든 블록의 모든 변수가 동일한 이름을 가질 때의 유사한 접근 시도를 보여 줍니다.

```sql
CREATE OR REPLACE PROCEDURE level_0
IS
    v_common        VARCHAR2(20) := 'Value from level_0';
    PROCEDURE level_1a
    IS
        v_common    VARCHAR2(20) := 'Value from level_1a';
        PROCEDURE level_2a
        IS
            v_common    VARCHAR2(20) := 'Value from level_2a';
        BEGIN
            DBMS_OUTPUT.PUT_LINE('...... BLOCK level_2a');
            DBMS_OUTPUT.PUT_LINE('........ v_common: ' || v_common);
            DBMS_OUTPUT.PUT_LINE('........ level_2a.v_common: ' || level_2a.v_common);
            DBMS_OUTPUT.PUT_LINE('........ level_1a.v_common: ' || level_1a.v_common);
            DBMS_OUTPUT.PUT_LINE('........ level_0.v_common: ' || level_0.v_common);
            DBMS_OUTPUT.PUT_LINE('...... END BLOCK level_2a');
        END level_2a;
    BEGIN
        DBMS_OUTPUT.PUT_LINE('.. BLOCK level_1a');
        DBMS_OUTPUT.PUT_LINE('.... v_common: ' || v_common);
        DBMS_OUTPUT.PUT_LINE('.... level_0.v_common: ' || level_0.v_common);
        level_2a;
        DBMS_OUTPUT.PUT_LINE('.. END BLOCK level_1a');
    END level_1a;
    PROCEDURE level_1b
    IS
        v_common    VARCHAR2(20) := 'Value from level_1b';
    BEGIN
        DBMS_OUTPUT.PUT_LINE('.. BLOCK level_1b');
        DBMS_OUTPUT.PUT_LINE('.... v_common: ' || v_common);
        DBMS_OUTPUT.PUT_LINE('.... level_0.v_common : ' || level_0.v_common);
        DBMS_OUTPUT.PUT_LINE('.. END BLOCK level_1b');
    END level_1b;
BEGIN
    DBMS_OUTPUT.PUT_LINE('BLOCK level_0');
    DBMS_OUTPUT.PUT_LINE('.. v_common: ' || v_common);
    level_1a;
    level_1b;
    DBMS_OUTPUT.PUT_LINE('END BLOCK level_0');
END level_0;
```

프로시저를 호출할 때 각 변수의 내용을 보여 주는 출력은 다음과 같습니다.

```sql
BEGIN
    level_0;
END;
```

Output

```text
BLOCK level_0
.. v_common: Value from level_0
.. BLOCK level_1a
.... v_common: Value from level_1a
.... level_0.v_common: Value from level_0
...... BLOCK level_2a
........ v_common: Value from level_2a
........ level_2a.v_common: Value from level_2a
........ level_1a.v_common: Value from level_1a
........ level_0.v_common: Value from level_0
...... END BLOCK level_2a
.. END BLOCK level_1a
.. BLOCK level_1b
.... v_common: Value from level_1b
.... level_0.v_common : Value from level_0
.. END BLOCK level_1b
END BLOCK level_0
```

## 레이블을 사용하여 변수 접근 한정하기

익명 블록의 레이블을 사용하여 변수 접근을 한정할 수도 있습니다. 이 예제는 중첩된 익명 블록 집합에서의 변수 접근을 보여 줍니다.

```sql
DECLARE
    v_common        VARCHAR2(20) := 'Value from level_0';
BEGIN
    DBMS_OUTPUT.PUT_LINE('BLOCK level_0');
    DBMS_OUTPUT.PUT_LINE('.. v_common: ' || v_common);
    <<level_1a>>
    DECLARE
        v_common    VARCHAR2(20) := 'Value from level_1a';
    BEGIN
        DBMS_OUTPUT.PUT_LINE('.. BLOCK level_1a');
        DBMS_OUTPUT.PUT_LINE('.... v_common: ' || v_common);
        <<level_2a>>
        DECLARE
            v_common    VARCHAR2(20) := 'Value from level_2a';
        BEGIN
            DBMS_OUTPUT.PUT_LINE('...... BLOCK level_2a');
            DBMS_OUTPUT.PUT_LINE('........ v_common: ' || v_common);
            DBMS_OUTPUT.PUT_LINE('........ level_1a.v_common: ' || level_1a.v_common);
            DBMS_OUTPUT.PUT_LINE('...... END BLOCK level_2a');
        END;
        DBMS_OUTPUT.PUT_LINE('.. END BLOCK level_1a');
    END;
    <<level_1b>>
    DECLARE
        v_common    VARCHAR2(20) := 'Value from level_1b';
    BEGIN
        DBMS_OUTPUT.PUT_LINE('.. BLOCK level_1b');
        DBMS_OUTPUT.PUT_LINE('.... v_common: ' || v_common);
        DBMS_OUTPUT.PUT_LINE('.... level_1b.v_common: ' || level_1b.v_common);
        DBMS_OUTPUT.PUT_LINE('.. END BLOCK level_1b');
    END;
    DBMS_OUTPUT.PUT_LINE('END BLOCK level_0');
END;
```

익명 블록을 호출할 때 각 변수의 내용을 보여 주는 출력은 다음과 같습니다.

Output

```text
BLOCK level_0
.. v_common: Value from level_0
.. BLOCK level_1a
.... v_common: Value from level_1a
...... BLOCK level_2a
........ v_common: Value from level_2a
........ level_1a.v_common: Value from level_1a
...... END BLOCK level_2a
.. END BLOCK level_1a
.. BLOCK level_1b
.... v_common: Value from level_1b
.... level_1b.v_common: Value from level_1b
.. END BLOCK level_1b
END BLOCK level_0
```

## 예제

### 예제: 부모 블록의 레코드 타입 접근

이 예제는 오브젝트 타입으로, 그 오브젝트 타입 메서드 `display_emp`에 레코드 타입 `emp_typ`과 서브프로시저 `emp_sal_query`가 포함되어 있습니다. `emp_sal_query`에 지역적으로 선언된 레코드 변수 `r_emp`는 부모 블록 `display_emp`에 선언된 레코드 타입 `emp_typ`에 접근할 수 있습니다.

```sql
CREATE OR REPLACE TYPE emp_pay_obj_typ AS OBJECT
(
    empno           NUMBER(4),
    MEMBER PROCEDURE display_emp(SELF IN OUT emp_pay_obj_typ)
);

CREATE OR REPLACE TYPE BODY emp_pay_obj_typ AS
    MEMBER PROCEDURE display_emp (SELF IN OUT emp_pay_obj_typ)
    IS
        TYPE emp_typ IS RECORD (
            ename           emp.ename%TYPE,
            job             emp.job%TYPE,
            hiredate        emp.hiredate%TYPE,
            sal             emp.sal%TYPE,
            deptno          emp.deptno%TYPE
         );
        PROCEDURE emp_sal_query (
            p_empno         IN emp.empno%TYPE
        )
        IS
            r_emp           emp_typ;
            v_avgsal        emp.sal%TYPE;
        BEGIN
            SELECT ename, job, hiredate, sal, deptno
                INTO r_emp.ename, r_emp.job, r_emp.hiredate, r_emp.sal, r_emp.deptno
                FROM emp WHERE empno = p_empno;
            DBMS_OUTPUT.PUT_LINE('Employee # : ' || p_empno);
            DBMS_OUTPUT.PUT_LINE('Name       : ' || r_emp.ename);
            DBMS_OUTPUT.PUT_LINE('Job        : ' || r_emp.job);
            DBMS_OUTPUT.PUT_LINE('Hire Date  : ' || r_emp.hiredate);
            DBMS_OUTPUT.PUT_LINE('Salary     : ' || r_emp.sal);
            DBMS_OUTPUT.PUT_LINE('Dept #     : ' || r_emp.deptno);

            SELECT AVG(sal) INTO v_avgsal
            FROM emp WHERE deptno = r_emp.deptno;
            IF r_emp.sal > v_avgsal THEN
                DBMS_OUTPUT.PUT_LINE('Employee''s salary is more than the '
                    || 'department average of ' || v_avgsal);
            ELSE
                DBMS_OUTPUT.PUT_LINE('Employee''s salary does not exceed the '
                    || 'department average of ' || v_avgsal);
            END IF;
        END;
    BEGIN
        emp_sal_query(SELF.empno);
    END;
END;
```

오브젝트 타입의 인스턴스를 생성하고 프로시저 `display_emp`를 호출할 때 표시되는 출력은 다음과 같습니다.

```sql
DECLARE
    v_emp          EMP_PAY_OBJ_TYP;
BEGIN
    v_emp := emp_pay_obj_typ(7900);
    v_emp.display_emp;
END;
```

Output

```text
Employee # : 7900
Name       : JAMES
Job        : CLERK
Hire Date  : 03-DEC-81 00:00:00
Salary     : 950.00
Dept #     : 30
Employee's salary does not exceed the department average of 1566.67
```

### 예제: 상위 레벨 프로시저 접근

이 예제는 세 레벨의 서브프로시저를 가진 패키지입니다. 상위 레벨 프로시저에 선언된 레코드 타입, 컬렉션 타입, 커서 타입은 후손 서브프로시저에서 접근할 수 있습니다.

```sql
CREATE OR REPLACE PACKAGE emp_dept_pkg
IS
    PROCEDURE display_emp (
        p_deptno        NUMBER
    );
END;

CREATE OR REPLACE PACKAGE BODY emp_dept_pkg
IS
    PROCEDURE display_emp (
        p_deptno        NUMBER
    )
    IS
        TYPE emp_rec_typ IS RECORD (
            empno           emp.empno%TYPE,
            ename           emp.ename%TYPE
        );
        TYPE emp_arr_typ IS TABLE OF emp_rec_typ INDEX BY BINARY_INTEGER;
        TYPE emp_cur_type IS REF CURSOR RETURN emp_rec_typ;
        PROCEDURE emp_by_dept (
            p_deptno        emp.deptno%TYPE
        )
        IS
            emp_arr         emp_arr_typ;
            emp_refcur      emp_cur_type;
            i               BINARY_INTEGER := 0;
            PROCEDURE display_emp_arr
            IS
            BEGIN
                DBMS_OUTPUT.PUT_LINE('EMPNO    ENAME');
                DBMS_OUTPUT.PUT_LINE('-----    -------');
                FOR j IN emp_arr.FIRST .. emp_arr.LAST LOOP
                    DBMS_OUTPUT.PUT_LINE(emp_arr(j).empno || '     ' ||
                        emp_arr(j).ename);
                END LOOP;
            END display_emp_arr;
        BEGIN
            OPEN emp_refcur FOR SELECT empno, ename FROM emp WHERE deptno = p_deptno;
            LOOP
                i := i + 1;
                FETCH emp_refcur INTO emp_arr(i).empno, emp_arr(i).ename;
                EXIT WHEN emp_refcur%NOTFOUND;
            END LOOP;
            CLOSE emp_refcur;
            display_emp_arr;
        END emp_by_dept;
    BEGIN
        emp_by_dept(p_deptno);
    END;
END;
```

최상위 레벨 패키지 프로시저를 호출할 때 표시되는 출력은 다음과 같습니다.

```sql
BEGIN
    emp_dept_pkg.display_emp(20);
END;
```

Output

```text
EMPNO    ENAME
-----    -------
7369     SMITH
7566     JONES
7788     SCOTT
7876     ADAMS
7902     FORD
```

### 예제: 블록의 변수 접근

이 예제는 다양한 블록의 변수를 한정자를 사용하거나 사용하지 않고 접근하는 방법을 보여 줍니다. 주석 처리된 라인은 오류를 발생시키는 변수 접근 시도를 보여 줍니다.

```sql
CREATE OR REPLACE PROCEDURE level_0
IS
    v_level_0       VARCHAR2(20) := 'Value from level_0';
    PROCEDURE level_1a
    IS
        v_level_1a  VARCHAR2(20) := 'Value from level_1a';
        PROCEDURE level_2a
        IS
            v_level_2a      VARCHAR2(20) := 'Value from level_2a';
        BEGIN
            DBMS_OUTPUT.PUT_LINE('...... BLOCK level_2a');
            DBMS_OUTPUT.PUT_LINE('........ v_level_2a: ' || v_level_2a);
            DBMS_OUTPUT.PUT_LINE('........ v_level_1a: ' || v_level_1a);
            DBMS_OUTPUT.PUT_LINE('........ level_1a.v_level_1a: ' || level_1a.v_level_1a);
            DBMS_OUTPUT.PUT_LINE('........ v_level_0: ' || v_level_0);
            DBMS_OUTPUT.PUT_LINE('........ level_0.v_level_0: ' || level_0.v_level_0);
            DBMS_OUTPUT.PUT_LINE('...... END BLOCK level_2a');
        END level_2a;
    BEGIN
        DBMS_OUTPUT.PUT_LINE('.. BLOCK level_1a');
        level_2a;
--        DBMS_OUTPUT.PUT_LINE('.... v_level_2a: ' || v_level_2a);
--                              Error - Descendent block ----^
--        DBMS_OUTPUT.PUT_LINE('.... level_2a.v_level_2a: ' || level_2a.v_level_2a);
--                              Error - Descendent block ---------------^
        DBMS_OUTPUT.PUT_LINE('.. END BLOCK level_1a');
    END level_1a;
    PROCEDURE level_1b
    IS
        v_level_1b  VARCHAR2(20) := 'Value from level_1b';
    BEGIN
        DBMS_OUTPUT.PUT_LINE('.. BLOCK level_1b');
        DBMS_OUTPUT.PUT_LINE('.... v_level_1b: ' || v_level_1b);
        DBMS_OUTPUT.PUT_LINE('.... v_level_0 : ' || v_level_0);
--        DBMS_OUTPUT.PUT_LINE('.... level_1a.v_level_1a: ' || level_1a.v_level_1a);
--                               Error - Sibling block -----------------^
--        DBMS_OUTPUT.PUT_LINE('.... level_2a.v_level_2a: ' || level_2a.v_level_2a);
--                               Error - Sibling block descendant ------^
        DBMS_OUTPUT.PUT_LINE('.. END BLOCK level_1b');
    END level_1b;
BEGIN
    DBMS_OUTPUT.PUT_LINE('BLOCK level_0');
    DBMS_OUTPUT.PUT_LINE('.. v_level_0: ' || v_level_0);
    level_1a;
    level_1b;
    DBMS_OUTPUT.PUT_LINE('END BLOCK level_0');
END level_0;
```

프로시저를 호출할 때 각 변수의 내용을 보여 주는 출력은 다음과 같습니다.

```sql
BEGIN
    level_0;
END;
```

Output

```text
BLOCK level_0
.. v_level_0: Value from level_0
.. BLOCK level_1a
...... BLOCK level_2a
........ v_level_2a: Value from level_2a
........ v_level_1a: Value from level_1a
........ level_1a.v_level_1a: Value from level_1a
........ v_level_0: Value from level_0
........ level_0.v_level_0: Value from level_0
...... END BLOCK level_2a
.. END BLOCK level_1a
.. BLOCK level_1b
.... v_level_1b: Value from level_1b
.... v_level_0 : Value from level_0
.. END BLOCK level_1b
END BLOCK level_0
```
