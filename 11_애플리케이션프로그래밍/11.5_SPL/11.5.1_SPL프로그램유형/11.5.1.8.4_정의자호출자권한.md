# 정의자 권한과 호출자 권한에 대하여 (About definer and invoker rights) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Program security › About definer and invoker rights](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/02_spl_programs/09_program_security/04_definers_vs_invokers_rights/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·절 이름은 원문 그대로 보존했습니다.

SPL 프로그램이 실행을 막 시작하려 할 때, 이 프로세스와 연결할 사용자가 결정됩니다. 이 사용자를 _현재 사용자(current user)_ 라고 합니다. 현재 사용자의 데이터베이스 객체 권한은 프로그램에서 참조된 데이터베이스 객체에 대한 접근이 허용되는지 판단하는 데 사용됩니다. 프로그램이 호출될 때 유효한 현재 검색 경로(search path)는 정규화되지 않은 객체 참조를 해석하는 데 사용됩니다.

현재 사용자의 선택은 SPL 프로그램이 정의자 권한(definer's rights)으로 생성되었는지 호출자 권한(invoker's rights)으로 생성되었는지에 따라 달라집니다. `AUTHID` 절이 그 선택을 결정합니다. `AUTHID DEFINER` 절이 나타나면 프로그램에 정의자 권한이 부여됩니다. 이는 `AUTHID` 절을 생략한 경우의 기본값이기도 합니다. `AUTHID CURRENT_USER` 절을 사용하면 프로그램에 호출자 권한이 부여됩니다. 둘의 차이는 다음과 같이 요약됩니다.

- 프로그램이 _정의자 권한(definer's rights)_ 을 가지면, 프로그램 실행이 시작될 때 프로그램의 소유자가 현재 사용자가 됩니다. 참조된 객체에 대한 접근이 허용되는지 판단하는 데 프로그램 소유자의 데이터베이스 객체 권한이 사용됩니다. 정의자 권한 프로그램에서는 실제로 프로그램을 호출한 사용자는 무관합니다.
- 프로그램이 _호출자 권한(invoker's rights)_ 을 가지면, 프로그램(반드시 하위 프로그램은 아님)이 실행되는 동안 프로그램이 호출된 시점의 현재 사용자가 그대로 현재 사용자로 유지됩니다. 호출자 권한 프로그램이 호출될 때, 현재 사용자는 일반적으로 세션을 시작한(데이터베이스 연결을 만든) 사용자입니다. 세션이 시작된 후에 `SET ROLE` 명령을 사용하여 현재 사용자를 변경할 수 있습니다. 호출자 권한 프로그램에서는 실제로 프로그램을 누가 소유하는지는 무관합니다.

앞의 정의로부터 다음과 같은 사항을 알 수 있습니다.

- 정의자 권한 프로그램이 정의자 권한 프로그램을 호출하면, 호출된 프로그램이 실행되는 동안 현재 사용자가 호출하는 프로그램의 소유자에서 호출되는 프로그램의 소유자로 변경됩니다.
- 정의자 권한 프로그램이 호출자 권한 프로그램을 호출하면, 호출하는 프로그램과 호출되는 프로그램이 모두 실행되는 동안 호출하는 프로그램의 소유자가 현재 사용자로 유지됩니다.
- 호출자 권한 프로그램이 호출자 권한 프로그램을 호출하면, 호출되는 프로그램이 실행되는 동안 호출하는 프로그램의 현재 사용자가 그대로 현재 사용자로 유지됩니다.
- 호출자 권한 프로그램이 정의자 권한 프로그램을 호출하면, 호출되는 프로그램이 실행되는 동안 현재 사용자가 정의자 권한 프로그램의 소유자로 전환됩니다.

이러한 경우에서 호출된 프로그램이 다시 또 다른 프로그램을 호출하더라도 동일한 원칙이 적용됩니다.
