# 객체 타입 삭제 (Dropping an object type) — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Dropping an object type](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/06_dropping_an_object_type/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·키워드는 원문 그대로 보존했습니다.

## 객체 타입 삭제 (Deleting an object type)

객체 타입을 삭제하는 구문은 다음과 같습니다.

```sql
DROP TYPE <objtype>;
```

여기서 `objtype`은 삭제할 객체 타입의 식별자입니다. `objtype`의 정의에 그 자체가 객체 타입이거나 컬렉션 타입(collection type)인 속성이 포함되어 있으면 이러한 중첩된 객체 타입이나 컬렉션 타입을 마지막에 삭제해야 합니다.

객체 타입에 객체 타입 본문(object type body)이 정의되어 있으면 `DROP TYPE` 명령은 객체 타입 명세(object-type specification)뿐 아니라 객체 타입 본문도 삭제합니다. 전체 객체 타입을 다시 생성하려면 `CREATE TYPE` 및 `CREATE TYPE BODY` 명령을 모두 다시 실행해야 합니다.

이 예제는 `emp_obj_typ`와 `addr_obj_typ` 객체 타입을 삭제합니다. `emp_obj_typ`는 정의에 `addr_obj_typ`를 속성으로 포함하므로 `emp_obj_typ`를 먼저 삭제해야 합니다.

```sql
DROP TYPE emp_obj_typ;
DROP TYPE addr_obj_typ;
```

## 객체 타입 본문만 삭제 (Dropping only the object type body)

객체 타입 명세는 삭제하지 않고 객체 타입 본문만 삭제하는 구문은 다음과 같습니다.

```sql
DROP TYPE BODY <objtype>;
```

`CREATE TYPE BODY` 명령을 실행하여 객체 타입 본문을 다시 생성할 수 있습니다.

이 예제는 `dept_obj_typ`의 객체 타입 본문만 삭제합니다.

```sql
DROP TYPE BODY dept_obj_typ;
```
