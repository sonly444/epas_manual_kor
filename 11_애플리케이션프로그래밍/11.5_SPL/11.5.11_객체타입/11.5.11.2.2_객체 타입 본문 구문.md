# Object type body syntax — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Object type components › Object type body syntax](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/02_object_type_components/02_object_type_body_syntax/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

객체 타입 본문(object type body)의 구문은 다음과 같습니다.

```sql
CREATE [ OR REPLACE ] TYPE BODY <name>
  { IS | AS }
  <method_spec> [...]
  [<constructor>] [...]
END;
```

여기서 `method_spec`은 `subprogram_spec`이며, `subprogram_spec`은 다음과 같습니다.

```sql
{ MEMBER | STATIC }
{ PROCEDURE <proc_name>
    [ ( [  SELF [ IN | IN OUT ] <name> ]\
        [, <parm1> [ IN | IN OUT | OUT ] <datatype1>\
                 [ DEFAULT <value1> ] ]\
        [, <parm2> [ IN | IN OUT | OUT ] <datatype2>\
                 [ DEFAULT <value2> ]\
        ] ...)\
    ]
{ IS | AS }
  [ PRAGMA AUTONOMOUS_TRANSACTION; ]
  [ <declarations> ]
  BEGIN
    <statement>; ...
[ EXCEPTION\
    WHEN ... THEN\
      <statement>; ...]
  END;
|
  FUNCTION <func_name>
    [ ( [  SELF [ IN | IN OUT ] <name> ]\
        [, <parm1> [ IN | IN OUT | OUT ] <datatype1>\
                 [ DEFAULT <value1> ] ]\
        [, <parm2> [ IN | IN OUT | OUT ] <datatype2>\
                 [ DEFAULT <value2> ]\
        ] ...)\
    ]
  RETURN <return_type>
{ IS | AS }
  [ PRAGMA AUTONOMOUS_TRANSACTION; ]
  [ <declarations> ]
  BEGIN
    <statement>; ...
[ EXCEPTION\
    WHEN ... THEN\
      <statement>; ...]
  END;
```

여기서 `constructor`는 다음과 같습니다.

```sql
CONSTRUCTOR FUNCTION <func_name>
  [ ( [ <parm1> [ IN | IN OUT | OUT ] <datatype1>\
               [ DEFAULT <value1> ] ]\
      [, <parm2> [ IN | IN OUT | OUT ] <datatype2>\
               [ DEFAULT <value2> ]\
      ] ...)\
  ]
RETURN <return_type>;
{ IS | AS }
[ <declarations> ]
BEGIN
  <statement>; ...
[ EXCEPTION\
  WHEN ... THEN\
    <statement>; ...]
END;
```

여기서:

`name`은 객체 타입에 할당된 식별자(선택적으로 스키마로 한정 가능)입니다.

`method_spec`은 `CREATE TYPE` 명령에서 지정된, 인스턴스화 가능한(instantiable) 메서드의 구현을 나타냅니다.

`CREATE TYPE` 명령의 `method_spec`에서 `INSTANTIABLE`이 지정되었거나 생략되었다면, `CREATE TYPE BODY` 명령에 이 메서드에 대한 `method_spec`이 반드시 있어야 합니다.

`CREATE TYPE` 명령의 `method_spec`에서 `NOT INSTANTIABLE`이 지정되었다면, `CREATE TYPE BODY` 명령에 이 메서드에 대한 `method_spec`이 있어서는 안 됩니다.

`subprogram_spec`은 프로시저 또는 함수의 명세를 나타내며 `MEMBER` 또는 `STATIC` 중 하나의 지정으로 시작합니다. `CREATE TYPE` 명령의 `subprogram_spec`에서 지정된 것과 동일한 한정자를 사용해야 합니다.

`proc_name`은 `CREATE TYPE` 명령에서 지정된 프로시저의 식별자입니다. 매개변수 선언은 `CREATE TYPE` 명령에서 설명한 것과 동일한 의미를 가집니다. 매개변수 선언은 `CREATE TYPE BODY` 명령에서 `CREATE TYPE` 명령에서와 동일한 방식으로 지정되어야 합니다.

생성자 함수를 정의하려면 `CONSTRUCTOR FUNCTION` 키워드와 함수 정의를 포함하십시오.

`func_name`은 `CREATE TYPE` 명령에서 지정된 함수의 식별자입니다. 매개변수 선언은 `CREATE TYPE` 명령에서 설명한 것과 동일한 의미를 가지며 `CREATE TYPE BODY` 명령에서 `CREATE TYPE` 명령에서와 동일한 방식으로 지정되어야 합니다. `return_type`은 함수가 반환하는 값의 데이터 타입이며 `CREATE TYPE` 명령에서 주어진 `return_type`과 일치해야 합니다.

`PRAGMA AUTONOMOUS_TRANSACTION`은 프로시저 또는 함수를 자율 트랜잭션(autonomous transaction)으로 설정하는 지시어(directive)입니다.

`declarations`는 변수, 커서, 타입 또는 서브프로그램 선언입니다. 서브프로그램 선언이 포함되는 경우, 이는 다른 모든 변수, 커서, 타입 선언 뒤에 선언되어야 합니다.

`statement`는 SPL 프로그램 문(statement)입니다.
