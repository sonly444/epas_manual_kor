# 객체 참조 (Referencing an object) — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Referencing an object](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/05_referencing_an_object/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 구문·코드는 원문 그대로 보존했습니다.

## 구문 (Syntax)

객체 변수를 생성하고 초기화한 후에는 다음 형식의 점 표기법(dot notation)을 사용하여 개별 속성을 참조할 수 있습니다.

```text
<object>.<attribute>
```

여기서:

`object`는 객체 변수에 할당된 식별자입니다.

`attribute`는 객체 타입 속성의 식별자입니다.

`attribute`가 객체 타입인 경우 참조는 다음 형식을 따라야 합니다.

```text
<object>.<attribute>.<attribute_inner>
```

여기서 `attribute_inner`는 `object`의 정의에서 `attribute`가 참조하는 객체 타입에 속하는 식별자입니다.

## 예제 (Examples)

이 예제는 `emp_obj_typ` 객체에 할당된 값을 표시합니다.

```sql
DECLARE
    v_emp          EMP_OBJ_TYP;
BEGIN
    v_emp := emp_obj_typ(9001,'JONES',
        addr_obj_typ('123 MAIN STREET','EDISON','NJ',08817));
    DBMS_OUTPUT.PUT_LINE('Employee No   : ' || v_emp.empno);
    DBMS_OUTPUT.PUT_LINE('Name          : ' || v_emp.ename);
    DBMS_OUTPUT.PUT_LINE('Street        : ' || v_emp.addr.street);
    DBMS_OUTPUT.PUT_LINE('City/State/Zip: ' || v_emp.addr.city || ', ' ||
        v_emp.addr.state || ' ' || LPAD(v_emp.addr.zip,5,'0'));
END;
```

다음은 이 익명 블록의 출력입니다.

출력(Output)

```text
Employee No   : 9001
Name          : JONES
Street        : 123 MAIN STREET
City/State/Zip: EDISON, NJ 08817
```

메서드는 속성과 유사한 방식으로 호출됩니다.

객체 변수를 생성하고 초기화한 후에는 다음 형식의 점 표기법을 사용하여 멤버 프로시저 또는 함수를 호출합니다.

```text
<object>.<prog_name>
```

여기서:

`object`는 객체 변수에 할당된 식별자입니다.

`prog_name`은 프로시저 또는 함수의 식별자입니다.

정적(static) 프로시저 또는 함수는 객체 변수를 사용하여 호출하지 않습니다. 대신 객체 타입 이름을 사용하여 프로시저 또는 함수를 호출합니다.

```text
<object_type>.<prog_name>
```

여기서:

`object_type`은 객체 타입에 할당된 식별자입니다.

`prog_name`은 프로시저 또는 함수의 식별자입니다.

멤버 프로시저 `display_emp`를 호출하여 앞선 익명 블록의 결과를 동일하게 재현할 수 있습니다.

```sql
DECLARE
    v_emp          EMP_OBJ_TYP;
BEGIN
    v_emp := emp_obj_typ(9001,'JONES',
        addr_obj_typ('123 MAIN STREET','EDISON','NJ',08817));
    v_emp.display_emp;
END;
```

다음은 이 익명 블록의 출력입니다.

출력(Output)

```text
Employee No   : 9001
Name          : JONES
Street        : 123 MAIN STREET
City/State/Zip: EDISON, NJ 08817
```

이 익명 블록은 `dept_obj_typ`의 인스턴스를 생성하고 멤버 프로시저 `display_dept`를 호출합니다.

```sql
DECLARE
    v_dept          DEPT_OBJ_TYP := dept_obj_typ (20);
BEGIN
    v_dept.display_dept;
END;
```

다음은 이 익명 블록의 출력입니다.

출력(Output)

```text
Dept No    : 20
Dept Name  : RESEARCH
```

다음과 같이 객체 타입 이름으로 한정하여 `dept_obj_typ`에 정의된 정적 함수를 직접 호출할 수 있습니다.

```sql
BEGIN
    DBMS_OUTPUT.PUT_LINE(dept_obj_typ.get_dname(20));
END;

RESEARCH
```
