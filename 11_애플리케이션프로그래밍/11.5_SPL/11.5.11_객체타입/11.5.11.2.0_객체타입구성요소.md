# 객체 타입 구성 요소 (Object type components) — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Object type components](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/02_object_type_components/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 용어·명령은 원문 그대로 보존했습니다.

객체 타입은 SPL 언어의 다음 두 가지 구성 요소(construct)를 사용하여 데이터베이스에 생성되고 저장됩니다.

- _객체 타입 명세(object type specification)_. 이 구성 요소는 객체 타입의 속성과 메서드 시그니처(method signature)를 지정하는 공개 인터페이스(public interface)입니다.
- _객체 타입 본문(object type body)_. 이 구성 요소는 객체 타입 명세에 지정된 메서드의 구현(implementation)을 포함합니다.
