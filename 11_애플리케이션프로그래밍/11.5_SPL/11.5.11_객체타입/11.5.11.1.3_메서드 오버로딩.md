# Overloading methods — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Basic object concepts › Overloading methods](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/01_basic_object_concepts/03_overloading_methods/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

객체 타입 안에서는 이름이 동일하고 유형(즉, 프로시저 또는 함수)도 같지만 시그니처(signature)가 서로 다른 둘 이상의 메서드를 정의할 수 있습니다. 이러한 메서드를 _오버로드된(overloaded)_ 메서드라고 합니다.

메서드의 시그니처는 형식 매개변수(formal parameter)의 개수, 형식 매개변수의 데이터 타입, 그리고 그것들의 순서로 구성됩니다.
