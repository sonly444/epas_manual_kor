# Methods — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Basic object concepts › Methods](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/01_basic_object_concepts/02_methods/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

메서드(method)는 객체 타입 안에 정의된 SPL 프로시저 또는 함수입니다. 메서드는 세 가지 일반적인 유형으로 분류됩니다.

- **멤버 메서드 (Member methods)** — 객체 인스턴스의 컨텍스트 안에서 동작하는 프로시저 또는 함수입니다. 멤버 메서드는 자신이 동작하고 있는 객체 인스턴스의 속성에 접근할 수 있으며 이를 변경할 수 있습니다.
- **정적 메서드 (Static methods)** — 특정 객체 인스턴스와 무관하게 독립적으로 동작하는 프로시저 또는 함수입니다. 정적 메서드는 객체 인스턴스의 속성에 접근할 수 없으며 이를 변경할 수도 없습니다.
- **생성자 메서드 (Constructor methods)** — 객체 타입의 인스턴스를 생성하는 데 사용되는 함수입니다. 객체 타입이 정의될 때 기본 생성자 메서드가 항상 제공됩니다.
