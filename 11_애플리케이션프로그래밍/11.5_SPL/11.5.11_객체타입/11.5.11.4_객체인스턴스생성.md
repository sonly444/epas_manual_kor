# 객체 인스턴스 생성 (Creating object instances) — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Creating object instances](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/04_creating_object_instances/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·키워드·코드는 원문 그대로 보존했습니다.

## 인스턴스 생성 (Creating an instance)

객체 타입의 인스턴스를 만들려면 먼저 객체 타입의 변수를 선언한 다음 선언한 객체 변수를 초기화해야 합니다. 객체 변수를 선언하는 구문은 다음과 같습니다.

```text
<object> <obj_type>
```

여기서:

`object`는 객체 변수에 할당된 식별자입니다.

`obj_type`은 이전에 정의된 객체 타입의 식별자입니다.

## 생성자 메서드 호출 (Invoking a constructor method)

객체 변수를 선언한 후에는 _생성자 메서드(constructor method)_ 를 호출하여 객체를 값으로 초기화해야 합니다. 생성자 메서드를 호출하려면 다음 구문을 사용합니다.

```sql
[NEW] <obj_type> ({<expr1> | NULL} [, {<expr2> | NULL} ] [, ...])
```

여기서:

`obj_type`은 객체 타입의 생성자 메서드 식별자입니다. 생성자 메서드는 이전에 선언된 객체 타입과 이름이 같습니다.

`expr1, expr2, …`는 객체 타입의 첫 번째 속성, 두 번째 속성 등과 타입 호환되는(type-compatible) 표현식입니다. 속성이 객체 타입인 경우 해당 표현식은 `NULL`, 객체 초기화 표현식, 또는 그 객체 타입을 반환하는 임의의 표현식이 될 수 있습니다.

이 익명 블록은 변수를 선언하고 초기화합니다.

```sql
DECLARE
    v_emp           EMP_OBJ_TYP;
BEGIN
    v_emp := emp_obj_typ (9001,'JONES',
        addr_obj_typ('123 MAIN STREET','EDISON','NJ',08817));
END;
```

변수 `v_emp`는 이전에 정의된 `EMP_OBJ_TYPE`이라는 객체 타입으로 선언됩니다. 블록의 본문은 `emp_obj_typ` 및 `addr_obj_type` 생성자를 사용하여 변수를 초기화합니다.

블록 본문에서 객체의 새 인스턴스를 만들 때 `NEW` 키워드를 포함할 수 있습니다. `NEW` 키워드는 제공된 인자와 시그니처가 일치하는 객체 생성자를 호출합니다.

## 예제 (Example)

이 예제는 `mgr`과 `emp`라는 두 변수를 선언합니다. 두 변수는 모두 `EMP_OBJ_TYPE`입니다. `mgr` 객체는 선언에서 초기화되고, `emp` 객체는 선언에서 `NULL`로 초기화된 다음 본문에서 값이 할당됩니다.

```sql
DECLARE
    mgr  EMP_OBJ_TYPE := (9002,'SMITH');
    emp  EMP_OBJ_TYPE;
BEGIN
    emp := NEW EMP_OBJ_TYPE (9003,'RAY');
END;
```

##### 참고

EDB Postgres Advanced Server에서는 생성자 메서드 대신 다음 대체 구문을 사용할 수 있습니다.

```sql
[ ROW ] ({ <expr1> | NULL } [, { <expr2> | NULL } ] [, ...])
```

괄호로 둘러싸고 쉼표로 구분된 목록에 둘 이상의 항목이 지정된 경우 `ROW`는 선택적 키워드입니다. 항목을 하나만 지정하는 경우에는 `ROW` 키워드를 지정해야 합니다.
