# Constructor methods — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Creating object types › Constructor methods](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/03_creating_object_types/03_constructor_methods/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

생성자 메서드(constructor method)는 객체 타입의 인스턴스를 생성하는 함수로, 일반적으로 객체의 멤버들에게 값을 할당함으로써 이를 수행합니다. 하나의 객체 타입은 서로 다른 작업을 수행하기 위해 여러 개의 생성자를 정의할 수 있습니다. 생성자 메서드는 이름이 타입의 이름과 일치하는 `SELF` 매개변수를 사용하여 호출되는 멤버 함수입니다.

예를 들어, `address`라는 이름의 타입을 정의하면 각 생성자의 이름은 `address`가 됩니다. 이름은 같지만 인수 타입이 다른 하나 이상의 생성자 함수를 생성함으로써 생성자를 오버로드(overload)할 수 있습니다.

SPL 컴파일러는 각 객체 타입에 대해 기본 생성자(default constructor)를 제공합니다. 기본 생성자는 이름이 타입의 이름과 일치하고 인수 목록이 타입 멤버들과 순서대로 일치하는 멤버 함수입니다. 예를 들어, 다음과 같은 객체 타입이 주어졌을 때:

```sql
CREATE TYPE address AS OBJECT
(
  street_address VARCHAR2(40),
  postal_code    VARCHAR2(10),
  city           VARCHAR2(40),
  state          VARCHAR2(2)
)
```

SPL 컴파일러는 다음과 같은 시그니처를 가진 기본 생성자를 제공합니다.

```sql
CONSTRUCTOR FUNCTION address
(
  street_address VARCHAR2(40),
  postal_code    VARCHAR2(10),
  city           VARCHAR2(40),
  state          VARCHAR2(2)
)
```

기본 생성자의 본문은 각 멤버를 `NULL`로 설정합니다.

사용자 정의 생성자(custom constructor)를 만들려면, constructor 키워드를 사용하여 `CREATE TYPE` 명령에서 생성자 함수를 선언하고, `CREATE TYPE BODY` 명령에서 생성 함수를 정의합니다. 예를 들어, `street_address`와 `postal_code`가 주어졌을 때 city와 state를 계산하는 `address` 타입의 사용자 정의 생성자를 만들고 싶을 수 있습니다.

```sql
CREATE TYPE address AS OBJECT
(
  street_address VARCHAR2(40),
  postal_code    VARCHAR2(10),
  city           VARCHAR2(40),
  state          VARCHAR2(2),

  CONSTRUCTOR FUNCTION address
   (
     street_address VARCHAR2,
     postal_code VARCHAR2
    ) RETURN self AS RESULT
)
CREATE TYPE BODY address AS
 CONSTRUCTOR FUNCTION address
  (
    street_address VARCHAR2,
    postal_code VARCHAR2
   ) RETURN self AS RESULT
 IS
   BEGIN
     self.street_address := street_address;
     self.postal_code := postal_code;
     self.city := postal_code_to_city(postal_code);
     self.state := postal_code_to_state(postal_code);
     RETURN;
   END;
END;
```

객체 타입의 인스턴스를 생성하려면, 그 타입의 생성자 메서드 중 하나를 호출합니다. 예를 들면 다음과 같습니다.

```sql
DECLARE
  cust_addr address := address('100 Main Street', 02203');
BEGIN
  DBMS_OUTPUT.PUT_LINE(cust_addr.city);  -- displays Boston
  DBMS_OUTPUT.PUT_LINE(cust_addr.state); -- displays MA
END;
```

사용자 정의 생성자 함수는 다음과 같은 용도로 사용됩니다.

- 불완전한 정보가 주어졌을 때 멤버 값을 계산하는 데 일반적으로 사용됩니다. 위 예제는 우편번호(postal code)가 주어졌을 때 `city`와 `state`의 값을 계산합니다.

- 객체의 상태를 제한하는 업무 규칙(business rule)을 강제하는 데에도 사용됩니다. 예를 들어, `payment`를 나타내는 객체 타입을 정의하는 경우, `amount`가 `NULL`이거나 음수이거나 0인 상태로는 `payment` 타입의 객체가 생성될 수 없도록 사용자 정의 생성자를 사용할 수 있습니다. 기본 생성자는 `payment.amount`를 `NULL`로 설정하므로, `NULL` 금액을 금지하려면 기본 생성자와 시그니처가 일치하는 사용자 정의 생성자를 생성해야 합니다.
