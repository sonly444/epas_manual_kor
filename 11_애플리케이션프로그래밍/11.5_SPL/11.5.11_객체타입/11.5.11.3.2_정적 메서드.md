# Static methods — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Creating object types › Static methods](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/03_creating_object_types/02_static_methods/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

멤버 메서드와 마찬가지로 정적 메서드(static method)도 하나의 타입에 속합니다. 그러나 정적 메서드는 타입의 인스턴스에 의해서가 아니라 타입의 이름을 사용하여 호출됩니다. 예를 들어, `emp_obj_type` 타입에 정의된 `get_count`라는 정적 함수를 호출하려면 다음과 같이 작성할 수 있습니다.

```sql
emp_obj_type.get_count();
```

정적 메서드는 객체 인스턴스의 속성에 접근할 수 없으며 이를 변경할 수도 없습니다. 정적 메서드는 일반적으로 타입의 인스턴스와 함께 동작하지 않습니다.

다음 객체 타입 명세는 정적 함수 `get_dname`과 멤버 프로시저 `display_dept`를 포함합니다.

```sql
CREATE OR REPLACE TYPE dept_obj_typ AS OBJECT (
    deptno          NUMBER(2),
    STATIC FUNCTION get_dname(p_deptno IN NUMBER) RETURN VARCHAR2,
    MEMBER PROCEDURE display_dept
);
```

`dept_obj_typ`에 대한 객체 타입 본문은 `get_dname`이라는 정적 함수와 `display_dept`라는 멤버 프로시저를 정의합니다.

```sql
CREATE OR REPLACE TYPE BODY dept_obj_typ AS
    STATIC FUNCTION get_dname(p_deptno IN NUMBER) RETURN VARCHAR2
    IS
        v_dname     VARCHAR2(14);
    BEGIN
        CASE p_deptno
            WHEN 10 THEN v_dname := 'ACCOUNTING';
            WHEN 20 THEN v_dname := 'RESEARCH';
            WHEN 30 THEN v_dname := 'SALES';
            WHEN 40 THEN v_dname := 'OPERATIONS';
            ELSE v_dname := 'UNKNOWN';
        END CASE;
        RETURN v_dname;
    END;

    MEMBER PROCEDURE display_dept
    IS
    BEGIN
        DBMS_OUTPUT.PUT_LINE('Dept No    : ' || SELF.deptno);
        DBMS_OUTPUT.PUT_LINE('Dept Name  : ' ||
            dept_obj_typ.get_dname(SELF.deptno));
    END;
END;
```

정적 함수 `get_dname`은 `SELF`를 참조할 수 없습니다. 정적 함수는 어떤 객체 인스턴스와도 무관하게 호출되므로, 어떤 객체 속성에도 암묵적으로 접근할 수 없습니다.

멤버 프로시저 `display_dept`는 `SELF` 매개변수로 전달된 객체 인스턴스의 `deptno` 속성에 접근할 수 있습니다. `display_dept` 매개변수 목록에 `SELF` 매개변수를 명시적으로 선언할 필요는 없습니다.

`display_dept` 프로시저의 마지막 `DBMS_OUTPUT.PUT_LINE` 문에는 객체 타입 이름 `dept_obj_typ`으로 한정된 정적 함수 `get_dname` 호출이 포함되어 있습니다.
