# Member methods — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Creating object types › Member methods](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/03_creating_object_types/01_member_methods/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

_멤버 메서드(member method)_ 는 객체 타입 안에 정의되며 그 타입의 인스턴스를 통해서만 호출할 수 있는 함수 또는 프로시저입니다. 멤버 메서드는 자신이 동작하고 있는 객체 인스턴스의 속성에 접근할 수 있으며 이를 변경할 수 있습니다.

다음 객체 타입 명세는 `emp_obj_typ` 객체 타입을 생성합니다.

```sql
CREATE OR REPLACE TYPE emp_obj_typ AS OBJECT
(
    empno           NUMBER(4),
    ename           VARCHAR2(20),
    addr            ADDR_OBJ_TYP,
    MEMBER PROCEDURE display_emp(SELF IN OUT emp_obj_typ)
);
```

객체 타입 `emp_obj_typ`는 `display_emp`라는 이름의 멤버 메서드를 포함합니다. `display_emp`는 `SELF` 매개변수를 사용하며, 이 매개변수는 메서드가 호출되는 대상 객체 인스턴스를 전달합니다.

`SELF` 매개변수는 데이터 타입이 정의 중인 객체 타입인 매개변수입니다. `SELF`는 항상 그 메서드를 호출하는 인스턴스를 참조합니다. `SELF` 매개변수는 매개변수 목록에 명시적으로 선언되었는지 여부와 관계없이 멤버 프로시저 또는 함수의 첫 번째 매개변수입니다.

다음 코드는 `emp_obj_typ`에 대한 객체 타입 본문을 정의합니다.

```sql
CREATE OR REPLACE TYPE BODY emp_obj_typ AS
    MEMBER PROCEDURE display_emp (SELF IN OUT emp_obj_typ)
    IS
    BEGIN
        DBMS_OUTPUT.PUT_LINE('Employee No   : ' || empno);
        DBMS_OUTPUT.PUT_LINE('Name          : ' || ename);
        DBMS_OUTPUT.PUT_LINE('Street        : ' || addr.street);
        DBMS_OUTPUT.PUT_LINE('City/State/Zip: ' || addr.city || ', ' ||
            addr.state || ' ' || LPAD(addr.zip,5,'0'));
    END;
END;
```

객체 타입 본문에서도 `SELF` 매개변수를 사용할 수 있습니다. `CREATE TYPE BODY` 명령에서 `SELF` 매개변수를 사용하면, 동일한 객체 타입 본문을 다음과 같이 작성할 수 있습니다.

```sql
CREATE OR REPLACE TYPE BODY emp_obj_typ AS
    MEMBER PROCEDURE display_emp (SELF IN OUT emp_obj_typ)
    IS
    BEGIN
        DBMS_OUTPUT.PUT_LINE('Employee No   : ' || SELF.empno);
        DBMS_OUTPUT.PUT_LINE('Name          : ' || SELF.ename);
        DBMS_OUTPUT.PUT_LINE('Street        : ' || SELF.addr.street);
        DBMS_OUTPUT.PUT_LINE('City/State/Zip: ' || SELF.addr.city || ', ' ||
            SELF.addr.state || ' ' || LPAD(SELF.addr.zip,5,'0'));
    END;
END;
```

`emp_obj_typ` 본문의 두 가지 버전은 서로 동등합니다.
