# 기본 객체 개념 (Basic object concepts) — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Basic object concepts](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/01_basic_object_concepts/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 용어는 원문 그대로 보존했습니다.

객체 타입(object type)은 어떤 엔티티에 대한 설명 또는 정의입니다. 객체 타입의 이 정의는 두 가지 구성 요소로 특징지어집니다.

- 속성(Attributes) — 객체 인스턴스의 특정 특성을 설명하는 필드입니다. person 객체의 경우 이름(name), 주소(address), 성별(gender), 생년월일(date of birth), 키(height), 몸무게(weight), 눈 색깔(eye color), 직업(occupation) 등이 그 예입니다.
- 메서드(Methods) — 객체에 대해 어떤 종류의 기능이나 연산을 수행하거나 객체와 관련된 프로그램입니다. person 객체의 경우 그 사람의 나이 계산, 그 사람의 속성 표시, 그 사람의 속성에 할당된 값 변경 등이 그 예입니다.
