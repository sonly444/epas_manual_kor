# Attributes — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Basic object concepts › Attributes](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/01_basic_object_concepts/01_attributes/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

모든 객체 타입은 최소한 하나의 속성(attribute)을 포함해야 합니다. 속성의 데이터 타입은 다음 중 어느 것이든 될 수 있습니다.

- `NUMBER`나 `VARCHAR2`와 같은 기본 데이터 타입
- 또 다른 객체 타입
- 중첩 테이블(nested table)이나 varray와 같이 전역적으로 정의된 컬렉션 타입(`CREATE TYPE` 명령으로 생성됨)

속성은 객체 인스턴스가 처음 생성될 때 초기값을 받으며, 이 초기값은 null일 수 있습니다. 각 객체 인스턴스는 자신만의 속성 값 집합을 가집니다.
