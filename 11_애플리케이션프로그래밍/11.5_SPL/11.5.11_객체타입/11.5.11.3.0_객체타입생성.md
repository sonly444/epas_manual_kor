# 객체 타입 생성 (Creating object types) — EPAS 18 SPL 객체 타입

> 원문: [EPAS v18 — SPL › Using object types and objects › Creating object types](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/15_object_types_and_objects/03_creating_object_types/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·타입·코드는 원문 그대로 보존했습니다.

`CREATE TYPE` 명령을 사용하여 객체 타입 명세(object type specification)를 생성하고, `CREATE TYPE BODY` 명령을 사용하여 객체 타입 본문(object type body)을 생성할 수 있습니다. 다음 예제들은 `CREATE TYPE` 및 `CREATE TYPE BODY` 명령을 사용합니다.

첫 번째 예제는 속성만 포함하고 메서드는 없는 `addr_object_type` 객체 타입을 생성합니다.

```sql
CREATE OR REPLACE TYPE addr_object_type AS OBJECT
(
    street          VARCHAR2(30),
    city            VARCHAR2(20),
    state           CHAR(2),
    zip             NUMBER(5)
);
```

이 객체 타입에는 메서드가 없으므로 객체 타입 본문이 필요하지 않습니다. 이 예제는 복합 타입(composite type)을 생성하며, 이를 통해 관련 객체를 단일 속성으로 다룰 수 있습니다.
