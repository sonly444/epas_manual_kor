# 연관 배열 사용 (Using associative arrays) — EPAS 18 SPL 컬렉션

> 원문: [EPAS v18 — SPL › Working with collection types › Using associative arrays](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/10_collections/01_associative_arrays/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입·구문·코드·출력은 원문 그대로 보존했습니다.

*연관 배열(associative array)*은 고유한 키를 값과 연관시키는 컬렉션 타입입니다. 키는 반드시 숫자일 필요가 없습니다. 문자 데이터일 수도 있습니다.

## 연관 배열 개요

연관 배열은 다음과 같은 특성을 가집니다.

- *연관 배열 타입(associative array type)*을 정의해야 하며, 그 후 해당 배열 타입의 *배열 변수(array variables)*를 선언할 수 있습니다. 데이터 조작은 배열 변수를 사용하여 이루어집니다.
- 배열 변수가 선언되면 연관 배열이 생성되지만 비어 있습니다. 키 값에 값을 할당하기 시작하십시오.
- `INDEX BY BINARY_INTEGER` 또는 `PLS_INTEGER`를 지정하면 키는 임의의 음의 정수, 양의 정수, 또는 0이 될 수 있습니다.
- `INDEX BY VARCHAR2`를 지정하면 키는 문자 데이터가 될 수 있습니다.
- 배열의 요소 수에는 미리 정의된 제한이 없습니다. 요소가 추가되면 동적으로 커집니다.
- 배열은 희소(sparse)할 수 있습니다. 키에 값을 할당할 때 간격이 있을 수 있습니다.
- 값이 할당되지 않은 배열 요소를 참조하려고 하면 예외가 발생합니다.

## 연관 배열 정의

`TYPE IS TABLE OF ... INDEX BY` 문을 사용하여 연관 배열 타입을 정의합니다.

```sql
TYPE <assoctype> IS TABLE OF { <datatype> | <rectype> | <objtype> }
  INDEX BY { BINARY_INTEGER | PLS_INTEGER | VARCHAR2(<n>) };
```

여기서:

`assoctype`은 배열 타입에 할당된 식별자입니다.

`datatype`은 `VARCHAR2`나 `NUMBER` 같은 스칼라 데이터 타입입니다.

`rectype`은 이전에 정의된 레코드 타입입니다.

`objtype`은 이전에 정의된 객체 타입입니다.

`n`은 문자 키의 최대 길이입니다.

## 변수 선언

배열을 사용하려면 그 배열 타입의 *변수(variable)*를 선언해야 합니다. 다음은 배열 변수를 선언하는 구문입니다.

```text
<array> <assoctype>
```

여기서:

`array`는 연관 배열에 할당된 식별자입니다.

`assoctype`은 이전에 정의된 배열 타입의 식별자입니다.

## 배열 요소 참조

다음 구문을 사용하여 배열의 요소를 참조합니다.

```text
<array>(<n>)[<.field> ]
```

`array`는 이전에 선언된 배열의 식별자입니다.

`n`은 `INDEX BY` 절에 지정된 데이터 타입과 타입 호환되는 키 값입니다.

`array`의 배열 타입이 레코드 타입이나 객체 타입으로부터 정의된 경우, `[.field ]`는 배열 타입이 정의된 레코드 타입의 개별 필드나 객체 타입의 속성을 참조해야 합니다. 또는 `[.field ]`를 생략하여 전체 레코드를 참조할 수 있습니다.

## 예제

이 예제는 `emp` 테이블에서 처음 10명의 직원 이름을 읽어 배열에 저장한 다음, 배열에서 결과를 표시합니다.

```sql
DECLARE
    TYPE emp_arr_typ IS TABLE OF VARCHAR2(10) INDEX BY BINARY_INTEGER;
    emp_arr         emp_arr_typ;
    CURSOR emp_cur IS SELECT ename FROM emp WHERE ROWNUM <= 10;
    i               INTEGER := 0;
BEGIN
    FOR r_emp IN emp_cur LOOP
        i := i + 1;
        emp_arr(i) := r_emp.ename;
    END LOOP;
    FOR j IN 1..10 LOOP
        DBMS_OUTPUT.PUT_LINE(emp_arr(j));
    END LOOP;
END;
```

이 예제는 다음과 같은 출력을 생성합니다.

출력

```text
SMITH
ALLEN
WARD
JONES
MARTIN
BLAKE
CLARK
SCOTT
KING
TURNER
```

이 예제는 배열 정의에서 레코드 타입을 사용합니다.

```sql
DECLARE
    TYPE emp_rec_typ IS RECORD (
        empno       NUMBER(4),
        ename       VARCHAR2(10)
    );
    TYPE emp_arr_typ IS TABLE OF emp_rec_typ INDEX BY BINARY_INTEGER;
    emp_arr         emp_arr_typ;
    CURSOR emp_cur IS SELECT empno, ename FROM emp WHERE ROWNUM <= 10;
    i               INTEGER := 0;
BEGIN
    DBMS_OUTPUT.PUT_LINE('EMPNO    ENAME');
    DBMS_OUTPUT.PUT_LINE('-----    -------');
    FOR r_emp IN emp_cur LOOP
        i := i + 1;
        emp_arr(i).empno := r_emp.empno;
        emp_arr(i).ename := r_emp.ename;
    END LOOP;
    FOR j IN 1..10 LOOP
        DBMS_OUTPUT.PUT_LINE(emp_arr(j).empno || '     ' ||
            emp_arr(j).ename);
    END LOOP;
END;
```

다음은 이 익명 블록의 출력입니다.

출력

```text
EMPNO    ENAME
-----    -------
7369     SMITH
7499     ALLEN
7521     WARD
7566     JONES
7654     MARTIN
7698     BLAKE
7782     CLARK
7788     SCOTT
7839     KING
7844     TURNER
```

이 예제는 `emp_rec_typ` 레코드 타입을 사용하는 대신 `emp%ROWTYPE` 속성을 사용하여 `emp_arr_typ`를 정의합니다.

```sql
DECLARE
    TYPE emp_arr_typ IS TABLE OF emp%ROWTYPE INDEX BY BINARY_INTEGER;
    emp_arr         emp_arr_typ;
    CURSOR emp_cur IS SELECT empno, ename FROM emp WHERE ROWNUM <= 10;
    i               INTEGER := 0;
BEGIN
    DBMS_OUTPUT.PUT_LINE('EMPNO    ENAME');
    DBMS_OUTPUT.PUT_LINE('-----    -------');
    FOR r_emp IN emp_cur LOOP
        i := i + 1;
        emp_arr(i).empno := r_emp.empno;
        emp_arr(i).ename := r_emp.ename;
    END LOOP;
    FOR j IN 1..10 LOOP
        DBMS_OUTPUT.PUT_LINE(emp_arr(j).empno || '     ' ||
            emp_arr(j).ename);
    END LOOP;
END;
```

결과는 배열 정의에서 레코드 타입을 사용하는 것과 동일합니다.

레코드의 각 필드를 개별적으로 할당하는 대신, `r_emp`에서 `emp_arr`로 레코드 수준 할당을 할 수 있습니다.

```sql
DECLARE
    TYPE emp_rec_typ IS RECORD (
        empno       NUMBER(4),
        ename       VARCHAR2(10)
    );
    TYPE emp_arr_typ IS TABLE OF emp_rec_typ INDEX BY BINARY_INTEGER;
    emp_arr         emp_arr_typ;
    CURSOR emp_cur IS SELECT empno, ename FROM emp WHERE ROWNUM <= 10;
    i               INTEGER := 0;
BEGIN
    DBMS_OUTPUT.PUT_LINE('EMPNO    ENAME');
    DBMS_OUTPUT.PUT_LINE('-----    -------');
    FOR r_emp IN emp_cur LOOP
        i := i + 1;
        emp_arr(i) := r_emp;
    END LOOP;
    FOR j IN 1..10 LOOP
        DBMS_OUTPUT.PUT_LINE(emp_arr(j).empno || '     ' ||
            emp_arr(j).ename);
    END LOOP;
END;
```

이 예제는 연관 배열의 키를 문자 데이터로 사용합니다.

```sql
DECLARE
    TYPE job_arr_typ IS TABLE OF NUMBER INDEX BY VARCHAR2(9);
    job_arr         job_arr_typ;
BEGIN
    job_arr('ANALYST')   := 100;
    job_arr('CLERK')     := 200;
    job_arr('MANAGER')   := 300;
    job_arr('SALESMAN')  := 400;
    job_arr('PRESIDENT') := 500;
    DBMS_OUTPUT.PUT_LINE('ANALYST  : ' || job_arr('ANALYST'));
    DBMS_OUTPUT.PUT_LINE('CLERK    : ' || job_arr('CLERK'));
    DBMS_OUTPUT.PUT_LINE('MANAGER  : ' || job_arr('MANAGER'));
    DBMS_OUTPUT.PUT_LINE('SALESMAN : ' || job_arr('SALESMAN'));
    DBMS_OUTPUT.PUT_LINE('PRESIDENT: ' || job_arr('PRESIDENT'));
END;

ANALYST  : 100
CLERK    : 200
MANAGER  : 300
SALESMAN : 400
PRESIDENT: 500
```
