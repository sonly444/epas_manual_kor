# 컬렉션 타입 작업 (Working with collection types) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › Working with collection types](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/10_collections/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입·용어는 원문 그대로 보존했습니다.

*컬렉션(collection)*은 동일한 데이터 타입을 가진 순서 있는 데이터 항목 집합입니다. 일반적으로 데이터 항목은 스칼라 필드입니다. 레코드 타입이나 객체 타입 같은 사용자 정의 타입일 수도 있습니다. 이 경우 사용자 정의 타입의 각 필드를 구성하는 구조와 데이터 타입이 집합의 각 요소에 대해 동일해야 합니다. 괄호 쌍 안의 첨자 표기법(subscript notation)을 사용하여 집합의 각 데이터 항목을 참조합니다.
