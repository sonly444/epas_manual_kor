# 컬렉션 타입 정보 (About collection types) — EPAS 18 SPL 컬렉션

> 원문: [EPAS v18 — SPL › Working with collection types › About collection types](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/10_collections/about_collections/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입·명령·예외는 원문 그대로 보존했습니다.

가장 흔히 알려진 컬렉션 타입은 배열(array)입니다. EDB Postgres Advanced Server에서 지원하는 컬렉션 타입은 다음과 같습니다.

- [연관 배열(Associative arrays)](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/10_collections/01_associative_arrays/) (Oracle에서 이전에 *index-by-tables*라고 불림)
- [중첩 테이블(Nested tables)](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/10_collections/02_nested_tables/)
- [Varray](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/10_collections/03_varrays/)

## 컬렉션 타입 정의

컬렉션을 설정하려면:

1. 원하는 타입의 컬렉션을 정의합니다. SPL 프로그램의 선언 섹션에서 정의할 수 있으며, 이 경우 해당 프로그램에서만 접근할 수 있는 *지역 타입(local type)*이 됩니다. 중첩 테이블과 varray 타입의 경우, `CREATE TYPE` 명령을 사용하여 정의할 수도 있으며, 이는 데이터베이스의 어떤 SPL 프로그램에서도 참조할 수 있는 영구적인 *독립형 타입(standalone type)*을 생성합니다.
2. 컬렉션 타입의 변수를 선언합니다. 변수 선언의 일부로 값 할당이 이루어지지 않으면, 이 시점에서 선언된 변수와 연관된 컬렉션은 초기화되지 않은 상태입니다.

## null 컬렉션 초기화

- 초기화되지 않은 중첩 테이블과 varray 컬렉션은 null입니다. *null 컬렉션*은 아직 존재하지 않습니다. 일반적으로 null 컬렉션에 컬렉션 메서드를 호출하면 `COLLECTION_IS_NULL` 예외가 발생합니다.
- null 컬렉션을 초기화하려면 그것을 빈 컬렉션으로 만들거나 null이 아닌 값을 할당해야 합니다. 일반적으로 null 컬렉션은 그 *생성자(constructor)*를 사용하여 초기화합니다.

## 연관 배열에 요소 추가

- 초기화되지 않은 연관 배열 컬렉션은 존재하지만 요소가 없습니다. 요소가 없는 기존 컬렉션을 *빈 컬렉션(empty collection)*이라고 합니다.
- 빈 연관 배열에 요소를 추가하려면 그 키에 값을 할당할 수 있습니다. 중첩 테이블과 varray의 경우, 일반적으로 그 생성자를 사용하여 중첩 테이블이나 varray에 초기 값을 할당합니다. 중첩 테이블과 varray의 경우, 그런 다음 `EXTEND` 메서드를 사용하여 생성자가 설정한 초기 크기를 넘어 컬렉션을 늘립니다.

## 제한

- 다단계 컬렉션(즉, 컬렉션의 데이터 항목이 또 다른 컬렉션인 경우)은 지원되지 않습니다.

- 컬렉션 타입의 컬럼은 지원되지 않습니다.

예를 들어, 배열 `varchar2_t`는 생성할 수 있지만, 배열 `varchar2_t`를 컬럼 데이터 타입으로 사용하여 테이블을 생성할 수는 없습니다.

```sql
  --Create an array
edb=# CREATE TYPE varchar2_t AS TABLE OF character varying;
CREATE TYPE
  --Create a table using array as the column data type
edb=# CREATE TABLE t(a varchar2_t);
```

출력

```text
ERROR:  column "a" has collection type varchar2_t, columns of collection types are not supported.
```
