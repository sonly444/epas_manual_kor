# 중첩 테이블 작업 (Working with nested tables) — EPAS 18 SPL 컬렉션

> 원문: [EPAS v18 — SPL › Working with collection types › Working with nested tables](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/10_collections/02_nested_tables/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입·명령·예외는 원문 그대로 보존했습니다.

*중첩 테이블(nested table)*은 양의 정수를 값과 연관시키는 컬렉션 타입입니다.

## 중첩 테이블 개요

중첩 테이블은 다음과 같은 특성을 가집니다.

- *중첩 테이블 타입(nested table type)*을 정의해야 합니다. 그 후 해당 중첩 테이블 타입의 *중첩 테이블 변수(nested table variables)*를 선언할 수 있습니다. 데이터 조작은 중첩 테이블 변수(간단히 테이블이라고도 함)를 사용하여 이루어집니다.
- 중첩 테이블 변수를 선언하면 중첩 테이블은 아직 존재하지 않습니다. null 컬렉션입니다. null 테이블은 *생성자(constructor)*로 초기화해야 합니다. 할당문의 오른쪽이 동일한 타입의 초기화된 테이블인 할당문을 사용하여 테이블을 초기화할 수도 있습니다.

> ##### 참고
>
> 중첩 테이블의 초기화는 Oracle에서는 필수이지만 SPL에서는 선택 사항입니다.

- 키는 양의 정수입니다.
- 생성자는 테이블의 요소 수를 설정합니다. `EXTEND` 메서드는 테이블에 요소를 추가합니다. 자세한 내용은 [Collection methods](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/11_collection_methods/#collection_methods)를 참조하십시오.

> ##### 참고
>
> 생성자를 사용하여 테이블의 요소 수를 설정하는 것과 `EXTEND` 메서드를 사용하여 테이블에 요소를 추가하는 것은 Oracle에서는 필수이지만 SPL에서는 선택 사항입니다.

- 테이블은 희소(sparse)할 수 있습니다. 키에 값을 할당할 때 간격이 있을 수 있습니다.
- 초기화되거나 확장된 크기를 넘어 테이블 요소를 참조하려고 하면 `SUBSCRIPT_BEYOND_COUNT` 예외가 발생합니다.

## 중첩 테이블 정의

SPL 프로그램의 선언 섹션에서 `TYPE IS TABLE` 문을 사용하여 중첩 테이블 타입을 정의합니다.

```sql
TYPE <tbltype> IS TABLE OF { <datatype> | <rectype> | <objtype> };
```

여기서:

`tbltype`은 중첩 테이블 타입에 할당된 식별자입니다.

`datatype`은 `VARCHAR2`나 `NUMBER` 같은 스칼라 데이터 타입입니다.

`rectype`은 이전에 정의된 레코드 타입입니다.

`objtype`은 이전에 정의된 객체 타입입니다.

> ##### 참고
>
> `CREATE TYPE` 명령을 사용하여 데이터베이스의 모든 SPL 프로그램에서 사용할 수 있는 중첩 테이블 타입을 정의할 수 있습니다. `CREATE TYPE` 명령에 대한 자세한 내용은 [SQL reference](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/39_create_type/)를 참조하십시오.

## 변수 선언

테이블을 사용하려면 그 중첩 테이블 타입의 *변수(variable)*를 선언해야 합니다. 다음은 테이블 변수를 선언하는 구문입니다.

```text
<table> <tbltype>
```

여기서:

`table`은 중첩 테이블에 할당된 식별자입니다.

`tbltype`은 이전에 정의된 중첩 테이블 타입의 식별자입니다.

## 중첩 테이블 초기화

중첩 테이블 타입의 생성자를 사용하여 중첩 테이블을 초기화합니다.

```sql
<tbltype> ([ { <expr1> | NULL } [, { <expr2> | NULL } ] [, ...] ])
```

여기서:

`tbltype`은 중첩 테이블 타입의 생성자 식별자로, 중첩 테이블 타입과 동일한 이름을 가집니다.

`expr1, expr2, …`는 테이블의 요소 타입과 타입 호환되는 표현식입니다. `NULL`을 지정하면 해당 요소는 null로 설정됩니다. 파라미터 목록이 비어 있으면 빈 중첩 테이블이 반환되며, 이는 테이블에 요소가 없음을 의미합니다. 테이블이 객체 타입으로부터 정의된 경우, `exprn`은 해당 객체 타입의 객체를 반환해야 합니다. 이 객체는 함수의 반환 값이거나 객체 타입의 생성자일 수 있습니다. 또는 동일한 타입의 다른 중첩 테이블의 요소일 수 있습니다.

초기화되지 않은 중첩 테이블에 `EXISTS` 이외의 컬렉션 메서드를 적용하면 `COLLECTION_IS_NULL` 예외가 발생합니다. 자세한 내용은 [Collection methods](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/11_collection_methods/#collection_methods)를 참조하십시오.

이 예제는 중첩 테이블의 생성자를 보여 줍니다.

```sql
DECLARE
    TYPE nested_typ IS TABLE OF CHAR(1);
    v_nested        nested_typ := nested_typ('A','B');
```

## 테이블 요소 참조

다음 구문을 사용하여 테이블의 요소를 참조합니다.

```text
<table>(<n>)[<.element> ]
```

여기서:

`table`은 이전에 선언된 테이블의 식별자입니다.

`n`은 양의 정수입니다.

`table`의 테이블 타입이 레코드 타입이나 객체 타입으로부터 정의된 경우, `[.element  ]`는 중첩 테이블 타입이 정의된 레코드 타입의 개별 필드나 객체 타입의 속성을 참조해야 합니다. 또는 `[.element  ]`를 생략하여 전체 레코드나 객체를 참조할 수 있습니다.

## 예제

이 예제는 요소가 4개인 것으로 알려진 중첩 테이블을 보여 줍니다.

```sql
DECLARE
    TYPE dname_tbl_typ IS TABLE OF VARCHAR2(14);
    dname_tbl       dname_tbl_typ;
    CURSOR dept_cur IS SELECT dname FROM dept ORDER BY dname;
    i               INTEGER := 0;
BEGIN
    dname_tbl := dname_tbl_typ(NULL, NULL, NULL, NULL);
    FOR r_dept IN dept_cur LOOP
        i := i + 1;
        dname_tbl(i) := r_dept.dname;
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('DNAME');
    DBMS_OUTPUT.PUT_LINE('----------');
    FOR j IN 1..i LOOP
        DBMS_OUTPUT.PUT_LINE(dname_tbl(j));
    END LOOP;
END;
```

다음은 이 예제의 출력입니다.

출력

```text
DNAME
----------
ACCOUNTING
OPERATIONS
RESEARCH
SALES
```

이 예제는 `emp` 테이블에서 처음 10명의 직원 이름을 읽어 중첩 테이블에 저장한 다음, 테이블에서 결과를 표시합니다. SPL 코드는 반환할 직원 수를 미리 알 수 없다고 가정하여 작성되었습니다.

```sql
DECLARE
    TYPE emp_rec_typ IS RECORD (
        empno       NUMBER(4),
        ename       VARCHAR2(10)
    );
    TYPE emp_tbl_typ IS TABLE OF emp_rec_typ;
    emp_tbl         emp_tbl_typ;
    CURSOR emp_cur IS SELECT empno, ename FROM emp WHERE ROWNUM <= 10;
    i               INTEGER := 0;
BEGIN
    emp_tbl := emp_tbl_typ();
    DBMS_OUTPUT.PUT_LINE('EMPNO    ENAME');
    DBMS_OUTPUT.PUT_LINE('-----    -------');
    FOR r_emp IN emp_cur LOOP
        i := i + 1;
        emp_tbl.EXTEND;
        emp_tbl(i) := r_emp;
    END LOOP;
    FOR j IN 1..10 LOOP
        DBMS_OUTPUT.PUT_LINE(emp_tbl(j).empno || '     ' ||
            emp_tbl(j).ename);
    END LOOP;
END;
```

익명 블록의 실행 섹션에서 첫 번째 문으로 생성자 `emp_tbl_typ()`를 사용하여 빈 테이블이 생성됩니다. 그런 다음 결과 집합에서 반환된 각 직원에 대해 `EXTEND` 컬렉션 메서드를 사용하여 테이블에 요소를 추가합니다. [Extend](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/11_collection_methods/04_extend/#extend)를 참조하십시오.

다음은 출력입니다.

출력

```text
EMPNO    ENAME
-----    -------
7369     SMITH
7499     ALLEN
7521     WARD
7566     JONES
7654     MARTIN
7698     BLAKE
7782     CLARK
7788     SCOTT
7839     KING
7844     TURNER
```

이 예제는 객체 타입의 중첩 테이블을 사용하는 방법을 보여 줍니다. 먼저 부서 이름과 위치에 대한 속성을 가진 객체 타입을 생성합니다.

```sql
CREATE TYPE dept_obj_typ AS OBJECT (
    dname           VARCHAR2(14),
    loc             VARCHAR2(13)
);
```

이 익명 블록은 요소가 `dept_obj_typ` 객체 타입으로 구성된 중첩 테이블 타입을 정의합니다. 중첩 테이블 변수를 선언하고 초기화한 다음 `dept` 테이블에서 채웁니다. 마지막으로 중첩 테이블의 요소를 표시합니다.

```sql
DECLARE
    TYPE dept_tbl_typ IS TABLE OF dept_obj_typ;
    dept_tbl        dept_tbl_typ;
    CURSOR dept_cur IS SELECT dname, loc FROM dept ORDER BY dname;
    i               INTEGER := 0;
BEGIN
    dept_tbl := dept_tbl_typ(
        dept_obj_typ(NULL,NULL),
        dept_obj_typ(NULL,NULL),
        dept_obj_typ(NULL,NULL),
        dept_obj_typ(NULL,NULL)
    );
    FOR r_dept IN dept_cur LOOP
        i := i + 1;
        dept_tbl(i).dname := r_dept.dname;
        dept_tbl(i).loc   := r_dept.loc;
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('DNAME          LOC');
    DBMS_OUTPUT.PUT_LINE('----------     ----------');
    FOR j IN 1..i LOOP
        DBMS_OUTPUT.PUT_LINE(RPAD(dept_tbl(j).dname,14) || ' ' ||
            dept_tbl(j).loc);
    END LOOP;
END;
```

중첩 테이블의 생성자 `dept_tbl_typ`를 구성하는 파라미터는 객체 타입의 생성자 `dept_obj_typ`에 대한 호출입니다. 다음은 익명 블록의 출력입니다.

출력

```text
DNAME          LOC
----------     ----------
ACCOUNTING     NEW YORK
OPERATIONS     BOSTON
RESEARCH       DALLAS
SALES          CHICAGO
```
