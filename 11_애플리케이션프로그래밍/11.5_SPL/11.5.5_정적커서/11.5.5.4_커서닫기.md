# 커서 닫기 (Closing a cursor) — EPAS 18 SPL 정적 커서

> 원문: [EPAS v18 — SPL › Working with static cursors › Closing a cursor](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/04_closing_a_cursor/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드는 원문 그대로 보존했습니다.

커서 결과 집합에서 원하는 행을 모두 조회하고 나면 커서를 닫습니다. 커서를 닫은 후에는 더 이상 결과 집합에 접근할 수 없습니다.

`CLOSE` 문은 다음과 같은 형태로 나타납니다.

```sql
CLOSE <name>;
```

`name`은 현재 열려 있는 커서의 식별자입니다. 커서를 닫은 후에는 다시 닫지 마십시오. 다만 커서를 닫은 후에 닫힌 커서에 대해 `OPEN` 문을 다시 사용하여 쿼리 결과 집합을 재구성할 수 있습니다. 그 후 `FETCH` 문으로 새 결과 집합의 행을 조회할 수 있습니다.

다음 예제는 `CLOSE` 문을 사용합니다.

```sql
CREATE OR REPLACE PROCEDURE cursor_example
IS
    v_emp_rec       emp%ROWTYPE;
    CURSOR emp_cur_1 IS SELECT * FROM emp;
BEGIN
    OPEN emp_cur_1;
    FETCH emp_cur_1 INTO v_emp_rec;
    DBMS_OUTPUT.PUT_LINE('Employee Number: ' || v_emp_rec.empno);
    DBMS_OUTPUT.PUT_LINE('Employee Name  : ' || v_emp_rec.ename);
    CLOSE emp_cur_1;
END;
```

이 프로시저는 다음 출력을 생성합니다. 직원 번호 `7369, SMITH`가 결과 집합의 첫 번째 행입니다.

```sql
EXEC cursor_example;
```

출력

```text
Employee Number: 7369
Employee Name  : SMITH
```
