# 파라미터화 커서 선언 (Declaring parameterized cursors) — EPAS 18 SPL 정적 커서

> 원문: [EPAS v18 — SPL › Working with static cursors › Declaring parameterized cursors](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/08_parameterized_cursors/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·구문·코드는 원문 그대로 보존했습니다.

파라미터를 받는 정적 커서를 선언할 수 있으며, 그 커서를 열 때 해당 파라미터에 값을 전달할 수 있습니다. 이 예제는 지정된 값보다 급여가 적은 `emp` 테이블의 모든 직원의 이름과 급여를 표시하는 파라미터화 커서를 만듭니다. 이 정보는 파라미터로 전달됩니다.

```sql
DECLARE
    my_record       emp%ROWTYPE;
    CURSOR c1 (max_wage NUMBER) IS
        SELECT * FROM emp WHERE sal < max_wage;
BEGIN
    OPEN c1(2000);
    LOOP
        FETCH c1 INTO my_record;
        EXIT WHEN c1%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE('Name = ' || my_record.ename || ', salary = '
            || my_record.sal);
    END LOOP;
    CLOSE c1;
END;
```

예를 들어, `max_wage`로 값 2000을 전달하면 급여가 2000 미만인 모든 직원의 이름과 급여만 표시됩니다. 다음은 위 쿼리의 결과입니다.

```sql
Name = SMITH, salary = 800.00
Name = ALLEN, salary = 1600.00
Name = WARD, salary = 1250.00
Name = MARTIN, salary = 1250.00
Name = TURNER, salary = 1500.00
Name = ADAMS, salary = 1100.00
Name = JAMES, salary = 950.00
Name = MILLER, salary = 1300.00
```
