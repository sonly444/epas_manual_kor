# 커서에서 행 페치 (Fetching rows from a cursor) — EPAS 18 SPL 정적 커서

> 원문: [EPAS v18 — SPL › Working with static cursors › Fetching rows from a cursor](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/03_fetching_rows_from_a_cursor/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·구문·코드는 원문 그대로 보존했습니다.

커서를 열고 나면 `FETCH` 문을 사용하여 커서의 결과 집합에서 행을 조회할 수 있습니다.

## 구문 (Syntax)

```sql
FETCH <name> INTO { <record> | <variable> [, <variable_2> ]... };
```

여기서:

- `name`은 이전에 연 커서의 식별자입니다.
- `record`는 이전에 정의된 레코드(예: `table%ROWTYPE`를 사용)의 식별자입니다.

`variable, variable_2...`는 페치된 행에서 필드 데이터를 받는 SPL 변수입니다. `record` 또는 `variable, variable_2...`의 필드는 커서 선언에 지정된 쿼리의 `SELECT` 목록에서 반환되는 필드와 개수·순서가 일치해야 합니다. `SELECT` 목록에 있는 필드의 데이터 타입은 `record`의 필드 또는 `variable, variable_2...`의 데이터 타입과 일치하거나 암묵적으로 변환 가능해야 합니다.

##### 참고

`BULK COLLECT` 절을 사용하는 `FETCH INTO`의 변형은 여러 행을 한 번에 컬렉션으로 반환할 수 있습니다. `FETCH INTO` 문과 함께 `BULK COLLECT` 절을 사용하는 방법에 대한 자세한 내용은 [BULK COLLECT 절 사용(Using the BULK COLLECT clause)](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/12_working_with_collections/04_using_the_bulk_collect_clause/#using_the_bulk_collect_clause)을 참조하십시오.

## 예제 (Example)

다음은 `FETCH` 문을 보여 줍니다.

```sql
CREATE OR REPLACE PROCEDURE cursor_example
IS
    v_empno         NUMBER(4);
    v_ename         VARCHAR2(10);
    CURSOR emp_cur_3 IS SELECT empno, ename FROM emp WHERE deptno = 10
        ORDER BY empno;
BEGIN
    OPEN emp_cur_3;
    FETCH emp_cur_3 INTO v_empno, v_ename;
        ...
END;
```

대상 변수의 데이터 타입을 명시적으로 선언하는 대신 `%TYPE`을 사용할 수 있습니다. 이 방식을 사용하면 데이터베이스 컬럼의 데이터 타입이 변경되더라도 SPL 프로그램의 대상 변수 선언을 변경할 필요가 없습니다. `%TYPE`은 지정된 컬럼의 새 데이터 타입을 가져옵니다.

```sql
CREATE OR REPLACE PROCEDURE cursor_example
IS
    v_empno         emp.empno%TYPE;
    v_ename         emp.ename%TYPE;
    CURSOR emp_cur_3 IS SELECT empno, ename FROM emp WHERE deptno = 10
        ORDER BY empno;
BEGIN
    OPEN emp_cur_3;
    FETCH emp_cur_3 INTO v_empno, v_ename;
        ...
END;
```

테이블의 모든 컬럼을 테이블에 정의된 순서대로 조회하는 경우, `%ROWTYPE`을 사용하여 `FETCH` 문이 조회된 데이터를 넣을 레코드를 정의할 수 있습니다. 그런 다음 점 표기법(dot notation)을 사용하여 레코드의 각 필드에 접근할 수 있습니다.

```sql
CREATE OR REPLACE PROCEDURE cursor_example
IS
    v_emp_rec       emp%ROWTYPE;
    CURSOR emp_cur_1 IS SELECT * FROM emp;
BEGIN
    OPEN emp_cur_1;
    FETCH emp_cur_1 INTO v_emp_rec;
    DBMS_OUTPUT.PUT_LINE('Employee Number: ' || v_emp_rec.empno);
    DBMS_OUTPUT.PUT_LINE('Employee Name  : ' || v_emp_rec.ename);
        ...
END;
```
