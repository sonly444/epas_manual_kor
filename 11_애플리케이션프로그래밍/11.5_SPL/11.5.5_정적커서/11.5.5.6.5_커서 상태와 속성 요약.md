# 커서 상태와 속성 요약 (Summary of cursor states and attributes) — EPAS 18 SPL 커서 속성

> 원문: [EPAS v18 — SPL › Working with static cursors › Cursor attributes › Summary of cursor states and attributes](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/06_cursor_attributes/05_summary_of_cursor_states_and_attributes/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

다음 표는 가능한 커서 상태와 커서 속성이 반환하는 값을 요약합니다.

| 커서 상태 (Cursor state) | %ISOPEN | %FOUND | %NOTFOUND | %ROWCOUNT |
| --- | --- | --- | --- | --- |
| `OPEN` 이전 | False | `INVALID_CURSOR` 예외 | `INVALID_CURSOR` 예외 | `INVALID_CURSOR` 예외 |
| `OPEN` 이후 & 첫 `FETCH` 이전 | True | Null | Null | 0 |
| 첫 번째 성공적인 `FETCH` 이후 | True | True | False | 1 |
| `n`번째 성공적인 `FETCH`(마지막 행) 이후 | True | True | False | n |
| n+1번째 `FETCH`(마지막 행 이후) 이후 | True | False | True | n |
| `CLOSE` 이후 | False | `INVALID_CURSOR` 예외 | `INVALID_CURSOR` 예외 | `INVALID_CURSOR` 예외 |
