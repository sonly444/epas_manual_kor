# %ROWCOUNT — EPAS 18 SPL 커서 속성

> 원문: [EPAS v18 — SPL › Working with static cursors › Cursor attributes › %ROWCOUNT](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/06_cursor_attributes/04_rowcount/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`%ROWCOUNT` 속성은 지정한 커서에서 지금까지 페치한 행의 수를 나타내는 정수를 반환합니다.

```text
<cursor_name>%ROWCOUNT
```

`cursor_name`은 커서의 이름으로, `%ROWCOUNT`는 지금까지 조회한 행의 수를 반환합니다. 마지막 행을 조회한 후 `%ROWCOUNT`는 커서가 닫힐 때까지 반환된 총 행 수로 유지됩니다. 커서가 닫힌 시점에 `%ROWCOUNT`를 참조하면 `INVALID_CURSOR` 예외가 발생합니다.

커서가 열리기 전이나 닫힌 후에 `%ROWCOUNT`를 참조하면 `INVALID_CURSOR` 예외가 발생합니다.

커서가 열려 있지만 첫 번째 `FETCH` 이전에 `%ROWCOUNT`를 참조하면 `0`을 반환합니다. 결과 집합에 처음부터 행이 없는 경우 첫 번째 `FETCH` 이후에도 `%ROWCOUNT`는 `0`을 반환합니다.

다음 예제는 `%ROWCOUNT`를 사용합니다:

```sql
CREATE OR REPLACE PROCEDURE cursor_example
IS
    v_emp_rec       emp%ROWTYPE;
    CURSOR emp_cur_1 IS SELECT * FROM emp;
BEGIN
    OPEN emp_cur_1;
    DBMS_OUTPUT.PUT_LINE('EMPNO    ENAME');
    DBMS_OUTPUT.PUT_LINE('-----    -------');
    LOOP
        FETCH emp_cur_1 INTO v_emp_rec;
        EXIT WHEN emp_cur_1%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE(v_emp_rec.empno || '     ' || v_emp_rec.ename);
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('**********************');
    DBMS_OUTPUT.PUT_LINE(emp_cur_1%ROWCOUNT || ' rows were retrieved');
    CLOSE emp_cur_1;
END;
```

이 프로시저는 직원 목록의 끝에 조회된 총 행 수를 다음과 같이 출력합니다:

```sql
EXEC cursor_example;
```
