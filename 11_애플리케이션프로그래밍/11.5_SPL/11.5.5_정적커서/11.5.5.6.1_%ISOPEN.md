# %ISOPEN — EPAS 18 SPL 커서 속성

> 원문: [EPAS v18 — SPL › Working with static cursors › Cursor attributes › %ISOPEN](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/06_cursor_attributes/01_isopen/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`%ISOPEN` 속성을 사용하여 커서가 열려 있는지 테스트합니다.

```text
<cursor_name>%ISOPEN
```

`cursor_name`은 커서의 이름으로, 커서가 열려 있으면 `BOOLEAN` 데이터 타입의 `TRUE`를, 그렇지 않으면 `FALSE`를 반환합니다.

다음 예제는 `%ISOPEN`을 사용합니다:

```sql
CREATE OR REPLACE PROCEDURE cursor_example
IS
        ...
    CURSOR emp_cur_1 IS SELECT * FROM emp;
        ...
BEGIN
        ...
    IF emp_cur_1%ISOPEN THEN
        NULL;
    ELSE
        OPEN emp_cur_1;
    END IF;
    FETCH emp_cur_1 INTO ...
        ...
END;
```
