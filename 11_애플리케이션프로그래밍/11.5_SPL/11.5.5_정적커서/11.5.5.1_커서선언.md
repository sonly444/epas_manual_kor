# 커서 선언 (Declaring a cursor) — EPAS 18 SPL 정적 커서

> 원문: [EPAS v18 — SPL › Working with static cursors › Declaring a cursor](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/01_declaring_a_cursor/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·구문·코드는 원문 그대로 보존했습니다.

커서를 사용하려면 먼저 SPL 프로그램의 선언 섹션에서 커서를 선언해야 합니다. 커서 선언은 다음과 같은 형태로 나타납니다.

```sql
CURSOR <name> IS <query>;
```

여기서:

- `name`은 프로그램 뒷부분에서 커서와 그 결과 집합을 참조하는 데 사용되는 식별자입니다.
- `query`는 커서로 조회 가능한 결과 집합을 결정하는 SQL `SELECT` 명령입니다.

##### 참고

이 구문의 확장을 통해 파라미터를 사용할 수 있습니다. 자세한 내용은 [파라미터화 커서(Parameterized cursors)](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/08_parameterized_cursors/#parameterized_cursors)를 참조하십시오.

다음 예제는 몇 가지 커서 선언을 보여 줍니다.

```sql
CREATE OR REPLACE PROCEDURE cursor_example
IS
    CURSOR emp_cur_1 IS SELECT * FROM emp;
    CURSOR emp_cur_2 IS SELECT empno, ename FROM emp;
    CURSOR emp_cur_3 IS SELECT empno, ename FROM emp WHERE deptno = 10
        ORDER BY empno;
BEGIN
    ...
END;
```
