# 커서에 %ROWTYPE 사용 (Using %ROWTYPE with cursors) — EPAS 18 SPL 정적 커서

> 원문: [EPAS v18 — SPL › Working with static cursors › Using %ROWTYPE with cursors](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/05_using__rowtype_with_cursors/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 속성·구문·코드는 원문 그대로 보존했습니다.

`%ROWTYPE` 속성을 사용하면 커서 또는 커서 변수에서 페치된 모든 컬럼에 대응하는 필드를 포함하는 레코드를 정의할 수 있습니다. 각 필드는 대응하는 컬럼의 데이터 타입을 취합니다. `%ROWTYPE` 속성 앞에는 커서 이름 또는 커서 변수 이름을 접두어로 붙입니다.

```text
<record> <cursor>%ROWTYPE;
```

`record`는 레코드에 할당된 식별자입니다. `cursor`는 현재 범위에서 명시적으로 선언된 커서입니다.

다음 예제는 `%ROWTYPE`과 함께 커서를 사용하여 어느 직원이 어느 부서에서 일하는지에 대한 정보를 얻는 방법을 보여 줍니다.

```sql
CREATE OR REPLACE PROCEDURE emp_info
IS
    CURSOR empcur IS SELECT ename, deptno FROM emp;
    myvar           empcur%ROWTYPE;
BEGIN
    OPEN empcur;
    LOOP
        FETCH empcur INTO myvar;
        EXIT WHEN empcur%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE( myvar.ename || ' works in department '
            || myvar.deptno );
    END LOOP;
    CLOSE empcur;
END;
```

다음은 이 프로시저의 출력입니다.

```sql
EXEC emp_info;
```
