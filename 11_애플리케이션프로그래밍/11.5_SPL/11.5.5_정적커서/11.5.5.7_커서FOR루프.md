# 커서 FOR 루프 사용 (Using a cursor FOR loop) — EPAS 18 SPL 정적 커서

> 원문: [EPAS v18 — SPL › Working with static cursors › Using a cursor FOR loop](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/07_cursor_for_loop/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·구문·코드는 원문 그대로 보존했습니다.

커서의 결과 집합을 처리하는 데 필요한 프로그래밍 로직은 일반적으로 커서를 여는 문, 결과 집합의 각 행을 조회하는 루프 구조, 결과 집합의 끝을 확인하는 테스트, 그리고 커서를 닫는 문을 포함합니다. *커서 FOR 루프(cursor FOR loop)*는 이러한 문들을 개별적으로 작성할 필요를 없애는 루프 구조입니다.

커서 `FOR` 루프는 이전에 선언된 커서를 열고, 커서 결과 집합의 모든 행을 페치한 다음, 커서를 닫습니다.

이런 방식으로 열린 커서는 홀더블 커서(holdable cursor)이며, 이는 `FOR` 루프 내에서 발생하는 모든 COMMIT 또는 ROLLBACK에도 커서가 유지됨을 의미합니다.

커서 `FOR` 루프를 만드는 구문은 다음과 같습니다.

```sql
FOR <record> IN <cursor>
LOOP
   <statements>
END LOOP;
```

여기서:

`record`는 정의가 `cursor%ROWTYPE`인 암묵적으로 선언된 레코드에 할당된 식별자입니다.

`cursor`는 이전에 선언된 커서의 이름입니다.

`statements`는 하나 이상의 SPL 문입니다. 최소한 하나의 문이 있어야 합니다.

다음 예제는 커서 `FOR` 루프를 사용합니다.

```sql
CREATE OR REPLACE PROCEDURE cursor_example
IS
    CURSOR emp_cur_1 IS SELECT * FROM emp;
BEGIN
    DBMS_OUTPUT.PUT_LINE('EMPNO    ENAME');
    DBMS_OUTPUT.PUT_LINE('-----    -------');
    FOR v_emp_rec IN emp_cur_1 LOOP
        DBMS_OUTPUT.PUT_LINE(v_emp_rec.empno || '     ' || v_emp_rec.ename);
    END LOOP;
END;
```

다음은 이 프로시저의 출력입니다.

```sql
EXEC cursor_example;
```
