# 변수 선언에서 %TYPE 사용 (Using %TYPE in variable declarations) v18

SPL 프로그램에서는 데이터베이스의 테이블에서 가져온 값을 보관하는 데 사용되는 변수가 흔히 선언됩니다. 테이블 컬럼과 SPL 변수 간의 호환성을 보장하려면 데이터 타입이 동일한지 확인해야 합니다.

그러나 테이블 정의는 종종 변경됩니다. 컬럼의 데이터 타입이 변경되면 SPL 프로그램의 해당 변수도 그에 맞게 변경해야 할 수 있습니다.

특정 컬럼 데이터 타입을 변수 선언에 직접 코딩하는 대신, 컬럼 속성 `%TYPE`을 사용할 수 있습니다. 점 표기법(dot notation)으로 한정된 컬럼 이름 또는 앞서 선언된 변수의 이름을 `%TYPE`의 접두사로 지정합니다. `%TYPE` 앞에 붙인 컬럼 또는 변수의 데이터 타입이 선언 중인 변수에 할당됩니다. 지정된 컬럼 또는 변수의 데이터 타입이 변경되면 새 데이터 타입이 변수에 연결되며, 선언 코드를 수정할 필요가 없습니다.

##### 참고 (Note)

`%TYPE` 속성은 형식 매개변수(formal parameter) 선언에도 사용할 수 있습니다.

## 구문 (Syntax)

```sql
<name> { { <table> | <view> }.<column> | <variable> }%TYPE;
```

- `name`은 선언 중인 변수 또는 형식 매개변수에 할당된 식별자입니다.
- `column`은 `table` 또는 `view`의 컬럼 이름입니다.
- `variable`은 `name`으로 식별되는 변수보다 먼저 선언된 변수의 이름입니다.

##### 참고 (Note)

변수는 `NOT NULL` 절 또는 `DEFAULT` 절로 컬럼에 지정한 컬럼의 다른 속성은 상속하지 않습니다.

## 예제: %TYPE을 사용한 매개변수 정의 (Example: Defining parameters using %TYPE)

이 예제에서 프로시저는 다음을 수행합니다.

- 사원 번호를 사용하여 `emp` 테이블을 조회
- 사원의 데이터를 표시
- 해당 사원이 속한 부서의 모든 사원의 평균 급여를 찾음
- 선택한 사원의 급여를 부서 평균과 비교

```sql
CREATE OR REPLACE PROCEDURE emp_sal_query (
    p_empno         IN NUMBER
)
IS
    v_ename         VARCHAR2(10);
    v_job           VARCHAR2(9);
    v_hiredate      DATE;
    v_sal           NUMBER(7,2);
    v_deptno        NUMBER(2);
    v_avgsal        NUMBER(7,2);
BEGIN
    SELECT ename, job, hiredate, sal, deptno
        INTO v_ename, v_job, v_hiredate, v_sal, v_deptno
        FROM emp WHERE empno = p_empno;
    DBMS_OUTPUT.PUT_LINE('Employee # : ' || p_empno);
    DBMS_OUTPUT.PUT_LINE('Name       : ' || v_ename);
    DBMS_OUTPUT.PUT_LINE('Job        : ' || v_job);
    DBMS_OUTPUT.PUT_LINE('Hire Date  : ' || v_hiredate);
    DBMS_OUTPUT.PUT_LINE('Salary     : ' || v_sal);
    DBMS_OUTPUT.PUT_LINE('Dept #     : ' || v_deptno);

    SELECT AVG(sal) INTO v_avgsal
        FROM emp WHERE deptno = v_deptno;
    IF v_sal > v_avgsal THEN
        DBMS_OUTPUT.PUT_LINE('Employee''s salary is more than the '
            || 'department average of ' || v_avgsal);
    ELSE
        DBMS_OUTPUT.PUT_LINE('Employee''s salary does not exceed the '
            || 'department average of ' || v_avgsal);
    END IF;
END;
```

또는, `emp` 테이블 데이터 타입을 프로시저의 선언 섹션에 명시적으로 코딩하지 않고 프로시저를 작성할 수 있습니다.

```sql
CREATE OR REPLACE PROCEDURE emp_sal_query (
    p_empno         IN emp.empno%TYPE
)
IS
    v_ename         emp.ename%TYPE;
    v_job           emp.job%TYPE;
    v_hiredate      emp.hiredate%TYPE;
    v_sal           emp.sal%TYPE;
    v_deptno        emp.deptno%TYPE;
    v_avgsal        v_sal%TYPE;
BEGIN
    SELECT ename, job, hiredate, sal, deptno
        INTO v_ename, v_job, v_hiredate, v_sal, v_deptno
        FROM emp WHERE empno = p_empno;
    DBMS_OUTPUT.PUT_LINE('Employee # : ' || p_empno);
    DBMS_OUTPUT.PUT_LINE('Name       : ' || v_ename);
    DBMS_OUTPUT.PUT_LINE('Job        : ' || v_job);
    DBMS_OUTPUT.PUT_LINE('Hire Date  : ' || v_hiredate);
    DBMS_OUTPUT.PUT_LINE('Salary     : ' || v_sal);
    DBMS_OUTPUT.PUT_LINE('Dept #     : ' || v_deptno);

    SELECT AVG(sal) INTO v_avgsal
        FROM emp WHERE deptno = v_deptno;
    IF v_sal > v_avgsal THEN
        DBMS_OUTPUT.PUT_LINE('Employee''s salary is more than the '
            || 'department average of ' || v_avgsal);
    ELSE
        DBMS_OUTPUT.PUT_LINE('Employee''s salary does not exceed the '
            || 'department average of ' || v_avgsal);
    END IF;
END;
```

`p_empno`는 `%TYPE`을 사용하여 정의된 형식 매개변수의 예를 보여줍니다. `v_avgsal`은 테이블 컬럼 대신 다른 변수를 참조하는 `%TYPE`의 사용을 보여줍니다.

다음은 이 프로시저를 실행한 샘플 출력입니다.

```sql
EXEC emp_sal_query(7698);
```

Output

```text
Employee # : 7698
Name       : BLAKE
Job        : MANAGER
Hire Date  : 01-MAY-81 00:00:00
Salary     : 2850.00
Dept #     : 30
Employee's salary is more than the department average of 1566.67
```
