# 사용자 정의 레코드 타입과 레코드 변수 (User-defined record types and record variables) v18

[레코드 선언에서 %ROWTYPE 사용](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/03_variable_declarations/03_using__row_type_in_record_declarations/)에서 설명한 것처럼 `%ROWTYPE` 속성을 사용하여 테이블 정의를 기반으로 레코드를 선언할 수 있습니다. 특정 테이블 정의에 얽매이지 않는 새로운 레코드 구조를 정의할 수도 있습니다.

`TYPE IS RECORD` 문을 사용하여 레코드 타입의 정의를 생성합니다. _레코드 타입(record type)_ 은 하나 이상의 식별자와 그에 대응하는 데이터 타입으로 구성된 레코드의 정의입니다. 레코드 타입 자체만으로는 데이터를 조작할 수 없습니다.

## 구문 (Syntax)

`TYPE IS RECORD` 문의 구문은 다음과 같습니다.

```sql
TYPE <rec_type> IS RECORD ( <fields> )
```

여기서 `fields`는 다음 형식의 하나 이상의 필드 정의를 쉼표로 구분한 목록입니다.

```sql
<field_name> <data_type> [NOT NULL][{:= | DEFAULT} <default_value>]
```

여기서:

- `rec_type`은 레코드 타입에 할당된 식별자입니다.
- `field_name`은 레코드 타입의 필드에 할당된 식별자입니다.
- `data_type`은 `field_name`의 데이터 타입을 지정합니다.
- `DEFAULT` 절은 해당 필드에 기본 데이터 값을 할당합니다. 기본 표현식의 데이터 타입은 컬럼의 데이터 타입과 일치해야 합니다. 기본값을 지정하지 않으면 기본값은 `NULL`입니다.

_레코드 변수(record variable)_ 또는 _레코드(record)_ 는 레코드 타입의 인스턴스입니다. 레코드는 레코드 타입으로부터 선언됩니다. 필드 이름 및 타입과 같은 레코드의 속성은 레코드 타입으로부터 상속됩니다.

다음은 레코드 선언의 구문입니다.

```text
<record> <rectype>
```

`record`는 레코드 변수에 할당된 식별자입니다. `rectype`은 이전에 정의된 레코드 타입의 식별자입니다. 선언한 후에는 레코드를 사용하여 데이터를 보관할 수 없습니다.

점 표기법(dot notation)을 사용하여 레코드의 필드를 참조합니다.

```text
<record>.<field>
```

`record`는 이전에 선언된 레코드 변수이고, `field`는 `record`가 정의된 레코드 타입에 속하는 필드의 식별자입니다.

## 예제 (Example)

이 `emp_sal_query` 프로시저는 사용자 정의 레코드 타입과 레코드 변수를 사용합니다.

```sql
CREATE OR REPLACE PROCEDURE emp_sal_query (
    p_empno         IN emp.empno%TYPE
)
IS
    TYPE emp_typ IS RECORD (
        ename       emp.ename%TYPE,
        job         emp.job%TYPE,
        hiredate    emp.hiredate%TYPE,
        sal         emp.sal%TYPE,
        deptno      emp.deptno%TYPE
    );
    r_emp           emp_typ;
    v_avgsal        emp.sal%TYPE;
BEGIN
    SELECT ename, job, hiredate, sal, deptno
        INTO r_emp.ename, r_emp.job, r_emp.hiredate, r_emp.sal, r_emp.deptno
        FROM emp WHERE empno = p_empno;
    DBMS_OUTPUT.PUT_LINE('Employee # : ' || p_empno);
    DBMS_OUTPUT.PUT_LINE('Name       : ' || r_emp.ename);
    DBMS_OUTPUT.PUT_LINE('Job        : ' || r_emp.job);
    DBMS_OUTPUT.PUT_LINE('Hire Date  : ' || r_emp.hiredate);
    DBMS_OUTPUT.PUT_LINE('Salary     : ' || r_emp.sal);
    DBMS_OUTPUT.PUT_LINE('Dept #     : ' || r_emp.deptno);

    SELECT AVG(sal) INTO v_avgsal
        FROM emp WHERE deptno = r_emp.deptno;
    IF r_emp.sal > v_avgsal THEN
        DBMS_OUTPUT.PUT_LINE('Employee''s salary is more than the '
            || 'department average of ' || v_avgsal);
    ELSE
        DBMS_OUTPUT.PUT_LINE('Employee''s salary does not exceed the '
            || 'department average of ' || v_avgsal);
    END IF;
END;
```

데이터 타입 이름을 지정하는 대신, 레코드 타입 정의에서 필드 데이터 타입에 `%TYPE` 속성을 사용할 수 있습니다.

다음은 이 저장 프로시저를 실행한 출력입니다.

```sql
EXEC emp_sal_query(7698);
```

Output

```text
Employee # : 7698
Name       : BLAKE
Job        : MANAGER
Hire Date  : 01-MAY-81 00:00:00
Salary     : 2850.00
Dept #     : 30
Employee's salary is more than the department average of 1566.67
```
