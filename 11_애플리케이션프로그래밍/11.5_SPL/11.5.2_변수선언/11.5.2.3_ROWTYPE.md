# 레코드 선언에서 %ROWTYPE 사용 (Using %ROWTYPE in record declarations) v18

`%TYPE` 속성은 컬럼의 데이터 타입에 의존하는 변수를 쉽게 생성하는 방법을 제공합니다. `%ROWTYPE` 속성을 사용하면 지정된 테이블의 모든 컬럼에 대응하는 필드를 포함하는 레코드를 정의할 수 있습니다. 각 필드는 대응하는 컬럼의 데이터 타입을 가집니다. 레코드의 필드는 `NOT NULL` 절이나 `DEFAULT` 절로 지정된 것과 같은 컬럼의 다른 속성은 상속하지 않습니다.

_레코드(record)_ 는 명명된, 순서가 있는 필드의 모음입니다. _필드(field)_ 는 변수와 유사합니다. 필드는 식별자와 데이터 타입을 가지지만, 레코드에 속한다는 추가적인 속성을 가집니다. 레코드 이름을 한정자로 하는 점 표기법(dot notation)을 사용하여 필드를 참조해야 합니다.

## 구문 (Syntax)

`%ROWTYPE` 속성을 사용하여 레코드를 선언할 수 있습니다. `%ROWTYPE` 속성 앞에는 테이블 이름이 붙습니다. 명명된 테이블의 각 컬럼은 해당 컬럼과 동일한 데이터 타입을 가지며 동일한 이름의 필드를 레코드에 정의합니다.

```text
<record> <table>%ROWTYPE;
```

- `record`는 레코드에 할당된 식별자입니다.
- `table`은 컬럼이 레코드의 필드를 정의하는 테이블 또는 뷰의 이름입니다.

## 예제 (Example)

이 예제는 [변수 선언에서 %TYPE 사용](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/03_variable_declarations/02_using__type_in_variable_declarations/)의 `emp_sal_query` 프로시저를 수정하여, `emp`의 컬럼에 대해 개별 변수를 선언하는 대신 `emp%ROWTYPE`을 사용하여 `r_emp`라는 레코드를 생성하는 방법을 보여줍니다.

```sql
CREATE OR REPLACE PROCEDURE emp_sal_query (
    p_empno         IN emp.empno%TYPE
)
IS
    r_emp           emp%ROWTYPE;
    v_avgsal        emp.sal%TYPE;
BEGIN
    SELECT ename, job, hiredate, sal, deptno
        INTO r_emp.ename, r_emp.job, r_emp.hiredate, r_emp.sal, r_emp.deptno
        FROM emp WHERE empno = p_empno;
    DBMS_OUTPUT.PUT_LINE('Employee # : ' || p_empno);
    DBMS_OUTPUT.PUT_LINE('Name       : ' || r_emp.ename);
    DBMS_OUTPUT.PUT_LINE('Job        : ' || r_emp.job);
    DBMS_OUTPUT.PUT_LINE('Hire Date  : ' || r_emp.hiredate);
    DBMS_OUTPUT.PUT_LINE('Salary     : ' || r_emp.sal);
    DBMS_OUTPUT.PUT_LINE('Dept #     : ' || r_emp.deptno);
    SELECT AVG(sal) INTO v_avgsal
        FROM emp WHERE deptno = r_emp.deptno;
    IF r_emp.sal > v_avgsal THEN
        DBMS_OUTPUT.PUT_LINE('Employee''s salary is more than the '
            || 'department average of ' || v_avgsal);
    ELSE
        DBMS_OUTPUT.PUT_LINE('Employee''s salary does not exceed the '
            || 'department average of ' || v_avgsal);
    END IF;
END;
```
