# 변수 선언 (Declaring a variable) v18

일반적으로 블록에서 사용하는 모든 변수는 블록의 선언 섹션에서 선언해야 합니다. 변수 선언은 변수에 할당되는 이름과 그 데이터 타입으로 구성됩니다. 선택적으로 변수 선언에서 변수를 기본값으로 초기화할 수 있습니다.

## 구문 (Syntax)

변수 선언의 일반적인 구문은 다음과 같습니다.

```sql
<name> <type> [ { := | DEFAULT } { <expression> | NULL } ];
```

`name`은 변수에 할당된 식별자입니다.

`type`은 변수에 할당된 데이터 타입입니다.

`[ := expression ]`은 주어진 경우, 블록에 진입할 때 변수에 할당되는 초기값을 지정합니다. 이 절이 주어지지 않으면 변수는 SQL `NULL` 값으로 초기화됩니다.

기본값은 블록에 진입할 때마다 평가됩니다. 따라서 예를 들어 `DATE` 타입의 변수에 `SYSDATE`를 할당하면 프로시저나 함수가 사전 컴파일(precompile)된 시각이 아니라 현재 호출 시각을 변수가 가지게 됩니다.

## 예제: 기본값을 사용하는 변수 선언 (Example: Variable declarations that use defaults)

이 프로시저는 문자열 및 숫자 표현식으로 구성된 기본값을 사용하는 몇 가지 변수 선언을 보여줍니다.

```sql
CREATE OR REPLACE PROCEDURE dept_salary_rpt (
    p_deptno        NUMBER
)
IS
    todays_date     DATE := SYSDATE;
    rpt_title       VARCHAR2(60) := 'Report For Department # ' || p_deptno
                             || ' on ' || todays_date;
    base_sal        INTEGER := 35525;
    base_comm_rate  NUMBER := 1.33333;
    base_annual     NUMBER := ROUND(base_sal * base_comm_rate, 2);
BEGIN
    DBMS_OUTPUT.PUT_LINE(rpt_title);
    DBMS_OUTPUT.PUT_LINE('Base Annual Salary: ' || base_annual);
END;
```

다음 프로시저 출력은 변수 선언의 기본값이 변수에 할당됨을 보여줍니다.

```sql
EXEC dept_salary_rpt(20);
```

Output

```text
Report For Department # 20 on 10-JUL-07 16:44:45
Base Annual Salary: 47366.55
```
