# 사용자 정의 REF CURSOR 타입 변수 선언 (Declaring a user-defined REF CURSOR type variable) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › REF CURSOR and cursor variables › Declaring a cursor variable › Declaring a user-defined REF CURSOR type variable](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/09_ref_cursors_and_cursor_variables/02_declaring_a_cursor_variable/02_declaring_a_user_defined_ref_cursor_type_variable/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

사용자 정의 `REF CURSOR` 변수를 사용하려면 두 가지 별개의 선언 단계를 수행해야 합니다:

- 참조 커서 `TYPE`을 생성합니다.
- 그 `TYPE`을 기반으로 실제 커서 변수를 선언합니다.

사용자 정의 `REF CURSOR` 타입을 생성하는 구문은 다음과 같습니다:

```sql
TYPE <cursor_type_name> IS REF CURSOR [RETURN <return_type>];
```

다음 예제는 커서 변수 선언을 보여줍니다:

```sql
DECLARE
    TYPE emp_cur_type IS REF CURSOR RETURN emp%ROWTYPE;
    my_rec emp_cur_type;
        ...
```
