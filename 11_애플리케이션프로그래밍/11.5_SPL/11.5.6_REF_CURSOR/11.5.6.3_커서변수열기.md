# 커서 변수 열기 (Opening a cursor variable) — EPAS 18 SPL REF CURSOR

> 원문: [EPAS v18 — SPL › REF CURSOR and cursor variables › Opening a cursor variable](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/09_ref_cursors_and_cursor_variables/03_opening_a_cursor_variable/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·구문·코드는 원문 그대로 보존했습니다.

커서 변수를 선언한 후에는 연관된 `SELECT` 명령으로 열어야 합니다. `OPEN FOR` 문은 결과 집합을 만드는 데 사용할 `SELECT` 명령을 지정합니다.

```sql
OPEN <name> FOR query;
```

여기서:

`name`은 이전에 선언된 커서 변수의 식별자입니다.

`query`는 문이 실행될 때 결과 집합을 결정하는 `SELECT` 명령입니다.

`OPEN FOR` 문이 실행된 후 커서 변수의 값은 결과 집합을 식별합니다.

이 예제는 선택된 부서의 직원 번호와 이름 목록인 결과 집합을 보여 줍니다. 표현식이 정상적으로 나타날 수 있는 곳이라면 어디에나 `SELECT` 명령에서 변수나 파라미터를 사용할 수 있습니다. 이 경우 부서 번호에 대한 동등 테스트에 파라미터가 사용됩니다.

```sql
CREATE OR REPLACE PROCEDURE emp_by_dept (
    p_deptno        emp.deptno%TYPE
)
IS
    emp_refcur      SYS_REFCURSOR;
BEGIN
    OPEN emp_refcur FOR SELECT empno, ename FROM emp WHERE deptno = p_deptno;
        ...
```
