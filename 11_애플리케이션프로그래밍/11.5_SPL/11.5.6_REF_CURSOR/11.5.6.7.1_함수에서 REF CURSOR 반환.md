# 함수에서 REF CURSOR 반환 (Returning a REF CURSOR from a function) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › REF CURSOR and cursor variables › Cursor variable examples › Returning a REF CURSOR from a function](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/09_ref_cursors_and_cursor_variables/07_examples/01_returning_a_ref_cursor_from_a_function/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 주어진 직무(job)의 직원을 선택하는 쿼리로 커서 변수를 엽니다. 커서 변수는 이 함수의 `RETURN` 문에 지정되며, 이를 통해 결과 집합을 함수 호출자가 사용할 수 있게 합니다.

```sql
CREATE OR REPLACE FUNCTION emp_by_job (p_job VARCHAR2)
RETURN SYS_REFCURSOR
IS
    emp_refcur      SYS_REFCURSOR;
BEGIN
    OPEN emp_refcur FOR SELECT empno, ename FROM emp WHERE job = p_job;
    RETURN emp_refcur;
END;
```

이 함수는 다음 익명 블록에서, 함수의 반환값을 익명 블록의 선언 섹션에 선언된 커서 변수에 할당하는 방식으로 호출됩니다. 결과 집합은 이 커서 변수를 사용하여 페치되고 그 후 닫힙니다.

```sql
DECLARE
    v_empno         emp.empno%TYPE;
    v_ename         emp.ename%TYPE;
    v_job           emp.job%TYPE := 'SALESMAN';
    v_emp_refcur    SYS_REFCURSOR;
BEGIN
    DBMS_OUTPUT.PUT_LINE('EMPLOYEES WITH JOB ' || v_job);
    DBMS_OUTPUT.PUT_LINE('EMPNO    ENAME');
    DBMS_OUTPUT.PUT_LINE('-----    -------');
    v_emp_refcur := emp_by_job(v_job);
    LOOP
        FETCH v_emp_refcur INTO v_empno, v_ename;
        EXIT WHEN v_emp_refcur%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE(v_empno || '     ' || v_ename);
    END LOOP;
    CLOSE v_emp_refcur;
END;
```

다음은 익명 블록을 실행했을 때의 출력입니다:

출력(Output)

```text
EMPLOYEES WITH JOB SALESMAN
EMPNO    ENAME
-----    -------
7499     ALLEN
7521     WARD
7654     MARTIN
7844     TURNER
```
