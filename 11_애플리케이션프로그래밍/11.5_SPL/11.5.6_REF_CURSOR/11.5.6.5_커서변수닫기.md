# 커서 변수 닫기 (Closing a cursor variable) — EPAS 18 SPL REF CURSOR

> 원문: [EPAS v18 — SPL › REF CURSOR and cursor variables › Closing a cursor variable](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/09_ref_cursors_and_cursor_variables/05_closing_a_cursor_variable/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드는 원문 그대로 보존했습니다.

결과 집합을 해제하려면 [커서 닫기(Closing a cursor)](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/04_closing_a_cursor/#closing_a_cursor)에서 설명한 `CLOSE` 문을 사용합니다.

##### 참고

정적 커서와 달리, 커서 변수를 다시 열기 전에 반드시 닫을 필요는 없습니다. 다시 열면 이전에 열었을 때의 결과 집합은 사라집니다.

이 예제에는 `CLOSE` 문이 포함되어 있습니다.

```sql
CREATE OR REPLACE PROCEDURE emp_by_dept (
    p_deptno        emp.deptno%TYPE
)
IS
    emp_refcur      SYS_REFCURSOR;
    v_empno         emp.empno%TYPE;
    v_ename         emp.ename%TYPE;
BEGIN
    OPEN emp_refcur FOR SELECT empno, ename FROM emp WHERE deptno = p_deptno;
    DBMS_OUTPUT.PUT_LINE('EMPNO    ENAME');
    DBMS_OUTPUT.PUT_LINE('-----    -------');
    LOOP
        FETCH emp_refcur INTO v_empno, v_ename;
        EXIT WHEN emp_refcur%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE(v_empno || '     ' || v_ename);
    END LOOP;
    CLOSE emp_refcur;
END;
```

다음은 이 프로시저의 출력입니다.

```sql
EXEC emp_by_dept(20)
```

출력

```text
EMPNO    ENAME
-----    -------
7369     SMITH
7566     JONES
7788     SCOTT
7876     ADAMS
7902     FORD
```
