# REF CURSOR 개요 (REF CURSOR overview) — EPAS 18 SPL REF CURSOR

> 원문: [EPAS v18 — SPL › REF CURSOR and cursor variables › REF CURSOR overview](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/09_ref_cursors_and_cursor_variables/01_ref_cursor_overview/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입·명령은 원문 그대로 보존했습니다.

*커서 변수(cursor variable)*는 쿼리 결과 집합에 대한 포인터를 담은 커서입니다. 결과 집합은 커서 변수를 사용하여 `OPEN FOR` 문을 실행함으로써 결정됩니다.

커서 변수는 정적 커서처럼 단일 쿼리에 묶이지 않습니다. 서로 다른 쿼리를 담은 `OPEN FOR` 문으로 동일한 커서 변수를 여러 번 열 수 있습니다. 매번 그 쿼리로부터 새 결과 집합이 생성되어 커서 변수를 통해 사용할 수 있게 됩니다.

`REF CURSOR` 타입을 저장 프로시저 및 함수의 파라미터로 전달하거나 반환할 수 있습니다. 함수의 반환 타입도 `REF CURSOR` 타입이 될 수 있습니다. 이 능력을 통해 프로그램 간에 커서 변수를 전달함으로써 커서에 대한 작업을 별도의 프로그램으로 모듈화할 수 있습니다.
