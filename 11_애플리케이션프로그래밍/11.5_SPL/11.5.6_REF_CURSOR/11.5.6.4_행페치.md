# 커서 변수에서 행 페치 (Fetching rows from a cursor variable) — EPAS 18 SPL REF CURSOR

> 원문: [EPAS v18 — SPL › REF CURSOR and cursor variables › Fetching rows from a cursor variable](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/09_ref_cursors_and_cursor_variables/04_fetching_rows_from_a_cursor_variable/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드는 원문 그대로 보존했습니다.

커서 변수를 연 후에는 `FETCH` 문을 사용하여 결과 집합에서 행을 조회할 수 있습니다. 자세한 내용은 [커서에서 행 페치(Fetching rows from a cursor)](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/03_fetching_rows_from_a_cursor/#fetching_rows_from_a_cursor)를 참조하십시오.

이 예제는 `FETCH` 문을 사용하여 결과 집합을 두 변수로 반환한 다음 표시합니다. 정적 커서의 커서 상태를 판단하는 데 사용하는 커서 속성을 커서 변수에도 사용할 수 있습니다. 자세한 내용은 [커서 속성(Cursor attributes)](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/08_static_cursors/06_cursor_attributes/#cursor_attributes)를 참조하십시오.

```sql
CREATE OR REPLACE PROCEDURE emp_by_dept (
    p_deptno        emp.deptno%TYPE
)
IS
    emp_refcur      SYS_REFCURSOR;
    v_empno         emp.empno%TYPE;
    v_ename         emp.ename%TYPE;
BEGIN
    OPEN emp_refcur FOR SELECT empno, ename FROM emp WHERE deptno = p_deptno;
    DBMS_OUTPUT.PUT_LINE('EMPNO    ENAME');
    DBMS_OUTPUT.PUT_LINE('-----    -------');
    LOOP
        FETCH emp_refcur INTO v_empno, v_ename;
        EXIT WHEN emp_refcur%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE(v_empno || '     ' || v_ename);
    END LOOP;
        ...
```
