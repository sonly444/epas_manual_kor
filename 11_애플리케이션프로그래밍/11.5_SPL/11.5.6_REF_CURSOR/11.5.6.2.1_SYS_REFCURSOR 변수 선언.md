# SYS_REFCURSOR 커서 변수 선언 (Declaring a SYS_REFCURSOR cursor variable) — EPAS 18 SPL

> 원문: [EPAS v18 — SPL › REF CURSOR and cursor variables › Declaring a cursor variable › Declaring a SYS_REFCURSOR cursor variable](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/09_ref_cursors_and_cursor_variables/02_declaring_a_cursor_variable/01_declaring_a_sys_refcursor_cursor_variable/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

다음은 `SYS_REFCURSOR` 커서 변수를 선언하는 구문입니다:

```sql
<name> SYS_REFCURSOR;
```

여기서 `name`은 커서 변수에 할당하는 식별자입니다.

다음 예제는 `SYS_REFCURSOR` 변수 선언을 보여줍니다:

```sql
DECLARE
    emp_refcur      SYS_REFCURSOR;
        ...
```
