# 동적 SQL 사용 (Using dynamic SQL) v18

_동적 SQL(Dynamic SQL)_ 은 명령이 실행되기 직전까지 알 수 없는 SQL 명령을 실행할 수 있게 해 주는 기법입니다. 정적(static) SQL 명령에서는 프로그램이 실행을 시작하기 전에 (변수를 제외한) 전체 명령이 알려져 있고 프로그램에 코딩되어 있어야 합니다. 동적 SQL을 사용하면 프로그램 런타임 중에 실행되는 SQL이 변경될 수 있습니다.

또한 동적 SQL은 `CREATE TABLE`과 같은 데이터 정의 명령을 SPL 프로그램에서 실행할 수 있는 유일한 방법입니다.

그러나 동적 SQL의 런타임 성능은 정적 SQL보다 느립니다.

## 구문 (Syntax)

`EXECUTE IMMEDIATE` 명령은 SQL 명령을 동적으로 실행하는 데 사용됩니다.

```sql
EXECUTE IMMEDIATE '<sql_expression>;'
  [ INTO { <variable> [, ...] | <record> } ]
  [ USING {[<bind_type>] <bind_argument>} [, ...]} ];
```

여기서:

- `sql_expression`은 동적으로 실행할 SQL 명령을 포함하는 문자열 표현식입니다.
- `variable`은 `sql_expression`의 SQL 명령 실행 결과로 생성된, 일반적으로 `SELECT` 명령에서 나온 결과 집합의 출력을 받습니다. 변수의 개수, 순서, 타입은 결과 집합의 필드의 개수 및 순서와 일치해야 하며 타입 호환이 가능해야 합니다.

`USING` 절을 사용하면 `expression`의 값이 _플레이스홀더(placeholder)_ 로 전달됩니다. 플레이스홀더는 변수를 사용할 수 있는 `sql_expression`의 SQL 명령 안에 내장되어 나타납니다. 플레이스홀더는 콜론(:) 접두사가 붙은 식별자로 표시되며, 예를 들어 `:name`과 같습니다. 평가된 표현식의 개수와 순서는 `sql_expression`의 플레이스홀더의 개수, 순서와 일치해야 합니다. 결과 데이터 타입도 플레이스홀더와 호환되어야 합니다. 플레이스홀더는 SPL 프로그램에서 선언하지 않습니다. 플레이스홀더는 `sql_expression`에만 나타납니다.

현재 `bind_type`은 무시되며, `bind_argument`는 `IN OUT`으로 처리됩니다.

또는, 레코드의 필드가 결과 집합의 개수 및 순서와 일치하고 타입 호환이 가능한 경우 `record`를 지정할 수 있습니다.

`INTO` 절을 사용할 때는 결과 집합에서 정확히 하나의 행이 반환되어야 합니다. 그렇지 않으면 예외가 발생합니다. `USING` 절을 사용하면 `expression`의 값이 _플레이스홀더(placeholder)_ 로 전달됩니다. 플레이스홀더는 변수를 사용할 수 있는 `sql_expression`의 SQL 명령 안에 내장되어 나타납니다. 플레이스홀더는 콜론(:) 접두사가 붙은 식별자로 표시되며, 예를 들어 `:name`과 같습니다. 평가된 표현식의 개수, 순서, 결과 데이터 타입은 `sql_expression`의 플레이스홀더의 개수 및 순서와 일치해야 하며 타입 호환이 가능해야 합니다.

플레이스홀더는 SPL 프로그램의 어디에서도 선언되지 않습니다. 플레이스홀더는 `sql_expression`에만 나타납니다.

현재 `bind_type`의 모든 옵션은 무시되며 `bind_argument`는 `IN OUT`으로 처리됩니다.

## 예제: 문자열 리터럴로서의 SQL 명령 (Example: SQL commands as string literals)

이 예제는 문자열 리터럴로 표현된 기본적인 동적 SQL 명령을 보여줍니다.

```sql
DECLARE
    v_sql           VARCHAR2(50);
BEGIN
    EXECUTE IMMEDIATE 'CREATE TABLE job (jobno NUMBER(3),' ||
        ' jname VARCHAR2(9))';
    v_sql := 'INSERT INTO job VALUES (100, ''ANALYST'')';
    EXECUTE IMMEDIATE v_sql;
    v_sql := 'INSERT INTO job VALUES (200, ''CLERK'')';
    EXECUTE IMMEDIATE v_sql;
END;
```

이 예제는 `USING` 절을 사용하여 SQL 문자열의 플레이스홀더에 값을 전달합니다.

```sql
DECLARE
    v_sql           VARCHAR2(50) := 'INSERT INTO job VALUES ' ||
                        '(:p_jobno, :p_jname)';
    v_jobno         job.jobno%TYPE;
    v_jname         job.jname%TYPE;
BEGIN
    v_jobno := 300;
    v_jname := 'MANAGER';
    EXECUTE IMMEDIATE v_sql USING v_jobno, v_jname;
    v_jobno := 400;
    v_jname := 'SALESMAN';
    EXECUTE IMMEDIATE v_sql USING v_jobno, v_jname;
    v_jobno := 500;
    v_jname := 'PRESIDENT';
    EXECUTE IMMEDIATE v_sql USING v_jobno, v_jname;
END;
```

이 예제는 `INTO` 절과 `USING` 절을 모두 보여줍니다. `SELECT` 명령의 마지막 실행은 개별 변수 대신 레코드로 결과를 반환합니다.

```sql
DECLARE
    v_sql           VARCHAR2(60);
    v_jobno         job.jobno%TYPE;
    v_jname         job.jname%TYPE;
    r_job           job%ROWTYPE;
BEGIN
    DBMS_OUTPUT.PUT_LINE('JOBNO    JNAME');
    DBMS_OUTPUT.PUT_LINE('-----    -------');
    v_sql := 'SELECT jobno, jname FROM job WHERE jobno = :p_jobno';
    EXECUTE IMMEDIATE v_sql INTO v_jobno, v_jname USING 100;
    DBMS_OUTPUT.PUT_LINE(v_jobno || '      ' || v_jname);
    EXECUTE IMMEDIATE v_sql INTO v_jobno, v_jname USING 200;
    DBMS_OUTPUT.PUT_LINE(v_jobno || '      ' || v_jname);
    EXECUTE IMMEDIATE v_sql INTO v_jobno, v_jname USING 300;
    DBMS_OUTPUT.PUT_LINE(v_jobno || '      ' || v_jname);
    EXECUTE IMMEDIATE v_sql INTO v_jobno, v_jname USING 400;
    DBMS_OUTPUT.PUT_LINE(v_jobno || '      ' || v_jname);
    EXECUTE IMMEDIATE v_sql INTO r_job USING 500;
    DBMS_OUTPUT.PUT_LINE(r_job.jobno || '      ' || r_job.jname);
END;
```

다음은 이 익명 블록(anonymous block)의 출력입니다.

Output

```text
JOBNO    JNAME
-----    -------
100      ANALYST
200      CLERK
300      MANAGER
400      SALESMAN
500      PRESIDENT
```

`BULK COLLECT` 절을 사용하여 `EXECUTE IMMEDIATE` 문의 결과 집합을 명명된 컬렉션(named collection)으로 모을 수 있습니다. 자세한 내용은 [Using the BULK COLLECT clause](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/12_working_with_collections/04_using_the_bulk_collect_clause/#using_the_bulk_collect_clause)의 `EXECUTE IMMEDIATE BULK COLLECT`를 참조하십시오.
