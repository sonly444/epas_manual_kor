# 패키지 참조 (Referencing a Package) — EPAS 18 Application Programming

> 원문: [EPAS v18 — Working with packages › Referencing a package](https://www.enterprisedb.com/docs/epas/latest/application_programming/02_packages/03_referencing_a_package/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드는 원문 그대로 보존했습니다.

패키지 명세에 선언된 타입·아이템·서브프로그램을 참조하려면 점 표기법(dot notation)을 사용합니다. 예:

`package_name.type_name`
`package_name.item_name`
`package_name.subprogram_name`

`emp_admin` 패키지 명세의 함수를 호출하려면 다음 SQL 명령을 실행합니다.
```sql
SELECT emp_admin.get_dept_name(10) FROM DUAL;
```
이 예는 `emp_admin` 패키지에 선언된 `get_dept_name` 함수를 호출합니다. 부서 번호를 인자로 전달하면 함수가 부서 이름을 반환합니다. 반환 값은 부서 번호 `10`에 해당하는 `ACCOUNTING`입니다.
