# 패키지 (Packages) — EPAS 18 Application Programming

> 원문: [EPAS v18 — Application programming › Working with packages](https://www.enterprisedb.com/docs/epas/latest/application_programming/02_packages/)
> EPAS v18 공식 문서의 한글 번역입니다. 패키지·키워드 이름은 원문 그대로 보존했습니다.

패키지는 함수, 프로시저, 변수, 커서, 사용자 정의 레코드 타입·레코드를 하나의 식별자로 묶은 명명된 모음입니다.

## 구조
- **패키지 명세(Package Specification)**: `EXECUTE` 권한을 가진 외부 프로그램에 보이는 공개(public) 선언.
- **패키지 본문(Package Body)**: 구현부. 비공개(private) 엔티티 포함.

공개 엔티티는 시그니처(이름·파라미터·반환 타입)만 노출하고 구현은 숨기며, 비공개 엔티티는 패키지 내부 서브프로그램에서만 접근 가능. 함수·프로시저는 서로 다른 시그니처로 오버로딩 가능합니다.

## 내장 패키지 (Oracle 호환, 참조 섹션에서 상세)
`DBMS_ALERT`, `DBMS_AQ`, `DBMS_AQADM`, `DBMS_CRYPTO`, `DBMS_JOB`, `DBMS_LOB`, `DBMS_OUTPUT`, `DBMS_PIPE`, `DBMS_PROFILER`, `DBMS_RANDOM`, `DBMS_REDACT`, `DBMS_RLS`, `DBMS_SCHEDULER`, `DBMS_SQL`, `UTL_ENCODE`, `UTL_FILE`, `UTL_HTTP`, `UTL_MAIL`, `UTL_RAW`, `UTL_SMTP`(AUTH·STARTTLS 지원), `UTL_URL` 등.

## 예시 (개념)
```sql
CREATE OR REPLACE PACKAGE emp_pkg IS
  PROCEDURE hire(p_ename VARCHAR2);
  FUNCTION  salary(p_empno NUMBER) RETURN NUMBER;
END emp_pkg;

CREATE OR REPLACE PACKAGE BODY emp_pkg IS
  PROCEDURE hire(p_ename VARCHAR2) IS BEGIN ... END;
  FUNCTION  salary(p_empno NUMBER) RETURN NUMBER IS BEGIN ... END;
END emp_pkg;
```
