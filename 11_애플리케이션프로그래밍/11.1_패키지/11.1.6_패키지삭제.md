# 패키지 삭제 (Dropping a Package) — EPAS 18 Application Programming

> 원문: [EPAS v18 — Working with packages › Dropping a package](https://www.enterprisedb.com/docs/epas/latest/application_programming/02_packages/05_dropping_a_package/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드는 원문 그대로 보존했습니다.

전체 패키지 또는 패키지 본문을 삭제하는 구문:
```sql
DROP PACKAGE [ BODY ] package_name;
```
키워드 `BODY`를 생략하면 패키지 명세와 패키지 본문이 모두 삭제되고, `BODY`를 지정하면 패키지 본문만 삭제되며 명세는 그대로 유지됩니다. `package_name` 파라미터는 제거할 패키지 식별자입니다.

## 예제
패키지 본문만 제거:
```sql
DROP PACKAGE BODY emp_admin;
```
전체 패키지 제거:
```sql
DROP PACKAGE emp_admin;
```
