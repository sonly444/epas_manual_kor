# 패키지 컴포넌트 (Package components) — EPAS 18 Application Programming

> 원문: [EPAS v18 — Application programming › Working with packages › Package components](https://www.enterprisedb.com/docs/epas/latest/application_programming/02_packages/01_package_components/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·키워드·구문·코드는 원문 그대로 보존했습니다.

패키지는 두 가지 주요 구성 요소로 이루어집니다.

- **패키지 명세(package specification)** — 공개 인터페이스입니다. 이 요소들은 패키지 외부에서 참조할 수 있습니다. 패키지에 속하는 모든 데이터베이스 객체를 명세에 선언합니다.

- **패키지 본문(package body)** — 패키지 명세에 선언된 모든 데이터베이스 객체의 실제 구현을 담습니다.

패키지 본문은 패키지 명세의 사양을 구현합니다. 애플리케이션에 보이지 않는 구현 세부와 비공개 선언을 포함합니다. 명세를 변경하지 않고 패키지 본문을 디버깅·개선·교체할 수 있습니다. 마찬가지로, 구현 세부가 애플리케이션에 보이지 않으므로 호출 프로그램을 재컴파일하지 않고 본문을 변경할 수 있습니다.

## 패키지 명세 구문 (Package specification syntax)

패키지 명세는 패키지의 사용자 인터페이스(API)를 정의합니다. 명세는 패키지 사용자에게 보이는 함수, 프로시저, 타입, 예외, 커서를 나열합니다.

패키지의 인터페이스를 정의하는 데 사용하는 구문은 다음과 같습니다.

```sql
CREATE [ OR REPLACE ] PACKAGE <package_name>
  [ <authorization_clause> ]
  { IS | AS }
  [ <declaration>; ] ...
  [ <procedure_or_function_declaration> ] ...
END [ <package_name> ] ;
```

여기서 `authorization_clause` :=

```sql
{ AUTHID DEFINER } | { AUTHID CURRENT_USER }
```

여기서 `procedure_or_function_declaration` :=

```text
procedure_declaration | function_declaration
```

여기서 `procedure_declaration` :=

```sql
PROCEDURE proc_name [ argument_list ];
[ restriction_pragma; ]
```

여기서 `function_declaration` :=

```sql
FUNCTION func_name [ argument_list ]
  RETURN rettype [ DETERMINISTIC ];
[ restriction_pragma; ]
```

여기서 `argument_list` :=

```text
( argument_declaration [, ...] )
```

여기서 `argument_declaration` :=

```text
argname [ IN | IN OUT | OUT ] argtype [ DEFAULT value ]
```

여기서 `restriction_pragma` :=

```sql
PRAGMA RESTRICT_REFERENCES(name, restrictions)
```

여기서 `restrictions` :=

```text
restriction [, ... ]
```

### 파라미터 (Parameters)

`package_name`

`package_name`은 패키지에 부여하는 식별자입니다. 각 패키지는 스키마 내에서 고유한 이름을 가져야 합니다.

`AUTHID DEFINER`

`AUTHID` 절을 생략하거나 `AUTHID DEFINER`를 지정하면, 데이터베이스 객체에 대한 접근 권한을 결정하는 데 패키지 소유자의 권한이 사용됩니다.

`AUTHID CURRENT_USER`

`AUTHID CURRENT_USER`를 지정하면, 패키지 내 프로그램을 실행하는 현재 사용자의 권한이 접근 권한 결정에 사용됩니다.

`declaration`

`declaration`은 공개 변수의 식별자입니다. 패키지 외부에서 `package_name.variable` 구문을 사용하여 공개 변수에 접근할 수 있습니다. 공개 변수는 0개, 1개, 또는 여러 개가 있을 수 있습니다. 공개 변수 정의는 프로시저 또는 함수 선언보다 앞에 와야 합니다.

`declaration`은 다음 중 하나일 수 있습니다.

- 변수 선언(Variable declaration)
- 레코드 선언(Record declaration)
- 컬렉션 선언(Collection declaration)
- `REF CURSOR` 및 커서 변수 선언
- 레코드, 컬렉션, `REF CURSOR`에 대한 `TYPE` 정의
- 예외(Exception)
- 객체 변수 선언(Object variable declaration)

`proc_name`

공개 프로시저의 이름입니다.

`argname`

인자의 이름입니다. 함수 또는 프로시저 본문에서 이 이름으로 인자를 참조합니다.

`IN` | `IN OUT` | `OUT`

인자 모드입니다. `IN`(기본값)은 인자를 입력 전용으로 선언합니다. `IN OUT`은 인자가 값을 수신하고 반환할 수 있게 합니다. `OUT`은 인자가 출력 전용임을 지정합니다.

`argtype`

인자의 데이터 타입입니다. 인자 타입은 기본 데이터 타입, `%TYPE`을 사용한 기존 컬럼 타입의 복사본, 또는 중첩 테이블(nested table)이나 객체 타입 같은 사용자 정의 타입일 수 있습니다. 기본 타입에는 길이를 지정하지 마십시오. 예를 들어 `VARCHAR2(10)`이 아니라 `VARCHAR2`를 지정합니다.

컬럼의 타입은 `tablename.columnname %TYPE`으로 참조합니다. 이 표기법을 사용하면 때때로 프로시저를 테이블 정의 변경으로부터 독립적으로 만드는 데 도움이 됩니다.

`DEFAULT value`

`DEFAULT` 절은 호출 시 값을 제공하지 않을 경우 입력 인자에 기본값을 공급합니다. `IN OUT` 또는 `OUT` 모드의 인자에는 `DEFAULT`를 지정할 수 없습니다.

`func_name`

공개 함수의 이름입니다.

`rettype`

반환 데이터 타입입니다.

`DETERMINISTIC`

`DETERMINISTIC`은 `IMMUTABLE`의 동의어입니다. `DETERMINISTIC` 함수는 데이터베이스를 수정할 수 없으며, 동일한 인자 값이 주어지면 항상 동일한 결과에 도달합니다. 데이터베이스 조회를 수행하지 않으며, 인자 목록에 직접 존재하지 않는 정보를 사용하지 않습니다. 이 절을 포함하면, 모든 인자가 상수인 함수 호출은 즉시 함수 값으로 대체될 수 있습니다.

`restriction`

다음 키워드는 호환성을 위해 수용되지만 무시됩니다.

`RNDS`

`RNPS`

`TRUST`

`WNDS`

`WNPS`

## 패키지 본문 구문 (Package body syntax)

패키지 구현 세부는 패키지 본문에 있습니다. 패키지 본문은 패키지 사용자에게 보이지 않는 객체를 담을 수 있습니다. EDB Postgres Advanced Server는 패키지 본문에 대해 다음 구문을 지원합니다.

```sql
CREATE [ OR REPLACE ] PACKAGE BODY <package_name>
  { IS | AS }
  [ <private_declaration>; ] ...
  [ <procedure_or_function_definition> ] ...
  [ <package_initializer> ]
END [ <package_name> ] ;
```

여기서 `procedure_or_function_definition` :=

```text
procedure_definition | function_definition
```

여기서 `procedure_definition` :=

```sql
PROCEDURE proc_name[ argument_list ]
  [ options_list ]
  { IS | AS }
    procedure_body
  END [ proc_name ] ;
```

여기서 `procedure_body` :=

```sql
[ PRAGMA AUTONOMOUS_TRANSACTION; ]
[ declaration; ] [, ...]
BEGIN
  statement; [...]
[ EXCEPTION
   { WHEN exception [OR exception] [...]] THEN statement; }
   [...]
]
```

여기서 `function_definition` :=

```sql
FUNCTION func_name [ argument_list ]
  RETURN rettype [ DETERMINISTIC ]
  [ options_list ]
  { IS | AS }
    function_body
  END [ func_name ] ;
```

여기서 `function_body` :=

```sql
[ PRAGMA AUTONOMOUS_TRANSACTION; ]
[ declaration; ] [, ...]
BEGIN
  statement; [...]
[ EXCEPTION
  { WHEN exception [ OR exception ] [...] THEN statement; }
  [...]
]
```

여기서 `argument_list` :=

```text
( argument_declaration [, ...] )
```

여기서 `argument_declaration` :=

```text
argname [ IN | IN OUT | OUT ] argtype [ DEFAULT value ]
```

여기서 `options_list` :=

```text
option [ ... ]
```

여기서 `option` :=

```sql
STRICT
LEAKPROOF
PARALLEL { UNSAFE | RESTRICTED | SAFE }
COST execution_cost
ROWS result_rows
SET config_param { TO value | = value | FROM CURRENT }
```

여기서 `package_initializer` :=

```sql
BEGIN
 statement; [...]
END;
```

### 파라미터 (Parameters)

`package_name`

`package_name`은 이 본문에 해당하는 패키지의 이름입니다. 이 이름의 패키지 명세가 이미 존재해야 합니다.

`private_declaration`

`private_declaration`은 패키지 내의 모든 프로시저 또는 함수가 접근할 수 있는 비공개 변수의 식별자입니다. 비공개 변수는 0개, 1개, 또는 여러 개가 있을 수 있습니다. `private_declaration`은 다음 중 하나일 수 있습니다.

- 변수 선언(Variable declaration)
- 레코드 선언(Record declaration)
- 컬렉션 선언(Collection declaration)
- `REF CURSOR` 및 커서 변수 선언
- 레코드, 컬렉션, `REF CURSOR`에 대한 `TYPE` 정의
- 예외(Exception)
- 객체 변수 선언(Object variable declaration)

`proc_name`

생성할 프로시저의 이름입니다.

`PRAGMA AUTONOMOUS_TRANSACTION`

`PRAGMA AUTONOMOUS_TRANSACTION`은 프로시저를 자율 트랜잭션(autonomous transaction)으로 설정하는 지시자입니다.

`declaration`

변수, 타입, `REF CURSOR`, 또는 서브프로그램 선언입니다. 서브프로그램 선언을 포함하는 경우, 다른 모든 변수·타입·`REF CURSOR` 선언 뒤에 선언합니다.

`statement`

SPL 프로그램 문입니다. `DECLARE - BEGIN - END` 블록은 그 자체로 하나의 SPL 문으로 간주됩니다. 따라서 함수 본문은 중첩 블록을 포함할 수 있습니다.

`exception`

`NO_DATA_FOUND`, `OTHERS`와 같은 예외 조건 이름입니다.

`func_name`

생성할 함수의 이름입니다.

`rettype`

반환 데이터 타입으로, `argtype`에 나열된 타입 중 무엇이든 될 수 있습니다. `argtype`과 마찬가지로 `rettype`에도 길이를 지정하지 마십시오.

`DETERMINISTIC`

동일한 인자 값이 주어지면 함수가 항상 동일한 결과를 반환하도록 지정하려면 `DETERMINISTIC`을 포함합니다. `DETERMINISTIC` 함수는 데이터베이스를 수정해서는 안 됩니다.

> **참고**
> `DETERMINISTIC` 키워드는 PostgreSQL `IMMUTABLE` 옵션과 동등합니다.

> **참고**
> 패키지 본문의 공개 함수에 `DETERMINISTIC`을 지정하면, 패키지 명세의 함수 선언에도 이를 지정해야 합니다. 비공개 함수의 경우 패키지 명세에 함수 선언이 없습니다.

`PRAGMA AUTONOMOUS_TRANSACTION`

`PRAGMA AUTONOMOUS_TRANSACTION`은 함수를 자율 트랜잭션(autonomous transaction)으로 설정하는 지시자입니다.

`argname`

형식 인자(formal argument)의 이름입니다. 프로시저 본문에서 이 이름으로 인자를 참조합니다.

`IN` | `IN OUT` | `OUT`

인자 모드입니다. `IN`(기본값)은 인자를 입력 전용으로 선언합니다. `IN OUT`은 인자가 값을 수신하고 반환할 수 있게 합니다. `OUT`은 인자가 출력 전용임을 지정합니다.

`argtype`

인자의 데이터 타입입니다. 인자 타입은 기본 데이터 타입, `%TYPE`을 사용한 기존 컬럼 타입의 복사본, 또는 중첩 테이블(nested table)이나 객체 타입 같은 사용자 정의 타입일 수 있습니다. 기본 타입에는 길이를 지정하지 마십시오. 예를 들어 `VARCHAR2(10)`이 아니라 `VARCHAR2`를 지정합니다.

컬럼의 타입은 `tablename.columnname%TYPE`으로 참조합니다. 이 표기법을 사용하면 때때로 프로시저를 테이블 정의 변경으로부터 독립적으로 만드는 데 도움이 됩니다.

`DEFAULT value`

`DEFAULT` 절은 프로시저 호출 시 값을 제공하지 않을 경우 입력 인자에 기본값을 공급합니다. `IN OUT` 또는 `OUT` 모드의 인자에는 `DEFAULT`를 지정하지 마십시오.

다음 옵션은 Oracle 데이터베이스와 호환되지 않습니다. 이 옵션들은 EDB Postgres Advanced Server만 제공하는 Oracle 패키지 구문의 확장입니다.

`STRICT`

`STRICT` 키워드는 `NULL` 인자로 호출될 경우 함수를 실행하지 않도록 지정합니다. 대신 함수는 `NULL`을 반환합니다.

`LEAKPROOF`

`LEAKPROOF` 키워드는 반환 값을 통하는 것 외에는 인자에 관한 어떤 정보도 드러내지 않도록 함수를 지정합니다.

`PARALLEL { UNSAFE | RESTRICTED | SAFE }`

`PARALLEL` 절은 병렬 순차 스캔(병렬 모드)의 사용을 활성화합니다. 병렬 순차 스캔은 직렬 순차 스캔과 대조적으로, 쿼리 중에 여러 워커를 사용하여 릴레이션을 병렬로 스캔합니다.

`UNSAFE`로 설정하면 프로시저 또는 함수를 병렬 모드에서 실행할 수 없습니다. 그러한 프로시저 또는 함수가 존재하면 직렬 실행 계획이 강제됩니다. `PARALLEL` 절을 생략하면 이것이 기본 설정입니다.

`RESTRICTED`로 설정하면 프로시저 또는 함수를 병렬 모드에서 실행할 수 있지만, 실행은 병렬 그룹 리더(parallel group leader)로 제한됩니다. 특정 릴레이션의 한정(qualification)에 병렬 제한(parallel restricted)된 것이 있으면 그 릴레이션은 병렬 처리 대상으로 선택되지 않습니다.

`SAFE`로 설정하면 프로시저 또는 함수를 제한 없이 병렬 모드에서 실행할 수 있습니다.

`execution_cost`

`execution_cost`는 `cpu_operator_cost` 단위로 함수의 추정 실행 비용을 나타내는 양수를 지정합니다. 함수가 집합을 반환하면 이는 반환되는 행당 비용입니다. 기본값은 `0.0025`입니다.

`result_rows`

`result_rows`는 쿼리 플래너가 함수가 반환할 것으로 예상하는 행의 추정 수입니다. 기본값은 `1000`입니다.

`SET`

`SET` 절을 사용하여 함수의 실행 기간 동안 파라미터 값을 지정합니다.

`config_param`은 파라미터 이름을 지정합니다.

`value`는 파라미터 값을 지정합니다.

`FROM CURRENT`는 함수가 종료될 때 파라미터 값이 복원되도록 보장합니다.

`package_initializer`

`package_initializer`의 문은 패키지가 처음 참조될 때 사용자 세션당 한 번 실행됩니다.

> **참고**
> `STRICT`, `LEAKPROOF`, `PARALLEL`, `COST`, `ROWS`, `SET` 키워드는 EDB Postgres Advanced Server를 위한 확장 기능을 제공합니다. Oracle은 이를 지원하지 않습니다.
