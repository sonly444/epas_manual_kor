# 사용자 정의 타입을 사용하는 패키지 (Using Packages with User-Defined Types) — EPAS 18

> 원문: [EPAS v18 — Working with packages › Using packages with user-defined types](https://www.enterprisedb.com/docs/epas/latest/application_programming/02_packages/04_using_packages_with_user_defined_types/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 코드·출력은 원문 그대로 보존했습니다.

이 예는 패키지 맥락에서 다양한 사용자 정의 타입을 통합합니다.

## 패키지 명세 (Package specification)

`emp_rpt` 패키지 명세는 레코드 타입 `emprec_typ`와 약타입(weakly typed) `REF CURSOR` `emp_refcur`를 공개로 선언합니다. 또한 두 함수와 두 프로시저를 보입니다. 함수 `open_emp_by_dept`는 `REF CURSOR` 타입 `EMP_REFCUR`를 반환합니다. 프로시저 `fetch_emp`·`close_refcur`는 약타입 `REF CURSOR`를 형식 매개변수로 선언합니다.

```sql
CREATE OR REPLACE PACKAGE emp_rpt
IS
    TYPE emprec_typ IS RECORD (
        empno       NUMBER(4),
        ename       VARCHAR(10)
    );
    TYPE emp_refcur IS REF CURSOR;

    FUNCTION get_dept_name (
        p_deptno    IN NUMBER
    ) RETURN VARCHAR2;
    FUNCTION open_emp_by_dept (
        p_deptno    IN emp.deptno%TYPE
    ) RETURN EMP_REFCUR;
    PROCEDURE fetch_emp (
        p_refcur    IN OUT SYS_REFCURSOR
    );
    PROCEDURE close_refcur (
        p_refcur    IN OUT SYS_REFCURSOR
    );
END emp_rpt;
```

## 패키지 본문 (Package body)

본문은 여러 비공개 변수를 선언합니다: 정적 커서 `dept_cur`, 테이블 타입 `depttab_typ`, 테이블 변수 `t_dept`, 정수 변수 `t_dept_max`, 레코드 변수 `r_emp`.

```sql
CREATE OR REPLACE PACKAGE BODY emp_rpt
IS
    CURSOR dept_cur IS SELECT * FROM dept;
    TYPE depttab_typ IS TABLE of dept%ROWTYPE
        INDEX BY BINARY_INTEGER;
    t_dept          DEPTTAB_TYP;
    t_dept_max      INTEGER := 1;
    r_emp           EMPREC_TYP;

    FUNCTION get_dept_name (
        p_deptno    IN NUMBER
    ) RETURN VARCHAR2
    IS
    BEGIN
        FOR i IN 1..t_dept_max LOOP
            IF p_deptno = t_dept(i).deptno THEN
                RETURN t_dept(i).dname;
            END IF;
        END LOOP;
        RETURN 'Unknown';
    END;

    FUNCTION open_emp_by_dept(
        p_deptno        IN emp.deptno%TYPE
    ) RETURN EMP_REFCUR
    IS
        emp_by_dept EMP_REFCUR;
    BEGIN
        OPEN emp_by_dept FOR SELECT empno, ename FROM emp
            WHERE deptno = p_deptno;
        RETURN emp_by_dept;
    END;

    PROCEDURE fetch_emp (
        p_refcur      IN OUT SYS_REFCURSOR
    )
    IS
    BEGIN
        DBMS_OUTPUT.PUT_LINE('EMPNO ENAME');
        DBMS_OUTPUT.PUT_LINE('----- -------');
        LOOP
            FETCH p_refcur INTO r_emp;
            EXIT WHEN p_refcur%NOTFOUND;
            DBMS_OUTPUT.PUT_LINE(r_emp.empno || ' ' || r_emp.ename);
        END LOOP;
    END;

    PROCEDURE close_refcur (
        p_refcur      IN OUT SYS_REFCURSOR
    )
    IS
    BEGIN
        CLOSE p_refcur;
    END;
BEGIN
    OPEN dept_cur;
    LOOP
        FETCH dept_cur INTO t_dept(t_dept_max);
        EXIT WHEN dept_cur%NOTFOUND;
        t_dept_max := t_dept_max + 1;
    END LOOP;
    CLOSE dept_cur;
    t_dept_max := t_dept_max - 1;
END emp_rpt;
```

이 패키지는 비공개 정적 커서 `dept_cur`를 사용하여 비공개 테이블 변수 `t_dept`를 로드하는 초기화 섹션을 포함합니다. `t_dept`는 함수 `get_dept_name`에서 부서 이름 조회 테이블 역할을 합니다. 함수 `open_emp_by_dept`는 주어진 부서의 사번·이름 결과 집합에 대한 `REF CURSOR` 변수를 반환합니다. 이 `REF CURSOR` 변수를 프로시저 `fetch_emp`에 전달하여 결과 집합의 개별 행을 조회·나열할 수 있습니다. 마지막으로 프로시저 `close_refcur`로 이 결과 집합에 연결된 `REF CURSOR` 변수를 닫을 수 있습니다.

## 익명 블록 사용 (Using anonymous blocks)

다음 익명 블록은 패키지 함수·프로시저를 실행합니다. 선언 섹션에서 패키지의 공개 `REF CURSOR` 타입 `EMP_REFCUR`를 사용해 커서 변수 `v_emp_cur`를 선언합니다. `v_emp_cur`는 패키지 함수·프로시저 사이에 전달되는 결과 집합 포인터를 담습니다.

```sql
DECLARE
    v_deptno dept.deptno%TYPE DEFAULT 30;
    v_emp_cur emp_rpt.EMP_REFCUR;
BEGIN
    v_emp_cur := emp_rpt.open_emp_by_dept(v_deptno);
    DBMS_OUTPUT.PUT_LINE('EMPLOYEES IN DEPT #' || v_deptno ||
        ': ' || emp_rpt.get_dept_name(v_deptno));
    emp_rpt.fetch_emp(v_emp_cur);
    DBMS_OUTPUT.PUT_LINE('**********************');
    DBMS_OUTPUT.PUT_LINE(v_emp_cur%ROWCOUNT || ' rows were retrieved');
    emp_rpt.close_refcur(v_emp_cur);
END;
```
결과:
```text
EMPLOYEES IN DEPT #30: SALES
EMPNO    ENAME
-----    -------
7499     ALLEN
7521     WARD
7654     MARTIN
7698     BLAKE
7844     TURNER
7900     JAMES
**********************
6 rows were retrieved
```

다음 익명 블록은 동일 결과를 얻는 다른 방법입니다. 패키지 프로시저 `fetch_emp`·`close_refcur` 대신 그 로직을 익명 블록에 직접 코딩합니다. 선언 섹션에 패키지 공개 레코드 타입 `EMPREC_TYP`로 선언한 레코드 변수 `r_emp`가 추가된 것에 유의하십시오.

```sql
DECLARE
    v_deptno     dept.deptno%TYPE DEFAULT 30;
    v_emp_cur    emp_rpt.EMP_REFCUR;
    r_emp        emp_rpt.EMPREC_TYP;
BEGIN
    v_emp_cur := emp_rpt.open_emp_by_dept(v_deptno);
    DBMS_OUTPUT.PUT_LINE('EMPLOYEES IN DEPT #' || v_deptno ||
        ': ' || emp_rpt.get_dept_name(v_deptno));
    DBMS_OUTPUT.PUT_LINE('EMPNO ENAME');
    DBMS_OUTPUT.PUT_LINE('----- -------');
    LOOP
        FETCH v_emp_cur INTO r_emp;
        EXIT WHEN v_emp_cur%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE(r_emp.empno || ' ' ||
            r_emp.ename);
    END LOOP;
    DBMS_OUTPUT.PUT_LINE('**********************');
    DBMS_OUTPUT.PUT_LINE(v_emp_cur%ROWCOUNT || ' rows were retrieved');
    CLOSE v_emp_cur;
END;
```
결과:
```text
EMPLOYEES IN DEPT #30: SALES
EMPNO    ENAME
-----    -------
7499     ALLEN
7521     WARD
7654     MARTIN
7698     BLAKE
7844     TURNER
7900     JAMES
**********************
6 rows were retrieved
```
