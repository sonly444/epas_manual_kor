# 버전 정보 얻기 (Obtaining version information) — EPAS 18 향상된 SQL

> 원문: [EPAS v18 — Application programming › Enhanced SQL › Obtaining version information](https://www.enterprisedb.com/docs/epas/latest/application_programming/15_enhanced_sql_and_other_misc_features/obtaining_version_information/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·출력은 원문 그대로 보존했습니다.

`version()` 함수는 제품 이름, 버전, 호스트 시스템 정보를 표시합니다. EDB Postgres Advanced Server의 경우 출력 형식은 PostgreSQL 커뮤니티 버전과 유사하며, 첫 단어가 (버전 10 이하에서 사용되던) "EnterpriseDB"가 아니라 "PostgreSQL"입니다.

## 일반 형식

표준 출력 형식은 다음과 같습니다.

```text
PostgreSQL $PG_VERSION_EXT (EnterpriseDB EDB Postgres Advanced Server $PG_VERSION) on $host
```

## 현재 버전 예제

EDB Postgres Advanced Server 버전 18에서 함수를 실행하면 다음이 출력됩니다.

```sql
edb@45032=#select version();
```

결과:

```text
PostgreSQL 18.1 (EnterpriseDB Advanced Server 18.1.0 (Debian 18.1.0-1.bullseye)) on 
x86_64-pc-linux-gnu, compiled by gcc (Debian 10.2.1-6) 10.2.1 20210110, 64-bit
```

## 이전 버전 비교

버전 10에서는 출력이 다음과 같이 나타났습니다.

```sql
edb=# select version();
```

결과:

```text
EnterpriseDB 10.4.9 on x86_64-pc-linux-gnu, compiled by gcc (GCC) 4.4.7 20120313 
(Red Hat 4.4.7-18), 64-bit
```
