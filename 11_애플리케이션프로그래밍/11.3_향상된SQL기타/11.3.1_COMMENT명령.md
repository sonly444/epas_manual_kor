# COMMENT 명령 사용 (Using the COMMENT command) — EPAS 18 향상된 SQL

> 원문: [EPAS v18 — Application programming › Enhanced SQL and other miscellaneous features › Using the COMMENT command](https://www.enterprisedb.com/docs/epas/latest/application_programming/15_enhanced_sql_and_other_misc_features/comment_command/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·구문·이름·코드는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 PostgreSQL `COMMENT` 명령이 지원하는 객체에 대한 주석을 허용하는 것에 더해, 다른 객체 유형에 대한 주석도 지원합니다. 지원되는 전체 구문은 다음과 같습니다.

```sql
COMMENT ON
{
  AGGREGATE <aggregate_name> ( <aggregate_signature> ) |
  CAST (<source_type> AS <target_type>) |
  COLLATION <object_name> |
  COLUMN <relation_name>.<column_name> |
  CONSTRAINT <constraint_name> ON <table_name> |
  CONSTRAINT <constraint_name> ON DOMAIN <domain_name> |
  CONVERSION <object_name> |
  DATABASE <object_name> |
  DOMAIN <object_name> |
  EXTENSION <object_name> |
  EVENT TRIGGER <object_name> |
  FOREIGN DATA WRAPPER <object_name> |
  FOREIGN TABLE <object_name> |
  FUNCTION <func_name> ([[<argmode>] [<argname>] <argtype> [,...]])|
  INDEX <object_name> |
  LARGE OBJECT <large_object_oid> |
  MATERIALIZED VIEW <object_name> |
  OPERATOR <operator_name> (left_type, right_type) |
  OPERATOR CLASS <object_name> USING <index_method> |
  OPERATOR FAMILY <object_name> USING <index_method> |
  PACKAGE <object_name>
  POLICY <policy_name> ON <table_name> |
  [ PROCEDURAL ] LANGUAGE <object_name> |
  PROCEDURE <proc_name> [([[<argmode>] [<argname>] <argtype> [, ...]])]
  PUBLIC SYNONYM <object_name>
  ROLE <object_name> |
  RULE <rule_name> ON <table_name> |
  SCHEMA <object_name> |
  SEQUENCE <object_name> |
  SERVER <object_name> |
  TABLE <object_name> |
  TABLESPACE <object_name> |
  TEXT SEARCH CONFIGURATION <object_name> |
  TEXT SEARCH DICTIONARY <object_name> |
  TEXT SEARCH PARSER <object_name> |
  TEXT SEARCH TEMPLATE <object_name> |
  TRANSFORM FOR <type_name> LANGUAGE <lang_name> |
  TRIGGER <trigger_name> ON <table_name> |
  TYPE <object_name> |
  VIEW <object_name>
} IS <'text'>
```

여기서 `aggregate_signature`는 다음과 같습니다.

```sql
* |
[ <argmode> ] [ <argname> ] <argtype> [ , ... ] |
[ [ <argmode> ] [ <argname> ] <argtype> [ , ... ] ]
ORDER BY [ <argmode> ] [ <argname> ] <argtype> [ , ... ]
```

## 파라미터 (Parameters)

`object_name`

주석을 다는 객체의 이름입니다.

`AGGREGATE aggregate_name (aggregate_signature)`

집계(aggregate)에 대한 주석을 생성하려면 `AGGREGATE` 절을 포함합니다. `aggregate_name`은 집계의 이름을 지정합니다. `aggregate_signature`는 다음 형식 중 하나로 연관된 시그니처를 지정합니다.

```sql
* |
[ <argmode> ] [ <argname> ] <argtype> [ , ... ] |
[ [ <argmode> ] [ <argname> ] <argtype> [ , ... ] ]
ORDER BY [ <argmode> ] [ <argname> ] <argtype> [ , ... ]
```

여기서 `argmode`는 함수, 프로시저, 또는 집계 인자의 모드입니다. `argmode`는 `IN`, `OUT`, `INOUT`, 또는 `VARIADIC`일 수 있습니다. 기본값은 `IN`입니다.

`argname`은 집계 인자의 이름입니다.

`argtype`은 집계 인자의 데이터 타입입니다.

`CAST (source_type AS target_type)`

캐스트(cast)에 대한 주석을 생성하려면 `CAST` 절을 포함합니다. 캐스트에 대한 주석을 생성할 때 `source_type`은 캐스트의 소스 데이터 타입을, `target_type`은 캐스트의 대상 데이터 타입을 지정합니다.

`COLUMN relation_name.column_name`

컬럼(column)에 대한 주석을 생성하려면 `COLUMN` 절을 포함합니다. `column_name`은 주석이 적용되는 컬럼의 이름을 지정합니다. `relation_name`은 컬럼이 속한 테이블, 뷰, 복합 타입(composite type), 또는 외부 테이블(foreign table)입니다.

`CONSTRAINT constraint_name ON table_name`

`CONSTRAINT constraint_name ON DOMAIN domain_name`

제약 조건(constraint)에 대한 주석을 추가하려면 `CONSTRAINT` 절을 포함합니다. 제약 조건에 대한 주석을 생성할 때 `constraint_name`은 제약 조건의 이름을 지정합니다. `table_name` 또는 `domain_name`은 제약 조건이 정의된 테이블 또는 도메인의 이름을 지정합니다.

`FUNCTION func_name ([[argmode] [argname] argtype [, ...]])`

함수(function)에 대한 주석을 추가하려면 `FUNCTION` 절을 포함합니다. `func_name`은 함수의 이름을 지정합니다. `argmode`는 함수의 모드를 지정합니다. `argmode`는 `IN`, `OUT`, `INOUT`, 또는 `VARIADIC`일 수 있습니다. 기본값은 `IN`입니다.

`argname`은 함수, 프로시저, 또는 집계 인자의 이름을 지정합니다. `argtype`은 함수, 프로시저, 또는 집계 인자의 데이터 타입을 지정합니다.

`large_object_oid`

`large_object_oid`는 주석을 다는 라지 오브젝트(large object)의 시스템 할당 OID입니다.

`OPERATOR operator_name (left_type, right_type)`

연산자(operator)에 대한 주석을 추가하려면 `OPERATOR` 절을 포함합니다. `operator_name`은 주석을 다는 연산자의 (선택적으로 스키마 한정된) 이름을 지정합니다. `left_type`과 `right_type`은 연산자 인자의 (선택적으로 스키마 한정된) 데이터 타입입니다.

`OPERATOR CLASS object_name USING index_method`

연산자 클래스(operator class)에 대한 주석을 추가하려면 `OPERATOR CLASS` 절을 포함합니다. `object_name`은 주석을 다는 연산자의 (선택적으로 스키마 한정된) 이름을 지정합니다. `index_method`는 연산자 클래스의 연관된 인덱스 방법(index method)을 지정합니다.

`OPERATOR FAMILY object_name USING index_method`

연산자 패밀리(operator family)에 대한 주석을 추가하려면 `OPERATOR FAMILY` 절을 포함합니다. `object_name`은 주석을 다는 연산자 패밀리의 (선택적으로 스키마 한정된) 이름을 지정합니다. `index_method`는 연산자 패밀리의 연관된 인덱스 방법을 지정합니다.

`POLICY policy_name ON table_name`

정책(policy)에 대한 주석을 추가하려면 `POLICY` 절을 포함합니다. `policy_name`은 정책의 이름을 지정합니다. `table_name`은 정책이 연관된 테이블을 지정합니다.

`PROCEDURE proc_name [([[argmode] [argname] argtype [, ...]])]`

프로시저(procedure)에 대한 주석을 추가하려면 `PROCEDURE` 절을 포함합니다. `proc_name`은 프로시저의 이름을 지정합니다. `argmode`는 프로시저의 모드를 지정합니다. `argmode`는 `IN`, `OUT`, `INOUT`, 또는 `VARIADIC`일 수 있습니다. 기본값은 `IN`입니다.

`argname`은 함수, 프로시저, 또는 집계 인자의 이름을 지정합니다. `argtype`은 함수, 프로시저, 또는 집계 인자의 데이터 타입을 지정합니다.

`RULE rule_name ON table_name`

규칙(rule)에 대한 주석을 지정하려면 `RULE` 절을 포함합니다. `rule_name`은 규칙의 이름을 지정합니다. `table_name`은 규칙이 정의된 테이블의 이름을 지정합니다.

`TRANSFORM FOR type_name LANGUAGE lang_name`

`TRANSFORM`에 대한 주석을 지정하려면 `TRANSFORM FOR` 절을 포함합니다.

`type_name`은 트랜스폼(transform)의 데이터 타입 이름을 지정합니다. `lang_name`은 트랜스폼의 언어 이름을 지정합니다.

`TRIGGER trigger_name ON table_name`

트리거(trigger)에 대한 주석을 지정하려면 `TRIGGER` 절을 포함합니다. `trigger_name`은 트리거의 이름을 지정합니다. `table_name`은 트리거가 정의된 테이블의 이름을 지정합니다.

`text`

문자열 리터럴로 작성된 주석이거나, 주석을 삭제하려면 `NULL`입니다.

> **참고**
> 테이블, 집계, 콜레이션, 변환(conversion), 도메인, 외부 테이블, 함수, 인덱스, 연산자, 연산자 클래스, 연산자 패밀리, 패키지, 프로시저, 시퀀스, 텍스트 검색 객체, 타입, 뷰의 이름은 스키마 한정될 수 있습니다.

## 예제 (Example)

이 예제는 `new_emp`라는 테이블에 주석을 추가합니다.

```sql
COMMENT ON TABLE new_emp IS 'This table contains information about new
employees.';
```

`COMMENT` 명령 사용에 대한 자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/sql-comment.html)를 참고하십시오.
