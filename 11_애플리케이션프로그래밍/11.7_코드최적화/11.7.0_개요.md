# 코드 최적화 (Optimizing code) — EPAS 18 애플리케이션 프로그래밍

> 원문: [EPAS v18 — Application programming › Optimizing code](https://www.enterprisedb.com/docs/epas/latest/application_programming/optimizing_code/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 힌트·명령 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 애플리케이션 프로그래머가 데이터베이스 성능 문제를 다루도록 돕는 기능을 포함합니다. SQL Profiler는 성능이 낮은 SQL 코드를 찾아 최적화하는 데 도움을 줍니다. `DELETE`, `INSERT`, `SELECT`, `UPDATE` 명령을 호출할 때 서버가 쿼리 계획을 선택하는 과정에 영향을 주기 위해 옵티마이저 힌트(optimizer hint)를 사용할 수 있습니다.
