# APPEND 옵티마이저 힌트 (APPEND optimizer hint) — EPAS 18 옵티마이저 힌트

> 원문: [EPAS v18 — Optimizing code › Using optimizer hints › APPEND optimizer hint](https://www.enterprisedb.com/docs/epas/latest/application_programming/optimizing_code/05_optimizer_hints/06_using_the_append_optimizer_hint/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 힌트·명령·코드는 원문 그대로 보존했습니다.

기본적으로 EDB Postgres Advanced Server는 테이블에서 처음으로 사용 가능한 빈 공간(free space)에 새 데이터를 삽입합니다. `APPEND` 지시어는 "새 행을 테이블의 끝에 붙임(affix)"으로써 이 동작을 수정하며, 이는 특히 대량 로딩(bulk loading) 작업 중에 유익합니다.

## 구문 (Syntax)

힌트는 다음 형식을 사용합니다.

```sql
/*+APPEND*/
```

## 사용 예제

**단일 행 삽입:**
```sql
INSERT /*+APPEND*/ INTO sales VALUES
(10, 10, '01-Mar-2011', 10, 'OR');
```

**다중 행 삽입:**
```sql
INSERT /*+APPEND*/ INTO sales VALUES
(20, 20, '01-Aug-2011', 20, 'NY'),
(30, 30, '01-Feb-2011', 30, 'FL'),
(40, 40, '01-Nov-2011', 40, 'TX');
```

**SELECT를 사용한 INSERT INTO:**
```sql
INSERT INTO sales_history SELECT /*+APPEND*/ FROM sales;
```

문서는 EDB Postgres Advanced Server가 이러한 삽입 시나리오 전반에 걸쳐 `APPEND` 힌트를 지원하며, 이 모두가 테이블 중간의 빈 공간을 건너뛰고 테이블 끝에 행을 추가함을 언급합니다.
