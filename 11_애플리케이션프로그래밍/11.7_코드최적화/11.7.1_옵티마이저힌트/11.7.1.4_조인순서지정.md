# 조인 순서 지정 (Specifying a join order) — EPAS 18 옵티마이저 힌트

> 원문: [EPAS v18 — Optimizing code › Using optimizer hints › Specifying a join order](https://www.enterprisedb.com/docs/epas/latest/application_programming/optimizing_code/05_optimizer_hints/03_specifying_a_join_order/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 힌트·명령·코드는 원문 그대로 보존했습니다.

이 문서는 쿼리에서 테이블 조인 순서를 제어하기 위해 `ORDERED` 지시어를 사용하는 방법을 설명합니다.

## 핵심 개념

`ORDERED` 힌트는 `FROM` 절에 나타나는 정확한 순서로 테이블을 조인하도록 쿼리 옵티마이저에 지시합니다. 이 지시어가 없으면 옵티마이저는 독립적으로 최적의 조인 순서를 결정합니다.

## 예제 비교

**지시어 없음**(옵티마이저가 순서 선택):
```sql
SELECT e.ename, d.dname, h.startdate
  FROM emp e, dept d, jobhist h
  WHERE d.deptno = e.deptno
  AND h.empno = e.empno;
```

**ORDERED 지시어 사용**(지정된 순서 강제):
```sql
SELECT /*+ ORDERED */ e.ename, d.dname, h.startdate
  FROM emp e, dept d, jobhist h
  WHERE d.deptno = e.deptno
  AND h.empno = e.empno;
```

## 중요 제한

문서는 다음을 언급합니다: "`ORDERED` 지시어는 Oracle 스타일 외부 조인(+ 기호를 포함하는 조인)에는 동작하지 않습니다."

이 기능은 개발자가 자동 옵티마이저보다 최적의 실행 경로에 대해 더 잘 알고 있을 때 쿼리 성능을 세밀하게 조정하도록 돕는 EDB 옵티마이저 힌트 시스템의 일부입니다.
