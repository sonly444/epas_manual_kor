# 옵티마이저 힌트 사용 (Using optimizer hints) — EPAS 18 코드 최적화

> 원문: [EPAS v18 — Optimizing code › Using optimizer hints](https://www.enterprisedb.com/docs/epas/latest/application_programming/optimizing_code/05_optimizer_hints/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 힌트·파라미터·명령은 원문 그대로 보존했습니다.

## 개요

`DELETE`, `INSERT`, `SELECT`, `UPDATE` 명령을 실행할 때 서버는 여러 실행 계획을 생성합니다. 분석 후, 결과를 가장 효율적으로 반환할 것으로 예상되는 계획을 선택합니다. 선택은 다음에 따라 달라집니다.

- 데이터 처리 작업의 추정 실행 비용
- `postgresql.conf`의 `Query Tuning` 섹션에 있는 파라미터 값
- ANALYZE 명령으로 수집된 컬럼 통계

쿼리 플래너는 일반적으로 가장 비용이 적은 계획을 선택합니다. 개발자는 *옵티마이저 힌트(optimizer hint)*를 사용하여 계획 선택에 영향을 줄 수 있습니다.
