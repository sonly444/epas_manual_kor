# 기본 최적화 모드 (Default optimization modes) — EPAS 18 옵티마이저 힌트

> 원문: [EPAS v18 — Optimizing code › Using optimizer hints › Default optimization modes](https://www.enterprisedb.com/docs/epas/latest/application_programming/optimizing_code/05_optimizer_hints/01_default_optimization_modes/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 힌트·파라미터·명령·코드는 원문 그대로 보존했습니다.

## 개요

EDB Postgres Advanced Server 데이터베이스 클러스터의 기본값으로 최적화 모드를 선택할 수 있습니다. 구성 파라미터 `OPTIMIZER_MODE`가 이 기본값을 제어하며, `ALTER SESSION`을 사용하여 세션별로 또는 개별 SQL 명령 내에서 수정할 수 있습니다.

### 사용 가능한 최적화 모드

| 힌트 | 설명 |
|------|-------------|
| `ALL_ROWS` | 결과 집합의 모든 행 조회에 최적화 |
| `CHOOSE` | 기본 최적화 없음. 이것이 기본 설정입니다. |
| `FIRST_ROWS` | 첫 번째 행만 조회하도록 최적화 |
| `FIRST_ROWS_10` | 첫 10개 행에 최적화 |
| `FIRST_ROWS_100` | 첫 100개 행에 최적화 |
| `FIRST_ROWS_1000` | 첫 1000개 행에 최적화 |
| `FIRST_ROWS(n)` | 첫 *n*개 행에 최적화(힌트 전용 형식) |

이 모드들은 클라이언트가 첫 *n*개 행만 원한다고 가정하고 그에 따라 자원 할당을 조정합니다.

### 최적화 모드 설정

첫 10개 행을 조회하도록 현재 세션을 변경하려면:

```sql
ALTER SESSION SET OPTIMIZER_MODE = FIRST_ROWS_10;
```

### 현재 설정 확인

PSQL 사용:
```sql
SHOW OPTIMIZER_MODE;
```

또는 Oracle 호환 구문:
```sql
SHOW PARAMETER OPTIMIZER_MODE;
```

### SELECT에 힌트를 사용한 예제

```sql
SELECT /*+ FIRST_ROWS(7) */ * FROM emp;
```
