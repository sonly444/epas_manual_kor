# 비효율적인 SQL 코드 최적화 (Optimizing inefficient SQL code) — EPAS 18 코드 최적화

> 원문: [EPAS v18 — Optimizing code › Optimizing inefficient SQL code](https://www.enterprisedb.com/docs/epas/latest/application_programming/optimizing_code/optimizing_code/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 도구 이름은 원문 그대로 보존했습니다.

비효율적인 SQL 코드는 데이터베이스 성능 문제의 주요 원인입니다. 데이터베이스 관리자와 개발자에게 주어진 주된 과제는 크고 복잡한 시스템 안에서 그러한 코드를 식별하고 최적화하는 것입니다.

문서는 독자에게 SQL Profiler 유틸리티를 안내하며, 이 도구는 "성능이 낮은 SQL 코드를 찾아 최적화하는 데 도움을 줄 수 있습니다."

(SQL Profiler 상세는 본 번역의 `10_성능관리/09_4_SQL_Profiler.md` 참조.)
