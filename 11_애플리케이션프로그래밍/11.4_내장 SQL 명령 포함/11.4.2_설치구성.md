# ECPGPlus 설치 및 구성 (Installing and configuring ECPGPlus) — EPAS 18 ECPGPlus

> 원문: [EPAS v18 — Application programming › Including embedded SQL commands › Installing and configuring ECPGPlus](https://www.enterprisedb.com/docs/epas/latest/application_programming/ecpgplus_guide/installing_ecpgplus/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·경로·명령·옵션·코드는 원문 그대로 보존했습니다.

Windows에서는 ECPGPlus가 EDB Postgres Advanced Server 설치 마법사에 의해 Database Server 구성 요소의 일부로 설치됩니다. Linux에서는 실행 파일을 실행하여 ECPGPlus를 설치합니다.

## ECPGPlus 설치 (Installing ECPGPlus)

Linux에서는 `edb-as<xx>-server-ecpg-devel` RPM 패키지와 `edb-as<xx>-server-devel` RPM 패키지 또는 `edb-as<xx>-server-dev` APT 패키지를 설치합니다(여기서 `<xx>`는 EDB Postgres Advanced Server 버전 번호). Linux에서 실행 파일은 다음 위치에 있습니다.

```text
/usr/edb/as18/bin
```

Windows에서 실행 파일은 다음 위치에 있습니다.

```text
C:\Program Files\edb\as18\bin
```

ECPGPlus 컴파일러를 호출할 때, 실행 파일이 검색 경로(Windows에서는 `%PATH%`, Linux에서는 `$PATH`)에 있어야 합니다. 예를 들어 다음 명령은 ECPGPlus 실행 파일 `ecpg`가 있는 디렉터리를 포함하도록 검색 경로를 설정합니다.

Windows에서는:

```shell
set EDB_PATH=C:\Program Files\edb\as18\bin
set PATH=%EDB_PATH%;%PATH%
```

Linux에서는:

```shell
export EDB_PATH=/usr/edb/as18/bin
export PATH=$EDB_PATH:$PATH
```

## makefile 작성 (Constructing a makefile)

makefile은 임베디드 SQL을 포함하는 C로 작성된 프로그램을 C 프로그램으로 변환하는 방법을 make 유틸리티에 알려주는 명령 집합을 담습니다. 예제를 시도하려면 다음이 필요합니다.

- C 컴파일러와 링커
- make 유틸리티
- ECPGPlus 전처리기와 라이브러리
- ECPGPlus에 대한 명령을 담은 makefile

다음 코드는 이 문서에 포함된 샘플용 makefile의 예입니다. 샘플 코드를 사용하려면, 소스 코드 파일이 있는 디렉터리에 `makefile`이라는 이름의 파일로 저장합니다.

```c
INCLUDES = -I$(shell pg_config --includedir)
LIBPATH = -L $(shell pg_config --libdir)
CFLAGS += $(INCLUDES) -g
LDFLAGS += -g
LDLIBS += $(LIBPATH) -lecpg -lpq

.SUFFIXES: .pgc,.pc

.pgc.c:
     ecpg -c $(INCLUDES) $?

.pc.c:
     ecpg -C PROC -c $(INCLUDES) $?
```

처음 두 줄은 pg_config 프로그램을 사용하여 필요한 헤더 파일과 라이브러리 디렉터리를 찾습니다.

```sql
INCLUDES = -I$(shell pg_config --includedir)
LIBPATH = -L $(shell pg_config --libdir)
```

pg_config 프로그램은 EDB Postgres Advanced Server와 함께 제공됩니다.

make는 C 컴파일러를 실행할 때 `CFLAGS` 변수를, 링커를 호출할 때 `LDFLAGS`와 `LDLIBS`를 사용하는 것을 알고 있습니다. ECPG 프로그램은 ECPG 런타임 라이브러리(`-lecpg`)와 libpq 라이브러리(`-lpq`)에 링크되어야 합니다.

```sql
CFLAGS += $(INCLUDES) -g
LDFLAGS += -g
LDLIBS += $(LIBPATH) -lecpg -lpq
```

샘플 makefile은 make에 `.pgc` 또는 `.pc` 파일을 C 프로그램으로 변환하는 방법을 알려줍니다. makefile의 두 줄이 소스 파일이 컴파일되는 모드를 지정합니다. 첫 번째 컴파일 옵션은 다음과 같습니다.

```c
.pgc.c:
      ecpg -c $(INCLUDES) $?
```

첫 번째 옵션은 make에, `.pgc`로 끝나는 파일(아마도 ECPG 소스 파일)을 ECPGPlus 확장 없이 커뮤니티 ECPG를 사용하여 `.c`로 끝나는 파일(C 프로그램)로 변환하는 방법을 알려줍니다. `-c` 플래그로 ECPG 사전 컴파일러를 호출하는데, 이 플래그는 `INCLUDES` 변수의 값과 `.pgc` 파일의 이름을 사용하여 SQL 코드를 C로 변환하도록 컴파일러에 지시합니다.

```c
.pc.c:
    ecpg -C PROC -c $(INCLUDES) $?
```

두 번째 옵션은 make에, `.pg`로 끝나는 파일(ECPG 소스 파일)을 ECPGPlus 확장을 사용하여 `.c`로 끝나는 파일(C 프로그램)로 변환하는 방법을 알려줍니다. `-c` 플래그로 ECPG 사전 컴파일러를 호출하여 SQL 코드를 C로 변환하도록 지시합니다. 또한 `-C PROC` 플래그를 사용하는데, 이 플래그는 `INCLUDES` 변수의 값과 `.pgc` 파일의 이름을 사용하여 ECPGPlus를 Pro\*C 호환 모드로 사용하도록 컴파일러에 지시합니다.

make를 실행할 때 컴파일하려는 ECPG 소스 코드 파일의 이름을 전달합니다. 예를 들어 `customer_list.pgc`라는 ECPG 소스 코드 파일을 컴파일하려면 다음 명령을 사용합니다.

```shell
make customer_list
```

make 유틸리티는 다음을 수행합니다.

1. 현재 디렉터리에 있는 makefile을 참조합니다.
2. makefile에 `customer_list.pgc`를 C 프로그램(`customer_list.c`)으로 컴파일하는 규칙이 있음을 발견합니다.
3. `make`에 내장된 규칙을 사용하여 `customer_list.c`를 실행 가능한 프로그램으로 컴파일합니다.

## ECPGPlus 명령줄 옵션 (ECPGPlus command line options)

샘플 makefile에서 make는 ECPGPlus를 호출할 때 `-C` 옵션을 포함하여 ECPGPlus를 Pro\*C 호환 모드로 호출합니다.

명령줄에서 `-C PROC` 키워드를 포함하면, ECPG 구문에 더해 Pro\*C 명령줄 구문을 사용할 수 있습니다. 예:

```shell
$ ecpg -C PROC INCLUDE=/usr/edb/as18/include acct_update.c
```

사용 가능한 다른 ECPGPlus 옵션의 전체 목록을 표시하려면, ECPGPlus 설치 디렉터리에서 다음을 입력합니다.

```shell
./ecpg --help
```

명령줄 옵션은 다음과 같습니다.

| 옵션 | 설명 |
|---|---|
| -c | 임베디드 SQL 코드에서 C 코드를 생성합니다. |
| -C \<mode> | 호환 모드를 지정합니다: `INFORMIX` / `INFORMIX_SE` / `PROC` |
| -D \<symbol> | 전처리기 심볼을 정의합니다. `-D` 키워드는 `PROC` 모드로 컴파일할 때 지원되지 않습니다. 대신 Oracle 스타일의 `'DEFINE='` 절을 사용합니다. |
| -h | 헤더 파일을 파싱합니다. 이 옵션은 옵션 `'-c'`를 포함합니다. |
| -i | 시스템 include 파일도 파싱합니다. |
| -I \<directory> | `include` 파일을 찾기 위해 \<directory>를 검색합니다. |
| -o \<outfile> | 결과를 \<outfile>에 씁니다. |
| -r \<option> | 런타임 동작을 지정합니다. \<option>의 값은 다음이 될 수 있습니다:<br>`no_indicator` — 지시자(indicator)를 사용하지 않고, 대신 특수 값을 사용하여 NULL 값을 나타냅니다.<br>`prepare` — 모든 문을 사용하기 전에 준비(prepare)합니다.<br>`questionmarks` — 물음표를 자리 표시자(placeholder)로 사용할 수 있게 합니다.<br>`usebulk` — 호스트 변수 배열에 대해 작동하는 `INSERT`, `UPDATE`, `DELETE` 문에 대해 대량 처리(bulk processing)를 활성화합니다. |
| --regression | 회귀 테스트(regression testing) 모드로 실행합니다. |
| -t | 트랜잭션 자동 커밋(autocommit)을 켭니다. |
| -l | `#line` 지시어를 비활성화합니다. |
| --help | 도움말 옵션을 표시합니다. |
| --version | 버전 정보를 출력합니다. |

> **참고**
> ECPGPlus를 호출할 때 출력 파일 이름을 지정하지 않으면, 파일 이름에서 `.pgc` 확장자를 제거하고 `.c`를 추가하여 출력 파일 이름이 생성됩니다.
