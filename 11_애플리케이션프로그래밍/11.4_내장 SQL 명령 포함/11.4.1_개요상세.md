# ECPGPlus 개요 (ECPGPlus overview) — EPAS 18 ECPGPlus

> 원문: [EPAS v18 — Application programming › ECPGPlus › ECPGPlus overview](https://www.enterprisedb.com/docs/epas/latest/application_programming/ecpgplus_guide/02_overview/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·라이브러리·코드는 원문 그대로 보존했습니다.

EDB는 PostgreSQL 전처리기인 ECPG를 향상시켜 ECPGPlus를 만들었습니다. ECPGPlus는 PostgreSQL C 전처리기의 Pro\*C 호환 버전입니다. ECPGPlus는 C 코드와 임베디드 SQL 문이 결합된 프로그램을 동등한 C 프로그램으로 변환합니다. 변환을 수행하면서 ECPGPlus는 각 SQL 구성의 구문이 올바른지 검증합니다.

## ECPGPlus 정보 (About ECPGPlus)

다음 다이어그램은 임베디드 SQL 문이 포함된 프로그램이 실행 파일로 컴파일되는 경로를 나타냅니다.

![Compilation of a program containing embedded SQL statements](https://www.enterprisedb.com/docs/static/9d1f8f741a42d2ed6e3c459e52da8d14/0ff56/ecpg_path.png)

*임베디드 SQL 문을 포함하는 프로그램의 컴파일(Compilation of a program containing embedded SQL statements)*

임베디드 SQL 문을 포함하는 C 프로그램에서 실행 파일을 생성하려면 다음과 같이 합니다.

1. 프로그램(다이어그램의 `my_program.pgc`)을 ECPGPlus 전처리기에 전달합니다. ECPGPlus는 `my_program.pgc`의 각 SQL 문을 `ecpglib` API를 호출하는 C 코드로 변환하여 C 프로그램(`my_program.c`)을 생성합니다.
2. C 프로그램을 C 컴파일러에 전달합니다. C 컴파일러는 오브젝트 파일(`my_program.o`)을 생성합니다.
3. 오브젝트 파일(`my_program.o`)과 `ecpglib` 라이브러리 파일 및 기타 필요한 라이브러리를 링커에 전달하면, 링커가 실행 파일(`my_program`)을 생성합니다.

ECPGPlus 전처리기는 각 SQL 문의 구문을 검증하지만, 의미(semantics)는 검증할 수 없습니다. 예를 들어 전처리기는 `INSERT` 문이 구문적으로 올바른지는 확인하지만, `INSERT` 문에 언급된 테이블이 존재하는지는 확인할 수 없습니다.

## 내부 동작 (Behind the scenes)

클라이언트 애플리케이션은 다음 요소로 구성된 C 코드와 SQL 코드의 혼합을 포함합니다.

- C 전처리기 지시어(C preprocessor directives)
- C 선언(변수, 타입, 함수 등)
- C 정의(변수, 타입, 함수 등)
- SQL 전처리기 지시어(SQL preprocessor directives)
- SQL 문(SQL statements)

예:

```c
1 #include <stdio.h>
2 EXEC SQL INCLUDE sqlca;
3
4 extern void printInt(char *label, int val);
5 extern void printStr(char *label, char *val);
6 extern void printFloat(char *label, float val);
7
8 void displayCustomer(int custNumber)
9 {
10  EXEC SQL BEGIN DECLARE SECTION;
11    VARCHAR custName[50];
12    float custBalance;
13    int custID = custNumber;
14  EXEC SQL END DECLARE SECTION;
15
16  EXEC SQL SELECT name, balance
17    INTO :custName, :custBalance
18    FROM customer
19    WHERE id = :custID;
20
21  printInt("ID", custID);
22  printStr("Name", custName);
23  printFloat("Balance", custBalance);
24 }
```

이 코드 조각에서:

- **1번 줄**은 C 전처리기에 대한 지시어를 지정합니다.

    C 전처리기 지시어는 해석되거나 무시될 수 있습니다. 이 옵션은 ECPGPlus를 호출할 때 입력하는 명령줄 옵션(`-C PROC`)으로 제어됩니다. 어느 경우든 ECPGPlus는 각 C 전처리기 지시어를 변경 없이 출력 파일로 복사합니다. 소스 파일에 있는 모든 C 전처리기 지시어는 출력 파일에 나타납니다.

- **2번 줄**은 SQL 전처리기에 대한 지시어를 지정합니다.

    SQL 전처리기 지시어는 ECPGPlus 전처리기에 의해 해석되며 출력 파일로 복사되지 않습니다.

- **4~6번 줄**은 C 선언을 포함합니다.

    C 선언은 변경 없이 출력 파일로 복사되지만, 각 `VARCHAR` 선언은 동등한 `struct` 선언으로 변환됩니다.

- **10~14번 줄**은 임베디드-SQL 선언 섹션을 포함합니다.

    SQL 코드에서 참조하는 C 변수를 *호스트 변수(host variable)*라고 합니다. ECPGPlus 전처리기를 Pro\*C 모드(`-C PROC`)로 호출하면 SQL 문에서 임의의 C 변수를 참조할 수 있습니다. 그렇지 않으면 각 호스트 변수를 `BEGIN/END DECLARATION SECTION` 쌍 안에 선언해야 합니다.

- **16~19번 줄**은 SQL 문을 포함합니다.

    SQL 문은 ECPGPlus 런타임 라이브러리 호출로 변환됩니다.

- **21~23번 줄**은 C 코드를 포함합니다.

    C 코드는 변경 없이 출력 파일로 복사됩니다.

모든 SQL 문 앞에 `EXEC SQL`을 붙입니다. SQL 문은 다음(따옴표로 묶이지 않은) 세미콜론까지 이어집니다. 예:

```sql
printf("Updating employee salaries\n");

EXEC SQL UPDATE emp SET sal = sal * 1.25;
EXEC SQL COMMIT;

printf("Employee salaries updated\n");
```

전처리기가 이 코드 조각을 만나면, C 코드(첫 줄과 마지막 줄)는 변환 없이 출력 파일로 전달하고, 각 `EXEC SQL` 문은 `ecpglib` 함수 호출로 변환합니다. 결과는 다음과 유사합니다.

```c
printf("Updating employee salaries\n");

{
  ECPGdo( __LINE__, 0, 1, NULL, 0, ECPGst_normal,
         "update emp set sal = sal * 1.25",
         ECPGt_EOIT, ECPGt_EORT);
}

{
  ECPGtrans(__LINE__, NULL, "commit");
}

printf("Employee salaries updated\n");
```
