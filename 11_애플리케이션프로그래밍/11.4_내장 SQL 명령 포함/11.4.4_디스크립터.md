# 디스크립터 사용 (Using descriptors) — EPAS 18 ECPGPlus

> 원문: [EPAS v18 — Application programming › Including embedded SQL commands › Using descriptors](https://www.enterprisedb.com/docs/epas/latest/application_programming/ecpgplus_guide/04_using_descriptors/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·지시어·속성·이름·코드·출력은 원문 그대로 보존했습니다.

동적 SQL(Dynamic SQL)은 클라이언트 애플리케이션이 런타임에 구성된 SQL 문을 실행할 수 있게 합니다. 이 기능은 클라이언트 애플리케이션을 작성할 때 문의 내용이나 형태를 알 수 없는 경우에 유용합니다. ECPGPlus는 식별자(테이블 이름, 컬럼 이름, 인덱스 이름 등) 대신 호스트 변수를 사용하는 것을 허용하지 않습니다. 대신, 동적 SQL 문을 사용하여 정보를 포함하는 문자열을 만든 다음 그 문자열을 실행합니다. 문자열은 *디스크립터(descriptor)* 형태로 클라이언트와 서버 사이에서 전달됩니다. 디스크립터는 데이터와 데이터의 형태(shape)에 관한 정보를 모두 담는 데이터 구조입니다.

## 클라이언트 애플리케이션 흐름 개요 (Overview of the client application flow)

클라이언트 애플리케이션은 디스크립터에서 정보를 조회하려면 `GET DESCRIPTOR` 문을 사용해야 합니다. 동적 SQL을 사용하는 클라이언트 애플리케이션의 기본 흐름은 다음과 같습니다.

1. `ALLOCATE DESCRIPTOR` 문을 사용하여 결과 집합(select 목록)을 위한 디스크립터를 할당합니다.
2. `ALLOCATE DESCRIPTOR` 문을 사용하여 입력 파라미터(바인드 변수)를 위한 디스크립터를 할당합니다.
3. SQL 문의 텍스트를 획득, 조립, 또는 계산합니다.
4. `PREPARE` 문을 사용하여 SQL 문의 구문을 파싱하고 확인합니다.
5. `DESCRIBE` 문을 사용하여 select 목록을 select-목록 디스크립터로 기술(describe)합니다.
6. `DESCRIBE` 문을 사용하여 입력 파라미터를 바인드-변수 디스크립터로 기술합니다.
7. (필요한 경우) 각 입력 파라미터의 값을 사용자에게 묻습니다. `SET DESCRIPTOR` 문을 사용하여 값을 디스크립터에 할당합니다.
8. `DECLARE CURSOR` 문을 사용하여 문에 대한 커서를 정의합니다.
9. `OPEN CURSOR` 문을 사용하여 문에 대한 커서를 엽니다.
10. `FETCH` 문을 사용하여 커서에서 각 행을 페치하여, 각 행을 select-목록 디스크립터에 저장합니다.
11. `GET DESCRIPTOR` 명령을 사용하여 select-목록 디스크립터를 조회(interrogate)하여 현재 행의 각 컬럼 값을 찾습니다.
12. `CLOSE CURSOR` 문을 사용하여 커서를 닫고 커서 리소스를 해제합니다.

## 디스크립터 속성 (Descriptor attributes)

디스크립터는 다음 속성을 담을 수 있습니다.

| 필드 | 타입 | 속성 설명 |
|---|---|---|
| `CARDINALITY` | `integer` | 결과 집합의 행 수. |
| `DATA` | N/A | 데이터 값. |
| `DATETIME_INTERVAL_CODE` | `integer` | `TYPE`이 `9`인 경우: `1 - DATE` / `2 - TIME` / `3 - TIMESTAMP` / `4 - TIME WITH TIMEZONE` / `5 - TIMESTAMP WITH TIMEZONE` |
| `DATETIME_INTERVAL_PRECISION` | `integer` | 미사용(Unused). |
| `INDICATOR` | `integer` | `NULL` 또는 잘린(truncated) 값을 나타냄. |
| `KEY_MEMBER` | `integer` | 미사용(`FALSE` 반환). |
| `LENGTH` | `integer` | 데이터 길이(서버에 저장된 대로). |
| `NAME` | `string` | 데이터가 있는 컬럼의 이름. |
| `NULLABLE` | `integer` | 미사용(`TRUE` 반환). |
| `OCTET_LENGTH` | `integer` | 서버에 저장된 데이터 길이(바이트 단위). |
| `PRECISION` | `integer` | 데이터 정밀도(데이터가 `numeric` 타입인 경우). |
| `RETURNED_LENGTH` | `integer` | 데이터 항목의 실제 길이. |
| `RETURNED_OCTET_LENGTH` | `integer` | 데이터 항목의 실제 길이. |
| `SCALE` | `integer` | 데이터 스케일(데이터가 `numeric` 타입인 경우). |
| `TYPE` | `integer` | 컬럼의 데이터 타입을 나타내는 숫자 코드: `1 - SQL3_CHARACTER` / `2 - SQL3_NUMERIC` / `3 - SQL3_DECIMAL` / `4 - SQL3_INTEGER` / `5 - SQL3_SMALLINT` / `6 - SQL3_FLOAT` / `7 - SQL3_REAL` / `8 - SQL3_DOUBLE_PRECISION` / `9 - SQL3_DATE_TIME_TIMESTAMP` / `10 - SQL3_INTERVAL` / `12 - SQL3_CHARACTER_VARYING` / `13 - SQL3_ENUMERATED` / `14 - SQL3_BIT` / `15 - SQL3_BIT_VARYING` / `16 - SQL3_BOOLEAN` |

## 예제: 디스크립터를 사용하여 데이터 반환 (Example: Using a descriptor to return data)

다음의 간단한 애플리케이션은 최종 사용자가 입력한 SQL 문을 실행합니다. 코드 샘플은 다음을 보여줍니다.

- SQL 디스크립터를 사용하여 `SELECT` 문을 실행하는 방법.
- 문이 반환한 데이터와 메타데이터를 찾는 방법.

이 애플리케이션은 최종 사용자로부터 SQL 문을 받아, 그 문에 `SELECT` 키워드가 포함되어 있는지 테스트하고, 문을 실행합니다.

### SQL 디스크립터를 사용하여 `SELECT` 문 실행 (Using a SQL descriptor to execute a SELECT statement)

애플리케이션을 호출할 때, 최종 사용자는 SQL 문을 수행할 데이터베이스의 이름과 쿼리 텍스트를 담은 문자열을 제공해야 합니다.

예를 들어 사용자는 다음 명령으로 샘플을 호출할 수 있습니다.

```text
./exec_stmt edb "SELECT * FROM emp"
```

샘플 프로그램:

```c
/************************************************************
 * exec_stmt.pgc
 *
 */

#include <stdio.h>
#include <stdlib.h>
#include <sql3types.h>
#include <sqlca.h>

EXEC SQL WHENEVER SQLERROR SQLPRINT;
static void print_meta_data( char * desc_name );

char *md1 = "col field                data              ret";
char *md2 = "num name                 type              len";
char *md3 = "--- -------------------- ----------------- ---";

int main( int argc, char *argv[] )
{

  EXEC SQL BEGIN DECLARE SECTION;
    char  *db   = argv[1];
    char  *stmt = argv[2];
    int    col_count;
  EXEC SQL END DECLARE SECTION;

  EXEC SQL CONNECT TO :db;

  EXEC SQL ALLOCATE DESCRIPTOR parse_desc;
  EXEC SQL PREPARE query FROM :stmt;
  EXEC SQL DESCRIBE query INTO SQL DESCRIPTOR parse_desc;
  EXEC SQL GET DESCRIPTOR parse_desc :col_count = COUNT;

if( col_count == 0 )
{
    EXEC SQL EXECUTE IMMEDIATE :stmt;

    if( sqlca.sqlcode >= 0 )
      EXEC SQL COMMIT;
}
else
{
    int row;

    EXEC SQL ALLOCATE DESCRIPTOR row_desc;
    EXEC SQL DECLARE my_cursor CURSOR FOR query;
    EXEC SQL OPEN my_cursor;

    for( row = 0; ; row++ )
    {
       EXEC SQL BEGIN DECLARE SECTION;
         int     col;
       EXEC SQL END DECLARE SECTION;
       EXEC SQL FETCH IN my_cursor
         INTO SQL DESCRIPTOR row_desc;

       if( sqlca.sqlcode != 0 )
          break;

       if( row == 0 )
          print_meta_data( "row_desc" );

       printf("[RECORD %d]\n", row+1);

       for( col = 1; col <= col_count; col++ )
       {
           EXEC SQL BEGIN DECLARE SECTION;
             short   ind;
             varchar val[40+1];
             varchar name[20+1];
           EXEC SQL END DECLARE SECTION;

           EXEC SQL GET DESCRIPTOR row_desc
             VALUE :col
             :val = DATA, :ind = INDICATOR, :name = NAME;

           if( ind == -1 )
             printf( "  %-20s : <null>\n", name.arr );
           else if( ind > 0 )
             printf( "  %-20s : <truncated>\n", name.arr );
           else
             printf( "  %-20s : %s\n", name.arr, val.arr );
       }

       printf( "\n" );

    }
    printf( "%d rows\n", row );
}

exit( 0 );
}

static void print_meta_data( char *desc_name )
{
   EXEC SQL BEGIN DECLARE SECTION;
     char  *desc = desc_name;
     int    col_count;
     int    col;
   EXEC SQL END DECLARE SECTION;

static char *types[] =
{
  "unused           ",
  "CHARACTER        ",
  "NUMERIC          ",
  "DECIMAL          ",
  "INTEGER          ",
  "SMALLINT         ",
  "FLOAT            ",
  "REAL             ",
  "DOUBLE           ",
  "DATE_TIME        ",
  "INTERVAL         ",
  "unused           ",
  "CHARACTER_VARYING",
  "ENUMERATED       ",
  "BIT              ",
  "BIT_VARYING      ",
  "BOOLEAN          ",
  "abstract         "
};

EXEC SQL GET DESCRIPTOR :desc :col_count = count;

printf( "%s\n", md1 );
printf( "%s\n", md2 );
printf( "%s\n", md3 );

for( col = 1; col <= col_count; col++ )
{

   EXEC SQL BEGIN DECLARE SECTION;
     int     type;
     int     ret_len;
     varchar name[21];
   EXEC SQL END DECLARE SECTION;
   char *type_name;

   EXEC SQL GET DESCRIPTOR :desc
     VALUE :col
     :name = NAME,
     :type = TYPE,
     :ret_len = RETURNED_OCTET_LENGTH;

   if( type > 0 && type < SQL3_abstract )
     type_name = types[type];
   else
     type_name = "unknown";

   printf( "%02d: %-20s %-17s %04d\n",
     col, name.arr, type_name, ret_len );
}
printf( "\n" );
}

/************************************************************/
```

코드 샘플은 먼저 C `stdio` 및 `stdlib` 라이브러리의 프로토타입과 타입 정의, SQL 데이터 타입 심볼, 그리고 `SQLCA`(SQL 통신 영역, SQL communications area) 구조를 포함합니다.

```c
#include <stdio.h>
#include <stdlib.h>
#include <sql3types.h>
#include <sqlca.h>
```

샘플은 최소한의 오류 처리를 제공합니다. 애플리케이션이 SQL 오류를 만나면 오류 메시지를 화면에 출력합니다.

```sql
EXEC SQL WHENEVER SQLERROR SQLPRINT;
```

### 문이 반환한 데이터와 메타데이터 찾기 (Finding the data and metadata returned by the statement)

애플리케이션은 디스크립터에서 찾은 메타데이터를 출력하는 `print_meta_data()`라는 함수에 대한 전방 선언(forward-declaration)을 포함합니다.

```c
static void print_meta_data( char * desc_name );
```

다음 코드는 애플리케이션이 메타데이터를 출력할 때 사용하는 컬럼 헤더 정보를 지정합니다.

```c
char *md1 = "col field data ret";
char *md2 = "num name type len";
char *md3 = "--- -------------------- ----------------- ---";

int main( int argc, char *argv[] )
{
```

다음 선언 섹션은 애플리케이션이 연결하는 데이터베이스의 이름, SQL 문의 내용, 그리고 결과 집합의 컬럼 수(있는 경우)를 담을 호스트 변수를 식별합니다.

```sql
EXEC SQL BEGIN DECLARE SECTION;
  char *db = argv[1];
  char *stmt = argv[2];
  int col_count;
EXEC SQL END DECLARE SECTION;
```

애플리케이션은 기본 자격 증명을 사용하여 데이터베이스에 연결합니다.

```sql
EXEC SQL CONNECT TO :db;
```

다음으로, 애플리케이션은 문에 대한 메타데이터를 담을 SQL 디스크립터를 할당합니다.

```sql
EXEC SQL ALLOCATE DESCRIPTOR parse_desc;
```

애플리케이션은 `PREPARE` 문을 사용하여 사용자가 제공한 문자열의 구문을 확인합니다.

```sql
EXEC SQL PREPARE query FROM :stmt;
```

또한 `DESCRIBE` 문을 사용하여 쿼리의 메타데이터를 SQL 디스크립터로 옮깁니다.

```sql
EXEC SQL DESCRIBE query INTO SQL DESCRIPTOR parse_desc;
```

그런 다음 애플리케이션은 디스크립터를 조회하여 결과 집합의 컬럼 수를 알아내고 이를 호스트 변수 `col_count`에 저장합니다.

```sql
EXEC SQL GET DESCRIPTOR parse_desc :col_count = COUNT;
```

컬럼 수가 0이면 최종 사용자가 `SELECT` 문을 입력하지 않은 것입니다. 애플리케이션은 `EXECUTE IMMEDIATE` 문을 사용하여 문의 내용을 처리합니다.

```c
if( col_count == 0 )
{
   EXEC SQL EXECUTE IMMEDIATE :stmt;
```

문이 성공적으로 실행되면 애플리케이션은 `COMMIT`을 수행합니다.

```c
if( sqlca.sqlcode >= 0 )
  EXEC SQL COMMIT;
}
else
{
```

사용자가 입력한 문이 `SELECT` 문인 경우(컬럼 수가 0이 아니므로 알 수 있음), 애플리케이션은 `row`라는 변수를 선언합니다.

```c
int row;
```

그런 다음 애플리케이션은 결과 집합의 특정 행에 대한 설명과 값을 담는 또 다른 디스크립터를 할당합니다.

```sql
EXEC SQL ALLOCATE DESCRIPTOR row_desc;
```

애플리케이션은 준비된(prepared) 문에 대한 커서를 선언하고 엽니다.

```sql
EXEC SQL DECLARE my_cursor CURSOR FOR query;
EXEC SQL OPEN my_cursor;
```

결과 집합의 행을 반복합니다.

```c
for( row = 0; ; row++ )
{
  EXEC SQL BEGIN DECLARE SECTION;
    int col;
  EXEC SQL END DECLARE SECTION;
```

그런 다음 `FETCH`를 사용하여 커서에서 다음 행을 디스크립터로 조회합니다.

```sql
EXEC SQL FETCH IN my_cursor INTO SQL DESCRIPTOR row_desc;
```

애플리케이션은 `FETCH`가 실패하지 않았는지 확인합니다. `FETCH`가 실패하면 애플리케이션은 결과 집합의 끝에 도달한 것이므로 루프를 중단합니다.

```c
if( sqlca.sqlcode != 0 )
   break;
```

애플리케이션은 이것이 커서의 첫 번째 행인지 확인합니다. 첫 번째 행이면 애플리케이션은 그 행의 메타데이터를 출력합니다.

```c
if( row == 0 )
   print_meta_data( "row_desc" );
```

다음으로, 행 번호를 담은 레코드 헤더를 출력합니다.

```c
printf("[RECORD %d]\n", row+1);
```

그런 다음 행의 각 컬럼을 반복합니다.

```c
for( col = 1; col <= col_count; col++ )
{
   EXEC SQL BEGIN DECLARE SECTION;
     short ind;
     varchar val[40+1];
     varchar name[20+1];
   EXEC SQL END DECLARE SECTION;
```

애플리케이션은 행 디스크립터(`row_desc`)를 조회하여 컬럼 값 `:val`, null 지시자 `:ind`, 컬럼 이름 `:name`을 앞서 선언한 호스트 변수로 복사합니다. 쉼표로 구분된 목록을 사용하여 디스크립터에서 여러 항목을 조회할 수 있습니다.

```sql
EXEC SQL GET DESCRIPTOR row_desc
  VALUE :col
  :val = DATA, :ind = INDICATOR, :name = NAME;
```

null 지시자(`ind`)가 음수이면 컬럼 값은 `NULL`입니다. null 지시자가 `0`보다 크면 컬럼 값이 너무 길어 val 호스트 변수에 맞지 않으므로 `<truncated>`를 출력합니다. 그렇지 않으면 null 지시자가 `0`, 즉 `NOT NULL`이므로 값을 출력합니다. 각 경우에 값(또는 `<null>`, `<truncated>`) 앞에 컬럼 이름을 붙입니다.

```c
if( ind == -1 )
  printf( " %-20s : <null>\n", name.arr );
else if( ind > 0 )
  printf( " %-20s : <truncated>\n", name.arr );
else
  printf( " %-20s : %s\n", name.arr, val.arr );
}

printf( "\n" );
}
```

루프가 종료되면 애플리케이션은 페치한 행 수를 출력하고 종료합니다.

```c
   printf( "%d rows\n", row );
  }

exit( 0 );
}
```

`print_meta_data()` 함수는 디스크립터에서 메타데이터를 추출하여 각 컬럼의 이름, 데이터 타입, 길이를 출력합니다.

```c
static void print_meta_data( char *desc_name )
{
```

애플리케이션은 호스트 변수를 선언합니다.

```sql
EXEC SQL BEGIN DECLARE SECTION;
  char *desc = desc_name;
  int col_count;
  int col;
EXEC SQL END DECLARE SECTION;
```

그런 다음 애플리케이션은 데이터 타입 값(`numeric`)을 데이터 타입 이름으로 매핑하는 문자열 배열을 정의합니다. 디스크립터에서 찾은 숫자 값을 사용하여 이 배열을 인덱싱합니다. 예를 들어 특정 컬럼이 타입 `2`임을 알게 되면, `types[2]`를 작성하여 그 타입의 이름(`NUMERIC`)을 찾을 수 있습니다.

```c
static char *types[] =
{
  "unused ",
  "CHARACTER ",
  "NUMERIC ",
  "DECIMAL ",
  "INTEGER ",
  "SMALLINT ",
  "FLOAT ",
  "REAL ",
  "DOUBLE ",
  "DATE_TIME ",
  "INTERVAL ",
  "unused ",
  "CHARACTER_VARYING",
  "ENUMERATED ",
  "BIT ",
  "BIT_VARYING ",
  "BOOLEAN ",
  "abstract "
};
```

애플리케이션은 디스크립터에서 컬럼 수를 조회합니다. 프로그램은 디스크립터의 이름을 담은 호스트 변수(`desc`)를 사용하여 디스크립터를 참조합니다. 대부분의 시나리오에서는 식별자를 사용하여 디스크립터를 참조합니다. 이 경우 호출자가 디스크립터 이름을 제공했으므로 호스트 변수를 사용하여 디스크립터를 참조할 수 있습니다.

```sql
EXEC SQL GET DESCRIPTOR :desc :col_count = count;
```

애플리케이션은 이 애플리케이션 시작 부분에 정의된 컬럼 헤더를 출력합니다.

```c
printf( "%s\n", md1 );
printf( "%s\n", md2 );
printf( "%s\n", md3 );
```

그런 다음 디스크립터에서 찾은 각 컬럼을 반복하며 각 컬럼의 이름, 타입, 길이를 출력합니다.

```c
for( col = 1; col <= col_count; col++ )
{
  EXEC SQL BEGIN DECLARE SECTION;
    int type;
    int ret_len;
    varchar name[21];
  EXEC SQL END DECLARE SECTION;
  char *type_name;
```

현재 컬럼의 이름, 타입 코드, 길이를 조회합니다.

```sql
EXEC SQL GET DESCRIPTOR :desc
 VALUE :col
 :name = NAME,
 :type = TYPE,
 :ret_len = RETURNED_OCTET_LENGTH;
```

숫자 타입 코드가 '알려진' 타입 코드(즉, `types[]` 배열에서 찾은 타입 코드)와 일치하면 `type_name`을 해당 타입의 이름으로 설정합니다. 그렇지 않으면 `type_name`을 `"unknown"`으로 설정합니다.

```c
if( type > 0 && type < SQL3_abstract )
  type_name = types[type];
else
  type_name = "unknown";
```

그런 다음 컬럼 번호, 이름, 타입 이름, 길이를 출력합니다.

```c
   printf( "%02d: %-20s %-17s %04d\n",
     col, name.arr, type_name, ret_len );
  }
  printf( "\n" );
}
```
