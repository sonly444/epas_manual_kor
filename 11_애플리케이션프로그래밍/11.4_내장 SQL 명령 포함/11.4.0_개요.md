# 임베디드 SQL 명령 포함 (Including embedded SQL commands / ECPGPlus) — EPAS 18 애플리케이션 프로그래밍

> 원문: [EPAS v18 — Application programming › Including embedded SQL commands](https://www.enterprisedb.com/docs/epas/latest/application_programming/ecpgplus_guide/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 지시어·명령·라이브러리 이름은 원문 그대로 보존했습니다.

EDB는 PostgreSQL 전처리기(precompiler)인 ECPG를 향상시켜 ECPGPlus를 만들었습니다. ECPGPlus를 사용하면 EDB Postgres Advanced Server 데이터베이스에 연결된 상태에서 C 애플리케이션에 Pro\*C 호환 임베디드 SQL 명령을 포함할 수 있습니다. ECPGPlus로 애플리케이션을 컴파일하면 SQL 코드 구문이 검사되고 C로 변환됩니다.

ECPGPlus는 다음을 지원합니다.

- Oracle 동적 SQL – 방식 4(Oracle Dynamic SQL – Method 4, ODS-M4)
- Pro\*C 호환 익명 블록(anonymous block)
- Oracle 데이터베이스와 호환되는 `CALL` 문

ECPGPlus의 Pro\*C 호환성의 일부로, `BEGIN DECLARE SECTION` 및 `END DECLARE SECTION` 지시어를 포함할 필요가 없습니다.

대부분의 ECPGPlus 문은 커뮤니티 PostgreSQL에서 동작하지만, `CALL` 문과 `EXECUTE…END EXEC` 문은 클라이언트 애플리케이션이 EDB Postgres Advanced Server에 연결된 경우에만 동작합니다.
