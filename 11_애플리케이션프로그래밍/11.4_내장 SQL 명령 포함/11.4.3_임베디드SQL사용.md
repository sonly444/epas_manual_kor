# 임베디드 SQL 사용 (Using embedded SQL) — EPAS 18 ECPGPlus

> 원문: [EPAS v18 — Application programming › Including embedded SQL commands › Using embedded SQL](https://www.enterprisedb.com/docs/epas/latest/application_programming/ecpgplus_guide/03_using_embedded_sql/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·지시어·이름·코드는 원문 그대로 보존했습니다.

다음 두 예제는 EDB Postgres Advanced Server에서 임베디드 SQL을 사용하는 방법을 보여줍니다.

## 예제: 간단한 쿼리 (Example: A simple query)

첫 번째 코드 샘플은 단일 행을 반환하는 `SELECT` 문을 실행하여 그 결과를 호스트 변수 그룹에 저장하는 방법을 보여줍니다. 호스트 변수를 선언한 후, 하드코딩된 역할 이름과 연관된 비밀번호를 사용하여 `edb` 샘플 데이터베이스에 연결하고 `emp` 테이블을 질의합니다. 쿼리는 선언된 호스트 변수로 값을 반환합니다. `NULL` 지시자 변수(indicator variable)의 값을 확인한 후, 간단한 결과 집합을 화면에 출력하고 연결을 닫습니다.

```c
/************************************************************
 * print_emp.pgc
 *
 */
#include <stdio.h>

int main(void)
{
  EXEC SQL BEGIN DECLARE SECTION;
    int v_empno;
    char v_ename[40];
    double v_sal;
    double v_comm;
    short v_comm_ind;
  EXEC SQL END DECLARE SECTION;

  EXEC SQL WHENEVER SQLERROR sqlprint;

  EXEC SQL CONNECT TO edb
    USER 'alice' IDENTIFIED BY '1safepwd';

  EXEC SQL
     SELECT
      empno, ename, sal, comm
     INTO
      :v_empno, :v_ename, :v_sal, :v_comm INDICATOR:v_comm_ind
     FROM
      emp
    WHERE
      empno = 7369;

  if (v_comm_ind)
    printf("empno(%d), ename(%s), sal(%.2f) comm(NULL)\n",
            v_empno, v_ename, v_sal);
  else
    printf("empno(%d), ename(%s), sal(%.2f) comm(%.2f)\n",
            v_empno, v_ename, v_sal, v_comm);
  EXEC SQL DISCONNECT;
}
/***********************************************************\*
```

코드 샘플은 먼저 C `stdio` 라이브러리의 프로토타입과 타입 정의를 포함한 다음 `main` 함수를 선언합니다.

```c
#include <stdio.h>

int main(void)
{
```

다음으로, 애플리케이션은 데이터베이스 서버와 상호작용하는 데 사용되는 호스트 변수 집합을 선언합니다.

```c
EXEC SQL BEGIN DECLARE SECTION;
  int v_empno;
  char v_ename[40];
  double v_sal;
  double v_comm;
  short v_comm_ind;
EXEC SQL END DECLARE SECTION;
```

`PROC` 모드로 코드를 사전 컴파일할 계획이라면 `BEGIN DECLARE…END DECLARE` 섹션을 생략할 수 있습니다. 호스트 변수 선언에 대한 자세한 내용은 아래 "호스트 변수 선언"을 참고하십시오.

선언 섹션의 각 변수와 연관된 데이터 타입은 C 데이터 타입입니다. 서버와 클라이언트 애플리케이션 간에 전달되는 데이터는 호환되는 데이터 타입을 공유해야 합니다. 데이터 타입에 대한 자세한 내용은 [지원되는 C 데이터 타입(Supported C data types)](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/07_reference/)을 참고하십시오.

다음 문은 서버에 오류를 처리하는 방법을 알려줍니다.

```sql
EXEC SQL WHENEVER SQLERROR sqlprint;
```

클라이언트 애플리케이션이 SQL 코드에서 오류를 만나면, 서버는 `ecpglib`와 함께 제공되는 `sqlprint()` 함수를 사용하여 `stderr`(표준 오류)에 오류 메시지를 출력합니다. 다음 `EXEC SQL` 문은 EDB Postgres Advanced Server와 연결을 설정합니다.

```sql
EXEC SQL CONNECT TO edb
  USER 'alice' IDENTIFIED BY '1safepwd';
```

이 예에서 클라이언트 애플리케이션은 `alice`라는 역할과 비밀번호 `1safepwd`를 사용하여 `edb` 데이터베이스에 연결합니다.

그런 다음 코드는 `emp` 테이블에 대해 쿼리를 수행합니다.

```sql
EXEC SQL
   SELECT
     empno, ename, sal, comm
   INTO
     :v_empno, :v_ename, :v_sal, :v_comm INDICATOR :v_comm_ind
   FROM
     emp
  WHERE
     empno = 7369;
```

쿼리는 사원 번호 7369에 대한 정보를 반환합니다.

`SELECT` 문은 `INTO` 절을 사용하여 조회된 값(`empno`, `ename`, `sal`, `comm` 컬럼에서)을 `:v_empno`, `:v_ename`, `:v_sal`, `:v_comm` 호스트 변수(및 `:v_comm_ind` null 지시자)에 할당합니다. 조회된 첫 번째 값은 `INTO` 절에 나열된 첫 번째 변수에, 두 번째 값은 두 번째 변수에 할당되는 식입니다.

`comm` 컬럼은 사원이 받은 커미션 값을 담으며 잠재적으로 `NULL` 값을 담을 수 있습니다. 이 문은 `INDICATOR` 키워드와 null 지시자를 담을 호스트 변수를 포함합니다.

코드는 null 지시자를 확인하고 적절한 결과를 표시합니다.

```c
if (v_comm_ind)
  printf("empno(%d), ename(%s), sal(%.2f) comm(NULL)\n",
          v_empno, v_ename, v_sal);
else
  printf("empno(%d), ename(%s), sal(%.2f) comm(%.2f)\n",
          v_empno, v_ename, v_sal, v_comm);
```

null 지시자가 `0`(즉, `false`)이면 `comm` 컬럼은 의미 있는 값을 담고 있으며 `printf` 함수가 커미션을 표시합니다. null 지시자가 0이 아닌 값을 담고 있으면 `comm`은 `NULL`이며 `printf`는 `NULL` 값을 표시합니다. `NULL`을 호스트 변수로 페치하면 그 호스트 변수(null 지시자 외)는 의미 있는 값을 담지 않습니다. `NULL`일 수 있는 모든 값을 식별하려면 null 지시자를 사용해야 합니다.

코드 샘플의 마지막 문은 서버 연결을 닫습니다.

```sql
EXEC SQL DISCONNECT;
}
```

### 지시자 변수 사용 (Using indicator variables)

앞의 예제는 (서버가 반환할 때) `comm` 컬럼의 값이 `NULL`이었던 행을 식별하는 *지시자 변수(indicator variable)*를 포함했습니다. 지시자 변수는 앞선 변수의 내용이 `NULL`인지 또는 잘렸는지(truncated)를 나타내는 추가 호스트 변수입니다. 지시자 변수는 행의 내용이 저장될 때 채워집니다. 지시자 변수는 다음 값을 담을 수 있습니다.

| 지시자 값 | 의미 |
|---|---|
| 지시자 변수가 `0`보다 작은 경우 | 서버가 반환한 값이 `NULL`이었습니다. |
| 지시자 변수가 `0`과 같은 경우 | 서버가 반환한 값이 `NULL`이 아니었고 잘리지 않았습니다. |
| 지시자 변수가 `0`보다 큰 경우 | 서버가 반환한 값이 호스트 변수에 저장될 때 잘렸습니다. |

`INTO` 절에 지시자 변수를 포함할 때, 선택적 `INDICATOR` 키워드를 포함할 필요는 없습니다.

쿼리가 해당 호스트 변수로 `NULL` 값을 절대 반환하지 않는다고 확신하는 경우 지시자 변수를 생략할 수 있습니다. 지시자 변수를 생략했는데 쿼리가 `NULL` 값을 반환하면, `ecpglib`는 런타임 오류를 발생시킵니다.

### 호스트 변수 선언 (Declaring host variables)

*호스트 변수(host variable)*는 SQL 문에서 값이 나타날 수 있는 지점이라면 어디에나 사용할 수 있습니다. 호스트 변수는 클라이언트 애플리케이션에서 서버로 데이터 값을 전달하고 서버에서 클라이언트 애플리케이션으로 데이터를 반환하는 데 사용할 수 있는 C 변수입니다. 호스트 변수는 다음이 될 수 있습니다.

- 배열
- `typedef`
- 포인터
- `struct`
- 임의의 스칼라 C 데이터 타입

다음 코드 조각은 `PROC` 모드와 비-`PROC` 모드에서 컴파일된 코드에서 호스트 변수를 사용하는 것을 보여줍니다. SQL 문은 `dept` 테이블에 행을 추가하여, 변수 `v_deptno`, `v_dname`, `v_loc`가 반환하는 값을 각각 `deptno` 컬럼, `dname` 컬럼, `loc` 컬럼에 삽입합니다.

`PROC` 모드로 컴파일하는 경우, `EXEC SQL BEGIN DECLARE SECTION`과 `EXEC SQL END DECLARE SECTION` 지시어를 생략할 수 있습니다. `PROC` 모드에서는 C 함수 파라미터를 호스트 변수로 사용할 수 있습니다.

```c
void addDept(int v_deptno, char v_dname, char v_loc)
{
  EXEC SQL INSERT INTO dept VALUES( :v_deptno, :v_dname, :v_loc);
}
```

`PROC` 모드로 컴파일하지 않는 경우, 임베디드 변수 선언을 `EXEC SQL BEGIN DECLARE SECTION`과 `EXEC SQL END DECLARE SECTION` 지시어로 감싸야 합니다.

```c
void addDept(int v_deptno, char v_dname, char v_loc)
{
  EXEC SQL BEGIN DECLARE SECTION;
    int v_deptno_copy = v_deptno;
    char v_dname_copy[14+1] = v_dname;
    char v_loc_copy[13+1] = v_loc;
  EXEC SQL END DECLARE SECTION;

  EXEC SQL INSERT INTO dept VALUES( :v_deptno, :v_dname, :v_loc);
}
```

호스트 변수를 사용하여 정보를 조회하기 위해 `SELECT` 문에 `INTO` 절을 포함할 수도 있습니다.

```sql
EXEC SQL SELECT deptno, dname, loc
  INTO :v_deptno, :v_dname, v_loc FROM dept;
```

`SELECT` 문이 반환하는 각 컬럼은 `INTO` 절에 타입 호환되는 대상 변수를 가져야 합니다. 이는 단일 행을 조회하는 간단한 예제입니다. 두 개 이상의 행을 조회하려면 다음 예제와 같이 커서를 정의해야 합니다.

## 예제: 커서로 결과 집합 처리 (Example: Using a cursor to process a result set)

다음 코드 샘플은 커서를 사용하여 결과 집합을 처리하는 것을 보여줍니다. 커서를 생성하고 사용하는 데는 네 가지 기본 단계가 있습니다.

1. `DECLARE CURSOR` 문을 사용하여 커서를 정의합니다.
2. `OPEN CURSOR` 문을 사용하여 커서를 엽니다.
3. `FETCH` 문을 사용하여 커서에서 데이터를 조회합니다.
4. `CLOSE CURSOR` 문을 사용하여 커서를 닫습니다.

호스트 변수를 선언한 후, 예제는 사용자가 제공한 역할 이름과 비밀번호를 사용하여 `edb` 데이터베이스에 연결하고 `emp` 테이블을 질의합니다. 쿼리는 `employees`라는 커서로 값을 반환합니다. 그런 다음 코드 샘플은 커서를 열고 결과 집합을 한 번에 한 행씩 반복하며 결과 집합을 출력합니다. 결과 집합의 끝을 감지하면 연결을 닫습니다.

```c
/************************************************************
 * print_emps.pgc
 *
 */
#include <stdio.h>

int main(int argc, char *argv[])
{
  EXEC SQL BEGIN DECLARE SECTION;
    char *username = argv[1];
    char *password = argv[2];
    int v_empno;
    char v_ename[40];
    double v_sal;
    double v_comm;
    short v_comm_ind;
  EXEC SQL END DECLARE SECTION;

  EXEC SQL WHENEVER SQLERROR sqlprint;

  EXEC SQL CONNECT TO edb USER :username IDENTIFIED BY :password;

  EXEC SQL DECLARE employees CURSOR FOR
    SELECT
      empno, ename, sal, comm
    FROM
      emp;

  EXEC SQL OPEN employees;

  EXEC SQL WHENEVER NOT FOUND DO break;

  for (;;)
  {
    EXEC SQL FETCH NEXT FROM employees
      INTO
       :v_empno, :v_ename, :v_sal, :v_comm INDICATOR :v_comm_ind;

    if (v_comm_ind)
      printf("empno(%d), ename(%s), sal(%.2f) comm(NULL)\n",
              v_empno, v_ename, v_sal);
    else
      printf("empno(%d), ename(%s), sal(%.2f) comm(%.2f)\n",
              v_empno, v_ename, v_sal, v_comm);
  }
  EXEC SQL CLOSE employees;
  EXEC SQL DISCONNECT;
}
/************************************************************/
```

코드 샘플은 먼저 C `stdio` 라이브러리의 프로토타입과 타입 정의를 포함한 다음 `main` 함수를 선언합니다.

```c
#include <stdio.h>

int main(int argc, char *argv[])
{
```

### DECLARE

다음으로, 애플리케이션은 데이터베이스 서버와 상호작용하는 데 사용되는 호스트 변수 집합을 선언합니다.

```sql
EXEC SQL BEGIN DECLARE SECTION;
  char *username = argv[1];
  char *password = argv[2];
  int v_empno;
  char v_ename[40];
  double v_sal;
  double v_comm;
  short v_comm_ind;
EXEC SQL END DECLARE SECTION;
```

`argv[]`는 사용자가 클라이언트 애플리케이션을 실행할 때 입력한 명령줄 인수를 담는 배열입니다. `argv[1]`은 첫 번째 명령줄 인수(이 경우 `username`)를 담고, `argv[2]`는 두 번째 명령줄 인수(`password`)를 담습니다. 이 예제는 실제 애플리케이션에서 일반적으로 포함할 오류 검사 코드를 생략합니다. 선언은 `username`과 `password`의 값을 초기화하여, 사용자가 클라이언트 애플리케이션을 호출할 때 입력한 값으로 설정합니다.

각 변수의 별도 복사본을 만드는 대신 SQL 문에서 `argv[1]`과 `argv[2]`를 참조할 수 있다고 생각할 수 있습니다. 그러나 그것은 동작하지 않습니다. `PROC` 모드로 컴파일하지 않는 한, 모든 호스트 변수는 `BEGIN/END DECLARE SECTION`에 선언되어야 합니다. `argv`는 함수 *파라미터*(자동 변수가 아님)이므로 `BEGIN/END DECLARE SECTION`에 선언할 수 없습니다. `PROC` 모드로 컴파일하는 경우, SQL 문에서 임의의 C 변수를 참조할 수 있습니다.

다음 문은 서버가 ECPGPlus 또는 데이터베이스 서버가 반환한 오류 메시지의 텍스트를 출력하여 SQL 오류에 응답하도록 지시합니다.

```sql
EXEC SQL WHENEVER SQLERROR sqlprint;
```

그런 다음 클라이언트 애플리케이션은 EDB Postgres Advanced Server와 연결을 설정합니다.

```sql
EXEC SQL CONNECT TO edb USER :username IDENTIFIED BY :password;
```

`CONNECT` 문은 연결 시 애플리케이션을 서버에 인증하기 위해 `:username`과 `:password` 호스트 변수에 있는 값을 사용하여 `edb` 데이터베이스에 대한 연결을 생성합니다.

다음 문은 `employees`라는 커서를 선언합니다.

```sql
EXEC SQL DECLARE employees CURSOR FOR
  SELECT
    empno, ename, sal, comm
  FROM
    emp;
```

`employees`는 `emp` 테이블에 대한 `SELECT` 문의 결과 집합을 담습니다. 쿼리는 `empno`, `ename`, `sal`, `comm` 컬럼에서 사원 정보를 반환합니다. 커서를 선언할 때는 `INTO` 절을 포함하지 않는 점에 유의하십시오. 대신 커서에서 `FETCH`할 때 대상 변수(또는 디스크립터)를 지정합니다.

### OPEN

커서에서 행을 페치하기 전에, 클라이언트 애플리케이션은 커서를 `OPEN`해야 합니다.

```sql
EXEC SQL OPEN employees;
```

이어지는 `FETCH` 섹션에서 클라이언트 애플리케이션은 커서의 내용을 반복합니다. 클라이언트 애플리케이션은 커서의 끝에 도달하면 서버가 `break`(즉, 루프 종료)하도록 지시하는 `WHENEVER` 문을 포함합니다.

```sql
EXEC SQL WHENEVER NOT FOUND DO break;
```

### FETCH

그런 다음 클라이언트 애플리케이션은 `FETCH` 문을 사용하여 커서에서 각 행을 이전에 선언된 호스트 변수로(`INTO`) 조회합니다.

```c
for (;;)
{
  EXEC SQL FETCH NEXT FROM employees
    INTO
     :v_empno, :v_ename, :v_sal, :v_comm INDICATOR :v_comm_ind;
```

`FETCH` 문은 `INTO` 절을 사용하여 조회된 값을 `:v_empno`, `:v_ename`, `:v_sal`, `:v_comm` 호스트 변수(및 `:v_comm_ind` null 지시자)에 할당합니다. 커서의 첫 번째 값은 `INTO` 절에 나열된 첫 번째 변수에, 두 번째 값은 두 번째 변수에 할당되는 식입니다.

`FETCH` 문도 `INDICATOR` 키워드와 null 지시자를 담을 호스트 변수를 포함합니다. 조회된 레코드의 `comm` 컬럼이 `NULL` 값을 담고 있으면 `v_comm_ind`가 0이 아닌 값으로 설정되어 그 컬럼이 `NULL`임을 나타냅니다.

그런 다음 코드는 null 지시자를 확인하고 적절한 결과를 표시합니다.

```c
if (v_comm_ind)
  printf("empno(%d), ename(%s), sal(%.2f) comm(NULL)\n",
          v_empno, v_ename, v_sal);
else
  printf("empno(%d), ename(%s), sal(%.2f) comm(%.2f)\n",
          v_empno, v_ename, v_sal, v_comm);
}
```

null 지시자가 `0`(즉, `false`)이면 `v_comm`은 의미 있는 값을 담고 있으며 `printf` 함수가 커미션을 표시합니다. null 지시자가 0이 아닌 값을 담고 있으면 `comm`은 `NULL`이며 `printf`는 문자열 `'NULL'`을 표시합니다. `NULL`을 호스트 변수로 페치하면 그 호스트 변수(null 지시자 외)는 의미 있는 값을 담지 않습니다. `NULL`일 수 있는 모든 값에는 null 지시자를 사용해야 합니다.

### CLOSE

코드 샘플의 마지막 문은 커서(`employees`)와 서버 연결을 닫습니다.

```sql
EXEC SQL CLOSE employees;
EXEC SQL DISCONNECT;
```
