# 디버거 시작 (Starting the debugger) — EPAS 18 프로그램 디버깅

> 원문: [EPAS v18 — Application programming › Debugging programs › Starting the debugger](https://www.enterprisedb.com/docs/epas/latest/application_programming/12_debugger/starting_debugger/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 메뉴·필드·명령은 원문 그대로 보존했습니다.

pgAdmin 4로 저장 프로시저나 함수를 디버깅하려면:

1. **대상 선택**: pgAdmin 4 Browser 패널에서 디버깅할 저장 프로시저, 함수, 또는 패키지 멤버를 선택합니다.

2. **디버깅 접근**: **Object > Debugging > Debug**로 이동합니다.

## 파라미터 구성

디버거가 시작되면 `IN` 또는 `IN OUT` 파라미터를 위한 창을 표시합니다. 인터페이스는 다음 필드를 제공합니다.

- **Name**: 형식 파라미터(formal parameter) 식별자
- **Type**: 파라미터 데이터 타입 지정
- **Null?**: 파라미터를 `NULL`로 표시하는 체크박스
- **Expression?**: Value 필드에 식(expression)이 포함된 경우 체크하는 체크박스
- **Value**: 프로그램에 전달되는 파라미터 값
- **Use Default?**: 기본값을 사용하기 위한 체크박스
- **Default Value**: 파라미터의 기본 설정값

## 패키지 초기화

패키지 멤버를 디버깅할 때, 기본 프로시저나 함수를 디버깅하기 전에 패키지 초기화 섹션을 단계별로 실행하려면 **Debug Package Initializer** 옵션을 체크합니다. 이 옵션을 선택하지 않으면 초기화 코드는 한 줄씩 표시되지 않고 실행됩니다.

파라미터를 구성한 후 **Debug**를 선택하여 디버깅 세션을 시작합니다.

**참고**: 인-컨텍스트 디버깅에서는 Debugger 창이 아니라 호출하는 애플리케이션이 파라미터 값을 제공합니다.

전체 디버깅 주기를 완료하면 파라미터 창이 다시 열려, 새 값을 입력하거나 세션을 종료할 수 있습니다.
