# 프로그램 디버깅 (Debugging programs) — EPAS 18 애플리케이션 프로그래밍

> 원문: [EPAS v18 — Application programming › Debugging programs](https://www.enterprisedb.com/docs/epas/latest/application_programming/12_debugger/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 메뉴·명령·이름은 원문 그대로 보존했습니다.

디버거는 개발자와 DBA에게 그래픽 기반의 동적 환경에서 서버 측 프로그램을 테스트하고 디버깅할 수 있는 능력을 제공합니다. 디버깅할 수 있는 프로그램 유형은 다음과 같습니다.

- SPL 저장 프로시저(stored procedure)
- 함수(function)
- 트리거(trigger)
- 패키지(package)
- PL/pgSQL 함수 및 트리거

- **디버거 실행 (Running the debugger)** — 프로그램을 디버깅하기 위해 수행할 수 있는 작업을 설명합니다. (`11_2_4_디버거실행.md`)
