# 디버거 인터페이스 개요 (Debugger interface overview) — EPAS 18 Application Programming

> 원문: [EPAS v18 — Application programming › Debugging programs › Debugger interface overview](https://www.enterprisedb.com/docs/epas/latest/application_programming/12_debugger/debugger_interface/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. UI 항목명·명령은 원문 그대로 보존했습니다.

메인 디버거 창은 두 개의 패널로 구성됩니다.

- 상단 Program Body 패널은 프로그램 소스 코드를 표시합니다.
- 하단 Tabs 패널은 다양한 정보를 위한 탭 집합을 제공합니다.

디버깅 기능에 접근하려면 상단 패널에 있는 도구 모음(tool bar) 아이콘을 사용합니다.

## Program Body 패널 (The Program Body panel)

Program Body 패널은 디버깅 중인 프로그램의 소스 코드를 표시합니다. 그림은 디버거가 `SELECT` 문을 실행하려는 참임을 보여줍니다. 프로그램 본문의 파란색 표시기(indicator)는 다음에 실행할 문을 강조합니다.

![The Program Body](https://www.enterprisedb.com/docs/static/80fe758933895511d9d4b77efb20638a/302a4/program_body.png)

## Tabs 패널 (The Tabs panel)

하단 Tabs 패널을 사용하여 파라미터 값이나 지역 변수를 보거나 수정하고, `RAISE INFO`로 생성된 메시지와 함수 결과를 볼 수 있습니다.

패널의 탭이 표시하는 정보는 다음과 같습니다.

- **Parameters** 탭은 현재 파라미터 값을 표시합니다.
- **Local variables** 탭은 프로그램에 선언된 모든 변수의 값을 표시합니다.
- **Messages** 탭은 프로그램이 실행되면서 반환하는 모든 결과를 표시합니다.
- **Results** 탭은 함수의 `RETURN` 문에서 나온 값과 같은 모든 프로그램 결과를 표시합니다.
- **Stack** 탭은 호출 스택(call stack)을 표시합니다.

## Stack 탭 (The Stack tab)

**Stack** 탭은 현재 호출 스택에 있는 프로그램, 즉 호출되었지만 아직 완료되지 않은 프로그램의 목록을 표시합니다. 프로그램이 호출되면 그 프로그램의 이름이 **Stack** 탭에 표시된 목록의 맨 위에 추가됩니다. 프로그램이 종료되면 그 이름이 목록에서 제거됩니다.

**Stack** 탭은 프로그램 호출에 대한 정보도 표시합니다. 이 정보에는 다음이 포함됩니다.

- 프로그램에서 호출이 이루어진 위치
- 호출 인자(call arguments)
- 호출되는 프로그램의 이름

호출 스택을 검토하면 일련의 중첩된 프로그램을 통한 실행 흐름을 추적하는 데 도움이 됩니다.
그림은 `emp_query_caller`가 `emp_query`라는 서브프로그램을 호출하려는 참임을 보여줍니다. `emp_query_caller`는 현재 호출 스택의 맨 위에 있습니다.

![A debugged program calling a subprogram](https://www.enterprisedb.com/docs/static/bcfedd1a80ea230fccc9f4e8af8e6315/302a4/stack_tab.png)

`emp_query` 호출이 실행된 후, `emp_query`가 **Stack** 탭의 맨 위에 표시되고 그 코드가 Program Body 패널에 표시됩니다.

![Debugging the called subprogram](https://www.enterprisedb.com/docs/static/bcfedd1a80ea230fccc9f4e8af8e6315/302a4/stack_tab.png)

서브프로그램의 실행을 완료한 후, 제어는 호출한 프로그램(`emp_query_caller`)으로 돌아가며, 이제 **Stack** 탭의 맨 위에 표시됩니다.
