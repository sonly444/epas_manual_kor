# 디버거 구성 (Configuring the debugger) — EPAS 18 프로그램 디버깅

> 원문: [EPAS v18 — Application programming › Debugging programs › Configuring the debugger](https://www.enterprisedb.com/docs/epas/latest/application_programming/12_debugger/configuring_debugger/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터·경로·명령은 원문 그대로 보존했습니다.

디버거는 pgAdmin 4 및 EDB Postgres Enterprise Manager와 통합됩니다. Windows용 EDB Postgres Advanced Server 설치본에서는 pgAdmin 4가 자동으로 설치되며 Windows 시작 메뉴를 통해 접근할 수 있습니다.

## 두 가지 디버깅 방식

**독립형 디버깅(Standalone debugging)**은 디버거 내에서 프로그램을 직접 시작하여 입력 파라미터를 제공하고, 즉시 코드를 관찰하며 단계별로 실행할 수 있게 합니다. 이 방법은 새 프로그램이나 초기 문제 조사에 일반적으로 사용됩니다.

**인-컨텍스트 디버깅(In-context debugging)**은 복잡한 애플리케이션 상호작용 때문에 문제를 재현하기 어려운 경우에 유용합니다. 전역 중단점(global breakpoint)이 설정된 상태에서 다른 애플리케이션으로부터 프로그램이 시작됩니다. 호출하는 애플리케이션이 이 중단점을 만나면 실행이 일시 중단되고 디버거가 제어권을 가져갑니다. 호출된 프로그램의 코드를 단계별로 실행한 후에는 일시 중단되었던 애플리케이션이 재개됩니다.

디버깅 도구와 작업은 두 방식에서 동일하게 유지되며, 호출 방법만 다릅니다.

## 설치 요구 사항

CentOS 또는 Linux 시스템에서는 다음 명령으로 pgAdmin4를 설치합니다.

```shell
yum install edb-pgadmin4*
```

Linux 설치본은 `edb-as<xx>-server-pldebugger` RPM 패키지도 필요합니다(`<xx>`는 EDB Postgres Advanced Server 버전). 이 RPM을 설치하면 pgAdmin4 아이콘이 애플리케이션 메뉴에 추가됩니다.

## 구성 단계

디버거를 사용하기 전에 EDB Postgres Advanced Server 데이터 하위 디렉터리에 있는 `postgresql.conf` 파일을 수정합니다. `shared_preload_libraries` 구성 파라미터에 `$libdir/plugin_debugger`를 추가합니다.

```ini
shared_preload_libraries = '$libdir/dbms_pipe,$libdir/edb_gen,$libdir/plugin_debugger'
```

파일 위치:
- Linux: `/var/lib/edb/as<xx>/data`
- Windows: `C:\Program Files\edb\as<xx>\data`

이 파라미터를 수정한 후 데이터베이스 서버를 재시작합니다.
