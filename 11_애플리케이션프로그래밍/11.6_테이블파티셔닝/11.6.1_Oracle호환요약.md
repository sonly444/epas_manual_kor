# Oracle 테이블 파티셔닝 호환 요약 (Oracle table partitioning compatibility summary) — EPAS 18 테이블 파티셔닝

> 원문: [EPAS v18 — Table partitioning › Oracle table partitioning compatibility summary](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_table_partitioning/01_oracle_compat_summary/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·키워드는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 Oracle 데이터베이스와 호환되는 테이블 파티셔닝의 여러 측면을 지원합니다.

## 중요 참고 사항

**선언적 파티셔닝(Declarative Partitioning):** "PostgreSQL 버전 10에서 도입된 *선언적 파티셔닝* 기능은 여기서 다루지 않습니다." PostgreSQL 선언적 파티셔닝은 Oracle 호환 테이블 파티셔닝과 함께 EDB Postgres Advanced Server 10에서 사용할 수 있습니다. 선언적 파티셔닝에 대한 세부 사항은 PostgreSQL 코어 문서를 참조하십시오.

**전역 인덱스(Global Indexes):** "EDB Postgres Advanced Server는 전역 인덱스를 지원하지 않으므로, 파티션 키 컬럼을 포함하지 않는 기본 키를 파티션 테이블에 정의할 때 인덱스가 상속되지 않습니다." 다만 `CREATE TABLE`에 정의된 각 파티션은 독립적인 기본 인덱스를 유지합니다. `ALTER TABLE ... ADD CONSTRAINT`를 사용하여 새 파티션에 기본 키를 추가할 수 있습니다. 이러한 인덱스는 개별 파티션 내에서는 고유성을 강제하지만 전체 계층에 걸쳐서는 강제하지 않으므로, 서로 다른 파티션 간에는 기본 키 컬럼에 중복 값이 허용됩니다.
