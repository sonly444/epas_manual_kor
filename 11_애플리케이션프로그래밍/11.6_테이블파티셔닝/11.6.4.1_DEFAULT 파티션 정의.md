# DEFAULT 파티션 정의 (Defining a DEFAULT partition) — EPAS 18 테이블 파티셔닝

> 원문: [EPAS v18 — Application programming › Table partitioning › Handling stray values › Defining a DEFAULT partition](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_table_partitioning/05_handling_stray_values_in_a_list_or_range_partitioned_table/defining_a_default_partition/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`DEFAULT` 파티션은 `LIST` 파티션 또는 서브파티션 테이블에서 다른 어떤 파티션에도 맞지 않는 행을 포착합니다. `DEFAULT` 규칙을 포함하지 않으면 파티셔닝 제약조건의 값 중 어느 것과도 일치하지 않는 행은 오류를 발생시킵니다. 각 `LIST` 파티션 또는 서브파티션은 자체 `DEFAULT` 규칙을 가질 수 있습니다.

`DEFAULT` 규칙의 구문은 다음과 같습니다:

```sql
PARTITION [<partition_name>] VALUES (DEFAULT)
```

여기서 `partition_name`은 다른 파티션에 지정된 규칙과 일치하지 않는 행을 저장하는 파티션 또는 서브파티션의 이름을 지정합니다.

## DEFAULT 파티션 추가 (Adding a DEFAULT partition)

`country` 열의 값을 기준으로 서버가 데이터를 저장할 파티션을 결정하는 리스트 파티션 테이블을 생성할 수 있습니다. 이 경우 `country` 열의 값이 규칙에 나열되지 않은 값을 담고 있는 행을 추가하려고 하면 오류가 보고됩니다:

```sql
edb=# INSERT INTO sales VALUES
edb-#  (40, '3000x', 'IRELAND', '01-Mar-2012', '45000');
ERROR:  no partition of relation "sales_2012" found for row
DETAIL:  Partition key of the failing row contains (country) = (IRELAND).
```

다음 예제는 그러한 테이블을 생성하되 `DEFAULT` 파티션을 추가합니다. 서버는 `europe`, `asia`, `americas` 파티션의 파티셔닝 규칙에 지정된 값과 일치하지 않는 행을 `others` 파티션에 저장합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST(country)
(
  PARTITION europe VALUES('FRANCE', 'ITALY'),
  PARTITION asia VALUES('INDIA', 'PAKISTAN'),
  PARTITION americas VALUES('US', 'CANADA'),
  PARTITION others VALUES (DEFAULT)
);
```

## DEFAULT 파티션 테스트 (Testing the DEFAULT partition)

`DEFAULT` 파티션을 테스트하려면 파티셔닝 제약조건에 지정된 국가 중 어느 것과도 일치하지 않는 값을 `country` 열에 담은 행을 추가합니다:

```text
INSERT INTO sales VALUES
  (40, '3000x', 'IRELAND', '01-Mar-2012', '45000');
```

`sales` 테이블의 내용을 조회하여 이전에 거부되었던 행이 이제 `sales_others` 파티션에 저장되었는지 확인합니다:

```sql
edb=# SELECT tableoid::regclass, * FROM sales;
```

EDB Postgres Advanced Server는 `DEFAULT` 파티션 또는 서브파티션의 내용을 재할당하는 다음과 같은 방법을 제공합니다:

- `ALTER TABLE… ADD PARTITION` 명령을 사용하여 `DEFAULT` 규칙이 있는 테이블에 파티션을 추가할 수 있습니다. 테이블의 기존 행과 추가하려는 파티션의 값 사이에 충돌하는 값이 있어서는 안 됩니다. 또는 `ALTER TABLE… SPLIT PARTITION` 명령을 사용하여 기존 파티션을 분할할 수 있습니다.
- `ALTER TABLE… ADD SUBPARTITION` 명령을 사용하여 `DEFAULT` 규칙이 있는 테이블에 서브파티션을 추가할 수 있습니다. 테이블의 기존 행과 추가하려는 서브파티션의 값 사이에 충돌하는 값이 있어서는 안 됩니다. 또는 `ALTER TABLE… SPLIT SUBPARTITION` 명령을 사용하여 기존 서브파티션을 분할할 수 있습니다.

## 예제: DEFAULT 파티션이 있는 테이블에 파티션 추가 (Example: Adding a partition to a table with a DEFAULT partition)

이 예제는 `ALTER TABLE... ADD PARTITION` 명령을 사용합니다. 테이블의 기존 행과 추가할 파티션의 값 사이에 충돌하는 값이 없다고 가정합니다.

```sql
edb=# ALTER TABLE sales ADD PARTITION africa values ('SOUTH AFRICA', 'KENYA');
ALTER TABLE
```

다음 행들이 테이블에 삽입되면 충돌하는 값이 있음을 나타내는 오류가 발생합니다:

```sql
edb=# INSERT INTO sales (dept_no, country) VALUES
(1,'FRANCE'),(2,'INDIA'),(3,'US'),(4,'SOUTH AFRICA'),(5,'NEPAL');
INSERT 0 5
```

`(4,'SOUTH AFRICA')` 행은 `ALTER TABLE... ADD PARTITION` 문의 `VALUES` 목록과 충돌하므로 오류가 발생합니다:

```sql
edb=# ALTER TABLE sales ADD PARTITION africa values ('SOUTH AFRICA', 'KENYA');
ERROR:  updated partition constraint for default partition "sales_others"
would be violated by some row
```

## 예제: DEFAULT 파티션 분할 (Example: Splitting a DEFAULT partition)

이 예제는 `DEFAULT` 파티션을 분할하여 그 파티션의 내용을 `sales` 테이블의 두 개의 새 파티션 사이에 재분배합니다.

이 명령은 `DEFAULT` 파티션에 들어갈 행을 포함하여 테이블에 행을 삽입합니다:

```sql
INSERT INTO sales VALUES
  (10, '4519b', 'FRANCE', '17-Jan-2012', '45000'),
  (10, '9519b', 'ITALY', '07-Jul-2012', '15000'),
  (20, '3788a', 'INDIA', '01-Mar-2012', '75000'),
  (20, '3788a', 'PAKISTAN', '04-Jun-2012', '37500'),
  (30, '9519b', 'US', '12-Apr-2012', '145000'),
  (30, '7588b', 'CANADA', '14-Dec-2012', '50000'),
  (40, '4519b', 'SOUTH AFRICA', '08-Apr-2012', '120000'),
  (40, '4519b', 'KENYA', '08-Apr-2012', '120000'),
  (50, '3788a', 'CHINA', '12-May-2012', '4950');
```

파티션에는 `DEFAULT others` 파티션이 포함됩니다:

```sql
edb=# SELECT partition_name, high_value FROM ALL_TAB_PARTITIONS;
```

출력(Output)

```text

----------------+---------------------
 EUROPE         | 'FRANCE', 'ITALY'
 ASIA           | 'INDIA', 'PAKISTAN'
 AMERICAS       | 'US', 'CANADA'
 OTHERS         | DEFAULT
(4 rows)
```

