# 인터벌 범위 파티셔닝 (Interval range partitioning) — EPAS 18 테이블 파티셔닝

> 원문: [EPAS v18 — Table partitioning › Selecting a partition type › Interval range partitioning](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_table_partitioning/02_selecting_a_partition_type/01_interval_range_partitioning/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 키워드·값은 원문 그대로 보존했습니다.

## 개요

"인터벌 범위 파티셔닝(Interval range partitioning)은 삽입된 데이터가 기존 파티션의 범위를 초과할 때 데이터베이스가 파티션을 생성하도록 허용하는 범위 파티셔닝의 확장입니다."

이 기능은 새로 생성되는 파티션의 범위 크기를 지정하기 위해 `INTERVAL` 절을 사용하며, 파티셔닝 키 값에 의해 결정되는 전환점(transition point)을 기반으로 파티션이 자동으로 생성됩니다.

## 예제 시나리오

문서는 실제 예제로 이를 설명합니다. 테이블에 2023년 2월 15일을 전환점으로 하는 월별 인터벌이 있고 2023년 5월 10일 데이터를 삽입하면, 필요한 5월 파티션만 생성됩니다. 중간의 3월과 4월 파티션은 자동으로 건너뜁니다.

## 주요 제약

인터벌 범위 파티셔닝에는 몇 가지 중요한 제한이 있습니다.

- 수치형 또는 날짜 기반이어야 하는 단일 파티션 키로 제한됨
- 최소한 하나의 미리 정의된 범위 파티션이 필요함
- `DEFAULT` 또는 `MAXVALUE` 절을 사용할 수 없음
- 인덱스 구성 테이블(index-organized table) 및 도메인 인덱스와 호환되지 않음
- 복합 파티셔닝(composite partitioning)의 서브파티션 수준에서 지원되지 않음
- NULL, NaN, Infinity 값을 제외함
- 파티션은 증가하는 순서로 생성해야 함
- 인터벌 표현식은 상수, 음이 아닌(non-negative) 값을 산출해야 함
