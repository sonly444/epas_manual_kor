# LIST 또는 RANGE 파티션 테이블의 경계 밖 값 처리 (Handling stray values in a LIST or RANGE partitioned table) — EPAS 18 테이블 파티셔닝

> 원문: [EPAS v18 — Table partitioning › Handling stray values in a LIST or RANGE partitioned table](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_table_partitioning/05_handling_stray_values_in_a_list_or_range_partitioned_table/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 키워드는 원문 그대로 보존했습니다.

이 페이지는 EDB Postgres Advanced Server v18에서 정의된 파티셔닝 규칙에 맞지 않는 값을 처리하는 방법을 설명합니다.

문서에 따르면 "`DEFAULT` 또는 `MAXVALUE` 파티션이나 서브파티션은 테이블에 정의된 다른 파티셔닝 규칙을 충족하지 않는 모든 행을 포착합니다."

이러한 이상치(outlier) 데이터를 관리하는 두 가지 접근 방식:

1. **DEFAULT 파티션 정의** — 다른 파티션 기준에 일치하지 않는 행을 포착합니다.
2. **MAXVALUE 파티션 정의** — 범위 파티션 테이블에서 정의된 범위를 초과하는 값을 처리합니다.

이는 LIST 및 RANGE 파티션 유형을 포함한 Oracle 호환 파티셔닝 전략을 다루는, EDB Postgres Advanced Server 애플리케이션 프로그래밍 문서의 더 넓은 테이블 파티셔닝 섹션의 일부입니다.
