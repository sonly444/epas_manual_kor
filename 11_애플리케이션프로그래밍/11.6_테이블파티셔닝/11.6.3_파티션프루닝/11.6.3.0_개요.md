# 파티션 프루닝 사용 (Using partition pruning) — EPAS 18 테이블 파티셔닝

> 원문: [EPAS v18 — Table partitioning › Using partition pruning](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_table_partitioning/03_using_partition_pruning/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터·명령·연산자는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server의 쿼리 플래너(query planner)는 *파티션 프루닝(partition pruning)*을 사용하여 `SELECT` 문의 `WHERE` 절 조건과 일치하는 행을 찾기 위한 효율적인 실행 계획을 만듭니다. 성공적인 파티션 프루닝을 위해서는 `WHERE` 절이 파티셔닝 키 컬럼에 대한 비교를 제약해야 합니다.

### 파티션 프루닝 효과

| 테이블 유형 | 효과적인 경우 |
|------------|---|
| 리스트 파티션 | `WHERE` 절이 `=`나 `AND` 같은 연산자를 사용하여 리터럴 값을 파티셔닝 키와 비교할 때 |
| 범위 파티션 | `WHERE` 절이 `=`, `<`, `>` 같은 연산자를 사용하여 리터럴 값을 파티셔닝 키와 비교할 때 |
| 해시 파티션 | `WHERE` 절이 `=` 같은 연산자를 사용하여 리터럴 값을 파티셔닝 키와 비교할 때 |

## 파티션 프루닝 기법

두 가지 최적화 기법이 파티션 프루닝을 지원합니다.

- **제약 배제(Constraint exclusion)**: 각 파티션에 정의된 제약 조건을 검사하여 충족 가능성을 판단합니다.
- **빠른 프루닝(Fast pruning)**: Oracle 파티션 테이블의 파티션 관계를 이해합니다.

"빠른 프루닝은 플래너가 고려해야 하는 파티션 수를 줄이기 위해 계획 과정 초기에 발생합니다. 제약 배제는 계획 과정 후반에 발생합니다."

## 제약 배제 사용 (Using Constraint Exclusion)

`constraint_exclusion` 파라미터가 이 기능을 제어하며, `on`, `off`, 또는 `partition`(기본값) 값을 받습니다. `partition`이나 `on`으로 설정하여 활성화합니다.

`WHERE` 절과 함께 활성화되면 쿼리 플래너는:
- 행을 저장할 파티션을 결정합니다.
- 쿼리 조각(fragment)을 해당 파티션으로 보냅니다.
- 행을 포함할 수 없는 파티션을 실행 계획에서 제거(prune)합니다.

제약 배제를 비활성화하면 비파티션 테이블의 성능이 향상될 수 있습니다.

## 빠른 프루닝 사용 (Using Fast Pruning)

불리언 파라미터 `enable_partition_pruning`(ON/OFF)으로 제어됩니다.

**제한**: "빠른 프루닝은 서브파티션 테이블에 대한 쿼리를 최적화하거나, 하나의 컬럼으로 파티션된 테이블에 한해 범위 파티션 테이블에 대한 쿼리를 최적화할 수 있습니다."

### 리스트 파티션 테이블

빠른 프루닝은 파티셔닝 컬럼을 리터럴 값으로 제약하는 `WHERE` 절을 처리합니다.
- `WHERE country = 'US'`
- `WHERE country IS NULL`

연산자는 동등(equality) 또는 데이터 타입에 적합한 등가 연산자여야 합니다.

### 범위 파티션 테이블

지원 연산자: `>`, `>=`, `=`, `<=`, `<`

`AND`와 `BETWEEN`을 사용하는 복합 표현식:
- `WHERE size > 100 AND size <= 200`
- `WHERE size BETWEEN 100 AND 200`

`OR`나 `IN`이 있는 표현식은 **프루닝할 수 없습니다**.

프루닝을 지원하는 예제 쿼리:
- `WHERE size > 100` — 'medium'과 'large'를 스캔
- `WHERE size = 100` — 'medium'을 스캔
- `WHERE size > 100 AND size < 199` — 'medium'을 스캔
- `WHERE color = 'red' AND size = 100` — 'medium'을 스캔

**참고**: "빠른 프루닝은 이러한 `WHERE` 절을 포함하는 `DELETE` 및 `UPDATE` 문도 최적화할 수 있습니다."
