# 예제: 파티션 프루닝 (Example: Partition pruning) — EPAS 18 테이블 파티셔닝

> 원문: [EPAS v18 — Table partitioning › Using partition pruning › Example: Partition pruning](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_table_partitioning/03_using_partition_pruning/01_example_partition_pruning/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·출력은 원문 그대로 보존했습니다.

`EXPLAIN` 문은 문(statement)의 실행 계획을 표시합니다. `EXPLAIN` 문을 사용하여 EDB Postgres Advanced Server가 쿼리의 실행 계획에서 파티션을 프루닝하고 있는지 확인할 수 있습니다.

이 예제는 파티션 프루닝의 효율성을 보여 줍니다. 간단한 테이블을 만듭니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST(country)
(
  PARTITION europe VALUES('FRANCE', 'ITALY'),
  PARTITION asia VALUES('INDIA', 'PAKISTAN'),
  PARTITION americas VALUES('US', 'CANADA')
);
```

`EXPLAIN` 문을 포함하는 제약된 쿼리를 수행합니다.

```sql
EXPLAIN (COSTS OFF) SELECT * FROM sales WHERE country = 'INDIA';
```

결과 쿼리 계획은 서버가 `sales_asia` 테이블만 스캔함을 보여 줍니다. 이는 `country` 값이 `INDIA`인 행이 저장되는 테이블입니다.

```sql
edb=# EXPLAIN (COSTS OFF) SELECT * FROM sales WHERE country = 'INDIA';
```

출력

```text
                    QUERY PLAN
---------------------------------------------------
 Append
   ->  Seq Scan on sales_asia
         Filter: ((country)::text = 'INDIA'::text)
(3 rows)
```

파티셔닝 키에 포함되지 않은 값과 일치하는 행을 검색하는 쿼리를 수행한다고 가정합니다.

```sql
EXPLAIN (COSTS OFF) SELECT * FROM sales WHERE dept_no = '30';
```

결과 쿼리 계획은 서버가 쿼리를 만족하는 행을 찾기 위해 모든 파티션을 살펴봐야 함을 보여 줍니다.

```sql
edb=# EXPLAIN (COSTS OFF) SELECT * FROM sales WHERE dept_no = '30';
```

출력

```text
                QUERY PLAN
-------------------------------------------
 Append
   ->  Seq Scan on sales_americas
         Filter: (dept_no = '30'::numeric)
   ->  Seq Scan on sales_europe
         Filter: (dept_no = '30'::numeric)
   ->  Seq Scan on sales_asia
         Filter: (dept_no = '30'::numeric)
(7 rows)
```

제약 배제는 서브파티션 테이블을 질의할 때도 적용됩니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY RANGE(date) SUBPARTITION BY LIST (country)
(
  PARTITION "2011" VALUES LESS THAN('01-JAN-2012')
  (
    SUBPARTITION europe_2011 VALUES ('ITALY', 'FRANCE'),
    SUBPARTITION asia_2011 VALUES ('PAKISTAN', 'INDIA'),
    SUBPARTITION americas_2011 VALUES ('US', 'CANADA')
  ),
  PARTITION "2012" VALUES LESS THAN('01-JAN-2013')
  (
    SUBPARTITION europe_2012 VALUES ('ITALY', 'FRANCE'),
    SUBPARTITION asia_2012 VALUES ('PAKISTAN', 'INDIA'),
    SUBPARTITION americas_2012 VALUES ('US', 'CANADA')
  ),
  PARTITION "2013" VALUES LESS THAN('01-JAN-2015')
  (
    SUBPARTITION europe_2013 VALUES ('ITALY', 'FRANCE'),
    SUBPARTITION asia_2013 VALUES ('PAKISTAN', 'INDIA'),
    SUBPARTITION americas_2013 VALUES ('US', 'CANADA')
  )
);
```

테이블을 질의하면 쿼리 플래너는 원하는 결과 집합을 포함할 수 없는 파티션이나 서브파티션을 검색 경로에서 제거합니다.

```sql
edb=# EXPLAIN (COSTS OFF) SELECT * FROM sales WHERE country = 'US' AND date = 'Dec 12, 2012';
```

출력

```text
                                                   QUERY PLAN
-----------------------------------------------------------------------------
------------------------------------
 Append
   ->  Seq Scan on sales_americas_2012
         Filter: (((country)::text = 'US'::text) AND (date = '12-DEC-12
         00:00:00'::timestamp without time zone))
(3 rows)
```
