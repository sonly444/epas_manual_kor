# EDB Postgres Advanced Server 18.3.0 릴리스 노트 — EPAS 18

> 원문: [EPAS v18 — Release notes › EPAS 18.3.0](https://www.enterprisedb.com/docs/epas/latest/epas_rel_notes/epas18_3_rel_notes/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 제품·컴포넌트·CVE·이슈 번호는 원문 그대로 보존했습니다.

**릴리스일:** 2026년 2월 26일

## 소개

EDB Postgres Advanced Server 18.3.0은 보안 업데이트와 버그 수정을 포함합니다. RHEL 9.6 호환성에 관한 참고: RHEL 9.7에 도입된 OpenSSL 및 LLVM 변경으로 인해 버전 17 이하 백브랜치의 현재 마이너 릴리스는 기존 사용자 안정성을 위해 RHEL 9.6에서 빌드되었습니다. EPAS 18은 RHEL 9.7 이상 버전을 요구합니다.

## 변경 사항

| 유형 | 설명 | 관련 이슈 |
|------|------|-----------|
| Security fix | CVE-2026-2003, CVE-2026-2004, CVE-2026-2005, CVE-2026-2006, CVE-2026-2007 해결. | — |
