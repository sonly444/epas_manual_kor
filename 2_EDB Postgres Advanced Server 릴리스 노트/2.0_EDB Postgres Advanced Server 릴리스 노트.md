# 릴리스 노트 (Release notes) — EPAS 18

> 원문: [EPAS v18 — Release notes](https://www.enterprisedb.com/docs/epas/latest/epas_rel_notes/)
> EPAS v18 공식 문서의 한글 **전문 번역** 인덱스입니다. 버전별 릴리스 노트를 개별 리프로 전문 번역했습니다.

EDB Postgres Advanced Server 릴리스 노트는 각 릴리스에 포함된 향상 기능, 새 기능, 버그 수정, 보안 수정을 설명합니다.

## 버전별 목록

- **02_릴리스노트_1** — EPAS 18.4.0 (2026-05-14)
- **02_릴리스노트_2** — EPAS 18.3.0 (2026-02-26)
- **02_릴리스노트_3** — EPAS 18.2.0 (2026-02-12)
- **02_릴리스노트_4** — EPAS 18.1.0 (2025-11-25)

> 참고: EPAS 18은 RHEL 9.7 이상을 요구합니다. RHEL 9.7에 도입된 OpenSSL 및 LLVM 변경으로 인해 버전 17 이하의 마이너 릴리스는 기존 사용자 안정성을 위해 RHEL 9.6에서 빌드되었으나, EPAS 18은 RHEL 9.7 이상의 새 툴셋에 의존하므로 RHEL 9.6 환경과 호환되지 않습니다.
