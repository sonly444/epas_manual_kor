# EDB Postgres Advanced Server 18.4.0 릴리스 노트 — EPAS 18

> 원문: [EPAS v18 — Release notes › EPAS 18.4.0](https://www.enterprisedb.com/docs/epas/latest/epas_rel_notes/epas18_4_rel_notes/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 제품·컴포넌트·CVE·이슈 번호는 원문 그대로 보존했습니다.

**릴리스일:** 2026년 5월 14일

## 플랫폼 지원 참고

### EPAS 18에서 RHEL 9.6이 지원되지 않는 이유는?

- **버전 전환:** RHEL 9.7에 도입된 OpenSSL 및 LLVM 변경으로 인해, 버전 17 이하 백브랜치(back-branch)의 현재 마이너 릴리스는 기존 사용자의 안정성을 유지하기 위해 RHEL 9.6에서 빌드되었습니다.

- **EPAS 18 요구 사항:** 앞으로 EPAS 18은 RHEL 9.7 이상 버전을 위해 특별히 설계되었습니다. EPAS 18은 9.7에서 사용 가능한 새로운 툴셋에 의존하며, 이는 9.6 환경과 호환되지 않습니다.
