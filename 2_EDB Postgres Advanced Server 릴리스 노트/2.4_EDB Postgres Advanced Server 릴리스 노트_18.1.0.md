# EDB Postgres Advanced Server 18.1.0 릴리스 노트 — EPAS 18

> 원문: [EPAS v18 — Release notes › EPAS 18.1.0](https://www.enterprisedb.com/docs/epas/latest/epas_rel_notes/epas18_1_rel_notes/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 제품·기능·함수·파라미터 이름은 원문 그대로 보존했습니다.

**릴리스일:** 2025년 11월 25일

## 개요

EDB Postgres Advanced Server 18.1.0은 보안, Oracle 호환성, 데이터베이스 관리 기능 전반에 걸친 향상 기능, 새 기능, 버그 수정을 포함합니다.

## 변경 사항 및 향상 기능

| 유형 | 설명 |
|------|------|
| Upstream merge | 커뮤니티 PostgreSQL 18.1과 병합. 자세한 내용은 PostgreSQL 18.1 릴리스 노트 참조. |
| Feature | 자동 비활성 계정 잠금(Automated Inactive Account Locking)을 위해 비밀번호 프로파일에 `INACTIVE_ACCOUNT_TIME` 옵션 추가. 구성 가능한 일수 후 휴면 계정을 자동으로 잠금. |
| Feature | 파싱 후 명령 트리 분석(post-parsing command tree analysis)을 통해 `edb_log_redact_password_statements` GUC를 사용하여 서버 로그에서 비밀번호를 포함하는 문을 마스킹하는 기능 추가. |
| Feature | `postgres_fdw` 사용자 매핑에서 비밀번호를 난독화하여 `PG_USER_MAPPING` 카탈로그에 평문 저장을 방지하는 기능 추가. |
| Feature | 로케일 규칙 기반의 콜레이션 인식 정렬을 위한 Oracle 등가 `NLSSORT()` 함수 변환 지원 추가. |
| Enhancement | 보안 이메일 통신을 위해 `UTL_SMTP`에 Secure(TLS) 및 Authenticated(AUTH) 이메일 지원 추가. |
| Enhancement | `edb_audit_nested_statements` 구성 파라미터를 통해 중첩 문(nested statements) 감사 지원 추가. |
| Enhancement | 민감한 객체 접근을 추적하기 위해 시스템 카탈로그 테이블에 대한 `edb_audit_group` 옵션 활성화. |
| Enhancement | `edb_audit_statement`에서 `COPY` 명령 감사 지원 추가. |
| Enhancement | `DBMS_SCHEDULER`의 캘린더 기반 스케줄링을 `FREQ=SECONDLY`, `INTERVAL` 키워드, 음수 `BYMONTHDAY` 지원으로 개선. |
| Enhancement | ECPGPlus에서 Oracle 및 ANSI Dynamic SQL Method 4에 대한 Indicator Array 지원 추가. |
| Enhancement | ECPGPlus에서 `INSERT` 문의 `sqlcode`를 개선하여 성공 실행 시 `sqlcode = 0` 반환. |
| Enhancement | ECPGPlus에서 `FETCH` 문의 `sqlcode`를 개선하여 커서가 끝에 도달하면 `sqlcode = 100` 반환. |
| Enhancement | 기존 데이터베이스 링크를 수정하기 위한 `ALTER [PUBLIC] DATABASE LINK` 구문 지원 추가. |
| Enhancement | `SYS` 스키마 객체에 대한 ACL 변경을 캡처하도록 pg_dump 개선. |
| Change | `pg_authid`의 EDB 전용 boolean 권한 컬럼들을 단일 integer 비트마스크 컬럼(`rolredwoodprivs`)으로 통합. |
| Change | DRITA 수집을 위한 서버 변수 `timed_statistics` 제거. |
| Bug fix | 원격 서버에서 결과 집합을 올바르게 페치하도록 `edb_dblink_oci`의 컬럼 이름 대소문자 수정. |
