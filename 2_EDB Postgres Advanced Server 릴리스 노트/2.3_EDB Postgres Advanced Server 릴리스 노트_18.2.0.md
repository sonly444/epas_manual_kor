# EDB Postgres Advanced Server 18.2.0 릴리스 노트 — EPAS 18

> 원문: [EPAS v18 — Release notes › EPAS 18.2.0](https://www.enterprisedb.com/docs/epas/latest/epas_rel_notes/epas18_2_rel_notes/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 제품·컴포넌트·이슈 번호는 원문 그대로 보존했습니다.

**릴리스일:** 2026년 2월 12일

## 개요

EDB Postgres Advanced Server 18.2.0은 커뮤니티 PostgreSQL 18.2와의 병합 및 주요 안정성 문제 해결을 포함한 향상 기능과 버그 수정을 통합합니다.

## 플랫폼 지원 참고

EPAS 18에서는 RHEL 9.6이 지원되지 않습니다. 이 버전은 초기 RHEL 버전과의 OpenSSL 및 LLVM 툴셋 비호환성으로 인해 RHEL 9.7 이상을 요구합니다.

## 변경 사항

| 유형 | 설명 |
|------|------|
| Upstream merge | 커뮤니티 PostgreSQL 18.2와 병합. 자세한 내용은 PostgreSQL 18.2 릴리스 노트 참조. |
| Bug fix | 워커가 해제된 데이터에 접근할 때 드문 크래시를 유발하던 병렬 실행 중 메모리 할당을 수정. 이제 메모리가 장기 컨텍스트로 올바르게 범위 지정됨. (이슈 #52519) |
| Bug fix | 파티션 생성 중 순환 참조로 인한 `edb_partition`의 스택 오버플로 해결. |
