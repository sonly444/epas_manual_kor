# 지원 플랫폼 (Supported Platforms) — EDB Postgres Advanced Server 18

> 원문: [EPAS v18 Documentation — Supported platforms](https://www.enterprisedb.com/docs/epas/latest/epas_platform_support/) · [EDB Platform Compatibility](https://www.enterprisedb.com/platform-compatibility#epas)
> EPAS v18 공식 문서의 한글 번역입니다. OS·아키텍처 이름과 버전은 원문 그대로 보존했습니다.

## 개요

EDB Postgres Advanced Server는 Linux 및 Windows 플랫폼에 설치할 수 있습니다. 지원 플랫폼의 전체 최신 목록은 EDB 웹사이트의 Platform Compatibility 페이지와 설치(Installing) 문서를 참조하십시오.

## 지원 운영체제 및 아키텍처 (EPAS 18.x)

### Linux x86-64 (amd64)
- Red Hat Enterprise Linux 9 / 8
- Oracle Linux 9 / 8
- Rocky Linux / AlmaLinux 9 / 8
- SUSE Linux Enterprise Server 15 SP7
- Ubuntu 24.04 / 22.04
- Debian 12

### Linux ARM64
- Red Hat Enterprise Linux 9
- Debian 12

### Linux on IBM Power (ppc64le)
- Red Hat Enterprise Linux 9 / 8
- SUSE Linux Enterprise Server 15 SP7

### IBM LinuxONE (s390x)
- Red Hat Enterprise Linux 9 / 8
- SUSE Linux Enterprise Server 15 SP7

### Windows x86-64
- Windows Server 2022 / 2025
- Windows 11

## 지원 수명 주기 (Lifecycle)

- **정식 출시(General availability)**: 2025년 11월 25일
- **표준 지원 종료(Standard support end date)**: 2030년 11월 25일

> 참고: 플랫폼별 정확한 지원 여부·마이너 버전은 시점에 따라 갱신되므로, 실제 심사·도입 시에는 EDB Platform Compatibility 페이지에서 최종 확인이 필요합니다.
