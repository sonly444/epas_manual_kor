# Enterprise Postgres (Oracle Compatible) — EPAS 18

> 원문: [EPAS v18 — Enterprise Postgres (Oracle Compatible)](https://www.enterprisedb.com/docs/epas/latest/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB는 혁신적이고 저비용의 오픈소스 기반 데이터베이스 솔루션을 제공하는 전 세계 유일의 기업입니다. 이러한 솔루션은 소규모 또는 대규모 기업을 위한 상용 품질, 사용 편의성, 호환성, 확장성, 성능을 제공합니다. Enterprise Postgres (Oracle Compatible)은 EDB Postgres Advanced Server(EPAS)라고도 하며, 오픈소스 PostgreSQL에 다음을 포함한 확장 기능을 추가합니다:

- [데이터베이스 관리 (Database administration)](https://www.enterprisedb.com/docs/epas/latest/database_administration/)
- [향상된 SQL 기능 (Enhanced SQL capabilities)](https://www.enterprisedb.com/docs/epas/latest/application_programming/15_enhanced_sql_and_other_misc_features/)
- [데이터베이스 및 애플리케이션 보안 (Database and application security)](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/)
- [성능 모니터링 및 분석 (Performance monitoring and analysis)](https://www.enterprisedb.com/docs/epas/latest/managing_performance/)
- [애플리케이션 개발 유틸리티 (Application development utilities)](https://www.enterprisedb.com/docs/epas/latest/application_programming/)
- [고급 복제(버전 14 이상) (Advanced replication (version 14 and higher))](https://www.enterprisedb.com/docs/pgd/latest/).

이러한 모든 기능은 Postgres 모드와 [Oracle 호환 모드(Oracle compatibility mode)](https://www.enterprisedb.com/docs/epas/latest/working_with_oracle_data/)에서 사용할 수 있습니다. EDB Postgres Advanced Server를 Oracle 호환 모드로 시작하면 Oracle에서 Postgres로의 마이그레이션에 도움이 되는 추가 기능을 얻을 수 있습니다.

- [Oracle 호환 사용자 정의 데이터 타입 (Oracle-compatible custom data types)](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/02_data_types/)
- [Oracle 키워드 (Oracle keywords)](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/01_sql_syntax/)
- [Oracle 함수 (Oracle functions)](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/)
- [Oracle 스타일 카탈로그 뷰 (Oracle-style catalog views)](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/)
- [Oracle MERGE와의 추가 호환성 (Additional compatibility with Oracle MERGE)](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/65a_merge/).

EDB는 또한 EDB Postgres Advanced Server 배포를 모니터링하고 관리하는 데 도움이 되는 [전체 도구 및 유틸리티 모음(full suite of tools and utilities)](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/)을 제공합니다.

EDB Postgres Advanced Server가 다른 데이터베이스와 어떻게 비교되는지 확인하려면 [Postgres 배포판 선택(Choosing your Postgres distribution)](https://www.enterprisedb.com/docs/edb-postgres-ai/databases/postgres_distributions/)을 참고하십시오.
