# 연결 도구 (Connectivity Tools) — EPAS 18 Tools

> 원문: [EPAS v18 — Tools › Connectivity tools](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/connectivity_tools/)
> EPAS v18 공식 문서의 한글 번역입니다. 도구 이름은 원문 그대로 보존했습니다.

EDB가 패키징·지원하는 오픈소스 구성 요소로 Postgres 데이터베이스에 연결·관리합니다. 세 범주로 구성됩니다.

- **데이터베이스 연결(Connecting to your database)**: EPAS에 연결하는 구성 요소(예: JDBC·ODBC·.NET 드라이버, libpq, EDB OCL Connector 등 — 각 커넥터 문서 참조).
- **외부 데이터 소스 연결(Connecting to external data sources)**: 외부 시스템 연동 구성 요소(포리언 데이터 래퍼 등).
- **연결 관리(Managing your database connections)**: 연결 관리를 위한 오픈소스 구성 요소(연결 풀러 등).
