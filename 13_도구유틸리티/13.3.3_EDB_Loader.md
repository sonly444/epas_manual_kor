# EDB*Loader — EPAS 18 Tools (DBA tools)

> 원문: [EPAS v18 — Tools › Database administrator tools › EDB*Loader](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/database_administration_tools/edb_loader_overview/)

EDB * Loader는 Oracle EDB Postgres Advanced Server용 데이터베이스와 호환되는 인터페이스를 제공하는 고성능 대용량 데이터 로더입니다. EDB * Loader 명령줄 유틸리티는 일반적으로 파일과 같은 입력 소스에서 Oracle SQL * Loader 에서 제공하는 매개변수의 하위 집합을 사용하여 하나 이상의 테이블로 데이터를 로드합니다 .

전체 전문 번역(핵심 개념·로딩 방식·오류 처리·컨트롤 파일 구문·예제·호출)은 "데이터베이스 관리" 섹션의 EDB\*Loader를 참조하십시오 → 본 번역의 `8_데이터베이스관리/8_3_EDB_Loader/`.
