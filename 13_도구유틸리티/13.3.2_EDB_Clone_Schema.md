# EDB Clone Schema — EPAS 18 Tools (DBA tools)

> 원문: [EPAS v18 — Tools › Database administrator tools › EDB clone schema](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/database_administration_tools/edb_clone_schema_overview/)

EDB Clone Schema는 EDB Postgres Advanced Server용 확장 모듈로, 로컬 또는 원격 데이터베이스(원본 데이터베이스)에서 스키마와 해당 데이터베이스 객체를 수신 데이터베이스(대상 데이터베이스)로 복사할 수 있도록 해줍니다.

원본 및 대상 데이터베이스는 다음 중 하나일 수 있습니다.

- 동일한 물리적 데이터베이스
- 동일한 데이터베이스 클러스터 내의 서로 다른 데이터베이스
- 서로 다른 데이터베이스 클러스터에서 실행되는 별도의 데이터베이스, 서로 다른 데이터베이스 서버 호스트.

전체 전문 번역(함수·설정·복사 절차)은 "데이터베이스 관리" 섹션의 EDB Clone Schema를 참조하십시오 → 본 번역의 `08_데이터베이스관리/08_4_EDB_Clone_Schema/`.
