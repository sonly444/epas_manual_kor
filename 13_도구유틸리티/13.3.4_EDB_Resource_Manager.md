# EDB Resource Manager — EPAS 18 Tools (DBA tools)

> 원문: [EPAS v18 — Tools › Database administrator tools › EDB Resource Manager](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/database_administration_tools/edb_resource_manager_overview/)

EDB 리소스 관리자는 EDB Postgres Advanced Server 프로세스에서 사용하는 운영 체제 리소스 사용을 제어할 수 있도록 해주는 EDB Postgres Advanced Server 기능입니다.

이 기능을 사용하면 특정 시스템 리소스를 제어할 수 없이 과도하게 사용하거나 독점할 수 있는 프로세스로부터 시스템을 보호할 수 있습니다.

전체 전문 번역(핵심 개념·리소스 그룹 CRUD·CPU 조절·더티 버퍼 조절·예제)은 "데이터베이스 관리" 섹션의 EDB Resource Manager를 참조하십시오 → 본 번역의 `8_데이터베이스관리/8_2_EDB_Resource_Manager/`.
