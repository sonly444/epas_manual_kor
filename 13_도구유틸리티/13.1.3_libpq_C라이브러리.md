# libpq C 라이브러리 (libpq C Library) — EPAS 18 Tools

> 원문: [EPAS v18 — Tools › Application programmer tools › libpq C library](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/application_developer_tools/11_libpq_c_library/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·헤더·코드·식별자 이름은 원문 그대로 보존했습니다.

libpq는 EDB Postgres Advanced Server를 위한 C 애플리케이션 프로그래머 인터페이스입니다. libpq는 클라이언트 프로그램이 EDB Postgres Advanced Server에 쿼리를 전달하고 그 쿼리의 결과를 받을 수 있게 해 주는 라이브러리 함수의 집합입니다.

libpq는 또한 C++, Perl, Python, Tcl, ECPG 등 여러 다른 EDB 애플리케이션 인터페이스의 기반이 되는 엔진이기도 합니다. 이러한 패키지 중 하나를 사용하는 경우, libpq의 동작 방식 중 일부는 중요하게 작용합니다.

## 사전 요건 (Prerequisites)

libpq를 사용하는 클라이언트 프로그램은 헤더 파일 `libpq-fe.h`를 포함(include)해야 하며 `libpq` 라이브러리와 링크(link)해야 합니다.

## EDB SPL과 함께 libpq 사용 (Using libpq with EDB SPL)

libpq 인터페이스 라이브러리와 함께 EDB SPL 언어를 사용할 수 있으며, 다음을 지원합니다:

- 프로시저, 함수, 패키지 (Procedures, functions, packages)
- 준비된 구문 (Prepared statements)
- `REFCURSORs`
- 정적 커서 (Static cursors)
- `structs` 및 `typedefs`
- 배열 (Arrays)
- DML 및 DDL 연산
- `IN`/`OUT`/`IN OUT` 파라미터

## REFCURSOR 지원 (REFCURSOR support)

이전 릴리스에서 EDB Postgres Advanced Server는 다음 libpq 함수들을 통해 REFCURSOR를 지원했습니다. 이 함수들은 이제 폐기(deprecated)되었습니다:

- `PQCursorResult()`
- `PQgetCursorResult()`
- `PQnCursor()`

이제는 `PQexec()`와 `PQgetvalue()`를 사용하여 SPL(또는 PL/pgSQL) 함수가 반환한 `REFCURSOR`를 조회할 수 있습니다. `REFCURSOR`는 커서의 이름을 나타내는 null로 끝나는(null-terminated) 문자열 형태로 반환됩니다. 커서의 이름을 얻고 나면, 하나 이상의 `FETCH` 문을 실행하여 그 커서를 통해 노출되는 값들을 조회할 수 있습니다.

##### 참고 (Note)

이어지는 예제들에는 실제 클라이언트 애플리케이션에서 필요한 오류 처리 코드가 포함되어 있지 않습니다.

### 단일 REFCURSOR 반환하기 (Returning a single REFCURSOR)

다음 예제는 `REFCURSOR` 타입의 값을 반환하는 SPL 함수를 보여 줍니다:

```sql
CREATE OR REPLACE FUNCTION getEmployees(p_deptno NUMERIC)
RETURN REFCURSOR AS
  result REFCURSOR;
BEGIN
  OPEN result FOR SELECT * FROM emp WHERE deptno = p_deptno;

  RETURN result;
END;
```

이 함수는 단일 파라미터 `p_deptno`를 받아, `OPEN` 문에 표시된 `SELECT` 쿼리의 결과 집합을 담는 `REFCURSOR`를 반환합니다. `OPEN` 문은 쿼리를 실행하고 그 결과 집합을 커서에 저장합니다. 서버는 해당 커서의 이름을 구성하여 `result`라는 변수에 저장합니다. 그런 다음 함수는 커서의 이름을 호출자에게 반환합니다.

libpq를 사용하는 C 클라이언트에서 이 함수를 호출하려면 `PQexec()`와 `PQgetvalue()`를 사용할 수 있습니다:

```c
#include <stdio.h>
#include <stdlib.h>
#include "libpq-fe.h"

static void fetchAllRows(PGconn *conn,
                         const char *cursorName,
                         const char *description);
static void fail(PGconn *conn, const char *msg);

int
main(int argc, char *argv[])
{
  PGconn    *conn = PQconnectdb(argv[1]);
  PGresult  *result;

  if (PQstatus(conn) != CONNECTION_OK)
    fail(conn, PQerrorMessage(conn));

  result = PQexec(conn, "BEGIN TRANSACTION");

  if (PQresultStatus(result) != PGRES_COMMAND_OK)
    fail(conn, PQerrorMessage(conn));

  PQclear(result);

  result = PQexec(conn, "SELECT * FROM getEmployees(10)");

  if (PQresultStatus(result) != PGRES_TUPLES_OK)
    fail(conn, PQerrorMessage(conn));

  fetchAllRows(conn, PQgetvalue(result, 0, 0), "employees");

  PQclear(result);

  PQexec(conn, "COMMIT");

  PQfinish(conn);

  exit(0);
}

static void
fetchAllRows(PGconn *conn,
             const char *cursorName,
             const char *description)
{
  size_t  commandLength = strlen("FETCH ALL FROM ") +
                          strlen(cursorName) + 3;

  char   *commandText = malloc(commandLength);
  PGresult *result;
  int       row;

  sprintf(commandText, "FETCH ALL FROM \"%s\"", cursorName);

  result = PQexec(conn, commandText);

  if (PQresultStatus(result) != PGRES_TUPLES_OK)
    fail(conn, PQerrorMessage(conn));

  printf("-- %s --\n", description);

  for (row = 0; row < PQntuples(result); row++)
  {
    const char *delimiter = "\t";
    int         col;

    for (col = 0; col < PQnfields(result); col++)
    {
      printf("%s%s", delimiter, PQgetvalue(result, row, col));
      delimiter = ",";
    }

    printf("\n");
  }

  PQclear(result);
  free(commandText);
}

static void
fail(PGconn *conn, const char *msg)
{
  fprintf(stderr, "%s\n", msg);

  if (conn != NULL)
    PQfinish(conn);

  exit(-1);
}
```

이 코드 예제에는 `getEmployees()` 함수를 호출하여 부서 `10`에 속한 모든 사원을 담은 결과 집합을 반환하는 코드 한 줄이 들어 있습니다:

```sql
result = PQexec(conn, "SELECT * FROM getEmployees(10)");
```

`PQexec()` 함수는 결과 집합 핸들을 C 프로그램에 반환합니다. 이 결과 집합에는 하나의 값, 즉 `getEmployees()`가 반환한 커서의 이름이 담겨 있습니다.

커서의 이름을 얻고 나면, SQL `FETCH` 문을 사용하여 해당 커서의 행들을 조회할 수 있습니다. `fetchAllRows()` 함수는 `FETCH ALL` 문을 만들고, 그 문을 실행한 뒤, `FETCH ALL` 문의 결과 집합을 출력합니다.

이 프로그램의 출력은 다음과 같습니다:

```sql
-- employees --
    7782,CLARK,MANAGER,7839,09-JUN-81 00:00:00,2450.00,,10
    7839,KING,PRESIDENT,,17-NOV-81 00:00:00,5000.00,,10
    7934,MILLER,CLERK,7782,23-JAN-82 00:00:00,1300.00,,10
```

### 여러 REFCURSOR 반환하기 (Returning multiple REFCURSORs)

다음 예제는 두 개의 `REFCURSOR`를 반환합니다:

- 첫 번째 `REFCURSOR`에는 호출자가 지정한 범위 내의 부서에서 근무하는 모든 사원을 담은 커서(`employees`)의 이름이 들어 있습니다.
- 두 번째 `REFCURSOR`에는 호출자가 지정한 범위 내의 모든 부서를 담은 커서(`departments`)의 이름이 들어 있습니다.

이 예제에서는 단일 `REFCURSOR`를 반환하는 대신, 함수가 `SETOF REFCURSOR`를 반환합니다. 즉 0개 이상의 `REFCURSORS`를 의미합니다. 또 다른 중요한 차이점은, libpq 프로그램이 결과 집합에서 단일 `REFCURSOR`를 기대해서는 안 된다는 것입니다. 각각 하나의 값을 담은 두 개의 행을 기대해야 합니다. 첫 번째 행에는 `employees` 커서의 이름이, 두 번째 행에는 `departments` 커서의 이름이 담깁니다.

```sql
CREATE OR REPLACE FUNCTION getEmpsAndDepts(p_min NUMERIC,
                                           p_max NUMERIC)
RETURN SETOF REFCURSOR AS
  employees   REFCURSOR;
  departments REFCURSOR;
BEGIN
  OPEN employees FOR
    SELECT * FROM emp WHERE deptno BETWEEN p_min AND p_max;
  RETURN NEXT employees;

  OPEN departments FOR
    SELECT * FROM dept WHERE deptno BETWEEN p_min AND p_max;
  RETURN NEXT departments;
END;
```

앞의 예제와 마찬가지로, `PQexec()`와 `PQgetvalue()`를 사용하여 SPL 함수를 호출할 수 있습니다:

```c
#include <stdio.h>
#include <stdlib.h>
#include "libpq-fe.h"

static void fetchAllRows(PGconn *conn,
                         const char *cursorName,
                         const char *description);
static void fail(PGconn *conn, const char *msg);

int
main(int argc, char *argv[])
{
  PGconn *conn = PQconnectdb(argv[1]);
  PGresult *result;

  if (PQstatus(conn) != CONNECTION_OK)
    fail(conn, PQerrorMessage(conn));

  result = PQexec(conn, "BEGIN TRANSACTION");

  if (PQresultStatus(result) != PGRES_COMMAND_OK)
    fail(conn, PQerrorMessage(conn));

  PQclear(result);

  result = PQexec(conn, "SELECT * FROM getEmpsAndDepts(20, 30)");

  if (PQresultStatus(result) != PGRES_TUPLES_OK)
    fail(conn, PQerrorMessage(conn));

  fetchAllRows(conn, PQgetvalue(result, 0, 0), "employees");
  fetchAllRows(conn, PQgetvalue(result, 1, 0), "departments");

  PQclear(result);

  PQexec(conn, "COMMIT");

  PQfinish(conn);

  exit(0);
}

static void

             const char *description)

                             strlen(cursorName) + 3;

  PGresult  *result;

  sprintf(commandText, "FETCH ALL FROM \"%s\"", cursorName);

  result = PQexec(conn, commandText);

  if (PQresultStatus(result) != PGRES_TUPLES_OK)
  fail(conn, PQerrorMessage(conn));

  printf("-- %s --\n", description);

  for (row = 0; row < PQntuples(result); row++)
  {

    for (col = 0; col < PQnfields(result); col++)
    {
      printf("%s%s", delimiter, PQgetvalue(result, row, col));
      delimiter = ",";
    }

    printf("\n");
  }

  PQclear(result);
  free(commandText);
}

static void
fail(PGconn *conn, const char *msg)
{
  fprintf(stderr, "%s\n", msg);

  if (conn != NULL)
    PQfinish(conn);

  exit(-1);
}
```

## 파라미터 배열 바인딩 (Binding arrays of parameters)

EDB Postgres Advanced Server의 배열 바인딩 기능을 사용하면 한 번의 왕복(round trip)으로 데이터 배열을 네트워크를 통해 전송할 수 있습니다. 백엔드가 대량(bulk) 데이터를 수신하면, 그 데이터를 사용하여 insert 또는 update 연산을 수행할 수 있습니다.

대량 연산은 준비된 구문(prepared statement)으로 수행합니다. 구문을 준비하려면 다음 함수를 사용합니다:

```c
PGresult *PQprepare(PGconn *conn,
                    const char *stmtName,
                    const char *query,
                    int nParams,
                    const Oid *paramTypes);
```

`PQprepare()`에 대한 자세한 내용은 준비된 구문(prepared statement) 절에서 확인할 수 있습니다.

대량 연산을 수행하려면 다음 함수들을 사용할 수 있습니다:

- `PQBulkStart`
- `PQexecBulk`
- `PQBulkFinish`
- `PQexecBulkPrepared`

### PQBulkStart

`PQBulkStart()`는 서버에서 대량 연산을 초기화합니다. 서버로 대량 데이터를 보내기 전에 반드시 이 함수를 호출해야 합니다. `PQBulkStart()`는 `stmtName`에 지정된 준비된 구문을 `paramFmts`로 지정된 형식의 데이터를 받도록 초기화합니다.

#### API 정의 (API definition)

```c
PGresult *PQBulkStart(PGconn *conn,
                      const char *Stmt_Name,
                      unsigned int nCol,
                      const int *paramFmts);
```

### PQexecBulk

`PQexecBulk()`를 사용하여, `PQBulkStart()`로 대량 연산을 위해 미리 초기화된 구문에 데이터`(paramValues)`를 공급합니다.

이 함수는 `PQBulkStart()` 이후에 여러 번 사용하여 여러 블록의 데이터를 보낼 수 있습니다.

#### API 정의 (API definition)

```c
PGresult *PQexecBulk(PGconn *conn,
                     unsigned int nRows,
                     const char *const * paramValues,
                     const int *paramLengths);
```

### PQBulkFinish

이 함수는 현재의 대량 연산을 완료합니다. 준비된 구문을 다시 준비하지 않고도 재사용할 수 있습니다.

#### API 정의 (API definition)

```c
PGresult *PQBulkFinish(PGconn *conn);
```

### PQexecBulkPrepared

또는, `PQexecBulkPrepared()` 함수를 사용하여 단일 함수 호출로 대량 연산을 수행할 수도 있습니다. `PQexecBulkPrepared()`는 주어진 파라미터로 준비된 구문을 실행하도록 요청을 보내고 그 결과를 기다립니다. 이 함수는 `PQbulkStart()`, `PQexecBulk()`, `PQBulkFinish()`의 기능을 결합한 것입니다. 이 함수를 사용할 때는 대량 연산을 초기화하거나 종료할 필요가 없습니다. 이 함수는 대량 연산을 시작하고, 데이터를 서버로 전달하며, 대량 연산을 종료합니다.

`stmtName` 자리에는 미리 준비된 구문을 지정합니다. 반복적으로 사용되는 명령은 실행할 때마다가 아니라 단 한 번만 파싱되고 계획(plan)됩니다.

#### API 정의 (API definition)

```c
PGresult *PQexecBulkPrepared(PGconn *conn,
                             const char *stmtName,
                             unsigned int nCols,
                             unsigned int nRows,
                             const char *const *paramValues,
                             const int *paramLengths,
                             const int *paramFormats);
```

### PQBulkStart, PQexecBulk, PQBulkFinish 사용하기 (Using PQBulkStart, PQexecBulk, PQBulkFinish)

이 예제는 `PGBulkStart`, `PQexecBulk`, `PQBulkFinish`를 사용합니다:

```c
void InsertDataUsingBulkStyle( PGconn *conn )
{
    PGresult            *res;
    Oid                 paramTypes[2];
    char                *paramVals[5][2];
    int                 paramLens[5][2];
    int                 paramFmts[2];
    int                 i;

    int                 a[5] = { 10, 20, 30, 40, 50 };
    char                b[5][10] = { "Test_1", "Test_2", "Test_3",
"Test_4", "Test_5" };

    paramTypes[0] = 23;
    paramTypes[1] = 1043;
    res = PQprepare( conn, "stmt_1", "INSERT INTO testtable1 values( $1, $2
)", 2, paramTypes );
    PQclear( res );

    paramFmts[0] = 1;   /* Binary format */
    paramFmts[1] = 0;

    for( i = 0; i < 5; i++ )
    {
        a[i] = htonl( a[i] );
        paramVals[i][0] = &(a[i]);
        paramVals[i][1] = b[i];

        paramLens[i][0] = 4;
        paramLens[i][1] = strlen( b[i] );
    }

       res = PQBulkStart(conn, "stmt_1", 2, paramFmts);
       PQclear( res );
       printf( "< -- PQBulkStart -- >\n" );

       res = PQexecBulk(conn, 5, (const char *const *)paramVals, (const
     int*)paramLens);
       PQclear( res );
       printf( "< -- PQexecBulk -- >\n" );

       res = PQexecBulk(conn, 5, (const char *const *)paramVals, (const
     int*)paramLens);
       PQclear( res );
       printf( "< -- PQexecBulk -- >\n" );

       res = PQBulkFinish(conn);
       PQclear( res );
       printf( "< -- PQBulkFinish -- >\n" );
}
```
