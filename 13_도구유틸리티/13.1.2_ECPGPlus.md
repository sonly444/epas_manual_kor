# ECPGPlus — EPAS 18 Tools (Application programmer tools)

> 원문: [EPAS v18 — Tools › Application programmer tools › ECPGPlus](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/application_developer_tools/10_ecpgplus/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 이름·키워드는 원문 그대로 보존했습니다.

EDB는 PostgreSQL 프리컴파일러 ECPG를 확장하여 ECPGPlus를 만들었습니다. 이 도구는 개발자가 C 애플리케이션에 SQL 명령을 임베드할 수 있게 합니다. ECPGPlus가 임베디드 SQL을 담은 코드를 컴파일할 때 구문 검증을 수행하고 SQL을 C 코드로 변환합니다.

## 주요 기능
EDB Postgres Advanced Server 데이터베이스와 작업할 때 Pro\*C 호환 구문을 지원합니다. 구체적으로 ECPGPlus는 다음을 지원합니다.
- Oracle Dynamic SQL – Method 4 (ODS-M4)
- Pro\*C 호환 익명 블록(anonymous blocks)
- Oracle 데이터베이스 호환 `CALL` 문

## Pro\*C 호환성
Pro\*C 호환의 일부로 ECPGPlus는 `BEGIN DECLARE SECTION`·`END DECLARE SECTION` 지시자 요구를 없애 개발 과정을 간소화합니다.
