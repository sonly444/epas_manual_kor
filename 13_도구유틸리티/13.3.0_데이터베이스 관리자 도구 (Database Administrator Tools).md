# 데이터베이스 관리자 도구 (Database Administrator Tools) — EPAS 18 Tools

> 원문: [EPAS v18 — Tools › Database administrator tools](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/database_administration_tools/)
> EPAS v18 공식 문서의 한글 번역입니다. 도구 이름은 원문 그대로 보존했습니다.

DBA 생산성을 높이는 EPAS 기능입니다.

- **Tools and utilities overview**: 지원되는 Oracle 호환 도구 및 유틸리티 프로그램에 대한 전반적인 개요 제공
- **EDB Clone Schema**: 로컬/원격 데이터베이스에서 스키마 복사(상세는 `08_4_EDB_Clone_Schema.md`).
- **EDB\*Loader**: 고성능 대량 데이터 로더(상세는 `08_3_EDB_Loader.md`).
- **EDB Resource Manager**: EPAS 프로세스의 운영체제 자원 사용 제어(상세는 `08_2_EDB_Resource_Manager.md`).

지원 Oracle 호환 도구·유틸리티 프로그램에 대한 개요도 함께 제공됩니다(13_4 참조).
