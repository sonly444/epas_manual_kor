# 외부 데이터 소스 연결 (Connecting to External Data Sources) — EPAS 18 Tools

> 원문: [EPAS v18 — Tools › Connectivity tools › Connecting to external data sources](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/connectivity_tools/data_sources/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 구성 요소 이름은 원문 그대로 보존했습니다.

EDB는 Postgres 데이터베이스 서버를 외부 데이터 소스에 연결하기 위한 여러 오픈소스 구성 요소를 패키징·지원합니다. 이 EDB 구성 요소는 해당 PostgreSQL 구성 요소의 향상된 버전입니다.

외부 데이터 소스 연결용 EDB 구성 요소:
- **EDB Hadoop Foreign Data Wrapper** — Hadoop 파일시스템에 있는 데이터를 Postgres 데이터베이스 서버에서 접근.
- **MongoDB Foreign Data Wrapper** — MongoDB 데이터베이스에 있는 데이터를 Postgres 데이터베이스 서버에서 접근.
- **MySQL Foreign Data Wrapper** — MySQL 데이터베이스에 있는 데이터를 Postgres 데이터베이스 서버에서 접근.
