# Oracle 호환 도구 (Oracle-Compatibility Tools) — EPAS 18 Tools

> 원문: [EPAS v18 — Tools › Oracle-compatibility tools](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/epas_compat_tools_guide/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 도구·명령 이름은 원문 그대로 보존했습니다.

이 도구·유틸리티를 통해 Oracle 유틸리티에 익숙한 개발자가 EDB Postgres Advanced Server를 친숙한 환경에서 사용할 수 있습니다.

## 지원 호환 도구

EDB Postgres Advanced Server가 지원하는 도구·유틸리티:

- **EDB\*Loader** — [데이터베이스 관리 문서](https://www.enterprisedb.com/docs/epas/latest/database_administration/02_edb_loader/)에서 제공(본 번역 `8_데이터베이스관리/8_3_EDB_Loader/`).
- **EDB\*Wrap** — [보안 가이드](https://www.enterprisedb.com/docs/epas/latest/epas_security_guide/03_edb_wrap/)에서 다룸(본 번역 `9_보안기능/9_5_EDB_Wrap/`).

## EDB\*Plus 명령줄 클라이언트

EDB\*Plus 명령줄 클라이언트는 SQL\*Plus 명령을 지원하는 사용자 인터페이스를 제공합니다. 다음을 할 수 있습니다.

- 데이터베이스 객체 질의
- 저장 프로시저 실행
- SQL 명령 출력 서식화
- 배치 스크립트 실행
- OS 명령 실행
- 출력 기록(record)

설치·사용 상세는 [EDB\*Plus 문서](https://www.enterprisedb.com/docs/edb_plus/latest/)를 참조하십시오.
