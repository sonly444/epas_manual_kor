# 애플리케이션 개발자 도구 (Application Programmer Tools) — EPAS 18 Tools

> 원문: [EPAS v18 — Tools › Application programmer tools](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/application_developer_tools/)
> EPAS v18 공식 문서의 한글 번역입니다. 도구·라이브러리 이름은 원문 그대로 보존했습니다.

애플리케이션 개발자를 돕는 도구입니다.

- **Unicode Collation Algorithm**: 유니코드 데이터의 콜레이션·비교를 위한 Unicode Collation Algorithm 명세 사용법.
- **ECPGPlus**: C 애플리케이션에 임베디드 SQL 명령을 포함하는 방법(Pro\*C 호환). 상세는 `10_4_ECPGPlus.md` 참조.
- **libpq C library**: 클라이언트 프로그램에서 libpq C 라이브러리 함수로 EPAS에 쿼리를 전달하는 방법.
