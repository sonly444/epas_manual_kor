# 데이터베이스 연결 (Connecting to Your Database) — EPAS 18 Tools

> 원문: [EPAS v18 — Tools › Connectivity tools › Connecting to your database](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/connectivity_tools/connectors/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 커넥터 이름은 원문 그대로 보존했습니다.

EDB는 EDB Postgres Advanced Server 데이터베이스 서버에 연결하기 위한 여러 구성 요소를 패키징·지원합니다. 이 EDB 구성 요소는 해당 PostgreSQL 구성 요소의 향상된 버전으로, 추가적인 EDB Postgres Advanced Server 기능을 지원하기 위한 것입니다.

데이터베이스 연결용 EDB 구성 요소:
- [EDB JDBC Connector](https://www.enterprisedb.com/docs/jdbc_connector/latest/) — Java 애플리케이션과 Postgres 데이터베이스 서버 간 연결 제공.
- [EDB .NET Connector](https://www.enterprisedb.com/docs/net_connector/latest/) — .NET 클라이언트 애플리케이션과 Postgres 데이터베이스 서버 간 연결 제공.
- [EDB OCL Connector](https://www.enterprisedb.com/docs/jdbc_connector/latest/) — Oracle Call Interface와 유사한 API를 제공하여 Postgres 데이터베이스 서버와 상호작용.
- [EDB ODBC Connector](https://www.enterprisedb.com/docs/odbc_connector/latest/) — ODBC 호환 클라이언트 애플리케이션이 Postgres 데이터베이스 서버에 연결.

PostgreSQL 커뮤니티 구성 요소를 EDB Postgres Advanced Server와 함께 사용할 수 있습니다. 다만 애플리케이션이 EDB Postgres Advanced Server 기능을 요구하면 EDB 구성 요소를 사용하십시오.
