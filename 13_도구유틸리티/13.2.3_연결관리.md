# 연결 관리 (Managing Your Database Connections) — EPAS 18 Tools

> 원문: [EPAS v18 — Tools › Connectivity tools › Managing your database connections](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/connectivity_tools/managing_connections/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 구성 요소 이름은 원문 그대로 보존했습니다.

EDB는 EDB Postgres Advanced Server 데이터베이스 서버 연결을 관리하기 위한 여러 오픈소스 구성 요소를 패키징·지원합니다. 이 EDB 구성 요소는 해당 PostgreSQL 구성 요소의 향상된 버전입니다.

연결 관리용 EDB 구성 요소:
- [EDB PgBouncer](https://www.enterprisedb.com/docs/pgbouncer/latest/) — Postgres 설치를 위한 경량 연결 풀링(connection pooling) 유틸리티.
- [EDB Pgpool-II](https://www.enterprisedb.com/docs/pgpool/latest/) — 클라이언트 애플리케이션과 Postgres 데이터베이스 서버 사이의 미들웨어로 동작.
