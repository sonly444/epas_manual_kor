# 도구, 유틸리티 및 구성 요소 (Tools, Utilities, and Components) — EDB Postgres Advanced Server 18

> 원문: [EPAS v18 Documentation — Tools, utilities, and components](https://www.enterprisedb.com/docs/epas/latest/tools_utilities_and_components/)
> EPAS v18 공식 문서의 한글 번역입니다. 도구·명령·라이브러리 이름은 원문 그대로 보존했습니다.

EPAS와 함께 제공·지원되는 도구와 구성 요소를 다룹니다. 하위 구성: 애플리케이션 개발자 도구 / 연결(Connectivity) 도구 / 데이터베이스 관리자 도구 / Oracle 호환 도구.

---

## 1. 애플리케이션 개발자 도구 (Application programmer tools)

- **Unicode Collation Algorithm**: 유니코드 데이터의 콜레이션·비교를 위한 Unicode Collation Algorithm 명세 사용법.
- **ECPGPlus**: C 애플리케이션에 임베디드 SQL 명령을 포함하는 방법(Pro\*C 호환).
- **libpq C library**: 클라이언트 프로그램에서 libpq C 라이브러리 함수로 EPAS에 쿼리를 전달하는 방법.

---

## 2. 연결 도구 (Connectivity tools)

EDB가 패키징·지원하는 오픈소스 구성 요소로 Postgres 데이터베이스에 연결·관리합니다. 세 범주로 구성됩니다.

- **데이터베이스 연결(Connecting to your database)**: EPAS에 연결하는 구성 요소(예: JDBC·ODBC·.NET 드라이버, libpq, EDB OCL Connector 등 — 상세는 각 커넥터 문서 참조).
- **외부 데이터 소스 연결(Connecting to external data sources)**: 외부 시스템 연동 구성 요소.
- **연결 관리(Managing your database connections)**: 연결 관리를 위한 오픈소스 구성 요소(예: 연결 풀러 등).

---

## 3. 데이터베이스 관리자 도구 (Database administrator tools)

DBA 생산성을 높이는 EPAS 기능입니다.

- **EDB Clone Schema**: 로컬/원격 데이터베이스에서 스키마 복사.
- **EDB\*Loader**: 고성능 대량 데이터 로더.
- **EDB Resource Manager**: EPAS 프로세스의 운영체제 자원 사용 제어.

(상세는 "데이터베이스 관리" 섹션 참조.)

---

## 4. Oracle 호환 도구 (Oracle-compatibility tools)

Oracle 유틸리티에 익숙한 개발자가 친숙한 환경에서 EPAS를 사용할 수 있게 하는 도구입니다.

- **EDB\*Loader**: Oracle SQL\*Loader 호환 데이터 로딩 유틸리티.
- **EDB\*Wrap**: 코드 보호·난독화 도구.
- **EDB\*Plus**: SQL\*Plus 호환 명령줄 인터페이스. EPAS에 대한 SQL\*Plus 명령을 지원하며, 주요 기능은 데이터베이스 객체 질의, 저장 프로시저 실행, SQL 명령 출력 서식화, 배치 스크립트 실행, OS 명령 실행, 출력 기록(record) 등.
