> 상위: # EDB Resource Manager — EPAS 18 Database Administration

## 1. 핵심 개념 (Key concepts)

> 원문: [edb_resource_manager_key_concepts](https://www.enterprisedb.com/docs/epas/latest/database_administration/10_edb_resource_manager/edb_resource_manager_key_concepts/)

EDB Resource Manager를 사용하여 EDB Postgres Advanced Server 프로세스가 사용하는 운영체제 자원의 사용을 제어합니다.

EDB Resource Manager 사용에 관한 주요 사항은 다음과 같습니다.

- EDB Resource Manager의 기본 구성 요소는 *리소스 그룹(resource group)*입니다. 리소스 그룹은 명명된 전역(global) 그룹입니다. EDB Postgres Advanced Server 인스턴스의 모든 데이터베이스에서 사용 가능하며, 그룹에 다양한 자원 사용 한도를 정의할 수 있습니다. 특정 리소스 그룹의 구성원으로 지정된 EDB Postgres Advanced Server 프로세스는 EDB Resource Manager에 의해 제어됩니다. 이 구성은 그룹 내 모든 프로세스의 총 자원 사용을 그룹에 정의된 한도 근처로 유지합니다.

- 데이터 정의 언어(DDL) 명령을 사용하여 리소스 그룹을 생성·변경·삭제합니다. 슈퍼유저 권한을 가진 데이터베이스 사용자만 이 명령들을 사용할 수 있습니다.

- *자원 유형 파라미터(Resource type parameters)*는 리소스 그룹에 속한 모든 프로세스의 원하는 총 소비 수준을 정의합니다. EDB Resource Manager가 현재 지원하는 서로 다른 유형의 시스템 자원에 대해 서로 다른 자원 유형 파라미터를 사용합니다.

- 각각 자원 유형 파라미터 설정이 다른 여러 리소스 그룹을 생성할 수 있으며, 이는 각 리소스 그룹에 대해 서로 다른 소비 수준을 정의합니다.

- EDB Resource Manager는 리소스 그룹의 프로세스를 조절(throttle)하여 자원 유형 파라미터로 정의된 한도 근처로 자원 소비를 유지합니다. 한 리소스 그룹에 여러 자원 유형 파라미터가 정의되어 있으면, 특정 자원 유형의 실제 소비량이 정의된 자원 유형 파라미터 설정보다 상당히 낮을 수 있습니다. 이는 EDB Resource Manager가 정의된 자원 유형 설정을 가진 모든 자원을 정의된 한도 내로 유지하려고 프로세스를 조절하기 때문에 발생합니다.

- 사용 가능한 리소스 그룹과 그 자원 유형 설정의 정의는 공유 전역 시스템 카탈로그(shared global system catalog)에 저장됩니다. 따라서 특정 EDB Postgres Advanced Server 인스턴스의 모든 데이터베이스가 리소스 그룹을 사용할 수 있습니다.

- `edb_max_resource_groups` 구성 파라미터는 실행 중인 프로세스와 동시에 활성화될 수 있는 리소스 그룹의 최대 수를 설정합니다. 기본 설정은 16개입니다. 이 파라미터의 변경은 데이터베이스 서버를 재시작할 때 적용됩니다.

- `SET edb_resource_group TO group_name` 명령을 사용하여 현재 프로세스를 지정된 리소스 그룹에 할당합니다. `RESET edb_resource_group` 명령을 사용하거나 `SET edb_resource_group`을 `DEFAULT`로 설정하여 현재 프로세스를 리소스 그룹에서 제거합니다.

- `ALTER ROLE ... SET` 명령으로 역할에, 또는 `ALTER DATABASE ... SET` 명령으로 데이터베이스에 기본 리소스 그룹을 할당할 수 있습니다. `postgresql.conf` 파일에서 파라미터를 설정하여 전체 데이터베이스 서버 인스턴스에 기본 리소스 그룹을 할당할 수 있습니다.

- 데이터베이스 서버 인스턴스의 백업 파일에 리소스 그룹을 포함하려면, `pg_dumpall` 백업 유틸리티를 기본 설정으로 사용하십시오. 즉 `--globals-only`, `--roles-only`, `--tablespaces-only` 옵션 중 어느 것도 지정하지 마십시오.
