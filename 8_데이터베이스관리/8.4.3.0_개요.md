# 데이터베이스 복사 (Copying a database) — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › EDB Clone Schema (Copying a database)](https://www.enterprisedb.com/docs/epas/latest/database_administration/14_edb_clone_schema/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Clone Schema는 EDB Postgres Advanced Server의 확장 모듈로, 로컬 또는 원격 데이터베이스(소스 데이터베이스)에서 수신 데이터베이스(대상 데이터베이스)로 스키마와 그 데이터베이스 객체를 복사할 수 있게 합니다.

소스 데이터베이스와 대상 데이터베이스는 다음 중 하나일 수 있습니다:

- 동일한 물리적 데이터베이스
- 같은 데이터베이스 클러스터 내의 서로 다른 데이터베이스
- 별도의 데이터베이스 서버 호스트에서 서로 다른 데이터베이스 클러스터로 실행되는 별개의 데이터베이스
