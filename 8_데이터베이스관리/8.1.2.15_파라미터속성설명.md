# 파라미터 속성 설명 (Description of parameter attributes) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Description of parameter attributes](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/attribute_descriptions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 속성 이름·값은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server 문서는 구성 파라미터를 설명하는 데 사용되는 주요 속성을 설명합니다.

1. **Parameter type(파라미터 타입)** - 파라미터가 받아들이는 값의 종류를 지정. 자세한 내용은 "구성 파라미터 설정" 섹션에서 확인 가능.

2. **Default value(기본값)** - 구성 파일에 명시적 값이 제공되지 않은 경우의 미리 설정된 구성.

3. **Range(범위)** - 파라미터가 받아들일 수 있는 허용 값.

4. **Minimum scope of effect(최소 적용 범위)** - 서로 다른 설정이 적용되는 최소 조직 수준. "전체 클러스터(the entire cluster)" 또는 "세션별(per session)"(역할, 데이터베이스, 또는 개별 세션에 따라 다름).

5. **When value changes take effect(값 변경 적용 시점)** - 파라미터 변경을 활성화하는 가장 덜 방해가 되는 방법. 다음으로 분류:
   - `restart`(데이터베이스 서버 재시작 필요)
   - `reload`(서버를 중지하지 않고 구성 파일 재로드)
   - `immediate`(클라이언트 측 작업)

6. **Required authorization to activate(활성화에 필요한 권한)** - 필요한 사용자 권한 수준. 서버 재시작 또는 구성 재로드는 일반적으로 서비스 계정 접근(`enterprisedb` 또는 설치 모드에 따라 `postgres`)이 필요.

> 참고: 이 속성들은 "구성 파라미터 요약" 참조 표의 컬럼과 대응합니다.
