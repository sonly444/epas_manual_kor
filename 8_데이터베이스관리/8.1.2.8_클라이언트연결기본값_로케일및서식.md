# 클라이언트 연결 기본값/로케일 및 서식 (Client connection defaults/locale and formatting) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Client connection defaults/locale and formatting](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/08_ccd_locale_and_formatting/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

이 구성 파라미터들은 로케일과 서식에 영향을 줍니다.

## icu_short_form

**파라미터 타입:** String
**기본값:** none
**범위:** n/a
**최소 적용 범위:** Database
**값 변경 적용 시점:** n/a
**활성화에 필요한 권한:** n/a

데이터베이스 또는 EDB Postgres Advanced Server 인스턴스에 할당된 기본 ICU 축약형(short-form) 이름을 포함합니다. ICU 축약형과 유니코드 콜레이션 알고리즘에 대한 일반 정보는 유니코드 콜레이션 알고리즘을 참조하십시오.

다음 경우에 이 구성 파라미터를 설정합니다.

- `ICU_SHORT_FORM` 파라미터와 함께 `CREATE DATABASE` 명령을 사용하는 경우. 이 경우 지정된 축약형 이름을 설정합니다. 이 데이터베이스에 연결될 때 `icu_short_form` 구성 파라미터에 나타납니다.
- `--icu_short_form` 옵션과 함께 `initdb` 명령을 사용하여 EDB Postgres Advanced Server 인스턴스를 생성하는 경우. 이 경우 지정된 축약형 이름을 설정합니다. 해당 EDB Postgres Advanced Server 인스턴스의 데이터베이스에 연결될 때 `icu_short_form` 구성 파라미터에 나타납니다. 데이터베이스가 자체 `ICU_SHORT_FORM` 파라미터와 다른 축약형으로 재정의하지 않습니다.

이 파라미터를 설정한 후에는 변경할 수 없습니다.
