# EDB*Loader 호출 (Invoking EDB*Loader) — EPAS 18

> 원문: [EPAS v18 — Database administration › EDB*Loader › Invoking EDB*Loader](https://www.enterprisedb.com/docs/epas/latest/database_administration/02_edb_loader/invoking_edb_loader/)
> EPAS v18 공식 문서의 한글 **전문 번역** 인덱스입니다. 아래 5개 하위 페이지를 개별 리프로 전문 번역했습니다.

이 절은 EDB*Loader를 호출하는 방법과 다양한 로드 경로(컨벤셔널·직접·병렬 직접·원격)를 설명합니다.

## 목록 (5)
1. EDB*Loader 실행 (Running EDB*Loader) — 명령 구문·요구 사항·종료 코드
2. 컨벤셔널 경로 로드로 테이블 업데이트 (Conventional path load)
3. 직접 경로 로드 (Direct path load)
4. 병렬 직접 경로 로드 (Parallel direct path load)
5. 원격 로딩 (Remote loading)
