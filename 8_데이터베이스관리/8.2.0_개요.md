# EDB Resource Manager — EPAS 18 Database Administration

> 원문: [EPAS v18 — Database administration › EDB Resource Manager](https://www.enterprisedb.com/docs/epas/latest/database_administration/10_edb_resource_manager/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·파라미터·카탈로그·뷰 이름과 터미널 출력은 원문 그대로 보존했습니다.
> 하위 구성: 핵심 개념 / 리소스 그룹 다루기 / CPU 사용 조절 / 더티 버퍼 조절.

EDB Resource Manager는 데이터베이스 프로세스가 소비하는 운영체제 자원을 관리하도록 설계된 EDB Postgres Advanced Server 기능입니다. 이 기능은 개별 프로세스가 중요한 시스템 자원을 독점하는 것을 방지합니다. 프로세스 수준에서 CPU와 I/O를 조절(throttling)합니다.
