> 상위: # EDB Resource Manager — EPAS 18 Database Administration

## 2. 리소스 그룹 다루기 (Working with resource groups)

> 원문: [creating_resource_groups](https://www.enterprisedb.com/docs/epas/latest/database_administration/10_edb_resource_manager/creating_resource_groups/)

다음 DDL 명령을 사용하여 리소스 그룹을 생성·관리합니다.

### 리소스 그룹 생성 (Creating a resource group)

`CREATE RESOURCE GROUP` 명령으로 새 리소스 그룹을 생성합니다.

```sql
CREATE RESOURCE GROUP <group_name>;
```

**설명**: `CREATE RESOURCE GROUP` 명령은 지정된 이름의 리소스 그룹을 생성합니다. 이후 `ALTER RESOURCE GROUP` 명령으로 그룹에 자원 한도를 정의할 수 있습니다. 리소스 그룹은 EDB Postgres Advanced Server 인스턴스의 모든 데이터베이스에서 접근 가능합니다. 이 명령을 사용하려면 슈퍼유저 권한이 필요합니다.

**파라미터** — `group_name`: 리소스 그룹의 이름.

**예제**: `resgrp_a`, `resgrp_b`, `resgrp_c` 세 리소스 그룹 생성:

```sql
edb=# CREATE RESOURCE GROUP resgrp_a;
CREATE RESOURCE GROUP
edb=# CREATE RESOURCE GROUP resgrp_b;
CREATE RESOURCE GROUP
edb=# CREATE RESOURCE GROUP resgrp_c;
CREATE RESOURCE GROUP
```

`edb_resource_group` 카탈로그의 항목 조회:

```sql
edb=# SELECT * FROM edb_resource_group;
```

```text
 rgrpname  | rgrpcpuratelimit | rgrpdirtyratelimit
-----------+------------------+--------------------
 resgrp_a  |                0 | 0
 resgrp_b  |                0 | 0
 resgrp_c  |                0 | 0
(3 rows)
```

### 리소스 그룹 수정 (Modifying a resource group)

`ALTER RESOURCE GROUP` 명령으로 기존 리소스 그룹의 속성을 변경합니다. 명령 구문은 세 가지 형태입니다.

이름 변경:

```sql
ALTER RESOURCE GROUP <group_name> RENAME TO <new_name>;
```

자원 유형 할당:

```sql
ALTER RESOURCE GROUP <group_name> SET
  <resource_type> { TO | = } { <value> | DEFAULT };
```

자원 유형 할당을 그룹의 기본값으로 재설정:

```sql
ALTER RESOURCE GROUP <group_name> RESET <resource_type>;
```

**설명**: `ALTER RESOURCE GROUP` 명령은 기존 리소스 그룹의 특정 속성을 변경합니다. `RENAME TO` 절 형태는 기존 리소스 그룹에 새 이름을 할당합니다. `SET resource_type TO` 절 형태는 지정된 리터럴 값을 자원 유형에 할당하며, `DEFAULT`를 지정하면 자원 유형을 재설정합니다. 자원 유형 재설정은 해당 그룹이 그 자원 유형에 대해 정의된 한도가 없음을 의미합니다. `RESET resource_type` 절 형태는 그룹의 자원 유형을 재설정합니다. 이 명령을 사용하려면 슈퍼유저 권한이 필요합니다.

**파라미터**: `group_name`(변경할 그룹 이름), `new_name`(새 이름), `resource_type`(사용량 값을 설정할 자원 유형), `value | DEFAULT`(값 지정 시 자원 유형에 할당할 리터럴 값, `DEFAULT` 지정 시 할당 재설정).

**예제**:

```sql
edb=# ALTER RESOURCE GROUP resgrp_a RENAME TO newgrp;
ALTER RESOURCE GROUP
edb=# ALTER RESOURCE GROUP resgrp_b SET cpu_rate_limit = .5;
ALTER RESOURCE GROUP
edb=# ALTER RESOURCE GROUP resgrp_b SET dirty_rate_limit = 6144;
ALTER RESOURCE GROUP
edb=# ALTER RESOURCE GROUP resgrp_c RESET cpu_rate_limit;
ALTER RESOURCE GROUP
```

결과:

```sql
edb=# SELECT * FROM edb_resource_group;
```

```text
 rgrpname  | rgrpcpuratelimit | rgrpdirtyratelimit
-----------+------------------+--------------------
 newgrp    | 0                | 0
 resgrp_b  | 0.5              | 6144
 resgrp_c  | 0                | 0
(3 rows)
```

### 리소스 그룹 제거 (Removing a resource group)

```sql
DROP RESOURCE GROUP [ IF EXISTS ] <group_name>;
```

**설명**: `DROP RESOURCE GROUP` 명령은 지정된 이름의 리소스 그룹을 제거합니다. 슈퍼유저 권한이 필요합니다.
**파라미터**: `group_name`(제거할 그룹 이름), `IF EXISTS`(그룹이 없어도 오류를 발생시키지 않고 notice를 발행).
**예제**:

```sql
edb=# DROP RESOURCE GROUP newgrp;
DROP RESOURCE GROUP
```

### 프로세스를 리소스 그룹에 할당 (Assigning a process to a resource group)

`SET edb_resource_group TO group_name` 명령으로 현재 프로세스를 지정된 리소스 그룹에 할당합니다.

```sql
edb=# SET edb_resource_group TO resgrp_b;
SET
edb=# SHOW edb_resource_group;
```

```text
 edb_resource_group
--------------------
 resgrp_b
(1 row)
```

그룹의 자원 유형 설정은 현재 프로세스에 즉시 적용됩니다. 현재 프로세스에 할당된 리소스 그룹을 변경하면 새로 할당된 그룹의 자원 유형 설정이 즉시 적용됩니다.

역할·데이터베이스·전체 데이터베이스 서버 인스턴스에 기본 리소스 그룹을 할당하여 프로세스를 기본적으로 리소스 그룹에 포함할 수 있습니다. 역할에는 `ALTER ROLE ... SET` 명령으로(자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/sql-alterrole.html)), 데이터베이스에는 `ALTER DATABASE ... SET` 명령으로(자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/sql-alterdatabase.html)) 기본 리소스 그룹을 할당할 수 있습니다. 전체 데이터베이스 서버 인스턴스에는 `postgresql.conf` 파일에서 `edb_resource_group` 구성 파라미터를 설정하여 할당합니다.

```ini
# - EDB Resource Manager -
#edb_max_resource_groups = 16           # 0-65536 (change requires restart)
edb_resource_group = 'resgrp_b'
```

`postgresql.conf`에서 `edb_resource_group`을 변경하면, 데이터베이스 서버 인스턴스에 적용되도록 구성 파일을 다시 로드하십시오.

### 프로세스를 리소스 그룹에서 제거 (Removing a process from a resource group)

`edb_resource_group`을 `DEFAULT`로 설정하거나 `RESET edb_resource_group`을 사용하여 현재 프로세스를 리소스 그룹에서 제거합니다.

```sql
edb=# SET edb_resource_group TO DEFAULT;
SET
edb=# SHOW edb_resource_group;
```

```text
 edb_resource_group
--------------------
(1 row)
```

역할에서 기본 리소스 그룹을 제거하려면 `ALTER ROLE ... RESET` 형태를, 데이터베이스에서 제거하려면 `ALTER DATABASE ... RESET` 형태를 사용합니다. 데이터베이스 서버 인스턴스에서 제거하려면 `postgresql.conf`의 `edb_resource_group`을 빈 문자열로 설정한 뒤 구성 파일을 다시 로드합니다.

### 리소스 그룹의 프로세스 모니터링 (Monitoring processes in resource groups)

리소스 그룹을 생성한 후, `edb_all_resource_groups` 뷰에서 이 그룹들을 능동적으로 사용하는 프로세스 수를 얻을 수 있습니다.

`edb_all_resource_groups`의 컬럼:

- **group_name**: 리소스 그룹 이름.
- **active_processes**: 그룹 내 활성 프로세스 수.
- **cpu_rate_limit**: 그룹에 할당된 CPU rate limit 자원 유형 값.
- **per_process_cpu_rate_limit**: 그룹 내 개별 활성 프로세스에 적용되는 CPU rate limit 입니다.
- **dirty_rate_limit**: 그룹에 할당된 dirty rate limit 값입니다.
- **per_process_dirty_rate_limit**: 그룹 내 개별 활성 프로세스에 적용되는 dirty rate limit 입니다.

> **참고**: `per_process_cpu_rate_limit`과 `per_process_dirty_rate_limit` 은 프로세스가 CPU 또는 dirty buffer 자원을 실제로 사용하는 경우 계산되어 표시됩니다. `pg_sleep()`과 같이 자원을 실질적으로 사용하지 않는 프로세스에서는 `16777216`(`2^24`)이 표시될 수 있으며, 이 값은 해당 프로세스에 대한 제한 없음(Unlimited)을 의미합니다.

예제(`resgrp_a` 활성 프로세스 0개, `resgrp_b` 2개, `resgrp_c` 1개):

```sql
edb=# SELECT * FROM edb_all_resource_groups ORDER BY group_name;
```

```text
-[ RECORD 1 ]-----------------+------------------
 group_name                   | resgrp_a
 active_processes             | 0
 cpu_rate_limit               | 0.5
 per_process_cpu_rate_limit   |
 dirty_rate_limit             | 12288
 per_process_dirty_rate_limit |
-[ RECORD 2 ]-----------------+------------------
 group_name                   | resgrp_b
 active_processes             | 2
 cpu_rate_limit               | 0.4
 per_process_cpu_rate_limit   | 0.195694289022895
 dirty_rate_limit             | 6144
 per_process_dirty_rate_limit | 3785.92924684337
-[ RECORD 3 ]-----------------+------------------
 group_name                   | resgrp_c
 active_processes             | 1
 cpu_rate_limit               | 0.3
 per_process_cpu_rate_limit   | 0.292342129631091
 dirty_rate_limit             | 3072
 per_process_dirty_rate_limit | 3072
```

이 리소스 그룹들에 할당된 CPU rate limit·dirty rate limit 설정:

```sql
edb=# SELECT * FROM edb_resource_group;
```

```text
 rgrpname  | rgrpcpuratelimit | rgrpdirtyratelimit
-----------+------------------+--------------------
 resgrp_a  | 0.5              | 12288
 resgrp_b  | 0.4              | 6144
 resgrp_c  | 0.3              | 3072
(3 rows)
```

`edb_all_resource_groups` 뷰에서 `per_process_cpu_rate_limit`과 `per_process_dirty_rate_limit` 값은 대략 해당 CPU rate limit·dirty rate limit를 활성 프로세스 수로 나눈 값입니다.
