# 클라이언트 연결 기본값/문 동작 (Client connection defaults/statement behavior) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Client connection defaults/statement behavior](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/09_ccd_statement_behaviour/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

이 구성 파라미터들은 문(statement) 동작에 영향을 줍니다.

## default_heap_fillfactor

**파라미터 타입:** Integer
**기본값:** 100
**범위:** 10 ~ 100
**최소 적용 범위:** 세션별(Per session)
**값 변경 적용 시점:** 변경 즉시(Immediate)
**활성화에 필요한 권한:** 세션 사용자

`CREATE TABLE` 명령에서 `FILLFACTOR` 저장 파라미터가 생략된 경우 테이블의 fill factor를 설정합니다.

테이블의 fill factor는 10에서 100까지의 백분율로, 100은 완전 패킹(complete packing)입니다. 더 작은 fill factor를 지정하면 `INSERT` 작업이 지정된 백분율까지만 테이블 페이지를 채웁니다. 각 페이지의 나머지 공간은 해당 페이지의 행 갱신을 위해 예약됩니다. 이 방식은 `UPDATE`가 갱신된 행 복사본을 원본과 같은 페이지에 배치할 기회를 주어, 다른 페이지에 배치하는 것보다 효율적입니다.

항목이 절대 갱신되지 않는 테이블의 경우 완전 패킹이 최선의 선택입니다. 갱신이 많은 테이블에는 더 작은 fill factor를 사용하십시오.

## edb_data_redaction

**파라미터 타입:** Boolean
**기본값:** `true`
**범위:** `{true | false}`
**최소 적용 범위:** 세션별(Per session)
**값 변경 적용 시점:** 변경 즉시(Immediate)
**활성화에 필요한 권한:** 세션 사용자

데이터 마스킹(data redaction)은 표시되는 정보를 변경하여 특정 민감 데이터의 특정 사용자에 대한 노출을 제한하는 정책의 지원입니다.

`TRUE`로 설정되면 슈퍼유저와 테이블 소유자를 제외한 모든 사용자에게 데이터 마스킹이 적용됩니다.

- 슈퍼유저와 테이블 소유자는 데이터 마스킹을 우회합니다.
- 다른 모든 사용자는 마스킹 정책이 적용되어 재구성된 데이터를 봅니다.

`FALSE`로 설정되면 다음이 발생합니다.

- 슈퍼유저와 테이블 소유자는 여전히 데이터 마스킹을 우회합니다.
- 다른 모든 사용자는 오류를 받습니다.

데이터 마스킹에 대한 정보는 EDB Postgres Advanced Server 보안 기능을 참조하십시오.
