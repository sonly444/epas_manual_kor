# 리소스 사용/메모리 (Resource usage/memory) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Resource usage/memory](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/02_resource_usage_memory/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

이 구성 파라미터들은 메모리와 관련된 리소스 사용을 제어합니다.

## edb_dynatune

**파라미터 타입:** Integer
**기본값:** 66
**범위:** 0 ~ 100
**최소 적용 범위:** Cluster
**값 변경 적용 시점:** Restart
**활성화에 필요한 권한:** EDB Postgres Advanced Server 서비스 계정

호스트 머신의 총 가용 리소스와 호스트 머신의 의도된 용도에 기반하여 데이터베이스 서버가 호스트 시스템 리소스를 얼마나 사용할지 결정합니다.

EDB Postgres Advanced Server를 처음 설치할 때, 설치된 호스트 머신의 용도(개발 머신, 혼합 용도 머신, 전용 서버)에 따라 `edb_dynatune`을 설정합니다. 대부분의 목적에서 데이터베이스 관리자는 성능 향상을 위해 `postgresql.conf` 파일의 여러 구성 파라미터를 조정할 필요가 없습니다.

`edb_dynatune` 파라미터는 0부터 100까지의 정수 값으로 설정할 수 있습니다. 값 0은 동적 튜닝 기능을 끄며, 데이터베이스 서버 리소스 사용을 `postgresql.conf` 파일의 다른 구성 파라미터의 제어 하에 둡니다.

낮은 0이 아닌 값(예: 1~33)은 데이터베이스 서버에 가장 적은 양의 호스트 머신 리소스를 할당합니다. 이 값들은 다른 많은 애플리케이션이 사용되는 개발 머신에 적합합니다.

34~66 범위의 값은 데이터베이스 서버에 적당한 양의 리소스를 할당합니다. 이 설정은 EDB Postgres Advanced Server와 같은 머신에서 고정된 수의 다른 애플리케이션을 실행하는 전용 애플리케이션 서버에 사용될 수 있습니다.

67~100의 가장 높은 값은 서버 리소스의 대부분을 데이터베이스 서버에 할당합니다. EDB Postgres Advanced Server 실행 전용 호스트 머신에는 이 범위의 설정을 사용하십시오.

`edb_dynatune` 값을 선택한 후, `postgresql.conf` 파일의 다른 구성 파라미터를 조정하여 데이터베이스 서버 성능을 더욱 미세 조정할 수 있습니다. 조정된 설정은 `edb_dynatune`이 선택한 해당 값을 재정의합니다. 파라미터 값을 변경하려면 구성 파라미터의 주석을 해제하고 원하는 값을 지정한 후 데이터베이스 서버를 재시작하십시오.

edb_dynatune는 다음 파라미터에 자동 튜닝 노력을 집중합니다.

- shared_buffers
- work_mem
- maintenance_work_mem
- effective_cache_size
- random_page_cost
- max_connections

튜닝 로직은 제한적이며, 수동으로 설정된 모든 파라미터는 자동 튜닝 프로세스에서 제외됩니다.

## edb_dynatune_profile

**파라미터 타입:** Enum
**기본값:** `oltp`
**범위:** `{oltp | reporting | mixed}`
**최소 적용 범위:** Cluster
**값 변경 적용 시점:** Restart
**활성화에 필요한 권한:** EDB Postgres Advanced Server 서비스 계정

데이터베이스 서버에서 예상되는 워크로드 프로파일에 기반하여 튜닝 측면을 제어합니다.

가능한 값은 다음과 같습니다.

- `oltp`. 데이터베이스 서버가 무거운 온라인 트랜잭션 처리(OLTP) 워크로드를 처리할 때 권장.
- `reporting`. 무거운 데이터 보고에 사용되는 데이터베이스 서버에 권장.
- `mixed`. 트랜잭션 처리와 데이터 보고를 혼합하여 제공하는 서버에 권장.
