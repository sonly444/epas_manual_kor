# 미분류 구성 파라미터 (Ungrouped configuration parameters) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Ungrouped configuration parameters](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/13_ungrouped/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

이 구성 파라미터들은 특정하고 제한된 목적으로 EDB Postgres Advanced Server에만 적용됩니다.

## nls_length_semantics

**파라미터 타입:** Enum
**기본값:** `byte`
**범위:** `{byte | char}`
**최소 적용 범위:** 세션별(Per session)
**값 변경 적용 시점:** 변경 즉시(Immediate)
**활성화에 필요한 권한:** 슈퍼유저

이 파라미터는 EDB Postgres Advanced Server에서 아무 효과가 없습니다. 구문은 허용되지만 세션 환경에 아무 변화를 일으키지 않습니다. 기능적 영향이 없으므로 `pg_settings` 시스템 뷰에 나타나지 않습니다.

## query_rewrite_enabled

**파라미터 타입:** Enum
**기본값:** `false`
**범위:** `{true | false | force}`
**최소 적용 범위:** 세션별(Per session)
**값 변경 적용 시점:** 변경 즉시(Immediate)
**활성화에 필요한 권한:** 세션 사용자

위 파라미터와 마찬가지로 이 설정은 EDB Postgres Advanced Server에서 아무 효과가 없으나 구문은 유효합니다. 마찬가지로 `pg_settings`에 나타나지 않습니다.

## query_rewrite_integrity

**파라미터 타입:** Enum
**기본값:** `enforced`
**범위:** `{enforced | trusted | stale_tolerated}`
**최소 적용 범위:** 세션별(Per session)
**값 변경 적용 시점:** 변경 즉시(Immediate)
**활성화에 필요한 권한:** 슈퍼유저

이 파라미터도 시스템 내에서 기능하지 않으며, 구문은 허용하지만 운영상의 변화를 일으키지 않습니다.
