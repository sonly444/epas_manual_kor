## 2. 데이터 로딩 방식 (Data loading methods)

> 원문: [data_loading_methods](https://www.enterprisedb.com/docs/epas/latest/database_administration/02_edb_loader/data_loading_methods/)

EDB*Loader는 Oracle SQL*Loader 기능을 반영하여 세 가지 데이터 가져오기 방식을 제공합니다.

- **일반 경로 로드(Conventional path load)**: 기본 옵션. 기본 insert 처리를 사용하여 테이블에 행을 추가합니다. 장점은 로딩 중 기본 키·외래 키·트리거 같은 데이터베이스 제약이 강제된다는 점입니다. 그러나 일반 로드 중에는 EDB Postgres 규칙(rule)이 적용되지 않으므로, 규칙으로 구현된 파티션 테이블은 로드할 수 없습니다.
- **직접 경로 로드(Direct path load)**: 일반 방식보다 성능이 향상되지만, 대신 테이블에서 대부분 유형의 제약과 트리거를 제거해야 하는 트레이드오프가 있습니다.
- **병렬 직접 경로 로드(Parallel direct path load)**: 여러 EDB*Loader 세션이 하나의 테이블을 동시에 로드할 수 있게 하여 처리량을 극대화합니다.

`CREATE RULE` 명령으로 생성되는 EDB Postgres Advanced Server 규칙은 Oracle의 규칙(rule) 및 규칙 집합(rule set) 데이터베이스 객체와는 다릅니다.
