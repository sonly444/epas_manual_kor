# 원격 로딩 (Performing Remote Loading) — EPAS 18

> 원문: [EPAS v18 — Database administration › EDB*Loader › Invoking EDB*Loader › Remote loading](https://www.enterprisedb.com/docs/epas/latest/database_administration/02_edb_loader/invoking_edb_loader/performing_remote_loading/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·옵션·코드는 원문 그대로 보존했습니다.

EDB*Loader는 *원격 로딩(remote loading)*이라는 기능을 지원합니다. 원격 로딩에서는 로드할 테이블을 포함하는 데이터베이스가 EDB*Loader가 입력 데이터 소스와 함께 호출되는 호스트와 다른 호스트의 데이터베이스 서버에서 실행됩니다.

이 기능은 로드할 데이터 양이 많고 데이터베이스 서버를 실행하는 호스트에 큰 데이터 파일을 생성하고 싶지 않을 때 유용합니다.

또한 표준 입력(standard input) 기능을 사용하여 다른 프로그램이나 스크립트 같은 데이터 소스에서 데이터를 EDB*Loader로 직접 파이핑할 수 있습니다. 그러면 EDB*Loader가 원격 데이터베이스의 테이블을 로드합니다. 이 기능은 EDB*Loader를 위해 디스크에 데이터 파일을 생성할 필요를 없앱니다.

## 요구 사항

표준 입력을 사용한 원격 로딩 수행에는 다음이 필요합니다.

- EDB*Loader 세션의 데이터 소스와 함께 호출할 클라이언트 호스트에 `edbldr` 프로그램이 설치되어 있어야 합니다.
- 데이터를 EDB*Loader의 표준 입력으로 직접 파이핑할 수 있도록 컨트롤 파일에 `INFILE 'stdin'` 절이 포함되어야 합니다. `INFILE` 절과 EDB*Loader 컨트롤 파일에 대한 정보는 "EDB*Loader 컨트롤 파일 작성"을 참조하십시오.
- 컨트롤 파일, bad 파일, discard 파일, 로그 파일 같은 EDB*Loader가 사용하는 모든 파일은 `edbldr`가 호출되는 클라이언트 호스트에 있거나 생성되어야 합니다.
- EDB*Loader를 호출할 때 `-h` 옵션을 사용하여 원격 데이터베이스 서버의 IP 주소를 지정합니다. 자세한 내용은 "EDB*Loader 호출"을 참조하십시오.
- 운영 체제 파이프 연산자(`|`) 또는 입력 리디렉션 연산자(`<`)를 사용하여 EDB*Loader에 입력 데이터를 제공합니다.

## 데이터베이스 로딩

이 예는 `datasource`라는 소스에서 파이핑된 데이터를 사용하여 `192.168.1.14`의 데이터베이스 서버에서 실행 중인 데이터베이스를 로드합니다.

```shell
datasource | ./edbldr -d edb -h 192.168.1.14 USERID=enterprisedb/password
CONTROL=remote.ctl
```

이 예는 표준 입력을 사용하는 방법도 보여줍니다.

```shell
./edbldr -d edb -h 192.168.1.14 USERID=enterprisedb/password
CONTROL=remote.ctl < datasource
```
