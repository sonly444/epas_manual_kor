# 클라이언트 연결 기본값/기타 기본값 (Client connection defaults/other defaults) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Client connection defaults/other defaults](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/10_ccd_other_defaults/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

이 페이지는 EDB Postgres Advanced Server의 기타 클라이언트 연결 설정을 제어하는 세 가지 구성 파라미터를 설명합니다.

## oracle_home

**타입:** String
**기본값:** None
**범위:** 클러스터 전체(Cluster-wide)
**적용 시점:** 서버 재시작 필요
**권한:** EDB Postgres Advanced Server 서비스 계정

이 파라미터는 데이터베이스를 Oracle home 디렉터리로 안내합니다. `oracle_home` 구성 파라미터에 지정된 값은 Linux의 `LD_LIBRARY_PATH` 환경 변수와 Windows의 `PATH` 환경 변수를 재정의합니다. 경로는 `libclntsh.so`(Linux) 또는 `oci.dll`(Windows)이 위치한 곳을 가리켜야 합니다.

## odbc_lib_path

**타입:** String
**기본값:** None
**범위:** 클러스터 전체(Cluster-wide)
**적용 시점:** 서버 재시작 필요
**권한:** EDB Postgres Advanced Server 서비스 계정

이 파라미터는 비표준 위치에 설치된 ODBC 드라이버 매니저의 위치를 지정하며, 일반적으로 `libodbc.so`를 가리킵니다.

## edb_role_last_login

**타입:** Boolean
**기본값:** False
**유효한 값:** TRUE, YES, ON, 1(활성화); FALSE, NO, OFF, 0(비활성화)
**권한:** 슈퍼유저 및 SET 권한을 가진 사용자

이 파라미터는 로그인 성공 시 `pg_authid` 카탈로그의 `rollastlogin` 타임스탬프를 갱신하여 역할 로그인 활동 추적을 활성화하며, `INACTIVE_ACCOUNT_TIME` 같은 보안 기능을 지원합니다. `ALTER SYSTEM SET`, 직접 파일 편집, 또는 세션 수준 `SET` 명령으로 구성할 수 있습니다.
