# maintenance_work_mem — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › maintenance_work_mem](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/03_maintenance_work_mem/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Integer

**기본값 (Default value):** 16MB

**범위 (Range):** 1024kB to 2097151kB

**효력의 최소 범위 (Minimum scope of effect):** Per session

**값 변경이 적용되는 시점 (When value changes take effect):** Immediate

**활성화에 필요한 권한 (Required authorization to activate):** Session user

`VACUUM`, `CREATE INDEX`, `ALTER TABLE ADD FOREIGN KEY`와 같은 유지 관리 작업이 사용하는 최대 메모리 양을 지정합니다. 기본값은 16MB입니다. 데이터베이스 세션은 한 번에 이러한 작업 중 하나만 실행할 수 있고, 설치 환경에서는 일반적으로 이러한 작업이 동시에 많이 실행되지 않으므로, 이 값을 `work_mem`보다 상당히 크게 설정해도 안전합니다. 더 큰 설정값은 vacuum 작업과 데이터베이스 덤프 복원의 성능을 향상시킬 수 있습니다.

autovacuum이 실행될 때 최대 `autovacuum_max_workers`배까지 할당할 수 있으므로, 기본값을 너무 높게 설정하지 않도록 주의하십시오.

좋은 경험 법칙은 이 값을 시스템 메모리의 약 5%로 설정하되 약 512MB를 넘지 않게 하는 것입니다. 더 큰 값이 반드시 성능을 향상시키는 것은 아닙니다.
