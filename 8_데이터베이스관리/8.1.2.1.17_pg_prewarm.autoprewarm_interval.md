# pg_prewarm.autoprewarm_interval — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › pg_prewarm.autoprewarm_interval](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/17_pg_prewarm.autoprewarm_interval/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Integer

**기본값 (Default value):** 300s

**범위 (Range):** 0s to 2147483s

**효력의 최소 범위 (Minimum scope of effect):** Cluster

**값 변경이 적용되는 시점 (When value changes take effect):** Reload

**활성화에 필요한 권한 (Required authorization to activate):** EDB Postgres Advanced Server service account

`autoprewarm` 백그라운드 워커가 shared buffers를 디스크로 덤프하는 최소 시간(초)입니다. 0으로 설정하면 shared buffers가 정기적인 간격으로 덤프되지 않습니다. 이 경우 서버를 종료할 때만 덤프됩니다.

`autoprewarm` 백그라운드 워커에 대한 정보는 [pg_prewarm.autoprewarm](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/16_pg_prewarm.autoprewarm/#pg_prewarm_autoprewarm)을 참조하십시오.
