# 최상위 성능 관련 파라미터 (Top performance-related parameters) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Top performance-related parameters](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름은 원문 그대로 보존했습니다.

이 페이지는 EDB Postgres Advanced Server에서 "성능에 가장 즉각적인 영향을 미치는" 구성 파라미터를 식별합니다. 다음 17개의 주요 성능 파라미터를 다음과 같이 조직하여 나열합니다.

**메모리 및 버퍼 관리:**
- shared_buffers
- work_mem
- maintenance_work_mem
- wal_buffers

**체크포인트 구성:**
- checkpoint_segments
- checkpoint_completion_target
- checkpoint_timeout
- max_wal_size
- min_wal_size

**백그라운드 작업:**
- bgwriter_delay

**쿼리 계획 비용:**
- seq_page_cost
- random_page_cost
- effective_cache_size

**트랜잭션 처리:**
- synchronous_commit

**EDB 전용 파라미터:**
- edb_max_spins_per_delay
- pg_prewarm.autoprewarm
- pg_prewarm.autoprewarm_interval

각 파라미터는 상세한 구성 지침을 제공하는 전용 문서 페이지로 연결됩니다.
