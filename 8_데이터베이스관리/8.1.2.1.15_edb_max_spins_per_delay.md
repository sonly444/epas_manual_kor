# edb_max_spins_per_delay — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › edb_max_spins_per_delay](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/15_edb_max_spins_per_delay/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Integer

**기본값 (Default value):** 1000

**범위 (Range):** 10 to 1000

**효력의 최소 범위 (Minimum scope of effect):** Per cluster

**값 변경이 적용되는 시점 (When value changes take effect):** Restart

**활성화에 필요한 권한 (Required authorization to activate):** EDB Postgres Advanced Server service account

세션이 스핀 락(spin lock)을 기다리는 동안 스핀(spin)하는 최대 횟수를 지정합니다. 락을 획득하지 못하면 세션은 대기(sleep)합니다.

이 파라미터는 비균일 메모리 접근(non-uniform memory access, NUMA) 아키텍처를 사용하는 시스템에 유용할 수 있습니다.
