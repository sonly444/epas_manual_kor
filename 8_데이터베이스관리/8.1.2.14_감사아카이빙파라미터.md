# 감사 아카이빙 파라미터 (Audit archiving parameters) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Audit archiving parameters](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/14_audit_archiver/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

이 페이지는 EDB Postgres Advanced Server의 감사 아카이빙(audit archiving) 기능을 제어하는 구성 파라미터를 설명합니다. `edb_audit_archiver`를 제외한 모든 파라미터는 EDB Postgres Advanced Server 서비스 계정 권한이 필요하며 reload 시 적용됩니다(`edb_audit_archiver`는 재시작 필요).

## 주요 파라미터

**edb_audit_archiver** - 클러스터 수준에서 감사 아카이빙 기능을 활성/비활성화하는 열거형 설정(true/false, 기본값: false). 적용에 서버 재시작 필요.

**edb_audit_archiver_timeout** - Integer 파라미터(기본값: 300초, 범위: 30초~하루). 로그 파일 아카이빙 작업의 타임아웃 지속 시간을 설정.

**edb_audit_archiver_filename_prefix** - String 파라미터(기본값: "audit-"). 명명 패턴에 기반하여 어떤 감사 로그 파일이 압축 또는 만료 대상인지 식별.

## 압축 설정

세 가지 압축 관련 파라미터:
- **edb_audit_archiver_compress_time_limit** - 경과 시간에 기반하여 파일이 압축 대상이 되는 시점을 결정(기본값: -1, 시간 기반 압축 없음)
- **edb_audit_archiver_compress_size_limit** - 크기 기반 압축 대상의 메가바이트 임계값 설정(기본값: -1)
- **edb_audit_archiver_compress_command** - 실행할 압축 유틸리티 지정(기본값: "gzip %p")
- **edb_audit_archiver_compress_suffix** - 압축 아카이브의 파일 확장자 정의(기본값: ".gz")

## 만료 설정

압축과 유사하게, 세 가지 만료 파라미터가 로그 파일 제거를 관리:
- **edb_audit_archiver_expire_time_limit** - 시간 기반 만료 대상(기본값: -1)
- **edb_audit_archiver_expire_size_limit** - 크기 기반 만료 대상, 메가바이트(기본값: -1)
- **edb_audit_archiver_expire_command** - 만료된 파일 제거 전 실행할 사용자 정의 명령(기본값: 빈 문자열)

**edb_audit_archiver_sort_file** - 가장 오래된 로그 파일을 식별할 때 정렬 방법을 "mtime"(수정 시간) 또는 "alphabetic"으로 결정.
