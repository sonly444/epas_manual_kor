# 호환성 옵션 (Compatibility options) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Compatibility options](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/11_compatibility_options/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

이 페이지는 EDB Postgres Advanced Server(EPAS)의 데이터베이스 호환성 기능을 제어하는 여덟 가지 구성 파라미터를 설명합니다. 모든 파라미터는 특별한 권한 없이 세션 수준에서 즉시 적용됩니다.

## edb_redwood_date (Boolean, 기본값: false)
테이블 정의의 `DATE` 컬럼이 `TIMESTAMP`로 변환되는지 여부를 결정합니다. 활성화되면 date 컬럼이 날짜와 함께 시간 구성 요소를 저장합니다.

## edb_redwood_greatest_least (Boolean, 기본값: true)
`GREATEST`와 `LEAST` 함수의 null 처리를 제어합니다. true이면 파라미터 중 하나라도 null이면 이 함수들은 null을 반환합니다. false이면 모두 null이 아닌 한 null 파라미터는 무시됩니다.

## edb_redwood_raw_names (Boolean, 기본값: false)
데이터베이스 객체 이름이 Redwood 카탈로그에 어떻게 나타나는지에 영향을 줍니다. false이면 이름이 따옴표가 유지된 채 대문자로 표시됩니다. true이면 PostgreSQL 시스템 카탈로그에 저장된 대로(일반적으로 소문자) 나타납니다.

## edb_redwood_strings (Boolean, 기본값: false)
null 값과의 문자열 연결(concatenation)을 관장합니다. true이면 문자열과 null을 연결하면 원래 문자열이 생성됩니다. false이면 결과가 null입니다(PostgreSQL 동작).

## edb_stmt_level_tx (Boolean, 기본값: false)
문 수준 트랜잭션 격리(statement-level transaction isolation)를 구현합니다. true이면 SQL 명령의 오류가 이전의 커밋되지 않은 갱신을 롤백하지 않습니다. false이면 예외가 커밋되지 않은 모든 데이터베이스 변경을 롤백합니다.

## db_dialect (Enum, 기본값: postgres)
PostgreSQL의 `pg_catalog`와 EPAS의 `sys` 카탈로그 간 카탈로그 검색 우선순위를 제어합니다. "postgres"는 기본 PostgreSQL 카탈로그를 우선하고, "redwood"는 확장 카탈로그 뷰를 우선합니다.

## default_with_rowids (Boolean, 기본값: false)
활성화되면 새 테이블에 1부터 시작하는 자동 증가 `ROWID` 컬럼이 자동으로 포함되며, 기본적으로 고유 인덱스가 생성됩니다.

## optimizer_mode (Enum, 기본값: choose)
쿼리 최적화 전략을 지정합니다: `ALL_ROWS`, `CHOOSE`, `FIRST_ROWS`, `FIRST_ROWS_10`, `FIRST_ROWS_100`, `FIRST_ROWS_1000` — 서로 다른 결과 집합 검색 가정에 대응.
