# max_wal_size — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › max_wal_size](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/08_max_wal_size/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Integer

**기본값 (Default value):** 1 GB

**범위 (Range):** 2 to 2147483647

**효력의 최소 범위 (Minimum scope of effect):** Cluster

**값 변경이 적용되는 시점 (When value changes take effect):** Reload

**활성화에 필요한 권한 (Required authorization to activate):** EDB Postgres Advanced Server service account

`max_wal_size`는 자동 WAL 체크포인트 사이에 WAL이 도달할 수 있는 최대 크기를 지정합니다. 이는 소프트 리밋(soft limit)입니다. 무거운 부하가 걸린 경우, archive_command가 실패하는 경우, 또는 `wal_keep_size` 설정이 높은 경우와 같은 특수한 상황에서는 WAL 크기가 `max_wal_size`를 초과할 수 있습니다.

이 파라미터를 증가시키면 크래시 복구에 필요한 시간이 늘어날 수 있습니다. 이 파라미터는 `postgresql.conf` 파일이나 서버 명령줄에서 설정할 수 있습니다.
