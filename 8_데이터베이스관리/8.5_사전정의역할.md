# 사전 정의 역할 (Predefined Roles) — EPAS 18 Database Administration

> 원문: [EPAS v18 — Database administration › Predefined roles](https://www.enterprisedb.com/docs/epas/latest/database_administration/roles/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 역할·패키지 이름은 원문 그대로 보존했습니다.

사전 정의 역할(predefined roles) 모음은 자주 필요한 권한 있는 기능과 정보에 대한 접근을 제공합니다. CREATE ROLE 권한을 가진 관리자를 포함한 데이터베이스 관리자는 이 역할들을 사용자와 다른 역할에 배포할 수 있습니다. 부여받은 대상은 지정된 기능과 정보에 대한 접근 권한을 얻습니다.

PostgreSQL의 전체 사전 정의 역할 목록은 [PostgreSQL 문서](https://www.postgresql.org/docs/18/predefined-roles.html)를 참조하십시오.

다음 표는 EDB Postgres Advanced Server에 고유한 사전 정의 역할을 상세히 설명합니다.

| 역할 | 허용되는 접근 |
| --- | --- |
| aq_administrator_role | 큐잉(queuing) 인프라 생성 및 관리 |
| capture_admin | `DBMS_PRIVILEGE_CAPTURE` 패키지에 대한 실행(Execute) 권한 |
| edb_createdirectory_admin | 디렉터리 생성 권한 |
| edb_dropdirectory_admin | 임의 디렉터리 삭제 권한 |
