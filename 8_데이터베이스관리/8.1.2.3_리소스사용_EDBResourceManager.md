# 리소스 사용/EDB Resource Manager (Resource usage/EDB Resource Manager) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Resource usage/EDB Resource Manager](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/03_resource_usage_edb_resource_manager/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

이 구성 파라미터들은 EDB Resource Manager를 통해 리소스 사용을 제어합니다.

## edb_max_resource_groups

**파라미터 타입:** Integer
**기본값:** 16
**범위:** 0 ~ 65536
**최소 적용 범위:** Cluster
**값 변경 적용 시점:** Restart
**활성화에 필요한 권한:** EDB Postgres Advanced Server 서비스 계정

EDB Resource Manager가 동시에 사용할 수 있는 최대 리소스 그룹 수를 제어합니다. `edb_max_resource_groups`가 지정한 값보다 많은 리소스 그룹을 생성할 수 있습니다. 그러나 이 그룹의 프로세스가 활발히 사용 중인 리소스 그룹 수는 이 값을 초과할 수 없습니다.

유지하려는 그룹 수를 처리할 수 있을 만큼 이 파라미터를 충분히 크게 설정하십시오.

## edb_resource_group

**파라미터 타입:** String
**기본값:** none
**범위:** n/a
**최소 적용 범위:** 세션별(Per session)
**값 변경 적용 시점:** Immediate
**활성화에 필요한 권한:** 세션 사용자

그룹의 리소스 타입 설정에 따라 현재 세션에서 EDB Resource Manager가 제어할 리소스 그룹의 이름입니다.

이 파라미터를 설정하지 않으면 현재 세션은 EDB Resource Manager를 사용하지 않습니다.
