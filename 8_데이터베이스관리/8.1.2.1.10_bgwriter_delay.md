# bgwriter_delay — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › bgwriter_delay](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/10_bgwriter_delay/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Integer

**기본값 (Default value):** 200ms

**범위 (Range):** 10ms to 10000ms

**효력의 최소 범위 (Minimum scope of effect):** Cluster

**값 변경이 적용되는 시점 (When value changes take effect):** Reload

**활성화에 필요한 권한 (Required authorization to activate):** EDB Postgres Advanced Server service account

백그라운드 라이터(background writer)의 활동 라운드 사이의 지연 시간을 지정합니다. 각 라운드에서 라이터는 일정 수의 더티 버퍼(dirty buffer)에 대한 쓰기를 발행합니다. (더티 버퍼의 수는 `bgwriter_lru_maxpages` 및 `bgwriter_lru_multiplier` 파라미터를 사용하여 제어할 수 있습니다.) 그런 다음 `bgwriter_delay` 밀리초 동안 대기(sleep)하고, 이를 반복합니다.

많은 시스템에서 대기 지연(sleep delay)의 실제 해상도는 10ms입니다. `bgwriter_delay`를 10의 배수가 아닌 값으로 설정하면 그다음 더 높은 10의 배수로 설정한 것과 동일한 결과가 나올 수 있습니다.

일반적으로 `bgwriter_delay`를 튜닝할 때는 기본값보다 줄입니다. 이 파라미터를 증가시키는 경우는 드뭅니다. 사용량이 매우 낮은 시스템에서 전력 소비를 절약하는 것이 값을 증가시킬 수 있는 한 가지 경우입니다.
