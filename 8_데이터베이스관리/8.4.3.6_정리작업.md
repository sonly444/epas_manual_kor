# 정리 작업 수행 (Performing cleanup tasks) — EPAS 18

> 원문: [EPAS v18 — Database administration › EDB Clone Schema › Performing cleanup tasks](https://www.enterprisedb.com/docs/epas/latest/database_administration/14_edb_clone_schema/performing_cleanup_tasks/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·파라미터·코드·출력은 원문 그대로 보존했습니다.

`remove_log_file_and_job` 함수는 스키마 클로닝 함수가 생성한 로그 파일과 비차단(non-blocking) 함수가 생성한 작업을 제거하여 정리(cleanup) 작업을 수행합니다.

```sql
remove_log_file_and_job (
  { <log_file> TEXT |
    <job_id> INTEGER |
    <log_file> TEXT, <job_id> INTEGER
  }
)
```

`remove_log_file_and_job` 함수를 호출할 때 두 파라미터 중 하나 또는 둘 다에 값을 지정할 수 있습니다.

- `log_file`만 지정하면 함수는 로그 파일만 제거합니다.
- `job_id`만 지정하면 함수는 작업만 제거합니다.
- 둘 다 지정하면 함수는 로그 파일과 작업을 제거합니다.

## 파라미터 (Parameters)

**`log_file`**
제거할 로그 파일의 이름입니다.

**`job_id`**
제거할 작업의 작업 ID입니다.

## 예제 (Example)

이 예제는 로그 파일 이름을 지정하여 로그 파일만 제거합니다.

```sql
edb=# SELECT edb_util.remove_log_file_and_job ('clone_edb_edbcopy');
```

출력

```text
 remove_log_file_and_job
-------------------------
 t
(1 row)
```

이 예제는 작업 ID를 지정하여 작업만 제거합니다.

```sql
edb=# SELECT edb_util.remove_log_file_and_job (3);
```

출력

```text
 remove_log_file_and_job
-------------------------
 t
(1 row)
```

이 예제는 두 값을 모두 지정하여 로그 파일과 작업을 제거합니다.

```sql
tgtdb=# SELECT edb_util.remove_log_file_and_job ('clone_rmt_src_tgt',2);
```

출력

```text
 remove_log_file_and_job
-------------------------
 t
(1 row)
```
