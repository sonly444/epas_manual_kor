# 데이터베이스 관리 (Database Administration) — EDB Postgres Advanced Server 18

> 원문: [EPAS v18 Documentation — Database administration](https://www.enterprisedb.com/docs/epas/latest/database_administration/)
> EPAS v18 공식 문서의 한글 번역입니다. 파라미터·명령·함수·역할 이름은 원문 그대로 보존했습니다.

이 섹션은 EPAS 데이터베이스를 운영·관리하기 위한 EPAS 고유 기능을 다룹니다. 하위 구성: 구성 파라미터 설정 / EDB Resource Manager / EDB\*Loader / EDB Clone Schema / 사전 정의 역할.

---

## 1. 구성 파라미터 설정 (Setting configuration parameters)

EPAS 구성 파라미터는 데이터 파일·로그 파일 위치, 연결·인증·보안 설정, 자원 할당·소비, 아카이빙·복제, 오류 로깅·통계 수집, 최적화·성능 튜닝, 로케일·서식 등 데이터베이스 서버 동작 전반을 제어합니다.

EPAS에만 적용되는 파라미터는 `edb_*` 접두어로 표기되며, 전체 목록과 설명은 참조(Reference) 가이드의 "Summary of configuration parameters"에 정리되어 있습니다. (대표 예: `edb_audit`, `edb_audit_nested_statements`, `edb_max_resource_groups`, `edb_redwood_date`, `edb_redwood_strings` 등 — 상세는 참조 섹션 참고.)

---

## 2. EDB Resource Manager

EDB Postgres Advanced Server 프로세스가 사용하는 운영체제 자원의 사용량을 제어하여, 특정 프로세스가 자원을 독점하는 것을 방지하는 기능입니다.

- **리소스 그룹(Resource Groups)**: 자원을 제어할 그룹을 생성·관리.
- **CPU 사용 조절(CPU usage throttling)**: 리소스 그룹의 CPU 사용을 제한.
- **더티 버퍼 조절(Dirty buffer throttling)**: 공유 버퍼(shared buffers)에 대한 쓰기를 제어.
- **주요 파라미터**: `edb_max_resource_groups` (생성 가능한 리소스 그룹 최대 수).

---

## 3. EDB\*Loader

Oracle 데이터베이스 호환 인터페이스를 제공하는 고성능 대량 데이터 로더입니다. 입력 소스(주로 파일)의 데이터를 하나 이상의 테이블로 적재하는 명령줄 유틸리티로, Oracle **SQL\*Loader** 파라미터의 부분집합을 사용합니다.

- **명령**: `edbldr` (명령줄 유틸리티).
- **컨트롤 파일(Control file)**: 로드 동작을 정의하는 구성 파일. "Building the control file" 절에서 작성 방법을 설명.
- **주요 기능 영역**: 핵심 개념·Oracle 호환성, 지원 데이터 로딩 방식, 오류 처리, 컨트롤 파일 작성, 호출 절차. (직접 경로 로딩(direct path load) 지원 — 단, TDE 활성화 시 데이터 암호화 보장을 위해 직접 경로 로딩이 방지됨. 릴리스 노트 18.4 참조.)

---

## 4. EDB Clone Schema

스키마와 그 데이터베이스 객체를 원본 데이터베이스(source)에서 대상 데이터베이스(target)로 복사하는 확장 모듈입니다. 원본과 대상은 동일 데이터베이스, 동일 클러스터 내 다른 데이터베이스, 또는 원격 서버의 별도 클러스터일 수 있습니다.

- **운영 모드**: 단일 데이터베이스 내 스키마 복제 / 동일 클러스터 내 데이터베이스 간 이전 / 원격 서버 간 클러스터 복제.
- **함수**: `edb_util` 스키마 하위에 로컬 복사(`localcopyschema`), 원격 복사(`remotecopyschema`), 상태 확인, 정리(cleanup) 용도의 함수들이 제공됨.
- **사전 요건**: "Setting up EDB Clone Schema" 절에서 설치·구성 절차를 별도로 다룸.

## 5. 사전 정의 역할 (Predefined roles)

EPAS에는 다음 네 가지 고유 사전 정의 역할이 있습니다. CREATE ROLE 권한을 가진 관리자가 사용자·다른 역할에 부여할 수 있습니다.

- **aq_administrator_role**: 큐잉(queuing) 인프라 생성·관리.
- **capture_admin**: `DBMS_PRIVILEGE_CAPTURE` 패키지 실행 권한.
- **edb_createdirectory_admin**: 디렉터리 생성 권한.
- **edb_dropdirectory_admin**: 임의 디렉터리 삭제 권한.
