# seq_page_cost — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › seq_page_cost](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/11_seq_page_cost/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Floating point

**기본값 (Default value):** 1

**범위 (Range):** 0 to 1.79769e+308

**효력의 최소 범위 (Minimum scope of effect):** Per session

**값 변경이 적용되는 시점 (When value changes take effect):** Immediate

**활성화에 필요한 권한 (Required authorization to activate):** Session user

일련의 순차적 페치(sequential fetch)의 일부인 디스크 페이지 페치 비용에 대한 플래너의 추정치를 설정합니다. 동일한 이름의 테이블스페이스 파라미터를 설정하여 특정 테이블스페이스에 대해 이 값을 재정의할 수 있습니다. PostgreSQL 코어 문서의 [`ALTER TABLESPACE`](https://www.postgresql.org/docs/current/sql-altertablespace.html)를 참조하십시오.

기본값은 캐싱이 거의 없다고 가정하므로, 이 값을 줄이는 것이 좋은 경우가 많습니다. 데이터베이스가 물리 메모리보다 상당히 크더라도, 이 파라미터를 기본값 1보다 낮은 값으로 설정하여 그렇게 함으로써 더 나은 쿼리 계획을 얻는지 시도해 보는 것이 좋을 수 있습니다. 데이터베이스가 전부 메모리에 들어간다면, 이 값을 훨씬 더 낮게, 예를 들어 0.1로 낮출 수 있습니다.
