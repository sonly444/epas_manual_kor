# 쿼리 튜닝/플래너 메서드 구성 (Query tuning/planner method configuration) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Query tuning/planner method configuration](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/05_query_tuning_planner_method_configuration/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

이 구성 파라미터들은 플래너 메서드 구성에 사용됩니다.

## enable_partition_pruning

**파라미터 타입:** Boolean
**기본값:** `false`
**범위:** `{true | false}`
**최소 적용 범위:** 세션별(Per session)
**값 변경 적용 시점:** 변경 즉시(Immediate)
**활성화에 필요한 권한:** 세션 사용자

쿼리 플래너가 파티션 테이블을 *조기 프루닝(early pruning)*할 수 있게 합니다. 조기 프루닝은 쿼리 플래너가 쿼리 계획을 생성하기 전에 쿼리에서 검색되지 않는 파티션을 "프룬"(즉, 무시)할 수 있음을 의미합니다. 이 설정은 검색되지 않는 파티션의 쿼리 계획 생성을 방지하므로 성능 향상에 도움이 됩니다.

반대로 *지연 프루닝(late pruning)*은 쿼리 플래너가 각 파티션에 대한 쿼리 계획을 생성한 후 파티션을 프루닝함을 의미합니다. `constraint_exclusion` 구성 파라미터가 지연 프루닝을 제어합니다.

조기 프루닝의 가능 여부는 `WHERE` 절의 쿼리 특성에 따라 달라집니다. 조기 프루닝은 `WHERE column = literal`(예: `WHERE deptno = 10`) 같은 제약 조건이 있는 단순 쿼리에서만 사용할 수 있습니다.

`WHERE column = expression`(예: `WHERE deptno = 10 + 5`) 같은 더 복잡한 쿼리에는 조기 프루닝을 사용하지 마십시오.
