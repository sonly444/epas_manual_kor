# 컨벤셔널 경로 로드로 테이블 업데이트 (Updating a table with a conventional path load) — EPAS 18

> 원문: [EPAS v18 — Database administration › EDB*Loader › Invoking EDB*Loader › Conventional path load](https://www.enterprisedb.com/docs/epas/latest/database_administration/02_edb_loader/invoking_edb_loader/conventional_path_load/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·컨트롤 파일·코드는 원문 그대로 보존했습니다.

EDB*Loader를 컨벤셔널 경로 로드(conventional path load)와 함께 사용하여 테이블의 행을 업데이트하고 새 데이터를 기존 데이터와 병합할 수 있습니다. 업데이트를 수행하기 위해 EDB*Loader를 호출하면 서버는 일치하는 기본 키를 가진 기존 행을 테이블에서 검색합니다.

- 서버가 일치하는 키를 가진 행을 찾으면 기존 행을 새 행으로 대체합니다.
- 서버가 일치하는 키를 가진 행을 찾지 못하면 새 행을 테이블에 추가합니다.

EDB*Loader로 테이블을 업데이트하려면 테이블에 기본 키가 있어야 합니다. 파티션 테이블은 EDB*Loader로 업데이트할 수 없습니다.

## 업데이트 수행

`UPDATE`를 수행하려면 컨벤셔널 경로 로드를 수행할 때와 동일한 단계를 사용합니다.

1. 업데이트 또는 삽입하려는 행을 포함하는 데이터 파일을 생성합니다.
2. `INFILE` 키워드를 사용하여 데이터 파일 이름을 지정하는 컨트롤 파일을 정의합니다. EDB*Loader 컨트롤 파일 작성에 대한 정보는 "EDB*Loader 컨트롤 파일 작성"을 참조하십시오.
3. 데이터베이스 이름, 연결 정보, 컨트롤 파일 이름을 지정하여 EDB*Loader를 호출합니다. EDB*Loader 호출에 대한 정보는 "EDB*Loader 호출"을 참조하십시오.

이 예는 EDB Postgres Advanced Server 샘플 데이터와 함께 배포되는 `emp` 테이블을 사용합니다. 기본적으로 테이블은 다음을 포함합니다.

```sql
edb=# select * from emp;
```

이 컨트롤 파일(`emp_update.ctl`)은 테이블의 필드를 쉼표로 구분된 목록으로 지정합니다. 컨트롤 파일은 `emp` 테이블에 `UPDATE`를 수행합니다.

```sql
LOAD DATA
  INFILE 'emp_update.dat'
  BADFILE 'emp_update.bad'
  DISCARDFILE 'emp_update.dsc'
UPDATE INTO TABLE emp
FIELDS TERMINATED BY ","
(empno, ename, job, mgr, hiredate, sal, comm, deptno)
```

업데이트 또는 삽입되는 데이터는 `emp_update.dat` 파일에 저장됩니다. `emp_update.dat`는 다음을 포함합니다.

```sql

```

데이터베이스 이름(`edb`), 데이터베이스 사용자와 연관된 비밀번호, 컨트롤 파일 이름(`emp_update.ctl`)을 지정하여 EDB*Loader를 호출합니다.

```shell
edbldr -d edb userid=user_name/password control=emp_update.ctl
```
