# 클론 프로세스 상태 확인 (Checking the status of the cloning process) — EPAS 18

> 원문: [EPAS v18 — Database administration › EDB Clone Schema › Checking status](https://www.enterprisedb.com/docs/epas/latest/database_administration/14_edb_clone_schema/checking_the_status/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·필드·코드·출력은 원문 그대로 보존했습니다.

`process_status_from_log` 함수는 클로닝 함수의 상태를 그 로그 파일에서 가져옵니다.

```sql
process_status_from_log (
  <log_file> TEXT
)
```

함수는 로그 파일에서 다음 필드를 반환합니다.

| 필드 이름 | 설명 |
|---|---|
| `status` | `STARTING`, `RUNNING`, `FINISH`, 또는 `FAILED` 중 하나를 표시합니다. |
| `execution_time` | 명령이 실행된 시각. 타임스탬프 형식으로 표시됩니다. |
| `pid` | 클론 스키마가 호출되는 세션 프로세스 ID. |
| `level` | `INFO` 또는 `ERROR` 중 하나를 표시합니다. |
| `stage` | `STARTUP`, `INITIAL`, `DDL-COLLECTION`, `PRE-DATA`, `DATA-COPY`, `POST-DATA`, 또는 `FINAL` 중 하나를 표시합니다. |
| `message` | 각 명령 또는 실패에 관한 정보. |

## 파라미터 (Parameters)

**`log_file`**
클로닝 함수가 호출될 때 지정된, 스키마 클로닝을 기록하는 로그 파일의 이름입니다.

## 예제 (Example)

다음은 `process_status_from_log` 함수의 사용을 보여줍니다.

```sql
edb=# SELECT edb_util.process_status_from_log('clone_edb_edbcopy');
```

출력

```text
                                      process_status_from_log
---------------------------------------------------------------------------------------------------
 (FINISH,"26-JUN-17 11:57:03.214458 -04:00",3691,INFO,"STAGE: FINAL","successfully cloned schema")
(1 row)
```
