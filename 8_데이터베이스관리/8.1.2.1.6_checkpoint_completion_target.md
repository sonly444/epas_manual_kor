# checkpoint_completion_target — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › checkpoint_completion_target](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/06_checkpoint_completion_target/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Floating point

**기본값 (Default value):** 0.5

**범위 (Range):** 0 to 1

**효력의 최소 범위 (Minimum scope of effect):** Cluster

**값 변경이 적용되는 시점 (When value changes take effect):** Reload

**활성화에 필요한 권한 (Required authorization to activate):** EDB Postgres Advanced Server service account

체크포인트 완료 목표를 체크포인트 사이의 전체 시간에 대한 비율로 지정합니다. 이 파라미터는 시스템이 다음 체크포인트를 향해 작업을 시작하는 동안 체크포인트 쓰기 작업을 분산시킵니다.

기본값 0.5는 다음 체크포인트의 50%가 준비되었을 때 체크포인트 쓰기를 완료하는 것을 목표로 합니다. 0.9의 값은 다음 체크포인트의 90%가 완료되었을 때 체크포인트 쓰기를 완료하는 것을 목표로 합니다. 이 값은 더 긴 시간에 걸쳐 체크포인트 쓰기를 조절(throttle)하여 성능 병목의 급증(spike)을 방지합니다.
