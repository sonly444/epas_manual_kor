# pg_prewarm.autoprewarm — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › pg_prewarm.autoprewarm](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/16_pg_prewarm.autoprewarm/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Boolean

**기본값 (Default value):** `true`

**범위 (Range):** `{true | false}`

**효력의 최소 범위 (Minimum scope of effect):** Cluster

**값 변경이 적용되는 시점 (When value changes take effect):** Restart

**활성화에 필요한 권한 (Required authorization to activate):** EDB Postgres Advanced Server service account

데이터베이스 서버가 `autoprewarm`을 실행할지 여부를 제어합니다. `autoprewarm`은 종료(shutdown) 전에 shared buffers를 디스크로 덤프하는 백그라운드 워커 프로세스입니다. 그런 다음 다음 번 서버 시작 시 shared buffers를 _prewarm_ 합니다. 즉, 디스크의 블록을 버퍼 풀(buffer pool)로 다시 로드합니다.

이 파라미터의 장점은 종료 전에 디스크로 덤프된 데이터를 로드함으로써 서버 재시작 후 워밍업(warmup) 시간을 단축한다는 점입니다.

`autoprewarm` 워커를 활성화하려면 `pg_prewarm.autoprewarm`을 on으로 설정하십시오. `autoprewarm`을 비활성화하려면 off로 설정하십시오.

`autoprewarm`을 사용하려면 먼저 다음 예제와 같이 `postgresql.conf` 파일의 `shared_preload_libraries` 구성 파라미터에 나열된 라이브러리에 `$libdir/pg_prewarm`을 추가해야 합니다.

```ini
shared_preload_libraries = '$libdir/dbms_pipe,$libdir/edb_gen,$libdir/dbms_aq,$libdir/pg_prewarm'
```

`shared_preload_libraries` 파라미터를 수정한 후 데이터베이스 서버를 재시작하십시오. 재시작 후, `autoprewarm` 백그라운드 워커는 서버가 일관된 상태에 도달한 직후 즉시 실행됩니다.

`autoprewarm` 프로세스는 버퍼 풀에 여유 버퍼 공간이 남지 않을 때까지 이전에 `$PGDATA/autoprewarm.blocks`에 기록된 블록을 로드하기 시작합니다. 이러한 방식으로, 복구 프로세스나 쿼리 클라이언트에 의해 로드된 새로운 블록은 대체되지 않습니다.

`autoprewarm` 프로세스가 디스크에서 버퍼 로드를 완료하면, `pg_prewarm.autoprewarm_interval` 파라미터에 지정된 간격으로 주기적으로 shared buffers를 디스크로 덤프합니다. 다음 서버 재시작 시, `autoprewarm` 프로세스는 마지막으로 디스크에 덤프된 블록으로 shared buffers를 prewarm합니다.

`autoprewarm` 백그라운드 워커에 대한 정보는 [pg_prewarm.autoprewarm_interval](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/17_pg_prewarm.autoprewarm_interval/#pg_prewarm_autoprewarm_interval)을 참조하십시오.
