# EDB*Loader 컨트롤 파일 예제 (Control File Examples) — EPAS 18

> 원문: [EPAS v18 — EDB*Loader › Building the control file › Control file examples](https://www.enterprisedb.com/docs/epas/latest/database_administration/02_edb_loader/building_the_control_file/control_file_examples/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·키워드·코드·데이터·출력은 원문 그대로 보존했습니다.

## 1. 구분자 분리 필드 데이터 파일 (Delimiter-separated field data file)

이 컨트롤 파일은 `emp` 테이블에 행을 추가하는 구분자 분리 데이터 파일을 사용합니다. `APPEND` 절로 `emp` 테이블에 추가 행 삽입을 허용합니다.

```
LOAD DATA
  INFILE 'emp.dat'
    BADFILE 'emp.bad'
  APPEND
  INTO TABLE emp
    FIELDS TERMINATED BY ',' OPTIONALLY ENCLOSED BY '"'
    TRAILING NULLCOLS
  (
    empno,
    ename,
    job,
    mgr,
    hiredate,
    sal,
    deptno,
    comm
  )
```

해당 구분자 분리 데이터 파일:
```
9101,ROGERS,CLERK,7902,17-DEC-10,1980.00,20
9102,PETERSON,SALESMAN,7698,20-DEC-10,2600.00,30,2300.00
9103,WARREN,SALESMAN,7698,22-DEC-10,5250.00,30,2500.00
9104,"JONES, JR.",MANAGER,7839,02-APR-09,7975.00,20
```

`TRAILING NULLCOLS` 절 덕분에 첫 번째와 마지막 레코드에서 `comm` 컬럼을 공급하는 마지막 필드를 생략할 수 있습니다. 이들 레코드에서 삽입된 행의 `comm` 컬럼은 null로 설정됩니다. 마지막 레코드의 값 `JONES, JR.`는 콤마 구분 문자가 필드 값의 일부이므로 큰따옴표로 감쌌습니다.

세션 후 테이블에 추가된 행 조회:
```
SELECT * FROM emp WHERE empno > 9100;
```
```
 empno| ename     | job     | mgr|   hiredate        | sal   | comm   |deptno
------+-----------+---------+----+-------------------+-------+--------+------
  9101| ROGERS    | CLERK   |7902| 17-DEC-10 00:00:00|1980.00|        |  20
  9102| PETERSON  | SALESMAN|7698| 20-DEC-10 00:00:00|2600.00| 2300.00|  30
  9103| WARREN    | SALESMAN|7698| 22-DEC-10 00:00:00|5250.00| 2500.00|  30
  9104| JONES, JR.| MANAGER |7839| 02-APR-09 00:00:00|7975.00|        |  20
(4 rows)
```

## 2. 고정 폭 필드 데이터 파일 (Fixed-width field data file)

이 컨트롤 파일은 동일한 행을 `emp` 테이블에 로드하되 고정 폭 필드를 담은 데이터 파일을 사용합니다. `FIELDS TERMINATED BY`·`OPTIONALLY ENCLOSED BY` 절이 없고, 대신 각 필드가 `POSITION` 절을 포함합니다.

```
LOAD DATA
  INFILE 'emp_fixed.dat'
    BADFILE 'emp_fixed.bad'
  APPEND
  INTO TABLE emp
    TRAILING NULLCOLS
  (
    empno POSITION (1:4),
    ename POSITION (5:14),
    job POSITION (15:23),
    mgr POSITION (24:27),
    hiredate POSITION (28:38),
    sal POSITION (39:46),
    deptno POSITION (47:48),
    comm POSITION (49:56)
  )
```

해당 고정 폭 필드 데이터 파일:
```
9101ROGERS    CLERK    790217-DEC-10    1980.0020
9102PETERSON  SALESMAN 769820-DEC-10    2600.0030 2300.00
9103WARREN    SALESMAN 769822-DEC-10    5250.0030 2500.00
9104JONES, JR.MANAGER  783902-APR-09    7975.0020
```

## 3. 단일 물리 레코드 데이터 파일 – RECORDS DELIMITED BY 절

이 컨트롤 파일은 동일한 행을 로드하되 하나의 물리 레코드를 담은 데이터 파일을 사용합니다. 테이블에 로드되는 각 레코드를 세미콜론(`;`)으로 종료하며, `RECORDS DELIMITED BY` 절이 이 값을 지정합니다.

```
LOAD DATA
  INFILE 'emp_recdelim.dat'
    BADFILE 'emp_recdelim.bad'
  APPEND
  INTO TABLE emp
    FIELDS TERMINATED BY ',' OPTIONALLY ENCLOSED BY '"'
    RECORDS DELIMITED BY ';'
    TRAILING NULLCOLS
  (
    empno,
    ename,
    job,
    mgr,
    hiredate,
    sal,
    deptno,
    comm
  )
```

해당 데이터 파일. 내용은 데이터 파일 내 단일 물리 레코드이며, 레코드 구분 문자가 마지막 레코드 뒤(즉 파일 끝)에 포함됩니다.
```
9101,ROGERS,CLERK,7902,17-DEC-10,1980.00,20,;9102,PETERSON,SALESMAN,7698,20-DEC-10,
2600.00,30,2300.00;9103,WARREN,SALESMAN,7698,22-DEC-10,5250.00,30,2500.00;9104,"JONES, 
JR.",MANAGER,7839,02-APR-09,7975.00,20,;
```

## 4. FILLER 절

이 컨트롤 파일은 `sal`·`comm` 컬럼의 데이터 필드에 `FILLER` 절을 사용합니다. EDB*Loader는 이 필드의 값을 무시하고 해당 컬럼을 null로 설정합니다.

```
LOAD DATA
  INFILE       'emp_fixed.dat'
    BADFILE    'emp_fixed.bad'
  APPEND
  INTO TABLE emp
    TRAILING NULLCOLS
  (
    empno       POSITION (1:4),
    ename       POSITION (5:14),
    job         POSITION (15:23),
    mgr         POSITION (24:27),
    hiredate    POSITION (28:38),
    sal         FILLER POSITION (39:46),
    deptno      POSITION (47:48),
    comm        FILLER POSITION (49:56)
  )
```

앞의 고정 폭 데이터 파일과 동일한 파일을 사용하면 테이블 결과 행은 다음과 같습니다(`sal`·`comm`이 null):
```
 empno| ename     | job     | mgr|   hiredate        | sal   | comm   |deptno
------+-----------+---------+----+-------------------+-------+--------+------
  9101| ROGERS    | CLERK   |7902| 17-DEC-10 00:00:00|       |        |  20
  9102| PETERSON  | SALESMAN|7698| 20-DEC-10 00:00:00|       |        |  30
  9103| WARREN    | SALESMAN|7698| 22-DEC-10 00:00:00|       |        |  30
  9104| JONES, JR.| MANAGER |7839| 02-APR-09 00:00:00|       |        |  20
(4 rows)
```

## 5. BOUNDFILLER 절

이 컨트롤 파일은 `job`·`mgr` 컬럼의 데이터 필드에 `BOUNDFILLER` 절을 사용합니다. EDB*Loader는 `FILLER`와 동일하게 이 필드 값을 무시하고 컬럼을 null로 설정합니다. 다만 `FILLER` 컬럼과 달리 `BOUNDFILLER` 컬럼은 `jobdesc` 컬럼처럼 표현식에 사용할 수 있습니다.

```
LOAD DATA
  INFILE    'emp.dat'
    BADFILE 'emp.bad'
  APPEND
  INTO TABLE empjob
    FIELDS TERMINATED BY ',' OPTIONALLY ENCLOSED BY '"'
    TRAILING NULLCOLS
  (
    empno,
    ename,
    job          BOUNDFILLER,
    mgr          BOUNDFILLER,
    hiredate     FILLER,
    sal          FILLER,
    deptno       FILLER,
    comm         FILLER,
    jobdesc      ":job || ' for manager ' || :mgr"
  )
```

이 예제에 사용된 구분자 분리 데이터 파일:
```
9101,ROGERS,CLERK,7902,17-DEC-10,1980.00,20
9102,PETERSON,SALESMAN,7698,20-DEC-10,2600.00,30,2300.00
9103,WARREN,SALESMAN,7698,22-DEC-10,5250.00,30,2500.00
9104,"JONES, JR.",MANAGER,7839,02-APR-09,7975.00,20
```

로드 대상 테이블:
```
CREATE TABLE empjob (
    empno               NUMBER(4) NOT NULL CONSTRAINT empjob_pk PRIMARY KEY,
    ename               VARCHAR2(10),
    job                 VARCHAR2(9),
    mgr                 NUMBER(4),
    jobdesc             VARCHAR2(25)
);
```

결과 행:
```
 empno |    ename   | job | mgr |         jobdesc
-------+------------+-----+-----+---------------------------
 9101  | ROGERS     |     |     | CLERK for manager 7902
 9102  | PETERSON   |     |     | SALESMAN for manager 7698
 9103  | WARREN     |     |     | SALESMAN for manager 7698
 9104  | JONES, JR. |     |     | MANAGER for manager 7839
(4 rows)
```

## 6. 길이 지정이 있는 필드 타입 (Field types with length specification)

이 컨트롤 파일은 길이 지정이 있는 필드 타입 절을 포함합니다.
```
LOAD DATA
  INFILE 'emp_fixed.dat'
    BADFILE 'emp_fixed.bad'
  APPEND
  INTO TABLE emp
    TRAILING NULLCOLS
  (
    empno       CHAR(4),
    ename       CHAR(10),
    job         POSITION (15:23) CHAR(9),
    mgr         INTEGER EXTERNAL(4),
    hiredate    DATE(11) "DD-MON-YY",
    sal         DECIMAL EXTERNAL(8),
    deptno      POSITION (47:48),
    comm        POSITION (49:56) DECIMAL EXTERNAL(8)
  )
```
> **참고**: 각 필드 정의가 `POSITION` 절과 `fieldtype(length)` 절 중 최소 하나를 포함하는 한, 두 절을 독립적으로 또는 함께 적용할 수 있습니다.

## 7. NULLIF 절

이 예제는 `sal` 컬럼에 `NULLIF` 절을 사용하여 직무가 `MANAGER`인 직원의 값을 null로 설정합니다. 또한 `comm` 컬럼에 이 절을 사용하여 직원이 `SALESMAN`이 아니고 부서 `30` 소속도 아니면 null로 설정합니다. 즉 직원이 `SALESMAN`이거나 부서 `30` 소속이면 `comm` 값을 받아들입니다.

컨트롤 파일:
```
LOAD DATA
  INFILE    'emp_fixed_2.dat'
    BADFILE 'emp_fixed_2.bad'
  APPEND
  INTO TABLE emp
    TRAILING NULLCOLS
  (
    empno       POSITION (1:4),
    ename       POSITION (5:14),
    job         POSITION (15:23),
    mgr         POSITION (24:27),
    hiredate    POSITION (28:38),
    sal         POSITION (39:46) NULLIF job = 'MANAGER',
    deptno      POSITION (47:48),
    comm        POSITION (49:56) NULLIF job <> 'SALESMAN' AND deptno <> '30'
  )
```

해당 데이터 파일:
```
9101ROGERS       CLERK        790217-DEC-10     1980.0020
9102PETERSON     SALESMAN     769820-DEC-10     2600.0030     2300.00
9103WARREN       SALESMAN     769822-DEC-10     5250.0030     2500.00
9104JONES, JR.   MANAGER      783902-APR-09     7975.0020
9105ARNOLDS      CLERK        778213-SEP-10     3750.0030     800.00
9106JACKSON      ANALYST      756603-JAN-11     4500.0040     2000.00
9107MAXWELL      SALESMAN     769820-DEC-10     2600.0010     1600.00
```

결과 행:
```
SELECT empno, ename, job, NVL(TO_CHAR(sal),'--null--') "sal",
  NVL(TO_CHAR(comm),'--null--') "comm", deptno FROM emp WHERE empno > 9100;
```
```
 empno |   ename    |    job   |   sal    |   comm   | deptno
-------+------------+----------+----------+----------+-------
  9101 | ROGERS     | CLERK    | 1980.00  | --null-- |   20
  9102 | PETERSON   | SALESMAN | 2600.00  | 2300.00  |   30
  9103 | WARREN     | SALESMAN | 5250.00  | 2500.00  |   30
  9104 | JONES, JR. | MANAGER  | --null-- | --null-- |   20
  9105 | ARNOLDS    | CLERK    | 3750.00  |  800.00  |   30
  9106 | JACKSON    | ANALYST  | 4500.00  | --null-- |   40
  9107 | MAXWELL    | SALESMAN | 2600.00  | 1600.00  |   10
(7 rows)
```
> **참고**: 직원 `JONES, JR.`의 `sal` 컬럼은 직무가 `MANAGER`이므로 null입니다. `PETERSON`, `WARREN`, `ARNOLDS`, `MAXWELL`의 `comm` 값은 이들이 `SALESMAN`이거나 부서 `30` 소속이므로 `emp` 테이블의 `comm` 컬럼에 로드됩니다. 직원 `JACKSON`의 데이터 파일 `comm` 값 `2000.00`은 무시되고 `comm` 컬럼이 null로 설정됩니다. 이 직원은 `SALESMAN`도 부서 `30` 소속도 아니기 때문입니다.

## 8. 필드 표현식 내 SELECT 문 (SELECT statement in a field expression)

이 예제는 필드 정의의 표현식에 `SELECT` 문을 사용하여 컬럼에 로드할 값을 반환합니다.
```
LOAD DATA
  INFILE    'emp_fixed.dat'
    BADFILE 'emp_fixed.bad'
  APPEND
  INTO TABLE emp
    TRAILING NULLCOLS
  (
    empno       POSITION (1:4),
    ename       POSITION (5:14),
    job         POSITION (15:23) "(SELECT dname FROM dept WHERE deptno = :deptno)",
    mgr         POSITION (24:27),
    hiredate    POSITION (28:38),
    sal         POSITION (39:46),
    deptno      POSITION (47:48),
    comm        POSITION (49:56)
  )
```

`SELECT` 문에 사용된 `dept` 테이블 내용:
```
 deptno |    dname   |   loc
---------+------------+---------
   10   | ACCOUNTING | NEW YORK
   20   | RESEARCH   | DALLAS
   30   | SALES      | CHICAGO
   40   | OPERATIONS | BOSTON
(4 rows)
```

해당 데이터 파일:
```

9102PETERSON   SALESMAN  769820-DEC-10    2600.0030   2300.00
9103WARREN     SALESMAN  769822-DEC-10    5250.0030   2500.00
9104JONES, JR. MANAGER   783902-APR-09    7975.0020
```

결과 행:
```

------+-----------+---------+----+-------------------+-------+--------+------
  9101| ROGERS    | RESEARCH|7902| 17-DEC-10 00:00:00|1980.00|        |  20
```

## 9. 다중 INTO TABLE 절 (Multiple INTO TABLE clauses)

이 예제는 여러 `INTO TABLE` 절을 사용합니다. `emp` 테이블과 동일한 데이터 정의를 가진 두 개의 빈 테이블을 만듭니다(원본 `emp` 행은 삽입하지 않음).
```
CREATE TABLE emp_research AS SELECT * FROM emp WHERE deptno = 99;
CREATE TABLE emp_sales AS SELECT * FROM emp WHERE deptno = 99;
```

이 컨트롤 파일은 두 개의 `INTO TABLE` 절을 담습니다. `APPEND` 절이 없으므로 기본 동작 `INSERT`를 사용합니다. 이 동작에서는 `emp_research`·`emp_sales` 테이블이 비어 있어야 합니다.
```
LOAD DATA
  INFILE        'emp_multitbl.dat'
    BADFILE     'emp_multitbl.bad'
    DISCARDFILE 'emp_multitbl.dsc'
  INTO TABLE emp_research
    WHEN (47:48) = '20'
    TRAILING NULLCOLS
  (
    empno      POSITION (1:4),
    ename      POSITION (5:14),
    job        POSITION (15:23),
    mgr        POSITION (24:27),
    hiredate   POSITION (28:38),
    sal        POSITION (39:46),
    deptno     CONSTANT '20',
    comm       POSITION (49:56)
  )
  INTO TABLE emp_sales
    WHEN (47:48) = '30'
    TRAILING NULLCOLS
  (
    empno     POSITION (1:4),
    ename     POSITION (5:14),
    job       POSITION (15:23),
    mgr       POSITION (24:27),
    hiredate  POSITION (28:38),
    sal       POSITION (39:46),
    deptno    CONSTANT '30',
    comm      POSITION (49:56) "ROUND(:comm + (:sal * .25), 0)"
  )
```

`WHEN` 절은 47~48 컬럼으로 지정된 필드가 `20`을 담으면 레코드를 `emp_research` 테이블에, `30`을 담으면 `emp_sales` 테이블에 삽입하도록 지정합니다. 두 조건 모두 참이 아니면 레코드는 discard 파일 `emp_multitbl.dsc`에 기록됩니다. `deptno` 컬럼에 `CONSTANT` 절이 주어져 각 레코드마다 지정된 상수 값이 `deptno`에 삽입됩니다. `CONSTANT` 절을 사용할 때는 상수 값이 할당되는 컬럼 이름 외에 필드 정의의 유일한 절이어야 합니다. `emp_sales` 테이블의 `comm` 컬럼에는 SQL 표현식이 할당됩니다. 표현식은 컬럼 이름 앞에 콜론(`:`)을 붙여 참조할 수 있습니다.

해당 데이터 파일:
```
9101ROGERS     CLERK     790217-DEC-10   1980.0020
9102PETERSON   SALESMAN  769820-DEC-10   2600.0030  2300.00
9103WARREN     SALESMAN  769822-DEC-10   5250.0030  2500.00
9104JONES, JR. MANAGER   783902-APR-09   7975.0020
9105ARNOLDS    CLERK     778213-SEP-10   3750.0010
9106JACKSON    ANALYST   756603-JAN-11   4500.0040
```

`ARNOLDS`·`JACKSON` 레코드는 47~48 컬럼에 `10`·`40`을 담아 어떤 `WHEN` 절도 만족하지 않으므로 discard 파일 `emp_multitbl.dsc`에 기록됩니다:
```
9105ARNOLDS   CLERK     778213-SEP-10   3750.0010
9106JACKSON   ANALYST   756603-JAN-11   4500.0040
```

`emp_research`·`emp_sales` 테이블에 로드된 행:
```

```
```
empno  |   ename    |   job   |  mgr |      hiredate      |   sal   | comm | deptno
-------+------------+---------+------+--------------------+---------+------+-------
 9101  | ROGERS     | CLERK   | 7902 | 17-DEC-10 00:00:00 | 1980.00 |      | 20.00
 9104  | JONES, JR. | MANAGER | 7839 | 02-APR-09 00:00:00 | 7975.00 |      | 20.00
(2 rows)
```
```

```
```
empno  |   ename  |    job   |  mgr |       hiredate     |    sal  |   comm  | deptno
-------+----------+----------+------+--------------------+---------+---------+--------
 9102  | PETERSON | SALESMAN | 7698 | 20-DEC-10 00:00:00 | 2600.00 | 2950.00 | 30.00
 9103  | WARREN   | SALESMAN | 7698 | 22-DEC-10 00:00:00 | 5250.00 | 3813.00 | 30.00
(2 rows)
```
