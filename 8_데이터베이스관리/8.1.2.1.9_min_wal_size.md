# min_wal_size — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › min_wal_size](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/09_min_wal_size/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Integer

**기본값 (Default value):** 80 MB

**범위 (Range):** 2 to 2147483647

**효력의 최소 범위 (Minimum scope of effect):** Cluster

**값 변경이 적용되는 시점 (When value changes take effect):** Reload

**활성화에 필요한 권한 (Required authorization to activate):** EDB Postgres Advanced Server service account

WAL 디스크 사용량이 `min_wal_size`로 지정된 값 아래로 유지되면, 오래된 WAL 파일은 체크포인트에서 제거되는 대신 향후 사용을 위해 재활용됩니다. 이 기능은 대규모 배치 작업을 실행할 때와 같이 WAL 사용량의 급증(spike)을 처리하기에 충분한 WAL 공간이 예약되도록 보장합니다. 이 파라미터는 `postgresql.conf` 파일이나 서버 명령줄에서 설정할 수 있습니다.
