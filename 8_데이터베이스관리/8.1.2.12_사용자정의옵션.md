# 사용자 정의 옵션 (Customized options) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Customized options](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/12_customized_options/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

이 페이지는 EDB Postgres Advanced Server 내의 특수 기능을 활성화하는 구성 파라미터를 다룹니다. Oracle 호환 기능과 EDB 전용 확장에 대한 구성 설정입니다.

## custom_variable_classes
버전 9.2부터 더 이상 사용되지 않음(deprecated). 애드온 모듈에 더 이상 필요하지 않습니다.

## dbms_alert.max_alerts
Integer 파라미터(기본값: 100, 범위 0~500). DBMS_ALERTS 패키지를 통한 동시 알림(alert)을 제어합니다. 변경 적용에 클러스터 수준 재시작 필요.

## dbms_pipe.total_message_buffer
Integer 파라미터(기본값: 30 KB, 범위 30~256 KB). DBMS_PIPE 패키지의 버퍼 크기를 지정합니다. 적용에 재시작 필요.

## edb_sql_protect.enabled
Boolean 파라미터(기본값: false). 보호된 역할에 대한 SQL/Protect 모니터링을 활성화합니다. reload 후 적용.

## edb_sql_protect.level
열거형 파라미터로 값은 learn, passive, active. 모니터링 동작 제어: learn 모드는 활동을 추적, passive 모드는 위반을 경고, active 모드는 유효하지 않은 문을 차단.

## edb_sql_protect.max_protected_relations
Integer 파라미터(기본값: 1024). 역할당 보호되는 릴레이션 수를 제한. 재시작 필요; 시작 시 공유 메모리 예약.

## edb_sql_protect.max_protected_roles
Integer 파라미터(기본값: 64). 보호 가능한 최대 역할 수를 설정. 재시작 필요; 시작 중 공유 메모리 할당.

## edb_sql_protect.max_queries_to_save
Integer 파라미터(기본값: 5000, 범위 100~2147483647). edb_sql_protect_queries 뷰에 저장되는 위반 쿼리 수를 결정. 재시작 필요.

## edb_wait_states.directory
String 파라미터. wait states의 로그 파일 저장 위치를 지정(기본값: edb_wait_states, $PGDATA/edb_wait_states 생성). 재시작 필요.

## edb_wait_states.retention_period
Integer 파라미터(기본값: 604800초/7일, 범위 86400초~2147483647초). wait state 로그 보존을 제어. reload 후 적용.

## edb_wait_states.sampling_interval
Integer 파라미터(기본값: 1초). wait states 모니터링의 샘플링 빈도를 설정. reload 가능.

## edbldr.empty_csv_field
열거형 파라미터(NULL, empty_string, pgsql). EDB*Loader가 빈 필드를 처리하는 방식을 결정. 세션별 범위, 즉시 적용.

## utl_encode.uudecode_redwood
Boolean 파라미터. true이면 Oracle 호환 uudecoding을 활성화. 세션 수준, 즉시 적용.

## utl_file.umask
String 파라미터(기본값: 0077). UTL_FILE 패키지 함수의 파일 생성 권한을 설정. Windows에서 미지원; 세션별, 즉시 적용.
