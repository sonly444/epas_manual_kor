# 쿼리 튜닝 (Query tuning) — EPAS 18

> 원문: [EPAS v18 — Database administration › Configuration parameters by functionality › Query tuning](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/04_query_tuning/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

이 페이지는 EDB Postgres Advanced Server의 옵티마이저 힌트(optimizer hints)를 위해 특별히 설계된 구성 파라미터를 다룹니다.

## enable_hints

**파라미터 타입:** Boolean
**기본값:** `true`
**범위:** `{true | false}`
**최소 적용 범위:** 세션별(Per session)
**값 변경 적용 시점:** 변경 즉시(Immediate)
**활성화에 필요한 권한:** 세션 사용자

이 파라미터는 데이터베이스가 SQL 명령에 포함된 옵티마이저 힌트를 인식할지 여부를 제어합니다. 이 파라미터가 off이면 옵티마이저 힌트는 무시됩니다.

> 참고: 옵티마이저 힌트에 대한 추가 정보는 문서의 애플리케이션 프로그래밍 섹션에서 확인할 수 있습니다.
