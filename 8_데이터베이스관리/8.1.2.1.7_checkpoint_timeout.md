# checkpoint_timeout — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › checkpoint_timeout](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/07_checkpoint_timeout/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Integer

**기본값 (Default value):** 5min

**범위 (Range):** 30s to 3600s

**효력의 최소 범위 (Minimum scope of effect):** Cluster

**값 변경이 적용되는 시점 (When value changes take effect):** Reload

**활성화에 필요한 권한 (Required authorization to activate):** EDB Postgres Advanced Server service account

자동 WAL 체크포인트 사이의 최대 시간(초 단위)입니다. 이 파라미터를 증가시키면 크래시 복구에 필요한 시간이 늘어날 수 있습니다.

`checkpoint_timeout`을 15분과 같이 더 큰 값으로 증가시키면, 특히 `shared_buffers`에 큰 값을 사용할 때 시스템의 I/O 부하를 줄일 수 있습니다.

체크포인트 파라미터에 이러한 조정을 가할 때의 단점은 시스템이 약간의 추가 디스크 공간을 사용하고 크래시 발생 시 복구하는 데 더 오래 걸린다는 점입니다. 그러나 대부분의 사용자에게 이는 상당한 성능 향상을 위해 감수할 가치가 있습니다.
