# shared_buffers — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › shared_buffers](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/01_shared_buffers/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Integer

**기본값 (Default value):** 128MB

**범위 (Range):** 128kB to system dependent

**효력의 최소 범위 (Minimum scope of effect):** Cluster

**값 변경이 적용되는 시점 (When value changes take effect):** Restart

**활성화에 필요한 권한 (Required authorization to activate):** EDB Postgres Advanced Server service account

데이터베이스 서버가 공유 메모리 버퍼에 사용하는 메모리의 양을 설정합니다. 기본값은 일반적으로 128MB이지만, `initdb` 실행 시 판별되는 커널 설정이 이를 지원하지 않는 경우 더 작을 수 있습니다. 이 설정은 최소한 128kB 이상이어야 합니다. (`BLCKSZ`의 기본값이 아닌 값은 이 최솟값을 변경합니다.) 그러나 좋은 성능을 위해서는 일반적으로 최솟값보다 상당히 높은 설정이 필요합니다.

1GB 이상의 RAM을 갖춘 전용 데이터베이스 서버가 있다면, `shared_buffers`의 합리적인 시작 값은 시스템 메모리의 25%입니다. 일부 워크로드에서는 `shared_buffers`에 대한 큰 설정값도 효과적입니다. 그러나 EDB Postgres Advanced Server는 운영 체제 캐시에도 의존하기 때문에, RAM의 40%를 초과하여 `shared_buffers`에 할당하더라도 더 작은 양보다 더 나은 성능을 낼 가능성은 낮습니다.

1GB 미만의 RAM을 가진 시스템에서는 운영 체제를 위한 공간을 남겨두기 위해 RAM의 더 작은 비율이 적절합니다. 이러한 상황에서는 메모리의 15%가 더 일반적입니다. 또한 Windows에서는 `shared_buffers`에 대한 큰 값이 그다지 효과적이지 않습니다. 설정값을 비교적 낮게 유지하고 대신 운영 체제 캐시를 더 많이 사용하는 것이 더 나은 결과를 낼 수 있습니다. Windows 시스템에서 `shared_buffers`의 유용한 범위는 일반적으로 64MB에서 512MB입니다.

이 파라미터를 증가시키면 EDB Postgres Advanced Server가 운영 체제의 기본 구성이 허용하는 것보다 더 많은 System V 공유 메모리를 요청하게 될 수 있습니다. 해당 파라미터를 조정하는 방법에 대한 정보는 PostgreSQL 코어 문서의 [Shared Memory and Semaphores](https://www.postgresql.org/docs/15/kernel-resources.html#SYSVIPC)를 참조하십시오.

### 동적 튜닝 참고

위 기본값은 해당 파라미터가 명시적으로 설정되지 않고 `edb_dynatune`의 영향을 받지 않을 때 적용되는 내부 기본값입니다. `edb_dynatune`이 활성화된 환경에서는 서버의 메모리, CPU 자원 및 `edb_dynatune_profile`에 따라 실제 적용값이 달라질 수 있습니다. 명시적으로 설정된 값은 동적 튜닝으로 계산된 값을 재정의합니다.

`edb_dynatune`은 다음 파라미터를 자동 조정할 수 있습니다.

- `shared_buffers`
- `work_mem`
- `maintenance_work_mem`
- `effective_cache_size`
- `random_page_cost`
- `max_connections`
