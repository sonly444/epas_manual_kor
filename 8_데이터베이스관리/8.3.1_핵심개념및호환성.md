> 상위: # EDB*Loader — EPAS 18 Database Administration

## 1. 핵심 개념 및 호환성 (Key concepts and compatibility)

> 원문: [edb_loader_overview_and_restrictions](https://www.enterprisedb.com/docs/epas/latest/database_administration/02_edb_loader/edb_loader_overview_and_restrictions/)

### 주요 기능 (Key features)
EDB*Loader 기능:
- Oracle SQL*Loader 데이터 로딩 방식 지원(일반 경로 로드, 직접 경로 로드, 병렬 직접 경로 로드).
- Oracle SQL*Loader와 호환되는 컨트롤 파일 지시자 구문.
- 구분자로 분리된(delimiter-separated) 또는 고정 폭(fixed-width) 필드의 입력 데이터.
- 거부된 레코드를 수집하는 bad 파일.
- 여러 대상 테이블 로딩.
- 어떤 대상 테이블의 선택 기준도 만족하지 않는 레코드를 수집하는 discard 파일.
- EDB*Loader 세션과 오류 메시지를 기록하는 log 파일.
- 표준 입력(standard input)으로부터의 데이터 로딩 및 원격 로딩. 원격 호스트의 대용량 데이터 소스에 특히 유용.

### 버전 호환성 제한 (Version compatibility restrictions)
EDB*Loader 클라이언트와 데이터베이스 서버 간 중요한 버전 호환성 제한:
- EDB*Loader 프로그램(`edbldr`)을 호출하면 파라미터와 지시자 정보를 데이터베이스 서버로 전달합니다. 사용 중인 EDB Postgres Advanced Server 버전에 제공된 `edbldr` 프로그램(EDB*Loader 클라이언트) 버전을 사용하여 데이터베이스 서버로만 데이터를 로드할 것을 강력히 권장합니다. 일반적으로 EDB*Loader 클라이언트와 데이터베이스 서버는 동일 버전을 사용하십시오.
- PgPool-II, PgBouncer 같은 연결 풀러(connection pooler)와 함께 EDB*Loader를 사용하는 것은 지원되지 않습니다. EDB*Loader는 EDB Postgres Advanced Server에 직접 연결해야 합니다. 대안으로 연결 풀러를 통해 데이터를 로드하려면 다음 명령을 사용할 수 있습니다.
  ```
  psql \copy
  jdbc copyIn
  psycopg2 copy_from
  ```
