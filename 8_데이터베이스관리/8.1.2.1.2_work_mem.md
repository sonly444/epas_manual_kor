# work_mem — EPAS 18 데이터베이스 관리

> 원문: [EPAS v18 — Database administration › Configuration parameters › Top performance-related parameters › work_mem](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/02_work_mem/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·파라미터 이름은 원문 그대로 보존했습니다.

**파라미터 타입 (Parameter type):** Integer

**기본값 (Default value):** 1MB

**범위 (Range):** 64kB to 2097151kB

**효력의 최소 범위 (Minimum scope of effect):** Per session

**값 변경이 적용되는 시점 (When value changes take effect):** Immediate

**활성화에 필요한 권한 (Required authorization to activate):** Session user

임시 디스크 파일에 쓰기 전에 내부 정렬 작업과 해시 테이블이 사용할 메모리의 양을 지정합니다.

복잡한 쿼리의 경우, 여러 개의 정렬 또는 해시 작업이 병렬로 실행될 수 있습니다. 각 작업은 임시 파일에 데이터를 쓰기 시작하기 전에 이 값이 지정하는 만큼의 메모리를 사용할 수 있습니다. 또한 여러 실행 중인 세션이 이러한 작업을 동시에 수행할 수 있습니다. 따라서 사용되는 총 메모리는 `work_mem` 값의 여러 배가 될 수 있습니다. 값을 선택할 때 이 정보를 염두에 두십시오.

정렬 작업은 `ORDER BY`, `DISTINCT`, 그리고 병합 조인(merge join)에 사용됩니다. 해시 테이블은 해시 조인, 해시 기반 집계, 그리고 `IN` 서브쿼리의 해시 기반 처리에 사용됩니다.

합리적인 값은 일반적으로 4MB에서 64MB 사이이며, 이는 사용자의 머신 크기, 예상하는 동시 연결 수(`max_connections`로 결정됨), 그리고 쿼리의 복잡도에 따라 달라집니다.
