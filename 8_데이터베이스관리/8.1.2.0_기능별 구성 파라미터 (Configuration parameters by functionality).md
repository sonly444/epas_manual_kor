# 기능별 구성 파라미터 (Configuration parameters by functionality) — EPAS 18

> 원문: [EPAS v18 — Database administration › Setting configuration parameters › Configuration parameters by functionality](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/)
> EPAS v18 공식 문서의 한글 **전문 번역** 인덱스입니다. 아래 15개 하위 그룹을 개별 리프로 전문 번역했습니다.

이 절은 EDB Postgres Advanced Server 구성 파라미터를 기능 그룹별로 조직합니다. 각 리프는 해당 그룹의 EDB 관련 파라미터를 상세히 설명합니다.

## 목록 (15)
1. 최상위 성능 관련 파라미터 (Top performance-related parameters)
2. 리소스 사용/메모리 (Resource usage/memory)
3. 리소스 사용/EDB Resource Manager
4. 쿼리 튜닝 (Query tuning)
5. 쿼리 튜닝/플래너 메서드 구성 (Query tuning/planner method configuration)
6. 보고 및 로깅/로그할 내용 (Reporting and logging/what to log)
7. 감사 설정 (Auditing settings)
8. 클라이언트 연결 기본값/로케일 및 서식 (Client connection defaults/locale and formatting)
9. 클라이언트 연결 기본값/문 동작 (Client connection defaults/statement behavior)
10. 클라이언트 연결 기본값/기타 기본값 (Client connection defaults/other defaults)
11. 호환성 옵션 (Compatibility options)
12. 사용자 정의 옵션 (Customized options)
13. 미분류 구성 파라미터 (Ungrouped configuration parameters)
14. 감사 아카이빙 파라미터 (Audit archiving parameters)
15. 파라미터 속성 설명 (Description of parameter attributes)
