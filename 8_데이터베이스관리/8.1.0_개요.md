# 데이터베이스 관리 (Database administration) — EPAS 18

> 원문: [EPAS v18 — Database administration](https://www.enterprisedb.com/docs/epas/latest/database_administration/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 EDB Postgres Advanced Server 데이터베이스를 유지 관리하고, 보안을 유지하며, 운영하는 데 도움이 되는 기능을 포함합니다.

## 하위 항목 (In this section)

### [구성 파라미터 설정 (Setting configuration parameters)](https://www.enterprisedb.com/docs/epas/latest/database_administration/01_configuration_parameters/)

데이터베이스 서버의 동작과 환경을 제어하는 구성 파라미터를 설정하는 방법

### [EDB Resource Manager](https://www.enterprisedb.com/docs/epas/latest/database_administration/10_edb_resource_manager/)

EDB Resource Manager를 사용하여 EDB Postgres Advanced Server 프로세스가 사용하는 운영체제 리소스의 사용을 제어하는 방법

### [EDB\*Loader](https://www.enterprisedb.com/docs/epas/latest/database_administration/02_edb_loader/)

고성능 대량 데이터 로더인 EDB\*Loader를 사용하는 방법

### [EDB Clone Schema](https://www.enterprisedb.com/docs/epas/latest/database_administration/14_edb_clone_schema/)

EDB Clone Schema 모듈을 사용하여 소스 데이터베이스의 스키마와 그 데이터베이스 객체를 대상 데이터베이스로 복사하는 방법

### [사전 정의된 롤 (Predefined roles)](https://www.enterprisedb.com/docs/epas/latest/database_administration/roles/)
