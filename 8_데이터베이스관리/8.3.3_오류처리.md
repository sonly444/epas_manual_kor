## 3. 오류 처리 (Error handling)

> 원문: [using_edb_loader](https://www.enterprisedb.com/docs/epas/latest/database_administration/02_edb_loader/using_edb_loader/)

EDB*Loader는 단일 또는 멀티바이트 문자셋의 구분자 분리 또는 고정 폭 필드 데이터 파일을 처리합니다. 각 EDB*Loader 세션은 단일의 독립적인 트랜잭션으로 실행됩니다.

로딩 중 오류가 발생하면 두 범주로 구분합니다.

**서식 오류(Formatting errors)** — 일반적으로 트랜잭션을 중단시키지 않습니다. 서식 문제가 있는 레코드는 bad 파일에 기록되고 설명은 log 파일에 나타납니다. 예:
- 숫자 컬럼에 비숫자 값을 로드.
- 컬럼 용량을 초과하는 숫자 값.
- 최대 길이를 초과하는 문자 값.
- 부적절하게 서식된 날짜 값.

**데이터베이스 무결성 오류(Database integrity errors)** — 트랜잭션 롤백을 유발합니다. 문제가 된 레코드는 bad 파일로, 상세는 log 파일로 갑니다. 예:
- 고유 제약 위반(기본 키, 고유 인덱스).
- 참조 무결성 제약 위반.
- 검사(check) 제약 위반.
- 행 삽입 중 트리거가 생성한 오류.

**Oracle과의 핵심 차이**: EDB*Loader는 데이터베이스 무결성 오류가 롤백을 유발한다는 점에서 Oracle SQL*Loader와 다릅니다. Oracle 버전은 문제 레코드만 거부하고 이전에 삽입된 데이터는 유지하며 작업을 계속합니다.
