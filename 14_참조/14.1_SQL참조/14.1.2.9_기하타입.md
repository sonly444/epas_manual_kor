# 기하 타입 (Geometric types) — EPAS 18 데이터 타입

> 원문: [EPAS v18 — Reference › SQL reference › Data types › Geometric types](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/02_data_types/geometric_types/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입·형식은 원문 그대로 보존했습니다.

이 문서는 EDB Postgres Advanced Server에서 "2차원 공간 객체"를 표현하기 위해 사용할 수 있는 여덟 가지 기하 데이터 타입을 설명합니다.

## 데이터 타입 개요

지원되는 기하 타입은 다음과 같습니다.

- **POINT**: 평면 위의 점을 16바이트로 저장하며 `(x,y)` 형식입니다.
- **LINE**: 무한 직선을 32바이트로 나타내며 `{A,B,C}`로 표시됩니다.
- **LSEG**: 유한 선분(line segment)으로 32바이트가 필요하며 `((x1,y1),(x2,y2))`로 표시됩니다.
- **BOX**: 직사각형 상자로 32바이트를 사용하며 `((x1,y1),(x2,y2))`로 표현됩니다.
- **PATH**: 두 가지 변형이 존재합니다 — 닫힌 경로(closed path, 16 + 16n 바이트, `((x1,y1),...)`로 표시)와 열린 경로(open path, 16 + 16n 바이트, `[(x1,y1),...]`로 표시).
- **POLYGON**: 닫힌 경로와 유사하며 40 + 16n 바이트의 저장 공간이 필요하고 `((x1,y1),...)` 형식입니다.
- **CIRCLE**: 원 모양으로 24바이트를 사용하며 중심과 반지름을 나타내기 위해 `<(x,y),r>`로 표현됩니다.

모든 기하 타입은 시스템의 네이티브 타입이며 별칭이 없습니다. 이 데이터 타입에 대한 추가 정보는 PostgreSQL 공식 문서를 참조하십시오.
