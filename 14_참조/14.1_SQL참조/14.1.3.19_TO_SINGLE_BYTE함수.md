# TO_SINGLE_BYTE 함수 (TO_SINGLE_BYTE function) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › TO_SINGLE_BYTE function](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/to_single_byte/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·코드·출력은 원문 그대로 보존했습니다.

`TO_SINGLE_BYTE`는 모든 멀티바이트 문자를 해당하는 단일 바이트 문자로 변환한 char를 반환합니다. char는 `CHAR`, `VARCHAR2`, `NCHAR`, 또는 `NVARCHAR2` 데이터 타입일 수 있습니다. 반환 값은 char와 동일한 데이터 타입입니다.

단일 바이트 등가물이 없는 char의 멀티바이트 문자는 출력에 멀티바이트 문자로 나타납니다. 이 함수는 데이터베이스 문자 집합이 단일 바이트 문자와 멀티바이트 문자를 포함하는 경우에 적용됩니다.

## 예제

```sql
SELECT to_single_byte('ＡＢＣ＆１２３') FROM dual;
```

출력:
```
 to_single_byte
----------------
 ABC&123
(1 row)
```

```sql
SELECT octet_length('Ａ') FROM dual;
```
출력: `3`

```sql
SELECT octet_length(to_single_byte('Ａ')) FROM dual;
```
출력: `1`

```sql
SELECT bit_length(to_single_byte('Ａ')) FROM dual;
```
출력: `8`

```sql
SELECT ascii(to_single_byte('Ａ')) FROM dual;
```
출력: `65`

```sql
SELECT to_hex(ascii(to_single_byte('Ａ'))) FROM dual;
```
출력: `41`

```sql
SELECT TO_SINGLE_BYTE( CHR(65313)) FROM dual;
```
출력: `A`
