# LIKE 연산자를 사용한 패턴 매칭 (Pattern matching using the LIKE operator) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Pattern matching using the LIKE operator](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/06_pattern_matching_using_the_like_operator/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 연산자·구문·코드는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 전통적인 SQL `LIKE` 연산자를 통해 다음 구문으로 패턴 매칭을 제공합니다.

```sql
string LIKE pattern [ ESCAPE escape-character ]
string NOT LIKE pattern [ ESCAPE escape-character ]
```

## LIKE의 동작 방식

`LIKE` 표현식은 문자열이 패턴과 일치하면 `TRUE`를 반환하고, `NOT LIKE`는 반대 결과를 반환합니다. 패턴에 특수 문자가 없으면 동등성 검사처럼 동작합니다.

## 패턴 매칭 문자

- **언더스코어(_)**: 임의의 단일 문자와 일치
- **퍼센트 기호(%)**: 0개 이상의 임의 문자 시퀀스와 일치

### 예제 패턴

```sql
'abc' LIKE 'abc'    true
'abc' LIKE 'a%'     true
'abc' LIKE '_b_'    true
'abc' LIKE 'c'      false
```

## 중요 고려 사항

"LIKE 패턴 매칭은 항상 전체 문자열을 대상으로 합니다. 문자열 안 어디에서든 패턴을 일치시키려면 패턴이 퍼센트 기호로 시작하고 끝나야 합니다."

리터럴 언더스코어나 퍼센트 문자를 일치시키려면 그 앞에 이스케이프 문자를 놓습니다. 기본 이스케이프 문자는 백슬래시이지만 `ESCAPE` 절로 다른 문자를 지정할 수 있습니다. 이스케이프 문자 자체를 일치시키려면 이스케이프 문자를 연속으로 두 번 사용합니다.

`ESCAPE ''`를 작성하여 이스케이프 메커니즘을 완전히 비활성화할 수 있지만, 이렇게 하면 리터럴 언더스코어와 퍼센트 기호를 일치시킬 수 없습니다.
