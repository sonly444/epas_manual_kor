# 비트 함수 (Bitwise functions) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Bitwise functions](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/14_bitwise_functions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·연산자·코드는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server의 비트 함수에는 `BITAND`와 `BITOR`가 포함됩니다.

## BITAND

`BITAND` 함수는 비트 AND 연산을 수행합니다. 시그니처:

```sql
BITAND(<expr1>, <expr2>)
```

이 함수는 "비트 `AND`를 사용하여 `expr1` 값의 각 비트를 `exp2`의 해당 비트와 비교"합니다. 두 입력 인자는 모두 `NUMBER` 데이터 타입이어야 합니다. 어느 인자든 `NULL`이면 결과는 `NULL`입니다. 함수는 입력 인자와 동일한 데이터 타입을 반환합니다.

**예:**
```sql
edb=# SELECT BITAND(10,11) FROM DUAL;
```
반환: `10`

## BITOR

`BITOR` 함수는 비트 OR 연산을 수행합니다. 시그니처:

```sql
BITOR(<expr1>, <expr2>)
```

이 함수는 "비트 `OR`를 사용하여 `expr1` 값의 각 비트를 `exp2`의 해당 비트와 비교"합니다. 입력 인자와 동일한 데이터 타입을 반환합니다. 모든 컬럼 값이 `NULL`이면 결과는 `NULL`입니다.

**예:**
```sql
edb=# SELECT BITOR(10,11) FROM DUAL;
```
반환: `11`

## 비트 연산자

두 연산자가 동등한 기능을 제공합니다.

- `&`는 비트 AND를 수행
- `|`는 비트 OR를 수행

**예:**
```sql
SELECT 10&11 FROM DUAL;   -- 반환: 10
SELECT 10|11 FROM DUAL;   -- 반환: 11
```
