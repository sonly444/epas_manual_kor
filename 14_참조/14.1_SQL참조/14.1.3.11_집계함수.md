# 집계 함수 (Aggregate Functions) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Aggregate functions](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/11_aggregate_functions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·코드 이름은 원문 그대로 보존했습니다.

집계 함수(aggregate function)는 입력 값 집합으로부터 단일 결과 값을 계산합니다.

## 기본 제공 집계 함수 (Built-in aggregate functions)

기본 제공 집계 함수는 다음 표에 나열되어 있습니다.

| 함수 | 인수 타입 | 반환 타입 | 설명 |
| --- | --- | --- | --- |
| `AVG (expression)` | `INTEGER, REAL, DOUBLE PRECISION, NUMBER` | 정수 타입은 `NUMBER`, 부동소수점 인수는 `DOUBLE PRECISION`, 그 외에는 인수 데이터 타입과 동일 | 모든 입력 값의 평균(산술 평균) |
| `COUNT(*)` |  | `BIGINT` | 입력 행의 개수 |
| `COUNT (expression)` | 임의 | `BIGINT` | expression 값이 null이 아닌 입력 행의 개수 |
| `MAX (expression)` | 임의의 numeric, 문자열, 날짜/시간, bytea 타입 | 인수 타입과 동일 | 모든 입력 값에 걸친 expression의 최댓값 |
| `MIN (expression)` | 임의의 numeric, 문자열, 날짜/시간, bytea 타입 | 인수 타입과 동일 | 모든 입력 값에 걸친 expression의 최솟값 |
| `SUM (expression)` | `INTEGER, REAL, DOUBLE PRECISION, NUMBER` | `SMALLINT`/`INTEGER` 인수는 `BIGINT`, `BIGINT` 인수는 `NUMBER`, 부동소수점 인수는 `DOUBLE PRECISION`, 그 외에는 인수 데이터 타입과 동일 | 모든 입력 값에 걸친 expression의 합 |

`COUNT`를 제외하고 이 함수들은 선택된 행이 없으면 null 값을 반환합니다. 특히 행이 없는 경우의 `SUM`은 0이 아니라 null을 반환합니다. 필요한 경우 `COALESCE` 함수를 사용해 null 대신 0을 대체할 수 있습니다.

## 통계 분석용 집계 함수 (Aggregate functions for statistical analysis)

다음 표는 통계 분석에서 일반적으로 사용되는 집계 함수를 보여줍니다. 설명에서 `N`은 모든 입력 표현식이 non-null인 입력 행의 개수를 의미합니다. 모든 경우에 계산이 무의미하면(예: `N`이 0일 때) null이 반환됩니다.

| 함수 | 인수 타입 | 반환 타입 | 설명 |
| --- | --- | --- | --- |
| `CORR(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | 상관 계수 |
| `COVAR_POP(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | 모집단 공분산 |
| `COVAR_SAMP(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | 표본 공분산 |
| `REGR_AVGX(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | 독립 변수의 평균 (sum`(X) / N`) |
| `REGR_AVGY(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | 종속 변수의 평균 (sum`(Y) / N`) |
| `REGR_COUNT(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | 두 표현식이 모두 non-null인 입력 행의 개수 |
| `REGR_INTERCEPT(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | `(X, Y)` 쌍으로 결정되는 최소제곱적합 선형 방정식의 y절편 |
| `REGR_R2(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | 상관 계수의 제곱 |
| `REGR_SLOPE(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | `(X, Y)` 쌍으로 결정되는 최소제곱적합 선형 방정식의 기울기 |
| `REGR_SXX(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | Sum(X²) − Sum(X)²/N (독립 변수의 "제곱합") |
| `REGR_SXY(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | Sum(X*Y) − Sum(X)*Sum(Y)/N (독립×종속 변수의 "곱의 합") |
| `REGR_SYY(Y, X)` | `DOUBLE PRECISION` | `DOUBLE PRECISION` | Sum(Y²) − Sum(Y)²/N (종속 변수의 "제곱합") |
| `STDDEV(expression)` | `INTEGER, REAL, DOUBLE PRECISION, NUMBER` | 부동소수점 인수는 `DOUBLE PRECISION`, 그 외에는 `NUMBER` | `STDDEV_SAMP`의 역사적 별칭 |
| `STDDEV_POP(expression)` | `INTEGER, REAL, DOUBLE PRECISION, NUMBER` | 부동소수점 인수는 `DOUBLE PRECISION`, 그 외에는 `NUMBER` | 입력 값의 모집단 표준편차 |
| `STDDEV_SAMP(expression)` | `INTEGER, REAL, DOUBLE PRECISION, NUMBER` | 부동소수점 인수는 `DOUBLE PRECISION`, 그 외에는 `NUMBER` | 입력 값의 표본 표준편차 |
| `VARIANCE(expression)` | `INTEGER, REAL, DOUBLE PRECISION, NUMBER` | 부동소수점 인수는 `DOUBLE PRECISION`, 그 외에는 `NUMBER` | `VAR_SAMP`의 역사적 별칭 |
| `VAR_POP(expression)` | `INTEGER, REAL, DOUBLE PRECISION, NUMBER` | 부동소수점 인수는 `DOUBLE PRECISION`, 그 외에는 `NUMBER` | 입력 값의 모집단 분산(모집단 표준편차의 제곱) |
| `VAR_SAMP(expression)` | `INTEGER, REAL, DOUBLE PRECISION, NUMBER` | 부동소수점 인수는 `DOUBLE PRECISION`, 그 외에는 `NUMBER` | 입력 값의 표본 분산(표본 표준편차의 제곱) |

## LISTAGG

`LISTAGG`는 여러 행의 데이터를 정렬된 방식으로 단일 행에 연결(concatenate)하는 집계 함수입니다. 선택적으로 데이터에 사용자 지정 구분자를 포함할 수 있습니다.

`LISTAGG` 함수는 측정(measure) 컬럼의 값을 연결하여 정렬된 집계 데이터를 생성하기 위해 `WITHIN GROUP` 절 아래에 `ORDER BY` 절 사용을 의무화합니다.

### 목적 (Objective)

- `LISTAGG`를 그룹화 없이 사용할 수 있습니다. 이 경우 `LISTAGG` 함수는 테이블의 모든 행에 작용하여 단일 행을 반환합니다.
- `LISTAGG`를 `GROUP BY` 절과 함께 사용할 수 있습니다. 이 경우 `LISTAGG` 함수는 각 그룹에 작용하여 그룹별 집계 출력을 반환합니다.
- `LISTAGG`를 `OVER` 절과 함께 사용할 수 있습니다. 이 경우 `LISTAGG` 함수는 `query_partition_by_clause`의 표현식을 기반으로 쿼리 결과 집합을 그룹으로 분할한 뒤 각 그룹의 데이터를 집계합니다.

### 구문 개요 (Synopsis)

```sql
LISTAGG( <measure_expr> [, <delimiter> ]) WITHIN GROUP( <order_by_clause> )
[ OVER <query_partition_by_clause> ]
```

### 파라미터 (Parameters)

`measure_expr` (필수)는 집계할 값을 할당하는 컬럼이나 표현식을 지정합니다. `NULL` 값은 무시됩니다.

`delimiter` (선택)는 결과 행에서 연결된 값들을 구분하는 문자열을 지정합니다. `delimiter`는 `NULL` 값, 문자열, 문자 리터럴, 컬럼 이름, 상수 표현식일 수 있습니다. 무시되면 `LISTAGG` 함수는 기본적으로 `NULL` 값을 사용합니다.

`order_by_clause` (필수)는 연결된 값이 반환되는 정렬 순서를 결정합니다.

`query_partition_by_clause` (선택)는 `LISTAGG` 함수를 분석 함수로 사용할 수 있게 하고 `OVER` 절에서 각 그룹의 레코드 범위를 설정합니다.

### 반환 타입 (Return type)

`LISTAGG` 함수는 문자열 값을 반환합니다.

### 예제 (Examples)

이 예는 `emp` 테이블의 값을 연결하고 구분자 쉼표로 구분하여 모든 사원을 나열합니다. 먼저 `emp` 테이블을 만들고 레코드를 삽입합니다.

```sql
edb=# CREATE TABLE emp
edb-#        (EMPNO NUMBER(4) NOT NULL,
edb(#         ENAME VARCHAR2(10),
edb(#         JOB VARCHAR2(9),
edb(#         MGR NUMBER(4),
edb(#         HIREDATE DATE,
edb(#         SAL NUMBER(7, 2),
edb(#         COMM NUMBER(7, 2),
edb(#         DEPTNO NUMBER(2));
CREATE TABLE
```

```sql
edb=# INSERT INTO emp VALUES
edb-#         (7499, 'ALLEN',  'SALESMAN',  7698,
edb(#         TO_DATE('20-FEB-1981', 'DD-MON-YYYY'), 1600,  300, 30);
INSERT 0 1
edb=# INSERT INTO emp VALUES
edb-#         (7521, 'WARD',   'SALESMAN',  7698,
edb(#         TO_DATE('22-FEB-1981', 'DD-MON-YYYY'), 1250,  500, 30);
INSERT 0 1
edb=# INSERT INTO emp VALUES
edb-#         (7566, 'JONES',  'MANAGER',   7839,
edb(#         TO_DATE('2-APR-1981', 'DD-MON-YYYY'),  2975, NULL, 20);
INSERT 0 1
edb=# INSERT INTO emp VALUES
edb-#         (7654, 'MARTIN', 'SALESMAN',  7698,
edb(#         TO_DATE('28-SEP-1981', 'DD-MON-YYYY'), 1250, 1400, 30);
INSERT 0 1
edb=# INSERT INTO emp VALUES
edb-#         (7698, 'BLAKE',  'MANAGER',   7839,
edb(#         TO_DATE('1-MAY-1981', 'DD-MON-YYYY'),  2850, NULL, 30);
INSERT 0 1
```

출력:

```text
edb=# SELECT LISTAGG(ENAME, ',') WITHIN GROUP (ORDER BY ENAME) FROM emp;
               listagg
-------------------------------------
 ALLEN,BLAKE,JONES,MARTIN,WARD
(1 row)
```

이 예는 `emp` 테이블에서 `LISTAGG`와 함께 `PARTITION BY` 절을 사용합니다. 전체 테이블이 아니라 각 파티션에 적용되는 `deptno`별 파티션을 기반으로 출력을 생성합니다.

```sql
edb=# SELECT DISTINCT DEPTNO, LISTAGG(ENAME, ',') WITHIN GROUP (ORDER BY
ENAME) OVER(PARTITION BY DEPTNO) FROM emp;
```

출력:

```text
 deptno |         listagg
--------+-------------------------
     30 | ALLEN,BLAKE,MARTIN,WARD
     20 | JONES
(2 rows)
```

이 예는 `GROUP BY` 절을 포함합니다.

```sql
edb=# SELECT DEPTNO, LISTAGG(ENAME, ',') WITHIN GROUP (ORDER BY ENAME) FROM
emp GROUP BY DEPTNO;
```

출력:

```text
 deptno |         listagg
--------+-------------------------
     20 | JONES
     30 | ALLEN,BLAKE,MARTIN,WARD
(2 rows)
```

## MEDIAN

`MEDIAN` 함수는 주어진 값 범위에서 표현식의 중앙값을 계산합니다. `NULL` 값은 무시됩니다. 쿼리가 사용자 정의 테이블을 참조하지 않으면 `MEDIAN` 함수는 오류를 반환합니다.

### 목적 (Objective)

- `MEDIAN`을 그룹화 없이 사용할 수 있습니다. 이 경우 `MEDIAN` 함수는 테이블의 모든 행에 작용하여 단일 행을 반환합니다.
- `MEDIAN`을 `OVER` 절과 함께 사용할 수 있습니다. 이 경우 `MEDIAN` 함수는 `PARTITION BY` 절에 지정된 `expression`을 기반으로 쿼리 결과 집합을 그룹으로 분할한 뒤 각 그룹의 데이터를 집계합니다.

### 구문 개요 (Synopsis)

```sql
MEDIAN( <median_expression> ) [ OVER ( [ PARTITION BY... ] ) ]
```

### 파라미터 (Parameters)

`median_expression` (필수)는 `MEDIAN` 함수가 작용하여 중앙값을 반환하는 대상 컬럼이나 표현식입니다. numeric, datetime, interval 데이터 타입일 수 있습니다.

`PARTITION BY` 절 (선택)은 `MEDIAN`을 분석 함수로 사용할 수 있게 하고 `OVER` 절에서 각 그룹의 레코드 범위를 설정합니다.

### 반환 타입 (Return types)

반환 타입은 `expression`의 입력 데이터 타입에 의해 결정됩니다. 다음 표는 각 입력 타입에 대한 반환 타입을 보여줍니다.

| 입력 타입 | 반환 타입 |
| --- | --- |
| `BIGINT` | `NUMERIC` |
| `FLOAT, DOUBLE PRECISION` | `DOUBLE PRECISION` |
| `INTEGER` | `NUMERIC` |
| `INTERVAL` | `INTERVAL` |
| `NUMERIC` | `NUMERIC` |
| `REAL` | `REAL` |
| `SMALLINT` | `NUMERIC` |
| `TIMESTAMP` | `TIMESTAMP` |
| `TIMESTAMPTZ` | `TIMESTAMPTZ` |

### 예제 (Examples)

이 예에서 쿼리는 `emp` 테이블의 각 부서에 대한 중앙값 급여를 반환합니다:

```sql
edb=# SELECT * FROM emp;
```

출력:

```text
 empno| ename |   job   | mgr  |      hiredate     |   sal  | comm   | deptno
 -----+-------+---------+------+-------------------+--------+--------+-------
 7369 | SMITH | CLERK   | 7902 | 17-DEC-80 00:00:00|  800.00|        |   20
 7499 | ALLEN | SALESMAN| 7698 | 20-FEB-81 00:00:00| 1600.00| 300.0  |   30
 7521 | WARD  | SALESMAN| 7698 | 22-FEB-81 00:00:00| 1250.00| 500.00 |   30
 7566 | JONES | MANAGER | 7839 | 02-APR-81 00:00:00| 2975.00|        |   20
 7654 | MARTIN| SALESMAN| 7698 | 28-SEP-81 00:00:00| 1250.00| 1400.00|   30
(5 rows)
```

```sql
 edb=# SELECT MEDIAN (SAL) FROM emp;
```

출력:

```text
  median
 --------
    1250
 (1 row)
```

이 예는 `emp` 테이블에서 `MEDIAN`과 함께 `PARTITION BY` 절을 사용하고 `deptno`별 파티션을 기반으로 중앙값 급여를 반환합니다:

```sql
edb=# SELECT EMPNO, ENAME, DEPTNO, MEDIAN (SAL) OVER (PARTITION BY DEPTNO)
FROM emp;
```

출력:

```text
 empno | ename  | deptno | median
-------+--------+--------+--------
  7369 | SMITH  |     20 | 1887.5
  7566 | JONES  |     20 | 1887.5
  7499 | ALLEN  |     30 |   1250
  7521 | WARD   |     30 |   1250
  7654 | MARTIN |     30 |   1250
(5 rows)
```

`MEDIAN` 함수를 `PERCENTILE_CONT`와 비교할 수 있습니다. 이 예에서 `MEDIAN`은 `PERCENTILE_CONT`와 같은 결과를 생성합니다:

```sql
edb=# SELECT MEDIAN (SAL), PERCENTILE_CONT(0.5) WITHIN GROUP(ORDER BY SAL)
FROM emp;
```

출력:

```text
 median | percentile_cont
--------+-----------------
   1250 |            1250
(1 row)
```

## STATS_MODE

`STATS_MODE` 함수는 값 집합을 인수로 받아 가장 높은 빈도로 나타나는 값을 반환합니다. 여러 값이 같은 빈도로 나타나면 `STATS_MODE` 함수는 임의로 첫 번째 값을 선택하여 그 값 하나만 반환합니다.

### 목적 (Objective)

- `STATS_MODE`를 그룹화 없이 사용할 수 있습니다. 이 경우 `STATS_MODE` 함수는 테이블의 모든 행에 작용하여 단일 값을 반환합니다.
- `STATS_MODE`를 `WITHIN GROUP` 절을 사용하는 정렬 집합 집계 함수(ordered-set aggregate function)로 사용할 수 있습니다. 이 경우 `STATS_MODE` 함수는 정렬된 데이터 집합에 작용합니다.
- `STATS_MODE`를 `GROUP BY` 절과 함께 사용할 수 있습니다. 이 경우 `STATS_MODE` 함수는 각 그룹에 작용하여 그룹별 최빈 집계 출력을 반환합니다.

### 구문 개요 (Synopsis)

```sql
STATS_MODE( <expr> )
```

또는

```sql
STATS_MODE() WITHIN GROUP ( ORDER BY sort_expression )
```

### 파라미터 (Parameters)

`expr` — 컬럼에 할당할 표현식이나 값입니다.

### 반환 타입 (Return type)

`STATS_MODE` 함수는 자주 나타나는 값을 반환합니다. 그러나 컬럼의 모든 값이 `NULL`이면 `STATS_MODE`는 `NULL`을 반환합니다.

### 예제 (Examples)

이 예는 `emp` 테이블에서 급여의 최빈값을 반환합니다:

```sql
edb=# SELECT STATS_MODE(SAL) FROM emp;
```

출력:

```text
 stats_mode
------------
   1250.00
(1 row)
```

이 예는 `emp` 테이블에서 `STATS_MODE`와 함께 `GROUP BY`, `ORDER BY` 절을 사용하고 `deptno`별 파티션을 기반으로 급여를 반환합니다:

```sql
edb=# SELECT STATS_MODE(SAL) FROM emp GROUP BY DEPTNO ORDER BY DEPTNO;
```

출력:

```text
 stats_mode
------------
   800.00
   1250.00
(2 rows)
```

이 예는 `STATS_MODE`와 함께 `WITHIN GROUP` 절을 사용해 정렬된 데이터 집합에 집계를 수행합니다.

```sql
SELECT STATS_MODE() WITHIN GROUP(ORDER BY SAL) FROM emp;
```

출력:

```text
 stats_mode
------------
   1250.00
(1 row)
```

## BIT_AND_AGG

`BIT_AND_AGG`는 비트 단위 `AND` 연산을 수행하고 입력 인수의 데이터 타입에 기반한 값을 반환하는 비트 집계 함수입니다.

### 목적 (Objective)

- `BIT_AND_AGG` 함수를 `GROUP BY` 절과 함께 사용할 수 있습니다. 이 경우 `BIT_AND_AGG` 함수는 그룹에 작용하여 비트 `AND` 연산의 결과를 반환합니다.
- `DISTINCT`나 `UNIQUE` 키워드를 `BIT_AND_AGG` 함수와 함께 사용해 `expr`의 고유 값만 계산에 사용되도록 할 수 있습니다.

### 구문 개요 (Synopsis)

```sql
BIT_AND_AGG ( [DISTINCT | ALL | UNIQUE]  <expr> )
```

### 파라미터 (Parameters)

`expr` — 컬럼에 할당할 표현식이나 값입니다.

### 반환 타입 (Return Type)

`BIT_AND_AGG` 함수는 입력 인수의 데이터 타입과 같은 값을 반환합니다. 그러나 컬럼의 모든 값이 `NULL`이면 `BIT_AND_AGG`는 `NULL`을 반환합니다.

### 예제 (Examples)

이 예는 `emp` 테이블의 `sal` 컬럼에 `BIT_AND_AGG` 함수를 적용하고 결과를 `deptno`별로 그룹화합니다:

```sql
edb=# SELECT deptno,BIT_AND_AGG(DISTINCT sal) FROM emp GROUP BY deptno;
```

출력:

```text
 deptno | bit_and_agg
--------+-------------
     20 |     2975.00
     30 |           0
(2 rows)
```

## BIT_OR_AGG

`BIT_OR_AGG`는 비트 단위 `OR` 연산을 수행하고 입력 인수의 데이터 타입에 기반한 값을 반환하는 비트 집계 함수입니다.

### 목적 (Objective)

- `BIT_OR_AGG` 함수를 `GROUP BY` 절과 함께 사용할 수 있습니다. 이 경우 `BIT_OR_AGG` 함수는 그룹에 작용하여 비트 `OR` 연산의 결과를 반환합니다.
- `DISTINCT`나 `UNIQUE` 키워드를 `BIT_OR_AGG` 함수와 함께 사용해 `expr`의 고유 값만 계산에 사용되도록 할 수 있습니다.

### 구문 개요 (Synopsis)

```sql
BIT_OR_AGG ( [DISTINCT | ALL | UNIQUE]  <expr> )
```

### 파라미터 (Parameters)

`expr` — 컬럼에 할당할 표현식이나 값입니다.

### 반환 타입 (Return type)

`BIT_OR_AGG` 함수는 입력 인수의 데이터 타입과 같은 값을 반환합니다. 그러나 컬럼의 모든 값이 `NULL`이면 `BIT_OR_AGG`는 `NULL`을 반환합니다.

### 예제 (Examples)

이 예는 `emp` 테이블의 `sal` 컬럼에 `BIT_OR_AGG`를 적용하고 결과를 `deptno`별로 그룹화합니다:

```sql
edb=# SELECT deptno,BIT_OR_AGG(DISTINCT sal) FROM emp GROUP BY deptno;
```

출력:

```text
 deptno | bit_or_agg
--------+------------
     20 |    2975.00
     30 |       4066
(2 rows)
```
