# NLS_UPPER 함수 — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › NLS functions › NLS_UPPER](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/nls_functions/nls_upper/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·파라미터·코드 이름은 원문 그대로 보존했습니다.

`NLS_UPPER`는 모든 글자를 대문자로 한 `<outputstring> TEXT`를 반환합니다.

```sql
NLS_UPPER(<inputstring> TEXT [, <'nlsparam'> TEXT])
```

여기서,

`inputstring`은 TEXT 데이터 타입입니다.

`nlsparam`은 TEXT 데이터 타입입니다. `nlsparam`은 `'NLS_SORT=value'` 형식으로 제공할 수 있습니다. 예: `'NLS_SORT=xdanish'`. 여기서 `xdanish`는 NLS 구성 파일의 NLS 파라미터로 취급되며, 이에 따라 대소문자 변환의 언어적 요구 사항이 처리됩니다.

`<outputstring>`은 TEXT 데이터 타입입니다. 반환 문자열은 `inputstring`과 같은 문자 집합입니다.

## 예제 (Examples)

이 예는 NLS 파라미터의 기본 매핑으로 NLS_UPPER 함수를 보여줍니다.

```sql
SELECT NLS_UPPER('Gloße', 'NLS_SORT = xdanish');
```

출력:

```text
 nls_upper
-----------
 GLOßE
(1 row)
```

이 예는 `edb_nls_cf_insert` 함수를 사용해 NLS 구성 파일에 NLS 파라미터와 콜레이션 값의 새 매핑을 추가하는 방법을 보여줍니다.

```sql
SELECT edb_nls_cf_insert('xdanish', '"pg_catalog"."da-x-icu"');
```

출력:

```text
 edb_nls_cf_insert
-------------------

(1 row)
```

이 예는 NLS 구성 파일에 새 매핑을 추가한 후의 NLS_UPPER 함수를 보여줍니다.

```sql
SELECT NLS_UPPER('Gloße', 'NLS_SORT = xdanish');
```

출력:

```text
 nls_upper
-----------
 GLOSSE
(1 row)
```

이 예는 단순 입력 문자열에 대한 NLS_UPPER 함수를 보여줍니다.

```sql
SELECT NLS_UPPER('abcDef', 'NLS_SORT = XGERMAN');
 nls_upper
-----------
 ABCDEF
(1 row)
```
