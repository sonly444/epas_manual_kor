# NLSSORT 함수 — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › NLS functions › NLSSORT](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/nls_functions/nlssort/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·파라미터·코드 이름은 원문 그대로 보존했습니다.

`NLSSORT` 함수는 지정된 콜레이션에 따라 문자나 문자열을 정렬하는 데 사용됩니다.

```sql
NLSSORT(<inputstring> TEXT [, <'nlsparam'> TEXT])
```

여기서,

`inputstring`은 TEXT 데이터 타입입니다.

`nlsparam`은 TEXT 데이터 타입입니다. `nlsparam`은 `'NLS_SORT=value'` 형식으로 제공할 수 있습니다. 예: `'NLS_SORT=xdanish'`. 여기서 `xdanish`는 NLS 구성 파일의 NLS 파라미터로 취급되며, 이에 따라 비교/정렬의 언어적 요구 사항이 처리됩니다.

`<outputstring>`은 TEXT 데이터 타입입니다. 반환 문자열은 `inputstring`과 같은 문자 집합입니다.

EPAS의 `NLSSORT`는 (Oracle의 NLSSORT와 달리) 독립 함수 호출로 사용하는 경우, 오류는 발생하지 않으나 지정한 NLS_SORT 파라미터가 적용되지 않고 입력 문자열이 변경 없이 그대로 반환되는 특징이 있습니다. 즉 Oracle의 NLSSORT 처럼 이진(binary) 정렬 키를 생성하여 반환하지는 않습니다. 

다음 과 같은 사용 시에는 Oracle과 동일하게 지원됩니다:

- 비교 조건(Comparison conditions)
- BETWEEN 절
- IN 절
- ORDER BY 절
- GROUP BY 절
- COUNT(DISTINCT) 절

## 예제 (Examples)

테이블을 만들고 몇 개의 행을 삽입합니다:

```sql
CREATE TABLE test_tab (name VARCHAR(15), id VARCHAR(5));
INSERT INTO test_tab VALUES ('ä', '1');
INSERT INTO test_tab VALUES ('Z', '3');
INSERT INTO test_tab VALUES ('A', '2');
INSERT INTO test_tab VALUES ('ä', '0');
```

이 예는 NLS 파라미터의 기본 매핑으로 NLSSORT 함수를 보여줍니다.

```sql
SELECT * FROM test_tab ORDER BY NLSSORT(name, 'NLS_SORT = xdanish');
```

출력:

```text
 name | id
------+----
 A    | 2
 ä    | 1
 ä    | 0
 Z    | 3
```

이 예는 `edb_nls_cf_insert` 함수를 사용해 NLS 구성 파일에 NLS 파라미터와 콜레이션 값의 새 매핑을 추가하는 방법을 보여줍니다.

```sql
SELECT edb_nls_cf_insert('xdanish', '"pg_catalog"."kl-GL-x-icu"');
```

출력:

```text
 edb_nls_cf_insert
-------------------

(1 row)
```

이 예는 NLS 구성 파일에 새 매핑을 추가한 후의 NLSSORT 함수를 보여줍니다.

```sql
SELECT * FROM test_tab ORDER BY NLSSORT(name, 'NLS_SORT = xdanish');
```

출력:

```text
 name | id
------+----
 A    | 2
 Z    | 3
 ä    | 1
 ä    | 0
(4 rows)
```

이 예는 EPAS에서 Oracle과 동작이 다른, NLSSORT 함수를 사용한 뷰 생성 방법을 보여줍니다:

```sql
CREATE VIEW test_view AS SELECT * FROM test_tab WHERE name BETWEEN NLSSORT('Z', 'NLS_SORT = xdanish') AND NLSSORT('ä', 'NLS_SORT = xdanish') ORDER BY NLSSORT(name, 'NLS_SORT = xdanish');
```

출력:

```text
CREATE VIEW
```

이 예는 위에서 만든 뷰에서 데이터를 읽는 방법을 보여줍니다.

```sql
SELECT * FROM test_view;
```

출력:

```text
name | id
------+----
 Z    | 3
 ä    | 1
 ä    | 0
(3 rows)
```
