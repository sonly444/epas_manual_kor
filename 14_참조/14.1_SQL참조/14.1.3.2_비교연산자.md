# 비교 연산자 (Comparison operators) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Comparison operators](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/02_comparison_operators/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 연산자·구문은 원문 그대로 보존했습니다.

이 페이지는 EDB Postgres Advanced Server 버전 18에서 사용할 수 있는 표준 비교 연산자를 설명합니다.

### 사용 가능한 연산자

| 연산자 | 설명 |
| -------- | ------------------------ |
| `<`      | 보다 작음 |
| `>`      | 보다 큼 |
| `<=`     | 보다 작거나 같음 |
| `>=`     | 보다 크거나 같음 |
| `=`      | 같음 |
| `<>`     | 같지 않음 |
| `!=`     | 같지 않음 |

### 주요 특성

"비교 연산자는 의미가 있는 모든 데이터 타입에 사용할 수 있습니다. 모든 비교 연산자는 `BOOLEAN` 타입 값을 반환하는 이항 연산자(binary operator)입니다."

### 추가 구문

`BETWEEN` 연산자는 특수 구문으로 제공됩니다.
- `a BETWEEN x AND y`는 `a >= x AND a <= y`와 같습니다.
- `a NOT BETWEEN x AND y`는 `a < x OR a > y`와 같습니다.

### NULL 값 처리

문서는 다음을 강조합니다: "`NULL`은 `NULL`과 '같지' 않으므로 `expression = NULL`이라고 작성하지 마십시오." 대신 null 값을 확인하려면 `expression IS NULL` 또는 `expression IS NOT NULL`을 사용합니다.
