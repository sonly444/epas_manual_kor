# DUMP 함수 (DUMP function) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › DUMP function](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/dump_function/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·구문·코드·출력은 원문 그대로 보존했습니다.

DUMP 함수는 표현식의 데이터 타입 코드, 바이트 길이, 내부 표현(internal representation)을 담은 VARCHAR2 값을 반환합니다.

```sql
DUMP(expr[, <return_fmt> [, <start_position> [, <length> ] ] ])
```

여기서 `return_fmt`는 다음 반환 값의 형식을 지정합니다.

- `8`은 결과를 8진 표기로 반환합니다.
- `10`은 결과를 10진 표기로 반환합니다.
- `16`은 결과를 16진 표기로 반환합니다.
- `17`은 각 바이트를 컴파일러의 문자 집합에서 인쇄 가능한 문자로 해석할 수 있는 경우에만 문자로 인쇄하여 반환합니다.

`start_position`과 `length` 인자는 결합하여 반환할 내부 표현의 부분을 결정합니다. 기본값은 전체 내부 표현을 10진 표기로 반환하는 것입니다.

`expr`이 null이면 함수는 `NULL`을 반환합니다.

## 예제

```sql
SELECT dump('abc', 10);
```

출력

```text
          dump  
------------------------
 Typ=25 Len=3: 97,98,99
(1 row)
```

```sql
SELECT dump('huvudvärke', 1017) FROM dual;
```

출력

```text
                           dump  
----------------------------------------------------------
 Typ=25 Len=11 CharacterSet=UTF8: h,u,v,u,d,v,c3,a4,r,k,e
(1 row)
```

```sql
SELECT dump ('edbpostgres', 8,2,3) FROM dual;
```

출력

```text
            dump  
----------------------------
 Typ=25 Len=11: 144,142,160
(1 row)
```

```sql
SELECT dump(to_timestamp('11-06-2021 12:45:24','MM-DD-YYYY HH:MI:SS'), 1008) FROM dual;
```

출력

```text
                           dump  
-----------------------------------------------------------
 Typ=1184 Len=8 CharacterSet=UTF8: 0,355,12,266,30,163,2,0
(1 row)
```

```sql
SELECT dump(100/4, 10) FROM dual;
```

출력

```text
            dump  
----------------------------
 Typ=1700 Len=4: 0,128,25,0
(1 row)
```
