# 논리 연산자 (Logical operators) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Logical operators](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/01_logical_operators/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 연산자·값은 원문 그대로 보존했습니다.

문서는 SQL에서 사용할 수 있는 세 가지 기본 논리 연산자 `AND`, `OR`, `NOT`을 설명합니다.

## 핵심 개념

시스템은 "null 값이 '알 수 없음(unknown)'을 나타내는 3값 불리언 논리(three-valued Boolean logic)"를 사용합니다. 이는 NULL을 별개의 논리 상태로 도입한다는 점에서 전통적인 2값 논리와 다릅니다.

## 진리표

**AND/OR 연산:**
- TRUE AND TRUE = TRUE
- TRUE AND FALSE = FALSE
- TRUE AND NULL = NULL
- FALSE AND FALSE = FALSE
- FALSE AND NULL = FALSE
- NULL AND NULL = NULL
- OR 연산에도 유사한 패턴이 적용됩니다.

**NOT 연산:**
- NOT TRUE = FALSE
- NOT FALSE = TRUE
- NOT NULL = NULL

## 중요 속성

"연산자 `AND`와 `OR`는 교환법칙이 성립(commutative)"하므로 피연산자 순서가 결과에 영향을 주지 않습니다. 이를 통해 논리적 결과를 바꾸지 않고 쿼리를 유연하게 구성할 수 있습니다.

문서는 NULL 처리가 모든 연산자에서 일관되며, NULL을 알 수 없는 값으로 취급하여 대부분의 논리 연산에서 NULL 결과를 생성함을 강조합니다.
