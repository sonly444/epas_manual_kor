# 의사 타입 (Pseudo-types) — EPAS 18 데이터 타입

> 원문: [EPAS v18 — Reference › SQL reference › Data types › Pseudo-types](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/02_data_types/pseudo_types/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입 이름은 원문 그대로 보존했습니다.

| 데이터 타입 | 네이티브 | 별칭 | 설명 |
| ------------------ | ------ | ----- | ------ |
| `any` | ✅ | | 함수가 임의의 입력 데이터 타입을 받음을 나타냅니다. |
| `anyelement` | ✅ | | 함수가 임의의 데이터 타입을 받음을 나타냅니다. 자세한 내용은 PostgreSQL 문서의 다형 타입(Polymorphic types)을 참조하십시오. |
| `anyarray` | ✅ | | 함수가 임의의 배열 데이터 타입을 받음을 나타냅니다. 자세한 내용은 PostgreSQL 문서의 다형 타입을 참조하십시오. |
| `anynonarray` | ✅ | | 함수가 임의의 비배열 데이터 타입을 받음을 나타냅니다. 자세한 내용은 PostgreSQL 문서의 다형 타입을 참조하십시오. |
| `anyenum` | ✅ | | 함수가 임의의 열거 데이터 타입을 받음을 나타냅니다. 자세한 내용은 PostgreSQL 문서의 다형 타입과 열거 타입을 참조하십시오. |
| `anyrange` | ✅ | | 함수가 임의의 범위 데이터 타입을 받음을 나타냅니다. 자세한 내용은 PostgreSQL 문서의 다형 타입과 범위 타입을 참조하십시오. |
| `cstring` | ✅ | | 함수가 null로 종료되는 C 문자열을 받거나 반환함을 나타냅니다. |
| `internal` | ✅ | | 함수가 서버 내부 데이터 타입을 받거나 반환함을 나타냅니다. |
| `language_handler` | ✅ | | 절차적 언어 호출 핸들러는 `language_handler`를 반환하도록 선언됩니다. |
| `fdw_handler` | ✅ | | 외부 데이터 래퍼(foreign-data wrapper) 핸들러는 `fdw_handler`를 반환하도록 선언됩니다. |
| `record` | ✅ | | 지정되지 않은 행 타입을 받거나 반환하는 함수를 식별합니다. |
| `trigger` | ✅ | | 트리거 함수는 trigger를 반환하도록 선언됩니다. |
| `event_trigger` | ✅ | | 이벤트 트리거 함수는 `event_trigger`를 반환하도록 선언됩니다. |
| `void` | ✅ | | 함수가 값을 반환하지 않음을 나타냅니다. |
| `opaque` | ✅ | | 이전에 위의 모든 용도로 사용되던 구식(obsolete) 타입 이름입니다. |

## 개요

"PostgreSQL 타입 시스템은 통칭하여 의사 타입(pseudo-type)이라 부르는 여러 특수 목적 항목을 포함합니다." 의사 타입은 컬럼 데이터 타입으로 사용할 수 없지만, 함수의 인자 또는 결과 타입을 선언하는 데 사용할 수 있습니다.

C로 코딩된 함수는 임의의 의사 데이터 타입을 받거나 반환하도록 선언할 수 있습니다. 함수 작성자는 의사 타입이 인자 타입으로 사용될 때 안전한 동작을 보장해야 합니다.

절차적 언어 함수는 의사 타입에 제한이 있습니다. 대부분 인자 타입으로의 사용을 금지하며, 결과 타입으로는 void와 record만 허용합니다(트리거 함수의 경우 trigger 또는 event_trigger 추가). 일부는 `anyelement`, `anyarray`, `anynonarray`, `anyenum`, `anyrange`를 사용하는 다형 함수(polymorphic function)를 지원합니다.

`internal` 의사 타입은 직접적인 SQL 호출이 아닌 데이터베이스 내부 용도로만 함수를 선언합니다. internal 타입 인자를 가진 함수는 SQL에서 호출할 수 없습니다. 다음 규칙을 따르십시오: 적어도 하나의 internal 인자를 갖지 않는 한 `internal`을 반환하도록 선언된 함수를 만들지 마십시오.
