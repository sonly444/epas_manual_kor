# 불리언 타입 (Boolean types) — EPAS 18 데이터 타입

> 원문: [EPAS v18 — Reference › SQL reference › Data types › Boolean types](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/02_data_types/05_boolean_type/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입·리터럴·코드는 원문 그대로 보존했습니다.

| 이름 | 네이티브 | 별칭 | 설명 |
| --------- | ------ | ----- | --------------------------------------------- |
| `BOOLEAN` | ✅ | | 논리 불리언(true/false), 1바이트 저장. |

## 개요

EDB Postgres Advanced Server는 표준 SQL `BOOLEAN` 타입을 구현하며, 이는 `TRUE` 또는 `FALSE` 두 논리 상태 중 하나를 나타냅니다. 세 번째 상태인 `UNKNOWN`은 SQL `NULL` 값을 사용하여 표현됩니다.

### 리터럴 값

시스템은 여러 리터럴 표현을 인식합니다.
- **TRUE 상태**: 'TRUE', 'true', 'y', '1', 't'
- **FALSE 상태**: 'FALSE', 'false', 'n', '0', 'f'
- **UNKNOWN 상태**: `NULL`(리터럴 값 없음)

### 사용 예제

```sql
CREATE TABLE test1 (a boolean, b text);
INSERT INTO test1 VALUES (TRUE, 'sic est');
INSERT INTO test1 VALUES (FALSE, 'non est');
SELECT * FROM test1;
 a |    b
---+---------
 t | sic est
 f | non est

SELECT * FROM test1 WHERE a;
 a |    b
---+---------
 t | sic est
```

### 파서 동작

파서는 `TRUE`와 `FALSE`를 불리언 타입 값으로 자동 인식합니다. 다만 `NULL`은 어떤 데이터 타입도 나타낼 수 있으므로, 특정 맥락에서는 `BOOLEAN`으로 명시적 캐스팅이 필요합니다.
