# SQL 구문 (SQL Syntax) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › SQL reference › SQL syntax](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/01_sql_syntax/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·식별자·코드는 원문 그대로 보존했습니다.

SQL의 일반 구문을 이해하는 것은 데이터를 정의하고 수정하기 위해 SQL 명령을 어떻게 적용하는지 이해하는 토대가 됩니다.

## 하위 구성

- **14.1.1.1 어휘 구조 (Lexical structure)** — SQL 입력이 명령·토큰·주석으로 구성되는 방식.
- **14.1.1.2 식별자와 키워드 (Identifiers and key words)** — 키워드와 식별자의 어휘 구조, 대소문자 처리, 구분(따옴표) 식별자.
- **14.1.1.3 상수 (Constants)** — 문자열·숫자 상수 및 기타 타입 상수(`CAST`, `CAST(MULTISET)`).
- **14.1.1.4 주석 (Comments)** — SQL 주석 표기법.
