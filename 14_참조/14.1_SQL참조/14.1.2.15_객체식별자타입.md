# 객체 식별자 타입 (Object identifier types) — EPAS 18 데이터 타입

> 원문: [EPAS v18 — Reference › SQL reference › Data types › Object identifier types](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/02_data_types/object_identifier_types/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입·카탈로그·코드는 원문 그대로 보존했습니다.

## 개요

객체 식별자(OID, Object identifier)는 PostgreSQL 시스템 테이블의 내부 기본 키(primary key) 역할을 합니다. 문서에 따르면, "OID는 테이블 생성 시 `WITH OIDS`를 지정하거나 `default_with_oids` 구성 변수를 활성화하지 않는 한 사용자가 만든 테이블에는 추가되지 않습니다."

`oid` 타입은 수치 객체 식별자를 나타내며 4바이트 부호 없는 정수(unsigned integer)로 구현됩니다. 시스템에는 여러 별칭 타입이 포함됩니다: `regproc`, `regprocedure`, `regoper`, `regoperator`, `regclass`, `regtype`, `regconfig`, `regdictionary`.

## 주요 특성

문서는 "사용자가 만든 테이블의 OID 컬럼을 기본 키로 사용하는 것은 권장되지 않습니다. OID는 시스템 테이블에 대한 참조에만 사용하는 것이 가장 좋습니다."라고 언급합니다.

OID 별칭 타입은 전용 입출력 루틴을 제공하여, 원시 수치 값 대신 시스템 객체의 심볼릭 이름을 사용할 수 있게 합니다. 예를 들어 복잡한 하위 쿼리 대신 다음과 같이 작성할 수 있습니다: `SELECT * FROM pg_attribute WHERE attrelid = 'mytable'::regclass;`

## 객체 식별자 타입 참조 표

| 타입 | 참조 | 설명 | 예 |
|------|-----------|-------------|---------|
| `oid` | 임의(Any) | 수치 식별자 | `564182` |
| `regproc` | `pg_proc` | 함수 이름 | `sum` |
| `regprocedure` | `pg_proc` | 타입이 포함된 함수 | `sum(int4)` |
| `regoper` | `pg_operator` | 연산자 이름 | `+` |
| `regoperator` | `pg_operator` | 타입이 포함된 연산자 | `*(integer,integer)` |
| `regclass` | `pg_class` | 릴레이션 이름 | `pg_type` |
| `regtype` | `pg_type` | 데이터 타입 이름 | `integer` |
| `regconfig` | `pg_ts_config` | 텍스트 검색 구성 | `english` |
| `regdictionary` | `pg_ts_dict` | 텍스트 검색 사전 | `simple` |

## 추가 시스템 식별자

시스템은 다른 식별자 타입도 사용합니다: `xid`(트랜잭션 식별자), `cid`(명령 식별자), `tid`(행 위치를 위한 튜플 식별자).
