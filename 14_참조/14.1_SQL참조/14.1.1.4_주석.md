# 주석 (Comments) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › SQL reference › SQL syntax › Comments](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/01_sql_syntax/04_comments/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 코드는 원문 그대로 보존했습니다.

주석(comment)은 두 개의 대시(`--`)로 시작하여 줄 끝까지 이어지는 임의의 문자 시퀀스입니다. 예:

`-- This is a standard SQL comment`

또는 C 스타일 블록 주석을 사용할 수 있습니다:

```sql
/* multiline comment
* block
*/
```

주석은 `/*`로 시작하여 이에 대응하는 `*/`가 나타나는 곳까지 이어집니다.
