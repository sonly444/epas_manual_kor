# 날짜/시간 함수·연산자 (Date/time functions and operators) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Date/time functions and operators](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/08_date_time_functions_and_operators/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·연산자·값은 원문 그대로 보존했습니다.

## 기본 산술 연산자

다음 연산자는 날짜/시간 값과 함께 동작합니다.

| 연산자 | 예 | 결과 |
|----------|---------|--------|
| `+` | `DATE '2001-09-28' + 7` | `05-OCT-01 00:00:00` |
| `+` | `TIMESTAMP '2001-09-28 13:30:00' + 3` | `01-OCT-01 13:30:00` |
| `-` | `DATE '2001-10-01' – 7` | `24-SEP-01 00:00:00` |
| `-` | `TIMESTAMP '2001-09-28 13:30:00' - 3` | `25-SEP-01 13:30:00` |
| `-` | `TIMESTAMP '2001-09-29 03:00:00' - TIMESTAMP '2001-09-27 12:00:00'` | `@ 1 day 15 hours` |

## 날짜 및 시간 함수 개요

| 함수 | 반환 타입 | 설명 |
|----------|------------|-------------|
| `ADD_MONTHS (DATE, NUMBER)` | DATE | "날짜에 개월을 더함." |
| `CURRENT_DATE` | DATE | "현재 날짜." |
| `CURRENT_TIMESTAMP` | TIMESTAMP | "현재 날짜와 시간을 반환." |
| `EXTRACT(field FROM TIMESTAMP)` | DOUBLE PRECISION | "하위 필드를 얻음." |
| `LAST_DAY(DATE)` | DATE | "주어진 날짜가 나타내는 달의 마지막 날을 반환." |
| `LOCALTIMESTAMP [ (precision) ]` | TIMESTAMP | "현재 날짜와 시간(현재 트랜잭션 시작)." |
| `MONTHS_BETWEEN (DATE, DATE)` | NUMBER | "두 날짜 사이의 개월 수." |
| `NEXT_DAY(DATE, dayofweek)` | DATE | "지정된 날짜 이후 `dayofweek`에 해당하는 날짜." |
| `NEW_TIME(DATE, VARCHAR, VARCHAR)` | DATE | "날짜와 시간을 대체 시간대로 변환." |
| `NUMTODSINTERVAL(NUMBER, INTERVAL)` | INTERVAL | "숫자를 지정된 일 또는 초 인터벌로 변환." |
| `NUMTOYMINTERVAL(NUMBER, INTERVAL)` | INTERVAL | "숫자를 지정된 연 또는 월 인터벌로 변환." |
| `ROUND(DATE [, format ])` | DATE | "`format`에 따라 반올림된 날짜." |
| `SYS_EXTRACT_UTC(TIMESTAMP WITH TIME ZONE)` | TIMESTAMP | "협정 세계시(UTC)를 반환." |
| `SYSDATE` | DATE | "현재 날짜와 시간을 반환." |
| `SYSTIMESTAMP()` | TIMESTAMP | "현재 날짜와 시간을 반환." |
| `TRUNC(DATE [format])` | DATE | "`format`에 따라 자름." |
| `DBTIMEZONE` | `[+\|-]TZH:TZM` 또는 시간대 지역 이름 | "시간대 오프셋을 `[+\|-]TZH:TZM` 형식 또는 시간대 지역 이름으로 반환." |
| `SESSIONTIMEZONE` | `[+\|-]TZH:TZM` 또는 시간대 지역 이름 | "시간대 오프셋을 `[+\|-]TZH:TZM` 형식 또는 시간대 지역 이름으로 반환." |

## ADD_MONTHS 함수

"주어진 날짜에 지정된 개월 수를 더하거나 뺍니다." 소수 부분은 잘립니다. 결과 일자는 입력 일자와 일치하지만, 그것이 달의 마지막 날인 경우에는 결과가 항상 달의 마지막 날이 됩니다.

## CURRENT DATE/TIME 함수

이 함수들은 트랜잭션 시작 시간을 기준으로 값을 반환합니다: `CURRENT_DATE`, `CURRENT_TIMESTAMP`, `LOCALTIMESTAMP`, `LOCALTIMESTAMP(precision)`. 값은 트랜잭션 내내 일관되게 유지됩니다.

## TIMEZONE 함수

**DBTIMEZONE**: "데이터베이스 시간대의 값을 반환."

**SESSIONTIMEZONE**: "현재 세션의 시간대를 반환."

## EXTRACT 함수

날짜/시간 값에서 하위 필드를 조회합니다. 유효한 필드: YEAR, MONTH, DAY, HOUR, MINUTE, SECOND.

## MONTHS_BETWEEN 함수

"두 날짜 사이의 개월 수를 반환." 첫 번째 날짜가 두 번째보다 크면 양수, 그렇지 않으면 음수입니다.

## NEXT_DAY 함수

"주어진 날짜보다 엄격히 큰, 주어진 요일의 첫 발생을 반환." 요일 이름의 최소 첫 세 글자가 필요합니다.

## NEW_TIME 함수

"날짜와 시간을 한 시간대에서 다른 시간대로 변환." 미리 정의된 목록의 시간대를 받습니다(AST, ADT, BST, BDT, CST, CDT, EST, EDT, GMT, HST, HDT, MST, MDT, NST, PST, PDT, YST, YDT).

## NUMTODSINTERVAL 함수

"숫자 값을 일~초 인터벌 단위를 포함하는 시간 인터벌로 변환." 유효한 인터벌 타입: DAY, HOUR, MINUTE, SECOND.

## NUMTOYMINTERVAL 함수

"숫자 값을 연~월 인터벌 단위를 포함하는 시간 인터벌로 변환." 유효한 인터벌 타입: YEAR, MONTH.

## ROUND 함수

"지정된 템플릿 패턴에 따라 반올림된 날짜를 반환." 세기, 연, ISO 연, 분기, 월, 주, 일, 시, 분 단위 반올림을 지원합니다.

## SYSDATE 함수

"데이터베이스 서버가 있는 운영체제의 현재 날짜와 시간(시간대 없는 timestamp)을 반환."

## TRUNC 함수

"지정된 템플릿 패턴에 따라 잘린 날짜를 반환." 세기, 연, ISO 연, 분기, 월, 주, 일, 시, 분 단위 자름을 지원합니다.
