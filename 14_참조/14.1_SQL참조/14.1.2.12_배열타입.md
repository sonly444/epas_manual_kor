# 배열 타입 (Array types) — EPAS 18 데이터 타입

> 원문: [EPAS v18 — Reference › SQL reference › Data types › Array types](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/02_data_types/array_types/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·구문·코드는 원문 그대로 보존했습니다.

## 개요

"PostgreSQL은 테이블의 컬럼을 가변 길이 다차원 배열(variable-length multidimensional array)로 정의하는 것을 허용합니다." 배열은 내장 타입, 사용자 정의 타입, 열거형(enum), 복합 타입(composite type)으로 만들 수 있지만, 도메인 배열(domain array)은 아직 지원되지 않습니다.

## 선언

배열 타입은 기본 타입 이름에 대괄호를 붙여 선언합니다. 예를 들어 `integer[]`는 1차원 정수 배열을, `text[][]`는 2차원 텍스트 배열을 생성합니다.

`ARRAY` 키워드를 사용하는 SQL 표준 구문도 지원됩니다.
- `integer ARRAY[4]`는 크기를 지정합니다(강제되지는 않음).
- `integer ARRAY`는 길이를 지정하지 않습니다.

"현재 구현은 제공된 배열 크기 한계를 무시하며" 선언된 차원을 강제하지 않습니다.

## 배열 값 입력

배열 리터럴은 쉼표로 구분된 값과 함께 중괄호를 사용합니다: `'{ val1 delim val2 ... }'`. 다차원 배열은 그에 맞춰 중괄호를 중첩합니다. 특수 문자나 쉼표를 포함할 때 요소를 큰따옴표로 묶을 수 있습니다.

`ARRAY` 생성자 구문은 대안을 제공합니다: `ARRAY[10000, 10000, 10000, 10000]`

"다차원 배열은 각 차원에 대해 일치하는 크기(extent)를 가져야 합니다."

## 배열 접근

단일 요소는 기본적으로 1부터 시작하는 인덱싱과 대괄호 표기를 사용합니다: `pay_by_quarter[1]`

배열 슬라이스는 범위 구문을 사용합니다: `schedule[1:2][1:1]`은 특정 직사각형 구간을 조회합니다.

헬퍼 함수:
- `array_dims()` — 차원 정보 반환
- `array_upper()` / `array_lower()` — 경계 값
- `array_length()` — 차원 길이

## 배열 수정

전체 교체: `UPDATE sal_emp SET pay_by_quarter = '{25000,25000,27000,27000}'`

단일 요소 업데이트: `UPDATE sal_emp SET pay_by_quarter[4] = 15000`

슬라이스 업데이트: `UPDATE sal_emp SET pay_by_quarter[1:2] = '{27000,27000}'`

연결 연산자 `||`는 배열을 결합하며, `array_prepend()`, `array_append()`, `array_cat()` 같은 함수가 대안을 제공합니다.

## 배열 내 검색

`ANY` 또는 `ALL`과 함께 비교 연산자를 사용합니다.
- `WHERE 10000 = ANY (pay_by_quarter)`는 일치하는 요소를 찾습니다.
- `WHERE 10000 = ALL (pay_by_quarter)`는 모든 요소가 일치해야 합니다.

`&&` 연산자는 중첩(overlap)을 검사합니다: `WHERE pay_by_quarter && ARRAY[10000]`

## 입출력 구문

"배열 값의 외부 텍스트 표현은 항목들과 배열 구조를 나타내는 장식(decoration)으로 구성됩니다." 중괄호는 구조를 나타내고, 구분자(일반적으로 쉼표)는 항목을 분리합니다.

"배열 출력 루틴은 요소 값이 빈 문자열이거나 중괄호, 구분 문자, 큰따옴표, 백슬래시, 공백을 포함하면 값 주위에 큰따옴표를 붙입니다."

비표준 하한(lower bound)을 지정할 수 있습니다: `'[1:1][-2:-1][3:5]={{{1,2,3},{4,5,6}}}'`
