# 수학 함수·연산자 (Mathematical functions and operators) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Mathematical functions and operators](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/03_mathematical_functions_and_operators/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·연산자·값은 원문 그대로 보존했습니다.

## 수학 연산자

데이터베이스는 다음 기본 수학 연산자를 제공합니다.

| 연산자 | 설명 | 예 | 결과 |
|----------|-------------|---------|--------|
| `+` | 덧셈 | `2 + 3` | `5` |
| `-` | 뺄셈 | `2 – 3` | `-1` |
| `*` | 곱셈 | `2 * 3` | `6` |
| `/` | 나눗셈 | `4 / 2` | `2` |
| `**` | 거듭제곱 | `2 ** 3` | `8` |

**나눗셈 동작 참고:** `db_dialect` 구성 파라미터가 정수 나눗셈에 영향을 줍니다. `redwood`로 설정하면 "한 쌍의 INTEGER 데이터 타입의 나눗셈이 잘린(truncated) 값을 생성하지 않습니다." `postgres` 설정에서는 정수 나눗셈이 결과를 자릅니다.

## 수학 함수

| 함수 | 반환 타입 | 설명 | 예 | 결과 |
|----------|-------------|-------------|---------|--------|
| `ABS(x)` | 입력과 동일 | 절댓값 | `ABS(-17.4)` | `17.4` |
| `CEIL(DOUBLE PRECISION or NUMBER)` | 입력과 동일 | "인자보다 작지 않은 가장 작은 정수" | `CEIL(-42.8)` | `-42` |
| `EXP(DOUBLE PRECISION or NUMBER)` | 입력과 동일 | 지수 | `EXP(1.0)` | `2.7182818284590452` |
| `FLOOR(DOUBLE PRECISION or NUMBER)` | 입력과 동일 | "인자보다 크지 않은 가장 큰 정수" | `FLOOR(-42.8)` | `43` |
| `LN(DOUBLE PRECISION or NUMBER)` | 입력과 동일 | 자연 로그 | `LN(2.0)` | `0.6931471805599453` |
| `LOG(b NUMBER, x NUMBER)` | NUMBER | 밑이 b인 로그 | `LOG(2.0, 64.0)` | `6.0000000000000000` |
| `MOD(y, x)` | 입력과 동일 | "y/x의 나머지" | `MOD(9, 4)` | `1` |
| `NVL(x, y)` | 입력과 동일 | "x가 null이면 NVL은 y를 반환" | `NVL(9, 0)` | `9` |
| `POWER(a DOUBLE PRECISION, b DOUBLE PRECISION)` | DOUBLE PRECISION | "a의 b제곱" | `POWER(9.0, 3.0)` | `729.0000000000000000` |
| `POWER(a NUMBER, b NUMBER)` | NUMBER | "a의 b제곱" | `POWER(9.0, 3.0)` | `729.0000000000000000` |
| `ROUND(DOUBLE PRECISION or NUMBER)` | 입력과 동일 | 가장 가까운 정수로 반올림 | `ROUND(42.4)` | `42` |
| `ROUND(v NUMBER, s INTEGER)` | NUMBER | "소수 s자리로 반올림" | `ROUND(42.4382, 2)` | `42.44` |
| `SIGN(DOUBLE PRECISION or NUMBER)` | 입력과 동일 | "인자의 부호(-1, 0, +1)" | `SIGN(-8.4)` | `-1` |
| `SQRT(DOUBLE PRECISION or NUMBER)` | 입력과 동일 | 제곱근 | `SQRT(2.0)` | `1.414213562373095` |
| `TRUNC(DOUBLE PRECISION or NUMBER)` | 입력과 동일 | 0을 향해 자름 | `TRUNC(42.8)` | `42` |
| `TRUNC(v NUMBER, s INTEGER)` | NUMBER | "소수 s자리로 자름" | `TRUNC(42.4382, 2)` | `42.43` |
| `WIDTH_BUCKET(op NUMBER, b1 NUMBER, b2 NUMBER, count INTEGER)` | INTEGER | "등깊이 히스토그램에서 op가 할당될 버킷을 반환" | `WIDTH_BUCKET(5.35, 0.024, 10.06, 5)` | `3` |

## 삼각 함수

모든 삼각 함수는 `DOUBLE PRECISION` 값을 받고 반환합니다.

- `ACOS(x)` – 역코사인
- `ASIN(x)` – 역사인
- `ATAN(x)` – 역탄젠트
- `ATAN2(x, y)` – "x/y의 역탄젠트"
- `COS(x)` – 코사인
- `SIN(x)` – 사인
- `TAN(x)` – 탄젠트
