# 어휘 구조 (Lexical Structure) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › SQL reference › SQL syntax › Lexical structure](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/01_sql_syntax/01_lexical_structure/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드는 원문 그대로 보존했습니다.

SQL의 어휘 구조에는 여러 측면이 있습니다.

- SQL 입력은 명령(command)의 시퀀스로 구성됩니다.
- 명령은 세미콜론(`;`)으로 종료되는 토큰(token)의 시퀀스로 이루어집니다. 입력 스트림의 끝 역시 명령을 종료합니다.
- 유효한 토큰은 명령의 구문에 따라 달라집니다.
- 토큰은 키워드(key word), 식별자(identifier), 따옴표로 묶인 식별자(quoted identifier), 리터럴 또는 상수(literal or constant), 특수 문자 기호(special character symbol) 중 하나일 수 있습니다. 토큰은 보통 공백(스페이스, 탭, 개행)으로 구분되지만, 모호함이 없다면 반드시 구분할 필요는 없습니다. 이는 일반적으로 특수 문자가 다른 토큰 유형에 인접해 있는 경우에만 해당합니다.
- SQL 입력에는 주석(comment)이 나타날 수 있습니다. 주석은 토큰이 아니며 공백과 동등하게 취급됩니다.

예를 들어, 다음은 구문적으로 유효한 SQL 입력입니다:

```sql
SELECT * FROM MY_TABLE;
UPDATE MY_TABLE SET A = 5;
INSERT INTO MY_TABLE VALUES (3, 'hi there');
```

이것은 세 개의 명령으로 이루어진 시퀀스로, 한 줄에 하나씩 작성되어 있습니다. 다만 이러한 형식이 필수는 아닙니다. 한 줄에 두 개 이상의 명령을 입력할 수 있고, 명령은 보통 여러 줄에 걸쳐 나눌 수도 있습니다.

SQL 구문은 명령을 식별하는 토큰과 피연산자(operand) 또는 파라미터인 토큰에 대해 매우 일관적이지는 않습니다. 처음 몇 개의 토큰은 일반적으로 명령 이름이므로, 위 예제에는 `SELECT`, `UPDATE`, `INSERT` 명령이 포함되어 있습니다. 하지만 예를 들어 `UPDATE` 명령은 항상 특정 위치에 `SET` 토큰이 나타나야 하며, 이 형태의 `INSERT`는 완성을 위해 `VALUES` 토큰도 필요합니다. 각 명령의 정확한 구문 규칙은 [SQL 참조](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/)에 설명되어 있습니다.
