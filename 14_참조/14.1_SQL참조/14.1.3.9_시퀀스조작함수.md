# 시퀀스 조작 함수 (Sequence manipulation functions) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Sequence manipulation functions](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/09_sequence_manipulation_functions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·명령·구문은 원문 그대로 보존했습니다.

시퀀스 객체(시퀀스 생성기라고도 함)는 `CREATE SEQUENCE` 명령으로 생성되는 특수한 단일 행 테이블로, 일반적으로 테이블 행의 고유 식별자를 생성하는 데 사용됩니다.

## 구문

```sql
sequence.NEXTVAL
sequence.CURRVAL
```

여기서 `sequence`는 시퀀스 생성 시 부여된 식별자입니다.

## 함수

**NEXTVAL**

시퀀스를 다음 값으로 이동시키고 그 값을 반환합니다. 이 작업은 원자적(atomic)입니다. 여러 동시 세션이 각각 안전하게 서로 다른 값을 받습니다.

**CURRVAL**

현재 세션에서 `NEXTVAL`로 얻은 가장 최근 값을 반환합니다. 그 세션에서 `NEXTVAL`이 한 번도 실행되지 않았으면 오류가 발생합니다. 이는 다른 세션의 활동과 관계없이 일관된 결과를 제공하는 세션 지역(session-local) 값을 반환합니다.

## 기본 동작

기본 파라미터로 생성된 시퀀스는 `NEXTVAL` 호출에서 1부터 시작하는 연속 값을 반환합니다. 대체 동작을 위해서는 `CREATE SEQUENCE`에서 특수 파라미터를 사용합니다.

## 중요 참고

`NEXTVAL` 작업은 동시 트랜잭션 차단을 방지하기 위해 결코 롤백되지 않습니다. 값이 한 번 가져와지면 트랜잭션이 나중에 중단되더라도 사용된 것으로 표시됩니다. 이로 인해 할당된 시퀀스 값에 사용되지 않은 간격(gap)이 생길 수 있습니다.
