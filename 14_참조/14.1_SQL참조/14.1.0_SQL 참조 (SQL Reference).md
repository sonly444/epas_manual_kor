# SQL 참조 (SQL Reference) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › SQL reference](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/)
> EPAS v18 공식 문서의 한글 번역입니다. 명령·타입 이름은 원문 그대로 보존했습니다.

EPAS와 Oracle 데이터베이스 간 호환되는 SQL 언어의 부분집합을 다룹니다.

## 하위 구성
- **SQL 구문(SQL syntax)**: 일반 구문에 대한 기본 정보(식별자·리터럴·연산자·표현식 등).
- **데이터 타입(Data types)**: 특정 데이터 타입 설명(`NUMBER`, `VARCHAR2`, `CHAR`, `DATE`, `TIMESTAMP`, `CLOB`, `BLOB`, `BOOLEAN` 등 Oracle 호환 타입 포함).
- **함수와 연산자(Functions and operators)**: 내장 데이터 타입에 대한 함수·연산자 설명(문자·숫자·날짜/시간·집계·변환 함수 등).

> 각 항목의 전체 표(모든 함수 시그니처·타입 속성)는 방대하므로, 특정 함수/타입의 상세가 필요하면 해당 페이지를 지정해 추가 번역할 수 있습니다.
