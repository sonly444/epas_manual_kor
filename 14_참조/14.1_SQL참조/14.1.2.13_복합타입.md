# 복합 타입 (Composite types) — EPAS 18 데이터 타입

> 원문: [EPAS v18 — Reference › SQL reference › Data types › Composite types](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/02_data_types/composite_types/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·구문·코드는 원문 그대로 보존했습니다.

## 개요

복합 타입(composite type)은 행이나 레코드의 구조 — 즉 필드 이름과 그 데이터 타입의 목록 — 를 나타냅니다. PostgreSQL은 복합 타입이 단순 타입과 유사하게 동작하도록 허용하며, 예를 들어 테이블 컬럼을 복합 타입으로 선언할 수 있습니다.

## 복합 타입 선언

복합 타입은 `CREATE TYPE` 구문으로 정의합니다.

```sql
CREATE TYPE complex AS (
    r       double precision,
    i       double precision
);

CREATE TYPE inventory_item AS (
    name            text,
    supplier_id     integer,
    price           numeric
);
```

구문은 `CREATE TABLE`과 유사하지만 필드 이름과 타입만 지정합니다. 문서에 따르면 "현재 (`NOT NULL` 같은) 제약 조건은 포함할 수 없습니다."

이 타입들은 이후 테이블 정의에 사용할 수 있습니다.

```sql
CREATE TABLE on_hand (
    item      inventory_item,
    count     integer
);

INSERT INTO on_hand VALUES (ROW('fuzzy dice', 42, 1.99), 1000);
```

## 복합 값 구성

복합 값은 괄호와 쉼표 구분을 사용하여 구성합니다.

```sql
'( val1 , val2 , ... )'
'("fuzzy dice",42,1.99)'
```

또는 `ROW` 표현식을 사용합니다.

```sql
ROW('fuzzy dice', 42, 1.99)
('fuzzy dice', 42, 1.99)
```

NULL 값의 경우 위치를 비워 두고, 빈 문자열의 경우 큰따옴표 `""`를 사용합니다.

## 복합 타입 접근

필드 접근은 복합 참조 주위에 괄호가 필요합니다.

```sql
SELECT (item).name FROM on_hand WHERE (item).price > 9.99;
SELECT (on_hand.item).name FROM on_hand WHERE (on_hand.item).price > 9.99;
```

## 복합 타입 수정

전체 복합 컬럼 삽입 또는 업데이트:

```sql
INSERT INTO mytab (complex_col) VALUES((1.1,2.2));
UPDATE mytab SET complex_col = ROW(1.1,2.2) WHERE ...;
```

개별 서브필드 업데이트:

```sql
UPDATE mytab SET complex_col.r = (complex_col).r + 1 WHERE ...;
```

INSERT 문에서 서브필드 지정:

```sql
INSERT INTO mytab (complex_col.r, complex_col.i) VALUES(1.1, 2.2);
```

## 쿼리에서 복합 타입 사용

테이블 참조는 현재 행의 복합 값을 나타냅니다.

```sql
SELECT c FROM inventory_item c;
```

`.*` 구문은 복합 값을 별도의 컬럼으로 확장합니다.

```sql
SELECT c.* FROM inventory_item c;
```

함수 표기법으로 필드를 상호 교환하여 추출할 수 있습니다.

```sql
SELECT c.name FROM inventory_item c WHERE c.price > 1000;
SELECT name(c) FROM inventory_item c WHERE price(c) > 1000;
```

## 복합 타입 입출력 구문

외부 표현은 괄호와 쉼표를 사용합니다. 필드 값은 특히 특수 문자를 포함할 때 큰따옴표로 묶일 수 있습니다. 빈 필드는 NULL을 나타내고 `""`는 빈 문자열을 나타냅니다.

문서는 다음을 언급합니다: "SQL 명령에서 복합 값을 작성할 때 `ROW` 생성자 구문이 복합 리터럴 구문보다 대개 다루기 쉽습니다."
