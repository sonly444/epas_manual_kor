# Redwood 권한 함수 (Redwood privileges functions) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Redwood privileges functions](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/redwood_specific_privs_functions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·권한 이름은 원문 그대로 보존했습니다.

역할이 Redwood 전용 권한을 가지는지 확인하는 데 사용할 수 있는 함수는 다음과 같습니다.

## has_createdblink_privilege(name)

사용자가 이름으로 비공개 데이터베이스 링크를 생성할 수 있는지 판단합니다.
- **입력:** 사용자 이름(문자열)
- **반환:** 사용자가 `CREATE DATABASE LINK` 권한을 가지면 `true`, 그렇지 않으면 `false`

## has_createdblink_privilege(oid)

사용자가 객체 식별자(OID)로 비공개 데이터베이스 링크를 생성할 수 있는지 판단합니다.
- **입력:** 사용자 OID
- **반환:** `CREATE DATABASE LINK` 권한을 가지면 `true`, 그렇지 않으면 `false`

## has_createpublicdblink_privilege(name)

사용자가 이름으로 **공개(public)** 데이터베이스 링크(모든 사용자가 접근 가능)를 생성할 수 있는지 확인합니다.
- **반환:** `CREATE PUBLIC DATABASE LINK` 권한을 가지면 `true`, 그렇지 않으면 `false`

## has_createpublicdblink_privilege(oid)

사용자가 OID로 **공개** 데이터베이스 링크를 생성할 수 있는지 확인합니다.
- **반환:** `CREATE PUBLIC DATABASE LINK` 권한을 가지면 `true`, 그렇지 않으면 `false`

## has_alterdblink_privilege(name) / (oid)

사용자가 이름 또는 OID로 비공개 링크에 대한 `ALTER DATABASE LINK` 권한을 가지는지 확인합니다.
- **반환:** 지정된 비공개 데이터베이스 링크를 변경할 수 있으면 `true`, 그렇지 않으면 `false`

## has_alterpublicdblink_privilege(name) / (oid)

사용자가 이름 또는 OID로 `ALTER PUBLIC DATABASE LINK` 권한을 가지는지 확인합니다.
- **반환:** 지정된 공개 데이터베이스 링크를 변경할 수 있으면 `true`, 그렇지 않으면 `false`

## has_droppublicdblink_privilege(name) / (oid)

사용자가 이름 또는 OID로 **공개** 데이터베이스 링크를 삭제할 수 있는지 판단합니다.
- **반환:** `DROP PUBLIC DATABASE LINK` 권한을 가지면 `true`, 그렇지 않으면 `false`

## has_exemptaccesspolicy_privilege(name) / (oid)

사용자가 역할에 대해 `EXEMPT ACCESS POLICY` 권한을 가지는지 확인합니다(행 수준 보안 정책 우회 허용). 이름 또는 OID로 지정합니다.
- **반환:** 지정된 역할에 대해 `EXEMPT ACCESS POLICY` 권한을 가지면 `true`, 그렇지 않으면 `false`
