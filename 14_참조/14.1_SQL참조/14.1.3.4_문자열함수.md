# 문자열 함수·연산자 (String functions and operators) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › String functions and operators](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/04_string_functions_and_operators/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·연산자 이름은 원문 그대로 보존했습니다.

## 개요

이 문서는 `CHAR`, `VARCHAR2`, `CLOB` 타입의 문자열 값을 검사하고 조작하는 함수를 다룹니다. 가이드에 따르면 "여기서 설명하는 함수는 비문자열(nonstring) 타입의 데이터를 먼저 문자열 표현으로 변환하여 그 데이터에도 동작합니다."

## 주요 문자열 함수

문서는 두 개의 포괄적인 문자열 조작 함수 표를 제시합니다.

**첫 번째 표에 포함된 것:**
- 연결 연산자(`||` 및 `CONCAT`)
- 변환 함수(`HEXTORAW`, `RAWTOHEX`)
- 위치 찾기(`INSTR`, `INSTRB`)
- 대소문자 변환(`LOWER`, `UPPER`)
- 문자 집합 함수(`NLS_CHARSET_ID`, `NLS_CHARSET_NAME`, `NLS_CHARSET_DECL_LEN`)
- 부분 문자열 추출(`SUBSTR`, `SUBSTRB`, `SUBSTR2`, `SUBSTR4`, `SUBSTRC`)
- 트리밍 함수(`TRIM`, `LTRIM`, `RTRIM`)

**두 번째 표에 포함된 것:**
- `ASCII()` — 첫 바이트의 ASCII 코드를 반환
- `CHR()` — 주어진 ASCII 코드에 해당하는 문자를 반환
- `DECODE()` — 조건부 매칭 및 치환
- `INITCAP()` — 각 단어의 첫 글자를 대문자로
- 길이 함수(`LENGTH`, `LENGTHB`, `LENGTHC`, `LENGTH2`, `LENGTH4`)
- 패딩 함수(`LPAD`, `RPAD`)
- `REPLACE()` — 검색 문자열을 치환
- `TRANSLATE()` — 문자 단위 치환

## NULL 연결 동작

중요한 참고: "EDB Postgres Advanced Server에서 컬럼 값이 `NULL`이면, 컬럼과 텍스트 문자열의 연결은 다음 중 하나로 나타날 수 있습니다: 텍스트 문자열 반환 [또는] 텍스트 문자열 소멸."

문서는 NULL 값에 대해 일관된 동작을 보장하기 위해 명시적 `::text` 캐스팅이나 `CONCAT` 함수 사용을 권장합니다.
