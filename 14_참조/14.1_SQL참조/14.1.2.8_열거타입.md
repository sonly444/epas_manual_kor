# 열거 타입 (Enumerated types) — EPAS 18 데이터 타입

> 원문: [EPAS v18 — Reference › SQL reference › Data types › Enumerated types](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/02_data_types/enumerated_types/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입·카탈로그·코드는 원문 그대로 보존했습니다.

## 개요

이 문서는 `ENUM` 데이터 타입을 "정적이고 순서가 있는 값 집합, 4바이트 저장, 최대 길이는 `NAMEDATALEN` 설정에 의해 제한됨"으로 설명합니다.

## 주요 특성

`ENUM` 타입은 대소문자를 구분하며, 열거 값 안의 공백(whitespace)은 의미를 가집니다. 열거 타입과 그 레이블은 `pg_enum` 시스템 카탈로그에서 관리됩니다.

## 사용 예제

문서는 다음 샘플 구현을 제공합니다.

```sql
CREATE TYPE city AS ENUM('Pune','Mumbai','Chennai');
CREATE TABLE shops(name text, location city);
INSERT INTO shops VALUES('Puma','Mumbai');
SELECT * FROM shops;
```

출력은 삽입된 데이터를 담은 name과 location 컬럼을 가진 테이블을 보여 줍니다.

## 저장 및 참조

이 타입은 값당 4바이트의 저장 공간을 사용합니다. 열거 데이터 타입에 대한 포괄적인 세부 정보는 해당 주제에 대한 PostgreSQL 공식 문서를 참조하십시오.
