# 식별자 함수 (Identifier functions) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Identifier functions](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/13_identifier_functions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·파라미터·코드는 원문 그대로 보존했습니다.

식별자 함수는 인스턴스와 세션에 대한 정보를 제공합니다.

## SYS_GUID

"`SYS_GUID` 함수는 전역적으로 고유한 식별자(globally unique identifier)를 생성하여 반환합니다. 이 식별자는 16바이트의 `RAW` 데이터 형태를 취합니다."

**시그니처:**
```sql
SYS_GUID()
```

**예:** SYS_GUID를 기본값으로 하는 RAW 컬럼을 가진 테이블을 생성하면 `\xb944970d3a1b42a7a2119265c49cbb7f` 같은 16바이트 16진수 값을 생성합니다.

## USERENV

"`USERENV` 함수는 현재 세션에 대한 정보를 조회합니다."

**시그니처:**
```sql
USERENV(<parameter>)
```

**지원 파라미터:**

| 파라미터 | 설명 |
|-----------|-------------|
| `ISDBA` | 현재 사용자가 DBA 권한을 가지면 `TRUE`, 그렇지 않으면 `FALSE`를 반환 |
| `LANGUAGE` | "현재 세션의 언어, 지역, 문자 집합을 다음 형식으로: `language_territory.characterset`" |
| `LANG` | 언어 이름의 ISO 약어 |
| `SID` | 현재 세션 식별자 |
| `TERMINAL` | "현재 세션의 운영체제 터미널 식별자" |

## SYS_CONTEXT

"`SYS_CONTEXT` 함수는 컨텍스트 `namespace`와 연관된 `parameter`의 값을 반환합니다."

**시그니처:**
```sql
SYS_CONTEXT(<namespace>, <parameter>)
SYS_CONTEXT(<userenv>, <parameter>)
```

내장 `USERENV` 네임스페이스를 사용할 때 USERENV와 동일한 파라미터를 지원합니다.
