# 패턴 매칭 문자열 함수 (Pattern matching string functions) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Pattern matching string functions](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/05_pattern_matching_string_functions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·시그니처·코드는 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 POSIX 스타일 정규 표현식을 사용하여 문자열을 검색하고 패턴 발생에 대한 정보를 반환하는 세 가지 주요 패턴 매칭 함수를 제공합니다.

## REGEXP_COUNT

이 함수는 정규 표현식 패턴이 문자열에 몇 번 나타나는지 셉니다.

**시그니처:**
```sql
INTEGER REGEXP_COUNT(srcstr TEXT, pattern TEXT, position DEFAULT 1, modifier DEFAULT NULL)
```

**파라미터:**
- `srcstr`: 검색할 문자열
- `pattern`: 찾을 정규 표현식
- `position`: 시작 위치(기본값: 1)
- `modifier`: 패턴 매칭 동작 제어(기본값: NULL)

**예:** `'reinitializing'`에서 글자 `i`를 검색하면 위치 1에서 시작할 때 `5`를, 위치 6에서 시작할 때 `3`을 반환합니다.

## REGEXP_INSTR

이 함수는 문자열 안에서 패턴 일치가 발생하는 위치를 찾습니다.

**시그니처:**
```sql
INTEGER REGEXP_INSTR(srcstr TEXT, pattern TEXT, position INT DEFAULT 1, occurrence INT DEFAULT 1, returnparam INT DEFAULT 0, modifier TEXT DEFAULT NULL, subexpression INT DEFAULT 0)
```

**파라미터:**
- `srcstr`: 검색할 문자열
- `pattern`: 일치시킬 정규 표현식
- `position`: 시작 위치(기본값: 1)
- `occurrence`: 반환할 일치 번호(기본값: 1)
- `returnparam`: 반환 유형 — 0은 일치 시작, >0은 일치 이후 위치(기본값: 0)
- `modifier`: 패턴 매칭 동작 제어(기본값: NULL)
- `subexpression`: 반환할 괄호 패턴 그룹(기본값: 0)

**예:** `'800-555-1212'`에서 `[0-9][0-9][0-9]`를 검색하면 첫 발생에 `1`, 두 번째에 `5`를 반환합니다.

## REGEXP_SUBSTR

이 함수는 지정된 패턴과 일치하는 부분 문자열을 추출하여 반환합니다.

**시그니처:**
```sql
TEXT REGEXP_SUBSTR(srcstr TEXT, pattern TEXT, position INT DEFAULT 1, occurrence INT DEFAULT 1, modifier TEXT DEFAULT NULL, subexpression INT DEFAULT 0)
```

**파라미터:**
- `srcstr`: 검색할 문자열
- `pattern`: 일치시킬 정규 표현식
- `position`: 시작 위치(기본값: 1)
- `occurrence`: 반환할 일치 번호(기본값: 1)
- `modifier`: 패턴 매칭 동작 제어(기본값: NULL)
- `subexpression`: 추출할 괄호 패턴 그룹(기본값: 0)

**예:** `'800-555-1212'`에서 `[0-9][0-9][0-9]`를 검색하면 첫 일치에 `'800'`, 두 번째에 `'555'`를 반환합니다.
