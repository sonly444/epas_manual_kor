# 네트워크 주소 타입 (Network address types) — EPAS 18 데이터 타입

> 원문: [EPAS v18 — Reference › SQL reference › Data types › Network address types](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/02_data_types/network_address_types/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 IP 및 MAC 주소를 저장하기 위한 네 가지 네트워크 주소 데이터 타입을 제공합니다.

| 데이터 타입 | 저장 | 용도 |
|-----------|---------|---------|
| `CIDR` | 7 또는 19바이트 | "IPV4 및 IPV6 네트워크" |
| `INET` | 7 또는 19바이트 | "IPV4 및 IPV6 호스트와 네트워크" |
| `MACADDR` | 6바이트 | MAC 주소 |
| `MACADDR8` | 8바이트 | "MAC 주소(EUI-64 형식)" |

## 주요 기능

이 플랫폼은 내장 기능과 함께 "IPV4, IPV6, MAC 주소를 저장하는 데이터 타입"을 제공합니다. 이 타입들은 데이터 검증과 조작 능력을 향상시키기 위해 "입력 오류 검사와 전용 연산자·함수"를 포함합니다.

네 가지 타입은 모두 시스템의 네이티브로 표시되며, 다른 타입의 별칭이 아니라 EDB Postgres Advanced Server의 핵심 기능임을 나타냅니다.

포괄적인 기술 세부 정보는 PostgreSQL 공식 네트워크 타입 문서를 참조하십시오.
