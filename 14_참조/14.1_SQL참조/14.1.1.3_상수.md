# 상수 (Constants) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › SQL reference › SQL syntax › Constants](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/01_sql_syntax/03_constants/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·타입 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server에서 암시적으로 타입이 지정되는(implicitly typed) 상수의 종류는 *문자열(strings)*과 *숫자(numbers)*입니다. 명시적 타입으로 상수를 지정할 수도 있으며, 이를 통해 더 정확한 표현과 시스템의 더 효율적인 처리가 가능해집니다.

## 문자열 상수 (String constants)

SQL에서 *문자열 상수(string constant)*는 작은따옴표(`'`)로 묶인 임의의 문자 시퀀스입니다. 예: `'This is a string'`. 문자열 상수에 작은따옴표 문자를 포함하려면, 인접한 작은따옴표 두 개를 넣습니다. 예: `'Dianne''s horse'`. (작은따옴표 두 개는 큰따옴표 문자(`"`)와 다릅니다.)

## 숫자 상수 (Numeric constants)

숫자 상수는 다음의 일반적인 형태로 허용됩니다:

```sql
digits
digits.[digits][e[+-]digits]
[digits].digits[e[+-]digits]
digitse[+-]digits
```

여기서 `digits`는 하나 이상의 십진 숫자(0부터 9)입니다. 소수점을 사용하는 경우 소수점 앞 또는 뒤에 적어도 하나의 숫자를 입력해야 합니다. 지수 표시자(`e`)가 있는 경우 그 뒤에 적어도 하나의 숫자가 와야 합니다. 상수에 공백이나 기타 문자를 포함하지 마십시오. 앞에 붙는 플러스 또는 마이너스 기호는 상수의 일부로 간주되지 않습니다. 그것들은 상수에 적용되는 연산자입니다.

다음은 유효한 숫자 상수의 예입니다:

```sql
42
3.5
4.
.001
5e2
1.925e-3
```

소수점이나 지수를 포함하지 않는 숫자 상수는, 값이 `INTEGER` 타입(32비트)에 맞으면 처음에는 `INTEGER` 타입으로 추정됩니다. 그렇지 않고 값이 `BIGINT` 타입(64비트)에 맞으면 `BIGINT` 타입으로 추정됩니다. 그런 다음에도 값이 `BIGINT` 타입에 맞지 않으면 `NUMBER` 타입으로 간주됩니다. 소수점이나 지수를 포함하는 상수는 항상 처음에 `NUMBER` 타입으로 추정됩니다.

숫자 상수에 처음 할당된 데이터 타입은 타입 해석(type resolution) 알고리즘의 시작점일 뿐입니다. 대부분의 경우 상수는 문맥에 따라 가장 적절한 타입으로 자동 강제 변환(coerce)됩니다. 필요한 경우, [기타 타입 상수](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/01_sql_syntax/03_constants/#constants-of-other-types)에서 설명하는 대로 캐스팅하여 숫자 값을 특정 데이터 타입으로 해석하도록 강제할 수 있습니다.

## 기타 타입의 상수 (Constants of other types)

### CAST

다음 표기법을 사용하여 임의 타입의 상수를 입력할 수 있습니다:

```sql
CAST('string' AS type)
```

문자열 상수의 텍스트는 `type`이라는 타입의 입력 변환 루틴으로 전달됩니다. 결과는 지정된 타입의 상수입니다. 상수의 타입에 모호함이 없는 경우(예: 테이블 컬럼에 직접 할당될 때)에는 명시적 타입 캐스트를 생략할 수 있으며, 이 경우 자동으로 강제 변환됩니다.

또한 `CAST`를 사용하여 임의 표현식의 런타임 타입 변환을 지정할 수 있습니다.

### CAST (MULTISET)

`MULTISET`은 서브쿼리 결과를 중첩 테이블 타입(nested table type)으로 변환하는 `CAST`의 확장입니다. 구문 개요는 다음과 같습니다:

```sql
CAST ( MULTISET ( < subquery > ) AS < datatype > )
```

여기서 `subquery`는 하나 이상의 행을 반환하는 쿼리이고, `datatype`은 중첩 테이블 타입입니다.

`CAST(MULTISET)`은 데이터 컬렉션을 테이블에 저장하는 데 사용됩니다.

## 예제 (Example)

이 예제는 `MULTISET`을 사용합니다:

```sql
edb=# CREATE OR REPLACE TYPE project_table_t AS TABLE OF VARCHAR2(25);
CREATE TYPE
edb=# CREATE TABLE projects (person_id NUMBER(10), project_name VARCHAR2(20));
CREATE TABLE
edb=# CREATE TABLE pers_short (person_id NUMBER(10), last_name VARCHAR2(25));
CREATE TABLE
```

```sql
edb=# INSERT INTO projects VALUES (1, 'Teach');
INSERT 0 1
edb=# INSERT INTO projects VALUES (1, 'Code');
INSERT 0 1
edb=# INSERT INTO projects VALUES (2, 'Code');
INSERT 0 1
edb=# INSERT INTO pers_short VALUES (1, 'Morgan');
INSERT 0 1
edb=# INSERT INTO pers_short VALUES (2, 'Kolk');
INSERT 0 1
edb=# INSERT INTO pers_short VALUES (3, 'Scott');
INSERT 0 1
edb=# COMMIT;
COMMIT
```

```sql
edb=# SELECT e.last_name, CAST(MULTISET(
edb(#   SELECT p.project_name
edb(#   FROM projects p
edb(#   WHERE p.person_id = e.person_id
edb(#   ORDER BY p.project_name) AS project_table_t)
edb-# FROM pers_short e;
```

출력(Output):

```text
 last_name | project_table_t
-----------+-----------------
 Morgan    | {Code,Teach}
 Kolk      | {Code}
 Scott     | {}
(3 rows)
```
