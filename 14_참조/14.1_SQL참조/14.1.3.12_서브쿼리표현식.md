# 서브쿼리 표현식 (Subquery expressions) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Subquery expressions](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/12_subquery_expressions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 연산자·구문·코드는 원문 그대로 보존했습니다.

SQL 준수 서브쿼리 표현식은 불리언(TRUE/FALSE) 결과를 반환합니다.

## EXISTS

`EXISTS` 연산자는 임의의 SELECT 문이나 서브쿼리가 행을 반환하는지 평가합니다. 문서에 따르면 "적어도 한 행을 반환하면 `EXISTS`의 결과는 `TRUE`입니다. 서브쿼리가 행을 반환하지 않으면 `EXISTS`의 결과는 `FALSE`입니다."

구문:
```sql
EXISTS(subquery)
```

서브쿼리는 적어도 한 행이 존재하는지 판단할 만큼만 실행되며, 반드시 완료까지 실행되지는 않습니다.

예:
```sql
SELECT dname FROM dept WHERE EXISTS (SELECT 1 FROM emp WHERE emp.deptno = dept.deptno);
```

## IN

오른쪽은 정확히 한 컬럼을 반환하는 괄호로 묶인 서브쿼리여야 합니다. 왼쪽 표현식은 각 서브쿼리 행과 비교됩니다. 같은 행이 존재하면 `TRUE`, 없으면 `FALSE`입니다. 어느 쪽이든 `NULL`을 산출하고 같은 일치가 없으면 결과는 `NULL`입니다.

구문:
```sql
expression IN (subquery)
```

## NOT IN

오른쪽 서브쿼리는 정확히 한 컬럼을 반환해야 합니다. 모든 서브쿼리 행이 왼쪽 표현식과 다를 때만 결과가 `TRUE`입니다. 같은 행이 하나라도 존재하면 `FALSE`입니다. `NULL` 결과는 표준 SQL 불리언 논리를 따릅니다.

구문:
```sql
expression NOT IN (subquery)
```

## ANY/SOME

지정된 연산자를 사용하여 왼쪽 표현식을 각 서브쿼리 행과 비교하여 불리언 결과를 산출합니다. 비교 중 하나라도 성공하면 `TRUE`, 하나도 성공하지 않으면 `FALSE`를 반환합니다. `SOME`은 `ANY`의 동의어이며, `IN`은 `= ANY`와 동등합니다.

구문:
```sql
expression operator ANY (subquery)
expression operator SOME (subquery)
```

## ALL

주어진 연산자를 사용하여 왼쪽 표현식을 각 서브쿼리 행과 비교합니다. 모든 행이 true를 산출하면(서브쿼리가 행을 반환하지 않는 경우 포함) `TRUE`, 어느 비교든 실패하면 `FALSE`를 반환합니다. `NOT IN`은 `<> ALL`과 동등합니다.

구문:
```sql
expression operator ALL (subquery)
```
