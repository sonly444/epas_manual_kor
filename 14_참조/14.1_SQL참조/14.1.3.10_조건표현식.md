# 조건 표현식 (Conditional expressions) — EPAS 18 함수와 연산자

> 원문: [EPAS v18 — Reference › SQL reference › Functions and operators › Conditional expressions](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/10_conditional_expressions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·키워드는 원문 그대로 보존했습니다.

## CASE

SQL의 `CASE` 표현식은 프로그래밍 언어의 if/else 로직과 유사한 조건문으로 동작합니다. 두 가지 변형이 있습니다.

**일반 형식:** 조건을 순차적으로 평가하여 하나가 `TRUE`를 반환할 때까지 진행한 다음, 연관된 결과를 반환합니다. 일치하는 조건이 없고 `ELSE` 절이 없으면 결과는 `NULL`입니다.

**단순 형식:** 표현식을 한 번 계산하여 `WHEN` 절의 여러 값과 비교합니다. 일치하는 값이 연관된 결과를 트리거합니다.

주요 장점: "`CASE` 표현식은 결과를 결정하는 데 필요하지 않은 하위 표현식은 평가하지 않습니다." 이를 통해 0으로 나누기 오류를 피하는 등의 기법이 가능합니다.

## COALESCE

"null이 아닌 첫 번째 인자를 반환합니다. 모든 인자가 null인 경우에만 null이 반환됩니다." 데이터 조회 중 기본값을 대체하는 데 유용합니다. `CASE`처럼 불필요한 인자 평가를 피합니다.

## NULLIF

"`NULLIF` 함수는 `value1`과 `value2`가 같으면 null 값을 반환합니다. 그렇지 않으면 `value1`을 반환합니다." `COALESCE`의 역연산을 수행합니다.

## NVL

null이 아닌 첫 번째 인자를 반환합니다. "반환 타입은 첫 번째 인자의 타입과 같습니다." 다른 데이터베이스의 `NVL` 및 `IFNULL` 함수와 유사한 Oracle 호환 null 처리를 제공합니다.

## NVL2

"첫 번째 표현식이 `NULL`이 아니면 `NVL2`는 `expr2`의 값을 반환합니다. 첫 번째 표현식이 `NULL`이면 `NVL2`는 `expr3`의 값을 반환합니다." null 상태에 기반한 조건 분기를 가능하게 합니다.

## NANVL

not-a-number(NaN) 값을 특별히 처리합니다. "그 표현식이 NAN 값으로 평가되면 `NANVL`은 두 번째 표현식을 반환합니다." 

## LNNVL

"조건이 `FALSE` 또는 `UNKNOWN`이면 `TRUE`를, 조건이 `TRUE`이면 `FALSE`를 반환합니다." `WHERE` 절과 `CASE` 표현식에서 간결한 null 인식 조건 평가를 가능하게 합니다.

## GREATEST와 LEAST

"임의 개수의 표현식 목록에서 가장 큰 값 또는 가장 작은 값을 선택합니다." null 값은 무시되며, 모든 표현식이 null로 평가될 때만 결과가 null입니다.
