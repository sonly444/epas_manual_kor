# 참조 (Reference) — EDB Postgres Advanced Server 18

> 원문: [EPAS v18 Documentation — Reference](https://www.enterprisedb.com/docs/epas/latest/reference/)
> EPAS v18 공식 문서의 한글 번역입니다. 명령·파라미터·뷰·패키지 이름은 원문 그대로 보존했습니다. 참조 섹션은 방대한 카탈로그이므로 항목 구조 중심으로 정리했습니다. 특정 항목의 전체 표·상세가 필요하면 해당 페이지를 지정해 추가 번역 가능합니다.

Reference는 네 개의 주요 하위 참조로 구성됩니다: SQL 참조 / 애플리케이션 프로그래머 참조 / 데이터베이스 관리자 참조 / Oracle 호환 참조.

---

## 1. SQL 참조 (SQL reference)

EPAS와 Oracle 데이터베이스 간 호환되는 SQL 언어의 부분집합을 다룹니다.

- **SQL 구문(SQL syntax)**: 일반 구문에 대한 기본 정보.
- **데이터 타입(Data types)**: 특정 데이터 타입 설명.
- **함수와 연산자(Functions and operators)**: 내장 데이터 타입에 대한 함수·연산자 설명.

---

## 2. 애플리케이션 프로그래머 참조 (Application programmer reference)

- **테이블 파티셔닝 뷰 참조(Table partitioning views reference)**: 파티션 관련 뷰.
- **시스템 카탈로그 테이블(System catalog tables)**: 지원되는 시스템 카탈로그 테이블 설명.
- **언어 요소 참조(Language element reference)**: ECPGPlus 언어 요소 설명.
- **SPL 참조(SPL reference)**: SPL 프로시저·함수·트리거·패키지에 대한 참조 콘텐츠.

---

## 3. 데이터베이스 관리자 참조 (Database administrator reference)

- **감사 로깅 구성 파라미터(Audit logging configuration parameters)**: 데이터베이스 감사를 제어하는 파라미터(`edb_audit*` 계열).
- **Oracle 호환 구성 파라미터(Configuration parameters compatible with Oracle databases)**: 시스템 동작을 PostgreSQL 또는 Oracle에 더 가깝게 맞추는 파라미터.
- **구성 파라미터 요약(Summary of configuration parameters)**: 사용 가능한 전체 구성 파라미터 목록(EPAS 전용 `edb_*` 포함).
- **감사 로그 파일(Audit log files)**: 감사 로그의 구조와 필드.
- **EDB\*Loader 컨트롤 파일 파라미터(EDB\*Loader control file parameters)**: 컨트롤 파일 각 절의 파라미터 설명.
- **시스템 카탈로그(System catalogs)**: EDB Resource Manager의 리소스 그룹 정보를 저장하는 시스템 카탈로그(`edb_resource_manager` 관련).

---

## 4. Oracle 호환 참조 (Oracle compatibility reference)

Oracle 애플리케이션을 EPAS로 전환하는 조직을 지원합니다.

- **dblink_ora 함수·프로시저**: dblink_ora가 지원하는 함수·프로시저(`dblink_ora_connect`, `dblink_ora_record`, `dblink_ora_exec`, `dblink_ora_call` 등).
- **Oracle 호환 파티셔닝 명령**: Oracle 호환 테이블 파티셔닝 구문 목록.
- **내장 패키지(Built-in packages)**: EPAS가 제공하는 내장 패키지 목록(`DBMS_*`, `UTL_*` 계열 등).
- **카탈로그 뷰(Catalog Views)**: EPAS가 제공하는 Oracle 데이터 딕셔너리 호환 카탈로그 뷰(`ALL_`/`DBA_`/`USER_` 계열 등).
- **Oracle 호환 SQL 명령**: Oracle 호환 SQL 명령 목록.
- **Oracle 호환 구성 파라미터 목록**: 시스템 동작을 PostgreSQL 또는 Oracle처럼 제어하는 파라미터 설명(`edb_redwood_date`, `edb_redwood_strings`, `edb_redwood_raw_names` 등).
- **SYS 스키마(SYS schema)**: EPAS의 SYS 스키마 정보.
