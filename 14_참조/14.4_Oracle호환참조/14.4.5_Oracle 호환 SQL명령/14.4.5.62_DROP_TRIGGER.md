# DROP TRIGGER — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP TRIGGER](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/59_drop_trigger/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`DROP TRIGGER` — 트리거를 제거합니다.

## 구문 개요 (Synopsis)

```sql
DROP TRIGGER <name>
```

## 설명 (Description)

`DROP TRIGGER`는 연결된 테이블에서 트리거를 제거합니다. 슈퍼유저 또는 연결된 테이블의 소유자가 이 명령을 실행할 수 있습니다.

## 파라미터 (Parameters)

`name`

제거할 트리거의 이름입니다.

## 예제 (Examples)

`emp_salary_trig`라는 이름의 트리거를 제거합니다.

```sql
DROP TRIGGER emp_salary_trig;
```
