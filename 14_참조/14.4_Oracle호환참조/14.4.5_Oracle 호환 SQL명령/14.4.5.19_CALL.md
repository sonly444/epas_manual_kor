# CALL — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › CALL](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/17_call/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`CALL` — 프로시저를 호출합니다.

## 구문 개요 (Synopsis)

```sql
CALL <procedure_name> '('[<argument_list>]')'
```

## 설명 (Description)

프로시저를 호출하려면 `CALL` 문을 사용합니다. `CALL` 문을 사용하려면 `CALL` 문이 호출하는 프로시저에 대한 `EXECUTE` 권한이 있어야 합니다.

## 파라미터 (Parameters)

`procedure_name`

프로시저 이름(선택적으로 스키마로 한정 가능).

`argument_list`

프로시저에 필요한 인수를 쉼표로 구분한 목록을 지정합니다. `argument_list`의 각 구성원은 프로시저가 기대하는 형식 인수(formal argument)에 대응합니다. 각 형식 인수는 `IN` 파라미터, `OUT` 파라미터, 또는 `INOUT` 파라미터일 수 있습니다.

##### 참고 (Note)

패키지 함수를 호출할 때는 `CALL` 문에 `OUT` 파라미터를 지정해야 합니다. `OUT` 파라미터는 패키지 오버로딩(overloading) 중에 `INOUT` 파라미터로 작동합니다.

## 예제 (Examples)

`CALL` 문은 프로시저에 필요한 인수에 따라 여러 형식을 취할 수 있습니다:

```sql
CALL update_balance();
CALL update_balance(1,2,3);
```
