# ROLLBACK TO SAVEPOINTv18

## 이름 (Name)

`ROLLBACK TO SAVEPOINT` — 세이브포인트로 롤백합니다.

## 구문 개요 (Synopsis)

```sql
ROLLBACK [ WORK ] TO [ SAVEPOINT ] <savepoint_name>
```

## 설명 (Description)

세이브포인트가 설정된 이후에 실행된 모든 명령을 롤백합니다. 세이브포인트는 유효한 상태로 유지되며, 필요하면 다시 롤백할 수 있습니다.

`ROLLBACK TO SAVEPOINT`는 지정된 세이브포인트 이후에 설정된 모든 세이브포인트를 소멸시킵니다.

## 파라미터 (Parameters)

`savepoint_name`

롤백할 대상 세이브포인트입니다.

## 참고 (Notes)

설정되지 않은 세이브포인트 이름을 지정하는 것은 오류입니다.

`ROLLBACK TO SAVEPOINT`는 SPL 프로그램에서 지원되지 않습니다.

## 예제 (Examples)

세이브포인트 `depts`가 설정된 시점부터 실행된 명령의 효과를 취소합니다:

```sql
\set AUTOCOMMIT off
INSERT INTO dept VALUES (50, 'HR', 'NEW YORK');
SAVEPOINT depts;
INSERT INTO emp (empno, ename, deptno) VALUES (9001, 'JONES', 50);
INSERT INTO emp (empno, ename, deptno) VALUES (9002, 'ALICE', 50);
ROLLBACK TO SAVEPOINT depts;
```
