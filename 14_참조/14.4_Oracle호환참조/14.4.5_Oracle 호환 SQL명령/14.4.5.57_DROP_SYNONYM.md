# DROP SYNONYM — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP SYNONYM](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/54_drop_synonym/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`DROP SYNONYM` — 동의어(synonym)를 제거합니다.

## 구문 개요 (Synopsis)

```sql
DROP [PUBLIC] SYNONYM [<schema>.]<syn_name>
```

## 설명 (Description)

`DROP SYNONYM`은 기존 동의어를 삭제합니다. 이 명령을 실행하려면 슈퍼유저이거나 해당 동의어의 소유자여야 하며, 동의어가 존재하는 스키마에 대한 `USAGE` 권한이 있어야 합니다.

## 파라미터 (Parameters)

`syn_name`

동의어의 이름입니다. 동의어 이름은 스키마 내에서 고유해야 합니다.

`schema`

동의어가 존재하는 스키마의 이름입니다.

스키마로 한정할 수 있는 다른 객체와 마찬가지로, 검색 경로(search path)에 같은 이름의 동의어를 두 개 가질 수 있습니다. 삭제하려는 동의어의 이름을 지정하려면 스키마 이름을 포함하세요. `DROP SYNONYM` 명령에서 동의어를 스키마로 한정하지 않으면, EDB Postgres Advanced Server는 검색 경로에서 처음 발견되는 동의어 인스턴스를 삭제합니다.

`public` 스키마에 존재하는 동의어를 삭제하려면 선택적으로 `PUBLIC` 절을 포함할 수 있습니다. Oracle 데이터베이스와 호환되는 `DROP PUBLIC SYNONYM` 명령은 `public` 스키마에 존재하는 동의어를 삭제합니다.

```sql
DROP PUBLIC SYNONYM syn_name;
```

## 예제 (Examples)

이 예제는 `personnel` 동의어를 삭제합니다.

```sql
DROP SYNONYM personnel;
```
