# CREATE TABLE AS v18

## 이름 (Name)

`CREATE TABLE AS` — 쿼리 결과로부터 새 테이블을 정의합니다.

## 구문 개요 (Synopsis)

```sql
CREATE [ GLOBAL TEMPORARY ] TABLE <table_name>
  [ (<column_name> [, ...] ) ]
  [ ON COMMIT { PRESERVE ROWS | DELETE ROWS } ]
  [ TABLESPACE tablespace ]
  AS <query>
```

## 설명 (Description)

`CREATE TABLE AS`는 테이블을 생성하고 `SELECT` 명령으로 계산된 데이터로 채웁니다. 테이블 컬럼은 `SELECT`의 출력 컬럼과 연관된 이름과 데이터 타입을 갖습니다. 새 컬럼 이름의 명시적 목록을 제공하여 컬럼 이름을 재정의할 수 있습니다.

`CREATE TABLE AS`는 뷰를 생성하는 것과 유사합니다. 다만 이것은 테이블을 생성하고 쿼리를 한 번 평가하여 새 테이블을 초기에 채운다는 점에서 다릅니다. 새 테이블은 쿼리의 소스 테이블에 대한 이후의 변경을 추적하지 않습니다. 반면 뷰는 쿼리할 때마다 정의하는 `SELECT` 문을 다시 평가합니다.

## 파라미터 (Parameters)

`GLOBAL TEMPORARY`

테이블을 임시 테이블로 생성하도록 지정합니다. 자세한 내용은 [`CREATE TABLE`](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/36_create_table/)을 참조하세요.

`table_name`

생성할 테이블의 이름(선택적으로 스키마로 한정).

`column_name`

새 테이블의 컬럼 이름입니다. 컬럼 이름을 제공하지 않으면 이름은 쿼리의 출력 컬럼 이름에서 가져옵니다.

`query`

쿼리 문(`SELECT` 명령)입니다. 허용되는 구문에 대한 설명은 [`SELECT`](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/71_select/)를 참조하세요.
