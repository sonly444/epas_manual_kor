# DROP PACKAGE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP PACKAGE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/49_drop_package/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`DROP PACKAGE` — 패키지를 제거합니다.

## 구문 개요 (Synopsis)

```sql
DROP PACKAGE [ BODY ] <name>
```

## 설명 (Description)

`DROP PACKAGE`는 기존 패키지를 삭제합니다. 이 명령을 실행하려면 슈퍼유저이거나 해당 패키지의 소유자여야 합니다. 패키지 명세(specification)를 삭제하지 않고 패키지 본문(body)만 제거하려면 `BODY`를 지정합니다. 패키지 명세와 본문을 모두 제거하려면 `BODY`를 생략합니다.

## 파라미터 (Parameters)

`name`

제거할 패키지의 이름(선택적으로 스키마로 한정할 수 있음)입니다.

## 예제 (Examples)

이 예제는 `emp_admin` 패키지를 제거합니다.

```sql
DROP PACKAGE emp_admin;
```
