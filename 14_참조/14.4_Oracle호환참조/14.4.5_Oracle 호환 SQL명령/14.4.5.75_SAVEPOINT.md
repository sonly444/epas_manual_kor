# SAVEPOINTv18

## 이름 (Name)

`SAVEPOINT` — 현재 트랜잭션에서 새 세이브포인트를 정의합니다.

## 구문 개요 (Synopsis)

```sql
SAVEPOINT <savepoint_name>
```

## 설명 (Description)

`SAVEPOINT`는 현재 트랜잭션에서 새 세이브포인트를 설정합니다.

세이브포인트는 트랜잭션 내부의 표시(mark)로, 그 이후에 실행되는 모든 명령을 롤백할 수 있게 합니다. 이는 트랜잭션 상태를 세이브포인트 시점의 상태로 복원합니다.

## 파라미터 (Parameters)

`savepoint_name`

세이브포인트의 이름입니다.

## 참고 (Notes)

세이브포인트로 롤백하려면 `ROLLBACK TO SAVEPOINT`를 사용하세요.

세이브포인트는 트랜잭션 블록 내부에 있을 때만 설정할 수 있습니다. 한 트랜잭션에 여러 개의 세이브포인트를 정의할 수 있습니다.

이전 세이브포인트와 동일한 이름으로 다른 세이브포인트를 설정하면 이전 세이브포인트는 유지됩니다. 그러나 롤백할 때는 더 최근의 것만 사용됩니다.

`SAVEPOINT`는 SPL 프로그램에서 지원되지 않습니다.

## 예제 (Examples)

세이브포인트를 설정한 다음, 그 이후에 실행된 모든 명령의 효과를 취소합니다:

```sql
\set AUTOCOMMIT off
INSERT INTO dept VALUES (50, 'HR', 'NEW YORK');
SAVEPOINT depts;
INSERT INTO emp (empno, ename, deptno) VALUES (9001, 'JONES', 50);
INSERT INTO emp (empno, ename, deptno) VALUES (9002, 'ALICE', 50);
SAVEPOINT emps;
INSERT INTO jobhist VALUES (9001,'17-SEP-07',NULL,'CLERK',800,NULL,50,'New Hire');
INSERT INTO jobhist VALUES (9002,'20-SEP-07',NULL,'CLERK',700,NULL,50,'New Hire');
ROLLBACK TO depts;
COMMIT;
```

이 트랜잭션은 `dept` 테이블에 한 행을 커밋합니다. `emp` 및 `jobhist` 테이블에 대한 삽입은 롤백됩니다.
