# CREATE SYNONYM v18

## 이름 (Name)

`CREATE SYNONYM` — 새 시노님(synonym)을 정의합니다.

## 구문 개요 (Synopsis)

```sql
CREATE [OR REPLACE] [PUBLIC] SYNONYM [<schema>.]<syn_name>
        FOR <object_schema>.<object_name>[@<dblink_name>];
```

## 설명 (Description)

`CREATE SYNONYM`은 특정 유형의 데이터베이스 객체에 대한 시노님을 정의합니다. EDB Postgres Advanced Server는 다음에 대한 시노님을 지원합니다.

- 테이블(Tables)
- 뷰(Views)
- 구체화된 뷰(Materialized views)
- 시퀀스(Sequences)
- 패키지(Packages)
- 프로시저(Procedures)
- 함수(Functions)
- 타입(Types)
- 데이터베이스 링크를 통해 접근할 수 있는 객체
- 다른 시노님

## 파라미터 (Parameters)

`syn_name`

시노님의 이름입니다. 시노님 이름은 스키마 내에서 고유해야 합니다.

`schema`

시노님이 위치하는 스키마의 이름입니다. 스키마 이름을 지정하지 않으면 시노님은 검색 경로(search path)에서 존재하는 첫 번째 스키마에 생성됩니다.

`object_name`

객체의 이름입니다.

`object_schema`

참조되는 객체가 위치하는 스키마의 이름입니다.

`dblink_name`

객체에 접근할 때 사용하는 데이터베이스 링크의 이름입니다.

기존 시노님 정의를 새 시노님 정의로 교체하려면 `REPLACE` 절을 포함합니다.

`public` 스키마에 시노님을 생성하려면 `PUBLIC` 절을 포함합니다. Oracle 데이터베이스와 호환되는 `CREATE PUBLIC SYNONYM` 명령은 `public` 스키마에 위치하는 시노님을 생성합니다.

```sql
CREATE [OR REPLACE] PUBLIC SYNONYM <syn_name> FOR
<object_schema>.<object_name>;
```

이것은 다음을 축약해서 작성하는 방법입니다.

```sql
CREATE [OR REPLACE] SYNONYM public.<syn_name> FOR
<object_schema>.<object_name>;
```

## 참고 사항 (Notes)

시노님이 참조하는 객체에 대한 접근은 시노님의 현재 사용자 권한에 의해 결정됩니다. 시노님 사용자는 기저의 데이터베이스 객체에 대한 적절한 권한을 가지고 있어야 합니다.

## 예제 (Examples)

`enterprisedb`라는 스키마에 있는 `emp` 테이블에 대한 시노님을 생성합니다.

```sql
CREATE SYNONYM personnel FOR enterprisedb.emp;
```
