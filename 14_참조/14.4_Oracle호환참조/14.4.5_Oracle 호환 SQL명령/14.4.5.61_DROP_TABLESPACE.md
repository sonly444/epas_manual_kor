# DROP TABLESPACE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP TABLESPACE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/58_drop_tablespace/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`DROP TABLESPACE` — 테이블스페이스를 제거합니다.

## 구문 개요 (Synopsis)

```sql
DROP TABLESPACE <tablespacename>
```

## 설명 (Description)

`DROP TABLESPACE`는 시스템에서 테이블스페이스를 제거합니다.

슈퍼유저 또는 테이블스페이스 소유자만이 테이블스페이스를 삭제할 수 있습니다. 테이블스페이스를 삭제하기 전에 그 안의 모든 데이터베이스 객체가 비어 있어야 합니다. 현재 데이터베이스의 어떤 객체도 그 테이블스페이스를 사용하고 있지 않더라도, 다른 데이터베이스의 객체가 여전히 그 테이블스페이스에 존재할 수 있습니다.

## 파라미터 (Parameters)

`tablespacename`

테이블스페이스의 이름입니다.

## 예제 (Examples)

이 예제는 시스템에서 `employee_space` 테이블스페이스를 제거합니다.

```sql
DROP TABLESPACE employee_space;
```
