# DROP PROFILE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP PROFILE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/51_drop_profile/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`DROP PROFILE` — 사용자 정의 프로필을 삭제합니다.

## 구문 개요 (Synopsis)

```sql
DROP PROFILE [IF EXISTS] <profile_name> [CASCADE | RESTRICT];
```

## 설명 (Description)

지정한 프로필이 존재하지 않을 때 오류를 방지하려면 `IF EXISTS` 절을 포함합니다. 오류 대신 알림(notice)을 발행합니다.

현재 해당 프로필에 연결된 사용자를 `default` 프로필로 재할당한 후 프로필을 삭제하려면 선택적 `CASCADE` 절을 포함합니다. 롤(role)에 연결된 프로필의 삭제를 막으려면 선택적 `RESTRICT` 절을 포함합니다. 이것이 기본 동작입니다.

## 파라미터 (Parameters)

`profile_name`

삭제할 프로필의 이름입니다.

## 예제 (Examples)

이 예제는 `acctg_profile`이라는 이름의 프로필을 삭제합니다. 이 명령은 먼저 `acctg_profile` 프로필에 연결된 모든 롤을 `default` 프로필에 연결한 후 `acctg_profile` 프로필을 삭제합니다.

```sql
DROP PROFILE acctg_profile CASCADE;
```

이 예제는 `acctg_profile`이라는 이름의 프로필을 삭제합니다. `RESTRICT` 절은 프로필에 연결된 롤이 있는 경우 `acctg_profile` 삭제를 막습니다.

```sql
DROP PROFILE acctg_profile RESTRICT;
```
