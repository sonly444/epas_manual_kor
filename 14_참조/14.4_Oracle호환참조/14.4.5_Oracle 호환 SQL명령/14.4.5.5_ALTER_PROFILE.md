# ALTER PROFILE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER PROFILE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/05_alter_profile/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·파라미터·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`ALTER PROFILE` — 기존 프로필을 변경합니다.

## 구문 개요 (Synopsis)

```sql
ALTER PROFILE <profile_name> RENAME TO <new_name>;

ALTER PROFILE <profile_name>
      LIMIT {<parameter value>}[...];
```

## 설명 (Description)

`ALTER PROFILE` 명령을 사용하여 사용자 정의 프로필을 수정합니다. EDB Postgres Advanced Server는 두 가지 형태의 명령을 지원합니다:

- 프로필 이름을 변경하려면 `ALTER PROFILE…RENAME TO`를 사용합니다.
- 프로필에 연관된 제한을 수정하려면 `ALTER PROFILE…LIMIT`를 사용합니다.

EDB Postgres Advanced Server가 적용하는 규칙을 지정하려면 `LIMIT` 절과 하나 이상의 공백 구분 `parameter/value` 쌍을 포함합니다.

## 파라미터 (Parameters)

`profile_name` — 프로필 이름.

`new_name` — 프로필의 새 이름.

`parameter` — 프로필로 제한되는 속성.

`value` — 파라미터 제한.

EDB Postgres Advanced Server는 각 파라미터에 대해 다음 값을 지원합니다:

`FAILED_LOGIN_ATTEMPTS` — 서버가 `PASSWORD_LOCK_TIME`으로 지정된 시간 동안 계정을 잠그기 전에 사용자가 할 수 있는 실패한 로그인 시도 횟수를 지정합니다. 지원 값:

- `0`보다 큰 `INTEGER` 값.
- `DEFAULT` — `DEFAULT` 프로필에 지정된 `FAILED_LOGIN_ATTEMPTS` 값.
- `UNLIMITED` — 접속하는 사용자가 무제한으로 실패한 로그인 시도를 할 수 있음.

`PASSWORD_LOCK_TIME` — `FAILED_LOGIN_ATTEMPTS`로 인해 잠긴 계정을 서버가 잠금 해제하기 전에 경과해야 하는 시간을 지정합니다. 지원 값:

- `0` 이상의 `NUMERIC` 값. 하루의 일부를 지정하려면 소수 값을 지정합니다. 예를 들어 `4.5`는 4일 12시간을 지정합니다.
- `DEFAULT` — `DEFAULT` 프로필에 지정된 값.
- `UNLIMITED` — 데이터베이스 슈퍼유저가 수동으로 잠금 해제할 때까지 계정이 잠김.

`PASSWORD_LIFE_TIME` — 사용자가 새 비밀번호를 제공하라는 프롬프트를 받기 전에 현재 비밀번호를 사용할 일수를 지정합니다. `PASSWORD_LIFE_TIME` 절을 사용할 때 `PASSWORD_GRACE_TIME` 절을 포함하여 비밀번호 만료 후 역할의 연결이 거부되기까지의 일수를 지정합니다. `PASSWORD_GRACE_TIME`을 지정하지 않으면 비밀번호는 `PASSWORD_GRACE_TIME` 기본값으로 지정된 날에 만료됩니다. 사용자는 새 비밀번호를 제공할 때까지 어떤 명령도 실행할 수 없습니다. 지원 값:

- `0` 이상의 `NUMERIC` 값(소수 가능).
- `DEFAULT` — `DEFAULT` 프로필 값.
- `UNLIMITED` — 비밀번호에 만료일이 없음.

`PASSWORD_GRACE_TIME` — 비밀번호 만료 후 사용자가 비밀번호를 변경해야 할 때까지의 유예 기간 길이를 지정합니다. 유예 기간이 만료되면 사용자는 연결할 수 있지만 만료된 비밀번호를 갱신할 때까지 어떤 명령도 실행할 수 없습니다. 지원 값:

- `0` 이상의 `NUMERIC` 값(소수 가능).
- `DEFAULT` — `DEFAULT` 프로필 값.
- `UNLIMITED` — 유예 기간이 무한.

`PASSWORD_REUSE_TIME` — 비밀번호를 재사용하기 전에 사용자가 기다려야 하는 일수를 지정합니다. `PASSWORD_REUSE_TIME`과 `PASSWORD_REUSE_MAX` 파라미터를 함께 사용합니다. 하나에 유한 값을 지정하고 다른 하나가 `UNLIMITED`이면 이전 비밀번호를 재사용할 수 없습니다. 둘 다 `UNLIMITED`이면 재사용에 제한이 없습니다. 지원 값:

- `0` 이상의 `NUMERIC` 값(소수 가능).
- `DEFAULT` — `DEFAULT` 프로필 값.
- `UNLIMITED` — 제한 없이 재사용 가능.

`PASSWORD_REUSE_MAX` — 비밀번호를 재사용하기 전에 발생해야 하는 비밀번호 변경 횟수를 지정합니다. `PASSWORD_REUSE_TIME`과 함께 사용합니다. 지원 값:

- `0` 이상의 `INTEGER` 값.
- `DEFAULT` — `DEFAULT` 프로필 값.
- `UNLIMITED` — 제한 없이 재사용 가능.

`PASSWORD_VERIFY_FUNCTION` — 비밀번호 복잡성을 지정합니다. 지원 값:

- PL/SQL 함수의 이름.
- `DEFAULT` — `DEFAULT` 프로필 값.
- `NULL`

`PASSWORD_ALLOW_HASHED` — 암호화된 비밀번호를 허용할지 지정합니다. `TRUE`로 지정하면 클라이언트 측에서 해시로 계산된 암호화 비밀번호를 지정하여 비밀번호를 변경할 수 있습니다. `FALSE`로 지정하면 오류 없이 검증하기 위해 평문 형태로 비밀번호를 지정해야 합니다. 지원 값:

- `BOOLEAN` 값 `TRUE/ON/YES/1` 또는 `FALSE/OFF/NO/0`.
- `DEFAULT` — `DEFAULT` 프로필 값.

##### 참고 (Note)

`PASSWORD_ALLOW_HASHED`는 Oracle과 호환되지 않습니다.

`INACTIVE_ACCOUNT_TIME` — 계정이 자동으로 잠기기 전에 (성공적인 로그인 없이) 비활성 상태로 남을 수 있는 일수를 정의합니다. 이 파라미터는 사용하지 않는 계정을 비활성화하여 휴면 계정이 악용될 위험을 줄여 보안을 강화합니다. 비활성으로 인해 계정이 잠기면 슈퍼유저만 잠금 해제할 수 있습니다. 비활성은 `pg_authid`의 `rollastlogin` 컬럼에서 결정되며, 이 값이 NULL이면 역할의 생성일이 대신 사용됩니다. 지원 값:

- `DEFAULT` — `DEFAULT` 프로필 값.
- `UNLIMITED` — 비활성으로 인해 계정이 절대 잠기지 않음.
- 15에서 24855 사이의 값.

## 예제 (Examples)

이 예는 `acctg_profile` 프로필을 수정합니다:

```sql
ALTER PROFILE acctg_profile
       LIMIT FAILED_LOGIN_ATTEMPTS 3 PASSWORD_LOCK_TIME 1;
```

`acctg_profile`은 로그인 역할이 서버 접속을 시도할 때 실패한 연결 시도를 셉니다. 이 프로필은 사용자가 세 번 시도 안에 올바른 비밀번호로 인증하지 못하면 계정을 하루 동안 잠그도록 지정합니다.

이 예는 `acctg_profile`의 이름을 `payables_profile`로 변경합니다:

```sql
ALTER PROFILE acctg_profile RENAME TO payables_profile;
```
