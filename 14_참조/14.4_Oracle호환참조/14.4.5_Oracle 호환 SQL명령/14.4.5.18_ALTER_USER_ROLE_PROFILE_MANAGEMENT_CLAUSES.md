# ALTER USER|ROLE… PROFILE MANAGEMENT CLAUSES — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER USER|ROLE… PROFILE MANAGEMENT CLAUSES](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/16_alter_user_role_profile_management_clauses/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`ALTER USER|ROLE`

## 구문 개요 (Synopsis)

```sql
ALTER USER|ROLE <name> [[WITH] option[…]
```

`option`은 다음과 같은 호환(compatible) 절이 될 수 있습니다:

```sql
  PROFILE <profile_name>
| ACCOUNT {LOCK|UNLOCK}
| PASSWORD EXPIRE [AT '<timestamp>']
```

`option`은 다음과 같은 비호환(non-compatible) 절이 될 수 있습니다:

```sql
| PASSWORD SET AT '<timestamp>'
| LOCK TIME '<timestamp>'
| STORE PRIOR PASSWORD {'<password>' '<timestamp>} [, ...]
```

EDB Postgres Advanced Server가 지원하는 `ALTER USER` 또는 `ALTER ROLE` 명령의 관리(administrative) 절에 대한 정보는 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/sql-commands.html)를 참조하십시오.

프로파일 관리를 적용하는 `ALTER USER|ROLE` 절은 데이터베이스 슈퍼유저만 사용할 수 있습니다. 이 절들은 다음 동작을 적용합니다:

- 미리 정의된 프로파일을 롤에 연결하거나 사용자에 연결된 미리 정의된 프로파일을 변경하려면 `PROFILE` 절과 `profile_name`을 포함합니다.

- 사용자 계정을 잠금(locked) 또는 잠금 해제(unlocked) 상태로 두려면 `ACCOUNT` 절과 `LOCK` 또는 `UNLOCK` 키워드를 포함합니다.

- 지정된 시간에 롤을 잠그고 이 롤에 할당된 프로파일의 `PASSWORD_LOCK_TIME` 파라미터가 나타내는 시간에 롤을 잠금 해제하려면 `LOCK TIME 'timestamp'` 절과 날짜/시간 값을 포함합니다. `LOCK TIME`이 `ACCOUNT LOCK` 절과 함께 사용되면, 데이터베이스 슈퍼유저만 `ACCOUNT UNLOCK` 절로 롤을 잠금 해제할 수 있습니다.

- 롤에 연결된 비밀번호가 만료될 날짜/시간을 지정하려면 `PASSWORD EXPIRE` 절과 `AT 'timestamp'` 키워드를 포함합니다. `AT 'timestamp'` 키워드를 생략하면 비밀번호가 즉시 만료됩니다.

- 비밀번호 만료 시간을 정의하려면 `PASSWORD SET AT 'timestamp'` 절을 포함합니다.

  - 지정된 타임스탬프가 미래이면 계정 상태가 EXPIRED(GRACE)로 설정됩니다.
  - 타임스탬프가 과거이거나 현재이면 계정 상태가 EXPIRED로 설정됩니다.
- 비밀번호 이력을 수정하여 새 비밀번호와 비밀번호가 설정된 시간을 추가하려면 `STORE PRIOR PASSWORD {'password' 'timestamp} [, ...]` 절을 포함합니다.

각 로그인 롤은 하나의 프로파일만 가질 수 있습니다. 현재 로그인 롤에 연결된 프로파일을 확인하려면 `DBA_USERS` 뷰의 `profile` 열을 조회합니다.

## 파라미터 (Parameters)

`name`

지정된 프로파일과 연결할 롤의 이름.

`password`

롤에 연결된 비밀번호.

`profile_name`

롤과 연결할 프로파일의 이름.

`timestamp`

절이 적용되는 날짜와 시간. `timestamp` 값을 지정할 때는 값을 작은따옴표로 묶습니다.

## 참고 (Notes)

`ALTER USER` 또는 `ALTER ROLE` 명령의 Postgres 호환 절에 대한 정보는 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/sql-alterrole.html)를 참조하십시오.

## 예제 (Examples)

이 예제는 `ALTER USER… PROFILE` 명령을 사용하여 `acctg`라는 프로파일을 `john`이라는 사용자와 연결합니다:

```sql
ALTER USER john PROFILE acctg_profile;
```

이 예제는 `ALTER ROLE… PROFILE` 명령을 사용하여 `acctg`라는 프로파일을 `john`이라는 사용자와 연결합니다:

```sql
ALTER ROLE john PROFILE acctg_profile;
```
