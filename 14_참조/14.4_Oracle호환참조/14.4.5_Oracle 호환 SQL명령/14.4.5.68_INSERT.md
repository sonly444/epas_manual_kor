# INSERT — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › INSERT](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/65_insert/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`INSERT` — 테이블에 행을 생성합니다.

## 구문 개요 (Synopsis)

```sql
INSERT INTO <table>[@<dblink> | [ AS ] <alias> ] [ ( <column> [, ...] ) ]
  { VALUES ( { <expression> | DEFAULT } [, ...] )
    [ RETURNING <return_expression> [, ...]\
        { INTO { <record> | <variable> [, ...] }\
        | BULK COLLECT INTO <collection> [, ...] } ]
  | <query> }
```

## 설명 (Description)

`INSERT`를 사용하면 테이블에 새 행을 삽입할 수 있습니다. 단일 행을 삽입하거나 쿼리의 결과로 여러 행을 삽입할 수 있습니다.

대상 목록(target list)의 열을 임의의 순서로 나열할 수 있습니다. 대상 목록에 없는 각 열은 기본값(선언된 기본값 또는 null)을 사용하여 삽입됩니다.

각 열에 대한 표현식이 올바른 데이터 타입을 가지고 있지 않으면 타입 변환이 시도됩니다.

`RETURNING INTO { record | variable [, ...] }` 절은 `INSERT` 명령이 SPL 프로그램에서 사용되고 `VALUES` 절이 사용되는 경우에만 지정할 수 있습니다.

`RETURNING BULK COLLECT INTO collection [, ...]` 절은 `INSERT` 명령이 SPL 프로그램에서 사용되는 경우에만 지정할 수 있습니다. `BULK COLLECT INTO` 절의 대상으로 둘 이상의 `collection`을 지정하는 경우, 각 `collection`은 단일 스칼라 필드로 구성되어야 합니다. 즉, `collection`은 레코드가 될 수 없습니다. 삽입된 각 행에 대해 평가된 `return_expression`은 첫 번째 요소부터 시작하여 `collection`의 요소가 됩니다. `collection`에 있는 기존 행은 모두 삭제됩니다. 결과 집합이 비어 있으면 `collection`도 비어 있습니다.

테이블에 삽입하려면 그 테이블에 대한 `INSERT` 권한이 필요합니다. `query` 절을 사용하여 쿼리의 행을 삽입하는 경우, 그 쿼리에서 사용되는 모든 테이블에 대한 `SELECT` 권한도 필요합니다.

## 파라미터 (Parameters)

`table`

기존 테이블의 이름입니다(선택적으로 스키마로 한정할 수 있습니다).

`alias`

대체 이름으로, 쿼리 실행 중 문에서 참조할 테이블, 뷰, 구체화된 뷰(materialized view) 또는 서브쿼리에 대한 별칭입니다.

`dblink`

원격 데이터베이스를 식별하는 데이터베이스 링크 이름입니다. 데이터베이스 링크에 대한 정보는 [`CREATE DATABASE LINK`](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/21_create_public_database_link/)를 참조하십시오.

`column`

`table`에 있는 열의 이름입니다.

`expression`

`column`에 할당할 표현식 또는 값입니다.

`DEFAULT`

이 열은 그 기본값으로 채워집니다.

`query`

삽입할 행을 제공하는 쿼리(`SELECT` 문)입니다. 구문에 대한 설명은 [`SELECT`](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/71_select/)를 참조하십시오.

`return_expression`

`table`의 하나 이상의 열을 포함할 수 있는 표현식입니다. `return_expression`에서 `table`의 열 이름을 지정하면, `return_expression`이 평가될 때 그 열을 대체하는 값은 다음과 같이 결정됩니다.

- `return_expression`에서 지정된 열이 `INSERT` 명령에서 값을 할당받으면, 그 할당된 값이 `return_expression`의 평가에 사용됩니다.

- `return_expression`에서 지정된 열이 `INSERT` 명령에서 값을 할당받지 않고, 테이블의 열 정의에 그 열에 대한 기본값이 없으면, `return_expression`의 평가에 null이 사용됩니다.

- `return_expression`에서 지정된 열이 `INSERT` 명령에서 값을 할당받지 않고, 테이블의 열 정의에 그 열에 대한 기본값이 있으면, `return_expression`의 평가에 그 기본값이 사용됩니다.


`record`

평가된 `return_expression`을 그 필드에 할당할 레코드입니다. 첫 번째 `return_expression`은 `record`의 첫 번째 필드에 할당되고, 두 번째 `return_expression`은 `record`의 두 번째 필드에 할당되며, 이런 식으로 계속됩니다. `record`의 필드 수는 표현식의 수와 정확히 일치해야 하며, 필드는 할당되는 표현식과 타입이 호환되어야 합니다.

`variable`

평가된 `return_expression`을 할당할 변수입니다. 둘 이상의 `return_expression`과 `variable`을 지정하면, 첫 번째 `return_expression`은 첫 번째 `variable`에 할당되고, 두 번째 `return_expression`은 두 번째 `variable`에 할당되며, 이런 식으로 계속됩니다. `INTO` 키워드 뒤에 지정된 변수의 수는 `RETURNING` 키워드 뒤의 표현식의 수와 정확히 일치해야 합니다. 변수는 할당되는 표현식과 타입이 호환되어야 합니다.

`collection`

평가된 `return_expression`으로부터 요소가 생성되는 컬렉션입니다. 다음 중 하나일 수 있습니다.

- 단일 컬렉션으로, 단일 필드의 컬렉션이거나 레코드 타입의 컬렉션일 수 있습니다.

- 둘 이상의 컬렉션으로, 이 경우 각 컬렉션은 단일 필드로 구성되어야 합니다.

반환 표현식의 수는 지정된 모든 컬렉션의 필드 수와 그 개수 및 순서가 일치해야 합니다. 대응하는 각 `return_expression`과 `collection` 필드는 타입이 호환되어야 합니다.


## 예제 (Examples)

테이블 `emp`에 단일 행을 삽입합니다.

```sql
INSERT INTO emp VALUES (8021,'JOHN','SALESMAN',7698,'22-FEB-07',1250,500,30);
```

이 예제는 `comm` 열을 생략하며, 이는 null의 기본값을 사용한다는 의미입니다.

```sql
INSERT INTO emp (empno, ename, job, mgr, hiredate, sal, deptno)
    VALUES (8022,'PETERS','CLERK',7698,'03-DEC-06',950,30);
```

이 예제는 `hiredate`와 `comm` 열에 값을 지정하는 대신 `DEFAULT` 절을 사용합니다.

```sql
INSERT INTO emp VALUES (8023,'FORD','ANALYST',7566,NULL,3000,NULL,20);
```

이 예제는 부서 이름을 위한 테이블을 생성한 다음 `dept` 테이블의 `dname` 열에서 선택하여 그 테이블에 삽입합니다.

```sql
CREATE TABLE deptnames (
    deptname        VARCHAR2(14)
);
INSERT INTO deptnames SELECT dname FROM dept;
```

이 예제는 테이블 `emp`에 대한 별칭 `enm`을 생성하고 테이블에 행을 삽입합니다.

```sql
INSERT INTO emp AS enm (enm.empno, enm.ename, enm.job, enm.mgr, enm.hiredate, enm.sal, enm.deptno)
  VALUES (7499, 'SMITH', 'ANALYST', 7902, '03-DEC-06', 2500, 20);
```
