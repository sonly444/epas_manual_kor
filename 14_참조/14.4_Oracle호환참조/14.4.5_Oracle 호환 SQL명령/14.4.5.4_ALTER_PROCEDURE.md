# ALTER PROCEDURE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER PROCEDURE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/04_alter_procedure/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`ALTER PROCEDURE` — 기존 프로시저를 수정합니다.

## 구문 개요 (Synopsis)

```sql
ALTER PROCEDURE <procedure_name> <options> [RESTRICT]
```

## 설명 (Description)

`ALTER PROCEDURE` 문을 사용하여 프로시저가 `SECURITY INVOKER`인지 `SECURITY DEFINER`인지 지정합니다.

## 파라미터 (Parameters)

`procedure_name` — 저장 프로시저의 이름(스키마 한정 가능).

`options`는 다음일 수 있습니다:

- `[EXTERNAL] SECURITY DEFINER`

프로시저를 만든 사용자의 권한으로 프로시저를 실행하려면 `SECURITY DEFINER`를 지정합니다. `EXTERNAL` 키워드는 호환성을 위해 허용되지만 무시됩니다.

- `[EXTERNAL] SECURITY INVOKER`

프로시저를 호출하는 사용자의 권한으로 프로시저를 실행하려면 `SECURITY INVOKER`를 지정합니다. `EXTERNAL` 키워드는 호환성을 위해 허용되지만 무시됩니다.

`RESTRICT` 키워드는 호환성을 위해 허용되지만 무시됩니다.

## 예제 (Examples)

이 명령은 `update_balance`가 프로시저를 호출하는 사용자의 권한으로 실행되도록 지정합니다:

```sql
ALTER PROCEDURE update_balance SECURITY INVOKER;
```
