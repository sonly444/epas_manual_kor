# ALTER TRIGGER — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER TRIGGER](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/13_alter_trigger/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`ALTER TRIGGER` — 트리거의 정의를 변경합니다.

## 구문 개요 (Synopsis)

EDB Postgres Advanced Server는 `ALTER TRIGGER` 명령의 세 가지 변형을 지원합니다. 트리거 정의를 변경하지 않고 지정된 트리거의 이름을 변경하려면 첫 번째 변형을 사용합니다:

```sql
ALTER TRIGGER <name> ON <table_name> RENAME TO <new_name>
```

트리거가 익스텐션에 의존하는 경우 `ALTER TRIGGER` 명령의 두 번째 변형을 사용합니다. 익스텐션이 삭제되면 트리거도 함께 삭제됩니다.

```sql
ALTER TRIGGER <name> ON <table_name> DEPENDS ON EXTENSION <extension_name>
```

트리거 객체의 소유권을 변경하려면 `ALTER TRIGGER` 명령의 세 번째 변형을 사용합니다:

```sql
ALTER TRIGGER <name> ON <table_name> AUTHORIZATION <rolespec>
```

EDB Postgres Advanced Server가 지원하는 `ALTER TRIGGER` 명령의 비호환(non-compatible) 구현 사용에 대한 정보는 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/sql-altertrigger.html)를 참조하십시오.

## 설명 (Description)

`ALTER TRIGGER`는 기존 트리거의 속성을 변경합니다. 트리거의 속성을 변경하려면 해당 트리거가 작동하는 테이블을 소유하고 있어야 합니다.

트리거의 암시적 객체(implicit object) 소유자를 변경하려면 `ALTER TRIGGER ...ON AUTHORIZATION` 명령을 사용할 수 있습니다. 권한 부여(authorization) 후 트리거의 암시적 객체 소유권을 사용자에게 할당하려면 `ALTER TRIGGER ...ON AUTHORIZATION` 명령을 실행할 권한이 있어야 합니다.

## 파라미터 (Parameters)

`name`

변경할 트리거의 이름.

`table_name`

트리거가 작동하는 테이블의 이름.

`rolespec`

트리거 객체의 소유자를 결정합니다.

## 예제 (Examples)

이 예제에는 슈퍼유저인 `bob`과 `carol` 사용자가 포함됩니다. 사용자 `bob`은 테이블 `emp`를 소유합니다. 사용자 `carol`은 테이블 `emp`에 생성된 `emp_sal_trig`라는 트리거를 소유합니다:

```sql
SELECT relname, relowner::regrole FROM pg_class WHERE relname = 'emp';
```

출력

```text
 relname | relowner
---------+----------
 emp     | bob
(1 row)
```

```sql
SELECT proname, proowner::regrole FROM pg_proc WHERE oid = (SELECT tgfoid
FROM pg_trigger WHERE tgname = 'emp_sal_trig') ORDER BY oid;
```

출력

```text
 proname           | proowner
-------------------+----------
 emp_sal_trig_emp  | carol
(1 row)
```

테이블 `emp`의 소유권을 사용자 `bob`에서 새 소유자 `edb`로 변경하려면:

```sql
ALTER TABLE emp OWNER TO edb;
ALTER TABLE

SELECT relname, relowner::regrole FROM pg_class WHERE relname = 'emp';
```

출력

```text
 relname | relowner
---------+----------
 emp     | edb
(1 row)
```

테이블 소유권은 사용자 `bob`에서 소유자 `edb`로 변경되었지만, `emp_sal_trig`의 트리거 소유권은 변경되지 않고 사용자 `carol`이 소유한 상태로 남아 있습니다. 테이블 `emp`의 트리거 `emp_sal_trig`를 변경하고 소유자 `edb`에게 권한을 부여합니다:

```sql
ALTER TRIGGER emp_sal_trig ON emp AUTHORIZATION edb;
ALTER TRIGGER

SELECT proname, proowner::regrole FROM pg_proc WHERE oid = (SELECT tgfoid
FROM pg_trigger WHERE tgname = 'emp_sal_trig') ORDER BY oid;
```

출력

```text
 proname          | proowner
------------------+----------
 emp_sal_trig_emp | edb
(1 row)
```

테이블 `emp`의 트리거 소유권 `emp_sal_trig`가 변경되어 소유자 `edb`에게 부여되었습니다.
