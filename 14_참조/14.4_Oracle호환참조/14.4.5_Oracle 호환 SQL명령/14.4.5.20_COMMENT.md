# COMMENT — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › COMMENT](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/18_comment/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`COMMENT` — 객체의 주석(comment)을 정의하거나 변경합니다.

## 구문 개요 (Synopsis)

```sql
COMMENT ON
{
  TABLE <table_name> |
  COLUMN <table_name.column_name>
} IS '<text>'
```

## 설명 (Description)

`COMMENT`는 데이터베이스 객체에 대한 주석을 저장합니다. 주석을 수정하려면 동일한 객체에 대해 새 `COMMENT` 명령을 실행합니다. 각 객체에 대해 하나의 주석 문자열만 저장됩니다. 주석을 제거하려면 `text`에 빈 문자열(중간에 공백 없이 연속된 두 개의 작은따옴표)을 지정합니다. 객체가 삭제되면 주석도 함께 삭제됩니다.

## 파라미터 (Parameters)

`table_name`

주석을 달 테이블의 이름(선택적으로 스키마로 한정 가능).

`table_name.column_name`

주석을 달 `table_name` 내 열의 이름(선택적으로 스키마로 한정 가능).

`text`

새 주석.

## 참고 (Notes)

현재 주석에 대한 보안 메커니즘은 없습니다. 데이터베이스에 연결된 모든 사용자는 해당 데이터베이스의 객체에 대한 모든 주석을 볼 수 있지만, 슈퍼유저만이 자신이 소유하지 않은 객체의 주석을 변경할 수 있습니다. 보안상 중요한 정보는 주석에 넣지 마십시오.

## 예제 (Examples)

테이블 `emp`에 주석을 첨부합니다:

```sql
COMMENT ON TABLE emp IS 'Current employee information';
```

`emp` 테이블의 `empno` 열에 주석을 첨부합니다:

```sql
COMMENT ON COLUMN emp.empno IS 'Employee identification number';
```

이 주석들을 제거합니다:

```sql
COMMENT ON TABLE emp IS '';
COMMENT ON COLUMN emp.empno IS '';
```
