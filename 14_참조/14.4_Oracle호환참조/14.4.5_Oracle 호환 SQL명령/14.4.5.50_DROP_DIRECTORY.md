# DROP DIRECTORY — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP DIRECTORY](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/46_drop_directory/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`DROP DIRECTORY` — 파일 시스템 디렉터리 경로에 대한 디렉터리 별칭(alias)을 제거합니다.

## 구문 개요 (Synopsis)

```sql
DROP DIRECTORY <name>
```

## 설명 (Description)

디렉터리를 삭제하려면 `DROP ANY DIRECTORY` 시스템 권한이 있어야 합니다. 다음은 관리자가 이 권한을 부여하는 방법의 예입니다.

```sql
grant drop any directory to example_role;
```

`DROP DIRECTORY`는 `CREATE DIRECTORY` 명령으로 생성한, 파일 시스템 디렉터리 경로에 대한 기존 별칭을 삭제합니다.

사용자 권한 관리에 대한 자세한 내용은 [UTL\_FILE 관련 문서](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/20_utl_file/)를 참조하세요.

디렉터리 별칭을 삭제해도 해당하는 물리적 파일 시스템 디렉터리는 영향을 받지 않습니다. 파일 시스템 디렉터리를 삭제하려면 운영 체제 명령을 사용하세요.

## 파라미터 (Parameters)

`name`

제거할 디렉터리 별칭의 이름입니다.

## 예제 (Examples)

디렉터리 별칭 `empdir`을 제거합니다.

```sql
DROP DIRECTORY empdir;
```
