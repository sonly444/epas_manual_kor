# ALTER INDEX — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER INDEX](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/03_alter_index/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`ALTER INDEX` — 기존 인덱스를 수정합니다.

## 구문 개요 (Synopsis)

EDB Postgres Advanced Server는 Oracle 데이터베이스와 호환되는 `ALTER INDEX` 명령의 세 가지 변형을 지원합니다. 첫 번째 변형은 인덱스 이름을 변경합니다:

```sql
ALTER INDEX <name> RENAME TO <new_name>
```

두 번째 변형은 인덱스를 재구축합니다:

```sql
ALTER INDEX <name> REBUILD
```

세 번째 변형은 `PARALLEL` 또는 `NOPARALLEL` 절을 설정합니다:

```sql
ALTER INDEX <name> { NOPARALLEL | PARALLEL [ <integer> ] }
```

## 설명 (Description)

`ALTER INDEX`는 기존 인덱스의 정의를 변경합니다. `RENAME` 절은 인덱스 이름을 변경합니다. `REBUILD` 절은 인덱스를 재구성하여, 기존 인덱스 복사본을 인덱스 테이블에 기반한 갱신된 버전으로 교체합니다.

`REBUILD` 절은 PostgreSQL `REINDEX` 명령을 호출합니다. `REBUILD` 절 사용에 대한 자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/sql-reindex.html)를 참고하십시오.

`PARALLEL` 절은 인덱스 재구축을 병렬화하는 데 사용할 수 있는 인덱스의 병렬 처리 수준(degree of parallelism)을 설정합니다.

`NOPARALLEL` 절은 병렬 처리를 기본값을 사용하도록 재설정합니다. `reloptions`는 `parallel_workers` 파라미터를 `0`으로 표시합니다.

`ALTER INDEX`는 저장된 데이터에 영향을 주지 않습니다.

## 파라미터 (Parameters)

`name` — 기존 인덱스의 이름(스키마 한정 가능).

`new_name` — 인덱스의 새 이름.

`PARALLEL` — 병렬 처리 수준을 지정하려면 `PARALLEL` 절을 포함합니다. `parallel_workers` 파라미터를 인덱스 재구축의 병렬 처리 수준과 같게 설정합니다. `PARALLEL`을 지정하되 병렬 처리 수준을 제공하지 않으면 기본 병렬 처리가 사용됩니다.

`NOPARALLEL` — 병렬 처리를 기본값으로 재설정하려면 `NOPARALLEL`을 지정합니다.

`integer` — 병렬 처리 수준, 즉 인덱스 재구축 시 사용되는 `parallel_workers`의 수를 나타냅니다.

## 예제 (Examples)

인덱스 이름을 `name_idx`에서 `empname_idx`로 변경하려면:

```sql
ALTER INDEX name_idx RENAME TO empname_idx;
```

`empname_idx` 인덱스를 재구축하려면:

```sql
ALTER INDEX empname_idx REBUILD;
```

이 예는 `empname_idx` 인덱스의 병렬 처리 수준을 7로 설정합니다:

```sql
ALTER INDEX empname_idx PARALLEL 7;
```
