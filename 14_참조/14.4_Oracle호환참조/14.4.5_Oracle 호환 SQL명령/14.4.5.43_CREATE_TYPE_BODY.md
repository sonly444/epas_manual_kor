# CREATE TYPE BODY v18

## 이름 (Name)

`CREATE TYPE BODY` — 새 객체 타입 본문(object type body)을 정의합니다.

## 구문 개요 (Synopsis)

```sql
CREATE [ OR REPLACE ] TYPE BODY <name>
  { IS | AS }
  <method_spec> [...]
END
```

여기서 `method_spec`은 다음과 같습니다.

```text
subprogram_spec
```

여기서 `subprogram_spec`은 다음과 같습니다.

```sql
{ MEMBER | STATIC }
{ PROCEDURE <proc_name>
    [ ( [ SELF [ IN | IN OUT ] <name> ]\
        [, <argname> [ IN | IN OUT | OUT ] <argtype>\
                     [ DEFAULT <value> ]\
        ] ...)\
    ]
{ IS | AS }
    <program_body>
  END;
|
  FUNCTION <func_name>
    [ ( [ SELF [ IN | IN OUT ] <name> ]\
        [, <argname> [ IN | IN OUT | OUT ] <argtype>\
                     [ DEFAULT <value> ]\
        ] ...)\
    ]
  RETURN <rettype>
{ IS |AS }
    <program_body>
  END;
}
```

## 설명 (Description)

`CREATE TYPE BODY`는 새 객체 타입 본문을 정의합니다. `CREATE OR REPLACE TYPE BODY`는 새 객체 타입 본문을 생성하거나 기존 본문을 교체합니다.

스키마 이름을 포함하면 객체 타입 본문은 지정된 스키마에 생성됩니다. 그렇지 않으면 현재 스키마에 생성됩니다. 새 객체 타입 본문의 이름은 동일한 스키마 내의 기존 객체 타입 명세와 일치해야 합니다. 기존 객체 타입 본문의 정의를 갱신하려는 경우가 아니라면, 새 객체 타입 본문 이름은 동일한 스키마 내의 어떤 기존 객체 타입 본문과도 일치할 수 없습니다. 갱신하려는 경우에는 `CREATE OR REPLACE TYPE BODY`를 사용합니다.

## 파라미터 (Parameters)

`name`

본문을 생성할 객체 타입의 이름(선택적으로 스키마로 한정).

`MEMBER`

`STATIC`

하위 프로그램이 객체 인스턴스에 대해 동작하는 경우 `MEMBER`를 지정합니다. 하위 프로그램이 특정 객체 인스턴스와 독립적으로 동작하는 경우 `STATIC`을 지정합니다.

`proc_name`

생성할 프로시저의 이름입니다.

`SELF [ IN | IN OUT ] name`

멤버 메서드에는 데이터 타입이 정의 중인 객체 타입과 동일한 `SELF`라는 암묵적인 내장 파라미터가 있습니다. `SELF`는 현재 메서드를 호출하고 있는 객체 인스턴스를 참조합니다. 파라미터 목록에서 `SELF`를 `IN` 또는 `IN OUT` 파라미터로 명시적으로 선언할 수 있습니다. 명시적으로 선언하는 경우 `SELF`는 파라미터 목록의 첫 번째 파라미터여야 합니다. `SELF`를 명시적으로 선언하지 않으면 그 파라미터 모드는 멤버 프로시저의 경우 `IN OUT`으로, 멤버 함수의 경우 `IN`으로 기본 설정됩니다.

`argname`

인수의 이름입니다. 인수는 메서드 본문에서 이 이름으로 참조됩니다.

`argtype`

메서드 인수의 데이터 타입입니다. 인수 타입은 기본 데이터 타입이거나 중첩 테이블 또는 객체 타입과 같은 사용자 정의 타입일 수 있습니다. 어떤 기본 타입에도 길이를 지정하지 마십시오. 예를 들어 `VARCHAR2(10)`이 아니라 `VARCHAR2`를 지정합니다.

`DEFAULT value`

메서드 호출에서 값을 제공하지 않는 경우 입력 인수에 대한 기본값을 제공합니다. `IN OUT` 또는 `OUT` 모드의 인수에는 `DEFAULT`를 지정할 수 없습니다.

`program_body`

함수 또는 프로시저의 본문을 구성하는 프래그마(pragma), 선언, SPL 문입니다. 함수 또는 프로시저를 자율 트랜잭션(autonomous transaction)으로 설정하려면 `PRAGMA AUTONOMOUS_TRANSACTION` 프래그마를 사용합니다.

`func_name`

생성할 함수의 이름입니다.

`rettype`

반환 데이터 타입이며, `argtype`에 나열된 타입 중 하나일 수 있습니다. `rettype`에는 길이를 지정하지 마십시오.

## 예제 (Examples)

객체 타입 `emp_obj_typ`에 대한 객체 타입 본문을 생성합니다.

```sql
CREATE OR REPLACE TYPE BODY emp_obj_typ AS
    MEMBER PROCEDURE display_emp (SELF IN OUT emp_obj_typ)
    IS
    BEGIN
        DBMS_OUTPUT.PUT_LINE('Employee No   : ' || empno);
        DBMS_OUTPUT.PUT_LINE('Name          : ' || ename);
        DBMS_OUTPUT.PUT_LINE('Street        : ' || addr.street);
        DBMS_OUTPUT.PUT_LINE('City/State/Zip: ' || addr.city || ', ' ||
            addr.state || ' ' || LPAD(addr.zip,5,'0'));
    END;
END;
```

객체 타입 `dept_obj_typ`에 대한 객체 타입 본문을 생성합니다.

```sql
CREATE OR REPLACE TYPE BODY dept_obj_typ AS
    STATIC FUNCTION get_dname (p_deptno IN NUMBER) RETURN VARCHAR2
    IS
        v_dname     VARCHAR2(14);
    BEGIN
        CASE p_deptno
            WHEN 10 THEN v_dname := 'ACCOUNING';
            WHEN 20 THEN v_dname := 'RESEARCH';
            WHEN 30 THEN v_dname := 'SALES';
            WHEN 40 THEN v_dname := 'OPERATIONS';
            ELSE v_dname := 'UNKNOWN';
        END CASE;
        RETURN v_dname;
    END;
    MEMBER PROCEDURE display_dept
    IS
    BEGIN
        DBMS_OUTPUT.PUT_LINE('Dept No    : ' || SELF.deptno);
        DBMS_OUTPUT.PUT_LINE('Dept Name  : ' ||
            dept_obj_typ.get_dname(SELF.deptno));
    END;
END;
```
