# CREATE CAPTURE PRIVILEGES POLICY — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › CREATE CAPTURE PRIVILEGES POLICY](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/19a_create_capture_privilege/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 `CREATE CAPTURE PRIVILEGES POLICY` SQL 명령을 통해 Oracle이 제공하지 않는 추가 구문을 포함합니다.

## 이름 (Name)

`CREATE CAPTURE PRIVILEGES POLICY` — 새로운 권한 캡처 정책을 생성합니다.

## 구문 개요 (Synopsis)

권한을 캡처하는 새 정책을 정의하려면 `CREATE CAPTURE PRIVILEGES POLICY`를 사용합니다:

```sql
## Create a policy on database
CREATE CAPTURE PRIVILEGES POLICY <name> [ WHERE ( <expression> ) ];

## Create a policy on a ROLE/USER
CREATE CAPTURE PRIVILEGES POLICY <name> ON { ROLE | USER } <role_names> [ WHERE ( <expression> ) ];
```

## 설명 (Description)

`CREATE CAPTURE PRIVILEGES POLICY` 명령을 사용하면 데이터베이스 슈퍼유저 또는 시스템 정의 `CAPTURE_ADMIN` 권한을 가진 사용자가 데이터베이스에 정책을 생성할 수 있습니다.

정책 이름이 스키마로 한정된 경우, 정책은 지정된 스키마에 생성됩니다. `CREATE CAPTURE PRIVILEGES POLICY` 명령에 스키마가 포함되지 않은 경우, 정책은 현재 스키마에 생성됩니다.

캡처 정책을 제거하려면 `DROP CAPTURE PRIVILEGES POLICY`를 사용합니다.

## 파라미터 (Parameters)

`name`

생성할 권한 캡처 정책의 이름으로, 선택적으로 스키마로 한정할 수 있습니다.

`expression`

최대 4000자까지 포함할 수 있는 부울 표현식입니다.

`role_names`

권한을 분석할 대상 롤입니다.

## 예제 (Examples)

이 명령은 데이터베이스에 `sampledb_p1`이라는 이름의 권한 캡처 정책을 생성합니다:

```sql
CREATE CAPTURE PRIVILEGES POLICY sampledb_p1;
```

이 명령은 롤 `sampledb_role1`과 `sampledb_user1`에 `sampledb_p2`라는 이름의 권한 캡처 정책을 생성합니다:

```sql
CREATE CAPTURE PRIVILEGES POLICY sampledb_p2 ON ROLE sampledb_role1,sampledb_user1;
```
