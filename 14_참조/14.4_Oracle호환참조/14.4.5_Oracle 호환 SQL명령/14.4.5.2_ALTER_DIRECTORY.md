# ALTER DIRECTORY — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER DIRECTORY](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/02_alter_directory/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`ALTER DIRECTORY` — [CREATE DIRECTORY](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/22_create_directory/) 명령으로 생성된 디렉터리의 소유자를 변경합니다.

## 구문 개요 (Synopsis)

```sql
ALTER DIRECTORY <name> OWNER TO <rolename>
```

## 설명 (Description)

`ALTER DIRECTORY ...OWNER TO` 명령은 디렉터리의 소유자를 변경합니다. 이 명령을 실행하려면 슈퍼유저 권한이 있어야 합니다. 디렉터리의 새 소유자도 슈퍼유저 권한이 있어야 합니다.

## 파라미터 (Parameters)

`name` — 변경할 디렉터리의 이름.

`rolename` — 디렉터리 소유자의 이름.

## 예제 (Examples)

다음 예들은 소유권을 변경합니다. `bob`과 `carol`은 슈퍼유저입니다. `bob`은 디렉터리 `EMPDIR`의 현재 소유자입니다.

```sql
SELECT * FROM all_directories where directory_name = 'EMPDIR' order
by 1,2,3;
```

출력:

```text
 owner | directory_name | directory_path
-------+----------------+----------------
 bob   | EMPDIR         | /path
(1 row)
```

디렉터리 `EMPDIR`의 소유권을 `carol`로 변경하려면:

```sql
ALTER DIRECTORY EMPDIR OWNER TO carol;
ALTER DIRECTORY

SELECT * FROM all_directories where directory_name = 'EMPDIR' order by
1,2,3;
```

출력:

```text
 owner | directory_name | directory_path
-------+----------------+----------------
 carol | EMPDIR         | /path
(1 row)
```
