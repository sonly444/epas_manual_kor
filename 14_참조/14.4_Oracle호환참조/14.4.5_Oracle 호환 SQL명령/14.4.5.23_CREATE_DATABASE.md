# CREATE DATABASE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › CREATE DATABASE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/20_create_database/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`CREATE DATABASE` — 데이터베이스를 생성합니다.

## 구문 개요 (Synopsis)

```sql
CREATE DATABASE <name>
```

## 설명 (Description)

`CREATE DATABASE`는 데이터베이스를 생성합니다.

데이터베이스를 생성하려면 슈퍼유저이거나 `CREATEDB` 권한을 가지고 있어야 합니다. 일반적으로 생성자가 새 데이터베이스의 소유자가 됩니다. `CREATEDB` 권한을 가진 비(非)슈퍼유저는 자신이 소유한 데이터베이스만 생성할 수 있습니다.

새 데이터베이스는 표준 시스템 데이터베이스 `template1`의 복제본입니다.

## 파라미터 (Parameters)

`name`

생성할 데이터베이스의 이름입니다.

##### 참고 (Note)

트랜잭션 블록 내에서는 `CREATE DATABASE`를 실행할 수 없습니다.

"could not initialize database directory"와 같은 오류는 대부분 데이터 디렉터리에 대한 권한 부족, 디스크 가득 참, 또는 기타 파일 시스템 문제와 관련이 있습니다.

## 예제 (Examples)

데이터베이스를 생성하려면:

```sql
CREATE DATABASE employees;
```
