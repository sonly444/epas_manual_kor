# DROP CAPTURE PRIVILEGES POLICY — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP CAPTURE PRIVILEGES POLICY](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/44a_drop_capture_privilege/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server에는 `DROP CAPTURE PRIVILEGES POLICY` SQL 명령을 통해 Oracle이 제공하지 않는 구문이 포함되어 있습니다.

## 이름 (Name)

`DROP CAPTURE PRIVILEGES POLICY` — 기존의 권한 캡처 정책(capture privilege policy)을 삭제합니다.

## 구문 개요 (Synopsis)

기존 권한 캡처 정책을 삭제하려면 `DROP CAPTURE PRIVILEGES POLICY`를 사용합니다.

```sql
DROP CAPTURE PRIVILEGES POLICY [ IF EXISTS ] <name> [ CASCADE | RESTRICT ]
```

## 설명 (Description)

`DROP CAPTURE PRIVILEGES POLICY`는 슈퍼유저 또는 `CREATE_CAPTURE` 권한을 가진 사용자가 기존 큐를 삭제할 수 있도록 합니다.

## 파라미터 (Parameters)

`name`

삭제할 권한 캡처 정책의 이름(선택적으로 스키마로 한정할 수 있음)입니다.

## 예제 (Examples)

이 예제는 `sampledb_p2`라는 이름의 권한 캡처 정책을 삭제합니다.

```sql
DROP CAPTURE PRIVILEGES POLICY sampledb_p2;
```
