# UPDATEv18

## 이름 (Name)

`UPDATE` — 테이블의 행을 갱신합니다.

## 구문 개요 (Synopsis)

```sql
edb=# \h UPDATE
Command:     UPDATE
Description: update rows of a table
Syntax:
[ WITH [ RECURSIVE ] with_query [, ...] ]
UPDATE [ <optimizer_hint> ][ ONLY ] <table_name>[@<dblink> ] [ * ] [ [ AS ] alias ]
    SET { { <column_name> = { <expression> | DEFAULT } |
            ( <column_name> [, ...] ) = [ ROW ] ( { expression | DEFAULT } [, ...] ) |
            ( <column_name> [, ...] ) = ( sub-SELECT )
          } [, ...] |
          ROW = <row_or_record_var>
        }
    [ FROM <from_item> [, ...] ]
    [ WHERE <condition> | WHERE CURRENT OF <cursor_name> ]
    [ RETURNING <return_expression> [, ...]\
      { INTO { <record> | <variable> [, ...] }\
      | BULK COLLECT INTO <collection> [, ...] } ]

URL: https://www.postgresql.org/docs/15/sql-update.html
     https://www.enterprisedb.com/docs
```

## 설명 (Description)

`UPDATE`는 조건을 충족하는 모든 행에서 지정된 열의 값을 변경합니다. `SET` 절에는 수정하려는 열만 언급하면 됩니다. 명시적으로 수정되지 않은 열은 자신의 값을 유지합니다.

`SET ROW`를 사용하면 레코드 타입 변수 또는 행 타입 객체를 사용하여 대상 레코드를 갱신할 수 있습니다. 사용되는 레코드 또는 행은 테이블의 열과 순서대로 호환 가능한 데이터 타입을 가져야 합니다.

`RETURNING INTO { record | variable [, ...] }` 절은 SPL 프로그램에서만 지정할 수 있습니다. 또한 `UPDATE` 명령의 결과 집합은 한 행을 초과하여 반환해서는 안 됩니다. 그렇지 않으면 예외가 발생합니다. 결과 집합이 비어 있으면 대상 레코드 또는 변수의 내용이 널(null)로 설정됩니다.

SPL 프로그램에서 `RETURNING BULK COLLECT INTO collection [, ...]` 절은 `UPDATE` 명령을 사용하는 경우에만 지정할 수 있습니다. `BULK COLLECT INTO` 절의 대상으로 둘 이상의 컬렉션을 지정하는 경우, 각 컬렉션은 단일 스칼라 필드로 구성되어야 합니다. 즉, `collection`은 레코드일 수 없습니다. `UPDATE` 명령의 결과 집합은 0개 이상의 행을 포함할 수 있습니다. 결과 집합의 각 행에 대해 평가된 `return_expression`은 첫 번째 요소부터 시작하여 `collection`의 요소가 됩니다. `collection`의 기존 행은 모두 삭제됩니다. 결과 집합이 비어 있으면 `collection`도 비어 있습니다.

테이블을 갱신하려면 해당 테이블에 대한 `UPDATE` 권한이 필요합니다. 또한 `expression`이나 `condition`에서 값을 읽는 모든 테이블에 대한 `SELECT` 권한도 필요합니다.

## 파라미터 (Parameters)

`optimizer_hint`

실행 계획을 선택하기 위한, 옵티마이저에 대한 주석 내장(comment-embedded) 힌트입니다.

`table`

갱신할 테이블의 이름(선택적으로 스키마로 한정 가능)입니다.

`dblink`

원격 데이터베이스를 식별하는 데이터베이스 링크 이름입니다. 데이터베이스 링크에 대한 정보는 [`CREATE DATABASE LINK` 명령](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/21_create_public_database_link/#create_public_database_link)을 참조하세요.

`column`

테이블에 있는 열의 이름입니다.

`expression`

열에 할당할 표현식입니다. 이 표현식은 이 열 및 테이블의 다른 열의 이전 값을 사용할 수 있습니다.

`DEFAULT`

열을 자신의 기본값으로 설정합니다. 기본 표현식을 할당하지 않은 경우 이는 널(null)입니다.

`condition`

`BOOLEAN` 타입의 값을 반환하는 표현식입니다. 이 표현식이 참을 반환하는 행만 갱신합니다.

`return_expression`

테이블의 하나 이상의 열을 포함할 수 있는 표현식입니다. `return_expression`에 테이블의 열 이름이 지정된 경우, `return_expression`을 평가할 때 그 열에 대해 대체되는 값은 다음과 같이 결정됩니다:

- `return_expression`에 지정된 열이 `UPDATE` 명령에서 값을 할당받은 경우, `return_expression`을 평가할 때 할당된 값이 사용됩니다.

- `return_expression`에 지정된 열이 `UPDATE` 명령에서 값을 할당받지 않은 경우, `return_expression`을 평가할 때 영향을 받는 행에서 그 열의 현재 값이 사용됩니다.


`record`

평가된 `return_expression`을 할당할 필드를 가진 레코드입니다. 첫 번째 `return_expression`은 `record`의 첫 번째 필드에 할당되고, 두 번째 `return_expression`은 `record`의 두 번째 필드에 할당되며, 이런 식으로 계속됩니다. `record`의 필드 수는 표현식의 수와 정확히 일치해야 하며, 필드는 할당된 표현식과 타입 호환이 되어야 합니다.

`variable`

평가된 `return_expression`을 할당할 변수입니다. 둘 이상의 `return_expression`과 `variable`이 지정된 경우, 첫 번째 `return_expression`은 첫 번째 `variable`에 할당되고, 두 번째 `return_expression`은 두 번째 `variable`에 할당되며, 이런 식으로 계속됩니다. `INTO` 키워드 뒤에 지정된 변수의 수는 `RETURNING` 키워드 뒤의 표현식 수와 정확히 일치해야 하며, 변수는 할당된 표현식과 타입 호환이 되어야 합니다.

`collection`

평가된 `return_expression`으로부터 요소가 생성되는 컬렉션입니다. 다음 중 하나일 수 있습니다:

- 단일 필드의 컬렉션이거나 레코드 타입의 컬렉션일 수 있는 단일 컬렉션

- 둘 이상의 컬렉션, 이 경우 각 컬렉션은 단일 필드로 구성되어야 함

반환 표현식의 수는 지정된 모든 컬렉션의 필드 수와 개수 및 순서가 일치해야 합니다. 각각 대응하는 `return_expression`과 `collection` 필드는 타입 호환이 되어야 합니다.


## 예제 (Examples)

`dept` 테이블에서 부서 `20`의 위치를 `AUSTIN`으로 변경합니다:

```sql
UPDATE dept SET loc = 'AUSTIN' WHERE deptno = 20;
```

`emp` 테이블에서 `job = SALESMAN`인 모든 직원에 대해 급여를 10% 인상하고 커미션을 500 증가시킵니다:

```sql
UPDATE emp SET sal = sal * 1.1, comm = comm + 500 WHERE job = 'SALESMAN';
```

`SET ROW` 예제:

```sql
CREATE TABLE db1425_t1(a INT, b INT);
INSERT INTO db1425_t1 VALUES(1,2);

DECLARE
	TYPE rec IS RECORD (x INT, y INT);
    	rec_var rec;
BEGIN
	rec_var = row(1000, 1000);
	UPDATE db1425_t1 SET ROW=rec_var WHERE a = 1;
END;
```
