# ALTER ROLE: Managing database link and DBMS_RLS privileges

EDB Postgres Advanced Server는 `ALTER ROLE` 명령에 대해 Oracle이 제공하지 않는 추가 구문을 포함합니다. 이 구문은 Oracle 데이터베이스와 호환되는 데이터베이스 링크를 생성하고 삭제하는 것과 관련된 권한을 할당하거나, `DBMS_RLS`를 사용한 세분화된 접근 제어(fine-grained access control)에 관한 권한을 할당할 때 유용하게 사용할 수 있습니다.

## CREATE DATABASE LINK

`CREATE DATABASE LINK` 권한을 보유한 사용자는 프라이빗 데이터베이스 링크를 생성할 수 있습니다. 다음 `ALTER ROLE` 명령은 지정된 롤이 프라이빗 데이터베이스 링크를 생성할 수 있도록 EDB Postgres Advanced Server 롤에 권한을 부여합니다:

```sql
ALTER ROLE role_name
    WITH [CREATEDBLINK | CREATE DATABASE LINK]
```

이 명령은 다음과 기능적으로 동일합니다:

```sql
GRANT CREATE DATABASE LINK to role_name
```

권한을 회수하려면 다음 명령을 사용합니다:

```sql
ALTER ROLE role_name
  WITH [NOCREATEDBLINK | NO CREATE DATABASE LINK]
```

##### 참고 (Note)

`CREATEDBLINK`와 `NOCREATEDBLINK` 키워드는 더 이상 사용되지 않는(deprecated) 구문입니다. `CREATE DATABASE LINK` 및 `NO CREATE DATABASE LINK` 구문 옵션을 사용할 것을 권장합니다.

## EXEMPT ACCESS POLICY

`EXEMPT ACCESS POLICY` 권한을 보유한 사용자는 세분화된 접근 제어(`DBMS_RLS`) 정책에서 면제됩니다. 이 권한을 보유한 사용자는 `DBMS_RLS` 정책에 의해 제약된 테이블의 모든 행을 조회하거나 수정할 수 있습니다. 다음 `ALTER ROLE` 명령은 지정된 롤을 정의된 모든 `DBMS_RLS` 정책에서 면제하도록 EDB Postgres Advanced Server 롤에 권한을 부여합니다:

```sql
ALTER ROLE role_name
    WITH [POLICYEXEMPT | EXEMPT ACCESS POLICY]
```

이 명령은 다음과 기능적으로 동일합니다:

```sql
GRANT EXEMPT ACCESS POLICY TO role_name
```

권한을 회수하려면 다음 명령을 사용합니다:

```sql
ALTER ROLE role_name
  WITH [NOPOLICYEXEMPT | NO EXEMPT ACCESS POLICY]
```

##### 참고 (Note)

`POLICYEXEMPT`와 `NOPOLICYEXEMPT` 키워드는 더 이상 사용되지 않는(deprecated) 구문입니다. `EXEMPT ACCESS POLICY` 및 `NO EXEMPT ACCESS POLICY` 구문 옵션을 사용할 것을 권장합니다.
