# SET ROLEv18

## 이름 (Name)

`SET ROLE` — 현재 세션의 현재 사용자 식별자를 설정합니다.

## 구문 개요 (Synopsis)

```sql
SET ROLE { rolename | NONE }
```

## 설명 (Description)

이 명령은 현재 SQL 세션 컨텍스트의 현재 사용자 식별자를 `<rolename>`으로 설정합니다. `SET ROLE` 이후, SQL 명령에 대한 권한 검사는 마치 지정된 롤이 처음에 로그인한 것처럼 수행됩니다.

지정된 롤 이름은 현재 세션 사용자가 멤버로 속해 있는 롤이어야 합니다. 슈퍼유저는 임의의 롤을 선택할 수 있습니다.

`NONE`은 현재 사용자 식별자를 현재 세션 사용자 식별자로 재설정합니다. 모든 사용자가 이 형식을 실행할 수 있습니다.

## 참고 (Notes)

이 명령을 사용하여 권한을 추가하거나 제한할 수 있습니다. 세션 사용자 롤이 `INHERITS` 속성을 가지고 있으면, 자신이 설정할 수 있는 모든 롤의 모든 권한을 자동으로 갖습니다. 이 경우 `SET ROLE`은 세션 사용자와 그가 멤버로 속한 다른 롤에 직접 할당된 모든 권한을 삭제하여, 지정된 롤에서 사용 가능한 권한만 남깁니다. 세션 사용자 롤이 `NOINHERITS` 속성을 가지고 있으면, `SET ROLE`은 세션 사용자에게 직접 할당된 권한을 삭제하고 대신 지정된 롤에서 사용 가능한 권한을 획득합니다. 슈퍼유저가 롤을 비슈퍼유저 롤로 설정하기로 선택하면, 슈퍼유저 권한을 잃습니다.

## 예제 (Examples)

사용자 `mary`가 롤 `admins`의 정체성을 취합니다:

```sql
SET ROLE admins;
```

사용자 `mary`가 자신의 정체성으로 되돌아갑니다:

```sql
SET ROLE NONE;
```
