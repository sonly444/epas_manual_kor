# CREATE USER v18

## 이름 (Name)

`CREATE USER` — 새 데이터베이스 사용자 계정을 정의합니다.

## 구문 개요 (Synopsis)

```sql
CREATE USER <name> [IDENTIFIED BY <password>]
```

## 설명 (Description)

`CREATE USER`는 EDB Postgres Advanced Server 데이터베이스 클러스터에 사용자를 추가합니다. 이 명령을 사용하려면 데이터베이스 슈퍼유저여야 합니다.

`CREATE USER` 명령을 호출하면 새 사용자와 동일한 이름의 스키마가 생성됩니다. 새 스키마는 새 사용자가 소유합니다. 이 사용자가 생성하는, 한정되지 않은 이름을 가진 객체는 이 스키마에 생성됩니다.

## 파라미터 (Parameters)

`name`

사용자의 이름입니다.

`password`

사용자의 비밀번호입니다. 나중에 `ALTER USER`를 사용하여 비밀번호를 변경할 수 있습니다.

## 참고 사항 (Notes)

사용자 이름과 비밀번호에 허용되는 최대 길이는 63자입니다.

## 예제 (Examples)

`john`이라는 사용자를 생성합니다.

```sql
CREATE USER john IDENTIFIED BY abc;
```
