# CREATE PACKAGE BODY — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › CREATE PACKAGE BODY](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/27_create_package_body/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`CREATE PACKAGE BODY` — 새로운 패키지 본문(package body)을 정의합니다.

## 구문 개요 (Synopsis)

```sql
CREATE [ OR REPLACE ] PACKAGE BODY <name>
{ IS | AS }
  [ declaration; ] | [ forward_declaration ] [, ...]
  [ { PROCEDURE <proc_name>
      [ (<argname> [ IN | IN OUT | OUT ] <argtype> [ DEFAULT <value> ] [, ...]) ]
      [ STRICT ]
      [ LEAKPROOF ]
      [ PARALLEL { UNSAFE | RESTRICTED | SAFE } ]
      [ COST <execution_cost> ]
      [ ROWS <result_rows> ]
      [ SET <config_param> { TO <value> | = <value> | FROM CURRENT } ]
    { IS | AS }
        <program_body>
      END [ <proc_name> ];
    |
      FUNCTION <func_name>
      [ (<argname> [ IN | IN OUT | OUT ] <argtype> [ DEFAULT <value> ] [, ...]) ]
      RETURN <rettype> [ DETERMINISTIC ]
      [ STRICT ]
      [ LEAKPROOF ]
      [ PARALLEL { UNSAFE | RESTRICTED | SAFE } ]
      [ COST <execution_cost> ]
      [ ROWS <result_rows> ]
      [ SET <config_param> { TO <value> | = <value> | FROM CURRENT } ]
    { IS | AS }
        <program_body>
      END [ <func_name> ];
    }
  ] [, ...]
  [ BEGIN
      <statement>; [, ...] ]
  END [ <name> ]

Where forward_declaration:=

[ { PROCEDURE <proc_name>
  [ (<argname> [ IN | IN OUT | OUT ] <argtype> [ DEFAULT <value> ] [, ...])
  ] ; ]
|
[ { FUNCTION <func_name>
  [ (<argname> [ IN | IN OUT | OUT ] <argtype> [ DEFAULT <value> ] [, ...])
  ]
  RETURN <rettype> [ DETERMINISTIC ]; ]
```

## 설명 (Description)

`CREATE PACKAGE BODY`는 새로운 패키지 본문을 정의합니다. `CREATE OR REPLACE PACKAGE BODY`는 새 패키지 본문을 생성하거나 기존 본문을 대체합니다.

스키마 이름을 포함하면 패키지 본문은 지정된 스키마에 생성됩니다. 그렇지 않으면 현재 스키마에 생성됩니다. 새 패키지 본문의 이름은 동일한 스키마 내의 기존 패키지 사양과 일치해야 합니다. 새 패키지 본문 이름은 기존 패키지 본문의 정의를 업데이트하려는 경우가 아니라면 동일한 스키마 내의 기존 패키지 본문과 일치할 수 없습니다. 그런 경우에는 `CREATE OR REPLACE PACKAGE BODY`를 사용합니다.

## 파라미터 (Parameters)

`name`

생성할 패키지 본문의 이름(선택적으로 스키마로 한정 가능)입니다.

`declaration`

비공개(private) 변수, 타입, 커서 또는 `REF CURSOR` 선언입니다.

`forward_declaration`

프로시저나 함수의 전방 선언(forward declaration)은 패키지 본문에 나타나며 실제 본문 정의보다 앞서서 선언됩니다. 블록에서 여러 서브프로그램을 생성할 수 있습니다. 서로를 호출하는 경우, 각각 전방 선언이 필요합니다. 서브프로그램을 호출하기 전에 먼저 선언해야 합니다. 전방 선언을 사용하여 서브프로그램을 정의하지 않고 선언할 수 있습니다. 전방 선언과 그에 해당하는 정의는 동일한 블록에 있어야 합니다.

`proc_name`

공개 또는 비공개 프로시저의 이름입니다. `proc_name`이 동일한 시그니처로 패키지 사양에 존재하면 공개입니다. 그렇지 않으면 비공개입니다.

`argname`

인수의 이름입니다.

`IN | IN OUT | OUT`

인수 모드입니다.

`argtype`

프로그램 인수의 데이터 타입입니다.

`DEFAULT value`

입력 인수의 기본값입니다.

`STRICT`

`NULL` 인수로 호출될 때 함수가 실행되지 않도록 지정하려면 `STRICT` 키워드를 사용합니다. 대신 함수는 `NULL`을 반환합니다.

`LEAKPROOF`

함수가 반환 값 이외의 방법으로 인수에 대한 정보를 드러내지 않도록 지정하려면 `LEAKPROOF` 키워드를 사용합니다.

`PARALLEL { UNSAFE | RESTRICTED | SAFE }`

`PARALLEL` 절은 병렬 순차 스캔(병렬 모드)의 사용을 활성화합니다. 병렬 순차 스캔은 직렬 순차 스캔과 대조적으로, 쿼리 중에 여러 워커(worker)를 사용하여 릴레이션을 병렬로 스캔합니다.

- `UNSAFE`(기본값)로 설정되면 프로시저나 함수는 병렬 모드에서 실행할 수 없습니다. 이러한 프로시저나 함수가 존재하면 직렬 실행 계획이 강제됩니다.

- `RESTRICTED`로 설정되면 프로시저나 함수는 병렬 모드에서 실행할 수 있지만, 실행은 병렬 그룹 리더로 제한됩니다. 특정 릴레이션에 대한 조건(qualification)에 병렬 제한(parallel restricted) 요소가 있으면 해당 릴레이션은 병렬 처리 대상으로 선택되지 않습니다.

- `SAFE`로 설정되면 프로시저나 함수는 제한 없이 병렬 모드에서 실행할 수 있습니다.


`execution_cost`

`execution_cost`는 `cpu_operator_cost` 단위로 함수의 예상 실행 비용을 나타내는 양수를 지정합니다. 함수가 집합(set)을 반환하는 경우, 이는 반환되는 행당 비용입니다. 기본값은 `0.0025`입니다.

`result_rows`

`result_rows`는 쿼리 플래너가 함수가 반환할 것으로 예상하는 행 수입니다. 기본값은 `1000`입니다.

`SET`

함수가 실행되는 동안의 파라미터 값을 지정하려면 `SET` 절을 사용합니다:

- `config_param`은 파라미터 이름을 지정합니다.

- `value`는 파라미터 값을 지정합니다.

- `FROM CURRENT`는 함수가 종료될 때 파라미터 값이 복원되도록 보장합니다.


`program_body`

함수 또는 프로시저의 본문을 구성하는 프래그마, 선언, SPL 문입니다.

프래그마는 함수나 프로시저를 자율 트랜잭션(autonomous transaction)으로 설정하기 위해 `PRAGMA AUTONOMOUS_TRANSACTION`일 수 있습니다.

선언은 변수, 타입, `REF CURSOR` 또는 서브프로그램 선언을 포함할 수 있습니다. 서브프로그램 선언을 포함하는 경우, 다른 모든 변수, 타입, `REF CURSOR` 선언 뒤에 선언합니다.

`func_name`

공개 또는 비공개 함수의 이름입니다. `func_name`이 동일한 시그니처로 패키지 사양에 존재하면 공개입니다. 그렇지 않으면 비공개입니다.

`rettype`

반환 데이터 타입입니다.

`DETERMINISTIC`

동일한 인수 값이 주어졌을 때 함수가 항상 동일한 결과를 반환하도록 지정하려면 `DETERMINISTIC`을 포함합니다. `DETERMINISTIC` 함수는 데이터베이스를 수정하면 안 됩니다.

##### 참고 (Note)

`DETERMINISTIC` 키워드는 PostgreSQL의 `IMMUTABLE` 옵션과 동등합니다. 패키지 본문의 공개 함수에 `DETERMINISTIC`을 지정하는 경우, 패키지 사양의 함수 선언에도 지정해야 합니다. 비공개 함수의 경우, 패키지 사양에 함수 선언이 없습니다.

`statement`

SPL 프로그램 문입니다. 패키지 초기화 섹션의 문은 패키지가 처음 참조될 때 세션당 한 번 실행됩니다.

##### 참고 (Note)

`STRICT`, `LEAKPROOF`, `PARALLEL`, `COST`, `ROWS`, `SET` 키워드는 EDB Postgres Advanced Server를 위한 확장 기능을 제공하며 Oracle에서는 지원되지 않습니다.

## 예제 (Examples)

다음은 `empinfo` 패키지의 패키지 본문입니다:

```sql
CREATE OR REPLACE PACKAGE BODY empinfo
IS
    v_counter       INTEGER;
    PROCEDURE get_name (
        p_empno     NUMBER
    )
    IS
    BEGIN
        SELECT ename INTO emp_name FROM emp WHERE empno = p_empno;
        v_counter := v_counter + 1;
    END;
    FUNCTION display_counter
    RETURN INTEGER
    IS
    BEGIN
        RETURN v_counter;
    END;
BEGIN
    v_counter := 0;
    DBMS_OUTPUT.PUT_LINE('Initialized counter');
END;
```

다음 두 익명 블록은 `empinfo` 패키지의 프로시저와 함수를 실행하고 공개 변수를 표시합니다:

```sql
BEGIN
    empinfo.get_name(7369);
    DBMS_OUTPUT.PUT_LINE('Employee Name    : ' || empinfo.emp_name);
    DBMS_OUTPUT.PUT_LINE('Number of queries: ' || empinfo.display_counter);
END;

Initialized counter
Employee Name    : SMITH
Number of queries: 1

BEGIN
    empinfo.get_name(7900);
    DBMS_OUTPUT.PUT_LINE('Employee Name    : ' || empinfo.emp_name);
    DBMS_OUTPUT.PUT_LINE('Number of queries: ' || empinfo.display_counter);
END;

Employee Name    : JAMES
Number of queries: 2
```

이 예제는 패키지 본문에서 전방 선언을 사용합니다. 이 예제는 급여가 지정된 범위에 속하는 직원의 이름과 수를 표시합니다.

```sql
CREATE OR REPLACE PACKAGE empinfo IS
  FUNCTION emp_comp (p_sal_range INTEGER) RETURN INTEGER;
END empinfo;

CREATE OR REPLACE PACKAGE BODY empinfo IS
  FUNCTION sal_range (p_sal_range INTEGER) RETURN INTEGER;
  PROCEDURE list_emp (p_sal_range INTEGER);

  FUNCTION emp_comp (p_sal_range INTEGER) RETURN INTEGER IS
  BEGIN
    dbms_output.put_line ('Employee details');
    return sal_range(p_sal_range);
  END;

  FUNCTION sal_range (p_sal_range INTEGER) RETURN INTEGER IS
    emp_cnt INTEGER;
  BEGIN
    select count(*) into emp_cnt from emp where sal <= p_sal_range;
    dbms_output.put_line('Number of employees in the salary range ' ||
p_sal_range|| ' is :'|| emp_cnt);
    list_emp(p_sal_range);
    return emp_cnt;
  END;

  PROCEDURE list_emp (p_sal_range IN INTEGER) IS
  BEGIN
    FOR i IN select ename from emp where sal <= p_sal_range
    LOOP
       dbms_output.put_line (i);
    END LOOP;
  END;

END empinfo;

SELECT empinfo.emp_comp(1500);
```

출력

```text
Employee details
Number of employees in the salary range 1500 is :7
(SMITH)
(WARD)
(MARTIN)
(TURNER)
(ADAMS)
(JAMES)
(MILLER)
emp_comp
----------
        7
(1 row)
```
