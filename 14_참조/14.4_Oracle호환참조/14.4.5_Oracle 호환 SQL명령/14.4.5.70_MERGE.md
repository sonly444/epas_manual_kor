# MERGEv18

## 이름 (Name)

`MERGE` — 테이블의 행을 조건에 따라 삽입, 갱신 또는 삭제합니다.

## 구문 개요 (Synopsis)

```sql
MERGE INTO target_table_name [ target_alias ]
USING data_source [ source_alias ] ON ( join_condition )
merge_update_clause merge_insert_clause

-- where merge_update_clause is
WHEN MATCHED THEN
   UPDATE SET column = value, ... [ WHERE where_condition ]
   [ DELETE WHERE where_condition ]

-- and merge_insert_clause is
WHEN NOT MATCHED THEN
   INSERT [(col_list)] VALUES (val_list) [ WHERE where_condition ]
```

## 설명 (Description)

`MERGE`를 사용하면 하나 이상의 소스에서 행을 선택하여 테이블에 갱신하거나 삽입할 수 있습니다. 대상 테이블을 갱신할지 삽입할지 결정하기 위해 조인 조건을 지정합니다. MERGE 문에서 WHERE 절을 사용하여 조건부 UPDATE 및 INSERT 문을 지정합니다.

`MERGE`는 조건에 따라 행을 INSERT, UPDATE 또는 DELETE할 수 있는 단일 SQL 문을 제공하며, 이는 그렇지 않으면 여러 개의 절차적 언어(procedural language) 문이 필요한 작업입니다.

자세한 내용은 [MERGE statement](https://www.postgresql.org/docs/current/sql-merge.html)를 참조하세요.

## 파라미터 (Parameters)

`target_table_name`

병합 대상이 되는 대상 테이블의 이름(선택적으로 스키마로 한정 가능)입니다.

`target_alias`

대상 테이블의 대체 이름입니다. 별칭이 제공되면 테이블의 실제 이름을 완전히 숨깁니다.

`data_source`

소스 테이블(선택적으로 스키마로 한정 가능) 또는 소스 쿼리의 이름입니다. 소스 테이블은 소스 테이블 이름, 뷰 이름 또는 전이 테이블(transition table) 이름입니다. 소스 쿼리(SELECT 또는 VALUES 문)는 target\_table\_name에 병합할 행을 제공합니다.

`source_alias`

데이터 소스의 대체 이름입니다. 별칭이 제공되면 테이블의 실제 이름을 완전히 숨깁니다.

`join_condition`

data\_source의 어떤 행이 target\_table\_name의 행과 일치하는지를 지정하는 WHERE 절과 유사한, boolean 타입의 값을 반환하는 표현식입니다.

`merge_update_clause`

대상 테이블의 새 열 값을 지정합니다. ON 절의 join\_condition이 참이면 이 갱신을 수행합니다.

지정된 조건이 참인 경우에만 데이터베이스가 갱신 작업을 실행하도록 하려면 where\_condition을 지정합니다. 이 조건은 데이터 소스나 대상 테이블 중 어느 쪽이든 참조할 수 있습니다. 조건이 참이 아니면 데이터베이스는 해당 행을 테이블에 병합할 때 갱신 작업을 건너뜁니다.

테이블을 채우거나 갱신하는 동안 테이블의 데이터를 정리하려면 DELETE where\_condition을 지정합니다. 이 절의 영향을 받는 유일한 행은 병합 작업으로 갱신되는 대상 테이블의 행뿐입니다. DELETE WHERE 조건은 UPDATE SET ... WHERE 조건이 평가한 원래 값이 아니라 갱신된 값을 평가합니다. 대상 테이블의 어떤 행이 DELETE 조건을 충족하지만 ON 절로 정의된 조인에 포함되지 않으면 삭제되지 않습니다.

이 절은 단독으로 지정하거나 merge\_insert\_clause와 함께 지정할 수 있습니다. 둘 다 지정하는 경우 순서는 어느 쪽이든 상관없습니다.

`merge_insert_clause`

merge\_insert\_clause는 ON 절의 조건이 거짓인 경우 대상 테이블의 열에 삽입할 값을 지정합니다. INSERT 키워드 뒤의 열 목록을 생략하면 대상 테이블의 열 수가 VALUES 절의 값 수와 일치해야 합니다.

모든 소스 행을 테이블에 삽입하려면 ON 절 조건에 상수 필터 술어(constant filter predicate)를 사용할 수 있습니다. 상수 필터 술어의 예로는 `ON (0=1)`이 있습니다. 데이터베이스는 이러한 술어를 인식하여 모든 소스 행을 테이블에 무조건 삽입합니다. 이 방식은 merge\_update\_clause를 생략하는 것과는 다릅니다. 그 경우 데이터베이스는 여전히 조인을 수행해야 합니다. 상수 필터 술어를 사용하면 조인이 수행되지 않습니다.

지정된 조건이 참인 경우에만 데이터베이스가 삽입 작업을 실행하도록 하려면 where\_clause를 지정합니다. 이 조건은 데이터 소스 테이블만 참조할 수 있습니다. 데이터베이스는 조건이 참이 아닌 모든 행에 대해 삽입 작업을 건너뜁니다.

이 절은 단독으로 지정하거나 merge\_update\_clause와 함께 지정할 수 있습니다. 둘 다 지정하는 경우 순서는 어느 쪽이든 상관없습니다.

## 예제 (Examples)

`target` 테이블과 `source` 테이블을 생성합니다:

```sql
CREATE TABLE target (tid integer, balance integer);
CREATE TABLE source (sid integer, delta integer);
```

두 테이블에 행을 추가합니다:

```sql
# Insert rows into target table
INSERT INTO target VALUES (1, 0);
INSERT INTO target VALUES (2, 20);
INSERT INTO target VALUES (3, 0);

# Insert rows into source table
INSERT INTO source VALUES (1, 100);
INSERT INTO source VALUES (2, 200);
INSERT INTO source VALUES (3, 300);
INSERT INTO source VALUES (4, 100);
INSERT INTO source VALUES (5, 300);
INSERT INTO source VALUES (6, 600);
```

다음 예제는 MERGE 문을 사용하여 대상 테이블의 행을 UPDATE 및 INSERT하는 방법을 보여줍니다:

```sql
MERGE INTO target t
USING source s
ON (t.tid = s.sid)
WHEN MATCHED THEN
    UPDATE SET balance = s.delta
WHEN NOT MATCHED THEN
    INSERT VALUES (s.sid, s.delta);
```

다음 예제는 MERGE 문을 사용하여 대상 테이블의 행을 UPDATE, INSERT하고 조건에 따라 DELETE하는 방법을 보여줍니다:

```sql
MERGE INTO target t
USING source s
ON (t.tid = s.sid)
WHEN MATCHED THEN
    UPDATE SET t.balance = t.balance + 100
    DELETE WHERE sid = 1
WHEN NOT MATCHED THEN
    INSERT VALUES (s.sid, s.delta);
```

다음 예제는 MERGE 문을 사용하여 대상 테이블의 행을 조건에 따라 UPDATE, INSERT, DELETE하는 방법을 보여줍니다:

```sql
MERGE INTO target t
USING source s
ON (t.tid = s.sid)
WHEN MATCHED THEN
    UPDATE SET balance = s.delta WHERE balance = 0
    DELETE WHERE sid = 1
WHEN NOT MATCHED THEN
    INSERT VALUES (s.sid, s.delta) WHERE s.sid >= 5;
```
