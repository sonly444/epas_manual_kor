# CREATE DIRECTORY — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › CREATE DIRECTORY](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/22_create_directory/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`CREATE DIRECTORY` — 파일 시스템 디렉터리 경로에 대한 별칭(alias)을 생성합니다.

## 구문 개요 (Synopsis)

```sql
CREATE DIRECTORY <name> AS '<pathname>'
```

## 설명 (Description)

디렉터리를 생성하려면 `CREATE ANY DIRECTORY` 시스템 권한이 있어야 합니다. 다음은 관리자가 이 권한을 부여하는 방법의 예입니다:

```sql
grant create any directory to example_role;
```

디렉터리를 생성하면 해당 디렉터리에 대한 `READ` 및 `WRITE` 권한이 자동으로 부여되며, 다른 사용자와 롤에 `READ` 및 `WRITE` 권한을 부여할 수 있습니다. 슈퍼유저도 이러한 권한을 다른 사용자와 롤에 부여할 수 있습니다. 사용자에 대한 권한 관리에 대한 자세한 내용은 [UTL_FILE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/20_utl_file/)을 참조하세요.

`CREATE DIRECTORY` 명령은 파일 시스템 디렉터리 경로 이름에 대한 별칭을 생성합니다.

이 별칭을 `UTL_FILE` 패키지의 프로그램에 적절한 파라미터로 지정하면, 운영체제 파일이 해당 별칭에 대응하는 디렉터리에 생성되거나 그 디렉터리에서 접근됩니다.

## 파라미터 (Parameters)

`name`

디렉터리 별칭 이름입니다.

`pathname`

별칭 이름으로 표현되는 완전한 형태의 디렉터리 경로입니다. `CREATE DIRECTORY` 명령은 운영체제 디렉터리를 생성하지 않습니다. 물리적 디렉터리는 운영체제 명령을 사용하여 별도로 생성해야 합니다.

## 참고 사항 (Notes)

`UTL_FILE` 패키지를 사용하여 디렉터리를 통해 파일을 생성하거나 읽으려면, 운영체제 사용자 ID `enterprisedb`가 해당 디렉터리에 대한 적절한 읽기 및 쓰기 권한을 가지고 있어야 합니다.

디렉터리 별칭은 `pg_catalog.edb_dir` 시스템 카탈로그 테이블에 저장됩니다.

##### 참고 (Note)

`edb_dir` 테이블은 Oracle 데이터베이스와 호환되지 않습니다.

Oracle 카탈로그 뷰 `SYS.ALL_DIRECTORIES`와 `SYS.DBA_DIRECTORIES`에서도 디렉터리 별칭을 볼 수 있습니다. 이 뷰들은 Oracle 데이터베이스와 호환됩니다.

디렉터리 별칭을 삭제하려면 `DROP DIRECTORY` 명령을 사용합니다. 디렉터리 별칭을 삭제해도 해당하는 물리적 파일 시스템 디렉터리에는 영향을 미치지 않습니다. 파일 시스템 디렉터리는 운영체제 명령을 사용하여 삭제하세요.

Linux 시스템에서 디렉터리 이름 구분자는 슬래시 `(/)`입니다.

Windows 시스템에서는 디렉터리 이름 구분자를 슬래시 `(/)` 또는 두 개의 연속된 백슬래시 `(\\)`로 지정할 수 있습니다.

## 예제 (Examples)

Linux에서 디렉터리 `/tmp/empdir`에 대한 `empdir`이라는 별칭을 생성합니다:

```sql
CREATE DIRECTORY empdir AS '/tmp/empdir';
```

Windows에서 디렉터리 `C:\TEMP\EMPDIR`에 대한 `empdir`이라는 별칭을 생성합니다:

```sql
CREATE DIRECTORY empdir AS 'C:/TEMP/EMPDIR';
```

모든 디렉터리 별칭을 봅니다:

```sql
SELECT * FROM pg_catalog.edb_dir;
```

출력

```text
dirname | dirowner |    dirpath     | diracl
--------+----------+----------------+--------
 empdir |       10 | C:/TEMP/EMPDIR |
(1 row)
```

Oracle 데이터베이스와 호환되는 뷰를 사용하여 디렉터리 별칭을 봅니다:

```sql
SELECT * FROM SYS.ALL_DIRECTORIES;
```

출력

```text
    owner     | directory_name | directory_path
--------------+----------------+----------------
 ENTERPRISEDB | EMPDIR         | C:/TEMP/EMPDIR
(1 row)
```
