# ALTER USER… IDENTIFIED BY — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER USER… IDENTIFIED BY](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/15_alter_user_identified_by/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`ALTER USER` — 데이터베이스 사용자 계정을 변경합니다.

## 구문 개요 (Synopsis)

```sql
ALTER USER <role_name> IDENTIFIED BY <password> REPLACE <prev_password>
```

## 설명 (Description)

`CREATEROLE` 권한이 없는 롤은 이 명령을 사용하여 자신의 비밀번호를 변경할 수 있습니다. 권한이 없는 롤은 프로파일의 `PASSWORD_VERIFY_FUNCTION`이 `NULL`이 아닌 경우 `REPLACE` 절과 자신의 이전 비밀번호를 포함해야 합니다. 슈퍼유저가 아닌 사용자가 `REPLACE` 절을 사용하면, 서버는 제공된 비밀번호를 기존 비밀번호와 비교하고 비밀번호가 일치하지 않으면 오류를 발생시킵니다.

데이터베이스 슈퍼유저는 이 명령을 사용하여 임의의 롤에 연결된 비밀번호를 변경할 수 있습니다. 슈퍼유저가 `REPLACE` 절을 포함하면 해당 절은 무시됩니다. 이전 비밀번호가 일치하지 않는 값이더라도 오류를 발생시키지 않습니다.

비밀번호를 변경하려는 롤이 `SUPERUSER` 속성을 가지고 있다면, 슈퍼유저가 이 명령을 실행해야 합니다. `CREATEROLE` 속성을 가진 롤은 이 명령을 사용하여 슈퍼유저가 아닌 롤에 연결된 비밀번호를 변경할 수 있습니다.

## 파라미터 (Parameters)

`role_name`

비밀번호를 변경할 롤의 이름.

`password`

롤의 새 비밀번호.

`prev_password`

롤의 이전 비밀번호.

## 예제 (Examples)

사용자 비밀번호를 변경합니다:

```sql
ALTER USER john IDENTIFIED BY xyRP35z REPLACE 23PJ74a;
```
