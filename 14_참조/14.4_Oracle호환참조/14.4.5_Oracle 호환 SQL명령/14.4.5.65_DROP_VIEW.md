# DROP VIEW — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP VIEW](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/62_drop_view/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`DROP VIEW` — 뷰를 제거합니다.

## 구문 개요 (Synopsis)

```sql
DROP VIEW <name>
```

## 설명 (Description)

`DROP VIEW`는 기존 뷰를 삭제합니다. 이 명령을 실행하려면 데이터베이스 슈퍼유저이거나 해당 뷰의 소유자여야 합니다. 뷰의 뷰(view of a view)와 같이 다른 객체가 이 뷰에 의존하고 있으면 지정된 뷰는 삭제되지 않습니다.

Oracle과 호환되는 형태의 `DROP VIEW` 명령은 `CASCADE` 절을 지원하지 않습니다. 뷰와 그 의존성을 함께 삭제하려면 `DROP VIEW` 명령의 PostgreSQL 호환 형태를 사용하십시오. 자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/sql-dropview.html)를 참조하십시오.

## 파라미터 (Parameters)

`name`

제거할 뷰의 이름입니다(선택적으로 스키마로 한정할 수 있습니다).

## 예제 (Examples)

이 예제는 `dept_30`이라는 이름의 뷰를 제거합니다.

```sql
DROP VIEW dept_30;
```
