# ALTER CAPTURE PRIVILEGE POLICY — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER CAPTURE PRIVILEGE POLICY](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/01_alter_capture_privilege/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 `ALTER CAPTURE PRIVILEGES POLICY` SQL 명령에 Oracle이 제공하지 않는 추가 구문을 포함합니다.

## 이름 (Name)

`ALTER CAPTURE PRIVILEGES POLICY` — 슈퍼유저 또는 `CAPTURE_ADMIN` 역할을 가진 사용자가 캡처 권한 정책의 속성을 수정할 수 있게 합니다.

## 구문 개요 (Synopsis)

이 명령은 다섯 가지 형태로 사용할 수 있습니다.

```sql
ALTER CAPTURE PRIVILEGES POLICY <name> SET WHERE ( <expression> )

ALTER CAPTURE PRIVILEGES POLICY <name> DROP WHERE

ALTER CAPTURE PRIVILEGES POLICY <name> SET { ROLE | USER } <role_names>

ALTER CAPTURE PRIVILEGES POLICY <name> DROP { ROLE | USER }

ALTER CAPTURE PRIVILEGES POLICY <name> { ENABLE | DISABLE } [ <run_name> ]
```

## 설명 (Description)

`ALTER CAPTURE PRIVILEGES POLICY` 명령은 데이터베이스 슈퍼유저 또는 시스템 정의 `CAPTURE_ADMIN` 권한을 가진 사용자가 데이터베이스의 정책을 변경할 수 있게 합니다.

캡처 정책을 제거하려면 `DROP CAPTURE PRIVILEGES POLICY`를 사용합니다.

## 파라미터 (Parameters)

`name` — 변경할 캡처 권한 정책의 이름(선택적으로 스키마 한정).

`expression` — 최대 4000자를 포함하는 불리언 표현식.

`role_names` — 권한을 분석할 역할들.

`run_name` — 캡처 실행(run)의 이름.

## 예제 (Examples)

이 명령은 캡처 권한 정책의 속성을 변경합니다:

```sql
## Enable and disable policy on the database
ALTER CAPTURE PRIVILEGES POLICY sampledb_p1 ENABLE sampledb_run1;
ALTER CAPTURE PRIVILEGES POLICY sampledb_p1 DISABLE;

## Enable and disable policy on the role
ALTER CAPTURE PRIVILEGES POLICY sampledb_p2 ENABLE sampledb_role_run1;
ALTER CAPTURE PRIVILEGES POLICY sampledb_p2 DISABLE sampledb_role_run1;
```
