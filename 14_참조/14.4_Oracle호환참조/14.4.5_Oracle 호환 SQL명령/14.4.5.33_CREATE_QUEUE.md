# CREATE QUEUE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › CREATE QUEUE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/30_create_queue/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 `CREATE QUEUE SQL` 명령을 통해 Oracle이 제공하지 않는 추가 구문을 포함합니다. 이 구문은 `DBMS_AQADM`과 함께 사용할 수 있습니다.

## 이름 (Name)

`CREATE QUEUE` — 큐(queue)를 생성합니다.

## 구문 개요 (Synopsis)

새 큐를 정의하려면 `CREATE QUEUE`를 사용합니다:

```sql
CREATE QUEUE <name> QUEUE TABLE <queue_table_name> [ ( { <option_name option_value>} [, ... ] ) ]
```

`option_name`과 해당하는 `option_value`의 가능한 값은 다음과 같습니다:

```sql
TYPE [normal_queue | exception_queue]
RETRIES [INTEGER]
RETRYDELAY [DOUBLE PRECISION]
RETENTION [DOUBLE PRECISION]
```

## 설명 (Description)

`CREATE QUEUE` 명령을 사용하면 데이터베이스 슈퍼유저 또는 시스템 정의 `aq_administrator_role` 권한을 가진 사용자가 현재 데이터베이스에 큐를 생성할 수 있습니다.

큐 이름이 스키마로 한정된 경우, 큐는 지정된 스키마에 생성됩니다. `CREATE QUEUE` 명령에 스키마가 포함되지 않은 경우, 큐는 현재 스키마에 생성됩니다. 큐는 큐 테이블이 상주하는 스키마에만 생성할 수 있습니다. 큐 이름은 동일한 스키마 내의 큐 중에서 고유해야 합니다.

큐를 제거하려면 `DROP QUEUE`를 사용합니다.

## 파라미터 (Parameters)

`name`

생성할 큐의 이름(선택적으로 스키마로 한정 가능)입니다.

`queue_table_name`

이 큐가 연결되는 큐 테이블의 이름입니다.

`option_name option_value`

새 큐와 연결할 옵션의 이름과 해당 옵션의 값입니다. `CREATE QUEUE` 호출에 중복된 옵션 이름이 포함되면, 서버는 오류를 반환합니다. 다음 값들이 수락됩니다:

- `TYPE` — 큐가 일반 큐임을 나타내려면 `normal_queue`를, 예외 큐(exception queue)를 나타내려면 `exception_queue`를 지정합니다. 예외 큐는 디큐(dequeue) 작업만 수락합니다.
- `RETRIES` — 큐에서 메시지를 제거하려는 최대 시도 횟수를 지정하는 정수 값입니다.
- `RETRYDELAY` — 롤백 후 서버가 메시지를 재시도하기 전에 대기하는 시간(초)을 지정하는 배정밀도(double-precision) 값입니다.
- `RETENTION` — 디큐 후 큐 테이블에 메시지를 저장할 시간(초)을 지정하는 배정밀도 값입니다.

## 예제 (Examples)

이 명령은 `work_order_table`이라는 이름의 큐 테이블과 연결된 `work_order`라는 이름의 큐를 생성합니다:

```sql
CREATE QUEUE work_order QUEUE TABLE work_order_table (RETRIES 5, RETRYDELAY 2);
```

서버는 큐에서 메시지를 제거하는 것을 5회 시도하도록 허용하고, 시도 간에 2초의 재시도 지연을 적용합니다.
