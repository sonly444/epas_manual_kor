# COMMIT — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › COMMIT](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/19_commit/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`COMMIT` — 현재 트랜잭션을 커밋합니다.

## 구문 개요 (Synopsis)

```sql
COMMIT [ WORK ]
```

## 설명 (Description)

`COMMIT`은 현재 트랜잭션을 커밋합니다. 트랜잭션에 의해 이루어진 모든 변경 사항은 다른 사용자에게 보이게 되며, 크래시가 발생하더라도 지속성(durable)이 보장됩니다.

## 파라미터 (Parameters)

`WORK`

아무런 효과가 없는 선택적 키워드.

## 참고 (Notes)

트랜잭션을 중단하려면 `ROLLBACK`을 사용합니다. 트랜잭션 내부가 아닐 때 `COMMIT`을 실행해도 아무런 문제가 없습니다.

##### 참고 (Note)

런타임 스택에 Oracle 스타일의 SPL 프로시저가 있는 경우, plpgsql 프로시저에서 `COMMIT`을 실행하면 오류가 발생합니다.

## 예제 (Examples)

현재 트랜잭션을 커밋하고 모든 변경 사항을 영구적으로 만들려면:

```sql
COMMIT;
```

## 관련 항목 (See also)

ROLLBACK, ROLLBACK TO SAVEPOINT
