# DROP USER — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP USER](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/61_drop_user/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`DROP USER` — 데이터베이스 사용자 계정을 제거합니다.

## 구문 개요 (Synopsis)

```sql
DROP USER <name> [ CASCADE ]
```

## 설명 (Description)

`DROP USER`는 지정된 사용자를 제거합니다. 슈퍼유저를 삭제하려면 슈퍼유저여야 합니다. 슈퍼유저가 아닌 사용자를 삭제하려면 `CREATEROLE` 권한이 필요합니다.

클러스터의 어떤 데이터베이스라도 해당 사용자를 참조하고 있다면 그 사용자를 제거할 수 없습니다. 사용자를 삭제하기 전에, 해당 사용자가 소유한 모든 객체를 삭제하거나 소유권을 다른 곳으로 이관해야 하며, 그 사용자에게 부여된 모든 권한을 회수해야 합니다.

그러나 해당 사용자와 관련된 롤 멤버십은 제거할 필요가 없습니다. `DROP USER`는 대상 사용자가 다른 롤에 대해 가진 멤버십과, 다른 롤이 대상 사용자에 대해 가진 멤버십을 모두 회수합니다. 그 다른 롤들은 삭제되지 않으며 그 밖의 영향도 받지 않습니다.

또는, 사용자가 소유한 유일한 객체들이 그 사용자가 소유하고 사용자와 같은 이름을 가진 스키마에 속해 있다면, `CASCADE` 옵션을 지정할 수 있습니다. 이 경우 `DROP USER name CASCADE` 명령을 실행하는 사람은 반드시 슈퍼유저여야 합니다. 지정된 사용자, 스키마, 그리고 그 스키마에 속한 모든 객체가 삭제됩니다.

## 파라미터 (Parameters)

`name`

제거할 사용자의 이름입니다.

`CASCADE`

지정하면, 사용자나 스키마에 대한 다른 의존성이 없는 한, 사용자가 소유하고 사용자와 같은 이름을 가진 스키마를 삭제합니다. 또한 그 스키마에 속하며 사용자가 소유한 모든 객체도 함께 삭제합니다.

## 예제 (Examples)

객체를 소유하지 않고 다른 객체에 대한 권한도 없는 `john`이라는 이름의 사용자 계정을 삭제합니다.

```sql
DROP USER john;
```

어떤 객체에 대한 권한도 없는 `john` 사용자 계정을 삭제합니다. 이 계정은 또한 `john` 사용자가 소유한 `john`이라는 이름의 스키마 외부에 어떤 객체도 소유하지 않습니다.

```sql
DROP USER john CASCADE;
```
