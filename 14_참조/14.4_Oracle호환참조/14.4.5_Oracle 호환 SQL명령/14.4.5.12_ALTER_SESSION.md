# ALTER SESSION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER SESSION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/11_alter_session/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`ALTER SESSION` — 런타임 파라미터를 변경합니다.

## 구문 개요 (Synopsis)

```sql
ALTER SESSION SET <name> = <value>
```

## 설명 (Description)

`ALTER SESSION` 명령은 런타임 구성 파라미터를 변경합니다. `ALTER SESSION`은 현재 세션에서 사용되는 값에만 영향을 줍니다. 이러한 파라미터 중 일부는 오로지 Oracle 구문과의 호환성을 위해 제공되며 EDB Postgres Advanced Server의 런타임 동작에는 아무런 영향을 주지 않습니다. 다른 일부는 이에 대응하는 EDB Postgres Advanced Server 데이터베이스 서버의 런타임 구성 파라미터를 변경합니다.

## 파라미터 (Parameters)

`name`

설정 가능한 런타임 파라미터의 이름.

`value`

파라미터의 새 값.

## 구성 파라미터 (Configuration parameters)

`ALTER SESSION` 명령을 사용하여 다음 구성 파라미터를 수정할 수 있습니다:

- `NLS_DATE_FORMAT (string)`

날짜 및 시간 값의 표시 형식과, 모호한 날짜 입력 값을 해석하는 규칙을 설정합니다. EDB Postgres Advanced Server의 `datestyle` 런타임 구성 파라미터를 설정하는 것과 동일한 효과를 가집니다.

- `NLS_LANGUAGE (string)`

메시지 표시 언어를 설정합니다. EDB Postgres Advanced Server의 `lc_messages` 런타임 구성 파라미터를 설정하는 것과 동일한 효과를 가집니다.

- `NLS_LENGTH_SEMANTICS (string)`

유효한 값은 `BYTE`와 `CHAR`입니다. 기본값은 `BYTE`입니다. 이 파라미터는 오로지 구문 호환성을 위해 제공되며 EDB Postgres Advanced Server에서는 아무런 효과가 없습니다.

- `OPTIMIZER_MODE (string)`

쿼리에 대한 기본 최적화 모드를 설정합니다. 유효한 값은 `ALL_ROWS`, `CHOOSE`, `FIRST_ROWS`, `FIRST_ROWS_10`, `FIRST_ROWS_100`, `FIRST_ROWS_1000`입니다. 기본값은 `CHOOSE`입니다. 이 파라미터는 EDB Postgres Advanced Server에서 구현되어 있습니다.

- `QUERY_REWRITE_ENABLED (string)`

유효한 값은 `TRUE`, `FALSE`, `FORCE`입니다. 기본값은 `FALSE`입니다. 이 파라미터는 오로지 구문 호환성을 위해 제공되며 EDB Postgres Advanced Server에서는 아무런 효과가 없습니다.

- `QUERY_REWRITE_INTEGRITY (string)`

유효한 값은 `ENFORCED`, `TRUSTED`, `STALE_TOLERATED`입니다. 기본값은 `ENFORCED`입니다. 이 파라미터는 오로지 구문 호환성을 위해 제공되며 EDB Postgres Advanced Server에서는 아무런 효과가 없습니다.

## 예제 (Examples)

언어를 UTF-8 인코딩의 미국 영어로 설정합니다. 이 예제에서 값 `en_US.UTF-8`은 EDB Postgres Advanced Server 형식입니다. 이 형식은 Oracle 데이터베이스와 호환되지 않습니다.

```sql
ALTER SESSION SET NLS_LANGUAGE = 'en_US.UTF-8';
```

날짜 표시 형식을 설정합니다:

```sql
ALTER SESSION SET NLS_DATE_FORMAT = 'dd/mm/yyyy';
```

##### 참고 (Note)

EDB Postgres Advanced Server의 ALTER SESSION 명령은 PostgreSQL SET 명령을 감싼 래퍼입니다. [PostgreSQL 문서](https://www.postgresql.org/docs/current/sql-set.html)에 따르면, SET이 나중에 롤백되는 트랜잭션 내에서 실행되면 구성 변경 사항은 유지되지 않습니다. 이 동작은 ALTER SESSION에도 동일하게 적용됩니다.

이 동작은 PostgreSQL 서버에 의해 제어되며 EPAS의 Oracle 호환 기능에 특정된 것이 아닙니다.
