# DROP SEQUENCE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP SEQUENCE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/56_drop_sequence/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`DROP SEQUENCE` — 시퀀스를 제거합니다.

## 구문 개요 (Synopsis)

```sql
DROP SEQUENCE <name> [, ...]
```

## 설명 (Description)

`DROP SEQUENCE`는 시퀀스 번호 생성기를 제거합니다. 이 명령을 실행하려면 슈퍼유저이거나 해당 시퀀스의 소유자여야 합니다.

## 파라미터 (Parameters)

`name`

시퀀스의 이름입니다(선택적으로 스키마로 한정할 수 있습니다).

## 예제 (Examples)

시퀀스 `serial`을 제거합니다.

```sql
DROP SEQUENCE serial;
```
