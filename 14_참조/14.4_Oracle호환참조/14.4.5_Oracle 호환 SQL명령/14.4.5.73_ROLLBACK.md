# ROLLBACKv18

## 이름 (Name)

`ROLLBACK` — 현재 트랜잭션을 중단합니다.

## 구문 개요 (Synopsis)

```sql
ROLLBACK [ WORK ]
```

## 설명 (Description)

`ROLLBACK`은 현재 트랜잭션을 롤백하고 해당 트랜잭션에서 수행한 모든 갱신을 폐기합니다.

## 파라미터 (Parameters)

`WORK`

아무 효과가 없는 선택적 키워드입니다.

## 참고 (Notes)

트랜잭션을 성공적으로 종료하려면 `COMMIT`을 사용하세요.

트랜잭션 내부에 있지 않을 때 `ROLLBACK`을 실행해도 아무런 문제가 없습니다.

##### 참고 (Note)

런타임 스택에 Oracle 스타일의 SPL 프로시저가 있는 경우, plpgsql 프로시저에서 `ROLLBACK`을 실행하면 오류가 발생합니다.

## 예제 (Examples)

모든 변경 사항을 중단합니다:

```sql
ROLLBACK;
```
