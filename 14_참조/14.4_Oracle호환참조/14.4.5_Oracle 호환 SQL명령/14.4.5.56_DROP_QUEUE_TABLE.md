# DROP QUEUE TABLE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP QUEUE TABLE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/53_drop_queue_table/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server에는 `DROP QUEUE TABLE SQL` 명령을 통해 Oracle이 제공하지 않는 구문이 포함되어 있습니다. 이 구문은 `DBMS_AQADM`과 함께 사용할 수 있습니다.

## 이름 (Name)

`DROP QUEUE TABLE` — 큐 테이블(queue table)을 삭제합니다.

## 구문 개요 (Synopsis)

큐 테이블을 삭제하려면 `DROP QUEUE TABLE`을 사용합니다.

```sql
DROP QUEUE TABLE [ IF EXISTS ] <name> [, ...]
[CASCADE | RESTRICT]
```

## 설명 (Description)

`DROP QUEUE TABLE`은 슈퍼유저 또는 `aq_administrator_role` 권한을 가진 사용자가 큐 테이블을 삭제할 수 있도록 합니다.

## 파라미터 (Parameters)

`name`

삭제할 큐 테이블의 이름(스키마로 한정할 수도 있음)입니다.

`IF EXISTS`

큐 테이블이 존재하지 않을 때 오류를 반환하지 않으려면 `IF EXISTS` 절을 포함합니다. 오류 대신 알림(notice)을 발행합니다.

`CASCADE`

큐 테이블에 의존하는 객체를 함께 삭제하려면 `CASCADE` 키워드를 포함합니다.

`RESTRICT`

큐 테이블에 의존하는 객체가 있으면 큐 테이블 삭제를 막으려면 `RESTRICT` 키워드를 포함합니다. 이것이 기본값입니다.

## 예제 (Examples)

이 예제는 `work_order_table`이라는 이름의 큐 테이블과 그것에 의존하는 모든 객체를 삭제합니다.

```sql
DROP QUEUE TABLE work_order_table CASCADE;
```
