# DROP TYPE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP TYPE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/60_drop_type/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`DROP TYPE` — 타입 정의를 제거합니다.

## 구문 개요 (Synopsis)

```sql
DROP TYPE [ BODY ] <name>
```

## 설명 (Description)

`DROP TYPE`은 타입 정의를 제거합니다. 이 명령을 실행하려면 슈퍼유저이거나 해당 타입의 소유자여야 합니다.

선택적인 `BODY` 한정어는 오브젝트 타입 정의에만 적용되며, 컬렉션 타입이나 복합 타입에는 적용되지 않습니다. `BODY`를 지정하면 오브젝트 타입 본문(body)만 제거되고 오브젝트 타입 명세(specification)는 제거되지 않습니다. `BODY`를 생략하면 오브젝트 타입 명세와 본문이 모두 제거됩니다.

다른 데이터베이스 객체가 지정된 타입에 의존하고 있으면 그 타입은 삭제되지 않습니다.

## 파라미터 (Parameters)

`name`

제거할 타입 정의의 이름입니다.

## 예제 (Examples)

`addr_obj_typ`라는 이름의 오브젝트 타입을 삭제합니다.

```sql
DROP TYPE addr_obj_typ;
```

`budget_tbl_typ`라는 이름의 중첩 테이블 타입(nested table type)을 삭제합니다.

```sql
DROP TYPE budget_tbl_typ;
```
