# CREATE VIEW — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › CREATE VIEW](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/43_create_view/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`CREATE VIEW` — 새 뷰를 정의합니다.

## 구문 개요 (Synopsis)

```sql
CREATE [ OR REPLACE ] VIEW <name> [ ( <column_name> [, ...] ) ]
  AS <query>
```

## 설명 (Description)

`CREATE VIEW`는 쿼리에 대한 뷰를 정의합니다. 뷰는 물리적으로 구체화(materialize)되지 않습니다. 대신, 뷰를 참조하는 쿼리가 실행될 때마다 해당 쿼리가 실행됩니다.

`CREATE OR REPLACE VIEW`도 비슷합니다. 다만, 같은 이름의 뷰가 이미 존재하면 이 명령이 해당 뷰를 대체합니다.

스키마 이름을 지정하면 지정한 스키마에 뷰가 생성됩니다. 그렇지 않으면 현재 스키마에 생성됩니다. 뷰 이름은 같은 스키마 내의 다른 뷰, 테이블, 시퀀스, 인덱스의 이름과 달라야 합니다.

## 파라미터 (Parameters)

`name`

생성할 뷰의 이름(선택적으로 스키마로 한정할 수 있음)입니다.

`column_name`

뷰의 컬럼에 사용할 이름의 선택적 목록입니다. 지정하지 않으면 컬럼 이름은 쿼리로부터 추론됩니다.

`query`

뷰의 컬럼과 행을 제공하는 쿼리(즉, `SELECT` 문)입니다. 유효한 쿼리에 대한 정보는 [`SELECT`](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/71_select/)를 참조하세요.

##### 참고 (Note)

현재 뷰는 읽기 전용입니다. 시스템은 뷰에 대한 insert, update, delete를 허용하지 않습니다. 뷰에 대한 insert 및 기타 명령을 다른 테이블에 대한 적절한 동작으로 다시 쓰는 규칙(rule)을 생성하면 갱신 가능한 뷰의 효과를 얻을 수 있습니다.

뷰에서 참조하는 테이블에 대한 접근은 뷰 소유자의 권한으로 결정됩니다. 그러나 뷰에서 호출되는 함수는 뷰를 사용하는 쿼리에서 직접 호출되는 것과 동일하게 취급됩니다. 따라서 뷰의 사용자는 뷰가 사용하는 모든 함수를 호출할 권한을 가지고 있어야 합니다.

## 예제 (Examples)

부서 30에 속한 모든 직원으로 구성된 뷰를 생성합니다.

```sql
CREATE VIEW dept_30 AS SELECT * FROM emp WHERE deptno = 30;
```
