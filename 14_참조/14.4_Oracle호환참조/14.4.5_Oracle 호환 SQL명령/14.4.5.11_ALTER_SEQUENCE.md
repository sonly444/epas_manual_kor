# ALTER SEQUENCE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER SEQUENCE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/10_alter_sequence/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`ALTER SEQUENCE` — 시퀀스 생성기(sequence generator)의 정의를 변경합니다.

## 구문 개요 (Synopsis)

```sql
ALTER SEQUENCE <name> [ INCREMENT BY <increment> ]
  [ MINVALUE <minvalue> ] [ MAXVALUE <maxvalue> ]
  [ CACHE <cache> | NOCACHE ] [ CYCLE ]
```

## 설명 (Description)

`ALTER SEQUENCE`는 기존 시퀀스 생성기의 파라미터를 변경합니다. `ALTER SEQUENCE` 명령에서 명시적으로 설정하지 않은 파라미터는 이전 설정을 그대로 유지합니다.

## 파라미터 (Parameters)

`name`

변경할 시퀀스의 이름(선택적으로 스키마로 한정 가능).

`increment`

`INCREMENT BY increment` 절은 선택 사항입니다. 양수 값은 오름차순 시퀀스를, 음수 값은 내림차순 시퀀스를 만듭니다. 지정하지 않으면 기존 증가값이 유지됩니다.

`minvalue`

선택적 절 `MINVALUE minvalue`는 시퀀스가 생성할 수 있는 최솟값을 결정합니다. 지정하지 않으면 현재 최솟값이 유지됩니다. `NO MINVALUE` 키워드를 사용하면 이 동작을 각각 오름차순 및 내림차순 시퀀스에 대한 기본값인 1과 -263-1로 되돌릴 수 있습니다. 다만 이 표현은 Oracle 데이터베이스와 호환되지 않습니다.

`maxvalue`

선택적 절 `MAXVALUE maxvalue`는 시퀀스의 최댓값을 결정합니다. 지정하지 않으면 현재 최댓값이 유지됩니다. `NO MAXVALUE` 키워드를 사용하면 이 동작을 각각 오름차순 및 내림차순 시퀀스에 대한 기본값인 263-1과 -1로 되돌릴 수 있습니다. 다만 이 표현은 Oracle 데이터베이스와 호환되지 않습니다.

`cache`

선택적 절 `CACHE cache`는 더 빠른 접근을 위해 미리 할당하여 메모리에 저장할 시퀀스 번호의 개수를 지정합니다. 최솟값은 `1`입니다. 한 번에 하나의 값만 생성하게 하려면, 즉 `NOCACHE`로 설정할 수 있습니다. 지정하지 않으면 기존 캐시 값이 유지됩니다.

`CYCLE`

`CYCLE` 옵션은 오름차순 시퀀스가 `maxvalue`에 도달하거나 내림차순 시퀀스가 `minvalue`에 도달했을 때 시퀀스가 순환(wrap around)하도록 합니다. 한계에 도달하면 다음에 생성되는 번호는 `minvalue` 또는 `maxvalue`가 됩니다. 지정하지 않으면 기존 순환 동작이 유지됩니다. `NO CYCLE` 키워드를 사용하면 시퀀스가 재순환하지 않도록 변경할 수 있습니다. 다만 이 표현은 Oracle 데이터베이스와 호환되지 않습니다.

## 참고 (Notes)

동일한 시퀀스에서 번호를 얻는 동시 트랜잭션을 차단하지 않도록, `ALTER SEQUENCE`는 절대 롤백되지 않습니다. 변경 사항은 즉시 적용되며 되돌릴 수 없습니다.

파라미터를 변경하는 `ALTER SEQUENCE`(`INCREMENT BY`, `MINVALUE`/`MAXVALUE`, `CACHE`, `CYCLE`)는 다른 백엔드가 미리 할당(캐시)했지만 아직 발급하지 않은 시퀀스 값을 모두 폐기하게 만듭니다. 다음 `NEXTVAL` 호출 시 해당 백엔드는 변경을 감지하고 새 파라미터에 따라 새로운 값 묶음을 가져오며, 기존 캐시에서 먼저 발급을 계속하지 않습니다. 현재 백엔드는 즉시 영향을 받습니다.

## 예제 (Examples)

시퀀스 `serial`의 증가값과 캐시 값을 변경합니다:

```sql
ALTER SEQUENCE serial INCREMENT BY 2 CACHE 5;
```
