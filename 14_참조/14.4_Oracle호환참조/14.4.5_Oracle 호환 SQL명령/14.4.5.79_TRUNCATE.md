# TRUNCATEv18

## 이름 (Name)

`TRUNCATE` — 테이블을 비웁니다.

## 구문 개요 (Synopsis)

```sql
TRUNCATE TABLE <name> [DROP STORAGE]
```

## 설명 (Description)

`TRUNCATE`는 테이블에서 모든 행을 제거합니다. 이는 한정되지 않은(unqualified) `DELETE`와 동일한 효과를 가집니다. 그러나 테이블을 스캔하지 않으므로 더 빠릅니다. `TRUNCATE`는 큰 테이블에서 가장 유용합니다.

`DROP STORAGE` 절은 호환성을 위해 허용되지만 무시됩니다.

## 파라미터 (Parameters)

`name`

잘라낼(truncate) 테이블의 이름(선택적으로 스키마로 한정 가능)입니다.

## 참고 (Notes)

다른 테이블에서 해당 테이블로의 외래 키(foreign-key) 참조가 있는 경우 `TRUNCATE`를 사용할 수 없습니다. 이러한 경우 유효성을 검사하려면 테이블 스캔이 필요한데, `TRUNCATE`는 이를 피하는 것을 목표로 합니다.

`TRUNCATE`는 테이블에 대한 어떤 사용자 정의 `ON DELETE` 트리거도 실행하지 않습니다.

## 예제 (Examples)

이 명령은 `accounts`라는 테이블을 잘라냅니다:

```sql
TRUNCATE TABLE accounts;
```
