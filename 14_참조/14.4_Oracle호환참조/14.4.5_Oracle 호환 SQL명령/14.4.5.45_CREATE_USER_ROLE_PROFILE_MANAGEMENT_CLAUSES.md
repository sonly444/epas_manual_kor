# CREATE USER|ROLE… PROFILE MANAGEMENT CLAUSES v18

## 이름 (Name)

`CREATE USER|ROLE` — 사용자 또는 롤을 생성합니다.

## 구문 개요 (Synopsis)

```sql
CREATE USER|ROLE <name> [[WITH] option […]]
```

여기서 `option`은 다음의 호환 가능한 절 중 하나입니다.

```sql
   PROFILE <profile_name>
|  ACCOUNT {LOCK|UNLOCK}
|  PASSWORD EXPIRE [AT '<timestamp>']
|  [ NO ] CREATE [ PUBLIC ] DATABASE LINK
|  [ NO ] ALTER [ PUBLIC ] DATABASE LINK
|  [ NO ] DROP PUBLIC DATABASE LINK
|  [ NO ] EXEMPT ACCESS POLICY
```

EDB Postgres Advanced Server가 지원하는 `CREATE USER` 또는 `CREATE ROLE` 명령의 관리 절(administrative clause)에 대한 정보는 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/sql-commands.html)를 참조하세요.

## 설명 (Description)

`CREATE ROLE|USER… PROFILE`은 연관된 프로파일(profile)을 가진 롤을 EDB Postgres Advanced Server 데이터베이스 클러스터에 추가합니다.

기본적으로 `CREATE USER` 명령으로 생성된 롤은 로그인 롤이며, `CREATE ROLE` 명령으로 생성된 롤은 로그인 롤이 아닙니다. `CREATE ROLE` 명령으로 로그인 계정을 생성하려면 `LOGIN` 키워드를 포함해야 합니다.

데이터베이스 슈퍼유저만 프로파일 관리를 강제하는 `CREATE USER|ROLE` 절을 사용할 수 있습니다. 이 절들은 다음과 같은 동작을 강제합니다.

- 미리 정의된 프로파일을 롤과 연관시키거나 사용자와 연관된 미리 정의된 프로파일을 변경하려면 `PROFILE` 절과 `profile_name`을 포함합니다.

- 사용자 계정을 잠금 또는 잠금 해제 상태로 두려면 `ACCOUNT` 절과 `LOCK` 또는 `UNLOCK` 키워드를 포함합니다.

- 롤과 연관된 비밀번호가 만료되는 날짜와 시간을 지정하려면 선택적 `AT 'timestamp'` 키워드와 함께 `PASSWORD EXPIRE` 절을 포함합니다. `AT 'timestamp'` 키워드를 생략하면 비밀번호가 즉시 만료됩니다.

- 원격 데이터베이스로의 연결을 허용하는 프라이빗 또는 퍼블릭 데이터베이스 링크를 생성하는 권한을 부여하거나 취소하려면 선택적 `PUBLIC` 키워드와 함께 `[NO] CREATE DATABASE LINK` 절을 포함합니다.

- 프라이빗 또는 퍼블릭 데이터베이스 링크를 변경하는 권한을 부여하거나 취소하려면 선택적 `PUBLIC` 키워드와 함께 `[NO] ALTER DATABASE LINK` 절을 포함합니다.

- 퍼블릭 데이터베이스 링크를 삭제하는 권한을 부여하거나 취소하려면 `[NO] DROP PUBLIC DATABASE LINK` 절을 포함합니다.

- 접근 정책(access policy)을 면제하는 권한을 부여하거나 취소하려면 `[NO] EXEMPT ACCESS POLICY` 절을 포함합니다.


각 로그인 롤은 하나의 프로파일만 가질 수 있습니다. 로그인 롤과 현재 연관된 프로파일을 찾으려면 `DBA_USERS` 뷰의 `profile` 컬럼을 쿼리합니다.

롤 또는 사용자가 createdblink, createpublicdblink, alterdblink, alterpublicdblink, droppublicdblink, exemptaccesspolicy 권한을 가지고 있는지 확인하려면 [redwood 전용 함수](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/redwood_specific_privs_functions/)를 쿼리합니다.

## 파라미터 (Parameters)

`name`

롤의 이름입니다.

`profile_name`

롤과 연관된 프로파일의 이름입니다.

`timestamp`

절이 강제되는 날짜와 시간입니다. `timestamp`의 값을 지정할 때는 값을 작은따옴표로 묶습니다.

## 예제 (Examples)

이 예제는 `CREATE USER`를 사용하여 `acctg_profile` 프로파일과 연관된 `john`이라는 로그인 롤을 생성합니다.

```sql
CREATE USER john PROFILE acctg_profile IDENTIFIED BY “1safepwd”;
```

`john`은 비밀번호 `1safepwd`를 사용하여 서버에 로그인할 수 있습니다.

이 예제는 `CREATE ROLE`을 사용하여 `acctg_profile` 프로파일과 연관된 `john`이라는 로그인 롤을 생성합니다.

```sql
CREATE ROLE john PROFILE acctg_profile LOGIN PASSWORD “1safepwd”;
```

`john`은 비밀번호 `1safepwd`를 사용하여 서버에 로그인할 수 있습니다.
