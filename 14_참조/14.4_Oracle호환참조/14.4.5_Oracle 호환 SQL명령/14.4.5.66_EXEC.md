# EXEC — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › EXEC](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/63_exec/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`EXEC` — 함수를 실행합니다.

## 구문 개요 (Synopsis)

```sql
EXEC function_name ['('[<argument_list>]')']
```

## 설명 (Description)

`EXECUTE`

## 파라미터 (Parameters)

`procedure_name`

함수 이름입니다(선택적으로 스키마로 한정할 수 있습니다).

`argument_list`

함수가 요구하는 인수를 쉼표로 구분한 목록입니다. `argument_list`의 각 멤버는 함수가 기대하는 형식 인수(formal argument)에 대응합니다. 각 형식 인수는 `IN` 파라미터, `OUT` 파라미터, 또는 `INOUT` 파라미터일 수 있습니다.

## 예제 (Examples)

`EXEC` 문은 함수가 요구하는 인수에 따라 여러 형태 중 하나를 취할 수 있습니다.

```sql
EXEC update_balance;
EXEC update_balance();
EXEC update_balance(1,2,3);
```
