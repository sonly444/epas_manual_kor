# CREATE PACKAGE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › CREATE PACKAGE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/26_create_package/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`CREATE PACKAGE` — 새로운 패키지 사양(package specification)을 정의합니다.

## 구문 개요 (Synopsis)

```sql
CREATE [ OR REPLACE ] PACKAGE <name>
[ AUTHID { DEFINER | CURRENT_USER } ]
{ IS | AS }
  [ <declaration>; ] [, ...]
  [ { PROCEDURE <proc_name>
      [ (<argname> [ IN | IN OUT | OUT ] <argtype> [ DEFAULT <value> ]
        [, ...]) ];
      [ PRAGMA RESTRICT_REFERENCES(<name>,
        { RNDS | RNPS | TRUST | WNDS | WNPS } [, ... ] ); ]
    |
      FUNCTION <func_name>
      [ (<argname> [ IN | IN OUT | OUT ] <argtype> [ DEFAULT <value> ]
        [, ...]) ]
      RETURN <rettype> [ DETERMINISTIC ];
      [ PRAGMA RESTRICT_REFERENCES(<name>,
        { RNDS | RNPS | TRUST | WNDS | WNPS } [, ... ] ); ]
    }
  ] [, ...]
  END [ <name> ]
```

## 설명 (Description)

`CREATE PACKAGE`는 새로운 패키지 사양을 정의합니다. `CREATE OR REPLACE PACKAGE`는 새 패키지 사양을 생성하거나 기존 사양을 대체합니다.

스키마 이름을 포함하면 패키지는 지정된 스키마에 생성됩니다. 그렇지 않으면 현재 스키마에 생성됩니다. 새 패키지의 이름은 기존 패키지의 정의를 업데이트하려는 경우가 아니라면 동일한 스키마 내의 기존 패키지와 일치할 수 없습니다. 그런 경우에는 `CREATE OR REPLACE PACKAGE`를 사용합니다.

프로시저를 생성하는 사용자가 패키지의 소유자가 됩니다.

## 파라미터 (Parameters)

`name`

생성할 패키지의 이름(선택적으로 스키마로 한정 가능)입니다.

`DEFINER | CURRENT_USER`

패키지에서 참조하는 데이터베이스 객체에 대한 접근이 허용되는지 결정하는 데 패키지 소유자의 권한(`DEFINER`)을 사용할지 또는 패키지 내의 프로그램을 실행하는 현재 사용자의 권한(`CURRENT_USER`)을 사용할지 지정합니다. `DEFINER`가 기본값입니다.

`declaration`

공개(public) 변수, 타입, 커서 또는 `REF CURSOR` 선언입니다.

`proc_name`

공개 프로시저의 이름입니다.

`argname`

인수의 이름입니다.

`IN | IN OUT | OUT`

인수 모드입니다.

`argtype`

프로그램 인수의 데이터 타입입니다.

`DEFAULT value`

입력 인수의 기본값입니다.

`func_name`

공개 함수의 이름입니다.

`rettype`

반환 데이터 타입입니다.

`DETERMINISTIC`

`DETERMINISTIC`은 `IMMUTABLE`의 동의어입니다. `DETERMINISTIC` 프로시저는 데이터베이스를 수정할 수 없으며 동일한 인수 값이 주어졌을 때 항상 동일한 결과에 도달합니다. 데이터베이스 조회를 수행하지 않으며 인수 목록에 직접 존재하는 정보만 사용합니다. 이 절을 포함하면, 모두 상수 인수로 이루어진 프로시저 호출을 프로시저 값으로 즉시 대체할 수 있습니다.

`RNDS | RNPS | TRUST | WNDS | WNPS`

이 키워드들은 호환성을 위해 수락되며 무시됩니다.

## 예제 (Examples)

패키지 사양 `empinfo`는 세 개의 공개 구성 요소를 포함합니다: 공개 변수, 공개 프로시저, 공개 함수:

```sql
CREATE OR REPLACE PACKAGE empinfo
IS
    emp_name        VARCHAR2(10);
    PROCEDURE get_name (
        p_empno     NUMBER
    );
    FUNCTION display_counter
    RETURN INTEGER;
END;
```
