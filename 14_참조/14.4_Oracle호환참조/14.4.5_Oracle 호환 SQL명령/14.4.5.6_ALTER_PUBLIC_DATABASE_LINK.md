# ALTER PUBLIC DATABASE LINK — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER PUBLIC DATABASE LINK](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/05a_alter_public_database_link/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`ALTER [PUBLIC] DATABASE LINK` — 기존 데이터베이스 링크를 변경합니다.

## 구문 개요 (Synopsis)

```sql
ALTER DATABASE LINK <name>
  OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }

ALTER [ PUBLIC ] DATABASE LINK [ IF EXISTS ] <name> CONNECT TO <new_user> IDENTIFIED BY <new_password> [ USING [connector_name] <connection_string> ];
```

## 설명 (Description)

`ALTER [PUBLIC] DATABASE LINK` 명령을 사용하여 데이터베이스 링크에 연관된 사용자 매핑과 외부 서버 옵션을 수정합니다. EDB Postgres Advanced Server는 두 가지 형태의 명령을 지원합니다:

- 데이터베이스 링크의 소유권을 변경하려면 `ALTER DATABASE LINK.. TO`를 사용합니다.
- 데이터베이스 링크가 원격 데이터베이스에 연결하는 데 사용하는 자격 증명을 수정하려면 `ALTER [PUBLIC] DATABASE LINK.. CONNECT TO`를 사용합니다.

데이터베이스 링크를 변경하려면 사용자에게 적절한 권한이 필요합니다:

- 비공개(private) 데이터베이스 링크를 변경하려면 `ALTER DATABASE LINK` 권한이 필요합니다.
- 공개(public) 데이터베이스 링크를 변경하려면 `ALTER PUBLIC DATABASE LINK` 권한이 필요합니다.

## 파라미터 (Parameters)

`name` — 데이터베이스 링크의 이름.

`new_owner` — 새 소유자로 할당할 특정 사용자나 역할의 이름.

`CURRENT_ROLE` — 현재 활성 역할을 소유자로 할당.

`CURRENT_USER` — 현재 사용자(명령을 실행하는 사용자)를 소유자로 할당.

`SESSION_USER` — 현재 데이터베이스 세션을 시작한 사용자를 소유자로 할당.

`PUBLIC` — 선택적 파라미터. 생략하면 데이터베이스 링크는 비공개이며 링크 소유자만 사용할 수 있습니다. 공개이면 모든 사용자가 접근할 수 있습니다.

`IF EXISTS` — 지정된 데이터베이스 링크가 없을 때 오류를 방지하는 선택적 절. 명령은 실패하는 대신 아무것도 하지 않습니다.

`CONNECT TO <new_user> IDENTIFIED BY <new_password>` — 데이터베이스 링크가 원격 데이터베이스에 연결하는 데 사용하는 자격 증명을 변경합니다.

- `<new_user>` — 새 연결의 사용자 이름.
- `<new_password>` — 새 사용자의 비밀번호.

`[ USING [ connector_name ] <connection_string> ]` — 연결하는 원격 데이터베이스를 변경하는 선택적 절.

- `connector_name` — 데이터베이스 링크에 사용되는 커넥터의 선택적 이름.
- `<connection_string>` — 원격 데이터베이스의 위치와 포트를 지정하는 문자열.

## 예제 (Examples)

- 비공개 데이터베이스 링크의 소유권을 변경하는 방법:

```sql
ALTER DATABASE LINK sales_db_link
  OWNER TO user1;
```

- 공개 데이터베이스 링크의 원격 데이터베이스 연결 문자열을 변경하는 방법:

```sql
ALTER PUBLIC DATABASE LINK public_reporting_link
  USING 'new_reporting_link';
```
