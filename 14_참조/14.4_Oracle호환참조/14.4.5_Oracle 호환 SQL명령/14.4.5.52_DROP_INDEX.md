# DROP INDEX — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › DROP INDEX](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/48_drop_index/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`DROP INDEX` — 인덱스를 제거합니다.

## 구문 개요 (Synopsis)

```sql
DROP INDEX <name>
```

## 설명 (Description)

`DROP INDEX`는 데이터베이스 시스템에서 기존 인덱스를 삭제합니다. 이 명령을 실행하려면 슈퍼유저이거나 해당 인덱스의 소유자여야 합니다. 인덱스에 의존하는 객체가 있으면 오류가 발생하고 인덱스는 삭제되지 않습니다.

## 파라미터 (Parameters)

`name`

제거할 인덱스의 이름(선택적으로 스키마로 한정할 수 있음)입니다.

## 예제 (Examples)

이 예제는 인덱스 `name_idx`를 제거합니다.

```sql
DROP INDEX name_idx;
```
