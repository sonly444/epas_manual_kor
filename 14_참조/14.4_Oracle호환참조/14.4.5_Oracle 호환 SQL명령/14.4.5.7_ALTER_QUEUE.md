# ALTER QUEUE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER QUEUE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/06_alter_queue/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 `ALTER QUEUE` SQL 명령에 Oracle이 제공하지 않는 추가 구문을 포함합니다. 이 구문은 `DBMS_AQADM` 패키지와 함께 사용할 수 있습니다.

## 이름 (Name)

`ALTER QUEUE` — 슈퍼유저 또는 `aq_administrator_role` 권한을 가진 사용자가 큐의 속성을 수정할 수 있게 합니다.

## 구문 개요 (Synopsis)

이 명령은 네 가지 형태로 사용할 수 있습니다.

## 첫 번째 형태의 파라미터

첫 번째 형태는 큐 이름을 변경합니다:

```sql
ALTER QUEUE <queue_name> RENAME TO <new_name>
```

`queue_name` — 기존 큐의 이름(선택적으로 스키마 한정).

`RENAME TO` — 큐 이름을 변경하려면 `RENAME TO` 절과 큐의 새 이름을 포함합니다.

`new_name` — 큐의 새 이름.

## 두 번째 형태의 파라미터

두 번째 형태는 큐의 속성을 수정합니다:

```sql
ALTER QUEUE <queue_name> SET [ ( { <option_name option_value> ) } [,SET <option_name> ] ]
```

`queue_name` — 기존 큐의 이름(선택적으로 스키마 한정).

큐의 속성을 수정하려면 `SET` 절과 `option_name/option_value` 쌍을 포함합니다.

`option_name option_value` — 새 큐에 연관할 옵션의 이름과 해당 값. 중복 옵션 이름을 제공하면 서버가 오류를 반환합니다.

- `option_name`이 `retries`이면 디큐(dequeue) 시도 횟수를 나타내는 정수를 제공합니다.
- `option_name`이 `retrydelay`이면 지연 초를 나타내는 배정밀도 값을 제공합니다.
- `option_name`이 `retention`이면 보존 시간(초)을 나타내는 배정밀도 값을 제공합니다.

## 세 번째 형태의 파라미터

세 번째 형태는 큐의 인큐(enqueue) 또는 디큐를 활성화하거나 비활성화합니다:

```sql
ALTER QUEUE <queue_name> ACCESS { START | STOP } [ FOR { enqueue | dequeue } ] [ NOWAIT ]
```

`queue_name` — 기존 큐의 이름(선택적으로 스키마 한정).

`ACCESS` — 큐의 인큐/디큐를 활성화/비활성화하려면 `ACCESS` 키워드를 포함합니다.

`START | STOP` — 큐의 원하는 상태를 나타내려면 `START`와 `STOP` 키워드를 사용합니다.

`FOR enqueue|dequeue` — 지정된 큐의 인큐 또는 디큐 활동 상태를 지정하는지 나타내려면 `FOR` 절을 사용합니다.

`NOWAIT` — 큐 상태를 변경하기 전에 서버가 미완료 트랜잭션의 완료를 기다리지 않도록 지정하려면 `NOWAIT` 키워드를 포함합니다. `NOWAIT` 키워드는 `ACCESS` 값이 `STOP`일 때만 사용할 수 있습니다. `START`와 함께 `NOWAIT`를 지정하면 서버가 오류를 반환합니다.

## 네 번째 형태의 파라미터

네 번째 형태는 큐에 콜백 세부 정보를 `ADD`하거나 `DROP`합니다.

```sql
ALTER QUEUE <queue_name> { ADD | DROP } CALL TO <location_name> [ WITH <callback_option> ]
```

`queue_name` — 기존 큐의 이름(선택적으로 스키마 한정).

`ADD | DROP` — 큐의 콜백 세부 정보를 추가하거나 제거하려면 `ADD`나 `DROP` 키워드를 포함합니다.

`location_name` — 콜백 프로시저의 이름을 지정합니다.

`callback_option` — `context`일 수 있습니다. 이 절을 포함할 때 `RAW` 값을 지정합니다.

## 예제 (Examples)

이 예는 큐 이름을 `work_queue_east`에서 `work_order`로 변경합니다:

```sql
ALTER QUEUE work_queue_east RENAME TO work_order;
```

이 예는 `work_order` 큐를 수정합니다. 재시도 횟수를 100, 재시도 간 지연을 2초, 디큐된 메시지를 큐가 보존하는 시간을 10초로 설정합니다:

```sql
ALTER QUEUE work_order SET (retries 100, retrydelay 2, retention 10);
```

다음 명령들은 `work_order` 큐에서 인큐와 디큐를 활성화합니다:

```sql
ALTER QUEUE work_order ACCESS START;
ALTER QUEUE work_order ACCESS START FOR enqueue;
ALTER QUEUE work_order ACCESS START FOR dequeue;
```

다음 명령들은 `work_order` 큐에서 인큐와 디큐를 비활성화합니다:

```sql
ALTER QUEUE work_order ACCESS STOP NOWAIT;
ALTER QUEUE work_order ACCESS STOP FOR enqueue;
ALTER QUEUE work_order ACCESS STOP FOR dequeue;
```
