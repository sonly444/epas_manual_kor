## 이름 (Name)

`DROP DATABASE LINK` — 데이터베이스 링크를 제거합니다.

## 구문 개요 (Synopsis)

```sql
DROP [ PUBLIC ] DATABASE LINK <name>
```

## 설명 (Description)

`DROP DATABASE LINK`는 기존 데이터베이스 링크를 삭제합니다. 이 명령을 실행하려면 슈퍼유저이거나 해당 데이터베이스 링크의 소유자여야 합니다.

## 파라미터 (Parameters)

`name`

제거할 데이터베이스 링크의 이름입니다.

`PUBLIC`

`name`이 공개(public) 데이터베이스 링크임을 나타냅니다.

## 예제 (Examples)

`oralink`라는 이름의 공개 데이터베이스 링크를 제거합니다.

```sql
DROP PUBLIC DATABASE LINK oralink;
```

`edblink`라는 이름의 비공개(private) 데이터베이스 링크를 제거합니다.

```sql
DROP DATABASE LINK edblink;
```
