# ALTER QUEUE TABLE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › ALTER QUEUE TABLE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/07_alter_queue_table/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 `ALTER QUEUE TABLE` SQL 명령에 Oracle이 제공하지 않는 추가 구문을 포함합니다. 이 구문은 `DBMS_AQADM` 패키지와 함께 사용할 수 있습니다.

## 이름 (Name)

`ALTER QUEUE TABLE` — 기존 큐 테이블을 수정합니다.

## 구문 개요 (Synopsis)

기존 큐 테이블의 이름을 변경하려면 `ALTER QUEUE TABLE`을 사용합니다:

```sql
ALTER QUEUE TABLE <name> RENAME TO <new_name>
```

## 설명 (Description)

`ALTER QUEUE TABLE`은 슈퍼유저 또는 `aq_administrator_role` 권한을 가진 사용자가 기존 큐 테이블의 이름을 변경할 수 있게 합니다.

## 파라미터 (Parameters)

`name` — 기존 큐 테이블의 이름(선택적으로 스키마 한정).

`new_name` — 큐 테이블의 새 이름.

## 예제 (Examples)

이 예는 큐 테이블의 이름을 `wo_table_east`에서 `work_order_table`로 변경합니다:

```sql
ALTER QUEUE TABLE wo_queue_east RENAME TO work_order_table;
```
