# CREATE MATERIALIZED VIEW — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 호환 SQL 명령 › CREATE MATERIALIZED VIEW](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/25_create_materialized_view/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

## 이름 (Name)

`CREATE MATERIALIZED VIEW` — 새로운 구체화 뷰(materialized view)를 정의합니다.

## 구문 개요 (Synopsis)

```sql
CREATE MATERIALIZED VIEW <name>
   [<build_clause>][<create_mv_refresh>] AS subquery

      Where <build_clause> is:

      BUILD {IMMEDIATE | DEFERRED}

      Where <create_mv_refresh> is:

      REFRESH [COMPLETE] [ON DEMAND]
```

## 설명 (Description)

`CREATE MATERIALIZED VIEW`는 쿼리에서 뷰가 참조될 때마다 업데이트되지 않는 쿼리의 뷰를 정의합니다. 기본적으로 뷰는 뷰가 생성될 때 채워집니다. `BUILD DEFERRED` 키워드를 포함하여 뷰 채우기를 지연시킬 수 있습니다.

구체화 뷰는 스키마로 한정될 수 있습니다. `CREATE MATERIALIZED VIEW` 명령을 호출할 때 스키마 이름을 지정하면, 뷰는 지정된 스키마에 생성됩니다. 뷰 이름은 동일한 스키마 내의 다른 뷰, 테이블, 시퀀스, 인덱스의 이름과 달라야 합니다.

## 파라미터 (Parameters)

`name`

생성할 뷰의 이름(선택적으로 스키마로 한정 가능)입니다.

`subquery`

뷰의 내용을 지정하는 `SELECT` 문입니다.

`build_clause`

뷰를 언제 채울지 지정하려면 `build_clause`를 포함합니다. `BUILD IMMEDIATE` 또는 `BUILD DEFERRED`를 지정합니다:

- `BUILD IMMEDIATE`(기본값)는 뷰를 즉시 채웁니다.
- `BUILD DEFERRED`는 나중에 `REFRESH` 작업 중에 뷰를 채웁니다.

`create_mv_refresh`

구체화 뷰의 내용을 언제 업데이트할지 지정하려면 `create_mv_refresh` 절을 포함합니다. 이 절은 `REFRESH` 키워드 뒤에 선택적 `COMPLETE` 및 `ON DEMAND` 키워드가 오며, 여기서:

- `COMPLETE`는 구체화 뷰를 리프레시할 때 현재 내용을 버리고 뷰의 정의 쿼리를 실행하여 구체화 뷰를 다시 로드합니다.

- `ON DEMAND`(기본값)는 `DBMS_MVIEW` 패키지를 호출하거나 Postgres `REFRESH MATERIALIZED VIEW` 문을 호출하여 구체화 뷰를 요청 시(on demand) 리프레시합니다.


## 참고 사항 (Notes)

구체화 뷰는 읽기 전용입니다. 서버는 뷰에 대한 `INSERT`, `UPDATE`, `DELETE`를 허용하지 않습니다.

뷰 소유자의 권한이 뷰에서 참조하는 테이블에 대한 접근을 결정합니다. 뷰 사용자는 뷰가 사용하는 모든 함수를 호출할 권한이 있어야 합니다.

Postgres `REFRESH MATERIALIZED VIEW` 명령에 대한 자세한 내용은 [PostgreSQL 핵심 문서](https://www.postgresql.org/docs/current/static/sql-refreshmaterializedview.html)를 참조하세요.

## 예제 (Examples)

이 문은 `dept_30`이라는 이름의 구체화 뷰를 생성합니다:

```sql
CREATE MATERIALIZED VIEW dept_30 BUILD IMMEDIATE AS SELECT * FROM emp WHERE deptno = 30;
```

이 뷰는 부서 `30`에서 근무하는 모든 직원에 대해 `emp` 테이블에서 검색한 정보를 포함합니다.
