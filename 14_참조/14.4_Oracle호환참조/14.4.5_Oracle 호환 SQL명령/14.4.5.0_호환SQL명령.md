# 호환 SQL 명령 (Compatible SQL Commands) — EPAS 18 Reference — 색인

> 원문: [EPAS v18 — Reference › Oracle compatibility reference › Compatible SQL commands](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/)
> EPAS v18 공식 문서의 한글 **전문 번역** 트리입니다. 명령·코드 이름은 원문 그대로 보존합니다.
> 이 파일은 **색인(전체 목록)** 이며, 각 명령은 `14.4.1.N_명령명.md` 리프로 전문 번역합니다(배치 진행).

EDB Postgres Advanced Server는 Oracle 데이터베이스와 호환되는 많은 SQL 명령을 지원합니다. 이 SQL 명령들은 Oracle 데이터베이스와 EDB Postgres Advanced Server 데이터베이스 양쪽에서 작동합니다.

EDB Postgres Advanced Server는 여기 설명되지 않은 추가 명령도 지원합니다. 이 명령들은 Oracle 대응 명령이 없거나, Oracle SQL 명령과 유사하거나 동일한 기능을 다른 구문으로 제공할 수 있습니다.

이어지는 SQL 명령들이 각 명령에 대해 사용 가능한 전체 구문·옵션·기능을 반드시 나타내는 것은 아닙니다. 대부분의 경우 Oracle 데이터베이스와 호환되지 않는 구문·옵션·기능은 명령 설명과 구문에 포함되지 않습니다. Oracle 데이터베이스와 호환되지 않는 명령 기능은 별도로 표기됩니다.
