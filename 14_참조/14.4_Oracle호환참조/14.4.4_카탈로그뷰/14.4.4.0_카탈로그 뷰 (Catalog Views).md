# 카탈로그 뷰 (Catalog Views) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle compatibility reference › Catalog Views](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/)
> EPAS v18 공식 문서의 한글 **전문 번역** 트리입니다. 모든 하위 뷰(총 111개)를 개별 리프로 전문 번역 완료했습니다.

카탈로그 뷰는 데이터베이스 객체 정보를 제공합니다. 두 범주가 있습니다.

1. **Oracle 카탈로그 뷰** (96개) — Oracle 데이터 딕셔너리 뷰와 호환. `13_4_4_1_Oracle카탈로그뷰/` 폴더.
2. **시스템 카탈로그** (15개) — PostgreSQL 시스템 카탈로그의 EDB 확장. `13_4_4_2_시스템카탈로그/` 폴더.

## 하위 구성

- **13_4_4_1_Oracle카탈로그뷰** — `ALL_*`(30, 현재 사용자 접근 가능 객체) · `DBA_*`(36, DB 전체 객체) · `USER_*`(28, 현재 사용자 소유 객체) + V$VERSION · PRODUCT_COMPONENT_VERSION(2). 각 뷰의 컬럼 정의 표를 전문 번역.
- **13_4_4_2_시스템카탈로그** — PG_ATTRIBUTE, PG_AUTHID, PG_CLASS, PG_COLLATION, PG_DATABASE, PG_NAMESPACE, PG_PARTITIONED_TABLE, PG_PROC, PG_ROLES, PG_SHADOW, PG_SUBSCRIPTION, PG_SYNONYM, PG_TRIGGER, PG_TYPE, PG_USER(15). PostgreSQL 표준 대비 EDB 추가 컬럼 중심.

> ✅ 상태: 111개 리프 전부 전문 번역·저장 완료 (2026-07-22).
