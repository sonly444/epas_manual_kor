# PG_AUTHID — EPAS 18 시스템 카탈로그

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › System catalogs › PG_AUTHID](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/pg_views/pg_authid/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 카탈로그·컬럼 이름은 원문 그대로 보존했습니다.

`PG_AUTHID` 뷰는 데이터베이스 인가 식별자(즉, 역할)에 대한 정보를 제공합니다. 역할에는 사용자와 그룹이 포함됩니다.

## EDB Postgres Advanced Server의 추가 컬럼

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `rolredwoodprivs` | `Integer` | 역할이 redwood 전용 권한을 가지는지 여부를 지정. |
| `rolprofile` | `Oid` | 역할의 프로파일에 대한 객체 식별자. |
| `rolaccountstatus` | `Smallint` | 역할의 계정 상태. |
| `rolfailedlogins` | `Integer` | 실패한 로그인 시도 횟수. 이 파라미터는 인증 실패로 로그인이 거부될 때 내부적으로 갱신됨. 이 횟수가 프로파일에 지정된 한도를 초과하면 역할이 잠김. 로그인 성공 시 이 카운터는 0으로 재설정됨. `ALTER ROLE`에 `ACCOUNT` 절을 명시적으로 사용해도 이 카운터를 0으로 재설정할 수 있음. |
| `rolpasswordsetat` | `Timestamp with time zone` | 비밀번호 설정 시각을 지정. 비밀번호가 설정되지 않았으면 null. |
| `rollockdate` | `Timestamp with time zone` | 계정이 마지막으로 잠긴 시각. 계정이 한 번도 잠긴 적이 없으면 null. |
| `rolpasswordexpire` | `Timestamp with time zone` | 다음 로그인 시 비밀번호 변경이 강제되는 시각. |
| `rollastlogin` | `Timestamp with time zone` | 마지막 사용자 로그인 시각을 지정. 값이 NULL이면 사용자가 데이터베이스에 로그인한 적이 없음. |
