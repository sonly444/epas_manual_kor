# ALL_JOBS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › ALL_JOBS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/11_all_jobs/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`ALL_JOBS` 뷰는 데이터베이스에 존재하는 모든 작업(job)에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `job` | `INTEGER` | 작업의 식별자(Job ID). |
| `log_user` | `TEXT` | 작업을 제출한 사용자의 이름. |
| `priv_user` | `TEXT` | `log_user`와 동일. 호환성을 위해서만 포함됨. |
| `schema_user` | `TEXT` | 작업을 파싱하는 데 사용된 스키마의 이름. |
| `last_date` | `TIMESTAMP WITH TIME ZONE` | 이 작업이 마지막으로 성공적으로 실행된 날짜. |
| `last_sec` | `TEXT` | `last_date`와 동일. |
| `this_date` | `TIMESTAMP WITH TIME ZONE` | 작업이 실행을 시작한 날짜. |
| `this_sec` | `TEXT` | `this_date`와 동일. |
| `next_date` | `TIMESTAMP WITH TIME ZONE` | 이 작업이 다음에 실행될 날짜. |
| `next_sec` | `TEXT` | `next_date`와 동일. |
| `total_time` | `INTERVAL` | 이 작업의 실행 시간(초). |
| `broken` | `TEXT` | `Y`이면 이 작업을 실행하려는 시도가 이루어지지 않음. `N`이면 이 작업이 실행을 시도함. |
| `interval` | `TEXT` | 작업이 반복되는 빈도를 결정함. |
| `failures` | `BIGINT` | 마지막 성공 실행 이후 작업이 완료에 실패한 횟수. |
| `what` | `TEXT` | 작업이 실행될 때 실행되는 작업 정의(PL/SQL 코드 블록). |
| `nls_env` | `CHARACTER VARYING(4000)` | 항상 `NULL`. 호환성을 위해서만 제공됨. |
| `misc_env` | `BYTEA` | 항상 `NULL`. 호환성을 위해서만 제공됨. |
| `instance` | `NUMERIC` | 항상 `0`. 호환성을 위해서만 제공됨. |
