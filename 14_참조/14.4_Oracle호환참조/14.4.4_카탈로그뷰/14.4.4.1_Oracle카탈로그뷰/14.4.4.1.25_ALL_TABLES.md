# ALL_TABLES — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › ALL_TABLES](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/26_all_tables/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`ALL_TABLES` 뷰는 모든 사용자 정의 테이블에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `owner` | `TEXT` | 테이블 소유자의 사용자 이름. |
| `schema_name` | `TEXT` | 테이블이 속한 스키마의 이름. |
| `table_name` | `TEXT` | 테이블의 이름. |
| `tablespace_name` | `TEXT` | 테이블이 위치한 테이블스페이스의 이름. 지정되지 않으면 기본 테이블스페이스 `PG_DEFAULT`. |
| `status` | `CHARACTER VARYING(5)` | 테이블의 상태가 유효한지 여부. 호환성을 위해서만 포함됨. 항상 `VALID`로 설정됨. |
| `degree` | `CHARACTER VARYING(10)` | 테이블을 스캔하는 인스턴스당 스레드 수, 또는 `DEFAULT`. |
| `temporary` | `CHARACTER(1)` | 임시 테이블이면 `Y`, 그렇지 않으면 `N`. |
