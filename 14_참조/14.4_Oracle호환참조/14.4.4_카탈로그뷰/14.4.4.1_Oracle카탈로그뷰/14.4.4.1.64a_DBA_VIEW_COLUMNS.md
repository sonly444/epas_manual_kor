# DBA_VIEW_COLUMNS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › DBA_VIEW_COLUMNS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/63_dba_view_columns/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`DBA_VIEW_COLUMNS` 뷰는 데이터베이스의 모든 컬럼에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `owner` | `CHARACTER VARYING` | 뷰 소유자의 사용자 이름. |
| `schema_name` | `CHARACTER VARYING` | 뷰가 속한 스키마의 이름. |
| `view_name` | `CHARACTER VARYING` | 뷰의 이름. |
| `column_name` | `CHARACTER VARYING` | 컬럼의 이름. |
| `data_type` | `CHARACTER VARYING` | 컬럼의 데이터 타입. |
| `data_length` | `NUMERIC` | 텍스트 컬럼의 길이. |
| `data_precision` | `NUMERIC` | `NUMBER` 컬럼의 정밀도(자릿수). |
| `data_scale` | `NUMERIC` | `NUMBER` 컬럼의 스케일. |
| `nullable` | `CHARACTER(1)` | 컬럼이 null 허용인지 여부. 뷰 컬럼은 원본 테이블의 제약과 무관하게 항상 'Y'로 표시됨. 가능한 값: `Y` – null 허용; `N` – null 불허. |
| `column_id` | `NUMERIC` | 뷰에서 컬럼의 상대적 위치. |
| `data_default` | `CHARACTER VARYING` | 컬럼에 할당된 기본값. |
