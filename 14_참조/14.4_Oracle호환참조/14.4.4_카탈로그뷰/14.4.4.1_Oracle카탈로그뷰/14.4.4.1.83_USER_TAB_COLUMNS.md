# USER_TAB_COLUMNS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › USER_TAB_COLUMNS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/83_user_tab_columns/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`USER_TAB_COLUMNS` 뷰는 현재 사용자가 소유한 테이블과 뷰의 모든 컬럼에 대한 정보를 표시합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `schema_name` | `CHARACTER VARYING` | 테이블 또는 뷰가 위치한 스키마의 이름. |
| `table_name` | `CHARACTER VARYING` | 컬럼이 위치한 테이블 또는 뷰의 이름. |
| `column_name` | `CHARACTER VARYING` | 컬럼의 이름. |
| `data_type` | `CHARACTER VARYING` | 컬럼의 데이터 타입. |
| `data_length` | `NUMERIC` | 텍스트 컬럼의 길이. |
| `data_precision` | `NUMERIC` | `NUMBER` 컬럼의 정밀도(자릿수). |
| `data_scale` | `NUMERIC` | `NUMBER` 컬럼의 스케일. |
| `nullable` | `CHARACTER(1)` | 컬럼이 null 허용인지 여부. 가능한 값: `Y` – null 허용; `N` – null 불허. |
| `column_id` | `NUMERIC` | 테이블에서 컬럼의 상대적 위치. |
| `data_default` | `CHARACTER VARYING` | 컬럼에 할당된 기본값. |
