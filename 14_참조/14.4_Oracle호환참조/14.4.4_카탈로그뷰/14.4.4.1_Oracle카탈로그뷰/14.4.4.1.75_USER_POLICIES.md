# USER_POLICIES — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › USER_POLICIES](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/75_user_policies/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`USER_POLICIES` 뷰는 정책이 적용되는 객체를 포함하는 스키마의 이름이 현재 세션 사용자의 이름과 같은 정책에 대한 정보를 제공합니다. 이 뷰는 슈퍼유저만 접근할 수 있습니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `schema_name` | `TEXT` | 객체가 위치한 스키마의 이름. |
| `object_name` | `TEXT` | 정책이 적용되는 객체의 이름. |
| `policy_group` | `TEXT` | 정책 그룹의 이름. 호환성을 위해서만 포함됨. 항상 빈 문자열로 설정됨. |
| `policy_name` | `TEXT` | 정책의 이름. |
| `pf_owner` | `TEXT` | 정책 함수를 포함하는 스키마, 또는 정책 함수를 포함하는 패키지가 속한 스키마의 이름. |
| `package` | `TEXT` | 정책 함수가 패키지에 속한 경우 그 함수를 포함하는 패키지의 이름. |
| `function` | `TEXT` | 정책 함수의 이름. |
| `sel` | `TEXT` | 정책이 `SELECT` 명령에 적용되는지 여부. 가능한 값은 `YES` 또는 `NO`. |
| `ins` | `TEXT` | 정책이 `INSERT` 명령에 적용되는지 여부. 가능한 값은 `YES` 또는 `NO`. |
| `upd` | `TEXT` | 정책이 `UPDATE` 명령에 적용되는지 여부. 가능한 값은 `YES` 또는 `NO`. |
| `del` | `TEXT` | 정책이 `DELETE` 명령에 적용되는지 여부. 가능한 값은 `YES` 또는 `NO`. |
| `idx` | `TEXT` | 정책이 인덱스 유지 관리에 적용되는지 여부. 가능한 값은 `YES` 또는 `NO`. |
| `chk_option` | `TEXT` | `INSERT` 및 `UPDATE` 명령에 대해 check option이 적용되는지 여부. 가능한 값은 `YES` 또는 `NO`. |
| `enable` | `TEXT` | 정책이 객체에서 활성화되어 있는지 여부. 가능한 값은 `YES` 또는 `NO`. |
| `static_policy` | `TEXT` | 호환성을 위해서만 포함됨. 항상 `NO`로 설정됨. |
| `policy_type` | `TEXT` | 정책 유형. 호환성을 위해서만 포함됨. 항상 `UNKNOWN`으로 설정됨. |
| `long_predicate` | `TEXT` | 호환성을 위해서만 포함됨. 항상 `YES`로 설정됨. |
