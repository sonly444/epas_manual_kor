# ALL_QUEUES — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › ALL_QUEUES](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/16_all_queues/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`ALL_QUEUES` 뷰는 현재 정의된 큐에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `owner` | `TEXT` | 큐 소유자의 사용자 이름. |
| `name` | `TEXT` | 큐의 이름. |
| `queue_table` | `TEXT` | 큐가 위치한 큐 테이블의 이름. |
| `qid` | `OID` | 시스템이 할당한 큐의 객체 ID. |
| `queue_type` | `CHARACTER VARYING` | 큐 유형. `EXCEPTION_QUEUE`, `NON_PERSISTENT_QUEUE`, 또는 `NORMAL_QUEUE`일 수 있음. |
| `max_retries` | `NUMERIC` | 최대 dequeue 시도 횟수. |
| `retry_delay` | `NUMERIC` | 재시도 사이에 허용되는 최대 시간. |
| `enqueue_enabled` | `CHARACTER VARYING` | 큐가 enqueue를 허용하면 `YES`, 허용하지 않으면 `NO`. |
| `dequeue_enabled` | `CHARACTER VARYING` | 큐가 dequeue를 허용하면 `YES`, 허용하지 않으면 `NO`. |
| `retention` | `CHARACTER VARYING` | 처리된 메시지가 큐에 유지되는 시간(초). |
| `user_comment` | `CHARACTER VARYING` | 사용자가 지정한 주석. |
| `network_name` | `CHARACTER VARYING` | 큐가 위치한 네트워크의 이름. |
| `sharded` | `CHARACTER VARYING` | 큐가 샤딩된 네트워크에 있으면 `TRUE`, 그렇지 않으면 `FALSE`. |
