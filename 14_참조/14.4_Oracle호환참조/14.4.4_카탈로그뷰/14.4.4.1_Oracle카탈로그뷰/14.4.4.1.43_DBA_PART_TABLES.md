# DBA_PART_TABLES — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › DBA_PART_TABLES](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/44_dba_part_tables/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`DBA_PART_TABLES` 뷰는 데이터베이스의 모든 파티션 테이블에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `owner` | `TEXT` | 파티션 테이블의 소유자. |
| `schema_name` | `TEXT` | 테이블이 위치한 스키마. |
| `table_name` | `TEXT` | 테이블의 이름. |
| `partitioning_type` | `TEXT` | 테이블 파티션을 정의하는 데 사용된 유형. |
| `subpartitioning_type` | `TEXT` | 테이블 서브파티션을 정의하는 데 사용된 서브파티셔닝 유형. |
| `partition_count` | `BIGINT` | 테이블의 파티션 수. |
| `def_subpartition_count` | `INTEGER` | 테이블의 서브파티션 수. |
| `partitioning_key_count` | `INTEGER` | 지정된 파티셔닝 키의 수. |
| `subpartitioning_key_count` | `INTEGER` | 지정된 서브파티셔닝 키의 수. |
| `status` | `CHARACTER VARYING(8)` | 호환성을 위해서만 제공됨. 항상 `VALID`. |
| `def_tablespace_name` | `CHARACTER VARYING(30)` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
| `def_pct_free` | `NUMERIC` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
| `def_pct_used` | `NUMERIC` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
| `def_ini_trans` | `NUMERIC` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
| `def_max_trans` | `NUMERIC` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
| `def_initial_extent` | `CHARACTER VARYING(40)` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
| `def_next_extent` | `CHARACTER VARYING(40)` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
| `def_min_extents` | `CHARACTER VARYING(40)` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
| `def_max_extents` | `CHARACTER VARYING(40)` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
| `def_pct_increase` | `CHARACTER VARYING(40)` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
| `def_freelists` | `NUMERIC` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
| `def_freelist_groups` | `NUMERIC` | 호환성을 위해서만 제공됨. 항상 `NULL`. |
