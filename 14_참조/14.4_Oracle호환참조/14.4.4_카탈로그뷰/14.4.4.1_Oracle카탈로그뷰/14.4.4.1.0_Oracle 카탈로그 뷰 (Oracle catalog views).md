# Oracle 카탈로그 뷰 (Oracle catalog views) — EPAS 18

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/)
> EPAS v18 공식 문서의 한글 **전문 번역** 인덱스입니다. 아래 96개 뷰를 개별 리프로 전문 번역 완료했습니다.

Oracle 카탈로그 뷰는 Oracle 데이터 딕셔너리 뷰와 호환되는 방식으로 데이터베이스 객체 정보를 제공합니다. `ALL_*` 뷰는 현재 사용자가 접근 가능한 객체, `DBA_*` 뷰는 데이터베이스 전체 객체, `USER_*` 뷰는 현재 사용자 소유 객체 정보를 제공합니다.
