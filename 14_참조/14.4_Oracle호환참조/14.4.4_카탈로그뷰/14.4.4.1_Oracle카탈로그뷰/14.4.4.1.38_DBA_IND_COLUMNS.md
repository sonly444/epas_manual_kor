# DBA_IND_COLUMNS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › DBA_IND_COLUMNS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/39_dba_ind_columns/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`DBA_IND_COLUMNS` 뷰는 데이터베이스의 모든 테이블의 인덱스에 포함된 모든 컬럼에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `index_owner` | `TEXT` | 인덱스 소유자의 사용자 이름. |
| `schema_name` | `TEXT` | 인덱스가 속한 스키마의 이름. |
| `index_name` | `TEXT` | 인덱스의 이름. |
| `table_owner` | `TEXT` | 테이블 소유자의 사용자 이름. |
| `table_name` | `TEXT` | 인덱스가 속한 테이블의 이름. |
| `column_name` | `TEXT` | 컬럼 또는 객체 컬럼 속성의 이름. |
| `column_position` | `SMALLINT` | 인덱스에서 컬럼의 위치. |
| `column_length` | `SMALLINT` | 컬럼의 길이(바이트). |
| `char_length` | `NUMERIC` | 컬럼의 길이(문자). |
| `descend` | `CHARACTER(1)` | 호환성을 위해서만 포함됨. 항상 `Y`(내림차순)로 설정됨. |
