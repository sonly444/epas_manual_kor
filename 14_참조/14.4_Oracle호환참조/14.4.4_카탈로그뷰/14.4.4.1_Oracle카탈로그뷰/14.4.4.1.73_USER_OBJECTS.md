# USER_OBJECTS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › USER_OBJECTS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/73_user_objects/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`USER_OBJECTS` 뷰는 현재 사용자가 소유한 모든 객체에 대한 정보를 제공합니다.

| 컬럼              | 타입                  | 설명                                                                                                                                                                                |
| ----------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `schema_name`   | `TEXT`              | 객체가 속한 스키마의 이름.                                                                                                                                                          |
| `object_name`   | `TEXT`              | 객체의 이름.                                                                                                                                                                        |
| `object_type`   | `TEXT`              | 객체의 유형. 가능한 값:`INDEX`, `FUNCTION`, `PACKAE`, `PACKAGE BODY`, `PROCEDURE`, `SEQUENCE`, `SYNONYM`, `TABLE`, `TRIGGER`, ` TYPE`, `TYPE_BODY`,`VIEW `. |
| `created`       | `DATE`              | 객체 생성 시각의 타임스탬프.                                                                                                                                                        |
| `last_ddl_time` | `DATE`              | grant 및 revoke를 포함한 DDL 문으로 인한 객체의 마지막 수정 시각의 타임스탬프.                                                                                                      |
| `status`        | `CHARACTER VARYING` | 호환성을 위해서만 포함됨. 항상`VALID`로 설정됨.                                                                                                                                   |
| `temporary`     | `TEXT`              | 객체가 임시이면`Y`, 임시가 아니면 `N`.                                                                                                                                          |
