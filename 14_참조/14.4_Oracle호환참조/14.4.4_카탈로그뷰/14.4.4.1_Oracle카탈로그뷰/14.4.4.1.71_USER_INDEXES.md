# USER_INDEXES — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › USER_INDEXES](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/71_user_indexes/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`USER_INDEXES` 뷰는 현재 사용자가 소유한 테이블의 모든 인덱스에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `schema_name` | `TEXT` | 인덱스가 속한 스키마의 이름. |
| `index_name` | `TEXT` | 인덱스의 이름. |
| `index_type` | `TEXT` | 호환성을 위해서만 포함됨. 인덱스 유형은 항상 `BTREE`. |
| `table_owner` | `TEXT` | 인덱스가 적용된 테이블 소유자의 사용자 이름. |
| `table_name` | `TEXT` | 인덱스가 적용된 테이블의 이름. |
| `table_type` | `TEXT` | 호환성을 위해서만 포함됨. 항상 `TABLE`로 설정됨. |
| `uniqueness` | `TEXT` | 인덱스가 `UNIQUE`인지 `NONUNIQUE`인지 나타냄. |
| `compression` | `CHARACTER(1)` | 호환성을 위해서만 포함됨. 항상 `N`(비압축)으로 설정됨. |
| `tablespace_name` | `TEXT` | 기본 테이블스페이스가 아닌 경우 테이블이 위치한 테이블스페이스의 이름. |
| `degree` | `CHARACTER VARYING(10)` | 인덱스를 스캔하는 인스턴스당 스레드 수. |
| `logging` | `TEXT` | 호환성을 위해서만 포함됨. 항상 `LOGGING`으로 설정됨. |
| `status` | `TEXT` | 객체의 상태가 유효한지 여부(`VALID` 또는 `INVALID`). |
| `partitioned` | `CHARACTER(3)` | 호환성을 위해서만 포함됨. 항상 `NO`로 설정됨. |
| `temporary` | `CHARACTER(1)` | 호환성을 위해서만 포함됨. 항상 `N`으로 설정됨. |
| `secondary` | `CHARACTER(1)` | 호환성을 위해서만 포함됨. 항상 `N`으로 설정됨. |
| `join_index` | `CHARACTER(3)` | 호환성을 위해서만 포함됨. 항상 `NO`로 설정됨. |
| `dropped` | `CHARACTER(3)` | 호환성을 위해서만 포함됨. 항상 `NO`로 설정됨. |
