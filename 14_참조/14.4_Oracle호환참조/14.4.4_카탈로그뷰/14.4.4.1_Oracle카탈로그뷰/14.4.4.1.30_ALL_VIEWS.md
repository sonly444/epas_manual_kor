# ALL_VIEWS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › ALL_VIEWS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/31_all_views/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`ALL_VIEWS` 뷰는 모든 사용자 정의 뷰에 대한 정보를 제공합니다.

| 컬럼            | 타입      | 설명                        |
| --------------- | --------- | --------------------------- |
| `owner`       | `TEXT`  | 뷰 소유자의 사용자 이름.    |
| `schema_name` | `TEXT`  | 뷰가 속한 스키마의 이름.    |
| `objid`       | `OBJID` | 뷰의 Object ID.            |
| `view_name`   | `TEXT`  | 뷰의 이름.                  |
| `text`        | `TEXT`  | 뷰를 정의하는`SELECT` 문. |
