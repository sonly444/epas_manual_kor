# DBA_QUEUE_TABLES — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › DBA_QUEUE_TABLES](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/48_dba_queue_tables/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`DBA_QUEUE_TABLES` 뷰는 데이터베이스의 모든 큐 테이블에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `owner` | `TEXT` | 큐 테이블 소유자의 역할 이름. |
| `queue_table` | `TEXT` | 사용자가 지정한 큐 테이블의 이름. |
| `type` | `CHARACTER VARYING` | 큐 테이블에 저장된 데이터의 유형. |
| `object_type` | `TEXT` | 사용자 정의 페이로드 타입. |
| `sort_order` | `CHARACTER VARYING` | 큐 테이블이 정렬되는 순서. |
| `recipients` | `CHARACTER VARYING` | 항상 `SINGLE`. |
| `message_grouping` | `CHARACTER VARYING` | 항상 `NONE`. |
| `compatible` | `CHARACTER VARYING` | 이 큐 테이블이 호환되는 EDB Postgres Advanced Server 릴리스 번호. |
| `primary_instance` | `NUMERIC` | 항상 `0`. |
| `secondary_instance` | `NUMERIC` | 항상 `0`. |
| `owner_instance` | `NUMERIC` | 큐 테이블을 소유한 인스턴스의 인스턴스 번호. |
| `user_comment` | `CHARACTER VARYING` | 테이블 생성 시 제공된 사용자 주석. |
| `secure` | `CHARACTER VARYING` | `YES`는 큐 테이블이 보안(secure) 상태임을 나타냄. `NO`는 그렇지 않음을 나타냄. |
