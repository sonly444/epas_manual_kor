# USER_SEQUENCES — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › USER_SEQUENCES](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/79_user_sequences/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`USER_SEQUENCES` 뷰는 현재 사용자에게 속한 모든 사용자 정의 시퀀스에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `schema_name` | `TEXT` | 시퀀스가 위치한 스키마의 이름. |
| `sequence_name` | `TEXT` | 시퀀스의 이름. |
| `min_value` | `NUMERIC` | 서버가 시퀀스에 할당하는 최솟값. |
| `max_value` | `NUMERIC` | 서버가 시퀀스에 할당하는 최댓값. |
| `increment_by` | `NUMERIC` | 다음 시퀀스 번호를 생성하기 위해 현재 시퀀스 번호에 더해지는 값. |
| `cycle_flag` | `CHARACTER VARYING` | 시퀀스가 `min_value` 또는 `max_value`에 도달했을 때 순환하는지 여부를 지정. |
| `order_flag` | `CHARACTER VARYING` | 호환성을 위해서만 포함됨. 항상 `Y`. |
| `cache_size` | `NUMERIC` | 메모리에 미리 할당된 시퀀스 번호의 수. |
| `last_number` | `NUMERIC` | 디스크에 저장된 마지막 시퀀스 번호의 값. |
