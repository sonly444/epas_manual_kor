# USER_USERS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › USER_USERS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/90_user_users/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`USER_USERS` 뷰는 현재 사용자에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `username` | `TEXT` | 사용자의 사용자 이름. |
| `user_id` | `OID` | 사용자의 ID 번호. |
| `account_status` | `CHARACTER VARYING(32)` | 계정의 현재 상태. 가능한 값: `OPEN`, `EXPIRED`, `EXPIRED(GRACE)`, `EXPIRED & LOCKED`, `EXPIRED & LOCKED(TIMED)`, `EXPIRED(GRACE) & LOCKED`, `EXPIRED(GRACE) & LOCKED(TIMED)`, `LOCKED`, `LOCKED(TIMED)`. 계정의 현재 상태를 얻으려면 `edb_get_role_status(role_id)` 함수를 사용. |
| `lock_date` | `TIMESTAMP WITHOUT TIME ZONE` | 계정 상태가 `LOCKED`이면 계정이 잠긴 날짜와 시간을 표시. |
| `expiry_date` | `TIMESTAMP WITHOUT TIME ZONE` | 계정의 만료 날짜. |
| `default_tablespace` | `TEXT` | 계정과 연관된 기본 테이블스페이스. |
| `temporary_tablespace` | `CHARACTER VARYING(30)` | 호환성을 위해서만 포함됨. 값은 항상 ''(빈 문자열). |
| `created` | `DATE` | 객체 생성 시각의 타임스탬프. |
| `last_ddl_time` | `DATE` | grant 및 revoke를 포함한 DDL 문으로 인한 객체의 마지막 수정 시각의 타임스탬프. |
| `initial_rsrc_consumer_group` | `CHARACTER VARYING(30)` | 호환성을 위해서만 포함됨. 값은 항상 `NULL`. |
| `external_name` | `CHARACTER VARYING(4000)` | 호환성을 위해서만 포함됨. 항상 `NULL`로 설정됨. |
