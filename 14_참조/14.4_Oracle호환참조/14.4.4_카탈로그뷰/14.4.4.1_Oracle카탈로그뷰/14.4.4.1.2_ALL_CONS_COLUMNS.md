# ALL_CONS_COLUMNS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › ALL_CONS_COLUMNS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/03_all_cons_columns/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`ALL_CONS_COLUMNS` 뷰는 현재 사용자가 접근할 수 있는 테이블에 설정된 제약 조건에 지정된 컬럼에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `owner` | `TEXT` | 제약 조건 소유자의 사용자 이름. |
| `schema_name` | `TEXT` | 제약 조건이 속한 스키마의 이름. |
| `constraint_name` | `TEXT` | 제약 조건의 이름. |
| `table_name` | `TEXT` | 제약 조건이 속한 테이블의 이름. |
| `column_name` | `TEXT` | 제약 조건에서 참조하는 컬럼의 이름. |
| `position` | `SMALLINT` | 객체 정의에서 컬럼의 위치. |
| `constraint_def` | `TEXT` | 제약 조건의 정의. |
