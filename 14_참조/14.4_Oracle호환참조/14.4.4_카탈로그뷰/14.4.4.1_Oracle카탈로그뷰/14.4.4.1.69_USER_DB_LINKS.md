# USER_DB_LINKS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › USER_DB_LINKS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/69_user_db_links/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`USER_DB_LINKS` 뷰는 현재 사용자가 소유한 모든 데이터베이스 링크에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `db_link` | `TEXT` | 데이터베이스 링크의 이름. |
| `type` | `CHARACTER VARYING` | 원격 서버의 유형. 값은 `REDWOOD` 또는 `EDB`. |
| `username` | `TEXT` | 로그인하는 사용자의 사용자 이름. |
| `password` | `TEXT` | 원격 서버에서 인증하는 데 사용되는 비밀번호. |
| `host` | `TEXT` | 원격 서버의 이름 또는 IP 주소. |
