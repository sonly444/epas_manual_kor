# DBA_COL_PRIVS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › DBA_COL_PRIVS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/35_dba_col_privs/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`DBA_COL_PRIVS` 뷰는 모든 데이터베이스 사용자에 대해 컬럼에 부여된 객체 권한 목록을 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `grantee` | `CHARACTER VARYING(128)` | 권한을 가진 사용자의 이름. |
| `owner` | `CHARACTER VARYING(128)` | 객체 소유자. |
| `schema_name` | `CHARACTER VARYING(128)` | 객체가 위치한 스키마의 이름. |
| `table_name` | `CHARACTER VARYING(128)` | 객체 이름. |
| `column_name` | `CHARACTER VARYING(128)` | 컬럼 이름. |
| `grantor` | `CHARACTER VARYING(128)` | 권한을 부여한 사용자의 이름. |
| `privilege` | `CHARACTER VARYING(40)` | 컬럼에 대한 권한. |
| `grantable` | `CHARACTER VARYING(3)` | 권한이 grant option과 함께 부여되었는지 여부(`YES` 또는 `NO`). `YES`는 `GRANTEE`가 다른 사람에게 권한을 부여할 수 있음을 의미. 피부여자가 관리자 권한을 가지면 `YES`가 될 수 있음. |
| `common` | `CHARACTER VARYING(3)` | 호환성을 위해서만 포함됨. 항상 `NO`. |
| `inherited` | `CHARACTER VARYING(3)` | 호환성을 위해서만 포함됨. 항상 `NO`. |
