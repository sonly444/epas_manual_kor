# ALL_SYNONYMS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › ALL_SYNONYMS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/21_all_synonyms/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`ALL_SYNONYMS` 뷰는 현재 사용자가 참조할 수 있는 모든 시노님(synonym)에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `owner` | `TEXT` | 시노님 소유자의 사용자 이름. |
| `schema_name` | `TEXT` | 시노님이 위치한 스키마의 이름. |
| `objid` | `OBJID` | 시노님의 Obejct ID. |
| `synonym_name` | `TEXT` | 시노님의 이름. |
| `table_owner` | `TEXT` | 객체 소유자의 사용자 이름. |
| `table_schema_name` | `TEXT` | 테이블이 위치한 스키마의 이름. |
| `table_name` | `TEXT` | 시노님이 참조하는 객체의 이름. |
| `db_link` | `TEXT` | 연결된 데이터베이스 링크의 이름. |
