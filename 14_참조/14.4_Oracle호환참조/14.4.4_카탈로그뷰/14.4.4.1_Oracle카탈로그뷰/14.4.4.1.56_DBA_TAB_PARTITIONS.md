# DBA_TAB_PARTITIONS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › DBA_TAB_PARTITIONS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/56_dba_tab_partitions/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`DBA_TAB_PARTITIONS` 뷰는 데이터베이스에 존재하는 모든 파티션에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `table_owner` | `TEXT` | 파티션이 위치한 테이블의 소유자. |
| `schema_name` | `TEXT` | 테이블이 위치한 스키마의 이름. |
| `table_name` | `TEXT` | 테이블의 이름. |
| `composite` | `TEXT` | 테이블이 서브파티션되어 있으면 `YES`, 그렇지 않으면 `NO`. |
| `partition_name` | `TEXT` | 파티션의 이름. |
| `subpartition_count` | `BIGINT` | 파티션 내 서브파티션의 수. |
| `high_value` | `TEXT` | `CREATE TABLE` 문에 지정된 상위 파티셔닝 값. |
| `high_value_length` | `INTEGER` | 상위 파티셔닝 값의 길이. |
| `partition_position` | `INTEGER` | 이 파티션의 서수 위치. |
| `tablespace_name` | `TEXT` | 파티션이 위치한 테이블스페이스의 이름. 지정되지 않으면 기본값 `PG_DEFAULT`. |
| `pct_free` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `0`. |
| `pct_used` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `0`. |
| `ini_trans` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `0`. |
| `max_trans` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `0`. |
| `initial_extent` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
| `next_extent` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
| `min_extent` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `0`. |
| `max_extent` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `0`. |
| `pct_increase` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `0`. |
| `freelists` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
| `freelist_groups` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
| `logging` | `CHARACTER VARYING(7)` | 호환성을 위해서만 포함됨. 항상 `YES`. |
| `compression` | `CHARACTER VARYING(8)` | 호환성을 위해서만 포함됨. 항상 `NONE`. |
| `num_rows` | `NUMERIC` | `pg_class.reltuples`와 동일. |
| `blocks` | `INTEGER` | `pg_class.relpages`와 동일. |
| `empty_blocks` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
| `avg_space` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
| `chain_cnt` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
| `avg_row_len` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
| `sample_size` | `NUMERIC` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
| `last_analyzed` | `TIMESTAMP WITHOUT TIME ZONE` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
| `buffer_pool` | `CHARACTER VARYING(7)` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
