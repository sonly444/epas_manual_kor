# ALL_TYPES — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › ALL_TYPES](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/28_all_types/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`ALL_TYPES` 뷰는 현재 사용자가 사용할 수 있는 객체 타입에 대한 정보를 제공합니다.

| 컬럼            | 타입        | 설명                                                              |
| --------------- | ----------- | ----------------------------------------------------------------- |
| `owner`       | `TEXT`    | 객체 타입의 소유자.                                               |
| `schema_name` | `TEXT`    | 타입이 정의된 스키마의 이름.                                      |
| `objid`       | `OBJID`   | 타입의 Object ID.                                                |
| `type_name`   | `TEXT`    | 타입의 이름.                                                      |
| `type_oid`    | `OID`     | 타입의 객체 식별자(OID).                                          |
| `typecode`    | `TEXT`    | 타입의 typecode. 가능한 값:`OBJECT`, `COLLECTION`, `OTHER`. |
| `attributes`  | `INTEGER` | 타입의 속성(attribute) 수.                                        |
