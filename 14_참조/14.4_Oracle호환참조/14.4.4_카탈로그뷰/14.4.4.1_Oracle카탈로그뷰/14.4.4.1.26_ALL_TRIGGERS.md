# ALL_TRIGGERS — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › ALL_TRIGGERS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/27_all_triggers/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`ALL_TRIGGERS` 뷰는 현재 사용자가 접근할 수 있는 테이블의 트리거에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `owner` | `TEXT` | 트리거 소유자의 사용자 이름. |
| `schema_name` | `TEXT` | 트리거가 위치한 스키마의 이름. |
| `objid` | `OBJID` | 트리거의 Obejct ID. |
| `trigger_name` | `TEXT` | 트리거의 이름. |
| `trigger_type` | `TEXT` | 트리거의 유형. 가능한 값: `BEFORE ROW`, `BEFORE STATEMENT`, `AFTER ROW`, `AFTER STATEMENT`. |
| `triggering_event` | `TEXT` | 트리거를 실행시키는 이벤트. |
| `table_owner` | `TEXT` | 트리거가 정의된 테이블 소유자의 사용자 이름. |
| `base_object_type` | `TEXT` | 호환성을 위해서만 포함됨. 값은 항상 `TABLE`. |
| `table_name` | `TEXT` | 트리거가 정의된 테이블의 이름. |
| `referencing_names` | `TEXT` | 호환성을 위해서만 포함됨. 값은 항상 `REFERENCING NEW AS NEW OLD AS OLD`. |
| `status` | `TEXT` | 트리거가 활성화(`ENABLED`)되었는지 비활성화(`DISABLED`)되었는지 나타냄. |
| `description` | `TEXT` | 호환성을 위해서만 포함됨. |
| `trigger_body` | `TEXT` | 트리거의 본문. |
| `action_statement` | `TEXT` | 트리거가 실행될 때 실행되는 SQL 명령. |
