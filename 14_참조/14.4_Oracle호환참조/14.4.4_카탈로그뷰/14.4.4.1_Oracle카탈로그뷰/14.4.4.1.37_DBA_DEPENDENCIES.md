# DBA_DEPENDENCIES — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › DBA_DEPENDENCIES](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/38_dba_dependencies/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`DBA_DEPENDENCIES` 뷰는 데이터베이스의 모든 객체 간의 종속성에 대한 정보를 제공합니다(시노님 제외).

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `owner` | `CHARACTER VARYING(128)` | 종속 객체의 소유자. |
| `schema_name` | `CHARACTER VARYING(128)` | 종속 객체가 위치한 스키마의 이름. |
| `name` | `CHARACTER VARYING(128)` | 종속 객체의 이름. |
| `type` | `CHARACTER VARYING(18)` | 종속 객체의 유형. |
| `referenced_owner` | `CHARACTER VARYING(128)` | 참조된 객체의 소유자. |
| `referenced_schema_name` | `CHARACTER VARYING(128)` | 참조된 객체가 위치한 스키마의 이름. |
| `referenced_name` | `CHARACTER VARYING(128)` | 참조된 객체의 이름. |
| `referenced_type` | `CHARACTER VARYING(18)` | 참조된 객체의 유형. |
| `referenced_link_name` | `CHARACTER VARYING(128)` | 호환성을 위해서만 포함됨. 항상 `NULL`. |
| `dependency_type` | `CHARACTER VARYING(4)` | 호환성을 위해서만 포함됨. 항상 `HARD`로 설정됨. |
