# DBA_SOURCE — EPAS 18 Oracle 카탈로그뷰

> 원문: [EPAS v18 — Reference › Oracle compatibility › Catalog views › Oracle catalog views › DBA_SOURCE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/52_dba_source/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`DBA_SOURCE` 뷰는 모든 데이터베이스 객체의 소스 코드에 대한 포괄적인 목록을 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `owner` | `TEXT` | 프로그램 소유자의 사용자 이름. |
| `schema_name` | `TEXT` | 프로그램이 속한 스키마의 이름. |
| `name` | `TEXT` | 프로그램의 이름. |
| `type` | `TEXT` | 프로그램의 유형. 가능한 값: `FUNCTION`, `PACKAGE`, `PACKAGE BODY`, `PROCEDURE`, `TRIGGER`. |
| `line` | `INTEGER` | 지정된 프로그램에 대한 소스 코드 줄 번호. |
| `text` | `TEXT` | 소스 코드 텍스트 줄. |
