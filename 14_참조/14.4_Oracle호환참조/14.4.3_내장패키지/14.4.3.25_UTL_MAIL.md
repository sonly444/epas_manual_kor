> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

# UTL_MAIL

`UTL_MAIL` 패키지는 이메일을 관리합니다. EDB Postgres Advanced Server는 다음 프로시저를 지원합니다.

| 함수/프로시저 | 반환 타입 | 설명 |
| --- | --- | --- |
| `SEND(sender, recipients, cc, bcc, subject, message [, mime_type [, priority ]])` | 해당 없음 | 이메일을 패키징하여 SMTP 서버로 보냅니다. |
| `SEND_ATTACH_RAW(sender, recipients, cc, bcc, subject, message, mime_type, priority, attachment [, att_inline [, att_mime_type [, att_filename ]]])` | 해당 없음 | `SEND` 프로시저와 동일하지만 `BYTEA` 또는 대형 객체(large object) 첨부 파일을 사용합니다. |
| `SEND_ATTACH_VARCHAR2(sender, recipients, cc, bcc, subject, message, mime_type, priority, attachment [, att_inline [, att_mime_type [, att_filename ]]])` | 해당 없음 | `SEND` 프로시저와 동일하지만 `VARCHAR2` 첨부 파일을 사용합니다. |

##### 참고 (Note)

관리자는 각 사용자나 그룹이 이 패키지를 사용하기 전에 실행 권한을 부여해야 합니다.

## SEND

`SEND` 프로시저는 이메일을 SMTP 서버로 보냅니다.

```sql
SEND(<sender> VARCHAR2, <recipients> VARCHAR2, <cc> VARCHAR2,
  <bcc> VARCHAR2, <subject> VARCHAR2, <message> VARCHAR2
  [, <mime_type> VARCHAR2 [, <priority> PLS_INTEGER ]])
```

### 파라미터 (Parameters)

`sender`

발신자의 이메일 주소입니다.

`recipients`

수신자의 이메일 주소를 쉼표로 구분한 것입니다.

`cc`

참조 수신자의 이메일 주소를 쉼표로 구분한 것입니다.

`bcc`

숨은 참조 수신자의 이메일 주소를 쉼표로 구분한 것입니다.

`subject`

이메일의 제목 줄입니다.

`message`

이메일의 본문입니다.

`mime_type`

메시지의 MIME 타입입니다. 기본값은 `text/plain; charset=us-ascii`입니다.

`priority`

이메일의 우선순위입니다. 기본값은 `3`입니다.

### 예제 (Examples)

다음 익명 블록은 간단한 이메일 메시지를 보냅니다.

```sql
DECLARE
    v_sender        VARCHAR2(30);
    v_recipients    VARCHAR2(60);
    v_subj          VARCHAR2(20);
    v_msg           VARCHAR2(200);
BEGIN
    v_sender := 'jsmith@enterprisedb.com';
    v_recipients := 'ajones@enterprisedb.com,rrogers@enterprisedb.com';
    v_subj := 'Holiday Party';
    v_msg := 'This year''s party is scheduled for Friday, Dec. 21 at ' ||
             '6:00 PM. Please RSVP by Dec. 15th.';
    UTL_MAIL.SEND(v_sender,v_recipients,NULL,NULL,v_subj,v_msg);
END;
```

## SEND_ATTACH_RAW

`SEND_ATTACH_RAW` 프로시저는 `BYTEA` 데이터 또는 대형 객체(large object의 `OID`로 식별됨)를 포함하는 첨부 파일과 함께 이메일을 SMTP 서버로 보냅니다. `SEND_ATTACH_RAW` 호출은 두 가지 방식으로 작성할 수 있습니다.

```sql
SEND_ATTACH_RAW(<sender> VARCHAR2, <recipients> VARCHAR2,
  <cc> VARCHAR2, <bcc> VARCHAR2, <subject> VARCHAR2, <message> VARCHAR2,
  <mime_type> VARCHAR2, <priority> PLS_INTEGER,
  <attachment> BYTEA[, <att_inline> BOOLEAN
  [, <att_mime_type> VARCHAR2[, <att_filename> VARCHAR2 ]]])
```

또는

```sql
SEND_ATTACH_RAW(<sender> VARCHAR2, <recipients> VARCHAR2,
  <cc> VARCHAR2, <bcc> VARCHAR2, <subject> VARCHAR2, <message> VARCHAR2,
  <mime_type> VARCHAR2, <priority> PLS_INTEGER, <attachment> OID
  [, <att_inline> BOOLEAN [, <att_mime_type> VARCHAR2
  [, <att_filename> VARCHAR2 ]]])
```

### 파라미터 (Parameters)

`sender`

발신자의 이메일 주소입니다.

`recipients`

수신자의 이메일 주소를 쉼표로 구분한 것입니다.

`cc`

참조 수신자의 이메일 주소를 쉼표로 구분한 것입니다.

`bcc`

숨은 참조 수신자의 이메일 주소를 쉼표로 구분한 것입니다.

`subject`

이메일의 제목 줄입니다.

`message`

이메일의 본문입니다.

`mime_type`

메시지의 MIME 타입입니다. 기본값은 `text/plain; charset=us-ascii`입니다.

`priority`

이메일의 우선순위입니다. 기본값은 `3`입니다.

`attachment`

첨부 파일입니다.

`att_inline`

`TRUE`로 설정하면 첨부 파일을 인라인으로 볼 수 있습니다. 기본값은 `TRUE`입니다.

`att_mime_type`

첨부 파일의 MIME 타입입니다. 기본값은 `application/octet`입니다.

`att_filename`

첨부 파일을 포함하는 파일 이름입니다. 기본값은 `NULL`입니다.

## SEND_ATTACH_VARCHAR2

`SEND_ATTACH_VARCHAR2` 프로시저는 텍스트 첨부 파일과 함께 이메일을 SMTP 서버로 보냅니다.

```sql
SEND_ATTACH_VARCHAR2(<sender> VARCHAR2, <recipients> VARCHAR2, <cc>
VARCHAR2, <bcc> VARCHAR2, <subject> VARCHAR2, <message> VARCHAR2,
<mime_type> VARCHAR2, <priority> PLS_INTEGER, <attachment> VARCHAR2 [,
<att_inline> BOOLEAN [, <att_mime_type> VARCHAR2 [, <att_filename> VARCHAR2
]]])
```

### 파라미터 (Parameters)

`sender`

발신자의 이메일 주소입니다.

`recipients`

수신자의 이메일 주소를 쉼표로 구분한 것입니다.

`cc`

참조 수신자의 이메일 주소를 쉼표로 구분한 것입니다.

`bcc`

숨은 참조 수신자의 이메일 주소를 쉼표로 구분한 것입니다.

`subject`

이메일의 제목 줄입니다.

`message`

이메일의 본문입니다.

`mime_type`

메시지의 MIME 타입입니다. 기본값은 `text/plain; charset=us-ascii`입니다.

`priority`

이메일의 우선순위입니다. 기본값은 `3.`입니다.

`attachment`

`VARCHAR2` 첨부 파일입니다.

`att_inline`

`TRUE`로 설정하면 첨부 파일을 인라인으로 볼 수 있습니다. 기본값은 `TRUE`입니다.

`att_mime_type`

첨부 파일의 MIME 타입입니다. 기본값은 `text/plain; charset=us-ascii`입니다.

`att_filename`

첨부 파일을 포함하는 파일 이름입니다. 기본값은 `NULL`입니다.

##### 참고 (Note)

EPAS의 UTL_MAIL 패키지는 패키지 API를 호출할 때 SMTP 설정을 명시적으로 제공하지 않으면 하드코딩된 기본 SMTP 설정을 사용합니다.

```text
DEFAULT_OUT_SERVER    CONSTANT VARCHAR2 := 'localhost';
DEFAULT_SENDER_DOMAIN CONSTANT VARCHAR2 := 'localhost';
DEFAULT_PORT          CONSTANT INTEGER  := 25;
DEFAULT_TIMEOUT       CONSTANT INTEGER  := 10;
```

다른 SMTP 서버를 사용하려면, 이메일을 보내기 전에 프로시저나 익명 PL/SQL 블록 내에서 이러한 기본값을 재정의할 수 있습니다.
