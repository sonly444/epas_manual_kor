# DBMS_AQADM — EPAS 18 내장 패키지

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_AQADM](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/03_dbms_aqadm/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·역할 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server advanced queueing은 EDB Postgres Advanced Server 데이터베이스를 위한 메시지 큐잉과 메시지 처리 기능을 제공합니다. 사용자 정의 메시지는 큐(queue)에 저장되며, 큐의 모음은 큐 테이블(queue table)에 저장됩니다. `DBMS_AQADM` 패키지의 프로시저는 메시지 큐와 큐 테이블을 생성하고 관리합니다. `DBMS_AQ` 패키지는 큐에 메시지를 추가하거나 큐에서 메시지를 제거하고, PL/SQL 콜백 프로시저를 등록하거나 등록 해제하는 데 사용합니다.

EDB Postgres Advanced Server는 또한 SQL 명령을 통해 `DBMS_AQ` 패키지에 대한 확장(비호환) 기능도 제공합니다. 다음 SQL 명령에 대한 자세한 정보는 [SQL reference](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/)를 참조하십시오.

- `ALTER QUEUE`
- `ALTER QUEUE TABLE`
- `CREATE QUEUE`
- `CREATE QUEUE TABLE`
- `DROP QUEUE`
- `DROP QUEUE TABLE`

`DBMS_AQADM` 패키지는 큐와 큐 테이블을 생성하고 관리할 수 있는 프로시저를 제공합니다. EDB Postgres Advanced Server의 `DBMS_AQADM` 구현은 Oracle 버전에 비하면 부분 구현입니다. 표에 나열된 함수와 프로시저만 지원됩니다.

| 함수/프로시저 | 반환 유형 | 설명 |
| --- | --- | --- |
| `ALTER_QUEUE` | 해당 없음 | 기존 큐를 수정합니다. |
| `ALTER_QUEUE_TABLE` | 해당 없음 | 기존 큐 테이블을 수정합니다. |
| `CREATE_QUEUE` | 해당 없음 | 큐를 생성합니다. |
| `CREATE_QUEUE_TABLE` | 해당 없음 | 큐 테이블을 생성합니다. |
| `DROP_QUEUE` | 해당 없음 | 기존 큐를 삭제합니다. |
| `DROP_QUEUE_TABLE` | 해당 없음 | 기존 큐 테이블을 삭제합니다. |
| `PURGE_QUEUE_TABLE` | 해당 없음 | 큐 테이블에서 하나 이상의 메시지를 제거합니다. |
| `START_QUEUE` | 해당 없음 | 큐를 인큐 및 디큐 프로시저에 사용할 수 있도록 만듭니다. |
| `STOP_QUEUE` | 해당 없음 | 큐를 인큐 및 디큐 프로시저에 사용할 수 없도록 만듭니다. |

EDB Postgres Advanced Server는 표에 나열된 인수의 사용을 지원합니다.

| 상수 | 설명 | 적용 매개변수 |
| --- | --- | --- |
| `DBMS_AQADM.TRANSACTIONAL(1)` | 이 상수는 정의되어 있으나 사용하면 오류를 반환합니다. | `message_grouping` |
| `DBMS_AQADM.NONE(0)` | 큐 테이블에 대한 메시지 그룹화를 지정하는 데 사용합니다. | `message_grouping` |
| `DBMS_AQADM.NORMAL_QUEUE(0)` | `create_queue`와 함께 `queue_type`을 지정하는 데 사용합니다. | `queue_type` |
| `DBMS_AQADM.EXCEPTION_QUEUE (1)` | `create_queue`와 함께 `queue_type`을 지정하는 데 사용합니다. | `queue_type` |
| `DBMS_AQADM.INFINITE(-1)` | `create_queue`와 함께 `retention_time`을 지정하는 데 사용합니다. | `retention_time` |
| `DBMS_AQADM.PERSISTENT (0)` | 메시지를 테이블에 저장합니다. | `enqueue_options_t.delivery_mode` |
| `DBMS_AQADM.BUFFERED (1)` | 이 상수는 정의되어 있으나 사용하면 오류를 반환합니다. | `enqueue_options_t.delivery_mode` |
| `DBMS_AQADM.PERSISTENT_OR_BUFFERED (2)` | 이 상수는 정의되어 있으나 사용하면 오류를 반환합니다. | `enqueue_options_t.delivery_mode` |
