# DBMS_SESSION

EDB Postgres Advanced Server는 다음 `DBMS_SESSION.SET_ROLE` 프로시저를 지원합니다.

| 함수/프로시저 | 반환 유형 | 설명 |
| --- | --- | --- |
| `SET_ROLE(role_cmd)` | n/a | `role_cmd`에 지정된 문자열 값이 뒤따르는 `SET ROLE` 문을 실행합니다. |

EDB Postgres Advanced Server의 `DBMS_SESSION` 구현은 Oracle 버전과 비교할 때 부분 구현입니다. `DBMS_SESSION.SET_ROLE`만 지원됩니다.

## SET_ROLE

`SET_ROLE` 프로시저는 현재 세션 사용자를 `role_cmd`에 지정된 역할로 설정합니다. `SET_ROLE` 프로시저를 호출한 후, 현재 세션은 지정된 역할에 할당된 권한을 사용합니다. 프로시저의 시그니처는 다음과 같습니다.

```sql
SET_ROLE(<role_cmd>)
```

`SET_ROLE` 프로시저는 `role_cmd`에 지정된 값을 `SET ROLE` 문에 덧붙인 다음 해당 문을 실행합니다.

### 매개변수 (Parameters)

`role_cmd`

`role_cmd`는 문자열 값 형태의 역할 이름을 지정합니다.

### 예제 (Example)

`SET_ROLE` 프로시저에 대한 다음 호출은 `SET ROLE` 명령을 실행하여 현재 세션 사용자의 신원을 manager로 설정합니다.

```sql
edb=# exec DBMS_SESSION.SET_ROLE('manager');
```
