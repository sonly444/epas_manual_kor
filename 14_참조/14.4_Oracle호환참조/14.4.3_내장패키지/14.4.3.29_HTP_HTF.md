# HTP and HTF

하이퍼텍스트 프로시저(HTP)와 하이퍼텍스트 함수(HTF) Oracle 패키지는 HTML 태그를 생성합니다. 각 HTP에는 대응하는 HTF가 있습니다. 이들은 동일한 HTML 태그를 생성하고 동일한 파라미터를 사용하지만, 구문이 다릅니다. 예를 들어, `htp.address`와 `htf.address`는 모두 `<ADDRESS>`와 `</ADDRESS>` 태그를 생성하고 동일한 파라미터를 사용합니다. 그러나 구문이 다릅니다.

```text
HTP.ADDRESS (
   cvalue         IN       VARCHAR2
   cnowrap        IN       VARCHAR2   DEFAULT NULL
   cclear         IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);
```

```text
HTF.ADDRESS (cvalue, cnowrap, cclear, cattributes) RETURN VARCHAR2;
```
