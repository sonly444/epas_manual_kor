# UTL_URL

`UTL_URL` 패키지는 URL에서 잘못된(illegal) 문자와 예약된(reserved) 문자를 이스케이프하는 방법을 제공합니다.

| 함수/프로시저 | 반환 타입 | 설명 |
| --- | --- | --- |
| `ESCAPE(url, escape_reserved_chars, url_charset)` | `VARCHAR2` | `ESCAPE` 함수를 사용하여 URL의 잘못된 문자와 예약된 문자를 이스케이프합니다. |
| `UNESCAPE(url, url_charset)` | `VARCHAR2` | `UNESCAPE` 함수를 사용하여 URL을 원래 형식으로 변환합니다. |

`UTL_URL` 패키지는 함수 호출에 잘못된 형식의 URL이 포함되어 있으면 `BAD_URL` 예외를 반환합니다.

## ESCAPE

`ESCAPE` 함수를 사용하여 URL의 잘못된 문자와 예약된 문자를 이스케이프합니다. 시그니처는 다음과 같습니다.

```sql
ESCAPE(<url> VARCHAR2, <escape_reserved_chars> BOOLEAN,
<url_charset> VARCHAR2)
```

예약된 문자는 퍼센트 기호 뒤에 이스케이프된 문자의 ASCII 값에 대한 두 자리 16진수 코드가 오는 형태로 대체됩니다.

### 파라미터 (Parameters)

`url`

`url`은 `UTL_URL`이 이스케이프하는 URL(Uniform Resource Locator)을 지정합니다.

`escape_reserved_chars`

`escape_reserved_chars`는 `ESCAPE` 함수가 잘못된 문자뿐만 아니라 예약된 문자도 이스케이프하도록 지시하는 부울 값입니다.

- `escaped_reserved_chars`가 `FALSE`이면, `ESCAPE`는 지정된 URL의 잘못된 문자만 이스케이프합니다.

- `escape_reserved_chars`가 `TRUE`이면, `ESCAPE`는 지정된 URL의 잘못된 문자와 예약된 문자를 모두 이스케이프합니다.

기본적으로 `escape_reserved_chars`는 `FALSE`입니다.

URL에서 유효한(legal) 문자는 다음과 같습니다.

| 대문자 A부터 Z | 소문자 a부터 z | 0부터 9 |
| --- | --- | --- |
| 별표 (*) | 느낌표 (!) | 하이픈 (-) |
| 왼쪽 괄호 (() | 마침표 (.) | 오른쪽 괄호 ()) |
| 작은따옴표 (') | 물결표 (~) | 밑줄 (_) |

일부 문자는 URL의 일부에서는 유효하지만 다른 부분에서는 잘못됩니다. 잘못된 문자에 대한 포괄적인 규칙을 검토하려면 RFC 2396을 참조하세요. URL의 어느 부분에서든 잘못된 것으로 간주되는 문자의 몇 가지 예는 다음과 같습니다.

| 잘못된 문자 | 이스케이프 시퀀스 |
| --- | --- |
| 공백 ( ) | `%20` |
| 중괄호 ({ 또는 }) | `%7b` 및 `%7d` |
| 해시 마크 (#) | `%23` |

`ESCAPE` 함수는 다음 문자를 예약된 것으로 취급하며, `escape_reserved_chars`가 `TRUE`로 설정되어 있으면 이들을 이스케이프합니다.

| 예약된 문자 | 이스케이프 시퀀스 |
| --- | --- |
| 앰퍼샌드 (&) | `%5C` |
| 골뱅이 기호 (@) | `%25` |
| 콜론 (:) | `%3a` |
| 쉼표 (,) | `%2c` |
| 달러 기호 ($) | `%24` |
| 등호 (=) | `%3d` |
| 더하기 기호 (+) | `%2b` |
| 물음표 (?) | `%3f` |
| 세미콜론 (;) | `%3b` |
| 슬래시 (/) | `%2f` |

`url_charset`

`url_charset`은 주어진 문자를 이스케이프하기 전에 변환할 문자 집합을 지정합니다. `url_charset`이 `NULL`이면 문자는 변환되지 않습니다. `url_charset`의 기본값은 `ISO-8859-1`입니다.

### 예제 (Examples)

이 익명 블록은 `ESCAPE` 함수를 사용하여 URL의 공백을 이스케이프합니다.

```sql
DECLARE
  result varchar2(400);
BEGIN
 result := UTL_URL.ESCAPE('http://www.example.com/Using the ESCAPE
function.html');
  DBMS_OUTPUT.PUT_LINE(result);
END;
```

결과로 이스케이프된 URL은 다음과 같습니다.

```text
http://www.example.com/Using%20the%20ESCAPE%20function.html
```

함수를 호출할 때 `escape_reserved_chars` 파라미터에 `TRUE` 값을 포함한다고 가정합니다.

```sql
DECLARE
  result varchar2(400);
BEGIN
 result := UTL_URL.ESCAPE('http://www.example.com/Using the ESCAPE
function.html', TRUE);
  DBMS_OUTPUT.PUT_LINE(result);
END;
```

`ESCAPE` 함수는 URL의 잘못된 문자뿐만 아니라 예약된 문자도 이스케이프합니다.

```text
http%3A%2F%2Fwww.example.com%2FUsing%20the%20ESCAPE%20function.html
```

## UNESCAPE

`UNESCAPE` 함수는 `ESCAPE` 함수에 의해 URL에 추가된 이스케이프 문자를 제거하여 URL을 원래 형식으로 변환합니다.

시그니처는 다음과 같습니다.

```sql
UNESCAPE(<url> VARCHAR2, <url_charset> VARCHAR2)
```

### 파라미터 (Parameters)

`url`

`url`은 `UTL_URL`이 언이스케이프(unescape)하는 URL(Uniform Resource Locator)을 지정합니다.

`url_charset`

문자를 언이스케이프한 후, 그 문자는 `url_charset` 인코딩으로 되어 있다고 가정되며, 반환되기 전에 해당 인코딩에서 데이터베이스 인코딩으로 변환됩니다. `url_charset`이 `NULL`이면 문자는 변환되지 않습니다. `url_charset`의 기본값은 `ISO-8859-1`입니다.

### 예제 (Examples)

이 익명 블록은 `ESCAPE` 함수를 사용하여 URL의 공백을 이스케이프합니다.

```sql
DECLARE
  result varchar2(400);
BEGIN
 result :=
UTL_URL.UNESCAPE('http://www.example.com/Using%20the%20UNESCAPE%20function.html');
  DBMS_OUTPUT.PUT_LINE(result);
END;
```

결과로 (언이스케이프된) URL은 다음과 같습니다.

```text
http://www.example.com/Using the UNESCAPE function.html
```
