# SUBMIT — EPAS 18 내장 패키지 DBMS_JOB
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_JOB › SUBMIT](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/05_dbms_job/07_submit/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`SUBMIT` 프로시저는 job 정의를 생성하여 데이터베이스에 저장합니다. job은 다음으로 구성됩니다.

- job 식별자
- 실행할 저장 프로시저
- job을 처음 실행할 시점
- job을 다음에 실행할 날짜/시간을 계산하는 날짜 함수

```sql
SUBMIT(<job> OUT BINARY_INTEGER, <what> VARCHAR2
  [, <next_date> DATE [, <interval> VARCHAR2 [, <no_parse> BOOLEAN ]]])
```

## 파라미터 (Parameters)

`job`

job에 할당된 식별자입니다.

`what`

job이 실행할 저장 프로시저의 이름입니다.

`next_date`

job을 다음에 실행할 날짜/시간입니다. 기본값은 `SYSDATE`입니다.

`interval`

평가될 때 job을 다음에 실행할 날짜/시간을 제공하는 날짜 함수입니다. `interval`이 null로 설정되면 job은 한 번만 실행됩니다. 기본값은 null입니다.

`no_parse`

`TRUE`로 설정하면 job 생성 시점에 저장 프로시저의 구문을 검사하지 않습니다. job이 처음 실행될 때만 검사합니다. `FALSE`로 설정하면 job 생성 시점에 프로시저를 검사합니다. 기본값은 `FALSE`입니다.

##### 참고 (Note)

`no_parse` 옵션은 이 `SUBMIT()` 구현에서는 지원되지 않습니다. 호환성을 위해서만 포함되어 있습니다.

## 예제 (Example)

이 예제는 저장 프로시저 `job_proc`를 사용하여 job을 생성합니다. job은 즉시 실행되며, 그 후에는 `interval` 파라미터 `SYSDATE + 1`에 설정된 대로 하루에 한 번씩 실행됩니다.

```sql
DECLARE
    jobid INTEGER;
BEGIN
    DBMS_JOB.SUBMIT(jobid,'job_proc;',SYSDATE,
        'SYSDATE + 1');
    DBMS_OUTPUT.PUT_LINE('jobid: ' || jobid);
END;

jobid: 104
```

job은 즉시 프로시저 `job_proc`를 실행하여 `jobrun` 테이블에 행 하나를 채웁니다.

```sql
SELECT * FROM jobrun;
```

출력(Output)

```text
            runtime
-------------------------------------
 job_proc run at 2007-12-11 11:43:25
(1 row)
```
