# RUN — EPAS 18 내장 패키지 DBMS_JOB
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_JOB › RUN](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/05_dbms_job/06_run/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`RUN` 프로시저는 job의 상태가 broken이더라도 job을 강제로 실행합니다.

```sql
RUN(<job> BINARY_INTEGER)
```

## 파라미터 (Parameter)

`job`

실행할 job의 식별자입니다.

## 예제 (Example)

job을 강제로 실행합니다.

```sql
BEGIN
    DBMS_JOB.RUN(104);
END;
```
