# SQL_OBJECT_NAME — EPAS 18 내장 패키지 DBMS_ASSERT

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_ASSERT › SQL_OBJECT_NAME](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/01a_dbms_assert/sql_object_name/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`SQL_OBJECT_NAME` 함수는 입력 문자열이 현재 사용자가 접근할 수 있는 유효한 SQL 객체인지 여부를 판별합니다. 그렇지 않은 경우 오류가 발생합니다.

이 함수는 먼저 데이터베이스 이름을 확인하고, 그다음 스키마 이름을 확인한 뒤, 다음 순서로 그 밖의 SQL 객체를 확인합니다.

1. 테이블, 뷰, 구체화 뷰(materialized view), 인덱스, 시퀀스, 외래 테이블(foreign table), 파티션 테이블(partition-table), 타입, 객체 타입(object type)
2. 함수, 프로시저, 집계(aggregate), 루틴(routine)
3. 패키지(Packages)
4. 시노님(Synonym)
5. 트리거(Trigger)
6. 큐(Queue), 큐 테이블(queue table)
7. 이벤트 트리거(Event trigger)

이 함수로는 현재 데이터베이스에 있는 객체만 검증할 수 있습니다. 이 함수는 `dbname.schema_name.object_name.object_member`의 네 단계까지 이름을 검증합니다. 함수는 처음 세 단계에 대해 실제 데이터베이스 객체가 존재하는지 확인합니다. 네 번째 단계인 `object_member`에 대해서는 구문(syntax)만 검증합니다.

예를 들어, 입력이 `table_name.column_name`인 경우, 함수는 현재 검색 경로(search path)에 있는 데이터베이스 객체를 검색하여 `table_name`을 검증합니다. `table_name`을 찾은 후, 함수는 `column_name`의 기본 구문을 검증하며 해당 컬럼이 실제로 존재하는지는 확인하지 않습니다. 마찬가지로 `package_name.member_name`의 경우, 함수는 검색 경로에서 패키지 이름을 찾은 후 `member_name`의 기본 구문만 검증합니다.

```sql
SQL_OBJECT_NAME(str VARCHAR2) RETURN VARCHAR2;
```

## 매개변수 (Parameters)

`str`

입력 문자열입니다.

## 예제 (Examples)

```sql
edb=# CREATE TABLE t1_dbassert (a INT);
CREATE TABLE
edb=# SELECT SYS.DBMS_ASSERT.SQL_OBJECT_NAME('t1_dbassert') FROM DUAL;
 sql_object_name
-----------------
 t1_dbassert
(1 row)

-- The column_name is only syntax verified
edb=# SELECT dbms_assert.sql_object_name('t1_dbassert.col1');
 sql_object_name
------------------
 t1_dbassert.col1
(1 row)

edb=# SELECT dbms_assert.sql_object_name('t1_dbassert.1col');
ERROR:  invalid object name

CREATE OR REPLACE package pkg_dbassert AS
    i_dbassert NUMBER;
    PROCEDURE proc_dbassert;
    FUNCTION func_dbassert(i INT) RETURN NUMBER;
    t1_table_dbassert t1_dbassert;
    CURSOR cur(c1 t1_dbassert.a%TYPE) IS SELECT a FROM t1_dbassert;
    TYPE trec_dbassert IS RECORD ( a INTEGER, b INTEGER );
    r trec_dbassert := NULL;
END;

edb=# SELECT DBMS_ASSERT.SQL_OBJECT_NAME('pkg_dbassert.i_dbassert') FROM DUAL;
     sql_object_name
-------------------------
 pkg_dbassert.i_dbassert
(1 row)

edb=# SELECT DBMS_ASSERT.SQL_OBJECT_NAME('public.pkg_dbassert.i_dbassert') FROM DUAL;
        sql_object_name
--------------------------------
 public.pkg_dbassert.i_dbassert
(1 row)
```
