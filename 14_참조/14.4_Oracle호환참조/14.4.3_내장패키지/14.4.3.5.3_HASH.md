# HASH

`HASH` 함수는 사용자가 지정한 알고리즘을 사용하여 `RAW` 또는 `CLOB` 값의 해시 값을 반환합니다. `HASH` 함수는 세 가지 형태로 제공됩니다.

```sql
HASH
  (<src> IN RAW, <typ> IN INTEGER) RETURN RAW

HASH
  (<src> IN CLOB, <typ> IN INTEGER) RETURN RAW
```

## 매개변수 (Parameters)

`src`

`src`는 해시 값이 생성될 값을 지정합니다. `RAW`, `BLOB`, 또는 `CLOB` 값을 지정할 수 있습니다.

`typ`

`typ`는 `HASH` 함수 유형을 지정합니다. EDB Postgres Advanced Server는 표에 표시된 `HASH` 함수 유형을 지원합니다.

| HASH 함수 |  |
| --- | --- |
| `HASH_MD4` | `CONSTANT INTEGER := 1;` |
| `HASH_MD5` | `CONSTANT INTEGER := 2;` |
| `HASH_SH1` | `CONSTANT INTEGER := 3;` |

## 예제 (Examples)

이 예제는 `DBMS_CRYPTO.HASH`를 사용하여 문자열 `cleartext source`의 `md5` 해시 값을 찾습니다.

```sql
DECLARE
  typ INTEGER := DBMS_CRYPTO.HASH_MD5;
  hash_value RAW(100);
BEGIN

  hash_value := DBMS_CRYPTO.HASH('cleartext source', typ);

END;
```
