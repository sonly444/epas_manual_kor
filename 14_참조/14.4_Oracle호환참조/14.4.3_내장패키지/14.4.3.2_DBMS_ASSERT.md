# DBMS_ASSERT — EPAS 18 내장 패키지

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_ASSERT](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/01a_dbms_assert/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·역할 이름은 원문 그대로 보존했습니다.

`DBMS_ASSERT` 패키지를 사용하면 사용자 입력을 소독(sanitize)하고 검증하여 애플리케이션에서 SQL 인젝션을 방어하는 데 도움이 됩니다. 다음 표는 지원되는 함수 목록입니다.

| 함수 | 반환 유형 | 설명 |
| --- | --- | --- |
| `ENQUOTE_LITERAL` | `VARCHAR2` | 문자열을 작은따옴표로 감쌉니다 |
| `ENQUOTE_NAME` | `VARCHAR2` | 문자열을 큰따옴표로 감쌉니다 |
| `NOOP` | `anycompatible` | 아무런 검사 없이 입력 값을 그대로 반환합니다 |
| `QUALIFIED_SQL_NAME` | `VARCHAR2` | 입력 문자열이 정규화된(qualified) SQL 이름인지 검사합니다 |
| `SCHEMA_NAME` | `VARCHAR2` | 입력 문자열이 존재하는 스키마 이름인지 검사합니다 |
| `SIMPLE_SQL_NAME` | `VARCHAR2` | 입력 문자열이 단순(simple) SQL 이름인지 검사합니다 |
| `SQL_OBJECT_NAME` | `VARCHAR2` | 입력 문자열이 존재하는 SQL 객체의 정규화된 SQL 식별자인지 검사합니다 |

`DBMS_ASSERT`를 사용하는 방법에 대한 몇 가지 예시는 [Examples for SQL injection](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/01a_dbms_assert/examples/)을 참조하십시오.
