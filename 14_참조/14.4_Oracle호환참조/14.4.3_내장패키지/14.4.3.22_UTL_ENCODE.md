# UTL_ENCODE

`UTL_ENCODE` 패키지는 데이터를 인코딩하고 디코딩하는 방법을 제공합니다. EDB Postgres Advanced Server는 다음 함수와 프로시저를 지원합니다.

| 함수/프로시저 | 반환 타입 | 설명 |
| --- | --- | --- |
| `BASE64_DECODE(r)` | `RAW` | `BASE64_DECODE` 함수를 사용하여 Base64로 인코딩된 문자열을 원래의 `RAW` 값으로 변환합니다. |
| `BASE64_ENCODE(r)` | `RAW` | `BASE64_ENCODE` 함수를 사용하여 `RAW` 문자열을 인코딩된 Base64 값으로 변환합니다. |
| `BASE64_ENCODE(loid)` | `TEXT` | `BASE64_ENCODE` 함수를 사용하여 `TEXT` 문자열을 인코딩된 Base64 값으로 변환합니다. |
| `MIMEHEADER_DECODE(buf)` | `VARCHAR2` | `MIMEHEADER_DECODE` 함수를 사용하여 인코딩된 `MIMEHEADER` 형식의 문자열을 원래 값으로 변환합니다. |
| `MIMEHEADER_ENCODE(buf, encode_charset, encoding)` | `VARCHAR2` | `MIMEHEADER_ENCODE` 함수를 사용하여 문자열을 `MIMEHEADER` 형식으로 변환하고 인코딩합니다. |
| `QUOTED_PRINTABLE_DECODE(r)` | `RAW` | `QUOTED_PRINTABLE_DECODE` 함수를 사용하여 인코딩된 문자열을 `RAW` 값으로 변환합니다. |
| `QUOTED_PRINTABLE_ENCODE(r)` | `RAW` | `QUOTED_PRINTABLE_ENCODE` 함수를 사용하여 입력 문자열을 quoted-printable 형식의 `RAW` 값으로 변환합니다. |
| `TEXT_DECODE(buf, encode_charset, encoding)` | `VARCHAR2` | `TEXT_DECODE` 함수를 사용하여 `TEXT_ENCODE`로 인코딩된 문자열을 디코딩합니다. |
| `TEXT_ENCODE(buf, encode_charset, encoding)` | `VARCHAR2` | `TEXT_ENCODE` 함수를 사용하여 문자열을 사용자가 지정한 문자 집합으로 변환한 다음 인코딩합니다. |
| `UUDECODE(r)` | `RAW` | `UUDECODE` 함수를 사용하여 uuencode로 인코딩된 문자열을 `RAW` 값으로 변환합니다. |
| `UUENCODE(r, type, filename, permission)` | `RAW` | `UUENCODE` 함수를 사용하여 `RAW` 문자열을 인코딩된 uuencode 값으로 변환합니다. |
