# QUALIFIED_SQL_NAME — EPAS 18 내장 패키지 DBMS_ASSERT

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_ASSERT › QUALIFIED_SQL_NAME](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/01a_dbms_assert/qualified_sql_name/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`QUALIFIED_SQL_NAME` 함수는 입력 문자열이 정규화된(qualified) SQL 이름인지 여부를 판별합니다.

정규화된 SQL 이름을 표현하려면 다음 문법을 사용합니다.

```text
<simple qualified name>  => <simple name> ['.' <simple name>]
<dblink name>            => <simple qualified name> ['@' <conn string>]
<conn string>            => <simple name>
<qualified name>         => <simple qualified name> ['@' <dblink name>]
```

## 매개변수 (Parameters)

`str`

입력 문자열입니다. 입력 문자열 안에는 큰따옴표가 허용됩니다.

## 예제 (Examples)

```sql
edb=# SELECT SYS.DBMS_ASSERT.QUALIFIED_SQL_NAME('schema_name."object_name"@dblink_name') FROM DUAL;
          qualified_sql_name
---------------------------------------
 schema_name."object_name"@dblink_name
(1 row)

edb=# SELECT SYS.DBMS_ASSERT.QUALIFIED_sql_name('こんにちは') FROM DUAL;
 qualified_sql_name
--------------------
 こんにちは
(1 row)

edb=# SELECT dbms_assert.qualified_sql_name('db1".etc"');
ERROR:  invalid qualified SQL name
```
