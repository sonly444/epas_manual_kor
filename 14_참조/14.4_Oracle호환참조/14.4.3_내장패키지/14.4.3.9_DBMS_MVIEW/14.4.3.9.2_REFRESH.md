# REFRESH

`REFRESH` 프로시저를 사용하여 뷰 이름을 쉼표로 구분한 목록 또는 `DBMS_UTILITY.UNCL_ARRAY` 값의 테이블에 지정된 모든 뷰를 새로 고칩니다. 이 프로시저에는 두 가지 시그니처가 있습니다. 뷰 이름을 쉼표로 구분한 목록으로 지정할 때는 첫 번째 형식을 사용합니다.

```sql
REFRESH(
  <list> IN VARCHAR2,
  <method> IN VARCHAR2 DEFAULT NULL,
  <rollback_seg> IN VARCHAR2 DEFAULT NULL,
  <push_deferred_rpc> IN BOOLEAN DEFAULT TRUE,
  <refresh_after_errors> IN BOOLEAN DEFAULT FALSE,
  <purge_option> IN NUMBER DEFAULT 1,
  <parallelism> IN NUMBER DEFAULT 0,
  <heap_size> IN NUMBER DEFAULT 0,
  <atomic_refresh> IN BOOLEAN DEFAULT TRUE,
  <nested> IN BOOLEAN DEFAULT FALSE);
```

`DBMS_UTILITY.UNCL_ARRAY` 값의 테이블로 뷰 이름을 지정할 때는 두 번째 형식을 사용합니다.

```sql
REFRESH(
  <tab> IN OUT DBMS_UTILITY.UNCL_ARRAY,
  <method> IN VARCHAR2 DEFAULT NULL,
  <rollback_seg> IN VARCHAR2 DEFAULT NULL,
  <push_deferred_rpc> IN BOOLEAN DEFAULT TRUE,
  <refresh_after_errors> IN BOOLEAN DEFAULT FALSE,
  <purge_option> IN NUMBER DEFAULT 1,
  <parallelism> IN NUMBER DEFAULT 0,
  <heap_size> IN NUMBER DEFAULT 0,
  <atomic_refresh> IN BOOLEAN DEFAULT TRUE,
  <nested> IN BOOLEAN DEFAULT FALSE);
```

## 파라미터 (Parameters)

`list`

`list`는 구체화 뷰의 이름 또는 구체화 뷰 이름을 쉼표로 구분한 목록을 지정하는 `VARCHAR2` 값입니다. 이름은 스키마로 한정할 수 있습니다.

`tab`

`tab`은 구체화 뷰의 이름을 지정하는 `DBMS_UTILITY.UNCL_ARRAY` 값의 테이블입니다.

`method`

`method`는 지정된 뷰에 적용할 새로 고침 방법을 지정하는 `VARCHAR2` 값입니다. 지원되는 유일한 방법은 `C`이며, 이는 뷰의 완전한 새로 고침을 수행합니다.

`rollback_seg`

`rollback_seg`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `NULL`입니다.

`push_deferred_rpc`

`push_deferred_rpc`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `TRUE`입니다.

`refresh_after_errors`

`refresh_after_errors`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `FALSE`입니다.

`purge_option`

`purge_option`은 호환성을 위해 허용되며 무시됩니다. 기본값은 `1`입니다.

`parallelism`

`parallelism`은 호환성을 위해 허용되며 무시됩니다. 기본값은 `0`입니다.

`heap_size IN NUMBER DEFAULT 0`,

`heap_size`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `0`입니다.

`atomic_refresh`

`atomic_refresh`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `TRUE`입니다.

`nested`

`nested`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `FALSE`입니다.

## 예제 (Example)

이 예제는 `DBMS_MVIEW.REFRESH`를 사용하여 `public.emp_view` 구체화 뷰에 대해 완전한 새로 고침을 수행합니다.

```sql
EXEC DBMS_MVIEW.REFRESH(list => 'public.emp_view', method => 'C');
```
