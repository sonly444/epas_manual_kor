# REFRESH_ALL_MVIEWS

`REFRESH_ALL_MVIEWS` 프로시저를 사용하여, 뷰가 의존하는 테이블 또는 뷰가 수정된 이후로 새로 고쳐지지 않은 구체화 뷰를 새로 고칩니다. 시그니처는 다음과 같습니다.

```sql
REFRESH_ALL_MVIEWS(
  <number_of_failures> OUT BINARY_INTEGER,
  <method> IN VARCHAR2 DEFAULT NULL,
  <rollback_seg> IN VARCHAR2 DEFAULT NULL,
  <refresh_after_errors> IN BOOLEAN DEFAULT FALSE,
  <atomic_refresh> IN BOOLEAN DEFAULT TRUE);
```

## 파라미터 (Parameters)

`number_of_failures`

`number_of_failures`는 새로 고침 중에 발생한 실패 횟수를 지정하는 `BINARY_INTEGER`입니다.

`method`

`method`는 지정된 뷰에 적용할 새로 고침 방법을 지정하는 `VARCHAR2` 값입니다. 지원되는 유일한 방법은 `C`이며, 이는 뷰의 완전한 새로 고침을 수행합니다.

`rollback_seg`

`rollback_seg`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `NULL`입니다.

`refresh_after_errors`

`refresh_after_errors`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `FALSE`입니다.

`atomic_refresh`

`atomic_refresh`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `TRUE`입니다.

## 예제 (Example)

이 예제는 모든 구체화 뷰에 대해 완전한 새로 고침을 수행합니다.

```sql
DECLARE
  errors INTEGER;
BEGIN
  DBMS_MVIEW.REFRESH_ALL_MVIEWS(errors, method => 'C');
END;
```

완료되면 `errors`에는 실패 횟수가 담깁니다.
