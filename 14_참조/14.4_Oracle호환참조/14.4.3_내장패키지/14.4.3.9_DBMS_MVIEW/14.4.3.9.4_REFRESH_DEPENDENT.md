# REFRESH_DEPENDENT

`REFRESH_DEPENDENT` 프로시저를 사용하여, 프로시저 호출에서 지정된 뷰에 의존하는 모든 구체화 뷰를 새로 고칩니다. 쉼표로 구분한 목록을 지정하거나 `DBMS_UTILITY.UNCL_ARRAY` 값의 테이블로 뷰 이름을 제공할 수 있습니다.

쉼표로 구분한 목록에 지정된 뷰에 의존하는 모든 구체화 뷰를 새로 고치려면 프로시저의 첫 번째 형식을 사용합니다.

```sql
REFRESH_DEPENDENT(
  <number_of_failures> OUT BINARY_INTEGER,
  <list> IN VARCHAR2,
  <method> IN VARCHAR2 DEFAULT NULL,
  <rollback_seg> IN VARCHAR2 DEFAULT NULL
  <refresh_after_errors> IN BOOLEAN DEFAULT FALSE,
  <atomic_refresh> IN BOOLEAN DEFAULT TRUE,
  <nested> IN BOOLEAN DEFAULT FALSE);
```

`DBMS_UTILITY.UNCL_ARRAY` 값의 테이블에 지정된 뷰에 의존하는 모든 구체화 뷰를 새로 고치려면 프로시저의 두 번째 형식을 사용합니다.

```sql
REFRESH_DEPENDENT(
  <number_of_failures> OUT BINARY_INTEGER,
  <tab> IN DBMS_UTILITY.UNCL_ARRAY,
  <method> IN VARCHAR2 DEFAULT NULL,
  <rollback_seg> IN VARCHAR2 DEFAULT NULL,
  <refresh_after_errors> IN BOOLEAN DEFAULT FALSE,
  <atomic_refresh> IN BOOLEAN DEFAULT TRUE,
  <nested> IN BOOLEAN DEFAULT FALSE);
```

## 파라미터 (Parameters)

`number_of_failures`

`number_of_failures`는 새로 고침 작업 중에 발생한 실패 횟수를 담는 `BINARY_INTEGER`입니다.

`list`

`list`는 구체화 뷰의 이름 또는 구체화 뷰 이름을 쉼표로 구분한 목록을 지정하는 `VARCHAR2` 값입니다. 이름은 스키마로 한정할 수 있습니다.

`tab`

`tab`은 구체화 뷰의 이름을 지정하는 `DBMS_UTILITY.UNCL_ARRAY` 값의 테이블입니다.

`method`

`method`는 지정된 뷰에 적용할 새로 고침 방법을 지정하는 `VARCHAR2` 값입니다. 지원되는 유일한 방법은 `C`이며, 이는 뷰의 완전한 새로 고침을 수행합니다.

`rollback_seg`

`rollback_seg`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `NULL`입니다.

`refresh_after_errors`

`refresh_after_errors`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `FALSE`입니다.

`atomic_refresh`

`atomic_refresh`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `TRUE`입니다.

`nested`

`nested`는 호환성을 위해 허용되며 무시됩니다. 기본값은 `FALSE`입니다.

## 예제 (Example)

이 예제는 `public` 스키마에 있는 `emp_view`라는 구체화 뷰에 의존하는 모든 구체화 뷰에 대해 완전한 새로 고침을 수행합니다.

```sql
DECLARE
  errors INTEGER;
BEGIN
  DBMS_MVIEW.REFRESH_DEPENDENT(errors, list => 'public.emp_view', method =>
'C');
END;
```

완료되면 `errors`에는 실패 횟수가 담깁니다.
