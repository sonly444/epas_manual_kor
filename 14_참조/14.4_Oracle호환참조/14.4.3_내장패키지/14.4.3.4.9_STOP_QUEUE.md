# STOP_QUEUE

지정한 큐에서 인큐(enqueue) 또는 디큐(dequeue)를 비활성화하려면 `STOP_QUEUE` 프로시저를 사용합니다. 시그니처는 다음과 같습니다.

```sql
STOP_QUEUE(
  <queue_name> IN VARCHAR2,
  <enqueue> IN BOOLEAN DEFAULT TRUE,
  <dequeue> IN BOOLEAN DEFAULT TRUE,
  <wait> IN BOOLEAN DEFAULT TRUE)
```

## 매개변수 (Parameters)

`queue_name`

`queue_name`은 중지할 큐의 이름을 지정합니다.

`enqueue`

인큐를 비활성화하려면 `TRUE`(기본값)를, 현재 설정을 변경하지 않고 그대로 두려면 `FALSE`를 지정합니다.

`dequeue`

디큐를 비활성화하려면 `TRUE`(기본값)를, 현재 설정을 변경하지 않고 그대로 두려면 `FALSE`를 지정합니다.

`wait`

지정한 변경 사항을 적용하기 전에 완료되지 않은 트랜잭션이 완료될 때까지 서버가 대기하도록 지시하려면 `TRUE`를 지정합니다. 큐 중지를 대기하는 동안에는 어떤 트랜잭션도 지정한 큐에서 인큐하거나 디큐할 수 없습니다. 큐를 즉시 중지하려면 `FALSE`를 지정합니다.

## 예제 (Example)

다음 익명 블록은 `work_order`라는 이름의 큐에서 인큐와 디큐를 비활성화합니다.

```sql
BEGIN
DBMS_AQADM.STOP_QUEUE(queue_name =>'work_order', enqueue=>TRUE,
dequeue=>TRUE, wait=>TRUE);
END;
```

미완료 트랜잭션이 모두 완료된 후 인큐와 디큐가 중지됩니다.
