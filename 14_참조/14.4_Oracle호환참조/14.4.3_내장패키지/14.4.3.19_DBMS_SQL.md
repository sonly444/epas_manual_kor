# DBMS_SQL

`DBMS_SQL` 패키지는 EDB 동적 SQL 기능에 대해 Oracle 데이터베이스와 호환되는 애플리케이션 인터페이스를 제공합니다. `DBMS_SQL`을 사용하면 애플리케이션을 작성할 때가 아니라 런타임에 쿼리 및 기타 명령을 구성할 수 있습니다. EDB Postgres Advanced Server는 동적 SQL에 대한 기본(native) 지원을 제공합니다. `DBMS_SQL`은 애플리케이션을 수정하지 않고도 Oracle 데이터베이스와 호환되는 방식으로 동적 SQL을 사용하는 방법을 제공합니다.

`DBMS_SQL`은 동적 SQL 문을 실행할 때 현재 사용자의 권한을 가정합니다.

EDB Postgres Advanced Server의 `DBMS_SQL` 구현은 Oracle 버전과 비교할 때 부분 구현입니다. 표에 나열된 함수와 프로시저만 지원됩니다.

| 함수/프로시저 | 함수 또는 프로시저 | 반환 유형 | 설명 |
| --- | --- | --- | --- |
| `BIND_ARRAY(c IN, name IN, table_variable IN [index1 IN, index2 IN])` | 프로시저 | n/a | 변수에 값 또는 값 집합을 바인딩합니다. |
| `BIND_VARIABLE(c, name, value [, out_value_size ])` | 프로시저 | n/a | 변수에 값을 바인딩합니다. |
| `BIND_VARIABLE_CHAR(c, name, value [, out_value_size ])` | 프로시저 | n/a | 변수에 `CHAR` 값을 바인딩합니다. |
| `BIND_VARIABLE_RAW(c, name, value [, out_value_size ])` | 프로시저 | n/a | 변수에 `RAW` 값을 바인딩합니다. |
| `CLOSE_CURSOR(c IN OUT)` | 프로시저 | n/a | 커서를 닫습니다. |

| `COLUMN_VALUE_LONG(c, position, length, offset, value OUT, value_length OUT)` | 프로시저 | n/a | `LONG` 열 값의 일부를 변수로 반환합니다. |
| `COLUMN_VALUE_ROWID(c, position, value OUT [ column_error OUT [, actual_length OUT ]])` | 프로시저 | n/a | 커서의 `ROWID` 열을 반환합니다. |
| `DEFINE_ARRAY(c IN, position IN, table_variable IN, cnt IN, lower_bnd IN )` | 프로시저 | n/a | 행을 페치할 열에 대한 컬렉션을 정의합니다. |

| `DEFINE_COLUMN_LONG(c, position)` | 프로시저 | n/a | `SELECT` 목록에 `LONG` 열을 정의합니다. |
| `DEFINE_COLUMN_ROWID(c IN, position IN, column IN)` | 프로시저 | n/a | `SELECT` 목록에 `ROWID` 열을 정의합니다. |
| `DESCRIBE_COLUMNS(c IN, col_cnt OUT, desc_t OUT, DESC_TAB)` | 프로시저 | n/a | 커서 결과 집합을 담을 열을 정의합니다. |
| `DESCRIBE_COLUMNS2(c IN, col_cnt OUT, desc_t OUT, DESC_TAB)` | 프로시저 | n/a | 커서 결과 집합을 담을 열을 정의합니다. |
| `DESCRIBE_COLUMNS3(c IN, col_cnt OUT, desc_t OUT, DESC_TAB)` | 프로시저 | n/a | 커서 결과 집합을 담을 열을 정의합니다. |
| `EXECUTE(c)` | 함수 | `INTEGER` | 커서를 실행합니다. |
