# UNREGISTER

`UNREGISTER` 프로시저를 사용하여 인큐 및 디큐와 관련된 알림을 끕니다. 시그니처는 다음과 같습니다.

```sql
UNREGISTER(
  <reg_list> IN SYS.AQ$_REG_INFO_LIST,
  <count> IN NUMBER)
```

## 매개변수 (Parameter)

`reg_list`

`reg_list`는 등록하려는 각 구독(subscription)에 대한 정보를 제공하는 `AQ$_REG_INFO_LIST` 타입의 목록입니다. 목록의 각 항목은 `AQ$_REG_INFO` 타입이며 다음을 포함할 수 있습니다.

| 속성 | 타입 | 설명 |
| --- | --- | --- |
| `name` | VARCHAR2 (128) | 구독의 이름(선택적으로 스키마로 한정 가능)입니다. |
| `namespace` | NUMERIC | 지원되는 유일한 값은 `DBMS_AQ.NAMESPACE_AQ (0)`입니다. |
| `callback` | VARCHAR2 (4000) | 알림 시 수행할 작업을 기술합니다. 현재는 PL/SQL 프로시저에 대한 호출만 지원됩니다. 호출은 다음 형식을 취합니다.<br>`plsql://schema.procedure`<br>여기서:<br>schema는 프로시저가 위치한 스키마를 지정합니다.<br>procedure는 알림을 보낼 프로시저의 이름을 지정합니다. |
| `context` | RAW (16) | 프로시저가 요구하는 임의의 사용자 정의 값입니다. |

`count`

`count`는 `reg_list`의 항목 수입니다.

## 예제 (Example)

다음 익명 블록은 `DBMS_AQ.UNREGISTER`를 호출하여 `DBMS_AQ.REGISTER` 예제에서 지정한 알림을 비활성화합니다.

```sql
DECLARE
   subscription1 sys.aq$_reg_info;
   subscription2 sys.aq$_reg_info;
   subscription3 sys.aq$_reg_info;
   subscriptionlist sys.aq$_reg_info_list;
BEGIN
   subscription1 := sys.aq$_reg_info('q', DBMS_AQ.NAMESPACE_AQ,
'plsql://assign_worker?PR=0',HEXTORAW('FFFF'));
   subscription2 := sys.aq$_reg_info('q', DBMS_AQ.NAMESPACE_AQ,
'plsql://add_to_history?PR=1',HEXTORAW('FFFF'));
   subscription3 := sys.aq$_reg_info('q', DBMS_AQ.NAMESPACE_AQ,
'plsql://reserve_parts?PR=2',HEXTORAW('FFFF'));

   subscriptionlist := sys.aq$_reg_info_list(subscription1,
subscription2, subscription3);
   dbms_aq.unregister(subscriptionlist, 3);
   commit;
  END;
   /
```

`subscriptionlist`는 `sys.aq$_reg_info_list` 타입이며 `sys.aq$_reg_info` 객체들을 포함합니다. 목록 이름과 객체 개수가 `dbms_aq.unregister`에 전달됩니다.
