# START_QUEUE

큐를 인큐(enqueue) 및 디큐(dequeue)에 사용할 수 있게 하려면 `START_QUEUE` 프로시저를 사용합니다. 시그니처는 다음과 같습니다.

```sql
START_QUEUE(
  <queue_name> IN VARCHAR2,
  <enqueue> IN BOOLEAN DEFAULT TRUE,
  <dequeue> IN BOOLEAN DEFAULT TRUE)
```

## 매개변수 (Parameters)

`queue_name`

`queue_name`은 시작할 큐의 이름을 지정합니다.

`enqueue`

인큐를 활성화하려면 `TRUE`(기본값)를, 현재 설정을 변경하지 않고 그대로 두려면 `FALSE`를 지정합니다.

`dequeue`

디큐를 활성화하려면 `TRUE`(기본값)를, 현재 설정을 변경하지 않고 그대로 두려면 `FALSE`를 지정합니다.

## 예제 (Example)

다음 익명 블록은 `work_order`라는 이름의 큐를 인큐에 사용할 수 있게 합니다.

```sql
BEGIN
DBMS_AQADM.START_QUEUE
(queue_name => 'work_order);
END;
```
