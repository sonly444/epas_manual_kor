# DESCRIBE_COLUMNS — EPAS 18 내장 패키지 DBMS_SQL
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SQL › DESCRIBE_COLUMNS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/17_dbms_sql/11_describe_columns/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`DESCRIBE_COLUMNS` 프로시저는 커서가 반환하는 컬럼을 기술합니다.

```sql
DESCRIBE_COLUMNS(<c> NUMBER, <col_cnt> OUT NUMBER, <desc_t> OUT
  DESC_TAB);
```

## 파라미터 (Parameters)

`c`

커서의 커서 ID입니다.

`col_cnt`

커서 결과 집합의 컬럼 수입니다.

`desc_tab`

커서가 반환하는 각 컬럼의 설명을 포함하는 테이블입니다. 설명은 `DESC_REC` 타입이며 다음 값들을 포함합니다.

| Column name | Type |
| --- | --- |
| `col_type` | `INTEGER` |
| `col_max_len` | `INTEGER` |
| `col_name` | `VARCHAR2(128)` |
| `col_name_len` | `INTEGER` |
| `col_schema_name` | `VARCHAR2(128)` |
| `col_schema_name_len` | `INTEGER` |
| `col_precision` | `INTEGER` |
| `col_scale` | `INTEGER` |
| `col_charsetid` | `INTEGER` |
| `col_charsetform` | `INTEGER` |
| `col_null_ok` | `BOOLEAN` |
