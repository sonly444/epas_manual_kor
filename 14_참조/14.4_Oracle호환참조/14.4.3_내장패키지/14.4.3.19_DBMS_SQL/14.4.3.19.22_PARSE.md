# PARSE — EPAS 18 내장 패키지 DBMS_SQL
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SQL › PARSE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/17_dbms_sql/18_parse/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`PARSE` 프로시저는 SQL 명령 또는 SPL 블록을 파싱합니다. SQL 명령이 DDL 명령인 경우 즉시 실행되며 `EXECUTE` 함수를 실행할 필요가 없습니다.

```sql
PARSE(<c> NUMBER, <statement> VARCHAR2, <language_flag> NUMBER)
```

## 파라미터 (Parameters)

`c`

열려 있는 커서의 커서 ID입니다.

`statement`

파싱할 SQL 명령 또는 SPL 블록입니다. SQL 명령은 세미콜론 종결자로 끝나면 안 됩니다. 그러나 SPL 블록은 세미콜론 종결자가 필요합니다.

`language_flag`

Oracle 구문과의 호환성을 위해 제공되는 언어 플래그입니다. `DBMS_SQL.V6`, `DBMS_SQL.V7` 또는 `DBMS_SQL.native`를 사용합니다. 이 플래그는 무시되며, 모든 구문은 EDB Postgres Advanced Server 형식인 것으로 간주됩니다.

## 예제 (Example)

이 익명 블록은 `job`이라는 이름의 테이블을 생성합니다. DDL 문은 `PARSE` 프로시저에 의해 즉시 실행되며 별도의 `EXECUTE` 단계가 필요하지 않습니다.

```sql
DECLARE
    curid           NUMBER;
BEGIN
    curid := DBMS_SQL.OPEN_CURSOR;
    DBMS_SQL.PARSE(curid, 'CREATE TABLE job (jobno NUMBER(3), ' ||
        'jname VARCHAR2(9))',DBMS_SQL.native);
    DBMS_SQL.CLOSE_CURSOR(curid);
END;
```

다음은 `job` 테이블에 두 개의 행을 삽입합니다.

```sql
DECLARE
    curid           NUMBER;
    v_sql           VARCHAR2(50);
    v_status        INTEGER;
BEGIN
    curid := DBMS_SQL.OPEN_CURSOR;
    v_sql := 'INSERT INTO job VALUES (100, ''ANALYST'')';
    DBMS_SQL.PARSE(curid, v_sql, DBMS_SQL.native);
    v_status := DBMS_SQL.EXECUTE(curid);
    DBMS_OUTPUT.PUT_LINE('Number of rows processed: ' || v_status);
    v_sql := 'INSERT INTO job VALUES (200, ''CLERK'')';
    DBMS_SQL.PARSE(curid, v_sql, DBMS_SQL.native);
    v_status := DBMS_SQL.EXECUTE(curid);
    DBMS_OUTPUT.PUT_LINE('Number of rows processed: ' || v_status);
    DBMS_SQL.CLOSE_CURSOR(curid);
END;

Number of rows processed: 1

```

이 익명 블록은 `DBMS_SQL` 패키지를 사용하여 두 개의 `INSERT` 문을 포함하는 블록을 실행합니다. 블록의 끝에는 종결 세미콜론이 있습니다. 앞의 예제에서는 각 `INSERT` 문에 종결 세미콜론이 없습니다.

```sql
DECLARE
    curid           NUMBER;
    v_sql           VARCHAR2(100);
    v_status        INTEGER;
BEGIN
    curid := DBMS_SQL.OPEN_CURSOR;
    v_sql := 'BEGIN ' ||
               'INSERT INTO job VALUES (300, ''MANAGER''); '  ||
               'INSERT INTO job VALUES (400, ''SALESMAN''); ' ||
             'END;';
    DBMS_SQL.PARSE(curid, v_sql, DBMS_SQL.native);
    v_status := DBMS_SQL.EXECUTE(curid);
    DBMS_SQL.CLOSE_CURSOR(curid);
END;
```
