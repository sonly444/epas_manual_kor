# COLUMN_VALUE_RAW — EPAS 18 내장 패키지 DBMS_SQL
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SQL › COLUMN_VALUE_RAW](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/17_dbms_sql/07_column_value_raw/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`COLUMN_VALUE_RAW` 프로시저는 커서로부터 `RAW` 값을 받을 변수를 정의합니다.

```sql
COLUMN_VALUE_RAW(<c> NUMBER, <position> NUMBER, <value> OUT RAW
  [, <column_error> OUT NUMBER [, <actual_length> OUT INTEGER ]])
```

## 파라미터 (Parameters)

`c`

정의되는 변수로 데이터를 반환하는 커서의 커서 ID입니다.

`position`

커서에서 반환된 데이터의 위치입니다. 커서의 첫 번째 값은 위치 1입니다.

`value`

이전 fetch 호출에 의해 커서에서 반환된 데이터를 받는 `RAW` 데이터 타입의 변수입니다.

`column_error`

해당 컬럼과 관련된 오류 번호가 있는 경우 그 번호입니다.

`actual_length`

잘라내기(truncation)가 발생하기 전 데이터의 실제 길이입니다.

## COLUMN_VALUE_LONG

`COLUMN_VALUE_LONG` 프로시저는 `LONG` 컬럼 값의 일부를 반환합니다.

```sql
COLUMN_VALUE_LONG(<c> NUMBER, <position> NUMBER, <length> NUMBER,
<offset> NUMBER, <value> OUT VARCHAR2, <value_length> OUT INTEGER)
```

### 파라미터 (Parameters)

`c`

값을 가져올 커서의 커서 ID입니다.

`position`

값을 가져올 컬럼의 위치입니다.

`length`

가져올 long 값의 바이트 수입니다.

`offset`

가져오기를 시작할 long 필드 내의 오프셋입니다.

`value`

컬럼의 값입니다.

`value_length`

value로 반환된 바이트 수입니다.

예제는 DEFINE_COLUMN_LONG을 참조하십시오.
