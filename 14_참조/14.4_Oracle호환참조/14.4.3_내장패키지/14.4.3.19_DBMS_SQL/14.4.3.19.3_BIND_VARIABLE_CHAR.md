# BIND_VARIABLE_CHAR — EPAS 18 내장 패키지 DBMS_SQL
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SQL › BIND_VARIABLE_CHAR](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/17_dbms_sql/02_bind_variable_char/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`BIND_VARIABLE_CHAR` 프로시저는 SQL 명령의 `IN` 또는 `IN OUT` 바인드 변수에 `CHAR` 값을 연결합니다.

```sql
BIND_VARIABLE_CHAR(<c> NUMBER, <name> VARCHAR2, <value> CHAR
  [, <out_value_size> NUMBER ])
```

## 파라미터 (Parameters)

`c`

바인드 변수가 있는 SQL 명령에 대한 커서의 커서 ID입니다.

`name`

SQL 명령 내 바인드 변수의 이름입니다.

`value`

할당할 `CHAR` 타입의 값입니다.

`out_value_size`

`name`이 `IN OUT` 변수인 경우, 출력 값의 최대 길이를 정의합니다. 지정하지 않으면 `value`의 길이가 사용됩니다.
