# TO_CURSOR_NUMBER — EPAS 18 내장 패키지 DBMS_SQL
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SQL › TO_CURSOR_NUMBER](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/17_dbms_sql/19_to_cursor_number/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`TO_CURSOR_NUMBER` 함수는 ref cursor를 SQL 커서 번호로 변환합니다.

이 함수는 반환 구조를 알 수 없는 SYS_REFCURSOR 변수를 가지고 있을 때, ref cursor로부터 메타데이터(컬럼, 컬럼 타입 등)를 검색하는 데 유용합니다.

```sql
TO_CURSOR_NUMBER (<rc> IN OUT SYS_REFCURSOR)
    RETURN INTEGER;
```

## 파라미터 (Parameters)

`rc`

커서 번호로 변환할 ref cursor입니다.

## 예제 (Example)

```sql
DECLARE
    cur1        SYS_REFCURSOR;
    cur_id      INTEGER;
    tbl_desc    test_tbl%ROWTYPE;
    totcols     INTEGER;
    ret         INTEGER;
    rowcnt      NUMBER;
    col1_data   VARCHAR(30);
    col2_data   VARCHAR(30);
BEGIN
    OPEN cur1 FOR 'SELECT * FROM test_tbl_tbl';
    cur_id:= dbms_sql.to_cursor_number(cur1);

    dbms_sql.define_column(cur_id, 1, tbl_desc.col1);
    dbms_sql.define_column(cur_id, 2, tbl_desc.col2);

    LOOP
      ret := dbms_sql.FETCH_ROWS(cur_id);
      EXIT WHEN ret = 0;
      dbms_sql.column_value(cur_id, 1, tbl_desc.col1);
      dbms_sql.column_value(cur_id, 2, tbl_desc.col2);
      dbms_output.put_line('Col1: ' || tbl_desc.col1 || ' Col2: ' || tbl_desc.col2);
    END LOOP;
END;
```
