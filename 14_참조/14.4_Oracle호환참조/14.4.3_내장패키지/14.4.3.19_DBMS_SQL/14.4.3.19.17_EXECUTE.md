# EXECUTE — EPAS 18 내장 패키지 DBMS_SQL
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SQL › EXECUTE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/17_dbms_sql/12_execute/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`EXECUTE` 함수는 파싱된 SQL 명령 또는 SPL 블록을 실행합니다.

```sql
<status> INTEGER EXECUTE(<c> NUMBER)
```

## 파라미터 (Parameters)

`c`

실행할 파싱된 SQL 명령 또는 SPL 블록의 커서 ID입니다.

`status`

SQL 명령이 `DELETE`, `INSERT`, `UPDATE`인 경우 처리된 행의 수입니다. 그 외 모든 명령에 대해서는 `status`가 의미를 갖지 않습니다.

## 예제 (Example)

다음 익명 블록은 `dept` 테이블에 행을 삽입합니다.

```sql
DECLARE
    curid           NUMBER;
    v_sql           VARCHAR2(50);
    v_status        INTEGER;
BEGIN
    curid := DBMS_SQL.OPEN_CURSOR;
    v_sql := 'INSERT INTO dept VALUES (50, ''HR'', ''LOS ANGELES'')';
    DBMS_SQL.PARSE(curid, v_sql, DBMS_SQL.native);
    v_status := DBMS_SQL.EXECUTE(curid);
    DBMS_OUTPUT.PUT_LINE('Number of rows processed: ' || v_status);
    DBMS_SQL.CLOSE_CURSOR(curid);
END;
```
