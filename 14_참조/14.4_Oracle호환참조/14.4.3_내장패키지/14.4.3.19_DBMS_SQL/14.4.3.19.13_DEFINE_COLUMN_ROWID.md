# DEFINE_COLUMN_ROWID — EPAS 18 내장 패키지 DBMS_SQL
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SQL › DEFINE_COLUMN_ROWID](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/17_dbms_sql/10b_define_column_rowid/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`DEFINE_COLUMN_ROWID` 프로시저는 커서에서 반환 및 검색될 `SELECT` 목록의 `ROWID` 타입 컬럼을 정의합니다.

##### 참고 (Note)

EDB Postgres Advanced Server에서 `ROWID`는 bigint가 아니라 도메인(domain)입니다.

이 프로시저를 사용할 때, 정의하는 컬럼은 지정된 커서 내 문의 SELECT 목록에서 해당 컬럼의 상대적 위치로 식별됩니다. COLUMN 값 타입이 정의되는 컬럼의 타입을 결정합니다.

```sql
DEFINE_COLUMN_ROWID(<c> IN NUMBER, <position> IN NUMBER, <column> IN NUMBER);
```

## 파라미터 (Parameters)

`c`

행이 선택되는 커서의 커서 ID입니다.

`position`

정의되는 행 내 컬럼의 상대적 위치입니다. 문의 첫 번째 컬럼은 위치 1입니다.

`column`

컬럼의 값입니다. 이 값의 타입이 정의되는 컬럼의 타입을 결정합니다.

### 예제 (Example)

이 예제는 `emp` 테이블의 `empno`, `ename`, `hiredate`, `sal`, `comm` 컬럼을 `DEFINE_COLUMN_ROWID` 프로시저로 정의하는 방법을 보여 줍니다.

```sql
DECLARE
    curid           NUMBER;
    v_rid           ROWID;
    v_empno         NUMBER(4);
    v_ename         VARCHAR2(10);
    v_hiredate      DATE;
    v_sal           NUMBER(7,2);
    v_comm          NUMBER(7,2);
    v_sql           VARCHAR2(55) := 'SELECT rid, empno, ename, hiredate, sal, ' ||
                                    'comm FROM emp';
    v_status        INTEGER;
BEGIN
    curid := DBMS_SQL.OPEN_CURSOR;
    DBMS_SQL.PARSE(curid,v_sql,DBMS_SQL.native);
    DBMS_SQL.DEFINE_COLUMN_rowid(curid,1, v_rid);
    DBMS_SQL.DEFINE_COLUMN(curid,2,v_empno);
    DBMS_SQL.DEFINE_COLUMN(curid,3,v_ename,10);
    DBMS_SQL.DEFINE_COLUMN(curid,4,v_hiredate);
    DBMS_SQL.DEFINE_COLUMN(curid,5,v_sal);
    DBMS_SQL.DEFINE_COLUMN(curid,6,v_comm);
    v_status := DBMS_SQL.EXECUTE(curid);
LOOP
        v_status := DBMS_SQL.FETCH_ROWS(curid);
EXIT WHEN v_status = 0;
    DBMS_SQL.COLUMN_VALUE_rowid(curid, 1, v_rid);
        DBMS_SQL.COLUMN_VALUE(curid,2,v_empno);
DBMS_SQL.COLUMN_VALUE(curid,3,v_ename);
DBMS_SQL.COLUMN_VALUE(curid,4,v_hiredate);
DBMS_SQL.COLUMN_VALUE(curid,5,v_sal);
DBMS_SQL.COLUMN_VALUE(curid,6,v_comm);
DBMS_OUTPUT.PUT_LINE(v_rid || ' ' || v_empno || ' ' ||v_ename|| ' ' ||
            TO_CHAR(v_hiredate,'yyyy-mm-dd') || ' ' ||
            TO_CHAR(v_sal,'9,999.99') || ' ' ||
            TO_CHAR(NVL(v_comm,0),'9,999.99'));
END LOOP;
    DBMS_SQL.CLOSE_CURSOR(curid);
END;
```
