# ENQUOTE_NAME — EPAS 18 내장 패키지 DBMS_ASSERT

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_ASSERT › ENQUOTE_NAME](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/01a_dbms_assert/enquote_name/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`ENQUOTE_NAME` 함수는 입력값이 이미 큰따옴표로 둘러싸여 있지 않은 경우 해당 문자열을 큰따옴표로 감쌉니다. 문자열 안에 있는 모든 큰따옴표에는 큰따옴표가 하나씩 덧붙여집니다.

다음 표는 따옴표가 어떻게 처리되는지에 대한 예시를 보여줍니다.

| 입력 | `dolower` 매개변수 | 출력 |
| --- | --- | --- |
| ab"c | TRUE | "ab""c" |
| "abc" | TRUE | "abc" |
| "a"bc" | TRUE | "a""bc" |
| ABC | TRUE | "abc" |
| ABC | FALSE | "ABC" |
| aBc | TRUE | "abc" |
| aBc | FALSE | "aBc" |

```sql
ENQUOTE_NAME(str VARCHAR2, dolower boolean := TRUE) RETURN VARCHAR2;
```

## 매개변수 (Parameters)

`str`

큰따옴표로 감쌀 문자열입니다.

`dolower`

선택 사항입니다. TRUE인 경우, 입력 문자열에서 큰따옴표로 둘러싸이지 않은 알파벳 문자는 소문자로 변환됩니다. FALSE인 경우, 입력 문자열은 소문자로 변환되지 않습니다.

기본값은 TRUE입니다. 따옴표로 둘러싸이지 않은 입력값은 소문자로 변환됩니다.

## 예제 (Examples)

```sql
edb=# SELECT SYS.DBMS_ASSERT.ENQUOTE_NAME('  ""ObjectName  ') FROM DUAL;
     enquote_name
----------------------
 "  """"objectname  "
(1 row)

edb=# SELECT 'test' || SYS.DBMS_ASSERT.ENQUOTE_NAME('  "ObjectName"  ') || 'test' FROM dual;
         ?column?
--------------------------
 test  "ObjectName"  test
(1 row)

edb=# EXEC DBMS_OUTPUT.put_line(SYS.DBMS_ASSERT.ENQUOTE_NAME('"REMAIN QUOTED and SAME CASE"'));
"REMAIN QUOTED and SAME CASE"
```
