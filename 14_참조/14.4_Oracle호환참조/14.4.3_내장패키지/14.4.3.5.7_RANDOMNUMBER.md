# RANDOMNUMBER

`RANDOMNUMBER()` 함수는 `0`부터 `2^128-1`사이의 무작위 숫자를 반환합니다. 즉 반환 범위는 `0`부터 `340,282,366,920,938,463,463,374,607,431,768,211,455`까지입니다. 시그니처는 다음과 같습니다.

```sql
RANDOMNUMBER() RETURNS NUMBER
```

## 예제 (Examples)

이 예제는 `RANDOMNUMBER` 함수를 사용하여 암호학적으로 강력한 무작위 숫자를 반환합니다.

```sql
DECLARE
  result NUMBER;
BEGIN
  result := DBMS_CRYPTO.RANDOMNUMBER();
  DBMS_OUTPUT.PUT_LINE(result);
END;
```
