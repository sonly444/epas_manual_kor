> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

# MAC

`MAC` 함수는 사용자가 지정한 `MAC` 함수를 사용하여 `RAW` 또는 `CLOB` 값의 해시된 `MAC` 값을 반환합니다. `MAC` 함수는 세 가지 형태로 제공됩니다.

```sql
MAC
  (<src> IN RAW, <typ> IN INTEGER, <key> IN RAW) RETURN RAW

MAC
  (<src> IN CLOB, <typ> IN INTEGER, <key> IN RAW) RETURN RAW
```

## 매개변수 (Parameters)

`src`

`src`는 `MAC` 값이 생성될 값을 지정합니다. `RAW`, `BLOB`, 또는 `CLOB` 값을 지정합니다.

`typ`

`typ`는 사용되는 `MAC` 함수를 지정합니다. EDB Postgres Advanced Server는 표에 표시된 `MAC` 함수를 지원합니다.

| MAC 함수 |  |
| --- | --- |
| `HMAC_MD5` | `CONSTANT INTEGER := 1;` |
| `HMAC_SH1` | `CONSTANT INTEGER := 2;` |

`key`

`key`는 해시된 `MAC` 값을 계산하는 데 사용되는 키를 지정합니다.

## 예제 (Examples)

이 예제는 문자열 `cleartext source`의 해시된 `MAC` 값을 찾습니다.

```sql
DECLARE
  typ INTEGER := DBMS_CRYPTO.HMAC_MD5;
  key RAW(100) := 'my secret key';
  mac_value RAW(100);
BEGIN

  mac_value := DBMS_CRYPTO.MAC('cleartext source', typ, key);

END;
```

`DBMS_CRYPTO.MAC`는 `cleartext source`의 `MAC` 값을 계산할 때 `my secret key`라는 키 값을 사용합니다.
