# RANDOMBYTES

`RANDOMBYTES` 함수는 암호학적으로 무작위인 바이트를 포함하는, 지정된 길이의 `RAW` 값을 반환합니다. 시그니처는 다음과 같습니다.

```sql
RANDOMBYTES
  (<number_bytes> IN INTEGER) RETURNS RAW
```

## 매개변수 (Parameter)

`number_bytes`

`number_bytes`는 반환할 무작위 바이트 수를 지정합니다.

## 예제 (Examples)

이 예제는 `RANDOMBYTES`를 사용하여 1024바이트 길이의 값을 반환합니다.

```sql
DECLARE
  result RAW(1024);
BEGIN
  result := DBMS_CRYPTO.RANDOMBYTES(1024);
END;
```
