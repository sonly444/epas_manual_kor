# PURGE_QUEUE_TABLE

큐 테이블에서 메시지를 삭제하려면 `PURGE_QUEUE_TABLE` 프로시저를 사용합니다. 시그니처는 다음과 같습니다.

```sql
PURGE_QUEUE_TABLE(
  <queue_table> IN VARCHAR2,
  <purge_condition> IN VARCHAR2,
  <purge_options> IN aq$_purge_options_t)
```

## 매개변수 (Parameters)

`queue_table`

`queue_table`은 메시지를 삭제할 큐 테이블의 이름을 지정합니다.

`purge_condition`

`purge_condition`을 사용하여 서버가 어떤 메시지를 제거할지 결정할 때 평가하는 조건(SQL `WHERE` 절)을 지정합니다.

`purge_options`

`purge_options`는 `aq$_purge_options_t` 유형의 객체입니다. `aq$_purge_options_t` 객체는 다음을 포함합니다.

| 속성 | 유형 | 설명 |
| --- | --- | --- |
| `block` | Boolean | 테이블의 모든 큐에 배타적 잠금(exclusive lock)을 유지하려면 `TRUE`를 지정합니다. 기본값은 `FALSE`입니다. |
| `delivery_mode` | INTEGER | `delivery_mode`는 제거할 메시지의 유형을 지정합니다. 허용되는 유일한 값은 `DBMS_AQ.PERSISTENT`입니다. |

## 예제 (Example)

다음 익명 블록은 `completed` 열의 값이 `YES`인 모든 메시지를 `work_order_table`에서 제거합니다.

```sql
DECLARE
   purge_options dbms_aqadm.aq$_purge_options_t;
BEGIN
   dbms_aqadm.purge_queue_table('work_order_table', 'completed = YES',
purge_options);
  END;
```
