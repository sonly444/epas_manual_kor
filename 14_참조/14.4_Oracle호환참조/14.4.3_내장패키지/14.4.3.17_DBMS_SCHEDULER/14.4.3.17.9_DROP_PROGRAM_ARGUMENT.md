# DROP_PROGRAM_ARGUMENT — EPAS 18 내장 패키지 DBMS_SCHEDULER
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SCHEDULER › DROP_PROGRAM_ARGUMENT](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/15_dbms_scheduler/09_drop_program_argument/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`DROP_PROGRAM_ARGUMENT` 프로시저를 사용하여 프로그램 인수를 삭제합니다. `DROP_PROGRAM_ARGUMENT` 프로시저는 두 가지 형식으로 제공됩니다. 첫 번째 형식은 인수 위치를 사용하여 삭제할 인수를 지정합니다.

```sql
DROP_PROGRAM_ARGUMENT(
  <program_name> IN VARCHAR2,
  <argument_position> IN PLS_INTEGER)
```

두 번째 형식은 인수 이름을 사용합니다.

```sql
DROP_PROGRAM_ARGUMENT(
  <program_name> IN VARCHAR2,
  <argument_name> IN VARCHAR2)
```

## 파라미터 (Parameters)

`program_name`

`program_name`은 수정되는 프로그램의 이름을 지정합니다.

`argument_position`

`argument_position`은 삭제되는 인수의 위치를 지정합니다.

`argument_name`

`argument_name`은 삭제되는 인수의 이름을 지정합니다.

## 예제 (Example)

다음 `DROP_PROGRAM_ARGUMENT` 호출은 `update_emp` 프로그램의 첫 번째 인수를 삭제합니다.

```sql
DBMS_SCHEDULER.DROP_PROGRAM_ARGUMENT('update_emp', 1);
```

다음 `DROP_PROGRAM_ARGUMENT` 호출은 `emp_name`이라는 인수를 삭제합니다.

```sql
DBMS_SCHEDULER.DROP_PROGRAM_ARGUMENT(update_emp', 'emp_name');
```
