# SET_JOB_ARGUMENT_VALUE — EPAS 18 내장 패키지 DBMS_SCHEDULER
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SCHEDULER › SET_JOB_ARGUMENT_VALUE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/15_dbms_scheduler/14_set_job_argument_value/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`SET_JOB_ARGUMENT_VALUE` 프로시저를 사용하여 인수의 값을 지정합니다. `SET_JOB_ARGUMENT_VALUE` 프로시저는 두 가지 형식으로 제공됩니다. 첫 번째 형식은 수정할 인수를 위치로 지정합니다.

```sql
SET_JOB_ARGUMENT_VALUE(
  <job_name> IN VARCHAR2,
  <argument_position> IN PLS_INTEGER,
  <argument_value> IN VARCHAR2)
```

두 번째 형식은 인수 이름을 사용하여 수정할 인수를 지정합니다.

```sql
SET_JOB_ARGUMENT_VALUE(
  <job_name> IN VARCHAR2,
  <argument_name> IN VARCHAR2,
  <argument_value> IN VARCHAR2)
```

`SET_JOB_ARGUMENT_VALUE` 프로시저로 설정한 인수 값은 기본적으로 설정된 값을 재정의합니다.

## 파라미터 (Parameters)

`job_name`

`job_name`은 수정되는 인수가 속한 작업의 이름을 지정합니다.

`argument_position`

`argument_position`을 사용하여 값이 설정되는 인수 위치를 지정합니다.

`argument_name`

`argument_name`을 사용하여 값이 설정되는 인수를 이름으로 지정합니다.

`argument_value`

`argument_value`는 인수의 새 값을 지정합니다.

## 예제 (Example)

이 예제는 `update_emp` 작업의 첫 번째 인수에 값 `30`을 할당합니다.

```sql
DBMS_SCHEDULER.SET_JOB_ARGUMENT_VALUE('update_emp', 1, '30');
```

이 예제는 `emp_name` 인수를 `SMITH`로 설정합니다.

```sql
DBMS_SCHEDULER.SET_JOB_ARGUMENT_VALUE('update_emp', 'emp_name', 'SMITH');
```
