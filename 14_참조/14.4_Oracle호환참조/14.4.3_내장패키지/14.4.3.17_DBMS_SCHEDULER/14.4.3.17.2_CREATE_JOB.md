# CREATE_JOB — EPAS 18 내장 패키지 DBMS_SCHEDULER
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SCHEDULER › CREATE_JOB](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/15_dbms_scheduler/02_create_job/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`CREATE_JOB` 프로시저를 사용하여 작업을 생성합니다. 이 프로시저는 두 가지 형식으로 제공됩니다. 프로시저의 첫 번째 형식은 작업이 실행될 때 호출할 작업 액션과 함께 작업 정의 내에 스케줄을 지정합니다.

```sql
CREATE_JOB(
  <job_name> IN VARCHAR2,
  <job_type> IN VARCHAR2,
  <job_action> IN VARCHAR2,
  <number_of_arguments> IN PLS_INTEGER DEFAULT 0,
  <start_date> IN TIMESTAMP WITH TIME ZONE DEFAULT NULL,
  <repeat_interval> IN VARCHAR2 DEFAULT NULL,
  <end_date> IN TIMESTAMP WITH TIME ZONE DEFAULT NULL,
  <job_class> IN VARCHAR2 DEFAULT 'DEFAULT_JOB_CLASS',
  <enabled> IN BOOLEAN DEFAULT FALSE,
  <auto_drop> IN BOOLEAN DEFAULT TRUE,
  <comments> IN VARCHAR2 DEFAULT NULL)
```

두 번째 형식은 작업이 실행되는 스케줄을 지정하기 위해 작업 스케줄을 사용하며, 작업이 실행될 때 실행할 프로그램의 이름을 지정합니다.

```sql
CREATE_JOB(
  <job_name> IN VARCHAR2,
  <program_name> IN VARCHAR2,
  <schedule_name> IN VARCHAR2,
  <job_class> IN VARCHAR2 DEFAULT 'DEFAULT_JOB_CLASS',
  <enabled> IN BOOLEAN DEFAULT FALSE,
  <auto_drop> IN BOOLEAN DEFAULT TRUE,
  <comments> IN VARCHAR2 DEFAULT NULL)
```

## 파라미터 (Parameters)

`job_name`

`job_name`은 생성되는 작업의 이름을 지정하며, 선택적으로 스키마 한정(schema-qualified)이 가능합니다.

`job_type`

`job_type`은 작업의 유형을 지정합니다. 현재 구현된 `CREATE_JOB`은 `PLSQL_BLOCK` 또는 `STORED_PROCEDURE` 작업 유형을 지원합니다.

`job_action`

- `job_type`이 `PLSQL_BLOCK`인 경우, `job_action`은 작업이 실행될 때 호출할 PL/SQL 블록의 내용을 지정합니다. 이 블록은 세미콜론(;)으로 종료되어야 합니다.

- `job_type`이 `STORED_PROCEDURE`인 경우, `job_action`은 프로시저의 이름을 지정하며, 선택적으로 스키마 한정이 가능합니다.


`number_of_arguments`

`number_of_arguments`는 작업이 예상하는 인수의 개수를 지정하는 정수 값입니다. 기본값은 `0`입니다.

`start_date`

`start_date`는 작업이 처음 실행되도록 스케줄된 시각을 지정하는 `TIMESTAMP WITH TIME ZONE` 값입니다. 기본값은 `NULL`이며, 이는 작업이 활성화될 때 실행되도록 스케줄함을 나타냅니다.

`repeat_interval`

`repeat_interval`은 작업이 얼마나 자주 반복되는지 지정하는 `VARCHAR2` 값입니다. `repeat_interval`을 지정하지 않으면 작업은 한 번만 실행됩니다. 기본값은 `NULL`입니다.

`end_date`

`end_date`는 작업이 더 이상 실행되지 않는 시각을 지정하는 `TIMESTAMP WITH TIME ZONE` 값입니다. 날짜를 지정하는 경우 `end_date`는 `start_date`보다 이후여야 합니다. 기본값은 `NULL`입니다.

`end_date`를 지정하지 않고 `repeat_interval`을 지정하면 작업은 비활성화할 때까지 무기한 반복됩니다.

`program_name`

`program_name`은 작업이 실행할 프로그램의 이름입니다.

`schedule_name`

`schedule_name`은 작업과 연결된 스케줄의 이름입니다.

`job_class`

`job_class`는 호환성을 위해 허용되며 무시됩니다.

`enabled`

`enabled`는 작업이 생성될 때 활성화되는지 지정하는 Boolean 값입니다. 기본적으로 작업은 `enabled`가 `FALSE`로 설정된 비활성화 상태로 생성됩니다. 작업을 활성화하려면 작업을 생성할 때 값 `TRUE`를 지정하거나 `DBMS_SCHEDULER.ENABLE` 프로시저로 작업을 활성화합니다.

`auto_drop`

`auto_drop` 파라미터는 호환성을 위해 허용되며 무시됩니다. 기본적으로 작업의 상태는 `end_date`에 지정된 시각 이후 `DISABLED`로 변경됩니다.

`comments`

`comments` 파라미터를 사용하여 작업에 대한 주석을 지정합니다.

## 예제 (Example)

이 예제는 `CREATE_JOB` 프로시저 호출을 보여줍니다.

```sql
EXEC
  DBMS_SCHEDULER.CREATE_JOB (
    job_name        => 'update_log',
    job_type        => 'PLSQL_BLOCK',
    job_action      => 'BEGIN INSERT INTO my_log VALUES(current_timestamp);
                        END;',
    start_date      => '01-JUN-15 09:00:00.000000',
    repeat_interval => 'FREQ=DAILY;BYDAY=MON,TUE,WED,THU,FRI;BYHOUR=17;',
    end_date        => NULL,
    enabled         => TRUE,
    comments        => 'This job adds a row to the my_log table.');
```

이 코드 조각은 매 평일 저녁 5시에 실행되는 `update_log`라는 작업을 생성합니다. 이 작업은 현재 타임스탬프를 로그 파일(`my_log`)에 삽입하는 PL/SQL 블록을 실행합니다. `end_date`가 지정되지 않았으므로 작업은 `DBMS_SCHEDULER.DISABLE` 프로시저로 비활성화될 때까지 실행됩니다.
