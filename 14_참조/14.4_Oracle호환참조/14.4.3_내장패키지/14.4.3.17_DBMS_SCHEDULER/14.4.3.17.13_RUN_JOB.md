# RUN_JOB — EPAS 18 내장 패키지 DBMS_SCHEDULER
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SCHEDULER › RUN_JOB](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/15_dbms_scheduler/13_run_job/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`RUN_JOB` 프로시저를 사용하여 작업을 즉시 실행합니다. `RUN_JOB` 프로시저의 시그니처는 다음과 같습니다.

```sql
RUN_JOB(
  <job_name> IN VARCHAR2,
  <use_current_session> IN BOOLEAN DEFAULT TRUE
```

## 파라미터 (Parameters)

`job_name`

`job_name`은 실행할 작업의 이름을 지정합니다.

`use_current_session`

기본적으로 작업은 현재 세션에서 실행됩니다. 지정하는 경우 `use_current_session`은 `TRUE`로 설정되어야 합니다. `use_current_session`이 `FALSE`로 설정되면 EDB Postgres Advanced Server는 오류를 반환합니다.

## 예제 (Example)

다음 `RUN_JOB` 호출은 `update_log`라는 작업을 실행합니다.

```sql
DBMS_SCHEDULER.RUN_JOB('update_log', TRUE);
```

두 번째 인수로 값 `TRUE`를 전달하면 서버가 현재 세션에서 작업을 호출하도록 지시합니다.
