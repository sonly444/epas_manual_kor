# CREATE_SCHEDULE — EPAS 18 내장 패키지 DBMS_SCHEDULER
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SCHEDULER › CREATE_SCHEDULE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/15_dbms_scheduler/04_create_schedule/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`CREATE_SCHEDULE` 프로시저를 사용하여 작업 스케줄을 생성합니다. `CREATE_SCHEDULE` 프로시저의 시그니처는 다음과 같습니다.

```sql
CREATE_SCHEDULE(
  <schedule_name> IN VARCHAR2,
  <start_date> IN TIMESTAMP WITH TIME ZONE DEFAULT NULL,
  <repeat_interval> IN VARCHAR2,
  <end_date> IN TIMESTAMP WITH TIME ZONE DEFAULT NULL,
  <comments> IN VARCHAR2 DEFAULT NULL)
```

## 파라미터 (Parameters)

`schedule_name`

`schedule_name`은 스케줄의 이름을 지정합니다.

`start_date`

`start_date`는 스케줄이 실행 가능해지는 날짜와 시각을 지정하는 `TIMESTAMP WITH TIME ZONE` 값입니다. `start_date`를 지정하지 않으면 작업이 활성화된 날짜가 `start_date`로 사용됩니다. 기본적으로 `start_date`는 `NULL`입니다.

`repeat_interval`

`repeat_interval`은 작업이 얼마나 자주 반복되는지 지정하는 `VARCHAR2` 값입니다. `repeat_interval`을 지정하지 않으면 작업은 `start_date`로 지정된 날짜에 한 번만 실행됩니다.

##### 참고 (Note)
`start_date` 또는 `repeat_interval` 중 하나에는 반드시 값을 제공해야 합니다. `start_date`와 `repeat_interval`이 모두 `NULL`이면 서버는 오류를 반환합니다.

`end_date`

`end_date`는 스케줄이 더 이상 실행되지 않는 시각을 지정하는 `TIMESTAMP WITH TIME ZONE` 값입니다. 날짜를 지정하는 경우 `end_date`는 `start_date`보다 이후여야 합니다. 기본값은 `NULL`입니다.

##### 참고 (Note)
`repeat_interval`을 지정하고 `end_date`를 지정하지 않으면 스케줄은 비활성화할 때까지 무기한 반복됩니다.

`comments`

`comments` 파라미터를 사용하여 스케줄에 대한 주석을 지정합니다. 기본적으로 이 파라미터는 `NULL`입니다.

## 예제 (Example)

이 코드 조각은 `CREATE_SCHEDULE`을 호출하여 `weeknights_at_5`라는 스케줄을 생성합니다.

```sql
EXEC
  DBMS_SCHEDULER.CREATE_SCHEDULE (
    schedule_name    => 'weeknights_at_5',
    start_date       => '01-JUN-13 09:00:00.000000',
    repeat_interval  => 'FREQ=DAILY;BYDAY=MON,TUE,WED,THU,FRI;BYHOUR=17;',
    comments         => 'This schedule executes each weeknight at 5:00');
```

이 스케줄은 2013년 6월 1일 이후부터 유효하며 매 평일 저녁 5시에 실행됩니다. `end_date`가 지정되지 않았으므로 스케줄은 `DBMS_SCHEDULER.DISABLE`로 비활성화될 때까지 무기한 실행됩니다.
