# DROP_PROGRAM — EPAS 18 내장 패키지 DBMS_SCHEDULER
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SCHEDULER › DROP_PROGRAM](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/15_dbms_scheduler/08_drop_program/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`DROP_PROGRAM` 프로시저는 프로그램을 삭제합니다. `DROP_PROGRAM` 프로시저의 시그니처는 다음과 같습니다.

```sql
DROP_PROGRAM(
  <program_name> IN VARCHAR2,
  <force> IN BOOLEAN DEFAULT FALSE)
```

## 파라미터 (Parameters)

`program_name`

`program_name`은 삭제되는 프로그램의 이름을 지정합니다.

`force`

`force`는 종속 작업이 있는 프로그램을 서버가 어떻게 처리할지 알려주는 Boolean 값입니다.

- 프로그램이 작업에 의해 참조되는 경우 오류를 반환하려면 `FALSE`를 지정합니다.

- 프로그램을 삭제하기 전에 해당 프로그램을 참조하는 작업을 비활성화하려면 `TRUE`를 지정합니다.

기본값은 `FALSE`입니다.


## 예제 (Example)

다음 `DROP_PROGRAM` 호출은 `update_emp`라는 작업을 삭제합니다.

```sql
DBMS_SCHEDULER.DROP_PROGRAM('update_emp');
```
