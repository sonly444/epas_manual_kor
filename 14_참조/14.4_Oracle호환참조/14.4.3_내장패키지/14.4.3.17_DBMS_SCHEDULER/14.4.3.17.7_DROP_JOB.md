# DROP_JOB — EPAS 18 내장 패키지 DBMS_SCHEDULER
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SCHEDULER › DROP_JOB](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/15_dbms_scheduler/07_drop_job/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`DROP_JOB` 프로시저를 사용하여 작업을 삭제하고, 작업에 속한 모든 인수를 삭제하며, 향후 작업 실행을 제거합니다. 프로시저의 시그니처는 다음과 같습니다.

```sql
DROP_JOB(
  <job_name> IN VARCHAR2,
  <force> IN BOOLEAN DEFAULT FALSE,
  <defer> IN BOOLEAN DEFAULT FALSE,
  <commit_semantics> IN VARCHAR2 DEFAULT 'STOP_ON_FIRST_ERROR')
```

## 파라미터 (Parameters)

`job_name`

`job_name`은 삭제되는 작업의 이름을 지정합니다.

`force`

`force`는 호환성을 위해 허용되며 무시됩니다.

`defer`

`defer`는 호환성을 위해 허용되며 무시됩니다.

`commit_semantics`

`commit_semantics`는 프로그램 또는 작업을 삭제하는 동안 발생한 오류를 서버가 어떻게 처리할지 알려줍니다. 기본적으로 `commit_semantics`는 `STOP_ON_FIRST_ERROR`로 설정되며, 이는 오류가 발생하면 중지함을 의미합니다.

`TRANSACTIONAL` 및 `ABSORB_ERRORS` 키워드는 호환성을 위해 허용되며 무시됩니다.

## 예제 (Example)

다음 `DROP_JOB` 호출은 `update_log`라는 작업을 삭제합니다.

```sql
DBMS_SCHEDULER.DROP_JOB('update_log');
```
