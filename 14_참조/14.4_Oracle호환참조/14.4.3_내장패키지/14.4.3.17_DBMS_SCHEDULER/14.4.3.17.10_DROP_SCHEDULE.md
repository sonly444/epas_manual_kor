# DROP_SCHEDULE — EPAS 18 내장 패키지 DBMS_SCHEDULER
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SCHEDULER › DROP_SCHEDULE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/15_dbms_scheduler/10_drop_schedule/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`DROP_SCHEDULE` 프로시저를 사용하여 스케줄을 삭제합니다. 시그니처는 다음과 같습니다.

```sql
DROP_SCHEDULE(
  <schedule_name> IN VARCHAR2,
  <force> IN BOOLEAN DEFAULT FALSE)
```

## 파라미터 (Parameters)

`schedule_name`

`schedule_name`은 삭제되는 스케줄의 이름을 지정합니다.

`force`

`force`는 지정한 스케줄이 어떤 작업에 의해 참조되는 경우 서버의 동작을 지정합니다.

- 지정한 스케줄이 작업에 의해 참조되는 경우 오류를 반환하려면 `FALSE`를 지정합니다. 이것이 기본 동작입니다.
- 스케줄을 삭제하기 전에 지정한 스케줄을 사용하는 작업을 비활성화하려면 `TRUE`를 지정합니다. 실행 중인 작업은 스케줄이 삭제되기 전에 완료되도록 허용됩니다.

## 예제 (Example)

다음 `DROP_SCHEDULE` 호출은 `weeknights_at_5`라는 스케줄을 삭제합니다.

```sql
DBMS_SCHEDULER.DROP_SCHEDULE('weeknights_at_5', TRUE);
```

서버는 스케줄을 삭제하기 전에 해당 스케줄을 사용하는 작업을 비활성화합니다.
