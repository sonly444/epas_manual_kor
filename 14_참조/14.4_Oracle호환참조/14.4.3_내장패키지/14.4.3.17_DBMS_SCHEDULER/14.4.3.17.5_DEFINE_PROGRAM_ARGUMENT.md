# DEFINE_PROGRAM_ARGUMENT — EPAS 18 내장 패키지 DBMS_SCHEDULER
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SCHEDULER › DEFINE_PROGRAM_ARGUMENT](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/15_dbms_scheduler/05_define_program_argument/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`DEFINE_PROGRAM_ARGUMENT` 프로시저를 사용하여 프로그램 인수를 정의합니다. `DEFINE_PROGRAM_ARGUMENT` 프로시저는 두 가지 형식으로 제공됩니다. 첫 번째 형식은 기본값이 있는 인수를 정의합니다.

```sql
DEFINE_PROGRAM_ARGUMENT(
  <program_name> IN VARCHAR2,
  <argument_position> IN PLS_INTEGER,
  <argument_name> IN VARCHAR2 DEFAULT NULL,
  <argument_type> IN VARCHAR2,
  <default_value> IN VARCHAR2,
  <out_argument> IN BOOLEAN DEFAULT FALSE)
```

두 번째 형식은 기본값이 없는 인수를 정의합니다.

```sql
DEFINE_PROGRAM_ARGUMENT(
  <program_name> IN VARCHAR2,
  <argument_position> IN PLS_INTEGER,
  <argument_name> IN VARCHAR2 DEFAULT NULL,
  <argument_type> IN VARCHAR2,
  <out_argument> IN BOOLEAN DEFAULT FALSE)
```

## 파라미터 (Parameters)

`program_name`

`program_name`은 인수가 속한 프로그램의 이름입니다.

`argument_position`

`argument_position`은 프로그램에 전달될 때 인수의 위치를 지정합니다.

`argument_name`

`argument_name`은 인수의 선택적 이름을 지정합니다. 기본적으로 `argument_name`은 `NULL`입니다.

`argument_type IN VARCHAR2`

`argument_type`은 인수의 데이터 유형을 지정합니다.

`default_value`

`default_value`는 인수에 할당되는 기본값을 지정합니다. `default_value`는 작업이 실행될 때 작업이 지정한 값으로 재정의됩니다.

`out_argument IN BOOLEAN DEFAULT FALSE`

`out_argument`는 현재 사용되지 않습니다. 지정하는 경우 값은 `FALSE`여야 합니다.

## 예제 (Example)

이 코드 조각은 `DEFINE_PROGRAM_ARGUMENT` 프로시저를 사용하여 `add_emp`라는 프로그램의 첫 번째와 두 번째 인수를 정의합니다.

```sql
EXEC
  DBMS_SCHEDULER.DEFINE_PROGRAM_ARGUMENT(
    program_name         => 'add_emp',
    argument_position    => 1,
    argument_name        => 'dept_no',
    argument_type        => 'INTEGER,
    default_value        => '20');
EXEC
  DBMS_SCHEDULER.DEFINE_PROGRAM_ARGUMENT(
    program_name         => 'add_emp',
    argument_position    => 2,
    argument_name        => 'emp_name',
    argument_type        => 'VARCHAR2');
```

첫 번째 인수는 기본값이 `20`인 `dept_no`라는 `INTEGER` 값입니다. 두 번째 인수는 `emp_name`이라는 `VARCHAR2` 값이며 기본값이 없습니다.
