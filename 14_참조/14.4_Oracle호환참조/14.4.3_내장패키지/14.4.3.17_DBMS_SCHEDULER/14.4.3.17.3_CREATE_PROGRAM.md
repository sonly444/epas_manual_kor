# CREATE_PROGRAM — EPAS 18 내장 패키지 DBMS_SCHEDULER
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_SCHEDULER › CREATE_PROGRAM](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/15_dbms_scheduler/03_create_program/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`CREATE_PROGRAM` 프로시저를 사용하여 `DBMS_SCHEDULER` 프로그램을 생성합니다. 시그니처는 다음과 같습니다.

```sql
CREATE_PROGRAM(
  <program_name> IN VARCHAR2,
  <program_type> IN VARCHAR2,
  <program_action> IN VARCHAR2,
  <number_of_arguments> IN PLS_INTEGER DEFAULT 0,
  <enabled> IN BOOLEAN DEFAULT FALSE,
  <comments> IN VARCHAR2 DEFAULT NULL)
```

## 파라미터 (Parameters)

`program_name`

`program_name`은 생성되는 프로그램의 이름을 지정합니다.

`program_type`

`program_type`은 프로그램의 유형을 지정합니다. 현재 구현된 `CREATE_PROGRAM`은 `PLSQL_BLOCK` 또는 `PROCEDURE`의 `program_type`을 지원합니다.

`program_action`

- `program_type`이 `PLSQL_BLOCK`인 경우, `program_action`은 프로그램이 호출될 때 실행되는 PL/SQL 블록을 포함합니다. PL/SQL 블록은 세미콜론(;)으로 종료되어야 합니다.

- `program_type`이 `PROCEDURE`인 경우, `program_action`은 저장 프로시저의 이름을 포함합니다.


`number_of_arguments`

- `program_type`이 `PLSQL_BLOCK`인 경우, 이 인수는 무시됩니다.

- `program_type`이 `PROCEDURE`인 경우, `number_of_arguments`는 프로시저에 필요한 인수의 개수를 지정합니다. 기본값은 `0`입니다.


`enabled`

`enabled`는 프로그램이 활성화 상태로 생성되는지 비활성화 상태로 생성되는지 지정합니다.

- `enabled`가 `TRUE`이면 프로그램은 활성화 상태로 생성됩니다.

- `enabled`가 `FALSE`이면 프로그램은 비활성화 상태로 생성됩니다. 비활성화된 프로그램을 활성화하려면 `DBMS_SCHEDULER.ENABLE` 프로그램을 사용합니다.

기본값은 `FALSE`입니다.


`comments`

`comments` 파라미터를 사용하여 프로그램에 대한 주석을 지정합니다. 기본적으로 이 파라미터는 `NULL`입니다.

## 예제 (Example)

다음 `CREATE_PROGRAM` 프로시저 호출은 `update_log`라는 프로그램을 생성합니다.

```sql
EXEC
  DBMS_SCHEDULER.CREATE_PROGRAM (
    program_name     => 'update_log',
    program_type     => 'PLSQL_BLOCK',
    program_action   => 'BEGIN INSERT INTO my_log VALUES(current_timestamp);
                         END;',
    enabled          => TRUE,
    comments         => 'This program adds a row to the my_log table.');
```

`update_log`는 현재 날짜와 시각을 포함하는 행을 `my_log` 테이블에 추가하는 PL/SQL 블록입니다. 프로그램은 `CREATE_PROGRAM` 프로시저가 실행될 때 활성화됩니다.
