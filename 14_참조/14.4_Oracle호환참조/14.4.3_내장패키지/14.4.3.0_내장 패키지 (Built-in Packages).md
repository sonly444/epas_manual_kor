# 내장 패키지 (Built-in Packages) — 인덱스 — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle compatibility reference › Built-in packages](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/)
> ⚠️ 이 페이지는 **인덱스(전체 목록)** 입니다. 각 패키지는 프로시저·함수가 다수인 대형 문서라, 트리 골격만 먼저 만들고 **필요한 패키지부터 개별 리프로 전문 번역**합니다.
> 번역 방식: 요약 금지, 전문 번역(요청 항목부터).

EPAS는 Oracle 호환 내장 패키지를 제공합니다. 아래는 전체 목록(30개)이며, 각 항목은 향후 `13_4_3_NN_패키지명.md` 리프로 전문 번역해 채웁니다.

## 전체 내장 패키지 목록 (30)

| # | 패키지 | 용도(요약) |
|---|--------|-----------|
| 1 | `DBMS_ALERT` | 알림(alert) 등록·전송·수신 |
| 2 | `DBMS_ASSERT` | 입력 값 검증(SQL 인젝션 방어 보조) |
| 3 | `DBMS_AQ` | 고급 큐잉(Advanced Queuing) — 큐 메시지 |
| 4 | `DBMS_AQADM` | 고급 큐잉 관리 |
| 5 | `DBMS_CRYPTO` | 암호화·복호화·해시 |
| 6 | `DBMS_JOB` | 작업(job) 예약(레거시) |
| 7 | `DBMS_LOB` | LOB(대용량 객체) 조작 |
| 8 | `DBMS_LOCK` | 사용자 정의 락·sleep |
| 9 | `DBMS_MVIEW` | 구체화 뷰 관리 |
| 10 | `DBMS_OUTPUT` | 서버 측 출력 버퍼 |
| 11 | `DBMS_PIPE` | 세션 간 파이프 통신 |
| 12 | `DBMS_PRIVILEGE_CAPTURE` | 권한 사용 캡처 |
| 13 | `DBMS_PROFILER` | PL/SPL 프로파일링 |
| 14 | `DBMS_RANDOM` | 난수 생성 |
| 15 | `DBMS_REDACT` | 데이터 마스킹(redaction) |
| 16 | `DBMS_RLS` | 행 수준 보안(VPD) 정책 |
| 17 | `DBMS_SCHEDULER` | 작업 스케줄러 |
| 18 | `DBMS_SESSION` | 세션 설정 제어 |
| 19 | `DBMS_SQL` | 동적 SQL |
| 20 | `DBMS_UTILITY` | 각종 유틸리티 |

| 22 | `UTL_ENCODE` | 인코딩/디코딩(base64 등) |
| 23 | `UTL_FILE` | 서버 파일 I/O |
| 24 | `UTL_HTTP` | HTTP 요청 |
| 25 | `UTL_MAIL` | 메일 전송(간편) |
| 26 | `UTL_RAW` | RAW 데이터 조작 |
| 27 | `UTL_SMTP` | SMTP 메일 전송(AUTH·STARTTLS 지원) |
| 28 | `UTL_URL` | URL 이스케이프/언이스케이프 |
| 29 | `HTP` / `HTF` | HTML 생성(하이퍼텍스트 프로시저·함수) |
| 30 | `UTL_TCP` | TCP 소켓 통신 |

> 진행 방법: GS 심사·개발에 필요한 패키지를 알려주시면 해당 패키지의 모든 프로시저·함수 시그니처와 예제를 전문 번역해 이 폴더에 `13_4_3_1_DBMS_...md` 형태로 추가합니다.
