# DBMS_LOB v18

`DBMS_LOB` 패키지를 사용하면 대형 객체(large object)를 조작할 수 있습니다. 다음 표는 지원되는 함수와 프로시저를 나열합니다. EDB Postgres Advanced Server의 `DBMS_LOB` 구현은 Oracle 버전과 비교했을 때 부분적인 구현입니다. 이 표에 나열된 함수와 프로시저만 지원됩니다.

| 함수/프로시저 | 반환 유형 | 설명 |
| --- | --- | --- |
| `APPEND(dest_lob IN OUT, src_lob)` | n/a | 한 대형 객체를 다른 대형 객체에 덧붙입니다. |
| `CLOSE(file_loc IN OUT)` | n/a | 열려 있는 BFILE을 닫습니다. |
| `COMPARE(lob_1, lob_2 [, amount [, offset_1 [, offset_2 ]]])` | `NUMBER` | 두 대형 객체를 비교합니다. |
| `CONVERTTOBLOB(dest_lob IN OUT, src_clob, amount, dest_offset IN OUT, src_offset IN OUT, blob_csid, lang_context IN OUT, warning OUT)` | n/a | 문자 데이터를 이진 데이터로 변환합니다. |
| `CONVERTTOCLOB(dest_lob IN OUT, src_blob, amount, dest_offset IN OUT, src_offset IN OUT, blob_csid, lang_context IN OUT, warning OUT)` | n/a | 이진 데이터를 문자 데이터로 변환합니다. |
| `COPY(dest_lob IN OUT, src_lob, amount [, dest_offset [, src_offset ]])` | n/a | 한 대형 객체를 다른 대형 객체로 복사합니다. |
| `ERASE(lob_loc IN OUT, amount IN OUT [, offset ])` | n/a | 대형 객체를 지웁니다. |
| `FILECLOSE(file_loc IN OUT)` | n/a | 열려 있는 BFILE을 닫습니다. |
| `FILECLOSEALL` | n/a | 열려 있는 모든 BFILE을 닫습니다. |
| `FILEEXISTS(file_loc)` | `NUMBER` | BFILE이 존재하는지 여부를 판별합니다. |
| `FILEGETNAME(file_loc, dir_alias OUT, filename OUT)` | n/a | BFILE 로케이터의 디렉터리 별칭과 파일명을 판별합니다. |
| `FILEOPEN(file_loc IN OUT, open_mode)` | n/a | 읽기 전용 BFILE을 엽니다. |
| `FILEISOPEN(file_loc)` | `NUMBER` | BFILE이 `FILE` 로케이터로 열렸는지 여부를 판별합니다. |
| `GET_STORAGE_LIMIT(lob_loc)` | `NUMBER` | 대형 객체의 저장 한도를 가져옵니다. |
| `GETLENGTH(lob_loc | file_loc)` | `NUMBER` | 대형 객체 또는 BFILE의 길이를 가져옵니다. |
| `INSTR(lob_loc | file_loc, pattern [, offset [, nth ]])` | `NUMBER` | `offset`부터 시작하여 대형 객체 또는 BFILE에서 패턴이 n번째로 나타나는 위치를 가져옵니다. |
| `ISOPEN(file_loc)` | `NUMBER` | BFILE이 `FILE` 로케이터로 열렸는지 여부를 판별합니다. |
| `LOADBLOBFROMFILE(dest_lob IN OUT, src_bfile, amount, dest_offset IN OUT, src_offset IN OUT)` | n/a | BFILE에서 내부 `BLOB`으로 데이터를 로드합니다. |
| `LOADCLOBFROMFILE(dest_lob IN OUT, src_bfile, amount, dest_offset IN OUT, src_offset IN OUT, bfile_csid, lang_context IN OUT, warning OUT)` | n/a | BFILE에서 내부 `CLOB`으로 데이터를 로드합니다. |
| `OPEN(file_loc IN OUT, open_mode)` | n/a | 읽기 전용 BFILE을 엽니다. |
| `READ(lob_loc | file_loc, amount IN OUT, offset, buffer OUT)` | n/a | 대형 객체 또는 BFILE을 읽습니다. |
| `SUBSTR(lob_loc | file_loc [, amount [, offset ]])` | `RAW, VARCHAR2` | 대형 객체 또는 BFILE의 일부를 가져옵니다. |
| `TRIM(lob_loc IN OUT, newlen)` | n/a | 대형 객체를 지정된 길이로 잘라냅니다. |
| `WRITE(lob_loc IN OUT, amount, offset, buffer)` | n/a | 대형 객체에 데이터를 씁니다. |
| `WRITEAPPEND(lob_loc IN OUT, amount, buffer)` | n/a | 버퍼의 데이터를 대형 객체의 끝에 씁니다. |

다음 표는 패키지에서 사용할 수 있는 공용 변수(public variable)를 나열합니다.

| 공용 변수 | 데이터 유형 | 값 |
| --- | --- | --- |
| `compress off` | `NUMBER` | `0` |
| `compress_on` | `NUMBER` | `1` |
| `deduplicate_off` | `NUMBER` | `0` |
| `deduplicate_on` | `NUMBER` | `4` |
| `default_csid` | `NUMBER` | `0` |
| `default_lang_ctx` | `NUMBER` | `0` |
| `encrypt_off` | `NUMBER` | `0` |
| `encrypt_on` | `NUMBER` | `1` |
| `file_readonly` | `NUMBER` | `0` |
| `lobmaxsize` | `NUMBER` | `1073741823` |
| `lob_readonly` | `NUMBER` | `0` |
| `lob_readwrite` | `NUMBER` | `1` |
| `no_warning` | `NUMBER` | `0` |
| `opt_compress` | `NUMBER` | `1` |
| `opt_deduplicate` | `NUMBER` | `4` |
| `opt_encrypt` | `NUMBER` | `2` |
| `warn_inconvertible_char` | `NUMBER` | `1` |

대형 객체가 `BLOB`인 경우 길이와 오프셋은 바이트 단위로 측정됩니다. 대형 객체가 `CLOB`인 경우 길이와 오프셋은 문자 단위로 측정됩니다.
