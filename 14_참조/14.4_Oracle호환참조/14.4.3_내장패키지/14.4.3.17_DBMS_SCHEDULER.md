# DBMS_SCHEDULER

`DBMS_SCHEDULER` 패키지의 작업(job)은 `edb_job_scheduler` 확장 모듈에 의해 백그라운드에서 스케줄링되어 실행됩니다. 자세한 내용은 [EDB Job Scheduler extension](https://www.enterprisedb.com/docs/pg_extensions/edb_job_scheduler/)을 참조하세요.

`DBMS_SCHEDULER` 패키지는 Oracle 스타일의 작업(job), 프로그램, 작업 스케줄을 생성하고 관리하는 방법을 제공합니다.

`DBMS_SCHEDULER` 패키지를 사용하려면 `CREATE EXTENSION IF NOT EXISTS dbms_scheduler`를 실행하여 `dbms_scheduler` 확장 모듈을 생성하세요.

`DBMS_SCHEDULER` 패키지는 다음 함수와 프로시저를 구현합니다.

| 함수/프로시저 | 반환 유형 | 설명 |
| --- | --- | --- |
| `CREATE_JOB(job_name, job_type, job_action, number_of_arguments, start_date, repeat_interval, end_date, job_class, enabled, auto_drop, comments)` | n/a | `CREATE_JOB` 프로시저의 첫 번째 형식을 사용하여 프로그램 및 스케줄 세부 정보를 매개변수로 지정하는 작업을 생성합니다. |
| `CREATE_JOB(job_name, program_name, schedule_name, job_class, enabled, auto_drop, comments)` | n/a | `CREATE_JOB`의 두 번째 형식을 사용하여 이름이 지정된 프로그램과 이름이 지정된 스케줄을 사용하는 작업을 생성합니다. |
| `CREATE_PROGRAM(program_name, program_type, program_action, number_of_arguments, enabled, comments)` | n/a | `CREATE_PROGRAM`을 사용하여 프로그램을 생성합니다. |
| `CREATE_SCHEDULE(schedule_name, start_date, repeat_interval, end_date, comments)` | n/a | `CREATE_SCHEDULE` 프로시저를 사용하여 스케줄을 생성합니다. |
| `DEFINE_PROGRAM_ARGUMENT(program_name, argument_position, argument_name, argument_type, default_value, out_argument)` | n/a | `DEFINE_PROGRAM_ARGUMENT` 프로시저의 첫 번째 형식을 사용하여 기본값이 있는 프로그램 인수를 정의합니다. |
| `DEFINE_PROGRAM_ARGUMENT(program_name, argument_position, argument_name, argument_type, out_argument)` | n/a | `DEFINE_PROGRAM_ARGUMENT` 프로시저의 첫 번째 형식을 사용하여 기본값이 없는 프로그램 인수를 정의합니다. |
| `DISABLE(name, force, commit_semantics)` | n/a | `DISABLE` 프로시저를 사용하여 작업 또는 프로그램을 비활성화합니다. |
| `DROP_JOB(job_name, force, defer, commit_semantics)` | n/a | `DROP_JOB` 프로시저를 사용하여 작업을 삭제합니다. |
| `DROP_PROGRAM(program_name, force)` | n/a | `DROP_PROGRAM` 프로시저를 사용하여 프로그램을 삭제합니다. |
| `DROP_PROGRAM_ARGUMENT(program_name, argument_position)` | n/a | `DROP_PROGRAM_ARGUMENT`의 첫 번째 형식을 사용하여 인수 위치를 지정해 프로그램 인수를 삭제합니다. |
| `DROP_PROGRAM_ARGUMENT(program_name, argument_name)` | n/a | `DROP_PROGRAM_ARGUMENT`의 두 번째 형식을 사용하여 인수 이름을 지정해 프로그램 인수를 삭제합니다. |
| `DROP_SCHEDULE(schedule_name, force)` | n/a | `DROP SCHEDULE` 프로시저를 사용하여 스케줄을 삭제합니다. |
| `ENABLE(name, commit_semantics)` | n/a | `ENABLE` 명령을 사용하여 프로그램 또는 작업을 활성화합니다. |
| `EVALUATE_CALENDAR_STRING(calendar_string, start_date, return_date_after, next_run_date)` | n/a | `EVALUATE_CALENDAR_STRING`을 사용하여 사용자 정의 캘린더 스케줄로 기술된 실행 날짜를 검토합니다. |
| `RUN_JOB(job_name, use_current_session, manually)` | n/a | `RUN_JOB` 프로시저를 사용하여 작업을 즉시 실행합니다. |
| `SET_JOB_ARGUMENT_VALUE(job_name, argument_position, argument_value)` | n/a | `SET_JOB_ARGUMENT_VALUE`의 첫 번째 형식을 사용하여 인수의 위치로 기술된 작업 인수의 값을 설정합니다. |
| `SET_JOB_ARGUMENT_VALUE(job_name, argument_name, argument_value)` | n/a | `SET_JOB_ARGUMENT_VALUE`의 두 번째 형식을 사용하여 인수의 이름으로 기술된 작업 인수의 값을 설정합니다. |

EDB Postgres Advanced Server의 `DBMS_SCHEDULER` 구현은 Oracle 버전과 비교할 때 부분 구현입니다. 표에 나열된 함수와 프로시저만 지원됩니다.
