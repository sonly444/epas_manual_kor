# DBMS_CRYPTO — EPAS 18 내장 패키지

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_CRYPTO](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/04_dbms_crypto/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·역할 이름은 원문 그대로 보존했습니다.

`DBMS_CRYPTO` 패키지는 `RAW, BLOB` 또는 `CLOB` 데이터를 암호화하거나 복호화할 수 있는 함수와 프로시저를 제공합니다. 또한 `DBMS_CRYPTO` 함수를 사용하여 암호학적으로 강력한 난수 값을 생성할 수 있습니다.

표는 `DBMS_CRYPTO` 함수와 프로시저를 나열합니다.

| 함수/프로시저 | 반환 유형 | 설명 |
| --- | --- | --- |
| `DECRYPT(src, typ, key, iv)` | `RAW` | `RAW` 데이터를 복호화합니다. |
| `DECRYPT(dst INOUT, src, typ, key, iv)` | 해당 없음 | `BLOB` 데이터를 복호화합니다. |
| `DECRYPT(dst INOUT, src, typ, key, iv)` | 해당 없음 | `CLOB` 데이터를 복호화합니다. |
| `ENCRYPT(src, typ, key, iv)` | `RAW` | `RAW` 데이터를 암호화합니다. |
| `ENCRYPT(dst INOUT, src, typ, key, iv)` | 해당 없음 | `BLOB` 데이터를 암호화합니다. |
| `ENCRYPT(dst INOUT, src, typ, key, iv)` | 해당 없음 | `CLOB` 데이터를 암호화합니다. |
| `HASH(src, typ)` | `RAW` | `RAW` 데이터에 해시 알고리즘을 적용합니다. |
| `MAC(src, typ, key)` | `RAW` | 지정한 해시 알고리즘과 키를 사용하여 주어진 `RAW` 데이터의 해시된 `MAC` 값을 반환합니다. |
| `MAC(src, typ, key)` | `RAW` | 지정한 해시 알고리즘과 키를 사용하여 주어진 `CLOB` 데이터의 해시된 `MAC` 값을 반환합니다. |
| `RANDOMBYTES(number_bytes)` | `RAW` | 지정한 개수만큼의 암호학적으로 강력한 난수 바이트를 반환합니다. |
| `RANDOMINTEGER()` | `INTEGER` | 임의의 정수를 반환합니다. |
| `RANDOMNUMBER()` | `NUMBER` | 임의의 숫자를 반환합니다. |

`DBMS_CRYPTO` 함수와 프로시저는 다음 오류 메시지를 지원합니다.

`ORA-28239 - DBMS_CRYPTO.KeyNull`

`ORA-28829 - DBMS_CRYPTO.CipherSuiteNull`

`ORA-28827 - DBMS_CRYPTO.CipherSuiteInvalid`

Oracle과 달리, EDB Postgres Advanced Server는 이전에 암호화된 정보를 다시 암호화하더라도 오류 `ORA-28233`을 반환하지 않습니다.

`RAW`와 `BLOB`은 PostgreSQL의 `BYTEA` 데이터 유형에 대한 동의어입니다. `CLOB`은 `TEXT`에 대한 동의어입니다.
