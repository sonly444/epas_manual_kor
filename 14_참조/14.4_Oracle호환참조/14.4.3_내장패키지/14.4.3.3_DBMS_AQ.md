# DBMS_AQ — EPAS 18 내장 패키지

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_AQ](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/02_dbms_aq/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·역할 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server Advanced Queueing은 EDB Postgres Advanced Server 데이터베이스를 위한 메시지 큐잉과 메시지 처리 기능을 제공합니다. 사용자 정의 메시지는 큐(queue)에 저장되며, 큐의 모음은 큐 테이블(queue table)에 저장됩니다. `DBMS_AQADM` 패키지의 프로시저는 메시지 큐와 큐 테이블을 생성하고 관리합니다. `DBMS_AQ` 패키지는 큐에 메시지를 추가하거나 큐에서 메시지를 제거하고, PL/SQL 콜백 프로시저를 등록하거나 등록 해제하는 데 사용합니다.

EDB Postgres Advanced Server는 또한 SQL 명령을 통해 `DBMS_AQ` 패키지에 대한 확장(비호환) 기능도 제공합니다. 다음 SQL 명령에 대한 자세한 정보는 [SQL reference](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/)를 참조하십시오.

- `ALTER QUEUE`
- `ALTER QUEUE TABLE`
- `CREATE QUEUE`
- `CREATE QUEUE TABLE`
- `DROP QUEUE`
- `DROP QUEUE TABLE`

`DBMS_AQ` 패키지는 메시지를 인큐(enqueue)하고, 디큐(dequeue)하며, 콜백 프로시저를 관리할 수 있는 프로시저를 제공합니다. 지원되는 프로시저는 다음과 같습니다.

| 함수/프로시저 | 반환 유형 | 설명 |
| --- | --- | --- |
| `ENQUEUE` | 해당 없음 | 큐에 메시지를 게시합니다. |
| `DEQUEUE` | 해당 없음 | 메시지가 사용 가능한 경우 또는 사용 가능해질 때 큐에서 메시지를 가져옵니다. |
| `REGISTER` | 해당 없음 | 콜백 프로시저를 등록합니다. |
| `UNREGISTER` | 해당 없음 | 콜백 프로시저를 등록 해제합니다. |

EDB Postgres Advanced Server의 `DBMS_AQ` 구현은 Oracle 버전에 비하면 부분 구현입니다. 위 표에 나열된 프로시저만 지원됩니다.

EDB Postgres Advanced Server는 다음 상수의 사용을 지원합니다.

| 상수 | 설명 | 적용 매개변수 |
| --- | --- | --- |
| `DBMS_AQ.BROWSE (0)` | 잠금 없이 메시지를 읽습니다. | `dequeue_options_t.dequeue_mode` |
| `DBMS_AQ.LOCKED (1)` | 이 상수는 정의되어 있으나 사용하면 오류를 반환합니다. | `dequeue_options_t.dequeue_mode` |
| `DBMS_AQ.REMOVE (2)` | 읽은 후 메시지를 삭제합니다(기본값). | `dequeue_options_t.dequeue_mode` |
| `DBMS_AQ.REMOVE_NODATA (3)` | 이 상수는 정의되어 있으나 사용하면 오류를 반환합니다. | `dequeue_options_t.dequeue_mode` |
| `DBMS_AQ.FIRST_MESSAGE (0)` | 검색 조건에 일치하는 첫 번째 사용 가능한 메시지를 반환합니다. | `dequeue_options_t.navigation` |
| `DBMS_AQ.NEXT_MESSAGE (1)` | 검색 조건에 일치하는 다음 사용 가능한 메시지를 반환합니다. | `dequeue_options_t.navigation` |
| `DBMS_AQ.NEXT_TRANSACTION (2)` | 이 상수는 정의되어 있으나 사용하면 오류를 반환합니다. | `dequeue_options_t.navigation` |
| `DBMS_AQ.FOREVER (-1)` | 검색 조건에 일치하는 메시지를 찾지 못하면 무한정 대기합니다(기본값). | `dequeue_options_t.wait` |
| `DBMS_AQ.NO_WAIT (0)` | 검색 조건에 일치하는 메시지를 찾지 못해도 대기하지 않습니다. | `dequeue_options_t.wait` |
| `DBMS_AQ.ON_COMMIT (0)` | 디큐가 현재 트랜잭션의 일부입니다. | `enqueue_options_t.visibility, dequeue_options_t.visibility` |
| `DBMS_AQ.IMMEDIATE (1)` | 이 상수는 정의되어 있으나 사용하면 오류를 반환합니다. | `enqueue_options_t.visibility, dequeue_options_t.visibility` |
| `DBMS_AQ.PERSISTENT (0)` | 메시지를 테이블에 저장합니다. | `enqueue_options_t.delivery_mode` |
| `DBMS_AQ.BUFFERED (1)` | 이 상수는 정의되어 있으나 사용하면 오류를 반환합니다. | `enqueue_options_t.delivery_mode` |
| `DBMS_AQ.READY (0)` | 메시지가 처리할 준비가 되었음을 지정합니다. | `message_properties_t.state` |
| `DBMS_AQ.WAITING (1)` | 메시지가 처리를 기다리고 있음을 지정합니다. | `message_properties_t.state` |
| `DBMS_AQ.PROCESSED (2)` | 메시지가 처리되었음을 지정합니다. | `message_properties_t.state` |
| `DBMS_AQ.EXPIRED (3)` | 메시지가 예외 큐(exception queue)에 있음을 지정합니다. | `message_properties_t.state` |
| `DBMS_AQ.NO_DELAY (0)` | 이 상수는 정의되어 있으나 사용하면 오류를 반환합니다. | `message_properties_t.delay` |
| `DBMS_AQ.NEVER (NULL)` | 이 상수는 정의되어 있으나 사용하면 오류를 반환합니다. | `message_properties_t.expiration` |
| `DBMS_AQ.NAMESPACE_AQ (0)` | `DBMS_AQ` 큐로부터의 알림을 수락합니다. | `sys.aq$_reg_info.namespace` |
| `DBMS_AQ.NAMESPACE_ANONYMOUS (1)` | 이 상수는 정의되어 있으나 사용하면 오류를 반환합니다. | `sys.aq$_reg_info.namespace` |

다음 표에 나열된 `DBMS_AQ` 구성 매개변수는 `postgresql.conf` 파일에서 정의할 수 있습니다. 구성 매개변수가 정의되면 `DBMS_AQ` 패키지를 호출하여 큐와 큐 테이블에 보관된 메시지를 사용하고 관리할 수 있습니다.

| 매개변수 | 설명 |
| --- | --- |
| `dbms_aq.max_workers` | 실행할 워커(worker)의 최대 개수입니다. |
| `dbms_aq.max_idle_time` | 워커가 종료되기 전에 대기해야 하는 유휴 시간입니다. |
| `dbms_aq.min_work_time` | 워커가 종료되기 전에 실행할 수 있는 최소 시간입니다. |
| `dbms_aq.launch_delay` | 워커를 생성하는 사이의 최소 시간입니다. |
| `dbms_aq.batch_size` | 단일 트랜잭션에서 처리할 최대 메시지 수입니다. 기본 배치 크기는 10입니다. |
| `dbms_aq.max_databases` | 데이터베이스의 `DBMS_AQ` 해시 테이블 크기입니다. 기본값은 1024입니다. |
| `dbms_aq.max_pending_retries` | 보류 중인 재시도(pending retries)의 `DBMS_AQ` 해시 테이블 크기입니다. 기본값은 1024입니다. |
