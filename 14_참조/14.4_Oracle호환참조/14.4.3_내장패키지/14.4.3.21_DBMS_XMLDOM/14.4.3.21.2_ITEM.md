# ITEM — EPAS 18 내장 패키지 DBMS_XMLDOM
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_XMLDOM › ITEM](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/18_dbms_xmldom/item/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`ITEM` 함수는 컬렉션에서 `idx` 파라미터에 해당하는 항목을 반환합니다. `idx` 파라미터의 값이 리스트의 노드 개수보다 크거나 같으면, 이 함수는 `NULL`을 반환합니다.

```text
ITEM(nl DOMNodeList, idx IN PLS_INTEGER) RETURN DOMNode
```

## 파라미터 (Parameters)

`nl`

`DOMNodeList`, 즉 리스트에 있는 노드의 개수입니다.

`idx`

항목을 검색하는 데 사용되는 NODELIST 내의 인덱스입니다.

## 예제 (Example)

이 예제는 XML 구조 `<Departments>Dept1</Departments>`를 생성하고 루트 노드인 문서 노드를 반환하는 함수 `func1`을 사용합니다.

```sql
CREATE OR REPLACE FUNCTION func1 RETURN DBMS_XMLDOM.DOMNode IS
   l_domdoc DBMS_XMLDOM.DOMDocument;
   l_root_node DBMS_XMLDOM.DOMNode;
   l_department_element DBMS_XMLDOM.DOMElement;
   l_departments_node DBMS_XMLDOM.DOMNode;
   l_name_text DBMS_XMLDOM.DOMText;
   l_name_textnode DBMS_XMLDOM.DOMNode;
BEGIN
   l_domdoc := DBMS_XMLDOM.NEWDOMDOCUMENT;
   l_root_node := DBMS_XMLDOM.MAKENODE(l_domdoc);
   l_department_element := DBMS_XMLDOM.CREATEELEMENT(l_domdoc, 'Departments' );
   l_departments_node := DBMS_XMLDOM.APPENDCHILD(l_root_node,DBMS_XMLDOM.MAKENODE(l_department_element));
   l_name_text := DBMS_XMLDOM.CREATETEXTNODE(l_domdoc, 'Dept1' );
   PERFORM DBMS_XMLDOM.APPENDCHILD(l_departments_node,DBMS_XMLDOM.MAKENODE(l_name_text));
   return l_root_node;
END;
```

문서 노드는 `func1` 함수를 사용하여 `GETCHILDNODES`에 전달되며, 이 함수는 문서 노드의 자식 목록을 반환합니다. 이 목록에는 `Departments`를 나타내는 `DOMElement`가 들어 있습니다. item 호출은 이 요소를 `DOMNode`로 반환하며, 이후 `GETNODENAME`이 이 값을 받아 이 `DOMElement`의 태그 이름을 가져옵니다.

```sql
DECLARE
   clist DBMS_XMLDOM.DOMNodeList;
   l_node DBMS_XMLDOM.DOMNode;
BEGIN
   clist := DBMS_XMLDOM.GETCHILDNODES(func1());
   l_node := DBMS_XMLDOM.ITEM(clist, 0);
   dbms_output.put_line(DBMS_XMLDOM.GETNODENAME(l_node));
END;
```
