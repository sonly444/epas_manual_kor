# MAKENODE — EPAS 18 내장 패키지 DBMS_XMLDOM
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_XMLDOM › MAKENODE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/18_dbms_xmldom/makenode/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`MAKENODE` 함수는 여러 유형의 값을 받아 `DOMNode`를 반환합니다.

```text
MAKENODE(doc DOMDocument) RETURN DOMNode

MAKENODE(elem DOMElement) RETURN DOMNode

MAKENODE(t DOMText) RETURN DOMNode
```

## 파라미터 (Parameters)

`doc`

캐스팅할 `DOMDocument`입니다.

`elem`

캐스팅할 `DOMElement`입니다.

`t`

캐스팅할 `DOMText`입니다.

## 예제 (Example)

`DOMDocument`, `DOMElement`, `DOMText`를 `DOMNode`로 변환할 수 있습니다.

이 예제는 XML `DOMDocument`를 생성하여 루트가 될 수 있도록 `DOMNode`로 변환합니다. 그런 다음 태그 이름이 `Departments`인 `DOMElement`를 생성하여 노드로 변환하고, `DOMElement`에 추가합니다. 이어서 태그 이름이 `Depts list`인 텍스트 노드 `DOMNode`를 생성하여 `DOMElement` 노드의 자식으로 추가합니다.

```sql
DECLARE
   l_domdoc DBMS_XMLDOM.DOMDocument;
   l_root_node DBMS_XMLDOM.DOMNode;
   l_department_element DBMS_XMLDOM.DOMElement;
   l_departments_node DBMS_XMLDOM.DOMNode;
   l_name_text DBMS_XMLDOM.DOMText;
   l_xmltype XMLTYPE;

BEGIN
   l_domdoc := DBMS_XMLDOM.NEWDOMDOCUMENT;
   l_root_node := DBMS_XMLDOM.MAKENODE(l_domdoc);
   l_department_element := DBMS_XMLDOM.CREATEELEMENT(l_domdoc, 'Departments' );
   l_departments_node := DBMS_XMLDOM.APPENDCHILD(l_root_node,DBMS_XMLDOM.makeNode(l_department_element));
   l_name_text := DBMS_XMLDOM.CREATETEXTNODE(l_domdoc, 'Depts list' );
   PERFORM DBMS_XMLDOM.APPENDCHILD(l_departments_node,DBMS_XMLDOM.MAKENODE(l_name_text));
   l_xmltype := DBMS_XMLDOM.GETXMLTYPE(l_domdoc);
   DBMS_OUTPUT.PUT_LINE(l_xmltype.getStringVal());
END;
```
