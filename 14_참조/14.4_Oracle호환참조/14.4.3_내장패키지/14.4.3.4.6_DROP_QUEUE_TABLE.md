# DROP_QUEUE_TABLE

큐 테이블을 삭제하려면 `DROP_QUEUE_TABLE` 프로시저를 사용합니다. 시그니처는 다음과 같습니다.

```sql
DROP_QUEUE_TABLE(
  <queue_table> IN VARCHAR2,
  <force> IN BOOLEAN default FALSE,
  <auto_commit> IN BOOLEAN default TRUE)
```

## 매개변수 (Parameters)

`queue_table`

큐 테이블의 (선택적으로 스키마로 한정된) 이름입니다.

`force`

`force` 키워드는 항목이 들어 있는 테이블을 삭제할 때 `DROP_QUEUE_TABLE` 명령의 동작을 결정합니다.

- 대상 테이블에 항목이 들어 있고 `force`가 `FALSE`이면 명령이 실패하며 서버가 오류를 발생시킵니다.
- 대상 테이블에 항목이 들어 있고 `force`가 `TRUE`이면 명령이 테이블과 모든 종속 객체를 삭제합니다.

`auto_commit`

`auto_commit`은 호환성을 위해 허용되지만 무시됩니다.

## 예제 (Example)

다음 익명 블록은 `work_order_table`이라는 이름의 테이블을 삭제합니다.

```sql
BEGIN
   DBMS_AQADM.DROP_QUEUE_TABLE ('work_order_table', force => TRUE);
END;
```
