# UTL_RAW — EPAS 18 내장 패키지
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › UTL_RAW](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/23_utl_raw/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

# UTL_RAW

`UTL_RAW` 패키지를 사용하면 raw 데이터 타입을 조작하거나 그 길이를 검색할 수 있습니다.

##### 참고 (Note)

관리자는 각 사용자나 그룹이 이 패키지를 사용하기 전에 실행 권한을 부여해야 합니다.

| 함수/프로시저 | 함수 또는 프로시저 | 반환 타입 | 설명 |
| --- | --- | --- | --- |
| `CAST_TO_RAW(c IN VARCHAR2)` | 함수 | `RAW` | `VARCHAR2` 문자열을 `RAW` 값으로 변환합니다. |
| `CAST_TO_VARCHAR2(r IN RAW)` | 함수 | `VARCHAR2` | `RAW` 값을 `VARCHAR2` 문자열로 변환합니다. |
| `CONCAT(r1 IN RAW, r2 IN RAW, r3 IN RAW,…)` | 함수 | `RAW` | 여러 `RAW` 값을 하나의 `RAW` 값으로 연결합니다. |
| `CONVERT(r IN RAW, to_charset IN VARCHAR2, from_charset IN VARCHAR2)` | 함수 | `RAW` | 인코딩된 데이터를 한 인코딩에서 다른 인코딩으로 변환하고 그 결과를 `RAW` 값으로 반환합니다. |
| `LENGTH(r IN RAW)` | 함수 | `NUMBER` | `RAW` 값의 길이를 반환합니다. |
| `SUBSTR(r IN RAW, pos IN INTEGER, len IN INTEGER)` | 함수 | `RAW` | `RAW` 값의 일부를 반환합니다. |

EDB Postgres Advanced Server의 `UTL_RAW` 구현은 Oracle 버전과 비교할 때 부분 구현입니다. 표에 나열된 함수와 프로시저만 지원됩니다.

## CAST_TO_RAW

`CAST_TO_RAW` 함수는 `VARCHAR2` 문자열을 `RAW` 값으로 변환합니다. 시그니처는 다음과 같습니다.

```sql
CAST_TO_RAW(<c> VARCHAR2)
```

`NULL`이 아닌 값을 전달하면 함수는 `RAW` 값을 반환합니다. `NULL` 값을 전달하면 함수는 `NULL`을 반환합니다.

### 파라미터 (Parameters)

`c`

`RAW`로 변환할 `VARCHAR2` 값입니다.

### 예제 (Example)

이 예제는 `CAST_TO_RAW` 함수를 사용하여 `VARCHAR2` 문자열을 `RAW` 값으로 변환합니다.

```sql
DECLARE
  v VARCHAR2;
  r RAW;
BEGIN
  v := 'Accounts';
  dbms_output.put_line(v);
  r := UTL_RAW.CAST_TO_RAW(v);
  dbms_output.put_line(r);
END;
```

결과 집합에는 원래 문자열의 내용과 변환된 `RAW` 값이 포함됩니다.

```text
Accounts
\x4163636f756e7473
```

## CAST_TO_VARCHAR2

`CAST_TO_VARCHAR2` 함수는 `RAW` 데이터를 `VARCHAR2` 데이터로 변환합니다. 시그니처는 다음과 같습니다.

```sql
CAST_TO_VARCHAR2(<r> RAW)
```

`NULL`이 아닌 값을 전달하면 함수는 `VARCHAR2` 값을 반환합니다. `NULL` 값을 전달하면 함수는 `NULL`을 반환합니다.

### 파라미터 (Parameters)

`r`

`VARCHAR2` 값으로 변환할 `RAW` 값입니다.

### 예제 (Example)

이 예제는 `CAST_TO_VARCHAR2` 함수를 사용하여 `RAW` 값을 `VARCHAR2` 문자열로 변환합니다.

```sql
DECLARE
  r RAW;
  v VARCHAR2;
BEGIN
  r := '\x4163636f756e7473'
  dbms_output.put_line(v);
  v := UTL_RAW.CAST_TO_VARCHAR2(r);
  dbms_output.put_line(r);
END;
```

결과 집합에는 원래 문자열의 내용과 변환된 `RAW` 값이 포함됩니다.

```text
\x4163636f756e7473
Accounts
```

## CONCAT

`CONCAT` 함수는 여러 `RAW` 값을 하나의 `RAW` 값으로 연결합니다. 시그니처는 다음과 같습니다.

```sql
CONCAT(<r1> RAW, <r2> RAW, <r3> RAW,…)
```

이 함수는 `RAW` 값을 반환합니다. Oracle 구현과 달리 EDB Postgres Advanced Server 구현은 가변 인수(variadic) 함수이며 연결할 수 있는 값의 개수에 제한을 두지 않습니다.

### 파라미터 (Parameters)

`r1, r2, r3,…`

`CONCAT`이 연결할 `RAW` 값들입니다.

### 예제 (Example)

이 예제는 `CONCAT` 함수를 사용하여 여러 `RAW` 값을 하나의 `RAW` 값으로 연결합니다.

```sql
SELECT UTL_RAW.CAST_TO_VARCHAR2(UTL_RAW.CONCAT('\x61', '\x62', '\x63')) FROM
DUAL;
```

출력(Output)

```text
 concat
--------
 abc
(1 row)
```

그런 다음 결과(연결된 값)는 `CAST_TO_VARCHAR2` 함수에 의해 `VARCHAR2` 형식으로 변환됩니다.

## CONVERT

`CONVERT` 함수는 문자열을 한 인코딩에서 다른 인코딩으로 변환하고 그 결과를 `RAW` 값으로 반환합니다. 시그니처는 다음과 같습니다.

```sql
CONVERT(<r> RAW, <to_charset> VARCHAR2, <from_charset> VARCHAR2)
```

이 함수는 `RAW` 값을 반환합니다.

### 파라미터 (Parameters)

`r`

변환할 `RAW` 값입니다.

`to_charset`

`r`이 변환되는 대상 인코딩의 이름입니다.

`from_charset`

`r`이 변환되는 원본 인코딩의 이름입니다.

### 예제 (Example)

이 예제는 `UTL_RAW.CAST_TO_RAW` 함수를 사용하여 `VARCHAR2` 문자열(`Accounts`)을 raw 값으로 변환합니다. 그런 다음 값을 `UTF8`에서 `LATIN7`로, 그리고 `LATIN7`에서 `UTF8`로 변환합니다.

```sql
DECLARE
  r RAW;
  v VARCHAR2;
BEGIN
  v:= 'Accounts';
  dbms_output.put_line(v);
  r:= UTL_RAW.CAST_TO_RAW(v);
  dbms_output.put_line(r);
  r:= UTL_RAW.CONVERT(r, 'UTF8', 'LATIN7');
  dbms_output.put_line(r);
  r:= UTL_RAW.CONVERT(r, 'LATIN7', 'UTF8');
  dbms_output.put_line(r);
```

이 예제는 `VARCHAR2` 값, `RAW` 값, 그리고 변환된 값들을 반환합니다.

```text
Accounts
\x4163636f756e7473
\x4163636f756e7473
\x4163636f756e7473
```

## LENGTH

`LENGTH` 함수는 `RAW` 값의 길이를 반환합니다. 시그니처는 다음과 같습니다.

```sql
LENGTH(<r> RAW)
```

이 함수는 `RAW` 값을 반환합니다.

### 파라미터 (Parameters)

`r`

`LENGTH`가 평가할 `RAW` 값입니다.

### 예제 (Example)

이 예제는 `LENGTH` 함수를 사용하여 `RAW` 값의 길이를 반환합니다.

```sql
SELECT UTL_RAW.LENGTH(UTL_RAW.CAST_TO_RAW('Accounts')) FROM DUAL;
```

출력(Output)

```text
 length
--------
 8
(1 row)
```

이 예제는 `LENGTH` 함수를 사용하여 멀티바이트 문자를 포함하는 `RAW` 값의 길이를 반환합니다.

```sql
SELECT UTL_RAW.LENGTH(UTL_RAW.CAST_TO_RAW('独孤求败'));
```

출력(Output)

```text
 length
--------
     12
(1 row)
```

## SUBSTR

`SUBSTR` 함수는 `RAW` 값의 부분 문자열을 반환합니다. 시그니처는 다음과 같습니다.

```sql
SUBSTR (<r> RAW, <pos> INTEGER, <len> INTEGER)
```

이 함수는 `RAW` 값을 반환합니다.

### 파라미터 (Parameters)

`r`

부분 문자열을 반환할 `RAW` 값입니다.

`pos`

`RAW` 값에서 반환되는 부분 문자열의 첫 번째 바이트 위치입니다.

- `pos`가 `0` 또는 `1`이면, 부분 문자열은 `RAW` 값의 첫 번째 바이트에서 시작합니다.
- `pos`가 1보다 크면, 부분 문자열은 `pos`로 지정된 첫 번째 바이트에서 시작합니다. 예를 들어 `pos`가 `3`이면, 부분 문자열은 값의 세 번째 바이트에서 시작합니다.
- `pos`가 음수이면, 부분 문자열은 원본 값의 끝에서 `pos` 바이트 위치에서 시작합니다. 예를 들어 `pos`가 `-3`이면, 부분 문자열은 값의 끝에서 세 번째 바이트에서 시작합니다.

`len`

반환할 최대 바이트 수입니다.

### 예제 (Example)

이 예제는 `SUBSTR` 함수를 사용하여 `RAW` 값의 시작에서 `3`바이트 위치에서 시작하는 부분 문자열을 선택합니다.

```sql
SELECT UTL_RAW.SUBSTR(UTL_RAW.CAST_TO_RAW('Accounts'), 3, 5) FROM DUAL;
```

출력(Output)

```text
 substr
--------
 count
(1 row)
```

이 예제는 `SUBSTR` 함수를 사용하여 `RAW` 값의 끝에서 5바이트 위치에서 시작하는 부분 문자열을 선택합니다.

```sql
SELECT UTL_RAW.SUBSTR(UTL_RAW.CAST_TO_RAW('Accounts'), -5 , 3) FROM DUAL;
```

출력(Output)

```text
 substr
--------
 oun
(1 row)
```
