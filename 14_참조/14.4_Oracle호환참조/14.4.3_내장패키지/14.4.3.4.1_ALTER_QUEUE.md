# ALTER_QUEUE

기존 큐를 수정하려면 `ALTER_QUEUE` 프로시저를 사용합니다. 시그니처는 다음과 같습니다.

```sql
ALTER_QUEUE(
  <max_retries> IN NUMBER DEFAULT NULL,
  <retry_delay> IN NUMBER DEFAULT 0
  <retention_time> IN NUMBER DEFAULT 0,
  <auto_commit> IN BOOLEAN DEFAULT TRUE)
  <comment> IN VARCHAR2 DEFAULT NULL,
```

## 매개변수 (Parameters)

`queue_name`

새 큐의 이름입니다.

`max_retries`

`max_retries`는 디큐(dequeue) 문으로 메시지를 제거하려는 시도의 최대 횟수를 지정합니다. `max_retries` 값은 각 `ROLLBACK` 문마다 증가합니다. 실패한 시도 횟수가 `max_retries`로 지정한 값에 도달하면 해당 메시지는 예외 큐(exception queue)로 이동됩니다. 재시도를 허용하지 않으려면 `0`을 지정합니다.

`retry_delay`

`retry_delay`는 `ROLLBACK` 이후 메시지가 재처리되도록 예약되기까지의 시간을 초 단위로 지정합니다. 메시지를 즉시 재시도하려면 `0`(기본값)을 지정합니다.

`retention_time`

`retention_time`은 메시지가 디큐된 후 저장되는 시간의 길이를 초 단위로 지정합니다. 디큐 후 메시지를 보존하지 않으려면 `0`(기본값)을 지정할 수 있고, 메시지를 영구히 보존하려면 `INFINITE`를 지정할 수 있습니다.

`auto_commit`

이 매개변수는 호환성을 위해 허용되며 무시됩니다.

`comment`

`comment`는 큐와 연결된 주석을 지정합니다.

## 예제 (Example)

다음 명령은 `work_order`라는 이름의 큐를 변경하여 `retry_delay` 매개변수를 5초로 설정합니다.

```sql
EXEC DBMS_AQADM.ALTER_QUEUE(queue_name => 'work_order', retry_delay => 5);
```
