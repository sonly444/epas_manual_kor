# ENQUOTE_LITERAL — EPAS 18 내장 패키지 DBMS_ASSERT

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_ASSERT › ENQUOTE_LITERAL](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/01a_dbms_assert/enquote_literal/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`ENQUOTE_LITERAL` 함수는 문자열이 이미 작은따옴표로 둘러싸여 있지 않은 경우 해당 문자열을 작은따옴표로 감쌉니다.

문자열 안에는 둘러싸는 따옴표를 제외하고 짝수 개의 작은따옴표만 허용됩니다.

```sql
ENQUOTE_LITERAL(str VARCHAR2) RETURN VARCHAR2;
```

## 매개변수 (Parameters)

`str`

작은따옴표로 감쌀 문자열입니다.

## 예제 (Examples)

```sql
edb=# SELECT sys.DBMS_ASSERT.ENQUOTE_LITERAL('literal without ''''quotes') FROM DUAL;
      enquote_literal
----------------------------
 'literal without ''quotes'
(1 row)

edb=# SELECT dbms_assert.ENQUOTE_LITERAL('''ab''') FROM dual;
 enquote_literal
-----------------
 'ab'
(1 row)
```
