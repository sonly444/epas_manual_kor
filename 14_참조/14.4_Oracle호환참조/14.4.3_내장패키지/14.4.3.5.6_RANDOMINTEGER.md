# RANDOMINTEGER

`RANDOMINTEGER()` 함수는 32비트 부호 있는 정수 범위인 `-2,147,483,648`부터`2,147,483,647` 사이의 무작위 정수를 반환합니다. 시그니처는 다음과 같습니다.

```sql
RANDOMINTEGER() RETURNS INTEGER
```

## 예제 (Examples)

이 예제는 `RANDOMINTEGER` 함수를 사용하여 암호학적으로 강력한 무작위 `INTEGER` 값을 반환합니다.

```sql
DECLARE
  result INTEGER;
BEGIN
  result := DBMS_CRYPTO.RANDOMINTEGER();
  DBMS_OUTPUT.PUT_LINE(result);
END;
```
