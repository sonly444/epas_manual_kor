# DBMS_OUTPUT — EPAS 18 내장 패키지

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_OUTPUT](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/09_dbms_output/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·역할 이름은 원문 그대로 보존했습니다.

# DBMS_OUTPUT v18

`DBMS_OUTPUT` 패키지는 메시지(텍스트 줄)를 메시지 버퍼로 보내거나 메시지 버퍼에서 메시지를 가져옵니다. 메시지 버퍼는 단일 세션에 국한됩니다. 세션 간에 메시지를 보내려면 `DBMS_PIPE` 패키지를 사용하세요.

`DBMS_OUTPUT` 패키지에서 사용할 수 있는 프로시저와 함수는 다음 표에 나열되어 있습니다.

| 함수/프로시저 | 반환 유형 | 설명 |
| --- | --- | --- |
| `DISABLE` | n/a | 메시지를 보내고 받는 기능을 비활성화합니다. |
| `ENABLE(buffer_size)` | n/a | 메시지를 보내고 받는 기능을 활성화합니다. |
| `GET_LINE(line OUT, status OUT)` | n/a | 메시지 버퍼에서 한 줄을 가져옵니다. |
| `GET_LINES(lines OUT, numlines IN OUT)` | n/a | 메시지 버퍼에서 여러 줄을 가져옵니다. |
| `NEW_LINE` | n/a | 줄 끝(end-of-line) 문자 시퀀스를 넣습니다. |
| `PUT(item)` | n/a | 줄 끝 문자 시퀀스 없이 부분적인 줄을 넣습니다. |
| `PUT_LINE(item)` | n/a | 줄 끝 문자 시퀀스와 함께 완전한 줄을 넣습니다. |
| `SERVEROUTPUT(stdout)` | n/a | `PUT, PUT_LINE,` 또는 `NEW_LINE`의 메시지를 표준 출력 또는 메시지 버퍼로 보냅니다. |

다음 표는 `DBMS_OUTPUT` 패키지에서 사용할 수 있는 공용 변수(public variable)를 나열합니다.

| 공용 변수 | 데이터 유형 | 값 | 설명 |
| --- | --- | --- | --- |
| `chararr` | `TABLE` |  | 메시지 줄을 위한 것입니다. |

## CHARARR

`CHARARR`은 여러 메시지 줄을 저장하기 위한 것입니다.

```sql
TYPE chararr IS TABLE OF VARCHAR2(32767) INDEX BY BINARY_INTEGER;
```

## DISABLE

`DISABLE` 프로시저는 메시지 버퍼를 비웁니다. `DISABLE` 프로시저가 실행되는 시점에 버퍼에 있는 어떤 메시지에도 더 이상 접근할 수 없습니다. 이후에 `PUT`, `PUT_LINE,` 또는 `NEW_LINE` 프로시저로 보낸 모든 메시지는 폐기됩니다. 메시지가 비활성화된 상태에서 `PUT`, `PUT_LINE,` 또는 `NEW_LINE` 프로시저가 실행될 때 발신자에게 어떠한 오류도 반환되지 않습니다.

메시지 송수신을 다시 활성화하려면 `ENABLE` 또는 `SERVEROUTPUT(TRUE)` 프로시저를 사용하세요.

```sql
DISABLE
```

### 예제 (Examples)

이 익명 블록은 현재 세션에서 메시지 송수신을 비활성화합니다.

```sql
BEGIN
    DBMS_OUTPUT.DISABLE;
END;
```

## ENABLE

`ENABLE` 프로시저를 사용하면 메시지 버퍼로 메시지를 보내거나 메시지 버퍼에서 메시지를 검색할 수 있습니다. `SERVEROUTPUT(TRUE)`를 실행하면 `ENABLE` 프로시저도 암묵적으로 수행됩니다.

`PUT`, `PUT_LINE`, 또는 `NEW_LINE`으로 보낸 메시지의 목적지는 `SERVEROUTPUT`의 상태에 따라 달라집니다.

- `SERVEROUTPUT`의 마지막 상태가 `TRUE`이면 메시지는 명령줄의 표준 출력으로 갑니다.
- `SERVEROUTPUT`의 마지막 상태가 `FALSE`이면 메시지는 메시지 버퍼로 갑니다.

```sql
ENABLE [ (<buffer_size> INTEGER) ]
```

### 매개변수 (Parameter)

`buffer_size`

메시지 버퍼의 최대 길이(바이트 단위)입니다. `buffer_size`를 2000보다 작게 지정하면 버퍼 크기는 2000으로 설정됩니다.

### 예제 (Examples)

이 익명 블록은 메시지를 활성화합니다. `SERVEROUTPUT(TRUE)`를 설정하면 메시지가 표준 출력으로 강제됩니다.

```sql
BEGIN
    DBMS_OUTPUT.ENABLE;
    DBMS_OUTPUT.SERVEROUTPUT(TRUE);
    DBMS_OUTPUT.PUT_LINE('Messages enabled');
END;

Messages enabled
```

`SERVEROUTPUT(TRUE)`를 사용하여 동일한 효과를 얻을 수 있습니다.

```sql
BEGIN
    DBMS_OUTPUT.SERVEROUTPUT(TRUE);
    DBMS_OUTPUT.PUT_LINE('Messages enabled');
END;

Messages enabled
```

이 익명 블록은 메시지를 활성화하지만, `SERVEROUTPUT(FALSE)`를 설정하면 메시지가 메시지 버퍼로 향합니다.

```sql
BEGIN
    DBMS_OUTPUT.ENABLE;
    DBMS_OUTPUT.SERVEROUTPUT(FALSE);
    DBMS_OUTPUT.PUT_LINE('Message sent to buffer');
END;
```

## GET_LINE

`GET_LINE` 프로시저는 메시지 버퍼에서 한 줄의 텍스트를 검색합니다. 줄 끝 문자 시퀀스로 종료된 텍스트만 검색됩니다. 여기에는 `PUT_LINE`을 사용하여 생성된 완전한 줄 또는 일련의 `PUT` 호출 뒤에 `NEW_LINE` 호출이 이어진 완전한 줄이 포함됩니다.

```sql
GET_LINE(<line> OUT VARCHAR2, <status> OUT INTEGER)
```

### 매개변수 (Parameters)

`line`

메시지 버퍼에서 텍스트 줄을 받는 변수입니다.

`status`

메시지 버퍼에서 줄이 반환되었으면 `0`, 반환할 줄이 없었으면 `1`입니다.

### 예제 (Examples)

이 익명 블록은 `emp` 테이블을 각 행에 대해 쉼표로 구분된 문자열로 메시지 버퍼에 씁니다.

```sql
EXEC DBMS_OUTPUT.SERVEROUTPUT(FALSE);

DECLARE
    v_emprec        VARCHAR2(120);
    CURSOR emp_cur IS SELECT * FROM emp ORDER BY empno;
BEGIN
    DBMS_OUTPUT.ENABLE;
    FOR i IN emp_cur LOOP
        v_emprec := i.empno || ',' || i.ename || ',' || i.job || ',' ||
            NVL(LTRIM(TO_CHAR(i.mgr,'9999')),'') || ',' || i.hiredate ||
            ',' || i.sal || ',' ||
            NVL(LTRIM(TO_CHAR(i.comm,'9990.99')),'') || ',' || i.deptno;
        DBMS_OUTPUT.PUT_LINE(v_emprec);
    END LOOP;
END;
```

이 익명 블록은 메시지 버퍼를 읽어 앞의 예제에서 작성한 메시지를 `messages`라는 테이블에 삽입합니다. 그런 다음 `messages`의 행이 표시됩니다.

```sql
CREATE TABLE messages (
    status          INTEGER,
    msg             VARCHAR2(100)
);

DECLARE
    v_line          VARCHAR2(100);
    v_status        INTEGER := 0;
BEGIN
    DBMS_OUTPUT.GET_LINE(v_line,v_status);
    WHILE v_status = 0 LOOP
        INSERT INTO messages VALUES(v_status, v_line);
        DBMS_OUTPUT.GET_LINE(v_line,v_status);
    END LOOP;
END;

SELECT msg FROM messages;
```

## GET_LINES

`GET_LINES` 프로시저는 메시지 버퍼에서 하나 이상의 텍스트 줄을 컬렉션으로 검색합니다. 줄 끝 문자 시퀀스로 종료된 텍스트만 검색됩니다. 여기에는 `PUT_LINE`을 사용하여 생성된 완전한 줄 또는 일련의 `PUT` 호출 뒤에 `NEW_LINE` 호출이 이어진 완전한 줄이 포함됩니다.

```sql
GET_LINES(<lines> OUT CHARARR, <numlines> IN OUT INTEGER)
```

### 매개변수 (Parameters)

`lines`

메시지 버퍼에서 텍스트 줄을 받는 테이블입니다. `lines`에 대한 설명은 `CHARARR`을 참조하세요.

`numlines IN`

메시지 버퍼에서 검색할 줄 수입니다.

`numlines OUT`

메시지 버퍼에서 실제로 검색된 줄 수입니다. `numlines`의 출력 값이 입력 값보다 작으면 메시지 버퍼에 더 이상 남은 줄이 없습니다.

### 예제 (Examples)

이 예제는 `GET_LINES` 프로시저를 사용하여 메시지 버퍼에 배치된 `emp` 테이블의 모든 행을 배열에 저장합니다.

```sql
EXEC DBMS_OUTPUT.SERVEROUTPUT(FALSE);

DECLARE
    v_emprec        VARCHAR2(120);
    CURSOR emp_cur IS SELECT * FROM emp ORDER BY empno;
BEGIN
    DBMS_OUTPUT.ENABLE;
    FOR i IN emp_cur LOOP
        v_emprec := i.empno || ',' || i.ename || ',' || i.job || ',' ||
            NVL(LTRIM(TO_CHAR(i.mgr,'9999')),'') || ',' || i.hiredate ||
            ',' || i.sal || ',' ||
            NVL(LTRIM(TO_CHAR(i.comm,'9990.99')),'') || ',' || i.deptno;
        DBMS_OUTPUT.PUT_LINE(v_emprec);
    END LOOP;
END;

DECLARE
    v_lines         DBMS_OUTPUT.CHARARR;
    v_numlines      INTEGER := 14;
    v_status        INTEGER := 0;
BEGIN
    DBMS_OUTPUT.GET_LINES(v_lines,v_numlines);
    FOR i IN 1..v_numlines LOOP
        INSERT INTO messages VALUES(v_numlines, v_lines(i));
    END LOOP;
END;

SELECT msg FROM messages;
```

## NEW_LINE

`NEW_LINE` 프로시저는 메시지 버퍼에 줄 끝 문자 시퀀스를 씁니다.

```sql
NEW_LINE
```

### 매개변수 (Parameter)

`NEW_LINE` 프로시저는 어떤 매개변수도 요구하지 않습니다.

## PUT

`PUT` 프로시저는 메시지 버퍼에 문자열을 씁니다. 문자열 끝에 줄 끝 문자 시퀀스가 쓰이지 않습니다. 줄 끝 문자 시퀀스를 추가하려면 `NEW_LINE` 프로시저를 사용하세요.

```sql
PUT(<item> VARCHAR2)
```

### 매개변수 (Parameter)

`item`

메시지 버퍼에 쓰이는 텍스트입니다.

### 예제 (Examples)

다음 예제는 `PUT` 프로시저를 사용하여 `emp` 테이블의 직원 목록을 쉼표로 구분하여 표시합니다.

## SERVEROUTPUT

`SERVEROUTPUT` 프로시저는 메시지를 명령줄의 표준 출력 또는 메시지 버퍼로 보냅니다. `SERVEROUTPUT(TRUE)`를 설정하면 `ENABLE`도 암묵적으로 실행됩니다.

`SERVEROUTPUT`의 기본 설정은 구현에 따라 다릅니다. 예를 들어, Oracle SQL\*Plus에서는 `SERVEROUTPUT(FALSE)`가 기본값입니다. PSQL에서는 `SERVEROUTPUT(TRUE)`가 기본값입니다. 또한 Oracle SQL\*Plus에서는 EDB Postgres Advanced Server에 구현된 것처럼 저장 프로시저로 제어하는 것이 아니라 SQL\*Plus의 `SET` 명령을 사용하여 이 설정을 제어합니다.

```sql
SERVEROUTPUT(<stdout> BOOLEAN)
```

Oracle 스타일의 표시 출력을 얻으려면 `postgresql.conf` 파일에서 `dbms_output.serveroutput`을 `FALSE`로 설정하여 메시지 출력을 비활성화할 수 있습니다. 기본값은 `TRUE`이며, 이는 메시지 출력을 활성화합니다.

### 매개변수 (Parameter)

`stdout`

이후의 `PUT`, `PUT_LINE`, 또는 `NEW_LINE`이 텍스트를 명령줄의 표준 출력으로 직접 보내도록 하려면 `TRUE`로 설정합니다. 텍스트를 메시지 버퍼로 보내려면 `FALSE`로 설정합니다.

### 예제 (Examples)

이 익명 블록은 첫 번째 메시지를 명령줄로 보내고 두 번째 메시지를 메시지 버퍼로 보냅니다.

```sql
BEGIN
    DBMS_OUTPUT.SERVEROUTPUT(TRUE);
    DBMS_OUTPUT.PUT_LINE('This message goes to the command line');
    DBMS_OUTPUT.SERVEROUTPUT(FALSE);
    DBMS_OUTPUT.PUT_LINE('This message goes to the message buffer');
END;
```
