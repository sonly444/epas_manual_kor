# DBMS_XMLDOM

`DBMS_XMLDOM` 패키지는 문서 객체 모델(Document Object Model, DOM)을 구현하며, DOM 문서를 처음부터 또는 XML 문서로부터 생성하는 데 사용됩니다.

EDB Postgres Advanced Server의 `DBMS_XMLDOM` 구현은 Oracle 버전과 비교할 때 부분 구현입니다. 다음 표에 나열된 함수와 프로시저만 지원됩니다.

## 타입 (Types)

`DBMS_XMLDOM` 패키지는 다음 타입을 구현합니다.

| 타입 이름 | 설명 |
| --- | --- |
| `DOMNode` | DOM Node 인터페이스를 구현합니다. |
| `DOMNodeList` | DOM NodeList 인터페이스를 구현합니다. |
| `DOMElement` | DOM Element 인터페이스를 구현합니다. |
| `DOMText` | DOM Text 인터페이스를 구현합니다. |
| `DOMDocument` | DOM Document 인터페이스를 구현합니다. |

## 서브프로그램 (Subprograms)

이 표는 `DBMS_XMLDOM` 패키지에서 사용할 수 있는 서브프로그램을 나열합니다.

| 서브프로그램 | 유형 | 반환 유형 | 설명 |
| --- | --- | --- | --- |
| `APPENDCHILD` | 함수 | DOMNode | 노드에 새 자식을 추가합니다. |
| `CREATEELEMENT` | 함수 | DOMElement | 엘리먼트를 생성합니다. |
| `CREATETEXTNODE` | 함수 | DOMText | 텍스트 노드를 생성합니다. |
| `FREEDOCUMENT` | 프로시저 | N/A | DOMDocument와 관련된 리소스를 해제합니다. |
| `GETATTRIBUTE` | 함수 | DOMElement | 속성 이름에 지정된 속성 값을 검색하여 VARCHAR2를 반환합니다. |
| `GETCHILDNODES` | 함수 | DOMNodeList | 노드의 자식들을 검색합니다. |
| `GETFIRSTCHILD` | 함수 | DOMNode | 노드의 첫 번째 자식을 검색합니다. |
| `GETLENGTH` | 함수 | PLS_INTEGER | 지정된 DOMNodeList의 항목 수를 검색합니다. |
| `GETNODENAME` | 함수 | VARCHAR2 | 노드의 이름을 검색합니다. |
| `GETNODEVALUE` | 함수 | VARCHAR2 | 노드의 값을 검색합니다. |
| `GETXMLTYPE` | 함수 | XMLTYPE | DOMDocument를 XMLType으로 변환하여 반환합니다. |
| `ITEM` | 함수 | DOMNode | NODELIST에서 지정된 인덱스의 항목을 검색합니다. |
| `MAKEELEMENT` | 함수 | DOMElement | 노드를 DOMElement로 캐스팅합니다. |
| `MAKENODE` | 함수 | DOMNode | 속성을 노드로 캐스팅합니다. |
| `NEWDOMDOCUMENT` | 함수 | DOMDocument | 문서를 생성합니다. |
| `SETATTRIBUTE` | 프로시저 | N/A | DOMElement의 속성 값을 설정합니다. |
| `SETVERSION` | 프로시저 | N/A | 문서의 버전을 설정합니다. |
