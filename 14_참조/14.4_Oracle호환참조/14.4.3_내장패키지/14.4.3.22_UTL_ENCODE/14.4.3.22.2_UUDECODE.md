# UUDECODE — EPAS 18 내장 패키지 UTL_ENCODE
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › UTL_ENCODE › UUDECODE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/19_utl_encode/09_uudecode/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`UUDECODE` 함수는 uuencode로 인코딩된 문자열을 원래 `UUENCODE` 함수로 인코딩되었던 `RAW` 값으로 변환하고 디코딩하는 데 사용합니다. 시그니처는 다음과 같습니다.

```sql
UUDECODE(<r> IN RAW)
```

이 함수는 `RAW` 값을 반환합니다.

Oracle에서 구현된 `UTL_ENCODE.UUENCODE` 함수로 생성된 uuencode 데이터를 디코딩하기 위해 EDB Postgres Advanced Server의 `UUDECODE` 함수를 사용하는 경우, Oracle에서 생성된 데이터에 대해 EDB Postgres Advanced Server의 `UUDECODE` 함수를 호출하기 전에 먼저 EDB Postgres Advanced Server 구성 파라미터 `utl_encode.uudecode_redwood`를 `TRUE`로 설정해야 합니다. 예를 들어, uuencode 데이터가 포함된 Oracle 테이블을 EDB Postgres Advanced Server 데이터베이스로 마이그레이션한 경우 이러한 상황이 발생할 수 있습니다.

Oracle 버전의 `UUENCODE` 함수로 생성된 uuencode 데이터는 EDB Postgres Advanced Server의 `UUENCODE` 함수로 생성된 uuencode 데이터와 형식이 다릅니다. 따라서 Oracle에서 uuencode된 데이터에 EDB Postgres Advanced Server의 `UUDECODE` 함수를 사용하려고 하면 구성 파라미터 `utl_encode.uudecode_redwood`가 `TRUE`로 설정되어 있지 않은 한 오류가 발생합니다.

그러나 EDB Postgres Advanced Server의 `UUENCODE` 함수로 생성된 uuencode 데이터에 EDB Postgres Advanced Server의 `UUDECODE` 함수를 사용하는 경우에는 `utl_encode.uudecode_redwood`를 `FALSE`로 설정해야 하며, 이것이 기본 설정입니다.

## 파라미터 (Parameters)

`r`

`r`에는 `RAW`로 변환할 uuencode된 문자열이 들어 있습니다.

## 예제 (Example)

예제를 실행하기 전에 다음 명령을 실행합니다.

```sql
SET bytea_output = escape;
```

이 명령은 출력할 수 없는 문자를 이스케이프 처리하고 `BYTEA` 또는 `RAW` 값을 화면에 읽을 수 있는 형태로 표시합니다. 자세한 내용은 [Postgres 코어 문서](https://www.postgresql.org/docs/current/static/datatype-binary.html)를 참조하세요.

이 예제는 `UUENCODE`와 `UUDECODE`를 사용하여 문자열을 먼저 인코딩한 다음 디코딩합니다.

```sql
edb=# SET bytea_output = escape;
SET
edb=# SELECT UTL_ENCODE.UUENCODE('What is the date?') FROM DUAL;
```

출력(Output)

```text
                              uuencode
--------------------------------------------------------------------
begin 0 uuencode.txt\01215VAA="!I<R!T:&4@9&%T93\\`\012`\012end\012
(1 row)
```

```sql
edb=# SELECT UTL_ENCODE.UUDECODE
edb-# ('begin 0 uuencode.txt\01215VAA="!I<R!T:&4@9&%T93\\`\012`\012end\012')
edb-# FROM DUAL;
```

출력(Output)

```text
     uudecode
-------------------
What is the date?
(1 row)
```
