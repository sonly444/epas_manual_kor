# UUENCODE — EPAS 18 내장 패키지 UTL_ENCODE
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › UTL_ENCODE › UUENCODE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/19_utl_encode/10_uuencode/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`UUENCODE` 함수는 `RAW` 데이터를 uuencode 형식으로 인코딩된 문자열로 변환하는 데 사용합니다. 시그니처는 다음과 같습니다.

```sql
UUENCODE(<r> IN RAW, <type> IN INTEGER DEFAULT 1, <filename> IN
VARCHAR2 DEFAULT NULL, <permission> IN VARCHAR2 DEFAULT NULL)
```

이 함수는 `RAW` 값을 반환합니다.

## 파라미터 (Parameters)

`r`

`r`에는 uuencode 형식으로 변환할 `RAW` 문자열이 들어 있습니다.

`type`

`type`은 반환할 uuencode된 문자열의 유형을 지정하는 `INTEGER` 값 또는 상수입니다. 기본값은 `1`입니다. 가능한 값은 다음과 같습니다.

| 값 | 상수 |
| --- | --- |
| `1` | `complete` |
| `2` | `header_piece` |
| `3` | `middle_piece` |
| `4` | `end_piece` |

`filename`

`filename`은 인코딩된 형태에 포함하려는 파일 이름을 지정하는 `VARCHAR2` 값입니다. 파일 이름을 지정하지 않으면 `UUENCODE`는 인코딩된 형태에 `uuencode.txt`라는 파일 이름을 포함합니다.

`permission`

`permission`은 권한 모드를 지정하는 `VARCHAR2`입니다. 기본값은 `NULL`입니다.

## 예제 (Example)

예제를 실행하기 전에 다음 명령을 실행합니다.

```sql
SET bytea_output = escape;
```

이 명령은 출력할 수 없는 문자를 이스케이프 처리하고 `BYTEA` 또는 `RAW` 값을 화면에 읽을 수 있는 형태로 표시합니다. 자세한 내용은 [Postgres 코어 문서](https://www.postgresql.org/docs/current/static/datatype-binary.html)를 참조하세요.

이 예제는 `UUENCODE`와 `UUDECODE`를 사용하여 문자열을 먼저 인코딩한 다음 디코딩합니다.

```sql
edb=# SET bytea_output = escape;
SET
edb=# SELECT UTL_ENCODE.UUENCODE('What is the date?') FROM DUAL;
```

출력(Output)

```text
                              uuencode
--------------------------------------------------------------------
 begin 0 uuencode.txt\01215VAA="!I<R!T:&4@9&%T93\\`\012`\012end\012
(1 row)
```

```sql
edb=# SELECT UTL_ENCODE.UUDECODE
edb-# ('begin 0 uuencode.txt\01215VAA="!I<R!T:&4@9&%T93\\`\012`\012end\012')
edb-# FROM DUAL;
```

출력(Output)

```text
     uudecode
-------------------
 What is the date?
(1 row)
```
