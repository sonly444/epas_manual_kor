# BASE64_ENCODE — EPAS 18 내장 패키지 UTL_ENCODE
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › UTL_ENCODE › BASE64_ENCODE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/19_utl_encode/02_base64_encode/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`BASE64_ENCODE` 함수는 RFC 4648에 설명된 대로 문자열을 Base64 형식으로 변환하고 인코딩하는 데 사용합니다. 이 함수는 `UTL_SMTP` 패키지를 사용하여 보낼 `MIME` 이메일을 작성할 때 유용할 수 있습니다. `BASE64_ENCODE` 함수에는 두 가지 시그니처가 있습니다.

```sql
BASE64_ENCODE(<r> IN RAW)
```

그리고

```sql
BASE64_ENCODE(<loid> IN OID)
```

이 함수는 `RAW` 값 또는 `OID`를 반환합니다.

## 파라미터 (Parameters)

`r`

`r`은 Base64로 변환할 `RAW` 문자열을 지정합니다.

`loid`

`loid`는 Base64로 변환할 라지 오브젝트의 오브젝트 ID를 지정합니다.

## 예제 (Example)

예제를 실행하기 전에 다음 명령을 실행합니다.

```sql
SET bytea_output = escape;
```

이 명령은 서버가 출력할 수 없는 문자를 이스케이프 처리하고 `BYTEA` 또는 `RAW` 값을 화면에 읽을 수 있는 형태로 표시하도록 지시합니다. 자세한 내용은 [Postgres 코어 문서](https://www.postgresql.org/docs/current/static/datatype-binary.html)를 참조하세요.

이 예제는 먼저 `abc`라는 텍스트가 포함된 문자열을 `BASE64_ENCODE`를 사용하여 인코딩한 다음, `BASE64_DECODE`를 사용하여 문자열을 디코딩합니다.

```sql
edb=# SELECT UTL_ENCODE.BASE64_ENCODE(CAST ('abc' AS RAW));
```

출력(Output)

```text
 base64_encode
---------------
 YWJj
(1 row)
```

```sql
edb=# SELECT UTL_ENCODE.BASE64_DECODE(CAST ('YWJj' AS RAW));
```

출력(Output)

```text
 base64_decode
---------------
 abc
(1 row)
```
