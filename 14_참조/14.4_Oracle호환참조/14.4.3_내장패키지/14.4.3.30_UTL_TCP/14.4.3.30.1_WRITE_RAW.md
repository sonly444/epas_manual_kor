# WRITE_RAW — EPAS 18 내장 패키지 UTL_TCP
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › UTL_TCP › WRITE_RAW](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/utl_tcp/write_raw/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`WRITE_RAW` 함수는 이미 설정된 연결을 통해 원격 호스트로 원시 바이너리 데이터를 전송합니다.

```sql
WRITE_RAW (
  c    IN connection,
  data IN BYTEA
) RETURN INTEGER;
```

## 파라미터 (Parameters)

`c`

활성 세션의 연결 핸들로, 원래 `OPEN_CONNECTION`이 반환한 값입니다.

`data`

전송할 바이너리 데이터(BYTEA)입니다.

## 반환 값 (Return value)

| 유형 | 설명 |
| --- | --- |
| INTEGER | 연결 버퍼에 성공적으로 기록된 총 바이트 수입니다. |

## 참고 (Notes)

- **바이너리 무결성(Binary integrity):** 이 함수는 이미지, 압축 파일, 암호화된 blob과 같은 비텍스트 데이터를 전송하는 데 사용됩니다.

- **줄바꿈 없음(No newline):** 이 함수는 어떠한 줄바꿈 문자도 추가하지 않으며, data 파라미터에 포함된 정확한 바이트만 전송합니다.

- **버퍼 제한(Buffer limits):** 매우 큰 `BYTEA` 객체의 경우, 한 번의 호출로 기록되는 데이터 양이 `OPEN_CONNECTION` 중에 정의된 `out_buffer_size`에 의해 제한될 수 있습니다.


## 예제 (Example)

```sql
DECLARE
  c      UTL_TCP.CONNECTION;
  count  INT;
BEGIN
  c := UTL_TCP.OPEN_CONNECTION('mail-arts.enterprisedb.com', 25);
  count := UTL_TCP.WRITE_RAW(c, 'Hello'::bytea);
  count := UTL_TCP.WRITE_RAW(c, 'World'::bytea);
  UTL_TCP.CLOSE_CONNECTION(c);
END;
```
