# SUBSTR

`SUBSTR` 연산은 지정된 오프셋에서 시작하여 대형 객체(large object) 또는 BFILE의 일부를 반환합니다. 반환되는 데이터는 원시(raw) 데이터입니다.

```sql
<data> { RAW | VARCHAR2 } SUBSTR(<lob_loc> { BLOB | CLOB }
   [, <amount> NUMBER [, <offset> NUMBER ]])

<data> { RAW } SUBSTR(<file_loc> IN { BFILE }[, <amount> IN NUMBER, <offset> IN NUMBER])
```

## 파라미터 (Parameters)

`lob_loc`

읽을 대형 객체의 대형 객체 로케이터(locator)입니다.

`file_loc`

읽을 BFILE에 대한 파일 로케이터(locator)입니다.

`amount`

반환할 바이트/문자 수입니다. 기본값은 32,767입니다.

`offset`

데이터 반환을 시작할 대형 객체 내의 위치입니다. 첫 번째 바이트/문자의 위치는 1입니다. 기본값은 1입니다.

`data`

읽어서 반환된 대형 객체의 일부입니다. `lob_loc`가 `BLOB`이거나 `file_loc`가 `BFILE`이면 반환 데이터 타입은 `RAW`입니다. `lob_loc`가 `CLOB`이면 반환 데이터 타입은 `VARCHAR2`입니다.

## 예제 (Example)

```sql
DECLARE
   src_loc      BFILE := BFILENAME('ANOTHER_DIR', 'a.txt');
   Position     NUMBER := 1;
   Buffer       RAW(1024);
   Amount       NUMBER := 1024;
BEGIN
  /* Opening the source BFILE is mandatory */
   DBMS_LOB.OPEN(src_loc, DBMS_LOB.LOB_READONLY);

   Buffer := DBMS_LOB.SUBSTR(src_loc, Amount, position);

   /* Close the BFILE: */
   DBMS_LOB.FILECLOSE(src_loc);
   COMMIT;
END;
```
