# WRITE

`WRITE` 프로시저는 대형 객체(large object)에 데이터를 기록합니다. 지정된 오프셋에서 지정된 길이만큼의 대형 객체 내 기존 데이터는 버퍼에 주어진 데이터로 덮어써집니다.

```sql
WRITE(<lob_loc> IN OUT { BLOB | CLOB },
  <amount> NUMBER,
  <offset> NUMBER, <buffer> { RAW | VARCHAR2 })
```

## 파라미터 (Parameters)

`lob_loc`

기록할 대형 객체의 대형 객체 로케이터(locator)입니다.

`amount`

`buffer`에서 대형 객체에 기록할 바이트/문자 수입니다.

`offset`

기록 작업을 시작할, 대형 객체의 시작 지점(원점은 1)부터의 오프셋(바이트/문자 단위)입니다.

`buffer`

대형 객체에 기록할 데이터를 담고 있습니다. `lob_loc`가 `BLOB`이면 `buffer`는 `RAW`여야 합니다. `lob_loc`가 `CLOB`이면 `buffer`는 `VARCHAR2`여야 합니다.
