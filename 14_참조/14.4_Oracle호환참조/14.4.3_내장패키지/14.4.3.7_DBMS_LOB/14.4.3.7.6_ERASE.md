# ERASE

`ERASE` 프로시저는 대형 객체(large object)의 일부를 지웁니다. 대형 객체를 지운다는 것은 지정된 부분을 `BLOB`의 경우 0바이트 채움 문자(zero-byte filler)로, `CLOB`의 경우 공백으로 대체하는 것을 의미합니다. 대형 객체의 실제 크기는 변경되지 않습니다.

```sql
ERASE(<lob_loc> IN OUT { BLOB | CLOB }, <amount> IN OUT NUMBER
  [, <offset> NUMBER ])
```

## 파라미터 (Parameters)

`lob_loc`

지울 대형 객체의 대형 객체 로케이터(locator)입니다.

`amount IN`

지울 바이트/문자 수입니다.

`amount OUT`

지워진 바이트/문자 수입니다. `amount` 바이트/문자를 지우기 전에 대형 객체의 끝에 도달하면 이 값은 입력 값보다 작을 수 있습니다.

`offset`

지우기를 시작할 대형 객체 내의 위치입니다. 첫 번째 바이트/문자의 위치는 1입니다. 기본값은 1입니다.
