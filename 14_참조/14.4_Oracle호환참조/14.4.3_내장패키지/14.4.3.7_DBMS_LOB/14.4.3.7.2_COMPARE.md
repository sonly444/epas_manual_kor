# COMPARE

`COMPARE` 프로시저는 지정된 오프셋에서 지정된 길이만큼 두 대형 객체(large object)를 바이트 단위로 정확하게 비교합니다. 비교 대상이 되는 대형 객체는 동일한 데이터 타입이어야 합니다. 이 프로시저를 사용해 BFILE을 비교할 때는 BFILE이 이미 열려 있어야 합니다.

```sql
<status> NUMBER COMPARE(<lob_1> { BLOB | CLOB },
   <lob_2> { BLOB | CLOB }
   [, <amount> NUMBER [, <offset_1> NUMBER [, <offset_2> NUMBER ]]])

<status> NUMBER COMPARE(<lob_1> { BFILE}, <lob_2> { BFILE }
   [, <amount> NUMBER [, <offset_1> NUMBER [, <offset_2> NUMBER ]]])
```

## 파라미터 (Parameters)

`lob_1`

비교할 첫 번째 대형 객체의 대형 객체 로케이터(locator)입니다. `lob_2`와 동일한 데이터 타입이어야 합니다.

`lob_2`

비교할 두 번째 대형 객체의 대형 객체 로케이터(locator)입니다. `lob_1`과 동일한 데이터 타입이어야 합니다.

`amount`

대형 객체의 데이터 타입이 `BLOB` 또는 `BFILE`이면 `amount` 바이트만큼 비교합니다. 대형 객체의 데이터 타입이 `CLOB`이면 `amount` 문자만큼 비교합니다. 기본값은 대형 객체의 최대 크기입니다.

`offset_1`

첫 번째 대형 객체에서 비교를 시작할 위치입니다. 첫 번째 바이트/문자의 오프셋은 1입니다. 기본값은 1입니다.

`offset_2`

두 번째 대형 객체에서 비교를 시작할 위치입니다. 첫 번째 바이트/문자의 오프셋은 1입니다. 기본값은 1입니다.

`status`

지정된 오프셋에서 지정된 길이만큼 두 대형 객체가 완전히 동일하면 0을 반환합니다. 두 객체가 동일하지 않으면 0이 아닌 값을 반환합니다. `amount`, `offset_1`, `offset_2` 중 하나라도 0보다 작으면 `NULL`을 반환합니다.

## 예제 (Example)

```sql
DECLARE
   /* Initialize the BFILE locator: */
   File_loc1       BFILE := BFILENAME('ANOTHER_DIR', 'a.txt');
   File_loc2       BFILE := BFILENAME('ANOTHER_DIR', 'b.txt');
   Retval          NUMBER;
BEGIN
   DBMS_LOB.OPEN(File_loc1, DBMS_LOB.LOB_READONLY);
   DBMS_LOB.OPEN(File_loc2, DBMS_LOB.LOB_READONLY);
   Retval := DBMS_LOB.COMPARE(File_loc2, File_loc1, DBMS_LOB.LOBMAXSIZE, 1, 1);
   DBMS_OUTPUT.PUT_LINE('BFILE comparison result :' || Retval);
   /* Close the BFILEs: */
   DBMS_LOB.CLOSE(File_loc1);
   DBMS_LOB.CLOSE(File_loc2);
END;
```
