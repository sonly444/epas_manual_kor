# APPEND

`APPEND` 프로시저는 하나의 대형 객체(large object)를 다른 대형 객체에 추가합니다. 두 대형 객체는 반드시 동일한 타입이어야 합니다.

```sql
APPEND(<dest_lob> IN OUT { BLOB | CLOB }, <src_lob> { BLOB | CLOB })
```

## 파라미터 (Parameters)

`dest_lob`

대상 객체에 대한 대형 객체 로케이터(locator)입니다. `src_lob`와 동일한 데이터 타입이어야 합니다.

`src_lob`

원본 객체에 대한 대형 객체 로케이터(locator)입니다. `dest_lob`와 동일한 데이터 타입이어야 합니다.
