# WRITEAPPEND

`WRITEAPPEND` 프로시저는 대형 객체(large object)의 끝에 데이터를 추가합니다.

```sql
WRITEAPPEND(<lob_loc> IN OUT { BLOB | CLOB },
  <amount> NUMBER, <buffer> { RAW | VARCHAR2 })
```

## 파라미터 (Parameters)

`lob_loc`

데이터를 추가할 대형 객체의 대형 객체 로케이터(locator)입니다.

`amount`

`buffer`에서 대형 객체에 추가할 바이트/문자 수입니다.

`buffer`

대형 객체에 추가할 데이터입니다. `lob_loc`가 `BLOB`이면 `buffer`는 `RAW`여야 합니다. `lob_loc`가 `CLOB`이면 `buffer`는 `VARCHAR2`여야 합니다.
