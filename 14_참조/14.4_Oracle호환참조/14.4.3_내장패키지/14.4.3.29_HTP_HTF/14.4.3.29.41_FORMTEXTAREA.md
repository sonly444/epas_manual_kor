# FORMTEXTAREAOPEN, FORMTEXTAREAOPEN2, and FORMTEXTAREACLOSE — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › FORMTEXTAREAOPEN, FORMTEXTAREAOPEN2, and FORMTEXTAREACLOSE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/formtextarea/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수들과 프로시저들은 `<TEXTAREA>` 및 `</TEXTAREA>` 태그를 생성하며, 이 태그는 텍스트 영역 폼 요소를 만듭니다. 두 open 함수 및 프로시저의 차이점은 `htp.formTextareaOpen2`에는 랩(wrap) 스타일을 지정하는 `cwrap` 파라미터가 있다는 것입니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.FORMTEXTAREAOPEN (
   cname          IN       VARCHAR2
   nrows          IN       INTEGER
   ncolumns       IN       INTEGER
   calign         IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);

HTP.FORMTEXTAREAOPEN2(
   cname          IN       VARCHAR2
   nrows          IN       INTEGER
   ncolumns       IN       INTEGER
   calign         IN       V2         DEFAULT NULL
   cwrap          IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);

HTP.FORMTEXTAREACLOSE;
```

다음은 HTF의 구문입니다.

```text
HTF.FORMTEXTAREAOPEN (cname, nrows, ncolumns, calign, cattributes) RETURN VARCHAR2;

HTF.FORMTEXTAREAOPEN2(cname, nrows, ncolumns, calign, cwrap, cattributes) RETURN VARCHAR2;
HTF.FORMTEXTAREACLOSE RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| cname | NAME 속성의 값 |
| nrows | ROWS 속성의 정수 값 |
| ncolumns | COLS 속성의 정수 값 |
| calign | ALIGN 속성의 값 |
| cwrap | WRAP 속성의 값 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
