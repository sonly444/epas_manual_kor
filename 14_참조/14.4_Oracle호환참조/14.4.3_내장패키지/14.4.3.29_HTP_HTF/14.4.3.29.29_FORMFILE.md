# FORMFILE — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › FORMFILE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/formfile/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 `TYPE="file"`이 지정된 `<INPUT>` 태그를 생성합니다. 이 태그를 사용하면 사용자가 폼과 함께 그 내용을 제출할 수 있는 파일을 선택할 수 있습니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.FORMFILE(
   cname          IN       varchar2
   caccept        IN       varchar2   DEFAULT NULL
   cattributes    IN       varchar2   DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.FORMFILE (cname, caccept, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| cname | NAME 속성의 값 |
| caccept | 업로드할 MIME 타입의 쉼표로 구분된 목록 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
