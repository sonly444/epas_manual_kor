# IMG and IMG2 — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › IMG and IMG2](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/img/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수들과 프로시저들은 `<IMG>` 태그를 생성하며, 이 태그는 HTML 페이지에 이미지를 로드합니다. 이 두 구문의 차이점은 `htp.img2`가 `cusemap` 파라미터를 사용한다는 것입니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.IMG (
   curl           IN       VARCHAR2   DEFAULT NULL
   calign         IN       VARCHAR2   DEFAULT NULL
   calt           IN       VARCHAR2   DEFAULT NULL
   cismap         IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);

htp.img2(
   calign         IN       VARCHAR2   DEFAULT NULL
   calt           IN       VARCHAR2   DEFAULT NULL
   cismap         IN       VARCHAR2   DEFAULT NULL
   cusemap        IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.IMG (curl, calign, calt, cismap, cattributes) RETURN VARCHAR2;

HTF.IMG2(curl, calign, calt, cismap, cusemap, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| curl | SRC 속성의 값. |
| calign | ALIGN 속성의 값. |
| calt | ALT 속성의 값으로, 브라우저가 이미지를 지원하지 않을 경우 표시할 대체 텍스트를 지정합니다. |
| cismap | 이 파라미터의 값이 `NULL`이 아니면 태그에 ISMAP 속성을 추가합니다. 이 속성은 이미지가 이미지맵임을 나타냅니다. |
| cusemap | USEMAP 속성의 값으로, 클라이언트 측 이미지 맵을 지정합니다. |
| cattributes | 태그에 그대로 포함할 기타 속성. |
