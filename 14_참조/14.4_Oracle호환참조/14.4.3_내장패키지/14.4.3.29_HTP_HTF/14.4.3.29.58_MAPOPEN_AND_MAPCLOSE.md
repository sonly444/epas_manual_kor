# MAPOPEN and MAPCLOSE — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › MAPOPEN and MAPCLOSE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/mapopen_and_mapclose/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 `<MAP>` 및 `</MAP>` 태그를 생성하며, 이 태그는 클라이언트 측 이미지 맵에서 일련의 영역을 표시합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.MAPOPEN(
   cname          IN       VARCHAR2
   cattributes    IN       VARCHAR2   DEFAULT NULL);

HTP.MAPCLOSE;
```

다음은 HTF의 구문입니다.

```text
HTF.MAPOPEN(cname, cattributes) RETURN VARCHAR2;

HTF.MAPCLOSE RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| cname | NAME 속성의 값 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
