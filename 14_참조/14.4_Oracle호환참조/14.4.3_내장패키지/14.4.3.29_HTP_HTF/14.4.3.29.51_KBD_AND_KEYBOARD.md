# KBD and KEYBOARD — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › KBD and KEYBOARD](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/kbd_and_keyboard/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수들과 프로시저들은 `<KBD>` 및 `</KBD>` 태그를 생성하며, 이 태그는 텍스트를 고정폭(monospace) 글꼴로 렌더링합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.KEYBOARD (
   ctext          IN       VARCHAR2
   cattributes    IN       VARCHAR2   DEFAULT NULL);

HTP.KBD (
   ctext          IN       VARCHAR2
   cattributes    IN       VARCHAR2   DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.KEYBOARD (ctext, cattributes) RETURN VARCHAR2;

HTF.KBD (ctext, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| ctext | 고정폭으로 렌더링할 텍스트 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
