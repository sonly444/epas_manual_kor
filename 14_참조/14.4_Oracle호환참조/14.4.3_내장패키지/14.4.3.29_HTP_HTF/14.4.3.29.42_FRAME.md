# FRAME — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › FRAME](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/frame/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 `<FRAME>` 태그를 생성하며, 이 태그는 `<FRAMESET>` 태그로 만들어진 프레임의 특성을 정의합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.FRAME(
   csrc           IN       VARCHAR2
   cname          IN       VARCHAR2   DEFAULT NULL
   cmarginwidth   IN       VARCHAR2   DEFAULT NULL
   cmarginheight  IN       VARCHAR2   DEFAULT NULL
   cscrolling     IN       VARCHAR2   DEFAULT NULL
   cnoresize      IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.FRAME (csrc, cname, cmarginwidth, cmarginheight, cscrolling, cnoresize, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| csrc | 프레임에 표시할 URL |
| cname | NAME 속성의 값 |
| cmarginwidth | MARGINWIDTH 속성의 값 |
| cmarginheight | MARGINHEIGHT 속성의 값 |
| cscrolling | SCROLLING 속성의 값 |
| noresize | 이 파라미터의 값이 `NULL`이 아니면 태그에 NORESIZE 속성을 추가합니다 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
