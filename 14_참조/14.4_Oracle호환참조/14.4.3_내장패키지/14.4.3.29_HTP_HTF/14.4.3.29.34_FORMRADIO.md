# FORMRADIO — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › FORMRADIO](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/formradio/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 `TYPE="radio"`가 지정된 `<INPUT>` 태그를 생성합니다. 이 태그는 HTML 폼에 라디오 버튼(단일 선택 옵션)을 만듭니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.FORMRADIO (
   cname          IN       VARCHAR2
   cvalue         IN       VARCHAR2
   cchecked       IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.FORMRADIO (cname, cvalue, cchecked, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| cname | NAME 속성의 값 |
| cvalue | VALUE 속성의 값 |
| cchecked | 이 파라미터의 값이 `NULL`이 아니면 태그에 CHECKED 속성을 추가합니다 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
