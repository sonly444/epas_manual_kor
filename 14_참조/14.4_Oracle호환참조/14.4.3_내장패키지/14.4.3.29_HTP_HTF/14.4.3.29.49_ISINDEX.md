# ISINDEX — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › ISINDEX](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/isindex/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 `"Enter value"`와 같은 텍스트 프롬프트가 있는 단일 입력 필드를 생성한 다음, 그 값을 페이지 또는 프로그램의 URL로 전송합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.ISINDEX (
   cprompt        IN       VARCHAR2    DEFAULT NULL
   curl           IN       VARCHAR2    DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.ISINDEX (cprompt, curl) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| cprompt | PROMPT 속성의 값 |
| curl | HREF 속성의 값 |
