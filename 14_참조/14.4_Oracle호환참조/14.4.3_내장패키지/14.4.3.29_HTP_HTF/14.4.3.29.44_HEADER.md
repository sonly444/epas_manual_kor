# HEADER — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › HEADER](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/header/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 제목 태그(`<H1>`부터 `<H6>`까지)와 그에 대응하는 닫는 태그(`</H1>`부터 `</H6>`까지)를 생성합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.HEADER (
   nsize          IN       INTEGER
   cheader        IN       VARCHAR2
   calign         IN       VARCHAR2   DEFAULT NULL
   cnowrap        IN       VARCHAR2   DEFAULT NULL
   cclear         IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.HEADER (nsize, cheader, calign, cnowrap, cclear, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| nsize | 제목 수준으로, 1에서 6 사이의 정수로 설정합니다 |
| calign | ALIGN 속성의 값 |
| cheader | 제목에 표시할 텍스트 |
| cnowrap | NOWRAP 속성의 값 |
| cclear | CLEAR 속성의 값 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
