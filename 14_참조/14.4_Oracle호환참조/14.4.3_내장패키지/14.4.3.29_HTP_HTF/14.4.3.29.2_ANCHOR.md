# ANCHOR and ANCHOR2 — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › ANCHOR and ANCHOR2](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/anchor/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수들과 프로시저들은 `<A>` 및 `</A>` HTML 태그를 생성하며, 이 태그는 하이퍼텍스트 링크의 소스 또는 대상을 지정합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.ANCHOR (
   curl           IN       VARCHAR2
   ctext          IN       VARCHAR2
   cname          IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);

HTP.ANCHOR2 (
   curl           IN       VARCHAR2
   ctext          IN       VARCHAR2
   cname          IN       VARCHAR2   DEFAULT NULL
   ctarget        IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.ANCHOR (curl, ctext, cname, cattributes) RETURN VARCHAR2;

HTF.ANCHOR2 (curl, ctext, cname, ctarget, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| curl | HREF 속성의 값 |
| ctext | `<A>` 태그와 `</A>` 태그 사이에 들어가는 문자열 |
| cname | NAME 속성의 값 |
| ctarget | TARGET 속성의 값 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
