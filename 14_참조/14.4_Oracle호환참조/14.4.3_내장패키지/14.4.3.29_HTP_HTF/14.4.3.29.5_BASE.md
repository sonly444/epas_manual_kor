# BASE — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › BASE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/base/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 `<BASE>` HTML 태그를 생성하며, 이 태그는 문서의 URL을 기록합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.BASE(ctarget, cattributes) RETURN VARCHAR2;
```

다음은 HTF의 구문입니다.

```text
HTF.BASE(ctarget, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| ctarget | TARGET 속성의 값으로, 이 문서의 모든 링크가 대상으로 삼는 창(window) 이름을 설정합니다 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
