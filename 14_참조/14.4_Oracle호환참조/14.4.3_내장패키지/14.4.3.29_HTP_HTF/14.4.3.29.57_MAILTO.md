# MAILTO — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › MAILTO](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/mailto/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 HREF가 메일 주소 인수 앞에 `'mailto'`를 붙인 값으로 설정된 `<A>` 태그를 생성합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.MAILTO (
   caddress       IN       VARCHAR2
   ctext          IN       VARCHAR2
   cname          IN       VARCHAR2
   cattributes    IN       VARCHAR2   DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.MAILTO (caddress, ctext, cname, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| caddress | 수신자의 이메일 주소 |
| ctext | 링크에서 클릭 가능한 부분 |
| cname | NAME 속성의 값 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
