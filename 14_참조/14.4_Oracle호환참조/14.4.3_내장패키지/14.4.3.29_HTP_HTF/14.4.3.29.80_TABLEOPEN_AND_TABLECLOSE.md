# TABLEOPEN and TABLECLOSE — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › TABLEOPEN and TABLECLOSE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/tableopen_and_tableclose/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 `<TABLE>` 및 `</TABLE>` 태그를 생성하며, 이 태그는 HTML 테이블을 정의합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.TABLEOPEN (
   cborder        IN       VARCHAR2   DEFAULT NULL
   calign         IN       VARCHAR2   DEFAULT NULL
   cnowrap        IN       VARCHAR2   DEFAULT NULL
   cclear         IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);

HTP.TABLECLOSE;
```

다음은 HTF의 구문입니다.

```text
HTF.TABLEOPEN (cborder, calign, cnowrap, cclear, cattributes) RETURN VARCHAR2;

HTF.TABLECLOSE RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| cborder | BORDER 속성의 값 |
| calign | ALIGN 속성의 값 |
| cnowrap | 이 파라미터의 값이 `NULL`이 아니면 태그에 NOWRAP 속성을 추가합니다 |
| cclear | CLEAR 속성의 값 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
