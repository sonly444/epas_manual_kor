# APPLETOPEN and APPLETCLOSE — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › APPLETOPEN and APPLETCLOSE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/applet/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`htp.appletopen`은 Java 애플릿을 호출하는 `<APPLET>` HTML 태그를 생성합니다. 애플릿은 `htp.appletclose`로 닫으며, 이는 `</APPLET>` HTML 태그를 생성합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.APPLETOPEN(
   ccode          IN       VARCHAR2
   cheight        IN       NUMBER
   cwidth         IN       NUMBER
   cattributes    IN       VARCHAR2   DEFAULT NULL);

HTP.APPLETCLOSE;
```

다음은 HTF의 구문입니다.

```text
HTF.APPLETOPEN(ccode, cheight, cwidth, cattributes) RETURN VARCHAR2;

HTF.APPLETCLOSE RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| ccode | CODE 속성의 값으로, 애플릿 클래스의 이름을 지정합니다 |
| cheight | HEIGHT 속성의 값 |
| cwidth | WIDTH 속성의 값 |
