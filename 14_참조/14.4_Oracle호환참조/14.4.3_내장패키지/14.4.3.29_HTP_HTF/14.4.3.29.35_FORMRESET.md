# FORMRESET — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › FORMRESET](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/formreset/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 `TYPE="reset"`이 지정된 `<INPUT>` 태그를 생성합니다. 이 태그는 폼 필드를 초기값으로 재설정하는 버튼을 만듭니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.FORMRESET (
   cvalue         IN       VARCHAR2   DEFAULT 'Reset'
   cattributes    IN       VARCHAR2   DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.FORMRESET (cvalue, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| cvalue | VALUE 속성의 값 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
