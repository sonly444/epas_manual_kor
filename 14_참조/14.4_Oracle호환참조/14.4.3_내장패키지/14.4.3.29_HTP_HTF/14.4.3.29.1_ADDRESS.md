# ADDRESS — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › ADDRESS](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/address/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 `<ADDRESS>` 및 `</ADDRESS>` 태그를 생성하며, 이 태그는 문서의 주소, 작성자, 서명을 지정합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.ADDRESS (
   cvalue         IN       VARCHAR2
   cnowrap        IN       VARCHAR2   DEFAULT NULL
   cclear         IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.ADDRESS (cvalue, cnowrap, cclear, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| cvalue | `<ADDRESS>` 태그와 `</ADDRESS>` 태그 사이에 들어가는 문자열 |
| cnowrap | 이 파라미터의 값이 `NULL`이 아니면 태그에 NOWRAP 속성을 추가합니다 |
| cclear | CLEAR 속성의 값 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
