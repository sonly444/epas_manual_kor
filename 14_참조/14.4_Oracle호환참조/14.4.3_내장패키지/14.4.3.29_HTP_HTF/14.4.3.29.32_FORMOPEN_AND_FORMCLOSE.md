# FORMOPEN and FORMCLOSE — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › FORMOPEN and FORMCLOSE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/formopen_and_formclose/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수와 프로시저는 `<FORM>` 및 `</FORM>` 태그를 생성하며, 이 태그는 HTML 문서에 폼 섹션을 만듭니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.FORMOPEN (
   curl           IN       VARCHAR2
   cmethod        IN       VARCHAR2   DEFAULT 'POST'
   ctarget        IN       VARCHAR2   DEFAULT NULL
   cenctype       IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);

htp.FORMCLOSE;
```

다음은 HTF의 구문입니다.

```text
HTF.FORMOPEN (curl, cmethod, ctarget, cenctype, cattributes) RETURN VARCHAR2;

HTF.FORMCLOSE RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| curl | 폼의 내용이 전송되는 WRB 또는 CGI 스크립트의 URL (필수) |
| cmethod | METHOD 속성의 값으로, `'GET'` 또는 `'POST'` 중 하나 |
| ctarget | TARGET 속성의 값 |
| cenctype | ENCTYPE 속성의 값 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
