# FORMTEXTAREA and FORMTEXTAREA2 — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › FORMTEXTAREA and FORMTEXTAREA2](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/formtextarea_and_formtextarea2/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수들과 프로시저들은 `<TEXTAREA>` 태그를 생성하며, 이 태그는 텍스트 영역에 미리 정의된 텍스트가 없는 텍스트 필드를 만듭니다. 이 필드를 사용하면 사용자가 여러 줄의 텍스트를 입력할 수 있습니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.FORMTEXTAREA (
   cname          IN       VARCHAR2
   nrows          IN       INTEGER
   ncolumns       IN       INTEGER
   calign         IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);

HTP.FORMTEXTAREA2 (
   cname          IN       VARCHAR2
   nrows          IN       INTEGER
   ncolumns       IN       INTEGER
   calign         IN       VARCHAR2   DEFAULT NULL
   cwrap          IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       varchar2   DEFAULT NULL);
```

다음은 HTF의 구문입니다.

```text
HTF.FORMTEXTAREA (cname, nrows, ncolumns, calign, cattributes) RETURN VARCHAR2;

HTF.FORMTEXTAREA2 (cname, nrows, ncolumns, calign, cwrap, cattributes) RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| cname | NAME 속성의 값 |
| nrows | ROWS 속성의 정수 값 |
| ncolumns | COLS 속성의 정수 값 |
| calign | ALIGN 속성의 값 |
| cwrap | WRAP 속성의 값 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
