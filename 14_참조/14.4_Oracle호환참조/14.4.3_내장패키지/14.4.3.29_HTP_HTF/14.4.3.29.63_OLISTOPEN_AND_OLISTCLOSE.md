# OLISTOPEN and OLISTCLOSE — EPAS 18 내장 패키지 HTP/HTF
> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › HTP and HTF › OLISTOPEN and OLISTCLOSE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/htp_and_htf/olistopen_and_olistclose/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

이 함수들과 프로시저들은 `<OL>` 및 `</OL>` 태그를 생성하며, 이 태그는 순서 있는(번호가 매겨진) 목록을 정의합니다.

## 구문 (Syntax)

다음은 HTP의 구문입니다.

```text
HTP.OLISTOPEN (
   cclear         IN       VARCHAR2   DEFAULT NULL
   cwrap          IN       VARCHAR2   DEFAULT NULL
   cattributes    IN       VARCHAR2   DEFAULT NULL);

HTP.OLISTCLOSE;
```

다음은 HTF의 구문입니다.

```text
HTF.OLISTOPEN (cclear, cwrap, cattributes) RETURN VARCHAR2;

HTF.OLISTCLOSE RETURN VARCHAR2;
```

## 파라미터 (Parameters)

| 파라미터 | 용도 |
| --- | --- |
| cclear | CLEAR 속성의 값 |
| cwrap | WRAP 속성의 값 |
| cattributes | 태그에 그대로 포함할 기타 속성 |
