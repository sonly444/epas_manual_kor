# SCHEMA_NAME — EPAS 18 내장 패키지 DBMS_ASSERT

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_ASSERT › SCHEMA_NAME](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/01a_dbms_assert/schema_name/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`SCHEMA_NAME` 함수는 입력 문자열이 기존에 존재하는 스키마 이름인지 여부를 판별합니다. 입력값이 유효한 스키마 이름이 아닌 경우 오류가 발생합니다.

```sql
SCHEMA_NAME(str VARCHAR2) RETURN VARCHAR2;
```

## 매개변수 (Parameters)

`str`

입력 문자열입니다. 공백이 큰따옴표 안에 포함되어 있지 않은 한, 문자열에서 공백은 제거됩니다. 대소문자 혼용이 허용됩니다.

입력 문자열은 기본적으로 소문자로 변환됩니다. 대소문자를 구분하는 이름을 검색하려면 해당 이름을 큰따옴표로 둘러싸십시오.

## 예제 (Examples)

```sql
edb=# SELECT SYS.DBMS_ASSERT.SCHEMA_NAME(current_database() || '."SCHEMA1"') FROM DUAL;
 schema_name
-------------
 edb."SCHEMA1"
(1 row)

edb=# SELECT SYS.DBMS_ASSERT.SCHEMA_NAME('"SCHEMA1"') FROM DUAL;
 schema_name
-------------
 SCHEMA1
(1 row)
```
