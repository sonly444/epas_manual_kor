# DBMS_RANDOM — EPAS 18 내장 패키지

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_RANDOM](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/12_dbms_random/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·역할 이름은 원문 그대로 보존했습니다.

`DBMS_RANDOM` 패키지는 임의(random) 값을 생성하는 메서드를 제공합니다. `DBMS_RANDOM` 패키지에서 사용할 수 있는 프로시저와 함수는 다음 표에 나열되어 있습니다.

| 함수/프로시저 | 반환 타입 | 설명 |
| --- | --- | --- |
| `INITIALIZE(val)` | 해당 없음 | `DBMS_RANDOM` 패키지를 지정된 시드 `value`로 초기화합니다. 더 이상 사용되지 않지만 하위 호환성을 위해 지원됩니다. |
| `NORMAL()` | `NUMBER` | 임의의 `NUMBER`를 반환합니다. |
| `RANDOM` | `INTEGER` | -2^31 이상 2^31 미만의 값을 가진 임의의 `INTEGER`를 반환합니다. 더 이상 사용되지 않지만 하위 호환성을 위해 지원됩니다. |
| `SEED(val)` | 해당 없음 | 지정된 `value`로 시드를 재설정합니다. |
| `SEED(val)` | 해당 없음 | 지정된 `value`로 시드를 재설정합니다. |
| `STRING(opt, len)` | `VARCHAR2` | 임의의 문자열을 반환합니다. |
| `TERMINATE` | 해당 없음 | `TERMINATE`는 아무런 효과가 없습니다. 더 이상 사용되지 않지만 하위 호환성을 위해 지원됩니다. |
| `VALUE` | `NUMBER` | 38자리 정밀도로 `0` 이상 `1` 미만의 값을 가진 임의의 숫자를 반환합니다. |
| `VALUE(low, high)` | `NUMBER` | `low` 이상 `high` 미만의 값을 가진 임의의 숫자를 반환합니다. |

## INITIALIZE

`INITIALIZE` 프로시저는 `DBMS_RANDOM` 패키지를 시드 값으로 초기화합니다. 시그니처는 다음과 같습니다.

```sql
INITIALIZE(<val> IN INTEGER)
```

이 프로시저는 더 이상 사용되지 않습니다. 하위 호환성을 위해 포함되어 있습니다.

### 매개변수 (Parameters)

`val`

`val`은 `DBMS_RANDOM` 패키지 알고리즘이 사용하는 시드 값입니다.

### 예제 (Example)

다음 코드는 `DBMS_RANDOM` 패키지를 시드 값 6475로 초기화하는 `INITIALIZE` 프로시저 호출을 보여줍니다.

```sql
DBMS_RANDOM.INITIALIZE(6475);
```

## NORMAL

`NORMAL` 함수는 `NUMBER` 타입의 임의의 숫자를 반환합니다. 시그니처는 다음과 같습니다.

```sql
<result> NUMBER NORMAL()
```

### 매개변수 (Parameters)

`result`

`result`는 `NUMBER` 타입의 임의의 값입니다.

### 예제 (Example)

다음 코드는 `NORMAL` 함수 호출을 보여줍니다.

```sql
x:= DBMS_RANDOM.NORMAL();
```

## RANDOM

`RANDOM` 함수는 -2^31 이상 2^31 미만인 임의의 `INTEGER` 값을 반환합니다. 시그니처는 다음과 같습니다.

```sql
<result> INTEGER RANDOM()
```

이 함수는 더 이상 사용되지 않습니다. 하위 호환성을 위해 포함되어 있습니다.

### 매개변수 (Parameters)

`result`

`result`는 `INTEGER` 타입의 임의의 값입니다.

### 예제 (Example)

다음 코드는 `RANDOM` 함수 호출을 보여줍니다. 이 호출은 임의의 숫자를 반환합니다.

```sql
x := DBMS_RANDOM.RANDOM();
```

## SEED

`SEED` 프로시저의 첫 번째 형식은 `INTEGER` 값으로 `DBMS_RANDOM` 패키지의 시드 값을 재설정합니다. `SEED` 프로시저는 두 가지 형식으로 제공됩니다. 첫 번째 형식의 시그니처는 다음과 같습니다.

```sql
SEED(<val> IN INTEGER)
```

### 매개변수 (Parameters)

`val`

`val`은 `DBMS_RANDOM` 패키지 알고리즘이 사용하는 시드 값입니다.

### 예제 (Example)

다음 코드는 `SEED` 프로시저 호출을 보여줍니다. 이 호출은 시드 값을 8495로 설정합니다.

```sql
DBMS_RANDOM.SEED(8495);
```

## SEED

`SEED` 프로시저의 두 번째 형식은 문자열 값으로 `DBMS_RANDOM` 패키지의 시드 값을 재설정합니다. `SEED` 프로시저는 두 가지 형식으로 제공됩니다. 두 번째 형식의 시그니처는 다음과 같습니다.

```sql
SEED(<val> IN VARCHAR2)
```

### 매개변수 (Parameters)

`val`

`val`은 `DBMS_RANDOM` 패키지 알고리즘이 사용하는 시드 값입니다.

### 예제 (Example)

다음 코드는 `SEED` 프로시저 호출을 보여줍니다. 이 호출은 시드 값을 `abc123`으로 설정합니다.

```sql
DBMS_RANDOM.SEED('abc123');
```

## STRING

`STRING` 함수는 사용자가 지정한 형식으로 임의의 `VARCHAR2` 문자열을 반환합니다. `STRING` 함수의 시그니처는 다음과 같습니다.

```sql
<result> VARCHAR2 STRING(<opt> IN CHAR, <len> IN NUMBER)
```

### 매개변수 (Parameters)

`opt`

반환되는 문자열의 서식 옵션입니다. `option`은 다음 중 하나일 수 있습니다.

| 옵션 | 지정하는 서식 옵션 |
| --- | --- |
| `u` 또는 `U` | 대문자 알파벳 문자열 |
| `l` 또는 `L` | 소문자 알파벳 문자열 |
| `a` 또는 `A` | 대소문자 혼합 문자열 |
| `x` 또는 `X` | 대문자 영숫자 문자열 |
| `p` 또는 `P` | 모든 인쇄 가능 문자 |

`len`

반환되는 문자열의 길이입니다.

`result`

`result`는 `VARCHAR2` 타입의 임의의 값입니다.

### 예제 (Example)

다음 코드는 `STRING` 함수 호출을 보여줍니다. 이 호출은 길이가 10인 임의의 영숫자 문자열을 반환합니다.

```sql
x := DBMS_RANDOM.STRING('X', 10);
```

## TERMINATE

`TERMINATE` 프로시저는 아무런 효과가 없습니다. 시그니처는 다음과 같습니다.

```sql
TERMINATE
```

`TERMINATE` 프로시저는 더 이상 사용되지 않습니다. 이 프로시저는 호환성을 위해 지원됩니다.

## VALUE

`VALUE` 함수는 38자리 정밀도로 0 이상 1 미만인 임의의 `NUMBER`를 반환합니다. `VALUE` 함수에는 두 가지 형식이 있습니다. 첫 번째 형식의 시그니처는 다음과 같습니다.

```sql
<result> NUMBER VALUE()
```

### 매개변수 (Parameters)

`result`

`result`는 `NUMBER` 타입의 임의의 값입니다.

### 예제 (Example)

다음 코드는 `VALUE` 함수 호출을 보여줍니다. 이 호출은 임의의 `NUMBER`를 반환합니다.

```sql
x := DBMS_RANDOM.VALUE();
```

## VALUE

`VALUE` 함수는 사용자가 지정한 경계 사이의 값을 가진 임의의 `NUMBER`를 반환합니다. `VALUE` 함수에는 두 가지 형식이 있습니다. 두 번째 형식의 시그니처는 다음과 같습니다.

```sql
<result> NUMBER VALUE(<low> IN NUMBER, <high> IN NUMBER)
```

### 매개변수 (Parameters)

`low`

`low`는 임의의 값의 하한 경계를 지정합니다. 임의의 값은 `low`와 같을 수 있습니다.

`high`

`high`는 임의의 값의 상한 경계를 지정합니다. 임의의 값은 `high`보다 작습니다.

`result`

`result`는 `NUMBER` 타입의 임의의 값입니다.

### 예제 (Example)

다음 코드는 `VALUE` 함수 호출을 보여줍니다. 이 호출은 1 이상 100 미만의 값을 가진 임의의 `NUMBER`를 반환합니다.

```sql
x := DBMS_RANDOM.VALUE(1, 100);
```
