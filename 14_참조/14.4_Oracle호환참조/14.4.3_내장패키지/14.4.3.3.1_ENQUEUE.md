# ENQUEUE — EPAS 18 내장 패키지 DBMS_AQ

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_AQ › ENQUEUE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/02_dbms_aq/01_enqueue/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

# ENQUEUE

`ENQUEUE` 프로시저는 큐(queue)에 항목을 추가합니다. 시그니처는 다음과 같습니다.

```sql
ENQUEUE(
  <queue_name> IN VARCHAR2,
  <enqueue_options> IN DBMS_AQ.ENQUEUE_OPTIONS_T,
  <message_properties> IN DBMS_AQ.MESSAGE_PROPERTIES_T,
  <payload> IN <type_name>,
  <msgid> OUT RAW)
```

## 매개변수 (Parameters)

`queue_name`

기존 큐의 이름(선택적으로 스키마로 한정 가능)입니다. 스키마 이름을 생략하면 서버는 `SEARCH_PATH`에 지정된 스키마를 사용합니다. Oracle과 달리, 따옴표로 감싸지 않은 식별자는 저장되기 전에 소문자로 변환됩니다. 특수 문자를 포함하거나 대소문자를 구분하는 이름을 사용하려면 이름을 큰따옴표로 감싸십시오.

큐 생성에 대한 자세한 정보는 [DBMS_AQADM.CREATE_QUEUE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/03_dbms_aqadm/03_create_queue/)를 참조하십시오.

`enqueue_options`

`enqueue_options`는 `enqueue_options_t` 타입의 값입니다.

```sql
DBMS_AQ.ENQUEUE_OPTIONS_T IS RECORD(
 visibility BINARY_INTEGER DEFAULT ON_COMMIT,
 relative_msgid RAW(16) DEFAULT NULL,
 sequence_deviation BINARY INTEGER DEFAULT NULL,
 transformation VARCHAR2(61) DEFAULT NULL,
 delivery_mode PLS_INTEGER NOT NULL DEFAULT PERSISTENT);
```

현재 `enqueue_options_t`에 대해 지원되는 매개변수 값은 다음뿐입니다.

| `visibility` | `ON_COMMIT`. |
| --- | --- |
| `delivery_mode` | `PERSISTENT` |
| `sequence_deviation` | `NULL` |
| `transformation` | `NULL` |
| `relative_msgid` | `NULL` |

`message_properties`

`message_properties`는 `message_properties_t` 타입의 값입니다.

```sql
message_properties_t IS RECORD(
  priority INTEGER,
  delay INTEGER,
  expiration INTEGER,
  correlation CHARACTER VARYING(128) COLLATE pg_catalog.”C”,
  attempts INTEGER,
  recipient_list “AQ$_RECIPIENT_LIST_T”,
  exception_queue CHARACTER VARYING(61) COLLATE pg_catalog.”C”,
  enqueue_time TIMESTAMP WITHOUT TIME ZONE,
  state INTEGER,
  original_msgid BYTEA,
  transaction_group CHARACTER VARYING(30) COLLATE pg_catalog.”C”,
  delivery_mode INTEGER
DBMS_AQ.PERSISTENT);
```

`message_properties_t`에 대해 지원되는 값은 다음과 같습니다.

|  |  |
| --- | --- |
| `priority` | 큐 테이블 정의에 `priority`를 참조하는 `sort_list`가 포함된 경우, 이 매개변수는 메시지가 디큐되는 순서에 영향을 줍니다. 값이 낮을수록 디큐 우선순위가 높음을 나타냅니다. |
| `delay` | 메시지가 디큐될 수 있게 되기까지 경과해야 할 초 수를 지정하거나 `NO_DELAY`를 지정합니다. |
| `expiration` | expiration 매개변수를 사용하여 메시지가 만료되기까지의 초 수를 지정합니다. |
| `correlation` | correlation을 사용하여 항목과 연결할 메시지를 지정합니다. 기본값은 `NULL`입니다. |
| `attempts` | 이는 메시지를 디큐하려고 시도한 횟수를 지정하는, 시스템이 유지 관리하는 값입니다. |
| `recipient_list` | 이 매개변수는 지원되지 않습니다. |
| `exception_queue` | `exception_queue` 매개변수를 사용하여, 메시지가 만료되거나 너무 여러 번 롤백하는 트랜잭션에 의해 디큐되는 경우 메시지를 이동할 예외 큐(exception queue)의 이름을 지정합니다. |
| `enqueue_time` | `enqueue_time`은 레코드가 큐에 추가된 시각입니다. 이 값은 시스템이 제공합니다. |
| `state` | 이 매개변수는 DBMS_AQ가 유지 관리합니다. state는 다음 중 하나일 수 있습니다.<br>`DBMS_AQ.WAITING` – delay에 도달하지 않았습니다.<br>`DBMS_AQ.READY` – 큐 항목이 처리 준비되었습니다.<br>`DBMS_AQ.PROCESSED` – 큐 항목이 처리되었습니다.<br>`DBMS_AQ.EXPIRED` – 큐 항목이 예외 큐로 이동되었습니다. |
| `original_msgid` | 이 매개변수는 호환성을 위해 허용되며 무시됩니다. |
| `transaction_group` | 이 매개변수는 호환성을 위해 허용되며 무시됩니다. |
| `delivery_mode` | 이 매개변수는 지원되지 않습니다. `DBMS_AQ.PERSISTENT` 값을 지정하십시오. |

`payload`

`payload` 매개변수를 사용하여 큐 항목과 연결할 데이터를 제공합니다. payload 타입은 해당 큐 테이블을 생성할 때 지정한 타입과 일치해야 합니다([DBMS_AQADM.CREATE_QUEUE_TABLE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/03_dbms_aqadm/04_create_queue_table/) 참조).

`msgid`

`msgid` 매개변수를 사용하여 고유한(시스템 생성) 메시지 식별자를 가져옵니다.

## 예제 (Example)

다음 익명 블록은 `DBMS_AQ.ENQUEUE`를 호출하여 `work_order`라는 이름의 큐에 메시지를 추가합니다.

```sql
DECLARE

  enqueue_options    DBMS_AQ.ENQUEUE_OPTIONS_T;
  message_properties DBMS_AQ.MESSAGE_PROPERTIES_T;
  message_handle     raw(16);
  payload            work_order;

BEGIN

  payload := work_order('Smith', 'system upgrade');

DBMS_AQ.ENQUEUE(
  queue_name         => 'work_order',
  enqueue_options    => enqueue_options,
  message_properties => message_properties,
  payload            => payload,
  msgid              => message_handle
    );
 END;
```
