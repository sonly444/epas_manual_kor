# SIMPLE_SQL_NAME — EPAS 18 내장 패키지 DBMS_ASSERT

> 원문: [EPAS v18 — Reference › Oracle compatibility › Built-in packages › DBMS_ASSERT › SIMPLE_SQL_NAME](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/03_built-in_packages/01a_dbms_assert/simple_sql_name/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 패키지·프로시저·함수 이름은 원문 그대로 보존했습니다.

`SIMPLE_SQL_NAME` 함수는 입력값이 단순(simple) SQL 이름인지 여부를 판별합니다.

```sql
SIMPLE_SQL_NAME(str VARCHAR2) RETURN VARCHAR2;
```

## 매개변수 (Parameters)

`str`

입력 문자열입니다. 문자열에서 공백은 제거됩니다. 대소문자 혼용이 허용됩니다. 문자열 안에는 큰따옴표가 허용됩니다.

## 예제 (Examples)

```sql
edb=# SELECT SYS.DBMS_ASSERT.SIMPLE_SQL_NAME('ABCD789$#_zxcvbnm') FROM DUAL;
  simple_sql_name
-------------------
 ABCD789$#_zxcvbnm
(1 row)

edb=# SELECT SYS.DBMS_ASSERT.SIMPLE_SQL_NAME('"12 valid name"') FROM DUAL;
 simple_sql_name
-----------------
 "12 valid name"

edb=# SELECT dbms_assert.simple_sql_name('    sch1.a1   ');
ERROR:  invalid SQL name
(1 row)
```
