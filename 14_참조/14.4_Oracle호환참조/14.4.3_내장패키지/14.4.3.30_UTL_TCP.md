# UTL_TCP

`UTL_TCP` 패키지는 TCP/IP 네트워크 서비스에 액세스하는 방법을 제공합니다. EDB Postgres Advanced Server는 다음 함수와 프로시저를 지원합니다.

| 함수/프로시저 | 반환 타입 | 설명 |
| --- | --- | --- |
| `OPEN_CONNECTION(remote_host, remote_port, local_host, local_port, in_buffer_size, out_buffer_size, charset, newline, tx_timeout, wallet_path, wallet_password, ssl_cert_path)` | `CONNECTION` | 이 함수를 사용하여 버퍼 크기와 문자 집합에 대한 선택적 파라미터와 함께 원격 호스트 및 포트에 대한 연결을 설정합니다. |
| `CLOSE_CONNECTION(c IN OUT)` |  | 이 프로시저를 사용하여 특정 활성 연결을 종료합니다. |
| `CLOSE_ALL_CONNECTIONS()` |  | 이 프로시저를 사용하여 현재 세션이 관리하는 모든 활성 연결을 닫습니다. |
| `WRITE_TEXT(c, data, len)` | `INTEGER` | 이 함수를 사용하여 지정된 양의 텍스트 데이터를 연결을 통해 보냅니다. |
| `WRITE_LINE(c, data)` | `INTEGER` | 이 함수를 사용하여 한 줄의 텍스트를 연결에 쓰며, 일반적으로 개행 문자를 추가합니다. |
| `WRITE_RAW(c, data)` | `INTEGER` | 이 함수를 사용하여 원시 바이너리 데이터(bytea)를 연결을 통해 전송합니다. |
| `READ_LINE(c, data IN OUT)` |  | 연결에서 한 줄의 데이터를 읽어 제공된 VARCHAR2 변수에 저장합니다. |
| `SECURE_CONNECTION(c IN OUT)` |  | 기존 연결을 보안(암호화) 상태로 업그레이드합니다. |
