# SYS 스키마 (SYS schema) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › SYS schema](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/sys_schema/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 데이터베이스는 표준 시스템 객체(함수, 프로시저, 패키지, 뷰 등)를 포함하는 Oracle 호환 SYS 스키마를 사용합니다.

스키마 덤프(dump) 작업 중에는 다음과 같이 처리됩니다:

- 시스템 객체 정의는 SYS 스키마에서 제외됩니다.

- SYS 객체에 대한 권한 변경 사항은 포함됩니다.

- SYS 스키마 내에 생성된 사용자 정의 객체는 포함됩니다.
