# Oracle 호환 구성 파라미터 목록 (List of Oracle compatible configuration parameters) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › List of Oracle compatible configuration parameters](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/summary_oracle_config_parameters/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 PostgreSQL 및 Oracle과 호환되는 애플리케이션의 개발과 실행을 지원합니다. 일부 시스템 동작을 더 PostgreSQL에 부합하거나 더 Oracle에 부합하는 방식으로 변경할 수 있습니다. 이러한 동작은 구성 파라미터(configuration parameter)를 사용하여 제어합니다.

- `edb_redwood_date` — `DATE` 열에 시간 구성 요소를 저장할지 여부를 제어합니다. Oracle 데이터베이스와 호환되는 동작을 위해서는 `edb_redwood_date`를 `TRUE`로 설정하십시오.
- `edb_redwood_raw_names` — Oracle 시스템 카탈로그에서 볼 때 데이터베이스 객체 이름이 대문자로 표시되는지 소문자로 표시되는지를 제어합니다. Oracle 데이터베이스와 호환되는 동작을 위해서는 `edb_redwood_raw_names`를 기본값인 `FALSE`로 설정합니다. PostgreSQL 시스템 카탈로그에 실제로 저장된 그대로 데이터베이스 객체 이름을 보려면 `edb_redwood_raw_names`를 `TRUE`로 설정하십시오.
- `edb_redwood_strings` — 문자열 연결(concatenation) 연산을 위해 `NULL`을 빈 문자열과 동일하게 취급합니다. Oracle 데이터베이스와 호환되는 동작을 위해서는 `edb_redwood_strings`를 `TRUE`로 설정하십시오.
- `edb_stmt_level_tx` — 중단된 SQL 명령의 자동 롤백을 문(statement) 수준 롤백으로만 격리합니다. 즉, 기본 PostgreSQL 동작처럼 현재 트랜잭션 전체가 자동으로 롤백되지 않습니다. Oracle 데이터베이스와 호환되는 동작을 위해서는 `edb_stmt_level_tx`를 `TRUE`로 설정하되, 반드시 필요한 경우에만 사용하십시오.
- `oracle_home` — EDB Postgres Advanced Server가 올바른 Oracle 설치 디렉터리를 가리키도록 지정합니다.

더 자세한 정보는 [Oracle 데이터베이스와 호환되는 구성 파라미터(Configuration parameters compatible with Oracle databases)](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/01_introduction/)를 참고하십시오.
