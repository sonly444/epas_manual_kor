# Oracle 호환 참조 (Oracle Compatibility Reference) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle compatibility reference](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/)
> EPAS v18 공식 문서의 한글 번역입니다. 명령·패키지·뷰 이름은 원문 그대로 보존했습니다.

Oracle 애플리케이션을 EPAS로 전환하는 조직을 지원하는 참조 콘텐츠입니다.

## 하위 구성
- **dblink_ora 함수·프로시저**: dblink_ora가 지원하는 함수·프로시저(`dblink_ora_connect`, `dblink_ora_record`, `dblink_ora_exec`, `dblink_ora_call` 등).
- **Oracle 호환 파티셔닝 명령**: Oracle 호환 테이블 파티셔닝 구문 목록(`PARTITION BY RANGE/LIST/HASH`, `ALTER TABLE ... ADD/DROP/SPLIT/MERGE/EXCHANGE PARTITION` 등).
- **내장 패키지(Built-in packages)**: EPAS가 제공하는 내장 패키지 목록(`DBMS_*`, `UTL_*` 계열 — 각 패키지의 프로시저·함수 포함).
- **카탈로그 뷰(Catalog Views)**: Oracle 데이터 딕셔너리 호환 카탈로그 뷰(`ALL_`/`DBA_`/`USER_` 계열).
- **Oracle 호환 SQL 명령**: Oracle 호환 SQL 명령 목록.
- **Oracle 호환 구성 파라미터 목록**: 시스템 동작을 PostgreSQL 또는 Oracle처럼 제어하는 파라미터(`edb_redwood_date`, `edb_redwood_strings`, `edb_redwood_raw_names` 등).
- **SYS 스키마(SYS schema)**: EPAS의 SYS 스키마 정보.

> 개별 내장 패키지(예: `DBMS_SCHEDULER`)의 전체 프로시저 시그니처나 특정 카탈로그 뷰의 전체 컬럼이 필요하면 해당 페이지를 지정해 추가 번역할 수 있습니다.
