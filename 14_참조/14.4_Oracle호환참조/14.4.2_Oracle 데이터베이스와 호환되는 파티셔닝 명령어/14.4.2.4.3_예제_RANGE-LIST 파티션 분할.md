# 예제: Splitting a RANGE/LIST partition — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...SPLIT PARTITION › Splitting a RANGE/LIST partition](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/04_alter_table_split_partition/03_example_splitting_a_range_list_partition)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 레인지 파티션된 `sales` 테이블의 파티션 중 하나를 새 파티션들로 나눕니다. 이 방식은 새로 생성된 파티션들에서 원래 테이블의 파티셔닝을 유지하고, 파티션의 내용을 그들 사이에 재분배합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY RANGE(date)
  SUBPARTITION BY LIST (country)
  (
    PARTITION q1_2012 VALUES LESS THAN('2012-Apr-01')
    (
      SUBPARTITION europe VALUES('FRANCE', 'ITALY'),
      SUBPARTITION americas VALUES('US', 'CANADA'),
      SUBPARTITION asia VALUES('INDIA', 'PAKISTAN')
    )
  );
```

`sales` 테이블은 `q1_2012` 파티션과 `europe`, `americas`, `asia`의 세 개 서브파티션을 포함합니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name, high_value FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name |     high_value
------------+----------------+-------------------+---------------------
 SALES      | Q1_2012        | EUROPE            | 'FRANCE', 'ITALY'
 SALES      | Q1_2012        | AMERICAS          | 'US', 'CANADA'
 SALES      | Q1_2012        | ASIA              | 'INDIA', 'PAKISTAN'
(3 rows)
```

다음 명령은 `q1_2012` 파티션을 `q1_2012_p1`과 `q1_2012_p2`라는 이름의 파티션으로 분할합니다.

```sql
ALTER TABLE sales SPLIT PARTITION q1_2012
  AT ('01-Mar-2012')
  INTO
  (
    PARTITION q1_2012_p1,
    PARTITION q1_2012_p2
  );
```

`SELECT` 문으로 새로 생성된 파티션 `q1_2012_p1`과 `q1_2012_p2`에 동일한 개수의 서브파티션이 시스템 생성 이름으로 생성되었음을 확인합니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name, high_value FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2,3;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name |     high_value
------------+----------------+-------------------+---------------------
 SALES      | Q1_2012_P1     | SYS0105           | 'US', 'CANADA'
 SALES      | Q1_2012_P1     | SYS0106           | 'FRANCE', 'ITALY'
 SALES      | Q1_2012_P1     | SYS0107           | 'INDIA', 'PAKISTAN'
 SALES      | Q1_2012_P2     | SYS0108           | 'US', 'CANADA'
 SALES      | Q1_2012_P2     | SYS0109           | 'FRANCE', 'ITALY'
 SALES      | Q1_2012_P2     | SYS0110           | 'INDIA', 'PAKISTAN'
(6 rows)
```

## Example: Splitting a partition with SUBPARTITIONS num...

이 예제는 리스트 파티션된 `sales` 테이블의 파티션 중 하나를 새 파티션들로 나눕니다. 새로 생성된 파티션들에서 원래 테이블의 파티셔닝을 유지하고, 파티션의 내용을 그들 사이에 재분배합니다. `SUBPARTITIONS` 절을 사용하면 지정된 개수의 서브파티션을 추가할 수 있습니다. `SUBPARTITIONS` 절이 없으면, 새 파티션은 기본 개수의 서브파티션을 상속받습니다.

다음 문은 `sales` 테이블을 생성합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST(country) SUBPARTITION BY HASH (part_no) SUBPARTITIONS 2
(
  PARTITION europe VALUES('FRANCE', 'ITALY'),
  PARTITION asia VALUES('INDIA', 'PAKISTAN'),
  PARTITION americas VALUES('US', 'CANADA')
);
```

테이블 정의는 `europe`, `asia`, `americas`의 세 개 파티션을 생성합니다. 각각은 두 개의 서브파티션을 포함합니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | AMERICAS       | SYS0105
 SALES      | AMERICAS       | SYS0106
 SALES      | ASIA           | SYS0103
 SALES      | ASIA           | SYS0104
 SALES      | EUROPE         | SYS0101
 SALES      | EUROPE         | SYS0102
(6 rows)
```

다음 명령은 `americas` 파티션을 `partition_us`와 `partition_canada`라는 이름의 파티션으로 분할합니다.

```sql
ALTER TABLE sales SPLIT PARTITION americas VALUES ('US') INTO (PARTITION
partition_us SUBPARTITIONS 5, PARTITION partition_canada);
```

`SELECT` 문으로 `americas` 파티션이 `partition_us`와 `partition_canada`로 분할되었음을 확인합니다. `partition_us`는 다섯 개의 서브파티션을 포함합니다. `partition_canada`는 시스템 생성 이름을 가진 두 개의 기본 서브파티션을 포함합니다.

```sql
edb=#  SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2,3;
```

출력(Output)

```text
 table_name |  partition_name  | subpartition_name
------------+------------------+-------------------
 SALES      | ASIA             | SYS0103
 SALES      | ASIA             | SYS0104
 SALES      | EUROPE           | SYS0101
 SALES      | EUROPE           | SYS0102
 SALES      | PARTITION_CANADA | SYS0115
 SALES      | PARTITION_CANADA | SYS0116
 SALES      | PARTITION_US     | SYS0110
 SALES      | PARTITION_US     | SYS0111
 SALES      | PARTITION_US     | SYS0112
 SALES      | PARTITION_US     | SYS0113
 SALES      | PARTITION_US     | SYS0114
(11 rows)
```

## Example: Splitting a partition with SUBPARTITIONS num...STORE IN

이 예제는 리스트 파티션된 `sales` 테이블의 `europe` 파티션을 두 개의 파티션으로 나눕니다. 새로 생성된 파티션들에서 원래 테이블의 파티셔닝을 유지하고, 파티션의 내용을 재분배합니다. `SUBPARTITIONS` 절을 사용하면 지정된 개수의 서브파티션을 추가할 수 있습니다.

`sales` 테이블을 생성하려면 다음 명령을 사용합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST(country) SUBPARTITION BY HASH (part_no) SUBPARTITIONS 4
(
  PARTITION europe VALUES('FRANCE', 'ITALY'),
  PARTITION asia VALUES('INDIA', 'PAKISTAN'),
  PARTITION americas VALUES('US', 'CANADA')
);
```

`sales` 테이블은 `europe`, `asia`, `americas` 파티션을 포함합니다. 각각은 시스템 생성 이름을 가진 네 개의 서브파티션을 포함합니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text

(12 rows)
```

다음 명령은 `europe` 파티션을 `france`와 `italy` 파티션으로 분할합니다.

```sql
ALTER TABLE sales SPLIT PARTITION europe VALUES ('FRANCE') INTO (PARTITION
france SUBPARTITIONS 10 STORE IN (ts1), PARTITION italy);
```

`SELECT` 문으로 `europe` 파티션이 두 개의 파티션으로 분할되었음을 확인합니다. `france` 파티션은 테이블스페이스 `ts1`에 저장된 10개의 서브파티션을 포함합니다. `italy` 파티션은 원래 파티션 `europe`와 마찬가지로 네 개의 서브파티션을 포함합니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name, tablespace_name
FROM ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2,3;
```
