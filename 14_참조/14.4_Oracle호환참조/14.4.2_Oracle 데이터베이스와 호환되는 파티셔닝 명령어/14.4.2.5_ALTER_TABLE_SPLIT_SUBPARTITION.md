# ALTER TABLE...SPLIT SUBPARTITION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...SPLIT SUBPARTITION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/05_alter_table_split_subpartition/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ALTER TABLE… SPLIT SUBPARTITION` 명령을 사용하여 단일 서브파티션을 두 개의 서브파티션으로 나누고 서브파티션의 내용을 재분배합니다. 명령은 두 가지 변형으로 제공됩니다.

첫 번째 변형은 범위 서브파티션을 두 서브파티션으로 분할합니다:

```sql
ALTER TABLE <table_name> SPLIT SUBPARTITION <subpartition_name>
  AT (range_part_value)
  INTO
  (
    SUBPARTITION <new_subpart1>
      [TABLESPACE <tablespace_name>],
    SUBPARTITION <new_subpart2>
      [TABLESPACE <tablespace_name>]
  );
```

두 번째 변형은 리스트 서브파티션을 두 서브파티션으로 분할합니다:

```sql
ALTER TABLE <table_name> SPLIT SUBPARTITION <subpartition_name>
  VALUES (<value>[, <value>]...)
  INTO
  (
    SUBPARTITION <new_subpart1>
      [TABLESPACE <tablespace_name>],
    SUBPARTITION <new_subpart2>
      [TABLESPACE <tablespace_name>]
  );
```

## 설명 (Description)

`ALTER TABLE...SPLIT SUBPARTITION` 명령은 기존 서브파티션 테이블에 서브파티션을 추가합니다. 정의할 수 있는 서브파티션 수에는 상한이 없습니다. `ALTER TABLE...SPLIT SUBPARTITION` 명령을 실행하면 EDB Postgres Advanced Server는 두 개의 서브파티션을 생성합니다. 지정된 서브파티션 규칙으로 제약되는 값을 포함하는 행을 `new_subpart1`로, 나머지 행을 `new_subpart2`로 이동합니다.

새 서브파티션 규칙은 기존 서브파티션을 정의하는 규칙에 지정된 컬럼을 참조해야 합니다.

새 서브파티션이 위치하는 테이블스페이스를 지정하려면 `TABLESPACE` 절을 포함합니다. 테이블스페이스를 지정하지 않으면 서브파티션은 기본 테이블스페이스에 생성됩니다.

테이블이 인덱싱되어 있으면 새 서브파티션에 인덱스가 생성됩니다.

`ALTER TABLE... SPLIT SUBPARTITION` 명령을 사용하려면 테이블 소유자이거나 슈퍼유저 또는 관리 권한이 있어야 합니다.

## 파라미터 (Parameters)

`table_name` — 파티션 테이블의 이름(선택적으로 스키마 한정).

`subpartition_name` — 분할되는 서브파티션의 이름.

`new_subpart1` — 생성할 첫 번째 서브파티션의 이름. 모든 파티션·서브파티션 중에서 고유해야 하며 객체 식별자 명명 규칙을 따라야 합니다. `new_subpart1`은 `ALTER TABLE… SPLIT SUBPARTITION` 명령에 지정된 서브파티셔닝 제약을 충족하는 행을 받습니다.

`new_subpart2` — 생성할 두 번째 서브파티션의 이름. 모든 파티션·서브파티션 중에서 고유해야 하며 객체 식별자 명명 규칙을 따라야 합니다. `new_subpart2`는 `ALTER TABLE… SPLIT SUBPARTITION` 명령에 지정된 서브파티셔닝 제약에 의해 `new_subpart1`로 보내지지 않는 행을 받습니다.

`(value[, value]...)` — 테이블 항목을 파티션으로 그룹화하는 기준이 되는, 따옴표로 묶인 리터럴 값 또는 쉼표 구분 리터럴 값 목록. 각 파티셔닝 규칙은 적어도 하나의 값을 지정해야 합니다. 규칙에 지정하는 값의 수에는 제한이 없습니다. `value`는 `NULL`, `LIST` 서브파티션 지정 시 `DEFAULT`, `RANGE` 서브파티션 지정 시 `MAXVALUE`일 수도 있습니다.

`DEFAULT`나 `MAXVALUE` 파티션 생성에 대한 정보는 [LIST 또는 RANGE 파티션 테이블에서 미분류 값 처리](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_table_partitioning/05_handling_stray_values_in_a_list_or_range_partitioned_table/#handling_stray_values_in_a_list_or_range_partitioned_table)를 참고하십시오.

`tablespace_name` — 파티션이나 서브파티션이 위치하는 테이블스페이스의 이름.

> **예제 하위 페이지(원문):** LIST 서브파티션 분할 · RANGE 서브파티션 분할 (필요 시 개별 번역 추가 가능)
