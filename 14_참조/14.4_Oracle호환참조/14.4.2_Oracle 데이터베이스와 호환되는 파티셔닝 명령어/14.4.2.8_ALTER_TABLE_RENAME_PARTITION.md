# ALTER TABLE...RENAME PARTITION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...RENAME PARTITION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/08_alter_table_rename_partition/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ALTER TABLE… RENAME PARTITION` 명령을 사용하여 테이블 파티션의 이름을 변경합니다. 구문은 두 가지 형태를 취합니다.

첫 번째 형태는 파티션 이름을 변경합니다:

```sql
ALTER TABLE <table_name>
 RENAME PARTITION <partition_name>
 TO <new_name>;
```

두 번째 형태는 서브파티션 이름을 변경합니다:

```sql
ALTER TABLE <table_name>
 RENAME SUBPARTITION <subpartition_name>
 TO <new_name>;
```

## 설명 (Description)

`ALTER TABLE… RENAME PARTITION` 명령은 파티션의 이름을 변경합니다.

`RENAME SUBPARTITION` 절과 함께 사용되는 `subpartition_name`의 동작도 동일합니다.

`ALTER TABLE… RENAME PARTITION`이나 `ALTER TABLE… RENAME SUBPARTITION`을 실행하려면 지정된 테이블을 소유해야 합니다.

## 파라미터 (Parameters)

`table_name` — 파티션이나 서브파티션이 위치하는 테이블의 이름(선택적으로 스키마 한정).

`partition_name` — 이름을 변경할 파티션의 이름.

`subpartition_name` — 이름을 변경할 서브파티션의 이름.

`new_name` — 파티션이나 서브파티션의 새 이름.

> **예제 하위 페이지(원문):** 파티션 이름 변경 (필요 시 개별 번역 추가 가능)
