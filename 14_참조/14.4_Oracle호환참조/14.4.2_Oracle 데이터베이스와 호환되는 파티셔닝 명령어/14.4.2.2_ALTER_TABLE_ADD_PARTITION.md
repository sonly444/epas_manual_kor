# ALTER TABLE...ADD PARTITION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...ADD PARTITION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/02_alter_table_add_partition/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ALTER TABLE… ADD PARTITION` 명령을 사용하여 기존 파티션 테이블에 파티션을 추가합니다. 구문은 다음과 같습니다:

```sql
ALTER TABLE <table_name> ADD PARTITION <partition_definition>;

여기서 partition_definition은:

        {<list_partition> | <range_partition>}

list_partition은:

        PARTITION [<partition_name>]
          VALUES (<value>[, <value>]...)
          [TABLESPACE <tablespace_name>]
          [(<subpartition>, ...)]

range_partition은:

        PARTITION [<partition_name>]
          VALUES LESS THAN (<value>[, <value>]...)
          [TABLESPACE <tablespace_name>]
          [(<subpartition>, ...)]

여기서 subpartition은:

        {<list_subpartition> | <range_subpartition> | <hash_subpartition>}

list_subpartition은:

        SUBPARTITION [<subpartition_name>]
          VALUES (<value>[, <value>]...)
          [TABLESPACE <tablespace_name>]

range_subpartition은:

        SUBPARTITION [<subpartition_name>]
          VALUES LESS THAN (<value>[, <value>]...)
          [TABLESPACE <tablespace_name>]

hash_subpartition은:

        SUBPARTITION [<subpartition_name>]
          [TABLESPACE <tablespace_name>] |
        SUBPARTITIONS <num> [STORE IN ( <tablespace_name> [, <tablespace_name>]... ) ]
```

## 설명 (Description)

`ALTER TABLE… ADD PARTITION` 명령은 기존 파티션 테이블에 파티션을 추가합니다. 파티션 테이블에 정의할 수 있는 파티션 수에는 상한이 없습니다.

새 파티션은 기존 파티션과 동일한 유형(`LIST`, `RANGE`, `HASH`)이어야 합니다. 새 파티션 규칙은 기존 파티션을 정의하는 파티셔닝 규칙에 지정된 것과 동일한 컬럼을 참조해야 합니다.

`ALTER TABLE… ADD PARTITION` 문을 사용하여 `DEFAULT` 규칙이 있는 테이블에 파티션을 추가할 수 있습니다. 다만 테이블의 기존 행과 추가할 파티션의 값 사이에 충돌하는 값이 있어서는 안 됩니다.

`MAXVALUE` 규칙이 있는 테이블에는 `ALTER TABLE… ADD PARTITION` 문을 사용하여 파티션을 추가할 수 없습니다.

대안으로 `ALTER TABLE… SPLIT PARTITION` 문을 사용하여 기존 파티션을 분할함으로써 테이블의 파티션 수를 늘릴 수 있습니다.

`RANGE` 파티션은 오름차순으로 지정하십시오. `RANGE` 파티션 테이블에서 기존 파티션보다 앞서는 새 파티션을 추가할 수 없습니다.

새 파티션이 위치하는 테이블스페이스를 지정하려면 `TABLESPACE` 절을 포함합니다. 테이블스페이스를 지정하지 않으면 파티션은 기본 테이블스페이스에 위치합니다.

자동 생성된 서브파티션이 저장되는 테이블스페이스 목록을 지정하려면 `STORE IN` 절을 사용합니다.

테이블이 인덱싱되어 있으면 새 파티션에 인덱스가 생성됩니다.

`ALTER TABLE... ADD PARTITION` 명령을 사용하려면 테이블 소유자이거나 슈퍼유저 또는 관리 권한이 있어야 합니다.

## 파라미터 (Parameters)

`table_name` — 파티션 테이블의 이름(선택적으로 스키마 한정).

`partition_name` — 생성할 파티션의 이름. 모든 파티션·서브파티션 중에서 고유해야 하며 객체 식별자 명명 규칙을 따라야 합니다.

`subpartition_name` — 생성할 서브파티션의 이름. 모든 파티션·서브파티션 중에서 고유해야 하며 객체 식별자 명명 규칙을 따라야 합니다.

`(value[, value]...)` — 행을 파티션으로 분산하는 기준이 되는, 따옴표로 묶인 리터럴 값 또는 쉼표 구분 리터럴 값 목록. 각 파티셔닝 규칙은 적어도 하나의 `value`를 지정해야 합니다. 규칙에 지정하는 값의 수에는 제한이 없습니다. `value`는 `NULL`, `LIST` 파티션 지정 시 `DEFAULT`, `RANGE` 파티션 지정 시 `MAXVALUE`일 수도 있습니다.

`DEFAULT`나 `MAXVALUE` 파티션 생성에 대한 정보는 [LIST 또는 RANGE 파티션 테이블에서 미분류 값 처리](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_table_partitioning/05_handling_stray_values_in_a_list_or_range_partitioned_table/#handling_stray_values_in_a_list_or_range_partitioned_table)를 참고하십시오.

`num` — `SUBPARTITIONS num` 절은 `HASH`에만 지원되며 해시 서브파티션 수를 지정하는 데 사용할 수 있습니다. 또는 서브파티션 정의를 사용하여 개별 서브파티션과 테이블스페이스를 지정할 수 있습니다. `SUBPARTITIONS`나 `SUBPARTITION DEFINITION`을 지정하지 않으면 파티션은 `SUBPARTITION TEMPLATE`를 기준으로 서브파티션을 생성합니다.

`tablespace_name` — 파티션이나 서브파티션이 위치하는 테이블스페이스의 이름.

> **예제 하위 페이지(원문):** LIST 파티션 테이블에 파티션 추가 · RANGE 파티션 테이블에 파티션 추가 · SUBPARTITIONS num으로 파티션 추가 (필요 시 개별 번역 추가 가능)
