# 예제: PARTITION BY HASH...PARTITIONS num... — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › CREATE TABLE...PARTITION BY › PARTITION BY HASH...PARTITIONS num...](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/01_create_table_partition_by/06_example_partitions_number)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 `PARTITION BY HASH` 절을 사용하여 해시 파티셔닝된 테이블 `sales`를 생성합니다. 파티셔닝 열은 `part_no`입니다. 이 예제는 생성할 파티션의 개수를 지정합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY HASH (part_no) PARTITIONS 8;
```

8개의 파티션이 생성되고 시스템이 생성한 이름이 할당됩니다. 파티션들은 테이블의 기본 테이블스페이스에 저장됩니다.

```sql
edb=# SELECT table_name, partition_name FROM ALL_TAB_PARTITIONS WHERE
table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name
------------+----------------
 SALES      | SYS0101
 SALES      | SYS0102
 SALES      | SYS0103
 SALES      | SYS0104
 SALES      | SYS0105
 SALES      | SYS0106
 SALES      | SYS0107
 SALES      | SYS0108
(8 rows)
```

## 예제: PARTITION BY HASH...PARTITIONS num...STORE IN

이 예제는 해시 파티셔닝된 테이블 `sales`를 생성합니다. 이 예제는 생성할 파티션의 개수와 파티션이 위치할 테이블스페이스를 지정합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY HASH (part_no) PARTITIONS 5 STORE IN (ts1, ts2, ts3);
```

`STORE IN` 절은 파티션들을 테이블스페이스 `ts1`, `ts2`, `ts3`에 균등하게 분배합니다.

```sql
edb=# SELECT table_name, partition_name, tablespace_name FROM
ALL_TAB_PARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | tablespace_name
------------+----------------+-----------------
 SALES      | SYS0101        | TS1
 SALES      | SYS0102        | TS2
 SALES      | SYS0103        | TS3
 SALES      | SYS0104        | TS1
 SALES      | SYS0105        | TS2
(5 rows)
```

## 예제: HASH/RANGE PARTITIONS num...

`HASH` 파티션 절을 사용하면 파티셔닝 전략을 정의할 수 있습니다. `PARTITION BY HASH` 절을 확장하여 `SUBPARTITION BY`에 `[ RANGE | LIST | HASH ]` 중 하나를 포함시켜 `HASH` 파티셔닝된 테이블에 서브파티션을 생성할 수 있습니다.

이 예제는 `part_no`로 해시 파티셔닝되고 `dept_no`로 범위 서브파티셔닝된 테이블 `sales`를 생성합니다. 이 예제는 테이블 `sales`를 생성할 때 파티션의 개수를 지정합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY HASH (part_no) SUBPARTITION BY RANGE (dept_no) PARTITIONS 5;
```

기본 서브파티션과 함께 5개의 파티션이 생성되고 시스템이 생성한 이름이 할당됩니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | SYS0101        | SYS0102
 SALES      | SYS0103        | SYS0104
 SALES      | SYS0105        | SYS0106
 SALES      | SYS0107        | SYS0108
 SALES      | SYS0109        | SYS0110
(5 rows)
```

## 예제: RANGE/HASH SUBPARTITIONS num...

이 예제는 범위 파티셔닝된 테이블 `sales`를 생성하며, 먼저 거래 날짜로 파티셔닝됩니다. 두 개의 범위 파티션이 생성된 다음 `country` 열의 값을 사용하여 해시 서브파티셔닝됩니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY RANGE (date) SUBPARTITION BY HASH (country) SUBPARTITIONS 2
(
  PARTITION p1 VALUES LESS THAN ('2012-Apr-01') (SUBPARTITION q1_europe),
  PARTITION p2 VALUES LESS THAN ('2012-Jul-01')
);
```

이 문은 두 개의 파티션을 가진 테이블을 생성합니다. 파티션 `p1`에 대해서는 명시적으로 이름이 지정된 서브파티션 `q1_europe`가 생성됩니다. 파티션 `p2`에 대해서는 서브파티션의 이름이 지정되지 않았으므로, 서브파티션들은 서브파티션 번호에 따라 생성되고 시스템이 생성한 이름이 할당됩니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | P1             | Q1_EUROPE
 SALES      | P2             | SYS0101
 SALES      | P2             | SYS0102
(3 rows)
```

## 예제: LIST/HASH STORE IN...TABLESPACES

이 예제는 리스트 파티셔닝된 테이블 `sales`를 생성합니다. 파티션 `p1`은 테이블스페이스 `ts2`에 명시적으로 저장되는 세 개의 서브파티션으로 구성됩니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST (country) SUBPARTITION BY HASH (part_no) SUBPARTITIONS 3
STORE IN (ts1)
(
  PARTITION p1 VALUES ('FRANCE', 'ITALY') TABLESPACE ts2
);
```

`SELECT` 문은 테이블스페이스 `ts2`에 저장된 세 개의 서브파티션으로 구성된 파티션 `p1`을 보여줍니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name, tablespace_name
FROM ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name | tablespace_name
------------+----------------+-------------------+-----------------
 SALES      | P1             | SYS0101           | TS2
 SALES      | P1             | SYS0102           | TS2
 SALES      | P1             | SYS0103           | TS2
(3 rows)
```

이 명령은 `sales` 테이블에 파티션 `p2`를 추가합니다. 다섯 개의 서브파티션이 생성되어 `STORE IN` 절에 나열된 테이블스페이스에 분배됩니다.

```sql
ALTER TABLE sales ADD PARTITION p2 VALUES ('US', 'CANADA') SUBPARTITIONS 5
STORE IN (ts1);
```

`ALL_TAB_PARTITIONS` 뷰를 조회하면 `p2`라는 이름의 파티션을 가진 `sales` 테이블이 보입니다. 이 파티션은 다섯 개의 서브파티션을 가집니다. `STORE IN` 절은 서브파티션들을 `ts1`이라는 이름의 테이블스페이스에 분배합니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name, tablespace_name
FROM ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' and partition_name =
'P2' ORDER BY 1,2;
```
