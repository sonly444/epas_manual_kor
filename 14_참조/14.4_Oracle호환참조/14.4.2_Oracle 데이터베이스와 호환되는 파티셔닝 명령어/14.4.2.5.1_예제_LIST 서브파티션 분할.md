# 예제: Splitting a lIST subpartition — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...SPLIT SUBPARTITION › Splitting a lIST subpartition](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/05_alter_table_split_subpartition/01_example_splitting_a_list_subpartition)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 리스트 서브파티션을 분할하여, 서브파티션의 내용을 두 개의 새 서브파티션 사이에 재분배합니다.

샘플 테이블 `sales`는 다음 명령으로 생성되었습니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY RANGE(date)
  SUBPARTITION BY LIST (country)
  (
    PARTITION first_half_2012 VALUES LESS THAN('01-JUL-2012')
    (
      SUBPARTITION p1_europe VALUES ('ITALY', 'FRANCE'),
      SUBPARTITION p1_americas VALUES ('US', 'CANADA')
    ),
    PARTITION second_half_2012 VALUES LESS THAN('01-JAN-2013')
    (
      SUBPARTITION p2_europe VALUES ('ITALY', 'FRANCE'),
      SUBPARTITION p2_americas VALUES ('US', 'CANADA')
    )
  );
```

`sales` 테이블에는 `first_half_2012`와 `second_half_2012`라는 이름의 파티션이 있습니다. 각 파티션에는 `country` 컬럼의 값에 따라 파티션의 내용을 서브파티션으로 분산하는 리스트로 정의된 두 개의 서브파티션이 있습니다.

```sql
edb=# SELECT partition_name, subpartition_name, high_value FROM ALL_TAB_SUBPARTITIONS;
```

출력(Output)

```text
  partition_name  | subpartition_name |    high_value
------------------+-------------------+-------------------
 SECOND_HALF_2012 | P2_AMERICAS       | 'US', 'CANADA'
 SECOND_HALF_2012 | P2_EUROPE         | 'ITALY', 'FRANCE'
 FIRST_HALF_2012  | P1_AMERICAS       | 'US', 'CANADA'
 FIRST_HALF_2012  | P1_EUROPE         | 'ITALY', 'FRANCE'
(4 rows)
```

다음 명령은 `p2_americas` 서브파티션을 두 개의 새 서브파티션으로 분할하고 내용을 재분배합니다.

```sql
ALTER TABLE sales SPLIT SUBPARTITION p2_americas
  VALUES ('US')
  INTO
  (
    SUBPARTITION p2_us,
    SUBPARTITION p2_canada
  );
```

명령을 실행한 후, `p2_americas` 서브파티션은 삭제됩니다. 그 자리에 서버는 `p2_us`와 `p2_canada` 서브파티션을 생성합니다.

```sql
edb=# SELECT partition_name, subpartition_name, high_value FROM ALL_TAB_SUBPARTITIONS;
```

출력(Output)

```text

------------------+-------------------+-------------------

 SECOND_HALF_2012 | P2_US             | 'US'

(5 rows)
```

`sales` 테이블을 조회하면 `p2_americas` 서브파티션의 내용이 재분배되었음을 알 수 있습니다.
