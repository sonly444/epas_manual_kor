# 예제: PARTITION BY LIST — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › CREATE TABLE...PARTITION BY › Example: PARTITION BY LIST](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/01_create_table_partition_by/01_example_partition_by_list/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 `PARTITION BY LIST` 절을 사용하여 파티션 테이블 `sales`를 생성합니다. `sales` 테이블은 정보를 `europe`, `asia`, `americas` 세 개의 파티션에 저장합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST(country)
(
  PARTITION europe VALUES('FRANCE', 'ITALY'),
  PARTITION asia VALUES('INDIA', 'PAKISTAN'),
  PARTITION americas VALUES('US', 'CANADA')
);
```

생성된 테이블은 `country` 열에 지정된 값에 따라 파티셔닝됩니다:

```sql
edb=# SELECT partition_name, high_value from ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |     high_value
----------------+---------------------
 EUROPE         | 'FRANCE', 'ITALY'
 ASIA           | 'INDIA', 'PAKISTAN'
 AMERICAS       | 'US', 'CANADA'
(3 rows)
```

- `country` 열의 값이 `FRANCE` 또는 `ITALY`인 행은 `europe` 파티션에 저장됩니다.
- `country` 열의 값이 `INDIA` 또는 `PAKISTAN`인 행은 `asia` 파티션에 저장됩니다.
- `country` 열의 값이 `US` 또는 `CANADA`인 행은 `americas` 파티션에 저장됩니다.

서버는 다음 문을 파티셔닝 규칙에 대해 평가하고 그 행을 `europe` 파티션에 저장합니다:

`INSERT INTO sales VALUES (10, '9519a', 'FRANCE', '18-Aug-2012', '650000');`
