# ALTER TABLE...SET [ PARTITIONING ] AUTOMATIC — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...SET [ PARTITIONING ] AUTOMATIC](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/10_alter_table_set_partitioning_automatic/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ALTER TABLE… SET [ PARTITIONING ] AUTOMATIC` 명령을 사용하여 기존 리스트 파티션 테이블을 자동 리스트 파티셔닝으로 변환합니다. `AUTOMATIC`이 설정되면 데이터베이스는 테이블에 삽입된 새 값을 기준으로 파티션을 자동 생성합니다. 구문은 다음과 같습니다:

```sql
ALTER TABLE <table_name> SET [ PARTITIONING ] AUTOMATIC;
```

`AUTOMATIC LIST PARTITIONING`을 비활성화하고 일반 `LIST` 파티션으로 변환하려면 다음 구문을 사용합니다:

```sql
ALTER TABLE <table_name> SET [ PARTITIONING ] MANUAL;
```

## 파라미터 (Parameters)

`table_name` — 리스트 파티션 테이블의 이름(선택적으로 스키마 한정).

## 설명 (Description)

`ALTER TABLE… SET [ PARTITIONING ] AUTOMATIC` 명령을 사용하여 일반 리스트 파티션 테이블이 자동 파티셔닝을 사용하도록 변환할 수 있습니다. 파티션이 생성되고, 새 파티션에 데이터를 삽입할 수 있습니다.

`ALTER TABLE… SET [ PARTITIONING ] MANUAL` 명령을 사용하여 자동 리스트 파티셔닝을 비활성화할 수 있습니다. 데이터베이스는 자동 리스트 파티션 테이블을 일반 리스트 파티션 테이블로 변환합니다.

> **예제 하위 페이지(원문):** 자동 LIST 파티션 설정 (필요 시 개별 번역 추가 가능)
