# 예제: CREATING SUBPARTITION TEMPLATE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › CREATE TABLE...PARTITION BY › CREATING SUBPARTITION TEMPLATE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/01_create_table_partition_by/09_example_subpartition_template)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제들은 서브파티션 템플릿(subpartition template)을 사용하여 파티션 테이블에 서브파티션을 생성하는 방법을 보여줍니다.

이 예제는 `country`로 리스트 파티셔닝되고 `date`로 리스트 서브파티셔닝된 테이블 `sales`를 생성합니다. `sales` 테이블은 서브파티션 템플릿을 사용하며 서브파티션과 테이블스페이스 이름을 표시합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST (country)
  SUBPARTITION BY LIST (date)
  SUBPARTITION TEMPLATE
(
    SUBPARTITION europe VALUES('2021-Jan-01') TABLESPACE ts1,
    SUBPARTITION asia VALUES('2021-Apr-01') TABLESPACE ts2,
    SUBPARTITION americas VALUES('2021-Jul-01') TABLESPACE ts3
)
(
    PARTITION q1_2021 VALUES('2021-Jul-01')
);
```

`SELECT` 문은 테이블스페이스 `ts1`, `ts2`, `ts3`에 저장된 세 개의 서브파티션으로 구성된 파티션 `q1_2021`을 보여줍니다.

```sql
edb=# SELECT partition_name, subpartition_name, high_value, tablespace_name
FROM DBA_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 partition_name | subpartition_name |      high_value      | tablespace_name
----------------+-------------------+----------------------+-----------------
 Q1_2021        | Q1_2021_AMERICAS  | '01-JUL-21 00:00:00' | TS3
 Q1_2021        | Q1_2021_ASIA      | '01-APR-21 00:00:00' | TS2
 Q1_2021        | Q1_2021_EUROPE    | '01-JAN-21 00:00:00' | TS1
(3 rows)
```

## 예제: LIST/RANGE 파티션 테이블용 서브파티션 템플릿 생성

이 예제는 `country`로 리스트 파티셔닝되고 `date` 열로 범위 파티셔닝을 사용하여 서브파티셔닝된 테이블 `sales`를 생성합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST(country)
  SUBPARTITION BY RANGE(date)
  SUBPARTITION TEMPLATE
(
    SUBPARTITION europe VALUES LESS THAN('2021-Jan-01') TABLESPACE ts1,
    SUBPARTITION asia VALUES LESS THAN('2021-Apr-01') TABLESPACE ts2,
    SUBPARTITION americas VALUES LESS THAN('2021-Jul-01') TABLESPACE ts3
)
(
    PARTITION q1_2021 VALUES ('2021-Jul-01')
);
```

`sales` 테이블은 테이블스페이스 `ts1`, `ts2`, `ts3`에 저장된 세 개의 서브파티션을 포함하는 `q1_2021`이라는 이름의 파티션을 생성합니다.

```sql
edb=# SELECT partition_name, subpartition_name, high_value, tablespace_name
FROM DBA_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 partition_name | subpartition_name |      high_value      | tablespace_name
----------------+-------------------+----------------------+-----------------
 Q1_2021        | Q1_2021_AMERICAS  | '01-JUL-21 00:00:00' | TS3
 Q1_2021        | Q1_2021_ASIA      | '01-APR-21 00:00:00' | TS2
 Q1_2021        | Q1_2021_EUROPE    | '01-JAN-21 00:00:00' | TS1
(3 rows)
```

    SUBPARTITION europe TABLESPACE ts1,
    SUBPARTITION asia TABLESPACE ts2,
    SUBPARTITION americas TABLESPACE ts3

    PARTITION q1_2021 VALUES ('2021-Jul-01')

`sales` 테이블은 테이블스페이스 `ts1`, `ts2`, `ts3`에 저장된 세 개의 서브파티션을 포함하는 `q1_2021` 파티션을 생성합니다.

## 예제: INTERVAL/HASH 파티션 테이블용 서브파티션 템플릿 생성

이 예제는 `date` 열에 대해 월별 인터벌로 인터벌 파티셔닝되고 `dept_no` 열의 값을 사용하여 해시 서브파티셔닝된 `sales` 테이블을 생성합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY RANGE(date) INTERVAL(NUMTOYMINTERVAL(1, 'MONTH'))
  SUBPARTITION BY HASH (dept_no)
  SUBPARTITION TEMPLATE
(
    SUBPARTITION europe TABLESPACE ts1,
    SUBPARTITION asia TABLESPACE ts2,
    SUBPARTITION americas TABLESPACE ts3
)
(
    PARTITION q2_2021 VALUES LESS THAN ('2021-Jul-01')
);
```

`sales` 테이블은 테이블스페이스 `ts1`, `ts2`, `ts3`에 저장된 세 개의 서브파티션으로 구성된 파티션 `q2_2021`을 생성합니다.

```sql
edb=# SELECT partition_name, subpartition_name, high_value, tablespace_name
FROM DBA_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 partition_name | subpartition_name | high_value | tablespace_name
----------------+-------------------+------------+-----------------
 Q2_2021        | Q2_2021_AMERICAS  |            | TS3
 Q2_2021        | Q2_2021_ASIA      |            | TS2

(3 rows)
```
