# 예제: Splitting a RANGE partition — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...SPLIT PARTITION › Splitting a RANGE partition](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/04_alter_table_split_partition/02_example_splitting_a_range_partition)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 레인지 파티션된 `sales` 테이블의 `q4_2012` 파티션을 두 개의 파티션으로 나누고, 파티션의 내용을 재분배합니다. `sales` 테이블을 생성하려면 다음 명령을 사용합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY RANGE(date)
(
  PARTITION q1_2012
    VALUES LESS THAN('2012-Apr-01'),
  PARTITION q2_2012
    VALUES LESS THAN('2012-Jul-01'),
  PARTITION q3_2012
    VALUES LESS THAN('2012-Oct-01'),
  PARTITION q4_2012
    VALUES LESS THAN('2013-Jan-01')
);
```

테이블 정의는 `q1_2012`, `q2_2012`, `q3_2012`, `q4_2012`의 네 개 파티션을 생성합니다. 다음 명령은 각 파티션에 행을 추가합니다.

다음 명령은 `q4_2012` 파티션을 `q4_2012_p1`과 `q4_2012_p2`라는 이름의 두 개 파티션으로 분할합니다.

```sql
ALTER TABLE sales SPLIT PARTITION q4_2012
  AT ('15-Nov-2012')
  INTO
  (
    PARTITION q4_2012_p1,
    PARTITION q4_2012_p2
  );
```
