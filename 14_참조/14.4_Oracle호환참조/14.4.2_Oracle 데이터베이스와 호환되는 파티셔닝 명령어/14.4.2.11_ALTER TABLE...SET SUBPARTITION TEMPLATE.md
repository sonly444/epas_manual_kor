# ALTER TABLE...SET SUBPARTITION TEMPLATE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...SET SUBPARTITION TEMPLATE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/11_alter_table_set_subpartition_template/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ALTER TABLE… SET SUBPARTITION TEMPLATE` 명령을 사용하여 테이블의 서브파티션 템플릿을 갱신합니다. 명령 구문은 여러 형태로 제공됩니다.

`HASH` 서브파티션에만 서브파티션 수를 설정하려면:

```sql
ALTER TABLE <table_name> SET SUBPARTITION TEMPLATE <num>;
```

기존 파티션 테이블에 서브파티션 설명을 설정하려면:

```sql
ALTER TABLE <table_name>
[SET SUBPARTITION TEMPLATE (<subpartition_template_description>)]
```

서브파티션 템플릿을 사용해 서브파티션 수를 기본값으로 재설정하려면:

```sql
ALTER TABLE <table_name> SET SUBPARTITION TEMPLATE ();
```

## 파라미터 (Parameters)

`table_name` — 파티션 테이블의 이름(선택적으로 스키마 한정).

`num` — 파티션에 추가할 서브파티션 수.

`subpartition_template_description` — 서브파티션 이름, 서브파티션 경계, 테이블스페이스 이름이 포함된 서브파티션 상세 목록.

## 설명 (Description)

`ALTER TABLE… SET SUBPARTITION TEMPLATE` 명령을 사용하여 범위·리스트·해시 파티션 테이블의 서브파티션 템플릿을 갱신할 수 있습니다. 파티션에 서브파티션 디스크립터(descriptor)를 지정하는 경우, 서브파티션 템플릿 대신 서브파티션 디스크립터를 사용합니다. 파티션에 서브파티션 디스크립터가 지정되지 않은 경우에는 언제든 서브파티션 템플릿을 사용할 수 있습니다. 서브파티션 디스크립터도 서브파티션 템플릿도 지정하지 않으면 기본적으로 단일 서브파티션이 생성됩니다.

서브파티션 템플릿 생성에 대한 자세한 내용은 [CREATE TABLE...PARTITION BY](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/01_create_table_partition_by/)를 참고하십시오.

##### 참고 (Note)

`ALTER TABLE… SET SUBPARTITION TEMPLATE` 명령을 실행한 후 테이블에 추가되는 파티션은 새 `SUBPARTITION TEMPLATE`를 사용합니다.

`ALTER TABLE… SET SUBPARTITION TEMPLATE ()` 명령을 사용하여 서브파티션 수를 기본값 `1`로 재설정할 수 있습니다.
