# 예제: Exchanging a table for a partition — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...EXCHANGE PARTITION › Exchanging a table for a partition](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/06_alter_table_exchange_partition/01_example_exchanging_a_table_for_a_partition)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 `sales` 테이블의 `americas` 파티션을 어떤 테이블과 교환(swap)합니다. `sales` 테이블은 다음 명령으로 생성할 수 있습니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST(country)
(
  PARTITION europe VALUES('FRANCE', 'ITALY'),
  PARTITION asia VALUES('INDIA', 'PAKISTAN'),
  PARTITION americas VALUES('US', 'CANADA')
);
```

다음 명령을 사용해 `sales` 테이블에 샘플 데이터를 추가합니다.

```sql
INSERT INTO sales VALUES
  (40, '9519b', 'US', '12-Apr-2012', '145000'),
  (10, '4519b', 'FRANCE', '17-Jan-2012', '45000'),
  (20, '3788a', 'INDIA', '01-Mar-2012', '75000'),
  (20, '3788a', 'PAKISTAN', '04-Jun-2012', '37500'),
  (10, '9519b', 'ITALY', '07-Jul-2012', '15000'),
  (10, '9519a', 'FRANCE', '18-Aug-2012', '650000'),

  (20, '4519a', 'INDIA', '18-Oct-2012', '650000'),
  (20, '4519b', 'INDIA', '2-Dec-2012', '5090');
```

`sales` 테이블을 조회하면 `americas` 파티션에는 오직 한 개의 행만 존재함을 알 수 있습니다.

```sql
edb=# SELECT tableoid::regclass, * FROM sales;
```

다음 명령은 `sales` 테이블의 정의와 일치하는 `n_america` 테이블을 생성합니다.

```sql
CREATE TABLE n_america
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
);
```

다음 명령은 `n_america` 테이블에 데이터를 추가합니다. 이 데이터는 `americas` 파티션의 파티셔닝 규칙을 준수합니다.

```sql
INSERT INTO n_america VALUES
  (40, '9519b', 'US', '12-Apr-2012', '145000'),
  (40, '4577b', 'US', '11-Nov-2012', '25000'),
  (30, '7588b', 'CANADA', '14-Dec-2012', '50000'),
  (30, '9519b', 'CANADA', '01-Feb-2012', '75000'),
  (30, '4519b', 'CANADA', '08-Apr-2012', '120000'),
  (40, '3788a', 'US', '12-May-2012', '4950'),
  (40, '4788a', 'US', '23-Sept-2012', '4950'),
  (40, '4788b', 'US', '09-Oct-2012', '15000');
```

다음 명령은 해당 테이블을 파티셔닝된 테이블 안으로 교환합니다.

```sql
ALTER TABLE sales
  EXCHANGE PARTITION americas
  WITH TABLE n_america;
```

`sales` 테이블을 조회하면 `n_america` 테이블의 내용이 `americas` 파티션의 내용과 교환되었음을 알 수 있습니다.

```sql
edb=# SELECT tableoid::regclass, * FROM sales;
```
