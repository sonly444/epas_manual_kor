# 파티셔닝 명령 제약사항 (Partitioning Command Limitations) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › Limitations](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

Oracle 호환 파티셔닝 명령에는 다음과 같은 제약사항이 있습니다.

## 기본 키 및 고유 키 제약사항 (Primary and unique key limitations)

파티션 테이블에 기본 키(primary key)나 고유 키(unique key)를 정의하는 경우, 파티션 키 열이 기본 키 또는 고유 키에 포함되어야 합니다. 즉, 파티셔닝 열이 기본 키·고유 키의 일부가 아니면 해당 제약조건을 만들 수 없습니다.

## 인터벌 파티셔닝 제약사항 (Interval partitioning limitations)

인터벌 파티셔닝(interval partitioning)에는 다음 제약이 적용됩니다.

인터벌 파티셔닝은 단일 파티션 키 열을 사용하는 `RANGE` 파티션 테이블에서만 지원됩니다. 파티션 키는 숫자(numeric) 또는 날짜/시간(date-time) 데이터 타입이어야 합니다.

인터벌 파티션 테이블에서는 `MAXVALUE`를 파티션 경계로 정의할 수 없습니다.

인터벌 파티션 테이블에는 서브파티션을 만들 수 없습니다.

## 자동 파티셔닝 제약사항 (Automatic list partitioning limitations)

자동 리스트 파티셔닝(automatic list partitioning)에는 다음 제약이 적용됩니다.

자동 리스트 파티셔닝은 단일 파티션 키 열을 사용하는 `LIST` 파티션 테이블에서만 지원됩니다.

자동 리스트 파티션 테이블에서는 `DEFAULT` 파티션을 정의할 수 없습니다.

자동 리스트 파티션 테이블에는 서브파티션을 만들 수 없습니다.
