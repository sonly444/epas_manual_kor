# ALTER TABLE...MOVE PARTITION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...MOVE PARTITION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/07_alter_table_move_partition/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ALTER TABLE… MOVE PARTITION` 명령을 사용하여 파티션을 다른 테이블스페이스로 이동합니다. 명령은 두 가지 형태를 취합니다.

첫 번째 형태는 파티션을 새 테이블스페이스로 이동합니다:

```sql
ALTER TABLE <table_name>
  MOVE PARTITION <partition_name>
   TABLESPACE <tablespace_name>;
```

두 번째 형태는 서브파티션을 새 테이블스페이스로 이동합니다:

```sql
ALTER TABLE <table_name>
  MOVE SUBPARTITION <subpartition_name>
   TABLESPACE <tablespace_name>;
```

## 설명 (Description)

`ALTER TABLE…MOVE PARTITION` 명령은 파티션을 현재 테이블스페이스에서 다른 테이블스페이스로 이동합니다. `ALTER TABLE… MOVE PARTITION` 명령은 `LIST`, `RANGE`, `HASH` 파티션 테이블의 파티션을 이동할 수 있습니다.

`MOVE SUBPARTITION` 절과 함께 사용되는 `subpartition_name`에도 동일한 동작이 적용됩니다.

`ALTER TABLE… MOVE PARTITION`이나 `ALTER TABLE… MOVE SUBPARTITION`을 실행하려면 테이블을 소유해야 합니다.

## 파라미터 (Parameters)

`table_name` — 파티션이나 서브파티션이 위치하는 테이블의 이름(선택적으로 스키마 한정).

`partition_name` — 이동할 파티션의 이름.

`subpartition_name` — 이동할 서브파티션의 이름.

`tablespace_name` — 파티션이나 서브파티션을 이동할 대상 테이블스페이스의 이름.

> **예제 하위 페이지(원문):** 파티션을 다른 테이블스페이스로 이동 (필요 시 개별 번역 추가 가능)
