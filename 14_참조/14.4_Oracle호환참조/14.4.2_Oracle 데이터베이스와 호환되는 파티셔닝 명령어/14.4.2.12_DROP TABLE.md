# DROP TABLE (파티셔닝) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › DROP TABLE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/12_drop_table/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

PostgreSQL `DROP TABLE` 명령을 사용하여 파티션 테이블 정의, 그 파티션과 서브파티션, 테이블 내용을 제거합니다. 구문은 다음과 같습니다:

```sql
DROP TABLE <table_name>
```

## 파라미터 (Parameters)

`table_name` — 파티션 테이블의 이름(선택적으로 스키마 한정).

## 설명 (Description)

`DROP TABLE` 명령은 전체 테이블과 그 테이블에 있는 데이터를 제거합니다. 테이블을 삭제하면 그 테이블의 파티션과 서브파티션도 삭제됩니다.

`DROP TABLE` 명령을 사용하려면 파티셔닝 루트(root)의 소유자, 테이블을 소유한 그룹의 멤버, 스키마 소유자, 또는 데이터베이스 슈퍼유저여야 합니다.

## 예제 (Example)

테이블을 삭제하려면 컨트롤러 노드(파티셔닝 루트의 호스트)에 연결하여 `DROP TABLE` 명령을 실행합니다. 예를 들어 `sales` 테이블을 삭제하려면:

```sql
DROP TABLE sales;
```

서버는 테이블이 삭제되었음을 확인합니다:

```sql
edb=# drop table sales;
DROP TABLE
edb=#
```

`DROP TABLE` 명령에 대한 자세한 내용은 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/sql-droptable.html)를 참고하십시오.
