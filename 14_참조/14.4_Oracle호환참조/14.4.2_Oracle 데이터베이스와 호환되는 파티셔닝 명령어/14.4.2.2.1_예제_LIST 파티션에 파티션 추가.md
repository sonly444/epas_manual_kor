# 예제: Adding a partition to a LIST partitioned table — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...ADD PARTITION › Adding a partition to a LIST partitioned table](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/02_alter_table_add_partition/01_example_adding_a_partition_to_a_list_partitioned_table)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 리스트 파티션된 `sales` 테이블에 파티션을 추가합니다. 이 테이블은 다음 명령으로 생성되었습니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST(country)
(
  PARTITION europe VALUES('FRANCE', 'ITALY'),
  PARTITION asia VALUES('INDIA', 'PAKISTAN'),
  PARTITION americas VALUES('US', 'CANADA')
);
```

이 테이블은 `americas`, `asia`, `europe`의 세 개 파티션을 포함합니다.

```sql
edb=# SELECT partition_name, high_value FROM ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |     high_value
----------------+---------------------
 EUROPE         | 'FRANCE', 'ITALY'
 ASIA           | 'INDIA', 'PAKISTAN'
 AMERICAS       | 'US', 'CANADA'
(3 rows)
```

다음 명령은 `sales` 테이블에 `east_asia`라는 이름의 파티션을 추가합니다.

```sql
ALTER TABLE sales ADD PARTITION east_asia
  VALUES ('CHINA', 'KOREA');
```

명령을 실행한 후, 테이블에는 `east_asia` 파티션이 포함됩니다.

```sql
edb=# SELECT partition_name, high_value FROM ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |     high_value
----------------+---------------------
 EUROPE         | 'FRANCE', 'ITALY'
 ASIA           | 'INDIA', 'PAKISTAN'
 AMERICAS       | 'US', 'CANADA'
 EAST_ASIA      | 'CHINA', 'KOREA'
(4 rows)
```
