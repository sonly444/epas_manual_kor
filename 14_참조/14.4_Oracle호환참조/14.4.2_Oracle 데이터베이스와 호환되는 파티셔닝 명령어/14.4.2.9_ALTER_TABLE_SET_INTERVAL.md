# ALTER TABLE...SET INTERVAL — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...SET INTERVAL](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/09_alter_table_set_interval/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ALTER TABLE… SET INTERVAL` 명령을 사용하여 기존 범위 파티션 테이블을 인터벌 범위 파티션 테이블로 변환합니다. `INTERVAL`을 설정하면 데이터베이스는 파티션 테이블에 대해 지정된 범위나 인터벌의 파티션을 생성합니다. 구문은 다음과 같습니다:

```sql
ALTER TABLE <table_name> SET INTERVAL (<constant> | <expression>);
```

인터벌 범위 파티션 테이블을 비활성화하고 범위 파티션 테이블로 변환하려면 다음 구문을 사용합니다:

```sql
ALTER TABLE <table_name> SET INTERVAL ();
```

## 파라미터 (Parameters)

`table_name` — 범위 파티션 테이블의 이름(선택적으로 스키마 한정).

`constant | expression` — `NUMERIC`, `DATE`, `TIME` 값을 지정합니다.

## 설명 (Description)

`ALTER TABLE… SET INTERVAL` 명령을 사용하여 범위 파티션 테이블이 인터벌 범위 파티셔닝을 사용하도록 변환할 수 있습니다. 명령은 지정된 인터벌의 새 파티션을 생성합니다. 그 후 새 파티션에 데이터를 삽입할 수 있습니다.

`SET INTERVAL ()` 명령을 사용하여 인터벌 범위 파티셔닝을 비활성화할 수 있습니다. 데이터베이스는 인터벌 범위 파티션 테이블을 범위 파티션 테이블로 변환하고, 인터벌 범위 파티션의 경계를 범위 파티션의 경계로 설정합니다.

> **예제 하위 페이지(원문):** 인터벌 범위 파티션 설정 (필요 시 개별 번역 추가 가능)
