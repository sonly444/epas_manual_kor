# 예제: Adding a partition to a RANGE partitioned table — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...ADD PARTITION › Adding a partition to a RANGE partitioned table](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/02_alter_table_add_partition/02_example_adding_a_partition_to_a_range_partitioned_table)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 `sales`라는 이름의 레인지 파티션된 테이블에 파티션을 추가합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY RANGE(date)
(
  PARTITION q1_2012
    VALUES LESS THAN('2012-Apr-01'),
  PARTITION q2_2012
    VALUES LESS THAN('2012-Jul-01'),
  PARTITION q3_2012
    VALUES LESS THAN('2012-Oct-01'),
  PARTITION q4_2012
    VALUES LESS THAN('2013-Jan-01')
);
```

이 테이블은 `q1_2012`, `q2_2012`, `q3_2012`, `q4_2012`의 네 개 파티션을 포함합니다.

```sql
edb=# SELECT partition_name, high_value FROM ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |      high_value
----------------+----------------------
 Q1_2012        | '01-APR-12 00:00:00'
 Q2_2012        | '01-JUL-12 00:00:00'
 Q3_2012        | '01-OCT-12 00:00:00'
 Q4_2012        | '01-JAN-13 00:00:00'
(4 rows)
```

다음 명령은 `sales` 테이블에 `q1_2013`이라는 이름의 파티션을 추가합니다.

```sql
ALTER TABLE sales ADD PARTITION q1_2013
  VALUES LESS THAN('01-APR-2013');
```

명령을 실행한 후, 테이블에는 `q1_2013` 파티션이 포함됩니다.

```sql
edb=# SELECT partition_name, high_value FROM ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |      high_value
----------------+----------------------
 Q1_2012        | '01-APR-12 00:00:00'
 Q2_2012        | '01-JUL-12 00:00:00'
 Q3_2012        | '01-OCT-12 00:00:00'
 Q4_2012        | '01-JAN-13 00:00:00'
 Q1_2013        | '01-APR-13 00:00:00'
(5 rows)
```
