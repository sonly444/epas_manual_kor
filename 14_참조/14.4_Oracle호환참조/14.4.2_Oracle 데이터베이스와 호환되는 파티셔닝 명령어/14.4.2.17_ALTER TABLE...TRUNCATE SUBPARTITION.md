# ALTER TABLE...TRUNCATE SUBPARTITION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...TRUNCATE SUBPARTITION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/17_alter_table_truncate_subpartition/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ALTER TABLE… TRUNCATE SUBPARTITION` 명령을 사용하여 서브파티션 정의는 보존하면서 서브파티션에서 데이터를 제거합니다. 구문은 다음과 같습니다:

```sql
ALTER TABLE <table_name>
TRUNCATE SUBPARTITION <subpartition_name>
  [{DROP|REUSE} STORAGE]
```

## 파라미터 (Parameters)

`table_name` — 파티션 테이블의 이름(선택적으로 스키마 한정).

`subpartition_name` — truncate할 서브파티션의 이름.

`DROP STORAGE`와 `REUSE STORAGE`는 Oracle 구문과의 호환성을 위해 파싱되지만 무시됩니다.

## 설명 (Description)

`ALTER TABLE… TRUNCATE SUBPARTITION` 명령은 서브파티션 정의는 보존하면서 지정한 서브파티션에서 데이터를 제거합니다.

`ALTER TABLE… TRUNCATE SUBPARTITION` 명령은 `ON TRUNCATE` 트리거를 발생시키지만 `ON DELETE` 트리거는 발생시키지 않습니다.

`ALTER TABLE… TRUNCATE SUBPARTITION` 명령을 사용하려면 지정한 서브파티션이 포함된 테이블에 대한 `TRUNCATE` 권한이 있어야 합니다.

> **예제 하위 페이지(원문):** 서브파티션 비우기 (필요 시 개별 번역 추가 가능)
