# 예제: Deleting a partition — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...DROP PARTITION › Deleting a partition](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/13_alter_table_drop_partition/01_example_deleting_a_partition)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 `sales` 테이블의 한 파티션을 삭제합니다.

`sales` 테이블을 생성합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST(country)
(
  PARTITION europe VALUES('FRANCE', 'ITALY'),
  PARTITION asia VALUES('INDIA', 'PAKISTAN'),
  PARTITION americas VALUES('US', 'CANADA')
);
```

`ALL_TAB_PARTITIONS` 뷰를 조회하여 파티션 이름을 표시합니다.

```sql
edb=# SELECT partition_name, high_value FROM ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |     high_value
----------------+---------------------
 EUROPE         | 'FRANCE', 'ITALY'
 ASIA           | 'INDIA', 'PAKISTAN'
 AMERICAS       | 'US', 'CANADA'
(3 rows)
```

`sales` 테이블에서 `americas` 파티션을 삭제합니다.

```sql
ALTER TABLE sales DROP PARTITION americas;
```

`ALL_TAB_PARTITIONS` 뷰를 조회하여 파티션이 성공적으로 삭제되었음을 확인합니다.

```sql
edb=# SELECT partition_name, high_value FROM ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |     high_value
----------------+---------------------
 EUROPE         | 'FRANCE', 'ITALY'
 ASIA           | 'INDIA', 'PAKISTAN'
(2 rows)
```
