# ALTER TABLE...SPLIT PARTITION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...SPLIT PARTITION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/04_alter_table_split_partition/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ALTER TABLE… SPLIT PARTITION` 명령을 사용하여 단일 파티션을 두 개의 파티션으로 나눕니다. 이 명령은 새로 생성된 파티션에서 원본 테이블의 파티셔닝을 유지하고, 파티션의 내용을 새 파티션들 사이에 재분배합니다. 명령 구문은 두 가지 형태로 제공됩니다.

첫 번째 형태는 `RANGE` 파티션을 두 파티션으로 분할합니다:

```sql
ALTER TABLE <table_name> SPLIT PARTITION <partition_name>
  AT (<range_part_value>)
  INTO
  (
    PARTITION <new_part1>
     [TABLESPACE <tablespace_name>]
     [SUBPARTITIONS <num>] [STORE IN ( <tablespace_name> [, <tablespace_name>]... ) ],
    PARTITION <new_part2>
     [TABLESPACE <tablespace_name>]
     [SUBPARTITIONS <num>] [STORE IN ( <tablespace_name> [, <tablespace_name>]... ) ]
  );
```

두 번째 형태는 `LIST` 파티션을 두 파티션으로 분할합니다:

```sql
ALTER TABLE <table_name> SPLIT PARTITION <partition_name>
  VALUES (<value>[, <value>]...)
  INTO
  (
    PARTITION <new_part1>
     [TABLESPACE <tablespace_name>]
     [SUBPARTITIONS <num>] [STORE IN ( <tablespace_name> [, <tablespace_name>]... ) ],
    PARTITION <new_part2>
     [TABLESPACE <tablespace_name>]
     [SUBPARTITIONS <num>] [STORE IN ( <tablespace_name> [, <tablespace_name>]... ) ]
  );
```

## 설명 (Description)

`ALTER TABLE...SPLIT PARTITION` 명령은 기존 `LIST` 또는 `RANGE` 파티션 테이블에 파티션을 추가합니다. `ALTER TABLE… SPLIT PARTITION` 명령은 `HASH` 파티션 테이블에는 파티션을 추가할 수 없습니다. 파티션 수에는 상한이 없습니다.

`ALTER TABLE...SPLIT PARTITION` 명령을 실행하면 EDB Postgres Advanced Server는:

- 두 개의 새 파티션을 생성합니다.
- 새로 생성된 파티션에서 원본 테이블의 파티셔닝을 유지합니다.
- 파티셔닝 규칙의 제약에 따라 기존 파티션의 내용을 새 파티션들 사이에 재분배합니다.

파티션이 위치하는 테이블스페이스를 지정하려면 `TABLESPACE` 절을 포함합니다. 테이블스페이스를 지정하지 않으면 파티션은 원본 파티션 테이블의 테이블스페이스에 위치합니다.

자동 생성된 서브파티션이 저장되는 테이블스페이스 목록을 지정하려면 `STORE IN` 절을 사용합니다.

테이블이 인덱싱되어 있으면 새 파티션에 인덱스가 생성됩니다.

`ALTER TABLE... SPLIT PARTITION` 명령을 사용하려면 테이블 소유자이거나 슈퍼유저 또는 관리 권한이 있어야 합니다.

## 파라미터 (Parameters)

`table_name` — 파티션 테이블의 이름(선택적으로 스키마 한정).

`partition_name` — 분할되는 파티션의 이름.

`new_part1` — 생성할 첫 번째 파티션의 이름. 모든 파티션·서브파티션 중에서 고유해야 하며 객체 식별자 명명 규칙을 따라야 합니다. `new_part1`은 `ALTER TABLE… SPLIT PARTITION` 명령에 지정된 파티셔닝 제약을 충족하는 행을 받습니다.

`new_part2` — 생성할 두 번째 파티션의 이름. 모든 파티션·서브파티션 중에서 고유해야 하며 객체 식별자 명명 규칙을 따라야 합니다. `new_part2`는 `ALTER TABLE… SPLIT PARTITION` 명령에 지정된 파티셔닝 제약에 의해 `new_part1`로 보내지지 않는 행을 받습니다.

`range_part_value` — 새 파티션을 생성할 경계 규칙을 지정합니다. 파티셔닝 규칙은 두 개의 연산자(크거나 같음 연산자와 작음 연산자)를 갖는 데이터 타입의 컬럼을 적어도 하나 포함해야 합니다. 범위 경계는 `LESS THAN` 절에 대해 평가되며 비포함입니다. 2010년 1월 1일이라는 날짜 경계는 2009년 12월 31일 이전(당일 포함)에 해당하는 날짜 값만 포함합니다.

`(value[, value]...)` — 행을 파티션으로 분산하는 기준이 되는, 따옴표로 묶인 리터럴 값 또는 쉼표 구분 리터럴 값 목록. 각 파티셔닝 규칙은 적어도 하나의 값을 지정해야 합니다. 규칙에 지정하는 값의 수에는 제한이 없습니다.

`DEFAULT`나 `MAXVALUE` 파티션 생성에 대한 정보는 [LIST 또는 RANGE 파티션 테이블에서 미분류 값 처리](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_table_partitioning/05_handling_stray_values_in_a_list_or_range_partitioned_table/#handling_stray_values_in_a_list_or_range_partitioned_table)를 참고하십시오.

`num` — `SUBPARTITIONS num` 절은 `HASH` 서브파티션에만 지원됩니다. 해시 서브파티션 수를 지정하는 데 사용합니다. 또는 서브파티션 정의를 사용하여 개별 서브파티션과 테이블스페이스를 지정할 수 있습니다. `SUBPARTITIONS`나 `SUBPARTITION DEFINITION`을 지정하지 않으면 파티션은 `SUBPARTITION TEMPLATE`를 기준으로 서브파티션을 생성합니다.

`tablespace_name` — 파티션이나 서브파티션이 위치하는 테이블스페이스의 이름.

> **예제 하위 페이지(원문):** LIST 파티션 분할 · RANGE 파티션 분할 · RANGE/LIST 파티션 분할 (필요 시 개별 번역 추가 가능)
