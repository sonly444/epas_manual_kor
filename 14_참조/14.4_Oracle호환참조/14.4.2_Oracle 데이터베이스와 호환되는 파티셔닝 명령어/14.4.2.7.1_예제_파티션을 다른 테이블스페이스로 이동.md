# 예제: Moving a partition to a different tablespace — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...MOVE PARTITION › Moving a partition to a different tablespace](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/07_alter_table_move_partition/01_example_moving_a_partition_to_a_different_tablespace)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

다음 예제는 `sales` 테이블의 한 파티션을 어떤 테이블스페이스에서 다른 테이블스페이스로 이동합니다.

다음 명령으로 `sales` 테이블을 생성합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY RANGE(date)
(
  PARTITION q1_2012 VALUES LESS THAN ('2012-Apr-01'),
  PARTITION q2_2012 VALUES LESS THAN ('2012-Jul-01'),
  PARTITION q3_2012 VALUES LESS THAN ('2012-Oct-01'),
  PARTITION q4_2012 VALUES LESS THAN ('2013-Jan-01') TABLESPACE ts_1,
  PARTITION q1_2013 VALUES LESS THAN ('2013-Mar-01') TABLESPACE ts_2
);
```

`ALL_TAB_PARTITIONS` 뷰를 조회하면 각 파티션이 예상한 서버와 테이블스페이스에 위치하고 있음을 확인할 수 있습니다.

```sql
edb=# SELECT partition_name, tablespace_name FROM ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name | tablespace_name
----------------+-----------------
 Q1_2012        |
 Q2_2012        |
 Q3_2012        |
 Q4_2012        | TS_1
 Q1_2013        | TS_2
(5 rows)
```

대상 테이블스페이스를 준비한 후, `ALTER TABLE… MOVE PARTITION` 명령을 실행하여 `q1_2013` 파티션을 `ts_2`라는 이름의 테이블스페이스에서 `ts_3`라는 이름의 테이블스페이스로 이동합니다.

```sql
ALTER TABLE sales MOVE PARTITION q1_2013 TABLESPACE ts_3;
```

`ALL_TAB_PARTITIONS` 뷰를 조회하면 이동이 성공적으로 완료되었음을 알 수 있습니다.

```sql
edb=# SELECT partition_name, tablespace_name FROM ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name | tablespace_name
----------------+-----------------
 Q1_2012        |
 Q2_2012        |
 Q3_2012        |
 Q4_2012        | TS_1
 Q1_2013        | TS_3
(5 rows)
```
