# 예제: INTERVAL RANGE PARTITION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › CREATE TABLE...PARTITION BY › INTERVAL RANGE PARTITION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/01_create_table_partition_by/04_example_interval_range_partition)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 `sold_month` 열을 기준으로 인터벌(interval)로 파티셔닝된 `sales` 테이블을 보여줍니다. 전환 지점(transition point)을 설정하기 위해 범위 파티션이 생성되며, 그 전환 지점 이후로 새 파티션이 생성됩니다. 데이터베이스는 새 인터벌 범위 파티션을 생성하고 테이블에 데이터를 추가합니다.

```sql
CREATE TABLE sales
(
  prod_id           int,
  prod_quantity     int,
  sold_month        date
)
PARTITION BY RANGE(sold_month)
INTERVAL(NUMTOYMINTERVAL(1, 'MONTH'))
(
  PARTITION p1
    VALUES LESS THAN('15-JAN-2019'),
  PARTITION p2
    VALUES LESS THAN('15-FEB-2019')
);
```

데이터베이스가 인터벌 범위 파티션을 생성하기 전에 `ALL_TAB_PARTITIONS` 뷰를 조회합니다.

```sql
edb=# SELECT partition_name, high_value from ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |      high_value
----------------+----------------------
 P1             | '15-JAN-19 00:00:00'
 P2             | '15-FEB-19 00:00:00'
(2 rows)
```

범위 파티션의 상한값(high value)을 초과하는 데이터를 `sales` 테이블에 삽입합니다.

```sql
edb=# INSERT INTO sales VALUES (1,200,'10-MAY-2019');
INSERT 0 1
```

삽입 후에 `ALL_TAB_PARTITIONS` 뷰를 다시 조회합니다. 데이터가 성공적으로 삽입되었으며, 시스템이 생성한 이름의 인터벌 범위 파티션이 만들어집니다. 그 이름은 세션마다 달라집니다.

```sql
edb=# SELECT partition_name, high_value from ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |      high_value
----------------+----------------------
 P1             | '15-JAN-19 00:00:00'
 P2             | '15-FEB-19 00:00:00'
 SYS916340103   | '15-MAY-19 00:00:00'
(3 rows)
```
