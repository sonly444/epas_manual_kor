# 예제: Setting an interval range partition — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...SET INTERVAL › Setting an interval range partition](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/09_alter_table_set_interval/01_example_setting_an_interval_range_partition)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 `sales` 테이블에 인터벌 범위 파티션(interval range partition)을 설정합니다. 이 예제는 테이블을 범위 파티셔닝(range partitioning)에서 월별 인터벌 범위 파티셔닝(monthly interval range partitioning)을 사용하도록 변환합니다.

다음 명령은 `sales` 테이블을 생성합니다.

```sql
CREATE TABLE sales
(
  prod_id           int,
  prod_quantity     int,
  sold_month        date
)
PARTITION BY RANGE(sold_month)
(
  PARTITION p1
    VALUES LESS THAN('15-JAN-2019'),
  PARTITION p2
    VALUES LESS THAN('15-FEB-2019')
);
```

`sales` 테이블에 인터벌 범위 파티셔닝을 설정합니다.

```sql
ALTER TABLE sales SET INTERVAL (NUMTOYMINTERVAL(1, 'MONTH'));
```

데이터베이스가 인터벌 범위 파티션을 생성하기 전에 `ALL_TAB_PARTITIONS` 뷰를 조회합니다.

```sql
edb=# SELECT partition_name, high_value from ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |      high_value
----------------+----------------------
 P1             | '15-JAN-19 00:00:00'
 P2             | '15-FEB-19 00:00:00'
(2 rows)
```

범위 파티션의 상한 값(high value)을 초과하는 데이터를 `sales` 테이블에 추가합니다.

```sql
edb=# INSERT INTO sales VALUES (1,100,'05-APR-2019');
INSERT 0 1
```

`INSERT` 문 이후에 `ALL_TAB_PARTITIONS` 뷰를 다시 조회합니다. 인터벌 범위 파티션이 성공적으로 생성되고 데이터가 삽입됩니다. 인터벌 범위 파티션의 시스템 생성 이름(system-generated name)이 만들어지며, 이 이름은 각 세션마다 달라집니다.

```sql
edb=# SELECT partition_name, high_value from ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |      high_value
----------------+----------------------
 P1             | '15-JAN-19 00:00:00'
 P2             | '15-FEB-19 00:00:00'
 SYS916340103   | '15-APR-19 00:00:00'
(3 rows)
```
