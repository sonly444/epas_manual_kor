# 예제: AUTOMATIC LIST PARTITION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › CREATE TABLE...PARTITION BY › Example: AUTOMATIC LIST PARTITION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/01_create_table_partition_by/02_example_automatic_list_partition/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 `AUTOMATIC` 절을 사용하여 `sales_state` 열에 대한 자동 리스트 파티션 테이블을 생성하는 `sales` 테이블을 보여줍니다. 데이터베이스는 파티션을 생성하고 테이블에 데이터를 추가합니다.

```sql
CREATE TABLE sales
(
  dept_no      number,
  part_no      varchar2,
  sales_state  varchar2(20),
  date         date,
  amount       number
)
PARTITION BY LIST(sales_state) AUTOMATIC
(
  PARTITION P_CAL VALUES('CALIFORNIA'),
  PARTITION P_FLO VALUES('FLORIDA')
);
```

성공적으로 생성된 기존 파티션을 보려면 `ALL_TAB_PARTITIONS` 뷰를 조회합니다:

```sql
edb=# SELECT table_name, partition_name, high_value from ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 table_name | partition_name |  high_value
------------+----------------+--------------
 SALES      | P_CAL          | 'CALIFORNIA'
 SALES      | P_FLO          | 'FLORIDA'
(2 rows)
```

기존 파티션에 들어갈 수 없는 데이터를 `sales` 테이블에 삽입합니다. 일반 리스트 파티션 테이블에서는 오류가 발생합니다. 그러나 자동 리스트 파티셔닝은 새 파티션을 생성하고 그 파티션에 데이터를 삽입합니다.

```sql
edb=# INSERT INTO sales VALUES (1, 'IND', 'INDIANA');
INSERT 0 1
edb=# INSERT INTO sales VALUES (2, 'OHI', 'OHIO');
INSERT 0 1
```

삽입 후 `ALL_TAB_PARTITIONS` 뷰를 다시 조회합니다. 새 값을 담기 위해 파티션이 생성되고 데이터가 삽입됩니다. 시스템이 생성한 파티션 이름이 만들어지며, 이 이름은 세션마다 다릅니다.

```sql
edb=# SELECT table_name, partition_name, high_value from ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 table_name | partition_name |  high_value
------------+----------------+--------------
 SALES      | P_CAL          | 'CALIFORNIA'
 SALES      | P_FLO          | 'FLORIDA'
 SALES      | SYS106900103   | 'INDIANA'
 SALES      | SYS106900104   | 'OHIO'
(4 rows)
```
