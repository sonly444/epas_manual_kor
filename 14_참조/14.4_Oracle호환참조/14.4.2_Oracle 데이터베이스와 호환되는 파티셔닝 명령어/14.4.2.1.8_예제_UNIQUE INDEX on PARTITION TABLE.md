# 예제: CREATING UNIQUE INDEX on PARTITION TABLE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › CREATE TABLE...PARTITION BY › CREATING UNIQUE INDEX on PARTITION TABLE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/01_create_table_partition_by/08_example_creating_unique_index)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

고유 인덱스(unique-index) 파티션 테이블의 경우, 범위(range), 리스트(list), 또는 해시(hash) 파티셔닝 방식을 사용할 수 있습니다. 파티션 테이블에 고유한 `ROWID`를 생성하려면 매개변수 `default_with_rowids = true`를 설정해야 합니다.

이 예제는 `PARTITION BY LIST` 절을 사용하여 파티션 테이블 `sales`를 생성합니다. `sales` 테이블은 `europe`, `asia`, `americas`의 세 파티션에 정보를 저장합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST(country)
(
  PARTITION europe VALUES('FRANCE', 'ITALY'),
  PARTITION asia VALUES('INDIA', 'PAKISTAN'),
  PARTITION americas VALUES('US', 'CANADA')
)
WITH(ROWIDS=TRUE);
```

테이블은 `country` 열에 지정된 값으로 파티셔닝됩니다.

```sql
edb=# SELECT partition_name, high_value from ALL_TAB_PARTITIONS;
```

출력(Output)

```text
 partition_name |     high_value
----------------+---------------------
 EUROPE         | 'FRANCE', 'ITALY'
 ASIA           | 'INDIA', 'PAKISTAN'
 AMERICAS       | 'US', 'CANADA'
(3 rows)
```

`sales` 테이블에 값을 삽입합니다.

```sql
INSERT INTO sales VALUES (10, '9519a', 'FRANCE', '18-Aug-2012', '650000');
INSERT INTO sales VALUES (10, '9519b', 'ITALY', '20-Aug-2012', '700000');
```

이 쿼리는 `sales` 테이블에 대해 고유 인덱스가 생성되었음을 보여줍니다.

```sql
edb=# SELECT oid, relname, relhasindex from pg_class where relname='sales';
```

출력(Output)

```text
  oid  | relname | relhasindex
-------+---------+-------------
 16557 | sales   | f
(1 row)
```

`sales_europe`의 내용을 조회하면 이 테이블에 대해 고유 인덱스가 생성되었음을 확인할 수 있습니다.

```sql
edb=# SELECT oid, relname, relhasindex from pg_class where relname='sales_europe';
```

출력(Output)

```text
  oid  |   relname    | relhasindex
-------+--------------+-------------
 16561 | sales_europe | t
(1 row)
```
