# PARTITION 또는 SUBPARTITION 접근 (Accessing a Partition or Subpartition) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › Accessing a partition or subpartition](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/18_accessing_a_partition_or_subpartition/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`PARTITION` 또는 `SUBPARTITION` 절을 사용하여 `SELECT`, `INSERT`, `UPDATE`, `DELETE` 명령에서 특정 파티션이나 서브파티션의 데이터에 접근할 수 있습니다.

다음 예제에서는 `sales` 테이블을 사용합니다. 이 테이블은 `date` 열을 기준으로 `RANGE`로 파티셔닝되고, 다시 `country` 열을 기준으로 `LIST`로 서브파티셔닝됩니다:

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY RANGE(date)
  SUBPARTITION BY LIST(country)
  (
    PARTITION first_half_2012 VALUES LESS THAN('01-JUL-2012')
    (
      SUBPARTITION europe_2012_h1 VALUES('ITALY', 'FRANCE'),
      SUBPARTITION americas_2012_h1 VALUES('CANADA', 'US'),
      SUBPARTITION asia_2012_h1 VALUES('INDIA', 'PAKISTAN')
    ),
    PARTITION second_half_2012 VALUES LESS THAN('01-JAN-2013')
    (
      SUBPARTITION europe_2012_h2 VALUES('ITALY', 'FRANCE'),
      SUBPARTITION americas_2012_h2 VALUES('CANADA', 'US'),
      SUBPARTITION asia_2012_h2 VALUES('INDIA', 'PAKISTAN')
    )
  );
```

## PARTITION 또는 SUBPARTITION의 내용 선택 (SELECT)

`SELECT` 명령에서 `PARTITION` 절을 사용하여 지정한 파티션의 내용을 조회합니다:

```sql
SELECT * FROM sales PARTITION (first_half_2012);
```

`SUBPARTITION` 절을 사용하여 지정한 서브파티션의 내용을 조회합니다:

```sql
SELECT * FROM sales SUBPARTITION (asia_2012_h1);
```

## PARTITION 또는 SUBPARTITION에 삽입 (INSERT)

파티션 테이블에 행을 삽입할 때는 대상 파티션이나 서브파티션을 지정할 수 있습니다. 삽입하는 값은 지정한 파티션·서브파티션의 경계 조건과 일치해야 하며, 일치하지 않으면 서버가 오류를 반환합니다:

```sql
INSERT INTO sales PARTITION (first_half_2012) VALUES
  (10, '9519a', 'FRANCE', '15-Jan-2012', '5000');
```

## PARTITION 또는 SUBPARTITION 갱신 (UPDATE)

`UPDATE` 명령에서 `PARTITION` 또는 `SUBPARTITION` 절을 사용하여 지정한 파티션이나 서브파티션의 행만 갱신합니다:

```sql
UPDATE sales PARTITION (first_half_2012) SET amount = '5500'
  WHERE part_no = '9519a';
```

## PARTITION 또는 SUBPARTITION에서 삭제 (DELETE)

`DELETE` 명령에서 `PARTITION` 또는 `SUBPARTITION` 절을 사용하여 지정한 파티션이나 서브파티션의 행만 삭제합니다:

```sql
DELETE FROM sales PARTITION (first_half_2012)
  WHERE country = 'FRANCE';
```

## 별칭 사용 (Using an alias)

파티션 또는 서브파티션 이름 뒤에 별칭(alias)을 지정할 수 있습니다. 다음 예제는 `first_half_2012` 파티션에 별칭 `s`를 부여합니다:

```sql
SELECT * FROM sales PARTITION (first_half_2012) AS s WHERE s.amount > 1000;
```
