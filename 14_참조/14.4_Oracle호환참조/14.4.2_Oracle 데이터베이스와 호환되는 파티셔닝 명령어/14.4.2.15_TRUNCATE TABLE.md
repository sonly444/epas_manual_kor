# TRUNCATE TABLE (파티셔닝) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › TRUNCATE TABLE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/15_truncate_table/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`TRUNCATE TABLE` 명령을 사용하여 테이블 정의는 보존하면서 테이블의 내용을 제거합니다. 테이블을 truncate하면 그 테이블의 파티션과 서브파티션도 truncate됩니다. 구문은 다음과 같습니다:

```sql
TRUNCATE TABLE <table_name>
```

## 파라미터 (Parameters)

`table_name` — 파티션 테이블의 이름(선택적으로 스키마 한정).

## 설명 (Description)

`TRUNCATE TABLE` 명령은 전체 테이블과 그 테이블에 있는 데이터를 제거합니다. 테이블을 삭제하면 그 테이블의 파티션과 서브파티션도 삭제됩니다.

`TRUNCATE TABLE` 명령을 사용하려면 파티셔닝 루트의 소유자, 테이블을 소유한 그룹의 멤버, 스키마 소유자, 또는 데이터베이스 슈퍼유저여야 합니다.

> **예제 하위 페이지(원문):** 테이블 비우기 (필요 시 개별 번역 추가 가능)
