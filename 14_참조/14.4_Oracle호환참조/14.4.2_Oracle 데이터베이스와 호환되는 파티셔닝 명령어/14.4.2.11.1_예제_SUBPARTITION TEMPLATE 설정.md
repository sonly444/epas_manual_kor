# 예제: Setting a SUBPARTITION TEMPLATE — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...SET SUBPARTITION TEMPLATE › Setting a SUBPARTITION TEMPLATE](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/11_alter_table_set_subpartition_template/01_example_setting_a_subpartition_template)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 `date`로 범위 파티셔닝(range partitioned)되고 `country`로 해시 서브파티셔닝(hash-subpartitioned)된 `sales` 테이블을 생성합니다.

다음 명령은 `sales` 테이블을 생성합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY RANGE (date) SUBPARTITION BY HASH (country) SUBPARTITIONS 2
(
  PARTITION q1_2012
    VALUES LESS THAN('2012-Apr-01'),
  PARTITION q2_2012
    VALUES LESS THAN('2012-Jul-01'),
  PARTITION q3_2012
    VALUES LESS THAN('2012-Oct-01'),
  PARTITION q4_2012
    VALUES LESS THAN('2013-Jan-01')
);
```

이 테이블 정의는 `q1_2012`, `q2_2012`, `q3_2012`, `q4_2012`라는 네 개의 파티션을 생성합니다. 각 파티션은 시스템 생성 이름(system-generated names)을 가진 두 개의 서브파티션으로 구성됩니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | Q1_2012        | SYS0101
 SALES      | Q1_2012        | SYS0102
 SALES      | Q2_2012        | SYS0103
 SALES      | Q2_2012        | SYS0104
 SALES      | Q3_2012        | SYS0105
 SALES      | Q3_2012        | SYS0106
 SALES      | Q4_2012        | SYS0107
 SALES      | Q4_2012        | SYS0108
(8 rows)
```

`sales` 테이블에 서브파티션 템플릿(subpartition template)을 설정합니다.

```sql
ALTER TABLE sales SET SUBPARTITION TEMPLATE 8;
```

`sales` 테이블이 수정되어 서브파티션 템플릿이 8로 설정됩니다. `q1_2013` 파티션을 추가하려고 하면, 새 파티션이 생성되고 여덟 개의 서브파티션으로 구성됩니다.

```sql
ALTER TABLE sales ADD PARTITION q1_2013 VALUES LESS THAN ('2013-Apr-01');
```

`ALL_TAB_PARTITIONS` 뷰를 조회합니다. `q1_2013` 파티션이 성공적으로 추가됩니다. 이 파티션은 시스템 생성 이름을 가진 여덟 개의 서브파티션을 가지고 있습니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' and partition_name =
'Q1_2013' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | Q1_2013        | SYS0113
 SALES      | Q1_2013        | SYS0114
 SALES      | Q1_2013        | SYS0115
 SALES      | Q1_2013        | SYS0116
 SALES      | Q1_2013        | SYS0117
 SALES      | Q1_2013        | SYS0118
 SALES      | Q1_2013        | SYS0119
 SALES      | Q1_2013        | SYS0120
(8 rows)
```

## 예제: LIST/LIST 파티션 테이블에 서브파티션 템플릿 추가하기

이 예제는 country로 리스트 파티셔닝(list-partitioned)된 `sales` 테이블을 생성합니다. 이 테이블은 `date` 열을 사용하여 리스트로 서브파티셔닝됩니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST (country)
  SUBPARTITION BY LIST (date)
  SUBPARTITION TEMPLATE
(
    SUBPARTITION europe VALUES('2021-Jan-01') TABLESPACE ts1,
    SUBPARTITION asia VALUES('2021-Apr-01') TABLESPACE ts2,
    SUBPARTITION americas VALUES('2021-Jul-01') TABLESPACE ts3
)
(
    PARTITION q1_2021 VALUES('2021-Jul-01')
);
```

`SELECT` 문은 `q1_2021` 파티션이 테이블스페이스 `ts1`, `ts2`, `ts3`에 저장된 세 개의 서브파티션으로 구성되어 있음을 보여줍니다.

```sql
edb=# SELECT partition_name, subpartition_name, high_value, tablespace_name FROM
DBA_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text

----------------+-------------------+----------------------+-----------------
 Q1_2021        | Q1_2021_AMERICAS  | '01-JUL-21 00:00:00' | TS3

 Q1_2021        | Q1_2021_EUROPE    | '01-JAN-21 00:00:00' | TS1
(3 rows)
```

다음 명령은 `sales` 테이블에 `q2_2021`이라는 이름의 파티션을 추가합니다.

## 예제: SUBPARTITION TEMPLATE 재설정하기

이 예제는 `country`로 리스트 파티셔닝되고 `part_no`로 해시 서브파티셔닝된 리스트 파티션 테이블 `sales`를 생성합니다.

다음 명령은 `sales` 테이블을 생성합니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST (country) SUBPARTITION BY HASH (part_no) SUBPARTITIONS 3
(
  PARTITION europe VALUES('FRANCE', 'ITALY'),
  PARTITION asia VALUES('INDIA', 'PAKISTAN'),
  PARTITION americas VALUES('US', 'CANADA')
);
```

이 테이블은 `americas`, `asia`, `europe`라는 세 개의 파티션을 포함합니다. 각 파티션은 시스템 생성 이름을 가진 세 개의 서브파티션으로 구성됩니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | AMERICAS       | SYS0109
 SALES      | AMERICAS       | SYS0107
 SALES      | AMERICAS       | SYS0108
 SALES      | ASIA           | SYS0105
 SALES      | ASIA           | SYS0104
 SALES      | ASIA           | SYS0106
 SALES      | EUROPE         | SYS0101
 SALES      | EUROPE         | SYS0103
 SALES      | EUROPE         | SYS0102
(9 rows)
```

다음 명령은 `sales` 테이블의 서브파티션 템플릿을 재설정합니다.

```sql
ALTER TABLE sales SET SUBPARTITION TEMPLATE ();
```

`sales` 테이블이 수정되어 서브파티션 템플릿이 기본값 `1`로 재설정됩니다. 다음 명령을 사용하여 새 파티션 `east_asia`를 추가해 봅니다.

```sql
ALTER TABLE sales ADD PARTITION east_asia VALUES ('CHINA', 'KOREA');
```

`ALL_TAB_PARTITIONS` 뷰를 조회합니다. 시스템 생성 이름을 가진 하나의 서브파티션으로 구성된 새 파티션 `east_asia`가 생성됩니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' and partition_name =
'EAST_ASIA' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | EAST_ASIA      | SYS0113
(1 row)
```
