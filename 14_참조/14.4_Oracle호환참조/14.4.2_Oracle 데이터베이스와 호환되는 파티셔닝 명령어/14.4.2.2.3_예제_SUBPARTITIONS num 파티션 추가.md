# 예제: Adding a partition with SUBPARTITIONS num...IN PARTITION DESCRIPTION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...ADD PARTITION › Adding a partition with SUBPARTITIONS num...IN PARTITION DESCRIPTION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/02_alter_table_add_partition/03_example_adding_a_partition_with_subpartitions_number)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

이 예제는 리스트 파티션된 `sales` 테이블에 파티션을 추가합니다. `SUBPARTITIONS` 절을 지정하여 지정된 개수의 서브파티션을 추가할 수 있습니다. `sales` 테이블은 다음 명령으로 생성되었습니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST (country) SUBPARTITION BY HASH (part_no) SUBPARTITIONS 2
(
  PARTITION europe VALUES ('FRANCE', 'ITALY'),
  PARTITION asia  VALUES ('INDIA', 'PAKISTAN')
);
```

이 테이블은 `europe`와 `asia`의 두 개 파티션을 포함합니다. 각 파티션은 두 개의 서브파티션을 포함합니다. 서브파티션에 이름이 지정되지 않았기 때문에 시스템이 생성한 이름이 할당됩니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | ASIA           | SYS0103
 SALES      | ASIA           | SYS0104
 SALES      | EUROPE         | SYS0101
 SALES      | EUROPE         | SYS0102
(4 rows)
```

다음 명령은 `sales` 테이블에 `americas` 파티션을 추가하고, 파티션 설명에 지정된 대로 여러 개의 서브파티션을 생성합니다.

```sql
ALTER TABLE sales ADD PARTITION americas
  VALUES ('US', 'CANADA');
```

명령을 실행한 후, 테이블에는 `americas` 파티션과 새로 추가된 두 개의 서브파티션이 포함됩니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | AMERICAS       | SYS0107
 SALES      | AMERICAS       | SYS0108
 SALES      | ASIA           | SYS0103
 SALES      | ASIA           | SYS0104
 SALES      | EUROPE         | SYS0101
 SALES      | EUROPE         | SYS0102
(6 rows)
```

## Example - Adding a Partition with SUBPARTITIONS num...

이 예제는 세 개의 서브파티션으로 구성된 리스트 파티션된 테이블 `sales`에 파티션을 추가합니다. `sales` 테이블은 다음 명령으로 생성되었습니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST (country) SUBPARTITION BY HASH (part_no) SUBPARTITIONS 3
(
  PARTITION europe VALUES ('FRANCE', 'ITALY'),
  PARTITION asia  VALUES ('INDIA', 'PAKISTAN')
);
```

이 테이블은 `europe`와 `asia` 파티션을 포함하며, 각 파티션은 세 개의 서브파티션을 포함합니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | ASIA           | SYS0104
 SALES      | ASIA           | SYS0105
 SALES      | ASIA           | SYS0106
 SALES      | EUROPE         | SYS0101
 SALES      | EUROPE         | SYS0102
 SALES      | EUROPE         | SYS0103
(6 rows)
```

다음 명령은 `ADD PARTITION` 절에 지정된 대로 `americas` 파티션과 다섯 개의 서브파티션을 추가합니다.

```sql
ALTER TABLE sales ADD PARTITION americas
  VALUES ('US', 'CANADA') SUBPARTITIONS 5;
```

명령을 실행한 후, `sales` 테이블에는 `americas` 파티션과 새로 추가된 다섯 개의 서브파티션이 포함됩니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' and partition_name =
'AMERICAS' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | AMERICAS       | SYS0109
 SALES      | AMERICAS       | SYS0110
 SALES      | AMERICAS       | SYS0111
 SALES      | AMERICAS       | SYS0112
 SALES      | AMERICAS       | SYS0113
(5 rows)
```

## Example: Adding a partition with SUBPARTITIONS num... STORE IN

이 예제는 세 개의 서브파티션으로 구성된 리스트 파티션된 테이블 `sales`에 파티션을 추가합니다. 이 테이블은 다음 명령으로 생성되었습니다.

```sql
CREATE TABLE sales
(
  dept_no     number,
  part_no     varchar2,
  country     varchar2(20),
  date        date,
  amount      number
)
PARTITION BY LIST (country) SUBPARTITION BY HASH (part_no) SUBPARTITIONS 3
(
  PARTITION europe VALUES('FRANCE', 'ITALY'),
  PARTITION asia VALUES('INDIA', 'PAKISTAN'),
  PARTITION americas VALUES('US', 'CANADA')
);
```

이 테이블은 `americas`, `asia`, `europe`의 세 개 파티션을 포함합니다. 각 파티션은 시스템이 생성한 이름을 가진 세 개의 서브파티션을 포함합니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name FROM
ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name
------------+----------------+-------------------
 SALES      | AMERICAS       | SYS0109
 SALES      | AMERICAS       | SYS0107
 SALES      | AMERICAS       | SYS0108
 SALES      | ASIA           | SYS0105
 SALES      | ASIA           | SYS0104
 SALES      | ASIA           | SYS0106
 SALES      | EUROPE         | SYS0101
 SALES      | EUROPE         | SYS0103
 SALES      | EUROPE         | SYS0102
(9 rows)
```

다음 명령은 `ADD PARTITION` 절에 지정된 대로 다섯 개의 서브파티션을 가진 `east_asia` 파티션을 추가합니다. 그리고 이들을 `ts1`이라는 이름의 테이블스페이스에 저장합니다.

```sql
ALTER TABLE sales ADD PARTITION east_asia
  VALUES ('CHINA', 'KOREA') SUBPARTITIONS 5 STORE IN (ts1);
```

명령을 실행한 후, 테이블에는 `east_asia` 파티션과 테이블스페이스 `ts1`에 저장된 새로 추가된 다섯 개의 서브파티션이 포함됩니다.

```sql
edb=# SELECT table_name, partition_name, subpartition_name, tablespace_name
FROM ALL_TAB_SUBPARTITIONS WHERE table_name = 'SALES' and partition_name =
'EAST_ASIA' ORDER BY 1,2;
```

출력(Output)

```text
 table_name | partition_name | subpartition_name | tablespace_name
------------+----------------+-------------------+-----------------
 SALES      | EAST_ASIA      | SYS0113           | TS1
 SALES      | EAST_ASIA      | SYS0114           | TS1
 SALES      | EAST_ASIA      | SYS0115           | TS1
 SALES      | EAST_ASIA      | SYS0116           | TS1
 SALES      | EAST_ASIA      | SYS0117           | TS1
(5 rows)
```
