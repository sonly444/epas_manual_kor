# ALTER TABLE...DROP SUBPARTITION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...DROP SUBPARTITION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/14_alter_table_drop_subpartition/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ALTER TABLE… DROP SUBPARTITION` 명령을 사용하여 서브파티션 정의와 그 서브파티션에 저장된 데이터를 삭제합니다. 구문은 다음과 같습니다:

```sql
ALTER TABLE <table_name> DROP SUBPARTITION <subpartition_name>;
```

## 파라미터 (Parameters)

`table_name` — 파티션 테이블의 이름(선택적으로 스키마 한정).

`subpartition_name` — 삭제할 서브파티션의 이름.

## 설명 (Description)

`ALTER TABLE… DROP SUBPARTITION` 명령은 서브파티션과 그 서브파티션에 저장된 데이터를 삭제합니다. `DROP SUBPARTITION` 절을 사용하려면 파티셔닝 루트의 소유자, 테이블을 소유한 그룹의 멤버, 또는 슈퍼유저나 관리 권한이 있어야 합니다.

> **예제 하위 페이지(원문):** 서브파티션 삭제 (필요 시 개별 번역 추가 가능)
