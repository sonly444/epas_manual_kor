# ALTER TABLE...ADD SUBPARTITION — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › 파티셔닝 명령 › ALTER TABLE...ADD SUBPARTITION](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/03_alter_table_add_subpartition/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드 이름은 원문 그대로 보존했습니다.

`ALTER TABLE… ADD SUBPARTITION` 명령은 기존의 서브파티션된 파티션에 서브파티션을 추가합니다. 구문은 다음과 같습니다:

```sql
ALTER TABLE <table_name> MODIFY PARTITION <partition_name>
      ADD SUBPARTITION <subpartition_definition>;

여기서 subpartition_definition은:

{<list_subpartition> | <range_subpartition>}

list_subpartition은:

        SUBPARTITION [<subpartition_name>]
          VALUES (<value>[, <value>]...)
          [TABLESPACE <tablespace_name>]

range_subpartition은:

        SUBPARTITION [<subpartition_name>]
          VALUES LESS THAN (<value>[, <value>]...)
          [TABLESPACE <tablespace_name>]
```

## 설명 (Description)

`ALTER TABLE… ADD SUBPARTITION` 명령은 기존 파티션에 서브파티션을 추가합니다. 파티션은 이미 서브파티션되어 있어야 합니다. 정의할 수 있는 서브파티션 수에는 상한이 없습니다.

새 서브파티션은 기존 서브파티션과 동일한 유형(`LIST`, `RANGE`, `HASH`)이어야 합니다. 새 서브파티션 규칙은 기존 서브파티션을 정의하는 서브파티셔닝 규칙에 지정된 것과 동일한 컬럼을 참조해야 합니다.

`ALTER TABLE… ADD SUBPARTITION` 문을 사용하여 `DEFAULT` 규칙이 있는 테이블에 서브파티션을 추가할 수 있습니다. 다만 테이블의 기존 행과 추가할 서브파티션의 값 사이에 충돌하는 값이 있어서는 안 됩니다.

`MAXVALUE` 규칙이 있는 테이블에는 `ALTER TABLE… ADD SUBPARTITION` 문을 사용하여 서브파티션을 추가할 수 없습니다.

`ALTER TABLE… SPLIT SUBPARTITION` 문으로 기존 서브파티션을 분할하여 실질적으로 테이블에 서브파티션을 추가할 수 있습니다.

범위 서브파티션 테이블에서 기존 서브파티션보다 앞서는 서브파티션을 추가할 수 없습니다. 범위 서브파티션은 오름차순으로 지정해야 합니다.

서브파티션이 위치하는 테이블스페이스를 지정하려면 `TABLESPACE` 절을 포함합니다. 테이블스페이스를 지정하지 않으면 서브파티션은 기본 테이블스페이스에 생성됩니다.

테이블이 인덱싱되어 있으면 새 서브파티션에 인덱스가 생성됩니다.

`ALTER TABLE... ADD SUBPARTITION` 명령을 사용하려면 테이블 소유자이거나 슈퍼유저 또는 관리 권한이 있어야 합니다.

## 파라미터 (Parameters)

`table_name` — 서브파티션이 위치하는 파티션 테이블의 이름(선택적으로 스키마 한정).

`partition_name` — 새 서브파티션이 위치하는 파티션의 이름.

`subpartition_name` — 생성할 서브파티션의 이름. 모든 파티션·서브파티션 중에서 고유해야 하며 객체 식별자 명명 규칙을 따라야 합니다.

`(value[, value]...)` — 테이블 항목을 파티션으로 그룹화하는 기준이 되는, 따옴표로 묶인 리터럴 값 또는 쉼표 구분 리터럴 값 목록. 각 파티셔닝 규칙은 적어도 하나의 값을 지정해야 합니다. 다만 규칙에 지정하는 값의 수에는 제한이 없습니다. `value`는 `NULL`, `LIST` 파티션 지정 시 `DEFAULT`, `RANGE` 파티션 지정 시 `MAXVALUE`일 수도 있습니다.

`DEFAULT`나 `MAXVALUE` 파티션 생성에 대한 정보는 [LIST 또는 RANGE 파티션 테이블에서 미분류 값 처리](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_table_partitioning/05_handling_stray_values_in_a_list_or_range_partitioned_table/#handling_stray_values_in_a_list_or_range_partitioned_table)를 참고하십시오.

`tablespace_name` — 서브파티션이 위치하는 테이블스페이스의 이름.
