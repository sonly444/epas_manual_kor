# dblink_ora 함수 및 프로시저 (dblink_ora functions and procedures) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 참조 › dblink_ora functions and procedures](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/01_dblink_ora_functions_and_procedures/)
> EPAS v18 공식 문서의 한글 **전문 번역** 트리입니다. 함수·프로시저·코드 이름은 원문 그대로 보존했습니다.

dblink_ora 유틸리티는 원격 Oracle 서버에 임의의 쿼리를 실행할 수 있게 하는 함수와 프로시저를 지원합니다.

## 하위 함수/프로시저 (7)

- **14.4.1.1 dblink_ora_connect()** — Oracle 데이터베이스 연결 설정
- **14.4.1.2 dblink_ora_status()** — 연결 상태 반환
- **14.4.1.3 dblink_ora_disconnect()** — 연결 종료
- **14.4.1.4 dblink_ora_record()** — 데이터베이스에서 정보 조회(SELECT)
- **14.4.1.5 dblink_ora_call()** — 비-SELECT 문 실행 후 결과 집합 반환
- **14.4.1.6 dblink_ora_exec()** — 원격 DB에서 DML/DDL 문 실행
- **14.4.1.7 dblink_ora_copy()** — Oracle 테이블을 EDB 테이블로 복사
