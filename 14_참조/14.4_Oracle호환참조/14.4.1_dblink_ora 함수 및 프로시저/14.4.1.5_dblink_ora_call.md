# dblink_ora_call() — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › dblink_ora › dblink_ora_call()](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/01_dblink_ora_functions_and_procedures/05_dblink_ora_call/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·파라미터·코드 이름은 원문 그대로 보존했습니다.

`dblink_ora_call()` 함수는 Oracle 데이터베이스에서 비-`SELECT` 문을 실행하고 결과 집합을 반환합니다. 시그니처는 다음과 같습니다:

```c
dblink_ora_call(<conn_name>, <command>, <iterations>)
```

여기서:

- `conn_name` — 링크의 이름을 지정합니다.
- `command` — Oracle 서버에서 실행되는 SQL 문의 텍스트를 지정합니다.
- `iterations` — 문이 실행되는 횟수를 지정합니다.

함수는 `SETOF` 레코드를 반환합니다.
