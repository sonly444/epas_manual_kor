# dblink_ora_status() — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › dblink_ora › dblink_ora_status()](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/01_dblink_ora_functions_and_procedures/02_dblink_ora_status/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·파라미터·코드 이름은 원문 그대로 보존했습니다.

`dblink_ora_status()` 함수는 데이터베이스 연결 상태를 반환합니다. 시그니처는 다음과 같습니다:

```c
dblink_ora_status(<conn_name>)
```

여기서:

`conn_name` — 링크의 이름을 지정합니다.

지정된 연결이 활성 상태이면, 함수는 `OK`라는 `TEXT` 값을 반환합니다.
