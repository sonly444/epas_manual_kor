# dblink_ora_exec() — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › dblink_ora › dblink_ora_exec()](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/01_dblink_ora_functions_and_procedures/06_dblink_ora_exec/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·파라미터·코드 이름은 원문 그대로 보존했습니다.

`dblink_ora_exec()` 프로시저는 원격 데이터베이스에서 DML 또는 DDL 문을 실행합니다. 시그니처는 다음과 같습니다:

```c
dblink_ora_exec(<conn_name>, <command>)
```

여기서:

- `conn_name` — 링크의 이름을 지정합니다.
- `command` — Oracle 서버에서 실행되는 `INSERT`, `UPDATE`, `DELETE` SQL 문의 텍스트를 지정합니다.

함수는 `VOID`를 반환합니다.
