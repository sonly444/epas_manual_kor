# dblink_ora_connect() — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › dblink_ora › dblink_ora_connect()](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/01_dblink_ora_functions_and_procedures/01_dblink_ora_connect/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·파라미터·코드 이름은 원문 그대로 보존했습니다.

`dblink_ora_connect()` 함수는 사용자가 지정한 연결 정보로 Oracle 데이터베이스에 연결을 설정합니다. 이 함수는 두 가지 형태로 제공됩니다.

첫 번째 형태의 시그니처는 다음과 같습니다:

```c
dblink_ora_connect(<conn_name>, <server_name>, <service_name>, <user_name>,
<password>, <port>, <asDBA>)
```

여기서:

- `conn_name` — 링크의 이름을 지정합니다.
- `server_name` — 호스트의 이름을 지정합니다.
- `service_name` — 서비스의 이름을 지정합니다.
- `user_name` — 서버 연결에 사용하는 이름을 지정합니다.
- `password` — 사용자 이름에 연관된 비밀번호를 지정합니다.
- `port` — 포트 번호를 지정합니다.
- `asDBA` — Oracle 서버에서 `SYSDBA` 권한을 요청하려면 `True`입니다. 이 파라미터는 선택적입니다. 생략하면 값은 `FALSE`입니다.

첫 번째 형태의 `dblink_ora_connect()`는 `TEXT` 값을 반환합니다.

`dblink_ora_connect()` 함수의 두 번째 형태의 시그니처는 다음과 같습니다:

```c
dblink_ora_connect(<foreign_server_name>, <asDBA>)
```

여기서:

- `foreign_server_name` — 외부 서버(foreign server)의 이름을 지정합니다.
- `asDBA` — Oracle 서버에서 `SYSDBA` 권한을 요청하려면 `True`입니다. 이 파라미터는 선택적입니다. 생략하면 값은 `FALSE`입니다.

`dblink_ora_connect()` 함수의 두 번째 형태를 사용하면, 서버에 연결할 때 사전 정의된 외부 서버의 연결 속성을 사용할 수 있습니다.

`dblink_ora_connect()` 함수의 두 번째 형태를 호출하기 전에, `CREATE SERVER` 명령을 사용해 링크의 연결 속성을 시스템 테이블에 저장하십시오. `dblink_ora_connect()` 함수를 호출할 때 링크 이름 대신 `CREATE SERVER` 명령에서 지정한 서버 이름을 대입합니다.

두 번째 형태의 `dblink_ora_connect()`는 `TEXT` 값을 반환합니다.
