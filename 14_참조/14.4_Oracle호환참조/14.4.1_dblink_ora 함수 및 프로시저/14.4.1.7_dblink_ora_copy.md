# dblink_ora_copy() — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Oracle 호환 › dblink_ora › dblink_ora_copy()](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/01_dblink_ora_functions_and_procedures/07_dblink_ora_copy/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 함수·파라미터·코드 이름은 원문 그대로 보존했습니다.

`dblink_ora_copy()` 함수는 Oracle 테이블을 EDB 테이블로 복사합니다. `dblink_ora_copy()` 함수는 복사된 행 수를 나타내는 `BIGINT` 값을 반환합니다. 시그니처는 다음과 같습니다:

```c
dblink_ora_copy(<conn_name>, <command>, <schema_name>, <table_name>,
<truncate>, <count>)
```

여기서:

- `conn_name` — 링크의 이름을 지정합니다.
- `command` — Oracle 서버에서 실행되는 SQL `SELECT` 문의 텍스트를 지정합니다.
- `schema_name` — 대상 스키마의 이름을 지정합니다.
- `table_name` — 대상 테이블의 이름을 지정합니다.
- `truncate` — 복사 전에 서버가 테이블에 대해 `TRUNCATE`를 수행할지 지정합니다. 서버가 테이블을 `TRUNCATE`하게 하려면 `TRUE`를 지정합니다. `truncate`는 선택적입니다. 생략하면 값은 `FALSE`입니다.
- `count` — `n` 레코드마다 상태 정보를 보고합니다(여기서 `n`은 숫자). 함수가 실행되는 동안 EDB Postgres Advanced Server는 count의 각 반복마다 심각도 `INFO`의 notice를 발생시킵니다. 예를 들어 FeedbackCount가 `10`이면 `dblink_ora_copy()`는 10 레코드마다 notice를 발생시킵니다. `count`는 선택적입니다. 생략하면 값은 `0`입니다.
