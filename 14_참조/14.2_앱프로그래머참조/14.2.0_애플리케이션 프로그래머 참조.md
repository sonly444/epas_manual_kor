# 애플리케이션 프로그래머 참조 (Application Programmer Reference) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Application programmer reference](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/)
> EPAS v18 공식 문서의 한글 번역입니다. 이름은 원문 그대로 보존했습니다.

애플리케이션 개발자를 위한 참조 콘텐츠입니다.

## 하위 구성
- **테이블 파티셔닝 뷰 참조(Table partitioning views reference)**: 파티션 관련 뷰(`ALL_PART_TABLES`, `ALL_TAB_PARTITIONS` 등).
- **시스템 카탈로그 테이블(System catalog tables)**: 지원되는 시스템 카탈로그 테이블 설명.
- **언어 요소 참조(Language element reference)**: ECPGPlus 언어 요소 설명.
- **SPL 참조(SPL reference)**: SPL 프로시저·함수·트리거·패키지에 대한 참조 콘텐츠.

> 개별 카탈로그 테이블의 전체 컬럼 정의가 필요하면 해당 페이지를 지정해 추가 번역할 수 있습니다.
