# CASE 표현식 (CASE expression) — EPAS 18 SPL 참조

> 원문: [EPAS v18 — SPL reference › Types of control structures › CASE expression](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/05_control_structures/04_case_expression/)
> EPAS v18 공식 문서 내용을 정리한 한국어 설명입니다. 구문·키워드·함수 이름은 원문 그대로 표기했습니다.

`CASE` 표현식은 값(value)을 반환하며, 그 값은 `CASE` 표현식이 위치한 자리에 대입됩니다. 즉 `CASE` 표현식은 값을 반환하는 **표현식**이라는 점에서, 동작을 수행하는 **`CASE` 문(statement)** 과 구분됩니다.

## 두 가지 형태

1. **선택자 CASE 표현식 (Selector CASE expression)** — 선택자(selector) 값을 여러 조건과 비교(match)합니다.

   ```text
   CASE <selector>
       WHEN <value_1> THEN <result_1>
       [ WHEN <value_2> THEN <result_2> ]...
       [ ELSE <result_else> ]
   END;
   ```

2. **검색 CASE 표현식 (Searched CASE expression)** — 명시적 선택자 없이 불리언(boolean) 조건을 평가합니다.

   ```text
   CASE
       WHEN <boolean_expr_1> THEN <result_1>
       [ WHEN <boolean_expr_2> THEN <result_2> ]...
       [ ELSE <result_else> ]
   END;
   ```

각 형태의 상세 구문과 예제는 원문의 하위 페이지에서 확인할 수 있습니다.
