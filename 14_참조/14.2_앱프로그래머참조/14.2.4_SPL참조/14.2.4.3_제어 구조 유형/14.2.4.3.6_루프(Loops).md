# 루프 (Loops) — EPAS 18 SPL 참조

> 원문: [EPAS v18 — SPL reference › Types of control structures › Loops](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/05_control_structures/06_loops/)
> EPAS v18 공식 문서 내용을 정리한 한국어 설명입니다. 구문·키워드·함수 이름은 원문 그대로 표기했습니다.

`LOOP`, `EXIT`, `CONTINUE`, `WHILE`, `FOR` 문을 사용하면 SPL 프로그램이 일련의 명령을 반복(repeat)할 수 있습니다.

## 주요 반복 구조

1. **LOOP** — 기본 무한 루프 구조. 내부에서 `EXIT`로 벗어납니다.

   ```text
   [ <<label>> ]
   LOOP
       <statements>
   END LOOP [ label ];
   ```

2. **EXIT** — 루프 실행을 종료합니다. `EXIT WHEN <condition>` 형태로 조건부 탈출도 가능합니다.

   ```text
   EXIT [ label ] [ WHEN <boolean-expression> ];
   ```

3. **CONTINUE** — 현재 반복을 건너뛰고 다음 반복으로 넘어갑니다. `CONTINUE WHEN <condition>` 형태도 가능합니다.

4. **WHILE** — 조건이 참인 동안 반복하는 조건 루프입니다.

   ```text
   [ <<label>> ]
   WHILE <boolean-expression> LOOP
       <statements>
   END LOOP [ label ];
   ```

5. **FOR (정수 변형)** — 정수 범위를 기반으로 반복합니다.

   ```text
   [ <<label>> ]
   FOR <name> IN [ REVERSE ] <expression> .. <expression> LOOP
       <statements>
   END LOOP [ label ];
   ```

레이블(`<<label>>`)을 사용하면 중첩 루프에서 특정 루프를 지정해 `EXIT`/`CONTINUE`할 수 있습니다. 각 형태의 상세 동작과 예제는 원문 페이지에서 확인할 수 있습니다.
