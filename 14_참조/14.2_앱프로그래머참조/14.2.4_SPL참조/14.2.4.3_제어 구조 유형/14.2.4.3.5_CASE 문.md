# CASE 문 (CASE statement) — EPAS 18 SPL 참조

> 원문: [EPAS v18 — SPL reference › Types of control structures › CASE statement](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/05_control_structures/05_case_statement/)
> EPAS v18 공식 문서 내용을 정리한 한국어 설명입니다. 구문·키워드·함수 이름은 원문 그대로 표기했습니다.

`CASE` 문은 지정한 검색 조건(search condition)이 참(`TRUE`)일 때 하나 이상의 문(statement) 집합을 실행합니다. `CASE` 문은 독립적으로 쓰이는 **문**인 반면, `CASE` 표현식은 반드시 표현식의 일부로 나타나야 한다는 점이 중요한 차이입니다.

## 두 가지 형태

1. **선택자 CASE 문 (Selector CASE statement)** — 선택자 값을 비교하여 일치하는 분기의 문을 실행합니다.

   ```text
   CASE <selector>
       WHEN <value_1> THEN <statements_1>
       [ WHEN <value_2> THEN <statements_2> ]...
       [ ELSE <statements_else> ]
   END CASE;
   ```

2. **검색 CASE 문 (Searched CASE statement)** — 검색 조건을 직접 평가하여 참인 분기의 문을 실행합니다.

   ```text
   CASE
       WHEN <boolean_expr_1> THEN <statements_1>
       [ WHEN <boolean_expr_2> THEN <statements_2> ]...
       [ ELSE <statements_else> ]
   END CASE;
   ```

`ELSE` 절이 없고 어떤 `WHEN` 조건도 일치하지 않으면 `CASE_NOT_FOUND` 예외가 발생합니다. 상세 구문·예제는 원문의 하위 페이지에서 확인할 수 있습니다.
