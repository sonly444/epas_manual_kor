# RETURN 문 (RETURN statement) — EPAS 18 SPL 참조

> 원문: [EPAS v18 — SPL reference › Types of control structures › RETURN statement](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/05_control_structures/02_return_statement/)
> EPAS v18 공식 문서 내용을 정리한 한국어 설명입니다. 구문·키워드·함수 이름은 원문 그대로 표기했습니다.

`RETURN` 문은 현재의 함수·프로시저·익명 블록을 종료하고 호출자(caller)에게 제어를 돌려줍니다.

## 두 가지 형태

**값을 반환하지 않는 형태** — void를 반환하는 프로시저나 함수에서 사용합니다.

```sql
RETURN;
```

**값을 반환하는 형태** — 호출 코드로 값을 되돌려 줍니다. 이때 표현식은 함수의 반환 타입(return type)과 동일한 데이터 타입으로 평가되어야 합니다.

```sql
RETURN <expression>;
```

## 예제

다음 함수는 계산된 값을 반환하는 형태를 보여줍니다. 급여와 수당의 합에 24를 곱해 연간 보상액을 계산합니다.

```sql
CREATE OR REPLACE FUNCTION emp_comp (
    p_sal           NUMBER,
    p_comm          NUMBER
) RETURN NUMBER
IS
BEGIN
    RETURN (p_sal + NVL(p_comm, 0)) * 24;
END emp_comp;
```

핵심 차이는 문맥입니다. 프로시저나 void 반환 블록은 첫 번째 형태를, 값을 반환하는 함수는 선언된 반환 타입과 일치하는 표현식을 갖는 두 번째 형태를 사용합니다.
