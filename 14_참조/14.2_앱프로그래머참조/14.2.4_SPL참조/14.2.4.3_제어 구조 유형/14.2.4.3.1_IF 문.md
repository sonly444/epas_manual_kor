# IF 문 (IF statement) — EPAS 18 SPL 참조

> 원문: [EPAS v18 — SPL reference › Types of control structures › IF statement](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/05_control_structures/01_if_statement/)
> EPAS v18 공식 문서 내용을 정리한 한국어 설명입니다. 구문·키워드·함수 이름은 원문 그대로 표기했습니다.

`IF` 문은 특정 조건에 따라 명령을 실행하게 해줍니다. EDB Postgres Advanced Server의 SPL은 다음 네 가지 형태를 지원합니다.

1. **IF-THEN** — 기본 조건 실행. 조건이 참일 때만 문 블록을 실행합니다.
2. **IF-THEN-ELSE** — 조건이 거짓일 때 실행할 대체(fallback) 분기를 둡니다.
3. **IF-THEN-ELSE IF** — 여러 조건을 중첩(chaining)하여 처리합니다.
4. **IF-THEN-ELSIF-ELSE** — 여러 분기와 마지막 `ELSE` 절을 함께 둡니다.

기본 구문 형태는 다음과 같습니다.

```text
IF <boolean-expression> THEN
    <statements>
[ ELSIF <boolean-expression> THEN
    <statements> ]...
[ ELSE
    <statements> ]
END IF;
```

각 형태의 상세 구문과 예제는 원문의 하위 페이지에서 확인할 수 있습니다.
