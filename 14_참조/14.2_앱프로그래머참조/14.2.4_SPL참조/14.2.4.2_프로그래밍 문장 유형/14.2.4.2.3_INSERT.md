# INSERT — EPAS 18 SPL 참조

> 원문: [EPAS v18 — SPL reference › Types of programming statements › INSERT](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/04_basic_statements/03_insert/)
> EPAS v18 공식 문서의 한글 전문 번역입니다. 코드·키워드·함수/파라미터 이름은 원문 그대로 보존했습니다.

SQL 언어에서 제공하는 `INSERT` 명령을 SPL 프로그램 안에서 사용할 수 있습니다.

SQL `INSERT` 명령에서 표현식이 허용되는 자리에는 어디든 SPL 언어의 표현식을 사용할 수 있습니다. 따라서 SPL 변수와 매개변수를 사용해 삽입 연산에 값을 공급할 수 있습니다.

다음 예제는 호출 프로그램에서 전달된 데이터를 사용하여 새 사원을 삽입하는 프로시저입니다.

```sql
CREATE OR REPLACE PROCEDURE emp_insert (
    p_empno         IN emp.empno%TYPE,
    p_ename         IN emp.ename%TYPE,
    p_job           IN emp.job%TYPE,
    p_mgr           IN emp.mgr%TYPE,
    p_hiredate      IN emp.hiredate%TYPE,
    p_sal           IN emp.sal%TYPE,
    p_comm          IN emp.comm%TYPE,
    p_deptno        IN emp.deptno%TYPE
)
IS
BEGIN
    INSERT INTO emp VALUES (
        p_empno,
        p_ename,
        p_job,
        p_mgr,
        p_hiredate,
        p_sal,
        p_comm,
        p_deptno);

    DBMS_OUTPUT.PUT_LINE('Added employee...');
    DBMS_OUTPUT.PUT_LINE('Employee # : ' || p_empno);
    DBMS_OUTPUT.PUT_LINE('Name       : ' || p_ename);
    DBMS_OUTPUT.PUT_LINE('Job        : ' || p_job);
    DBMS_OUTPUT.PUT_LINE('Manager    : ' || p_mgr);
    DBMS_OUTPUT.PUT_LINE('Hire Date  : ' || p_hiredate);
    DBMS_OUTPUT.PUT_LINE('Salary     : ' || p_sal);
    DBMS_OUTPUT.PUT_LINE('Commission : ' || p_comm);
    DBMS_OUTPUT.PUT_LINE('Dept #     : ' || p_deptno);
    DBMS_OUTPUT.PUT_LINE('----------------------');
EXCEPTION
    WHEN OTHERS THEN
        DBMS_OUTPUT.PUT_LINE('OTHERS exception on INSERT of employee # '
            || p_empno);
        DBMS_OUTPUT.PUT_LINE('SQLCODE : ' || SQLCODE);
        DBMS_OUTPUT.PUT_LINE('SQLERRM : ' || SQLERRM);
END;
```

예외(exception)가 발생하면 프로시저에서 수행한 모든 데이터베이스 변경이 롤백(rollback)됩니다. 이 예제에서 `WHEN OTHERS` 절이 있는 `EXCEPTION` 섹션은 모든 예외를 잡습니다. 두 개의 변수가 표시됩니다. `SQLCODE`는 발생한 특정 예외를 식별하는 숫자이고, `SQLERRM`은 오류를 설명하는 텍스트 메시지입니다. 자세한 내용은 "예외 처리(Exception handling)"를 참조하십시오.

이 프로시저를 실행하면 다음과 같은 출력이 나타납니다.

```sql
EXEC emp_insert(9503,'PETERSON','ANALYST',7902,'31-MAR-05',5000,NULL,40);

Added employee...
Employee # : 9503
Name       : PETERSON
Job        : ANALYST
Manager    : 7902
Hire Date  : 31-MAR-05 00:00:00
Salary     : 5000
Dept #     : 40
----------------------

SELECT * FROM emp WHERE empno = 9503;
```

출력:

```text
 empno | ename  |  job   | mgr  |      hiredate     |   sal   | comm | deptno
-------+--------+--------+------+-------------------+---------+------+-------
  9503 |PETERSON| ANALYST| 7902 | 31-MAR-05 00:00:00| 5000.00 |      |   40
(1 row)
```

##### 참고

`INSERT` 명령을 `FORALL` 문에 포함할 수 있습니다. `FORALL` 문을 사용하면 하나 이상의 컬렉션에서 공급된 값으로 단일 `INSERT` 명령이 여러 행을 삽입할 수 있습니다. 자세한 내용은 "FORALL 문 사용(Using the FORALL statement)"을 참조하십시오.
