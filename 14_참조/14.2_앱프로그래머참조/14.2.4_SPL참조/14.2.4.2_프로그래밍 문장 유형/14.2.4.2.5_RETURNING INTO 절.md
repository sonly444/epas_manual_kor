# RETURNING INTO 절 — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Application programmer reference › SPL reference › Programming statements › RETURNING INTO](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/04_basic_statements/05_using_the_returning_into_clause/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 명령·코드·식별자 이름은 원문 그대로 보존했습니다.

`INSERT`, `UPDATE`, `DELETE` 명령에 선택적 `RETURNING INTO` 절을 덧붙일 수 있습니다. 이 절을 통해 SPL 프로그램은 각각 `INSERT`, `UPDATE`, `DELETE` 명령의 결과에서 새로 추가·수정·삭제된 값을 캡처할 수 있습니다.

## 구문 (Syntax)

```sql
{ <insert> | <update> | <delete> }
   RETURNING { * | <expr_1> [, <expr_2> ] ...}
     INTO { <record> | <field_1> [, <field_2> ] ...};
```

- `insert`는 유효한 `INSERT` 명령입니다.
- `update`는 유효한 `UPDATE` 명령입니다.
- `delete`는 유효한 `DELETE` 명령입니다.
- `*`를 지정하면, `INSERT`, `UPDATE`, `DELETE` 명령의 영향을 받은 행의 값이 `INTO` 키워드 오른쪽의 레코드나 필드에 할당될 수 있게 됩니다. (`*` 사용은 EDB Postgres Advanced Server 확장이며 Oracle 데이터베이스와 호환되지 않습니다.)
- `expr_1, expr_2...`는 `INSERT`, `UPDATE`, `DELETE` 명령의 영향을 받은 행에 대해 평가되는 표현식입니다. 평가 결과는 `INTO` 키워드 오른쪽의 레코드나 필드에 할당됩니다.
- `record`는 `RETURNING` 절의 값들과 개수·순서가 일치하고 데이터 타입이 호환되는 필드를 포함해야 하는 레코드의 식별자입니다.
- `field_1, field_2,...`는 `RETURNING` 절의 값 집합과 개수·순서가 일치하고 데이터 타입이 호환되어야 하는 변수들입니다.

`INSERT`, `UPDATE`, `DELETE` 명령이 둘 이상의 행을 가진 결과 집합을 반환하면, `SQLCODE 01422, query returned more than one row` 예외가 발생합니다. 결과 집합에 행이 없으면 `INTO` 키워드 뒤의 변수들은 null로 설정됩니다.

##### 참고 (Note)

`BULK COLLECT` 절을 사용하는 `RETURNING INTO`의 변형은 둘 이상의 행으로 이루어진 결과 집합을 컬렉션으로 반환하는 것을 허용합니다. 자세한 내용은 [BULK COLLECT 절 사용](https://www.enterprisedb.com/docs/epas/latest/application_programming/epas_compat_spl/12_working_with_collections/04_using_the_bulk_collect_clause/#using_the_bulk_collect_clause)을 참고하십시오.

## RETURNING INTO 절 추가 (Adding the RETURNING INTO clause)

이 예는 [UPDATE](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/04_basic_statements/07_update/#update)에서 소개된 `emp_comp_update` 프로시저를 수정하여 `RETURNING INTO` 절을 추가합니다:

```sql
CREATE OR REPLACE PROCEDURE emp_comp_update (
    p_empno         IN emp.empno%TYPE,
    p_sal           IN emp.sal%TYPE,
    p_comm          IN emp.comm%TYPE
)
IS
    v_empno         emp.empno%TYPE;
    v_ename         emp.ename%TYPE;
    v_job           emp.job%TYPE;
    v_sal           emp.sal%TYPE;
    v_comm          emp.comm%TYPE;
    v_deptno        emp.deptno%TYPE;
BEGIN
    UPDATE emp SET sal = p_sal, comm = p_comm WHERE empno = p_empno
    RETURNING
        empno,
        ename,
        job,
        sal,
        comm,
        deptno
    INTO
        v_empno,
        v_ename,
        v_job,
        v_sal,
        v_comm,
        v_deptno;

    IF SQL%FOUND THEN
        DBMS_OUTPUT.PUT_LINE('Updated Employee # : ' || v_empno);
        DBMS_OUTPUT.PUT_LINE('Name               : ' || v_ename);
        DBMS_OUTPUT.PUT_LINE('Job                : ' || v_job);
        DBMS_OUTPUT.PUT_LINE('Department         : ' || v_deptno);
        DBMS_OUTPUT.PUT_LINE('New Salary         : ' || v_sal);
        DBMS_OUTPUT.PUT_LINE('New Commission     : ' || v_comm);
    ELSE
        DBMS_OUTPUT.PUT_LINE('Employee # ' || p_empno || ' not found');
    END IF;
END;
```

`emp_insert` 프로시저로 생성된 사원 `9503`이 여전히 테이블에 존재한다고 가정할 때, 이 프로시저의 출력은 다음과 같습니다:

```sql
EXEC emp_comp_update(9503, 6540, 1200);
```

출력:

```text
Updated Employee # : 9503
Name               : PETERSON
Job                : ANALYST
Department         : 40
New Salary         : 6540.00
New Commission     : 1200.00
```

## 레코드 타입을 사용한 RETURNING INTO 절 추가 (Adding the RETURNING INTO clause using record types)

이 예는 `emp_delete` 프로시저를 수정하여 레코드 타입을 사용한 `RETURNING INTO` 절을 추가합니다:

```sql
CREATE OR REPLACE PROCEDURE emp_delete (
    p_empno         IN emp.empno%TYPE
)
IS
    r_emp           emp%ROWTYPE;
BEGIN
    DELETE FROM emp WHERE empno = p_empno
    RETURNING
        *
    INTO
        r_emp;

    IF SQL%FOUND THEN
        DBMS_OUTPUT.PUT_LINE('Deleted Employee # : ' || r_emp.empno);
        DBMS_OUTPUT.PUT_LINE('Name               : ' || r_emp.ename);
        DBMS_OUTPUT.PUT_LINE('Job                : ' || r_emp.job);
        DBMS_OUTPUT.PUT_LINE('Manager            : ' || r_emp.mgr);
        DBMS_OUTPUT.PUT_LINE('Hire Date          : ' || r_emp.hiredate);
        DBMS_OUTPUT.PUT_LINE('Salary             : ' || r_emp.sal);
        DBMS_OUTPUT.PUT_LINE('Commission         : ' || r_emp.comm);
        DBMS_OUTPUT.PUT_LINE('Department         : ' || r_emp.deptno);
    ELSE
        DBMS_OUTPUT.PUT_LINE('Employee # ' || p_empno || ' not found');
    END IF;
END;
```

이 프로시저의 출력은 다음과 같습니다:

```sql
EXEC emp_delete(9503);
```

출력:

```text
Deleted Employee # : 9503
Name               : PETERSON
Job                : ANALYST
Manager            : 7902
Hire Date          : 31-MAR-05 00:00:00
Salary             : 6540.00
Commission         : 1200.00
Department         : 40
```
