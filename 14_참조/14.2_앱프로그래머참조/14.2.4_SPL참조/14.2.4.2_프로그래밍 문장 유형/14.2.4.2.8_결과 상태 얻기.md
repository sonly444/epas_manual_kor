# 결과 상태 얻기 (Obtaining the result status) — EPAS 18 SPL 참조

> 원문: [EPAS v18 — SPL reference › Types of programming statements › Obtaining the result status](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/04_basic_statements/08_obtaining_the_result_status/)
> EPAS v18 공식 문서 내용을 정리한 한국어 설명입니다. 구문·키워드·함수 이름은 원문 그대로 표기했습니다.

명령의 실행 결과를 평가하는 데 사용하는 세 가지 SQL 속성(attribute)이 있습니다.

## SQL%FOUND

`INSERT`, `UPDATE`, `DELETE`, `SELECT INTO` 명령이 **최소 한 행 이상**에 영향을 주었으면 `TRUE`를 반환하는 불리언(Boolean) 속성입니다. 다음은 레코드를 삽입하고 성공 여부를 확인하는 예입니다.

```sql
BEGIN
    INSERT INTO emp (empno,ename,job,sal,deptno) VALUES (
        9001, 'JONES', 'CLERK', 850.00, 40);
    IF SQL%FOUND THEN
        DBMS_OUTPUT.PUT_LINE('Row has been inserted');
    END IF;
END;
```

## SQL%ROWCOUNT

영향을 받은 행의 개수를 `BIGINT` 데이터 타입으로 제공하는 속성입니다. 예를 들어 `UPDATE` 후 `'# rows updated: ' || SQL%ROWCOUNT` 형태로 개수를 조회하면 `# rows updated: 1` 과 같은 출력을 얻습니다.

## SQL%NOTFOUND

`SQL%FOUND`의 반대 속성으로, 영향을 받거나 조회된 행이 하나도 없을 때 `TRUE`를 반환합니다. 존재하지 않는 레코드를 대상으로 한 `UPDATE`는 이 조건을 발생시키며, 이를 이용해 조건 로직으로 빈 결과 집합을 처리할 수 있습니다.

이 속성들을 통해 개발자는 저장 프로시저 안에서 오류 처리를 구현하고 데이터베이스 변경의 성공 여부를 확인할 수 있습니다.
