# NULL — EPAS 18 SPL 참조

> 원문: [EPAS v18 — SPL reference › Types of programming statements › NULL](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/04_basic_statements/04_null/)
> EPAS v18 공식 문서의 한글 전문 번역입니다. 코드·키워드·함수/파라미터 이름은 원문 그대로 보존했습니다.

`NULL` 문은 SPL에서 가장 기본적인 실행 가능 구문으로, **아무 동작도 하지 않는(does nothing)** 실행 문입니다.

## 기본 구문

이 문은 다음 형태를 취합니다.

```sql
NULL;
```

## 최소 유효 프로그램

완전한 SPL 프로그램은 이 문 하나만으로도 구성될 수 있습니다.

```sql
BEGIN
    NULL;
END;
```

## 주요 용도

`NULL` 문은 실행 문이 필요한 상황에서 자리표시자(placeholder) 역할을 합니다. 특히 조건 분기에서 유용합니다. 다음 예제는 `IF-THEN-ELSE` 구조의 `THEN` 분기에 `NULL`을 두는 경우를 보여줍니다.

```sql
CREATE OR REPLACE PROCEDURE divide_it (
    p_numerator     IN  NUMBER,
    p_denominator   IN  NUMBER,
    p_result        OUT NUMBER
)
IS
BEGIN
    IF p_denominator = 0 THEN
        NULL;
    ELSE
        p_result := p_numerator / p_denominator;
    END IF;
END;
```

이 프로시저에서는 분모(denominator)가 0일 때, `NULL` 문이 다른 로직을 실행하는 대신 나눗셈 연산을 수행하지 않도록 합니다. 이를 통해 개발자는 모든 분기에 실제 기능 코드를 두지 않고도 예외적인 경우를 명시적으로 처리할 수 있습니다.
