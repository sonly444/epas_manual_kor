# DELETE — EPAS 18 SPL 참조

> 원문: [EPAS v18 — SPL reference › Types of programming statements › DELETE](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/04_basic_statements/02_delete/)
> EPAS v18 공식 문서의 한글 전문 번역입니다. 코드·키워드·함수/파라미터 이름은 원문 그대로 보존했습니다.

SQL의 `DELETE` 명령을 SPL 프로그램 안에서 사용할 수 있습니다. SQL `DELETE` 명령에서 표현식이 허용되는 자리에는 어디든 SPL 언어의 표현식을 사용할 수 있습니다. 따라서 SPL 변수와 매개변수를 사용해 삭제 연산에 값을 공급할 수 있습니다.

## 예제

다음은 삭제 연산을 구현하는 방법을 보여주는 예제입니다.

```sql
CREATE OR REPLACE PROCEDURE emp_delete (
    p_empno         IN emp.empno%TYPE
)
IS
BEGIN
    DELETE FROM emp WHERE empno = p_empno;

    IF SQL%FOUND THEN
        DBMS_OUTPUT.PUT_LINE('Deleted Employee # : ' || p_empno);
    ELSE
        DBMS_OUTPUT.PUT_LINE('Employee # ' || p_empno || ' not found');
    END IF;
END;
```

## 결과 상태

`SQL%FOUND` 조건은 행이 삭제되면 `TRUE`를, 그렇지 않으면 `FALSE`를 반환하므로 개발자가 삭제 결과를 확인할 수 있습니다.

## 고급 사용

`DELETE` 명령은 `FORALL` 문에 포함될 수 있습니다. 이를 통해 하나 이상의 컬렉션(collection)에서 공급된 값을 사용하여 단일 `DELETE` 명령으로 여러 행을 삭제할 수 있습니다.
