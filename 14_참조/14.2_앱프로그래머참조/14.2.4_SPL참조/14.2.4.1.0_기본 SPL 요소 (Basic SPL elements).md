# 기본 SPL 요소 (Basic SPL elements) — EPAS 18 SPL 참조

> 원문: [EPAS v18 — Reference › Application programmer reference › SPL reference › Basic SPL elements](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/stored_procedural_language_reference/01_basic_spl_elements/)
> EPAS v18 공식 문서의 한글 전문 번역입니다. 코드·키워드·함수/파라미터 이름은 원문 그대로 보존했습니다.

SPL 프로그램의 기본 프로그래밍 요소에는 대소문자 구분(case sensitivity)이나 사용 가능한 문자 집합(character set) 같은 측면이 포함됩니다.

## 이 섹션의 구성

1. 대소문자 구분 (Case sensitivity)
2. 식별자 (Identifiers)
3. 한정자 (Qualifiers)
4. 상수 (Constants)
5. 사용자 정의 PL/SQL 서브타입 (User-defined PL/SQL subtypes)
6. 문자 집합 (Character set)
