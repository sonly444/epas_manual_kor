# 지원되는 C 데이터 타입 (Supported C data types) — EPAS 18

> 원문: [EPAS v18 — Reference › Application programmer reference › Language element reference › Supported C data types](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/07_reference/supported_c_data_types/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 타입 이름과 코드는 원문 그대로 보존했습니다.

## 개요

ECPGPlus 애플리케이션은 SQL 타입과 C 타입이라는 두 가지 별개의 데이터 타입 시스템을 다뤄야 합니다. 시스템은 서버에서 데이터를 검색할 때 SQL 데이터 타입을 해당하는 C 변수 타입으로 자동 매핑합니다.

## 타입 변환 원칙

ECPGPlus는 대부분의 SQL 서버 타입을 유사한 C 타입으로 변환할 수 있지만, 모든 조합이 유효한 것은 아닙니다. 데이터가 호환되지 않으면 변환이 런타임에 실패할 수 있습니다. 예를 들어 문자를 포함하는 SQL character를 C integer로 변환하려는 경우입니다.

문서에 따르면 ECPGPlus는 모든 SQL 타입을 C 문자 값(`char[n]` 또는 `varchar[n]`)으로 변환할 수 있습니다. 이는 안전한 대체(fallback) 방법을 제공하지만, 효율성을 위해서는 `int`, `double`, `float`와 같은 더 자연스러운 타입이 선호되는 경우가 많습니다.

## 지원되는 C 데이터 타입

표준 C 타입:
- `short`
- `int`
- `unsigned int`
- `long long int`
- `float`
- `double`
- `char[n+1]`
- `varchar[n+1]`
- `bool`
- `typedef`를 통한 사용자 정의 타입

## pgtypeslib를 통한 확장 타입

`pgtypeslib` 런타임 라이브러리는 특수한 데이터 타입을 제공합니다.
- `timestamp`
- `interval`
- `date`
- `decimal`
- `numeric`

개발자는 애플리케이션에서 `pgtypeslib` 타입을 사용하려면 적절한 헤더 파일을 포함해야 합니다.
