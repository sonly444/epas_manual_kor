# SQLDA 구조 (The SQLDA structure) — EPAS 18

> 원문: [EPAS v18 — Reference › Application programmer reference › Language element reference › The SQLDA structure](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/07_reference/sqlda_structure/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 구조체·멤버 이름과 코드는 원문 그대로 보존했습니다.

## 개요

SQLDA 데이터 구조는 Oracle Dynamic SQL method 4의 기본 구성 요소로, 동적 SQL 문과 연관된 데이터 및 메타데이터의 컨테이너 역할을 합니다. 입력 파라미터와 결과 집합을 모두 관리합니다.

## 구조 레이아웃

SQLDA는 다음 멤버를 포함하는 C 구조체(struct)로 정의됩니다.

```c
struct SQLDA
{
  int     N; /* Number of entries             */
  char  **V; /* Variables                 */
  int    *L; /* Variable lengths          */
  short  *T; /* Variable types            */
  short **I; /* Indicators                */
  int     F; /* Count of variables discovered by DESCRIBE */
  char  **S; /* Variable names            */
  short  *M; /* Variable name maximum lengths     */
  short  *C; /* Variable name actual lengths  */
  char  **X; /* Indicator names           */
  short  *Y; /* Indicator name maximum lengths */
  short  *Z; /* Indicator name actual lengths     */
};
```

## 주요 파라미터

**N (최대 항목 수)**: `sqlald()` 함수가 할당 중에 이 값을 설정합니다. 개발자는 OPEN 또는 FETCH 연산을 실행하기 전에 실제 값을 반영하도록 조정해야 합니다.

**V (데이터 값)**: 디스크립터 유형에 따라 결과 집합 값 또는 파라미터 값을 담는 배열을 가리킵니다.

**L (값 길이)**: 각 배열 멤버는 NULL 종료 문자를 포함하여 해당 값에 사용 가능한 메모리를 지정합니다.

**T (데이터 타입)**: 숫자 타입 코드를 포함합니다. SELECT 목록 디스크립터의 경우 `sqlnul()` 함수가 타입 정보와 nullable 플래그를 추출합니다.

**I (인디케이터)**: NULL 상태를 신호합니다. 0이 아니면 NULL, 0이면 non-NULL 값을 나타냅니다.

**F (실제 개수)**: 값 또는 파라미터의 실제 개수를 반영합니다. 양수 값은 성공적인 설명을, 음수 값은 디스크립터 용량이 초과되었음을 나타냅니다.

**S, M, C**: 컬럼 또는 파라미터 이름과 그 길이 사양을 관리합니다.

**X, Y, Z**: Pro*C 호환성을 위해 인디케이터 변수 이름을 저장하지만, ECPGPlus는 이를 사용하지 않습니다.
