# 타입 코드 (Type codes) — EPAS 18

> 원문: [EPAS v18 — Reference › Application programmer reference › Language element reference › Type codes](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/07_reference/type_codes/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 코드·타입 이름은 원문 그대로 보존했습니다.

## 외부 데이터 타입의 타입 코드

다음 표는 *외부(external)* 데이터 타입의 타입 코드를 포함합니다. 외부 데이터 타입은 C 호스트 변수의 타입을 나타내는 데 사용됩니다. 애플리케이션이 파라미터에 값을 바인딩하거나 `SELECT` 목록 항목에 버퍼를 바인딩할 때, 해당 SQLDA 디스크립터 `(descriptor->T[column])`의 타입 코드를 다음 값 중 하나로 설정하십시오.

| 타입 코드 | 호스트 변수 타입 (C 데이터 타입) |
|-----------|-----------------------------------|
| `1, 2, 8, 11, 12, 15, 23, 24, 91, 94, 95, 96, 97` | `char[]` |
| `3` | `int` |
| `4, 7, 21` | `float` |
| `5, 6` | `null 종료 문자열 (char[length+1])` |
| `9` | `varchar` |
| `22` | `double` |
| `68` | `unsigned int` |

## 내부 데이터 타입의 타입 코드

다음 표는 *내부(internal)* 데이터 타입의 타입 코드를 포함합니다. 내부 타입 코드는 값이 데이터베이스에 존재하는 방식대로의 타입을 나타내는 데 사용됩니다. `DESCRIBE SELECT LIST` 문은 다음 값을 사용하여 데이터 타입 배열 `(descriptor->T[column])`을 채웁니다.

| 내부 타입 코드 | 서버 타입 |
|----------------|-----------|
| `1` | `VARCHAR2` |
| `2` | `NUMBER` |
| `8` | `LONG` |
| `11` | `ROWID` |
| `12` | `DATE` |
| `23` | `RAW` |
| `24` | `LONG RAW` |
| `96` | `CHAR` |
| `100` | `BINARY FLOAT` |
| `101` | `BINARY DOUBLE` |
| `104` | `UROWID` |
| `187` | `TIMESTAMP` |
| `188` | `TIMESTAMP W/TIMEZONE` |
| `189` | `INTERVAL YEAR TO MONTH` |
| `190` | `INTERVAL DAY TO SECOND` |
| `232` | `TIMESTAMP LOCAL_TZ` |
