# C 전처리기 지시자 (C-preprocessor directives) — EPAS 18

> 원문: [EPAS v18 — Reference › Application programmer reference › Language element reference › C-preprocessor directives](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/07_reference/c_preprocessor_directives/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 지시자·옵션·코드는 원문 그대로 보존했습니다.

ECPGPlus C 전처리기는 ECPGPlus를 호출하는 모드에 따라 두 가지 동작을 강제합니다.

- `PROC` 모드
- 비`PROC` 모드

## PROC 모드에서 컴파일

`PROC` 모드에서 ECPGPlus는 다음을 허용합니다.

- `EXEC SQL BEGIN/END DECLARE SECTION` 외부에서 호스트 변수 선언.
- 데이터 타입이 ECPG와 호환되는 한 모든 C 변수를 호스트 변수로 사용.

`-C PROC` 키워드를 포함하여 `PROC` 모드로 ECPGPlus를 호출하면, ECPG 컴파일러는 다음 C 전처리기 지시자를 준수합니다.

```c
#include
#if expression
#ifdef symbolName
#ifndef symbolName
#else
#elif expression
#endif
#define symbolName expansion
#define symbolName([macro arguments]) expansion
#undef symbolName
#defined(symbolName)
```

전처리기 지시자는 컴파일러가 받는 코드에 영향을 주거나 지시하는 데 사용됩니다. 예를 들어 다음 코드 샘플을 보십시오.

```c
#if HAVE_LONG_LONG == 1
#define BALANCE_TYPE long long
#else
#define BALANCE_TYPE double
#endif
...
BALANCE_TYPE customerBalance;
```

다음 명령줄 인수로 ECPGPlus를 호출한다고 가정합니다.

```shell
ecpg –C PROC –DHAVE_LONG_LONG=1
```

ECPGPlus는 전체 코드 조각을 변경 없이 출력 파일에 복사합니다. ECPG 파서에는 다음 토큰만 전달합니다.

```shell
long long customerBalance;
```

반면, 다음 명령줄 인수로 ECPGPlus를 호출한다고 가정합니다.

```shell
ecpg –C PROC –DHAVE_LONG_LONG=0
```

ECPG 파서는 다음 토큰을 받습니다.

```shell
double customerBalance;
```

코드가 전처리기 지시자를 사용하여 컴파일러로 보내는 코드를 필터링하는 경우, 완전한 코드는 원본 코드에 유지되고 ECPG 파서는 처리된 토큰 스트림만 봅니다.

다음 전처리기 지시자를 `EXEC` 지시자와 함께 실행할 때 호환 구문을 사용할 수도 있습니다.

```sql
EXEC ORACLE DEFINE
EXEC ORACLE UNDEF
EXEC ORACLE INCLUDE
EXEC ORACLE IFDEF
EXEC ORACLE IFNDEF
EXEC ORACLE ELIF
EXEC ORACLE ELSE
EXEC ORACLE ENDIF
EXEC ORACLE OPTION
```

예를 들어 코드에 다음이 포함되어 있다고 가정합니다.

```sql
EXEC ORACLE IFDEF HAVE_LONG_LONG;
#define BALANCE_TYPE long long
EXEC ORACLE ENDIF;
BALANCE_TYPE customerBalance;
```

다음 명령줄 인수로 ECPGPlus를 호출합니다.

```shell
ecpg –C PROC DEFINE=HAVE_LONG_LONG=1
```

ECPGPlus는 다음 토큰을 출력 파일과 ECPG 파서에 보냅니다.

```c
long long customerBalance;
```

##### 참고

`EXEC ORACLE` 전처리기 지시자는 ECPG 명령줄에 `-C PROC`를 지정한 경우에만 작동합니다.

## SELECT_ERROR 프리컴파일러 옵션 사용

ECPGPlus를 호환 모드에서 사용할 때, `SELECT_ERROR` 프리컴파일러 옵션을 사용하여 호스트 변수가 수용할 수 있는 것보다 많은 행을 포함하는 결과 집합을 프로그램이 어떻게 처리할지 지정할 수 있습니다. 구문은 다음과 같습니다.

```ini
SELECT_ERROR={YES|NO}
```

기본값은 `YES`입니다. `SELECT` 문은 결과 집합이 호스트 변수의 용량을 초과하면 오류 메시지를 반환합니다. `SELECT` 문이 호스트 변수가 수용할 수 있는 것보다 많은 행을 반환할 때 오류 메시지를 억제하려면 `NO`를 지정하십시오.

`SELECT_ERROR`는 `EXEC ORACLE OPTION` 지시자와 함께 사용합니다.

## 비PROC 모드에서 컴파일

`-C PROC` 명령줄 옵션을 포함하지 않으면:

- C 전처리기 지시자가 변경 없이 출력 파일에 복사됩니다.
- 호스트 변수로 사용하려는 각 C 변수의 타입과 이름을 `EXEC SQL BEGIN/END DECLARE` 섹션에 선언해야 합니다.

비`PROC` 모드로 호출되면 ECPG는 PostgreSQL 코어 문서에 설명된 동작을 구현합니다.
