# 테이블 파티셔닝 뷰 참조 (Table partitioning views reference) — EPAS 18

> 원문: [EPAS v18 — Reference › Application programmer reference › Table partitioning views reference](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/01_table_partitioning_views_reference/)
> EPAS v18 공식 문서의 한글 **전문 번역** 인덱스입니다. 아래 5개 뷰를 개별 리프로 전문 번역했습니다.

EDB Postgres Advanced Server는 테이블 파티션과 서브파티션에 대한 정보를 제공하는 뷰를 지원합니다.

## 목록 (5) — 13_2_1_1 ~ 5
ALL_PART_TABLES, ALL_TAB_PARTITIONS, ALL_TAB_SUBPARTITIONS, ALL_PART_KEY_COLUMNS, ALL_SUBPART_KEY_COLUMNS

> 참고: 이 뷰들은 `13_4_4_카탈로그뷰 › Oracle 카탈로그뷰`의 동일 뷰와 컬럼 정의가 같습니다.
