# ALL_PART_KEY_COLUMNS — EPAS 18 파티셔닝 뷰 참조

> 원문: [EPAS v18 — Reference › Application programmer reference › Table partitioning views reference › ALL_PART_KEY_COLUMNS](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/01_table_partitioning_views_reference/04_all_part_key_columns/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 뷰·컬럼 이름은 원문 그대로 보존했습니다.

`ALL_PART_KEY_COLUMNS` 뷰는 데이터베이스에 존재하는 파티션 테이블의 키 컬럼에 대한 정보를 제공합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `owner` | `TEXT` | 테이블의 소유자. |
| `schema_name` | `TEXT` | 테이블이 위치한 스키마의 이름. |
| `name` | `TEXT` | 컬럼이 위치한 테이블의 이름. |
| `object_type` | `CHARACTER(5)` | 호환성을 위해서만 포함됨. 항상 `TABLE`. |
| `column_name` | `TEXT` | 키가 정의된 컬럼의 이름. |
| `column_position` | `INTEGER` | 첫 번째 컬럼은 `1`, 두 번째 컬럼은 `2`, 이런 식으로 표시. |
