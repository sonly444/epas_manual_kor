# 시스템 카탈로그 (EDB 리소스 매니저) — EPAS 18 DBA 참조

> 원문: [EPAS v18 — Reference › Database administrator reference › System catalogs (EDB Resource Manager)](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/edb_resource_manager_system_catalogs/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 카탈로그·컬럼 이름은 원문 그대로 보존했습니다.

시스템 카탈로그는 EDB Resource Manager가 사용하는 리소스 그룹 정보를 저장합니다.

## edb_all_resource_groups

다음 표는 `edb_all_resource_groups` 카탈로그에서 사용 가능한 정보를 나열합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `group_name` | `name` | 리소스 그룹의 이름. |
| `active_processes` | `integer` | 리소스 그룹에서 현재 활성 프로세스 수. |
| `cpu_rate_limit` | `float8` | 리소스 그룹의 최대 CPU 속도 제한. `0`은 제한 없음을 의미. |
| `per_process_cpu_rate_limit` | `float8` | 리소스 그룹에서 현재 활성 프로세스당 최대 CPU 속도 제한. |
| `dirty_rate_limit` | `float8` | 리소스 그룹의 최대 dirty 속도 제한. `0`은 제한 없음을 의미. |
| `per_process_dirty_rate_limit` | `float8` | 리소스 그룹에서 현재 활성 프로세스당 최대 dirty 속도 제한. |

## edb_resource_group

다음 표는 `edb_resource_group` 카탈로그에서 사용 가능한 정보를 나열합니다.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `rgrpname` | `name` | 리소스 그룹의 이름. |
| `rgrpcpuratelimit` | `float8` | 리소스 그룹의 최대 CPU 속도 제한. `0`은 제한 없음을 의미. |
| `rgrpdirtyratelimit` | `float8` | 리소스 그룹의 최대 dirty 속도 제한. `0`은 제한 없음을 의미. |
