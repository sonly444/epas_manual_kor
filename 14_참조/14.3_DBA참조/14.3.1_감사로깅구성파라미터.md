# 감사 로깅 구성 파라미터 (Audit logging configuration parameters) — EPAS 18

> 원문: [EPAS v18 — Reference › Database administrator reference › Audit logging configuration parameters](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/01_audit_logging_configuration_parameters/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값·기본값은 원문 그대로 보존했습니다.

## edb_audit

데이터베이스 감사(auditing) 기능을 관리합니다. `XML`, `CSV`, 또는 `JSON` 값을 받아 지정된 파일 형식으로 감사를 활성화하며, 기본값은 `none`(감사 비활성화)입니다. 참고: 이 파라미터가 작동하려면 `logging_collector` 파라미터가 `on`으로 설정되어야 합니다.

## edb_audit_archiver

감사 로그 파일 아카이빙의 활성/비활성 여부를 제어합니다.

## edb_audit_archiver_timeout

데이터베이스 감사 로그 아카이빙 작업의 타임아웃 지속 시간을 초 단위로 지정합니다. 30초에서 하루까지의 값을 받습니다.

## edb_audit_archiver_filename_prefix

아카이빙 대상 감사 로그의 명명 패턴을 정의합니다. `edb_audit_filename` 파라미터와 일치해야 합니다. 기본값은 `audit-`입니다. `edb_audit_directory`에서 이 접두사와 일치하는 파일이 압축 및 만료 후보가 됩니다.

## edb_audit_archiver_compress_time_limit

아카이빙된 로그가 압축 대상이 되기까지의 지속 시간을 초 단위로 설정합니다. 옵션: `0`(파일이 더 이상 현재 파일이 아닐 때 즉시 압축) 또는 `-1`(시간 기반 압축 비활성화).

## edb_audit_archiver_compress_size_limit

압축 대상 여부를 트리거하는 파일 크기 임계값을 메가바이트 단위로 설정합니다. 여러 로그가 합쳐서 임계값을 초과하면 각각 개별적으로 대상이 될 수 있습니다. `-1`로 설정하면 크기 기반 압축을 비활성화합니다.

## edb_audit_archiver_compress_command

감사 로그에 실행할 압축 명령을 지정합니다. 기본값은 `gzip %p`이며, `%p`는 파일 경로를 나타냅니다.

## edb_audit_archiver_compress_suffix

압축된 감사 로그의 파일 확장자를 지정합니다. 기본값은 `.gz`입니다.

## edb_audit_archiver_expire_time_limit

아카이빙된 로그가 만료 대상이 되기까지의 지속 시간을 초 단위로 나타냅니다. `0`(파일이 더 이상 현재 파일이 아닐 때 즉시 만료) 또는 `-1`(시간 기반 만료 비활성화)을 받습니다.

## edb_audit_archiver_expire_size_limit

만료 대상 여부의 파일 크기 임계값을 메가바이트 단위로 설정합니다. 여러 로그가 합쳐서 임계값을 초과하면 각각 개별적으로 만료 대상이 됩니다. `-1`로 설정하면 크기 기반 만료를 비활성화합니다.

## edb_audit_archiver_expire_command

제거 전에 만료된 감사 로그에 실행할 명령을 지정합니다.

## edb_audit_archiver_sort_file

가장 오래된 로그 파일을 식별하는 정렬 방법을 결정합니다: `alphabetic`(파일명 기반) 또는 `mtime`(수정 시간 기반).

## edb_audit_directory

감사 로그 파일의 저장 위치를 지정합니다. 상대 경로(데이터 폴더 기준) 또는 절대 경로를 받습니다. 기본값은 `PGDATA/edb_audit`입니다.

## edb_audit_filename

감사 로그 파일명 패턴을 지정합니다. 기본값은 `audit-%Y%m%d_%H%M%S`입니다. `%Y`, `%m`과 같은 이스케이프 시퀀스는 현재 날짜/시간 값으로 대체됩니다.

## edb_audit_rotation_day

감사 파일의 로테이션 일정을 지정합니다. 유효한 값: `sun`, `mon`, `tue`, `wed`, `thu`, `fri`, `sat`, `every`, `none`. 기본값은 `every`입니다. 로테이션을 비활성화하려면 `none`, 매일 로테이션하려면 `every`를 사용합니다.

## edb_audit_rotation_size

로테이션을 강제하는 파일 크기 임계값을 메가바이트 단위로 설정합니다. 기본값은 0 MB입니다. `0`으로 설정하면 크기 기반 로테이션을 비활성화합니다.

## edb_audit_rotation_seconds

새 로그 파일을 생성하는 시간 간격을 초 단위로 설정합니다. 기본값은 `0`(비활성화)입니다.

## edb_audit_connect

연결 시도 감사를 제어합니다. 옵션: `none`(모두 비활성화), `all`(모든 시도 감사), `failed`(실패만 감사 — 기본값).

## edb_audit_disconnect

연결 해제 감사를 관리합니다. 옵션: `all`(감사 활성화) 또는 `none`(비활성화 — 기본값).

## edb_audit_statement

감사할 SQL 문 범주를 지정합니다. 다음의 조합을 받습니다: `none`, `dml`, `insert`, `update`, `delete`, `truncate`, `select`, `error`, `rollback`, `ddl`, `create`, `drop`, `alter`, `grant`, `revoke`, `set`, `copy`, `all` 및 역할 기반 패턴. 기본값은 `ddl`과 `error`입니다.

## edb_audit_tag

추적 식별자로 각 감사 로그 항목에 삽입되는 문자열 값을 받습니다.

## edb_log_every_bulk_value

대량(bulk) 작업 중 로깅 빈도를 제어합니다. `true`이면 모든 문이 개별적으로 로깅됩니다. `false`(기본값)이면 대량 작업당 하나의 통합 메시지가 행 수와 지속 시간을 기록합니다.

## edb_audit_destination

감사 로그 저장 위치를 결정합니다. `file`(기본값)로 설정하면 `edb_audit_directory` 위치에, `syslog`로 설정하면 syslog 프로세스 관리(Linux 전용, Windows 미지원)에 저장합니다.
