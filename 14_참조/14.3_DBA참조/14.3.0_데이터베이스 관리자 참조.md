# 데이터베이스 관리자 참조 (Database administrator reference) — EPAS 18

> 원문: [EPAS v18 — Reference › Database administrator reference](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/)
> EPAS v18 공식 문서의 한글 **전문 번역** 인덱스입니다. 아래 6개 페이지를 개별 리프로 전문 번역했습니다.

데이터베이스 관리자 참조는 EDB Postgres Advanced Server의 구성 파라미터, 감사 로깅, EDB*Loader 제어 파일, 리소스 매니저 카탈로그에 대한 참조 자료를 제공합니다.

## 목록 (6)

- **14_3_1 감사 로깅 구성 파라미터** — edb_audit 및 edb_audit_* 계열 파라미터(23개)
- **14_3_2 Oracle 데이터베이스와 호환되는 구성 파라미터** — edb_redwood_date, edb_redwood_raw_names, edb_redwood_strings, edb_stmt_level_tx, oracle_home
- **14_3_3 구성 파라미터 요약** — 모든 EPAS 구성 파라미터(300+)의 범위·적용시점·사용주체 요약 표
- **14_3_4 감사 로그 파일** — CSV/XML/JSON 감사 로그 형식
- **14_3_5 EDB*Loader 제어 파일 파라미터** — OPTIONS·INFILE·컬럼 정의 등 제어 파일 지시자 전체
- **14_3_6 시스템 카탈로그(EDB 리소스 매니저)** — edb_all_resource_groups, edb_resource_group
