# edb_stmt_level_tx — EPAS 18 Oracle 호환 구성 파라미터

> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터·명령·식별자 이름은 원문 그대로 보존했습니다.

## 문장 수준 트랜잭션 격리 정보

Oracle에서는 SQL 명령에서 런타임 오류가 발생하면 해당 단일 명령으로 인한 데이터베이스의 모든 업데이트가 롤백됩니다. 이를 _문장 수준 트랜잭션 격리(statement level transaction isolation)_ 라고 합니다. 예를 들어, 단일 `UPDATE` 명령이 다섯 개의 행을 성공적으로 업데이트했지만 여섯 번째 행을 업데이트하려는 시도가 예외를 발생시키면, 이 `UPDATE` 명령으로 수행된 여섯 개 행 전체에 대한 업데이트가 롤백됩니다. 아직 커밋되거나 롤백되지 않은 이전 SQL 명령의 효과는 `COMMIT` 또는 `ROLLBACK` 명령이 실행될 때까지 보류 상태로 유지됩니다.

PostgreSQL에서는 SQL 명령을 실행하는 동안 예외가 발생하면 트랜잭션 시작 이후의 데이터베이스에 대한 모든 업데이트가 롤백됩니다. 또한 트랜잭션은 중단된(aborted) 상태로 남겨지며, 다른 트랜잭션을 시작하기 전에 `COMMIT` 또는 `ROLLBACK` 명령을 실행해야 합니다.

`edb_stmt_level_tx`가 `TRUE`로 설정되면, 예외가 발생해도 이전의 커밋되지 않은 데이터베이스 업데이트가 자동으로 롤백되지 않아 Oracle 동작을 에뮬레이션합니다. `edb_stmt_level_tx`가 `FALSE`로 설정되면, 예외가 커밋되지 않은 데이터베이스 업데이트를 롤백합니다.

##### 참고 (Note)

`edb_stmt_level_tx`를 `TRUE`로 설정하면 성능에 부정적인 영향을 줄 수 있으므로 필요한 경우에만 사용하세요.

## 예제 (Example)

다음은 PSQL에서 실행한 예제로, `edb_stmt_level_tx`가 `FALSE`일 때 두 번째 `INSERT` 명령의 중단이 첫 번째 `INSERT` 명령도 롤백함을 보여줍니다. PSQL에서는 `\set AUTOCOMMIT off` 명령을 실행해야 하며, 그렇지 않으면 모든 문장이 자동으로 커밋되어 `edb_stmt_level_tx`의 효과를 보여주려는 목적이 무의미해집니다.

```sql
\set AUTOCOMMIT off
SET edb_stmt_level_tx TO off;

INSERT INTO emp (empno,ename,deptno) VALUES (9001, 'JONES', 40);
INSERT INTO emp (empno,ename,deptno) VALUES (9002, 'JONES', 00);
ERROR:  insert or update on table "emp" violates foreign key constraint
"emp_ref_dept_fk"
DETAIL:  Key (deptno)=(0) is not present in table "dept".

COMMIT;
SELECT empno, ename, deptno FROM emp WHERE empno > 9000;
```

출력(Output)

```text
empno  | ename | deptno
-------+-------+--------
(0 rows)
```

다음 예제에서는 `edb_stmt_level_tx`가 `TRUE`로 설정되어, 두 번째 `INSERT` 명령의 오류 이후에도 첫 번째 `INSERT` 명령이 롤백되지 않았습니다. 이 시점에서 첫 번째 `INSERT` 명령은 커밋하거나 롤백할 수 있습니다.

```sql
\set AUTOCOMMIT off
SET edb_stmt_level_tx TO on;

INSERT INTO emp (empno,ename,deptno) VALUES (9001, 'JONES', 40);
INSERT INTO emp (empno,ename,deptno) VALUES (9002, 'JONES', 00);
ERROR:  insert or update on table "emp" violates foreign key constraint
"emp_ref_dept_fk"
DETAIL:  Key (deptno)=(0) is not present in table "dept".

SELECT empno, ename, deptno FROM emp WHERE empno > 9000;
```

출력(Output)

```text
empno  | ename | deptno
-------+-------+--------
9001   | JONES |     40
(1 row)

COMMIT;
```

`COMMIT` 명령 대신 `ROLLBACK` 명령을 실행할 수 있습니다. 그 경우 직원 번호 `9001`의 삽입도 함께 롤백됩니다.
