# edb_redwood_raw_names — EPAS 18 Oracle 호환 구성 파라미터
> 원문: [EPAS v18 — Reference › Database administrator reference › Configuration parameters compatible with Oracle databases › edb_redwood_raw_names](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/01_introduction/02_edb_redwood_raw_names/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터·명령·식별자 이름은 원문 그대로 보존했습니다.

## 데이터베이스 객체 이름 표시 정보

`edb_redwood_raw_names`가 기본값인 `FALSE`로 설정되면, 테이블 이름, 컬럼 이름, 트리거 이름, 프로그램 이름, 사용자 이름과 같은 데이터베이스 객체 이름이 Oracle 카탈로그에서 볼 때 대문자로 나타납니다. 지원되는 카탈로그 뷰의 전체 목록은 [Catalog views](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/)를 참조하세요. 또한, 따옴표로 묶어 생성된 이름은 따옴표로 감싸져 표시됩니다.

`edb_redwood_raw_names`가 `TRUE`로 설정되면, 데이터베이스 객체 이름이 Oracle 카탈로그에서 볼 때 PostgreSQL 시스템 카탈로그에 저장된 그대로 표시됩니다. 따라서 따옴표 없이 생성된 이름은 PostgreSQL에서 예상되는 대로 소문자로 나타납니다. 따옴표로 묶어 생성된 이름은 생성된 그대로 나타나지만 따옴표는 표시되지 않습니다.

## 예제 (Example)

예를 들어, 다음과 같이 사용자 이름을 생성한 다음 해당 사용자로 세션을 시작합니다.

```sql
CREATE USER reduser IDENTIFIED BY password;
edb=# \c - reduser
Password for user reduser:
You are now connected to database "edb" as user "reduser".
```

`reduser`로 데이터베이스에 연결된 상태에서 다음 테이블을 생성합니다.

```sql
CREATE TABLE all_lower (col INTEGER);
CREATE TABLE ALL_UPPER (COL INTEGER);
CREATE TABLE "Mixed_Case" ("Col" INTEGER);
```

`edb_redwood_raw_names`를 기본값 `FALSE`로 설정한 상태에서 Oracle 카탈로그 `USER_TABLES`에서 조회하면 이름이 대문자로 나타납니다. 예외는 `Mixed_Case` 이름으로, 생성된 그대로 그리고 따옴표와 함께 나타납니다.

```sql
edb=> SELECT * FROM USER_TABLES;
```

출력(Output)

```text
 schema_name  |  table_name  | tablespace_name | status | temporary
--------------+--------------+-----------------+--------+-----------
 REDUSER      | ALL_LOWER    |                 | VALID  | N
 REDUSER      | ALL_UPPER    |                 | VALID  | N
 REDUSER      | "Mixed_Case" |                 | VALID  | N
(3 rows)
```

`edb_redwood_raw_names`를 `TRUE`로 설정한 상태에서 조회하면 `Mixed_Case` 이름을 제외한 이름이 소문자로 나타납니다. 해당 이름은 생성된 그대로 나타나지만 따옴표는 표시되지 않습니다.

```sql
edb=> SET edb_redwood_raw_names TO true;
SET
edb=> SELECT * FROM USER_TABLES;
```

출력(Output)

```text
 schema_name  | table_name | tablespace_name | status | temporary
--------------+------------+-----------------+--------+-----------
 reduser      | all_lower  |                 | VALID  | N
 reduser      | all_upper  |                 | VALID  | N
 reduser      | Mixed_Case |                 | VALID  | N
(3 rows)
```

이제 이 이름들은 PostgreSQL `pg_tables` 카탈로그에서 조회할 때의 대소문자와 일치합니다.

```sql
edb=> SELECT schemaname, tablename, tableowner FROM pg_tables WHERE
tableowner = 'reduser';
```

출력(Output)

```text
 schemaname  | tablename  | tableowner
-------------+------------+------------
 reduser     | all_lower  | reduser
 reduser     | all_upper  | reduser
 reduser     | Mixed_Case | reduser
(3 rows)
```
