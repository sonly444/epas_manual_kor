# 감사 로그 파일 (Audit Log Files) — EPAS 18 Reference

> 원문: [EPAS v18 — Reference › Database administrator reference › Audit log files](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/04_audit_log_file/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 필드·코드·로그 예시는 원문 그대로 보존했습니다.

감사 로그 파일은 CSV, XML 또는 JSON 형식으로 생성할 수 있습니다. 형식은 `edb_audit` 구성 파라미터에 의해 결정됩니다.

감사 로그의 정보는 [PostgreSQL 코어 문서](https://www.postgresql.org/docs/current/static/runtime-config-logging.html)의 "Error Reporting and Logging" 아래 "Using CSV-Format Log Output"에 설명된 대로 PostgreSQL이 수행하는 로깅에 기반합니다.

## CSV 감사 로그 형식 개요 (Overview of the CSV audit log format)

다음 표는 CSV 감사 로그 형식에 나타나는 순서대로 필드를 나열합니다. 표에는 다음 정보가 포함됩니다:

- **Field** — PostgreSQL 문서의 샘플 테이블 정의에 나온 필드 이름
- **XML element/attribute** — XML 형식의 경우, 값을 참조하는 XML 요소와 그 속성(사용되는 경우) 이름
- **Data type** — PostgreSQL 샘플 테이블 정의가 제공하는 필드의 데이터 타입
- **Description** — 필드 설명

로깅할 값이 없는 필드는 CSV 형식에서 연속된 쉼표(,,)로 나타납니다.

| Field | XML element/attribute | Data type | 설명 |
| --- | --- | --- | --- |
| `log_time` | `event/log_time` | `timestamp with time zone` | 구문의 로그 날짜/시간 |
| `user_name` | `event/user` | `text` | 구문을 실행한 데이터베이스 사용자 |
| `database_name` | `event/database` | `text` | 구문이 실행된 데이터베이스 |
| `process_id` | `event/process_id` | `integer` | 구문이 실행된 운영체제 프로세스 ID |
| `connection_from` | `event/remote_host` | `text` | 구문이 실행된 호스트와 포트 위치 |
| `session_id` | `event/session_id` | `text` | 구문이 실행된 세션 ID |
| `session_line_num` | `event/session_line_num` | `bigint` | 세션 내 구문의 순서 |
| `process_status` | `event/process_status` | `text` | 처리 상태 |
| `session_start_time` | `event/session_start_time` | `timestamp with time zone` | 세션이 시작된 날짜/시간 |
| `virtual_transaction_id` | `event/virtual_transaction_id` | `text` | 구문의 가상 트랜잭션 ID |
| `transaction_id` | `event/transaction_id` | `bigint` | 구문의 일반 트랜잭션 ID |
| `error_severity` | `error_severity` | `text` | 구문 심각도. 감사된 구문은 `AUDIT`, 결과 오류 메시지는 `ERROR` |
| `sql_state_code` | `event/sql_state_code` | `text` | 구문에 대해 반환된 SQL 상태 코드. XML 로그 형식에서 값이 00000이면 로깅되지 않음 |
| `message` | `message` | `text` | 실행이 시도된 SQL 구문 |
| `detail` | `detail` | `text` | 오류 메시지 상세 |
| `hint` | `hint` | `text` | 오류에 대한 힌트 |
| `internal_query` | `internal_query` | `text` | 오류를 일으킨 내부 쿼리(있는 경우) |
| `internal_query_pos` | `internal_query_pos` | `integer` | 내부 쿼리에서의 오류 위치 문자 수 |
| `context` | `context` | `text` | 오류 컨텍스트 |
| `query` | `query` | `text` | 오류를 일으킨 사용자 쿼리. 오류 전용 |
| `query_pos` | `query_pos` | `integer` | 쿼리에서의 오류 위치 문자 수. 오류 전용 |
| `location` | `location` | `text` | 소스 코드에서 오류의 위치. `log_error_verbosity`가 verbose로 설정되면 채워짐 |
| `application_name` | `event/application_name` | `text` | 구문이 실행된 애플리케이션 이름(예: `psql.bin`) |
| `backend_type` | `event/backend_type` | `text` | `pg_stat_activity.backend_type`이 보여주는 것에 해당하며 csv 로그에 컬럼으로 추가됨 |
| `leader_pid` | `event/leader_pid` | `integer` | 활성 병렬 워커의 리더 프로세스 ID |
| `query_id` | `event/query_id` | `long` | 이 백엔드의 가장 최근 쿼리 식별자 |
| `command_tag` | `event/command_tag` | `text` | 구문의 SQL 명령 |
| `audit_tag` | `event/audit_tag` | `text` | 구성 파일의 `audit_tag` 파라미터로 지정된 값 |
| `type` | `event/type` | `text` | 로그에서 메시지를 식별하기 위한 감사 `event_type`을 결정 |

다음 예들은 CSV와 XML 형식으로 생성됩니다.

`postgresql.conf` 파일의 비기본 감사 설정은 다음과 같습니다:

```ini
logging_collector = 'on'
edb_audit = 'csv'
edb_audit_connect = 'all'
edb_audit_disconnect = 'all'
edb_audit_statement = 'ddl, dml, select, error'
edb_audit_tag = 'edbaudit'
```

XML 형식을 생성할 때는 `edb_audit` 파라미터를 `xml`로 변경합니다.

감사된 세션은 다음과 같습니다:


## JSON 감사 로그 형식 개요 (Overview of the JSON audit log format)

`edb_audit` 파라미터의 값으로 `json`을 포함하면([구성 파라미터 요약](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/02_summary_of_configuration_parameters/) 참고) 로그 파일을 다양한 프로그램으로 가져올 수 있습니다. 이 옵션은 JSON 형식의 로그 라인을 생성합니다.

다음 표는 JSON 키와 연관된 값을 보여줍니다. null 값을 가진 문자열 필드는 출력에서 제외됩니다.

| 키 이름 | 타입 | 설명 |
| --- | --- | --- |
| timestamp | string | 밀리초 단위 타임스탬프 |
| user | string | 사용자 이름 |
| dbname | string | 데이터베이스 이름 |
| pid | number | 프로세스 ID |
| remote_host | string | 클라이언트 호스트 |
| remote_port | number | 클라이언트 포트 |
| session_id | string | 세션 ID |
| line_num | number | 세션별 라인 번호 |
| ps | string | 현재 ps 표시 |
| session_start | string | 세션 시작 시간 |
| vxid | string | 가상 트랜잭션 ID |
| txid | string | 일반 트랜잭션 ID |
| error_severity | string | 오류 심각도 |
| state_code | string | SQLSTATE 코드 |
| message | string | 오류 메시지 |
| detail | string | 오류 메시지 상세 |
| hint | string | 오류 메시지 힌트 |
| internal_query | string | 오류를 일으킨 내부 쿼리 |
| internal_position | number | 내부 쿼리에서의 커서 인덱스 |
| context | string | 오류 컨텍스트 |
| statement | string | 클라이언트가 제공한 쿼리 문자열 |
| cursor_position | number | 쿼리 문자열에서의 커서 인덱스 |
| func_name | string | 오류 위치 함수 이름 |
| file_name | string | 오류 위치의 파일 이름 |
| file_line_num | number | 오류 위치의 파일 라인 번호 |
| application_name | string | 클라이언트 애플리케이션 이름 |
| backend_type | string | 백엔드 타입 |
| leader_pid | number | 활성 병렬 워커의 리더 프로세스 ID |
| query_id | number | 쿼리 ID |
| command_tag | string | 구문의 SQL 명령 |
| audit_tag | string | 구성 파일의 `audit_tag` 파라미터로 지정된 값 |
| event_type | string | 로그에서 메시지를 식별하기 위한 감사 `event_type`을 결정 |
