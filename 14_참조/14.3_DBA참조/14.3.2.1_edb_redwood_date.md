# edb_redwood_date — EPAS 18 Oracle 호환 구성 파라미터
> 원문: [EPAS v18 — Reference › Database administrator reference › Configuration parameters compatible with Oracle databases › edb_redwood_date](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/01_introduction/01_edb_redwood_date/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터·명령·식별자 이름은 원문 그대로 보존했습니다.

`DATE`는 명령에서 컬럼의 데이터 타입으로 나타날 수 있습니다. 테이블 정의가 데이터베이스에 저장될 때 이를 `TIMESTAMP`로 변환하려면 구성 파라미터 `edb_redwood_date`를 `TRUE`로 설정합니다. 이 경우 컬럼에는 날짜와 함께 시간 구성 요소가 저장됩니다. 이는 Oracle의 `DATE` 데이터 타입과 일관됩니다.

`edb_redwood_date`가 `FALSE`로 설정되면, `CREATE TABLE` 또는 `ALTER TABLE` 명령에서 컬럼의 데이터 타입은 네이티브 PostgreSQL `DATE` 데이터 타입으로 유지됩니다. 그리고 그대로 데이터베이스에 저장됩니다. PostgreSQL `DATE` 데이터 타입은 컬럼에 시간 구성 요소 없이 날짜만 저장합니다.

`edb_redwood_date`의 설정과 관계없이, `DATE`가 다른 컨텍스트에서 데이터 타입으로 나타날 때는 항상 내부적으로 `TIMESTAMP`로 변환되며, 따라서 시간 구성 요소가 있으면 이를 처리할 수 있습니다. 이러한 컨텍스트에는 SPL 선언 섹션에서 변수의 데이터 타입, SPL 프로시저 또는 SPL 함수에서 형식 매개변수의 데이터 타입, 또는 SPL 함수의 반환 타입이 포함됩니다.
