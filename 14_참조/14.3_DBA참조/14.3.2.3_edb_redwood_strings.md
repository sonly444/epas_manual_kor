# edb_redwood_strings — EPAS 18 Oracle 호환 구성 파라미터
> 원문: [EPAS v18 — Reference › Database administrator reference › Configuration parameters compatible with Oracle databases › edb_redwood_strings](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/01_introduction/03_edb_redwood_strings/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터·명령·식별자 이름은 원문 그대로 보존했습니다.

## 연결(concatenation) 후 문자열 표시 정보

Oracle에서는 문자열이 null 변수 또는 null 컬럼과 연결(concatenate)될 때 그 결과가 원래 문자열이 됩니다. 그러나 PostgreSQL에서는 문자열과 null 변수 또는 null 컬럼의 연결이 null 결과를 반환합니다.

`edb_redwood_strings` 파라미터가 `TRUE`로 설정되면, 연결 연산은 Oracle이 하는 것처럼 원래 문자열을 결과로 반환합니다. `edb_redwood_strings`가 `FALSE`로 설정되면, 네이티브 PostgreSQL 동작이 유지됩니다.

## 예제 (Example)

샘플 애플리케이션에는 직원 테이블이 있습니다. 이 테이블에는 대부분의 직원에 대해 null인 `comm`이라는 컬럼이 있습니다. 다음 쿼리는 `edb_redwood_string`을 `FALSE`로 설정한 상태에서 실행됩니다. null 컬럼과 비어 있지 않은 문자열의 연결은 최종 결과로 null을 생성하므로, 커미션이 있는 직원만 쿼리 결과에 나타납니다. 다른 모든 직원에 대한 출력 줄은 null입니다.

```sql
SET edb_redwood_strings TO off;

SELECT RPAD(ename,10) || ' ' || TO_CHAR(sal,'99,999.99') || ' ' ||
TO_CHAR(comm,'99,999.99') "EMPLOYEE COMPENSATION" FROM emp;
```

출력(Output)

```text
    EMPLOYEE COMPENSATION
----------------------------------

 ALLEN        1,600.00     300.00
 WARD         1,250.00     500.00

 MARTIN       1,250.00   1,400.00

 TURNER       1,500.00        .00

(14 rows)
```

다음은 `edb_redwood_strings`가 `TRUE`로 설정된 상태에서 실행된 동일한 쿼리입니다. 여기서는 null 컬럼의 값이 빈 문자열로 처리됩니다. 빈 문자열과 비어 있지 않은 문자열의 연결은 비어 있지 않은 문자열을 생성합니다. 이 결과는 동일한 쿼리에 대해 Oracle이 생성하는 결과와 일관됩니다.

```sql
SET edb_redwood_strings TO on;

SELECT RPAD(ename,10) || ' ' || TO_CHAR(sal,'99,999.99') || ' ' ||
TO_CHAR(comm,'99,999.99') "EMPLOYEE COMPENSATION" FROM emp;
```

출력(Output)

```text
   EMPLOYEE COMPENSATION
----------------------------------
SMITH          800.00
ALLEN        1,600.00     300.00
WARD         1,250.00     500.00
JONES        2,975.00
MARTIN       1,250.00   1,400.00
BLAKE        2,850.00
CLARK        2,450.00
SCOTT        3,000.00
KING         5,000.00
TURNER       1,500.00        .00
ADAMS        1,100.00
JAMES          950.00
FORD         3,000.00
MILLER       1,300.00
(14 rows)
```
