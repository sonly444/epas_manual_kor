# Oracle 데이터베이스와 호환되는 구성 파라미터 (Configuration parameters compatible with Oracle databases) — EPAS 18

> 원문: [EPAS v18 — Reference › Database administrator reference › Configuration parameters compatible with Oracle databases](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/01_introduction/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름·값은 원문 그대로 보존했습니다.

EDB Postgres Advanced Server는 구성 파라미터로 제어되는 조정 가능한 시스템 동작을 통해 애플리케이션이 PostgreSQL과 Oracle 양쪽에서 작동할 수 있게 합니다.

## 주요 파라미터

다섯 가지 주요 구성 파라미터가 있습니다.

**edb_redwood_date** — DATE 컬럼에 시간 구성 요소가 저장되는지 여부를 제어합니다. TRUE로 설정하면 Oracle 호환 동작이 활성화됩니다.

**edb_redwood_raw_names** — 데이터베이스 객체 이름이 Oracle 시스템 카탈로그에서 볼 때 대문자로 나타날지 소문자로 나타날지 제어합니다. 기본값 FALSE는 Oracle 호환성을 제공합니다.

**edb_redwood_strings** — 문자열 연결(concatenation) 연산에서 NULL을 빈 문자열과 동등하게 취급합니다. TRUE로 활성화하면 Oracle 동작과 일치합니다.

**edb_stmt_level_tx** — 중단된 SQL 명령의 자동 롤백을 문 수준(statement level) 롤백으로만 격리합니다. 이는 PostgreSQL의 기본 트랜잭션 수준 롤백과 다르며 신중하게 사용해야 합니다.

**oracle_home** — 서버를 적절한 Oracle 설치 디렉터리로 안내합니다.

## 목적

이 파라미터들은 관리자가 PostgreSQL-Oracle 호환성 스펙트럼을 따라 시스템 동작을 튜닝할 수 있게 하여, 단일 데이터베이스 플랫폼 내에서 서로 다른 애플리케이션 요구 사항과 마이그레이션 시나리오를 수용합니다.
