# oracle_home — EPAS 18 Oracle 호환 구성 파라미터
> 원문: [EPAS v18 — Reference › Database administrator reference › Configuration parameters compatible with Oracle databases › oracle_home](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/01_introduction/05_oracle_home/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터·명령·식별자 이름은 원문 그대로 보존했습니다.

Oracle 서버로의 링크를 생성하기 전에, EDB Postgres Advanced Server가 올바른 Oracle 홈 디렉터리를 가리키도록 지정해야 합니다. Linux에서는 `LD_LIBRARY_PATH` 환경 변수(또는 Windows에서는 `PATH`)를 Oracle 클라이언트 설치 디렉터리의 `lib` 디렉터리로 설정합니다.

또는, `postgresql.conf` 파일에서 `oracle_home` 구성 파라미터 값을 설정할 수도 있습니다. `oracle_home` 구성 파라미터에 지정된 값은 Linux에서는 `LD_LIBRARY_PATH` 환경 변수를, Windows에서는 `PATH` 환경 변수를 재정의합니다.

##### 참고 (Note)

`oracle_home` 구성 파라미터는 Oracle 클라이언트, 즉 `OCI` 라이브러리에 대한 올바른 경로를 제공해야 합니다.

## 구성 파라미터 설정

`postgresql.conf` 파일에서 `oracle_home` 구성 파라미터를 설정하려면 다음 줄을 추가합니다.

```ini
oracle_home = 'lib_directory'
```

`lib_directory`에는 Linux에서는 `libclntsh.so`를, Windows에서는 `oci.dll`을 포함하는 Oracle 클라이언트 설치 디렉터리에 대한 `oracle_home` 경로 이름을 대체하여 입력합니다.

## 서버 재시작

`oracle_home` 구성 파라미터를 설정한 후에는 변경 사항이 적용되도록 서버를 재시작해야 합니다. 서버를 재시작합니다.

- Linux에서는 `systemctl` 명령 또는 `pg_ctl` 서비스를 사용합니다.
- Windows에서는 Windows 서비스 콘솔에서 재시작합니다.
