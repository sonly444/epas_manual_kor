# 구성 파라미터 요약 (Summary of configuration parameters) — EPAS 18

> 원문: [EPAS v18 — Reference › Database administrator reference › Summary of configuration parameters](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/02_summary_of_configuration_parameters/)
> EPAS v18 공식 문서의 한글 **전문 번역**입니다. 파라미터 이름과 속성 값은 원문 그대로 보존했습니다.

이 요약 표는 EDB Postgres Advanced Server의 모든 구성 파라미터를 그 범위, 적용 시점, 수정에 필요한 권한 같은 주요 속성과 함께 나열합니다.

표는 다음 속성별로 파라미터를 정리합니다.

- **Parameter(파라미터)**: 구성 설정 이름과 간단한 기능 설명. `(EPAS only)` 표시는 EDB Postgres Advanced Server 전용 파라미터임을 의미합니다.
- **Scope(범위)**: 설정이 클러스터 전체(`Cluster`), 데이터베이스별(`Database`), 또는 세션별(`Session`)로 적용되는지 여부.
- **In effect(적용 시점)**: 변경이 적용되는 방식 — `Preset`(미리 설정됨/변경 불가), `Restart`(재시작 필요), `Reload`(재로드 필요), `Immediately`(즉시).
- **Used by(사용 주체)**: 파라미터를 수정하는 데 필요한 계정 유형 또는 역할 — `EPAS account`(EPAS 계정), `User`(사용자), `Superuser`(슈퍼유저), `n/a`(해당 없음).
